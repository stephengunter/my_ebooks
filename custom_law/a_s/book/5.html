海關緝私條例 5 處分程序

處分書之製作與送達

  • 海關依照《海關緝私條例》作出的處罰決定：
    • 必須製作成正式的「處分書」，並送達給受處罰的人。讓他知道被罰了什麼、為什麼被罰、以及如何救濟。
    但如果處罰是「沒收貨物」，而貨物所有人不明（不知道貨主是誰），就無法送達給特定人，此時可以：
    • 用「公告」或刊登在政府公報、新聞紙上的方式來代替送達。
簡單說：
  • 處罰決定須以書面處分書送達當事人。
  • 若貨物所有人不明，則以公告代替送達。
詳情解析
  • 「海關依本條例處分之緝私案件」
    • 適用前提：限於海關依本條例所為之「處分」（如罰鍰、沒入、追徵稅款等），不含單純之通知。
  • 「應製作處分書送達受處分人」
    原則規定：
    • 海關應「製作處分書」（書面要式性）。處分書應載明處分主旨、事實、理由、法令依據及救濟途徑。
    • 處分書應「送達受處分人」（使處分對其發生效力）。
  • 「但裁處沒入貨物或物品之所有人不明者」
    例外前提：
    • 限於「沒入」處分，且貨物或物品之「所有人不明」。
    • 常見於走私案件，貨物被查獲時無法查明貨主。
  • 「其送達以公告或刊登政府公報或新聞紙代替之」
    替代送達方式：
    • 以「公告」（張貼於海關公告欄或網站）或「刊登政府公報」或「刊登新聞紙」之方式為之。
    • 該公告或刊登視為合法送達，並自公告或刊登之日起發生送達效力。
舉個例子
例1（處分書送達）
  • 海關查獲A公司私運貨物，依法裁處罰鍰並沒入貨物。
  • 海關製作處分書，載明處分理由、依據及救濟途徑，送達A公司。
  • → 符合第46條本文（海關應製作處分書送達受處分人）。
例2（所有人不明——公告送達）
  • 海關查獲一批走私農產品，惟無法查明貨主。
  • 海關依法裁處沒入該批農產品，並以公告方式代替送達，將沒入處分公告於海關公告欄及網站。
  • → 符合第46條但書（所有人不明者，以公告代替送達）。
例3（刊登政府公報）
  • 海關查獲一批無主私貨，依法裁處沒入，並將沒入處分刊登於政府公報，以完成送達程序。
  • → 符合第46條但書（刊登政府公報代替送達）。
相關規定
  • 第46條
    • 海關依本條例處分之緝私案件，應製作處分書送達受處分人。
      • 但裁處沒入貨物或物品之所有人不明者，其送達以公告或刊登政府公報或新聞紙代替之。
記憶口訣
  • 緝私處分要書面，應送達受處分人；
  • 所有人若不明者，公告公報代送達。

復查程序

  • 受處罰的人或利害關係人，如果對海關的處分不服：
    • 可以在收到處分書的隔天開始算「30天內」，依照規定的格式寫成書面申請書，向原來作處分的海關申請「復查」。
  • 海關收到申請書後，原則上要在「2個月內」作出復查決定，並製作復查決定書。
    • 如果有必要（例如案情複雜），可以延長一次，最長再延2個月。
  • 復查決定書的正本，必須在決定的隔天起「15天內」送達給受處分人。
簡單說：
  • 不服處分可在30天內申請復查。
  • 海關應在2個月內作決定（可延長一次2個月），決定書須在15天內送達。
詳情解析
第1項
  • 「受處分人及利害關係人不服前條處分者」
    申請主體：
    • 「受處分人」：直接受海關處分之相對人。
    • 「利害關係人」：雖非受處分人，但權益因該處分而受影響之人（如貨物所有權人、保證人等）。
  • 「得於收到處分書之翌日起算三十日內」
    申請期間：
    • 自「收到處分書之翌日」起算「30日內」。
    • 末日若為星期日、國定假日或其他休息日，以該日之次日為期間之末日。
  • 「依規定格式，以書面向原處分海關申請復查」
    申請方式：
    • 須依海關規定之「格式」，以「書面」為之（不得以口頭或電話）。
    • 受理機關為「原處分海關」（即作成原處分之海關）。
第2項
  • 「海關應於接到復查申請書之翌日起算二個月內為復查決定，並作成復查決定書」
    復查決定期限與方式：
    • 自「接到復查申請書之翌日」起算「2個月內」須「作成復查決定書」（書面要式性）。
  • 「必要時，得予延長，並通知受處分人或利害關係人。延長以一次為限，最長不得逾二個月」
    延長機制：
    • 有「必要」時（如案情複雜、須調查證據等），得延長。
    • 須「通知」受處分人或利害關係人。
    • 「以一次為限」，最長「不得逾2個月」。
    • 總期限最長為4個月（2個月 + 2個月）。
第3項
  • 「復查決定書之正本，應於決定之翌日起算十五日內送達受處分人」
    決定書送達期限：
    • 自「決定之翌日」起算「15日內」。
    • 應送達「正本」予受處分人（利害關係人亦得受送達）。
舉個例子
例1（30日內申請復查）
  • A公司於113年1月1日收到海關之處分書。
  • A公司不服，於113年1月20日（30日內）以書面向原處分海關申請復查。
  • → 符合第47條第1項（收到處分書翌日起30日內申請復查）。
例2（復查決定期限）
  • 海關於113年2月1日收到A公司之復查申請書，應於113年4月1日前（2個月內）作成復查決定。
  • 若案情複雜，海關得延長一次至113年6月1日前（最長延長2個月），並應通知A公司。
  • → 符合第47條第2項（2個月內為復查決定，必要時得延長一次最長2個月）。
例3（決定書送達期限）
  • 海關於113年3月15日作成復查決定，應於113年3月30日前（15日內）將復查決定書正本送達A公司。
  • → 符合第47條第3項（決定之翌日起15日內送達）。
相關規定
  • 第47條
    1. 受處分人及利害關係人不服前條處分者，得於收到處分書之翌日起算三十日內，依規定格式，以書面向原處分海關申請復查。
    2. 海關應於接到復查申請書之翌日起算二個月內為復查決定，並作成復查決定書。
      • 必要時，得予延長，並通知受處分人或利害關係人。延長以一次為限，最長不得逾二個月。
    3. 復查決定書之正本，應於決定之翌日起算十五日內送達受處分人。
記憶口訣
  • 不服緝私三十天，書面復查原處分。
  • 海關審查兩個月，延長一次兩個月。
  • 決定書十五日送，程序期限要記牢。

復查後之救濟與確定退稅加計利息

  • 如果不服海關的復查決定，可以繼續依法提起訴願和行政訴訟。
  • 如果經過復查、訴願或行政訴訟，最後確定海關應該退還稅款：
    • 海關必須在確定的隔天起「十天內」把錢退還。
    • 而且，除了退還本金外，還要加計利息：
      • 從納稅人繳稅的隔天開始算，一直到海關開立退稅支票的那一天為止，利率按繳稅當天的郵政儲金一年期定期儲金固定利率計算。
簡單說：
  • 不服復查決定可繼續訴願及行政訴訟。
  • 確定應退稅者，海關應於十天內退還並加計利息。
詳情解析
第1項
  • 「受處分人及利害關係人不服前條復查決定者」
    • 適用主體：受處分人及利害關係人。
    • 前提：不服第47條之復查決定。
  • 「得依法提起訴願及行政訴訟」
    • 依訴願法及行政訴訟法之規定，提起訴願（向行政院或財政部為之）及行政訴訟（向高等行政法院、最高行政法院為之）。
第2項
  • 「經依復查、訴願或行政訴訟確定應退還稅款者」
    • 退稅前提：經行政救濟程序（復查、訴願、行政訴訟）「確定」應退還稅款。
  • 「海關應於確定之翌日起算十日內，予以退還」
    • 退稅期限：自「確定之翌日」起算「十日內」退還。
  • 「並自受處分人繳納該項稅款之翌日起，至填發收入退還書或國庫支票之日止」
    利息計算期間：
    • 起算日：受處分人「繳納稅款之翌日」。
    • 終止日：「填發收入退還書或國庫支票之日」。
  • 「按退稅額，依繳納稅款之日郵政儲金一年期定期儲金固定利率，按日加計利息，一併退還」
    利息計算方式：
    • 利率：以「繳納稅款之日」之郵政儲金一年期定期儲金固定利率為準。
    • 計算方式：按日加計利息。
    • 利息隨同稅款一併退還。

例3（利息計算）

  • 海關應退還本金及自110年1月2日起至填發退稅支票日止，按110年1月1日之郵政儲金一年期定期儲金固定利率計算之利息。
  • → 符合第48條第2項（利息自繳納稅款之翌日起算，利率按繳納稅款之日之利率）。
相關規定
  • 第48條
    1. 受處分人及利害關係人不服前條復查決定者，得依法提起訴願及行政訴訟。
    2. 經依復查、訴願或行政訴訟確定應退還稅款者，海關應於確定之翌日起算十日內，予以退還。
      • 並自受處分人繳納該項稅款之翌日起，至填發收入退還書或國庫支票之日止，按退稅額，依繳納稅款之日郵政儲金一年期定期儲金固定利率，按日加計利息，一併退還。
記憶口訣
  • 復查不服提訴願，訴願不服行政訟。
  • 確定退稅十日還，加計利息一併退。

假扣押或假處分之聲請與準用規定

  • 如果受處分人沒有貨物被扣押，也沒有提供擔保，海關為了防止他把財產藏起來或轉移掉，逃避罰款：
    • 可以在處分書送達後，向法院聲請「假扣押」或「假處分」（也就是暫時凍結或限制處分財產）， 而且不必提供擔保金。
    但如果受處分人事後提供了足夠的財產保證：
    • 海關就必須立刻向法院聲請撤銷假扣押或假處分。
  • 另外，關稅法關於徵收期間和退稅加計利息的規定，也適用於緝私條例的罰鍰。
簡單說：
  • 為防止脫產，海關可向法院聲請假扣押或假處分且免擔保。
  • 受處分人提供擔保後應即撤銷；執行程序準用關稅法。
詳情解析
第1項
  • 「受處分人未經扣押貨物或提供適當擔保者」
    • 適用前提：受處分人之貨物未被扣押，且未向海關提供適當之擔保（如保證金、銀行保證書等）。
  • 「海關為防止其隱匿或移轉財產以逃避執行」
    • 聲請目的在於防止受處分人「隱匿」或「移轉」財產，致將來罰鍰無從執行。
  • 「得於處分書送達後，聲請法院假扣押或假處分」
    聲請權限與時機：
    • 時機：處分書「送達後」。
    • 方式：向法院聲請「假扣押」（對金錢債權）或「假處分」（對非金錢債權之財產）。
  • 「並免提擔保」
    • 免除擔保義務：海關聲請假扣押或假處分時，無須提供擔保金。
  • 「但受處分人已提供相當財產保證者，應即聲請撤銷或免為假扣押或假處分」
    • 撤銷機制：若受處分人嗣後已「提供相當財產保證」，海關「應」即聲請撤銷或免為假扣押或假處分。
    • 此為強制義務，不得拖延。
第2項
  • 「關稅法第九條及第四十八條規定，於依本條例所處之罰鍰準用之」
    • 準用規定：
      1. 關稅法第9條：徵收期間（確定後五年內徵起，已移送執行者五年內執行）
      2. 關稅法第48條：欠稅之保全措施與限制出境
      於緝私條例所處之罰鍰準用之。
舉個例子
例1（聲請假扣押）
  • A公司因走私被處罰鍰500萬元，貨物已放行且未提供擔保。
  • 海關為防止A公司脫產，於處分書送達後向法院聲請假扣押A公司之銀行存款。
  • → 符合第49-1條第1項前段（未經扣押貨物或提供擔保者，得聲請假扣押，免提擔保）。
例2（撤銷假扣押）
  • B公司遭海關聲請假扣押後，向海關提供銀行保證書作為擔保。
  • 海關應即向法院聲請撤銷假扣押。
  • → 符合第49-1條第1項但書（已提供相當財產保證者，應即聲請撤銷假扣押）。
例3（準用關稅法）
  • C公司因緝私案件被處罰鍰，其罰鍰之徵收期間（確定後五年內徵起）及執行期間，準用關稅法第9條之規定。
  • → 符合第49-1條第2項（關稅法第九條及第四十八條規定，於本條例所處之罰鍰準用之）。
相關規定
  • 第49-1條
    1. 受處分人未經扣押貨物或提供適當擔保者，海關為防止其隱匿或移轉財產以逃避執行，得於處分書送達後，聲請法院假扣押或假處分，並免提擔保。
      • 但受處分人已提供相當財產保證者，應即聲請撤銷或免為假扣押或假處分。
    2. 關稅法第九條及第四十八條規定，於依本條例所處之罰鍰準用之。
記憶口訣
  • 處分送達未擔保，海關聲請假扣押。
  • 免提擔保防脫產，提供保證即撤銷。
  • 罰鍰準用關稅法，限制出境與保全。
