海關緝私條例 3 扣押

貨物與運輸工具之扣押

  • 海關如果查到一批貨物，認為有走私嫌疑：
    • 就「必須」把這批貨物扣押起來，不能讓它被運走或處理掉。
  • 如果這批貨物是在船、飛機或車子裡面查到的，而且案情很重大：
    • 為了方便繼續仔細搜查，海關可以「暫時」把這艘船、這架飛機或這輛車也扣下來。
    • 但是，扣押的時間只能以「完成搜查所需要的時間」為限，搜查完就要放行，不能一直扣著。
簡單說：
  • 查到走私貨物必須扣押。
  • 必要時可暫時扣押運輸工具以便搜查，但只能扣必要的時間。
詳情解析
第1項
  • 「海關查獲貨物認有違反本條例情事者」
    貨物扣押之「前提要件」：
    • 「查獲」貨物：實際發現該貨物。
    • 「認有違反本條例情事」：海關主觀上認定該貨物涉及走私行為，如私運、虛報等。
  • 「應予扣押」
    貨物扣押之「法律效果」：
    • 用語為「應」，表示海關負有扣押之「義務」，無裁量權。
    • 扣押之目的在於保全證據及確保後續沒入處分之執行。
第2項
  • 「前項貨物如係在運輸工具內查獲而情節重大者」
    運輸工具扣押之前提要件：
    1. 該違法貨物係在「運輸工具內」查獲（如船舶貨艙、貨車車廂）。
    2. 「情節重大」：如走私數量龐大、涉及管制物品、有組織性犯罪等。
  • 「為繼續勘驗與搜索，海關得扣押該運輸工具」
    運輸工具扣押之法律效果：
    • 用語為「得」，表示海關有「裁量權」，得視必要性決定是否扣押運輸工具。
    • 目的限於「繼續勘驗與搜索」，而非處罰運輸工具本身。
  • 「但以足供勘驗與搜索之時間為限」
    運輸工具扣押之時間限制：
    • 扣押時間不得超過「必要之範圍」，即以完成勘驗與搜索所需時間為限。
    • 搜索完成後應立即解除扣押，不得繼續留置。
舉個例子
例1（貨物扣押）
  • 海關於進口貨櫃中查獲夾藏未申報之菸酒，認有違反本條例情事，當場將該批菸酒予以扣押。
  • → 符合第17條第1項（查獲貨物認有違反本條例情事者，應予扣押）。
例2（運輸工具扣押）
  • 海關在一艘漁船暗艙中查獲大量走私毒品，數量龐大，案情重大。
  • 為徹底搜索全船，海關決定暫時扣押該漁船，以便繼續勘驗。
  • → 符合第17條第2項（貨物在運輸工具內查獲且情節重大，為繼續勘驗搜索，得扣押運輸工具）。
例3（扣押時間限制）
  • 海關扣押漁船後，於三日內完成全面搜索及勘驗，隨即解除對該漁船之扣押，將船舶發還船主。
  • → 符合第17條第2項但書（以足供勘驗與搜索之時間為限）。
相關規定
  • 第17條
    1. 海關查獲貨物認有違反本條例情事者，應予扣押。
    2. 前項貨物如係在運輸工具內查獲而情節重大者，為繼續勘驗與搜索，海關得扣押該運輸工具。但以足供勘驗與搜索之時間為限。
記憶口訣
  • 查獲私貨應扣押，運輸工具情節重。
  • 為續勘驗始得扣，時間以勘驗為限。

運輸工具之扣押

  • 如果船、飛機、車輛等運輸工具，依照《海關緝私條例》的規定：
    • 已經達到「應該被沒收」或「可以被沒收」的程度，海關就可以先把這些運輸工具扣押起來。
    以確保將來如果真的決定要沒收，能夠執行。
簡單說：
  • 依規定可能會被沒收的運輸工具，海關可以先扣起來。
詳情解析
  • 「船舶、航空器、車輛或其他運輸工具」
    扣押之「客體」：運輸工具。
    • 包括所有類型之運輸工具：船舶（漁船、貨輪、快艇等）、航空器（飛機、直升機等）、車輛（貨車、轎車、機車等）及其他運輸工具。
  • 「依本條例應受或得受沒入處分者」
    扣押之「實體要件」：
    • 「應受沒入處分」：該運輸工具之違法情節已達「必須」沒入之程度（如運送私貨且情節重大）。
    • 「得受沒入處分」：該運輸工具之違法情節已達「得」沒入之程度（由海關裁量是否沒入）。
    • 此要件係連結至本條例其他實體規定（如第35條、第36條等）。
  • 「海關得予以扣押」
    扣押之「法律效果」：
    • 用語為「得」，表示海關有「裁量權」，得視必要性決定是否扣押運輸工具。
    • 扣押後，若後續處分確定沒入，則運輸工具將被沒入；若未確定沒入，則應予發還。
舉個例子
例1（應受沒入）
  • A公司利用所屬貨輪走私大量管制物品。
  • 依第36條規定該貨輪「應」受沒入處分，海關依本條規定將該貨輪予以扣押。
  • → 符合第18條（運輸工具依本條例應受沒入處分者，海關得予以扣押）。
例2（得受沒入）
  • B車主將其車輛借予他人運送私貨。依第36條但書規定，該車輛「得」受沒入處分（由海關裁量）。
  • 海關先將該車輛扣押，以保全將來可能之沒入處分。
  • → 符合第18條（運輸工具依本條例得受沒入處分者，海關得予以扣押）。
例3（未達沒入要件）
  • C公司貨輪雖曾運送私貨，惟經調查認其已善盡管理監督之責，依規定「不得」沒入。
  • 海關不得依本條扣押該貨輪。
  • → 不符合第18條（運輸工具未達應受或得受沒入處分之程度，不得扣押）。
相關規定
  • 第18條
    • 船舶、航空器、車輛或其他運輸工具，依本條例應受或得受沒入處分者，海關得予以扣押。
記憶口訣
  • 運輸工具若沒入，海關得先扣押它。
  • 應受得受為要件，保全將來執行用。

扣押物之保管方式

  • 海關扣押的貨物或運輸工具，如果因為太大、太重、太多或不好搬運，沒辦法運回海關倉庫保管：
    • 海關可以先貼上封條，然後交給原來的所有人、管理人或持有人，讓他們簽立保管切結書負責保管。
    • 或者交給當地的公務機關（例如港務局）代為保管。
  • 如果交給公務機關保管：海關必須通知原所有人、管理人或持有人，讓他們知道東西在哪裡、由誰保管。
簡單說：
  • 扣到的東西若太難搬運或保管，海關可查封後交由原主或公務機關保管，但須通知相關人。
詳情解析
  • 「扣押之貨物或運輸工具，因解送困難或保管不易者」
    適用本條之「前提要件」：
    • 「解送困難」：指扣押物因體積、重量、數量或距離等因素，難以運送至海關指定處所。
    • 「保管不易」：指扣押物因性質特殊（如易腐、易燃、易爆），或數量龐大，難以在海關倉庫內妥善保管。
  • 「得由海關查封後」
    替代保管之前置程序：查封。
    • 海關須先對扣押物實施「查封」（如張貼封條、標示扣押文號等），以公示該物已受公權力拘束。
    • 查封後，該物之處分權已受限制，即使未實際移置於海關，仍具扣押效力。
  • 「交其所有人、管領人或持有人具結保管」
    替代保管方式一：交其所有人具結保管。
    • 得將扣押物交由原「所有人」（所有權人）、「管領人」（實際管理之人）或「持有人」（實際持有之人）保管。
    • 該保管人須「具結」，即出具書面保證書，承諾負責保管、不擅自處分或移轉、配合海關檢查等義務。
  • 「或交當地公務機關保管」
    替代保管方式二：交公務機關保管。
    • 得將扣押物交由當地公務機關（如港務局、警察機關、倉庫管理單位等）代為保管。
  • 「其交公務機關保管者，應通知其所有人、管領人或持有人」
    通知義務：
    • 若選擇交由公務機關保管，海關應「通知」原所有人、管領人或持有人。
    • 通知之目的在於使其知悉扣押物之去向及保管機關，以保障其權益。

舉個例子
例1（交原保管人具結保管）
  • 海關扣押一艘涉嫌走私之漁船，因體積龐大無法拖回海關碼頭。
  • 海關依法查封該船後，交由船主具結保管，船主簽立保證書承諾不擅自移動該船，並配合海關後續檢查。
  • → 符合第19條（因解送困難，查封後交所有人具結保管）。
例2（交公務機關保管）
  • 海關查獲一批數量龐大之走私貨櫃。
  • 因海關倉庫容量不足，將貨櫃查封後交由港務局之貨櫃場代為保管，並依法通知貨主。
  • → 符合第19條（因保管不易，查封後交當地公務機關保管，並通知所有人）。
例3（不適用——無解送困難或保管不易）
  • 海關查獲一批數量不多、體積不大之走私電子產品，可直接搬運至海關倉庫保管，無須適用本條之替代保管方式。
  • → 不適用第19條（無解送困難或保管不易，應逕行移置海關保管）。
相關規定
  • 第19條
    • 扣押之貨物或運輸工具，因解送困難或保管不易者，得由海關查封後，交其所有人、管領人或持有人具結保管，或交當地公務機關保管。
      • 其交公務機關保管者，應通知其所有人、管領人或持有人。
記憶口訣
  • 扣押貨物海關管，解送困難保管難。
  • 查封可交原有人，具結保管負責擔。
  • 或交公務機關管，通知所有人知悉。

扣押物之變賣、送交處理與毀棄

  • 如果扣押的貨物沒辦法交給別人保管， 或者因為是生鮮食品、化學原料等，有腐敗、變質或損壞的風險：
    • 海關可以在案件還沒有最終確定之前，就先公告變賣，把賣得的錢先保管起來。
    • 或者直接送交相關機關處理。
  • 但不管怎麼處理，都要通知貨物的所有人、管理人或持有人。
  • 為了保留證據，海關可以在處理前先留一些樣品或拍照存證。
  • 如果是容易發生危險的扣押物（例如爆裂物、有毒物質），海關可以直接銷毀掉。
簡單說：
  • 扣押物若無法保管或有腐敗、毀損之虞，海關可提前變賣或送交有關機關處理。
    • 不管怎麼處理，都要通知貨物的所有人、管理人或持有人。
  • 危險物品，海關可以直接銷毀掉。
詳情解析
第1項
  • 「扣押物有不能依前條規定處理或有腐敗、毀損之虞者」
    發動本條處置之「前提要件」：
    • 「不能依前條規定處理」：指無法依第19條交由原保管人或公務機關保管（如所有人不明、無人具結、公務機關拒絕保管等）。
    • 「有腐敗、毀損之虞」：指扣押物因性質或時間因素，有腐敗（如生鮮食品）、毀損（如機械生銹）之可能。
  • 「海關得於案件確定前，公告變賣並保管其價金」
    處置方式一：變賣。
    • 無須等待案件確定，即得先行變賣。
    • 須以「公告」方式為之（如刊登公報或網站公告）。
    • 變賣所得「價金」由海關保管，替代原扣押物。
  • 「或逕送有關機關處理」
    處置方式二：送交有關機關處理。
    • 如將農產品送農政機關檢驗或銷毀、將化學品送環保機關處理。
  • 「並通知其所有人、管領人或持有人」
    • 通知義務：無論採變賣或送交處理，均應「通知」原所有人、管領人或持有人，使其知悉扣押物之去向。
第2項
  • 「依前項規定處理之扣押物，得由海關酌予留樣或拍照存證」
    證據保全：
    • 處理前得酌予「留樣」（保留部分樣品）或「拍照存證」。
    • 目的在於日後如有爭議，仍有證據可供查證。
第3項
  • 「易生危險之扣押物，得毀棄之」
    危險物之毀棄：
    • 適用客體：易生危險之扣押物（如爆裂物、毒性化學物質、易燃品等）。
    • 效果：海關得逕行「毀棄」，無須經過變賣或公告程序。
舉個例子
例1（變賣易腐敗物品）
  • 海關查獲一批走私生鮮水果，因易腐敗，無法等待案件確定，遂依法公告變賣，將變賣所得價金保管於海關專戶，並通知貨主。
  • → 符合第20條第1項（有腐敗之虞者，得於案件確定前公告變賣並保管價金）。
例2（危險物毀棄）
  • 海關查獲一批走私工業用易燃化學品，存放於倉庫有高度危險，海關依法逕行銷毀，並拍照存證。
  • → 符合第20條第3項（易生危險之扣押物，得毀棄之）。
例3（送交有關機關處理）
  • 海關查獲一批走私動物產品，因涉及防疫檢疫，海關將該批貨物送交農業部動植物防疫檢疫署處理，並通知貨主。
  • → 符合第20條第1項（逕送有關機關處理，並通知所有人）。
相關規定
  • 第20條
    1. 扣押物有不能依前條規定處理或有腐敗、毀損之虞者，海關得於案件確定前，公告變賣並保管其價金或逕送有關機關處理，並通知其所有人、管領人或持有人。
    2. 依前項規定處理之扣押物，得由海關酌予留樣或拍照存證。
    3. 易生危險之扣押物，得毀棄之。
記憶口訣
  • 扣押物有腐敗虞，案件確定前可賣。
  • 公告變賣保管錢，或送機關來處理。
  • 留樣拍照可存證，危險物品得毀棄。

撤銷扣押之擔保制度

  • 被海關扣押的貨物或運輸工具，其所有人、管理人或持有人可以：
    1. 向海關繳交一筆與貨物價值相當的保證金。
      2. 或者
    2. 提供銀行保證書等其他擔保。
    來申請撤銷扣押，把貨物或運輸工具領回去。 這樣一來，漁船可以繼續出海作業，貨物也可以及時處理，不會因為等待案件確定而遭受損失。
  • 如果後續確定要沒收或補稅，海關就從保證金或擔保品中取償。
    • 如果確定不處罰，保證金就會退還。
簡單說：
  • 被扣押的貨或船：
    • 只要提供等值保證金或擔保，就可以申請撤銷扣押，先拿回來使用。
詳情解析
  • 「扣押之貨物或運輸工具」
    • 適用客體：限於已依第17條或第18條扣押之貨物或運輸工具。
  • 「得由其所有人、管領人或持有人」
    申請主體：
    • 所有人：所有權人。
    • 管領人：實際管理之人（如船長、倉庫管理人）。
    • 持有人：實際持有之人（如承租人、借用人）。
  • 「向海關提供相當之保證金或其他擔保」
    • 「相當之保證金」：金額由海關按貨物或運輸工具之價值核定。
    • 「其他擔保」：如銀行保證書、政府債券、不動產抵押、信託機構保證等。
    • 擔保之目的在於確保將來海關債權（沒入、罰鍰、稅款）之實現。
  • 「申請撤銷扣押」
    法律效果：
    • 經海關審查同意並提供擔保後，扣押即告撤銷。
    • 撤銷後，貨物或運輸工具回復自由狀態，得由所有人自由處分。

舉個例子
例1（繳納保證金撤銷扣押）
  • A公司之貨輪因涉嫌走私被海關扣押，A公司為避免貨輪長期滯留影響營運， 向海關繳納與貨輪價值相當之保證金新臺幣500萬元，海關同意撤銷扣押，貨輪得以恢復營運。
  • → 符合第21條（提供保證金申請撤銷扣押）。
例2（其他擔保——銀行保證書）
  • B公司之貨物被扣押，B公司向銀行申請開立保證書，以該保證書作為擔保向海關申請撤銷扣押，經海關同意後貨物獲釋。
  • → 符合第21條（提供其他擔保申請撤銷扣押）。
例3（擔保之取償）
  • C公司提供保證金後撤銷扣押，惟後續案件經確定應沒入該貨物， 海關逕自保證金中扣抵相當於貨物價值之金額，餘額返還C公司。
  • → 符合第21條（擔保品用以確保沒入處分之執行）。
相關規定
  • 第21條
    • 扣押之貨物或運輸工具，得由其所有人、管領人或持有人向海關提供相當之保證金或其他擔保，申請撤銷扣押。
記憶口訣
  • 扣押物可撤扣押，所有人等可申請。
  • 提供相當之擔保，保證金或銀行保。
