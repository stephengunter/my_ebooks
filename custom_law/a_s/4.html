4 罰則

第23條 運輸工具抗不遵照命令之處罰
  • 「船舶、航空器、車輛或其他運輸工具，違反第八條規定而抗不遵照者，處管領人新臺幣六萬元以上十二萬元以下罰鍰；經查明以載運私貨為主要目的者，並沒入該運輸工具。」
這一條是關於？
  • 本條係針對運輸工具違反第8條「停駛、回航或降落指定地點」命令之處罰規定：
    • 對「抗不遵照」之運輸工具管領人處以罰鍰；
    • 若經查明該運輸工具「以載運私貨為主要目的」，則進一步沒入該運輸工具。
  • 簡單說：
    • 運輸工具不聽海關命令停車或停船者，管領人罰6萬至12萬元。
    • 若該運輸工具的主要用途就是載私貨，則連運輸工具一起沒收。
白話文
  • 如果船、飛機或車輛等運輸工具，違反海關第8條的停車、停船或降落命令，硬是不聽從：
    • 該運輸工具的管領人（例如船長、司機）將被處以新臺幣6萬元到12萬元的罰款。
    如果進一步查明，這艘船或這輛車的主要目的就是專門用來走私的，那麼除了罰管領人錢之外：
    • 這艘船或這輛車也會被沒收。
  • 簡單說：不聽海關命令停駛者，管領人罰6至12萬元；若是專業走私工具，連運輸工具一起沒收。
舉個例子
例1（抗命罰鍰）
  • 海關緝私艇命令一艘可疑漁船停駛受檢，該漁船船長加速逃逸，經緝私艇追緝攔截。
  • 海關調查後認定該船長抗不遵照命令，處以罰鍰新臺幣8萬元。
  • → 符合第23條前段（違反第八條抗不遵照者，處管領人罰鍰）。
例2（載運私貨為主要目的——沒入）
  • 經調查發現，某漁船多次改裝暗艙、於夜間至非通商口岸接駁私貨， 其船體結構及航行模式均顯示「以載運私貨為主要目的」。
  • 本次查獲後，除處罰船長罰鍰外，併予沒入該漁船。
  • → 符合第23條後段（經查明以載運私貨為主要目的者，並沒入該運輸工具）。
例3（抗命但非專業走私——僅罰鍰）
  • 某貨車司機因一時緊張，未聽從海關停車檢查之命令而短暫加速，旋即停車配合。
  • 經調查該車並無私貨，亦非以載運私貨為目的，海關僅處以罰鍰，未予沒入。
  • → 符合第23條前段（僅抗命行為，無載運私貨為主要目的，僅處罰鍰）。
第24條 擅自駛入非通商口岸之處罰
  • 「船舶、航空器、車輛或其他運輸工具，未經允許擅自駛入非通商口岸者，沒入之。但因不可抗力或有其他正當理由，經管領人函報當地有關主管機關核實證明者，不在此限。」
這一條是關於？
  • 本條規定運輸工具未經許可擅自進入非通商口岸者，原則上「沒入」該運輸工具。
  • 但若係因不可抗力（如天災、機械故障）或有其他正當理由，且管領人已函報主管機關核實證明者，則可免予沒入。
  • 簡單說：船、飛機或車輛未經允許擅自開進非通商口岸，原則上沒收；但因天災等不可抗力且已通報者，可免。
這一條的核心
  • 本條係《海關緝私條例》關於「運輸工具違規進入非通商口岸」之處罰規定，
    • 其立法目的在於「確保所有進出國境之運輸工具均經由海關監管之通商口岸出入」，以維護邊境管制與關稅徵收之完整性。
  • 本條之法律意義如下：
    • 原則：沒入：運輸工具未經允許擅自駛入非通商口岸者，不問有無載運私貨，即構成沒入之要件。
    • 例外：免沒入：若係因不可抗力（如颱風、機械故障、海難等）或有其他正當理由， 且管領人已「函報」當地有關主管機關並經「核實證明」者，則可免予沒入。
白話文
  • 如果船、飛機或車輛沒有經過允許，擅自開進非通商口岸（例如未開放的港口或海岸）：
    • 這艘船或這輛車就會被沒收。
    • 不過，如果是因為颱風、機械故障或其他正當理由，而且船長或司機已經通報當地主管機關並獲得證明， 就可以不用被沒收。
  • 簡單說：未經許可擅入非通商口岸者，運輸工具沒收；但不可抗力且已通報證明者除外。
舉個例子
例1（沒入）
  • 某漁船未經許可，擅自於夜間駛入未開放之海岸卸載貨物，經海巡查獲，該漁船依法沒入。
  • → 符合第24條前段（未經允許擅自駛入非通商口岸者，沒入之）。
例2（不可抗力——免沒入）
  • 某貨輪於航行中遭遇強烈颱風，為避難而駛入非通商口岸之港灣。
  • 船長立即以無線電通報港務局，並於事後補具書面函報，經主管機關核實證明確屬不可抗力。
  • → 符合第24條但書（因不可抗力且經函報核實證明者，不在此限）。
例3（正當理由——免沒入）
  • 某漁船因引擎突然故障失去動力，隨漂流進入非通商口岸之海岸，船長立即通報海巡單位，經查證屬實。
  • → 符合第24條但書（因其他正當理由且經函報核實證明者，不在此限）。
一句話總結
    第24條是「運輸工具擅入非通商口岸之沒入規定」——
  • 未經許可擅入非通商口岸者，運輸工具沒入；但不可抗力且已通報證明者除外。
第25條 船舶毀壞或拋棄貨物文件以逃避查緝之處罰
  • 「船舶在沿海二十四海里界內，或經追緝逃出界外，將貨物或貨物有關文件毀壞或拋棄水中，以避免緝獲者，處管領人及行為人各新臺幣三萬元以上十五萬元以下罰鍰，並得沒入該船舶。」
這一條是關於？
  • 本條針對船舶於我國沿海二十四海里內（或經追緝逃出界外）：
    • 為逃避海關查緝，故意將貨物或相關文件毀壞或拋棄入海之行為， 對「管領人」及「行為人」分別處以罰鍰，並「得」沒入該船舶。
  • 簡單說：船在沿海24海里內（或被追到界外），為了不被抓，把貨或文件丟進海裡或銷毀：
    • 船長和動手的人各罰3至15萬元，船也可能被沒收。
這一條的核心
  • 本條係《海關緝私條例》關於「湮滅證據以逃避緝私」之處罰規定，
    • 其立法目的在於「防止走私者以毀壞或拋棄貨物之方式湮滅證據，規避查緝與處罰」。
  • 走私者於面臨查緝時，常將私貨或相關文件拋入海中或銷毀，以消滅證據，使海關難以證明其走私行為。
    • 本條即對此類湮滅證據之行為設有獨立之處罰規定，不以是否查獲私貨為必要。
  • 本條之法律意義如下：
    • 適用範圍：限於「船舶」（不含航空器或車輛），且須於「沿海二十四海里界內」或「經追緝逃出界外」。
    • 處罰對象：「管領人」（如船長）與「行為人」（實際毀壞或拋棄之人）各別處罰，不採連帶責任。
    • 罰鍰金額：各新臺幣3萬元以上15萬元以下（由海關裁量）。
    • 沒入船舶：海關「得」沒入該船舶（裁量權），非「應」沒入。
白話文
  • 如果船舶在台灣沿海24海里內，或是被海關追緝而逃到24海里外：
    • 為了不被抓到，故意把貨物或相關文件丟進海裡或銷毀掉， 那麼船長（管領人）和實際動手丟貨銷毀的人，各會被罰新臺幣3萬元到15萬元。
    • 而且，這艘船也可能被沒收。
  • 簡單說：走私船在沿海24海里內（或被追到界外）為滅證而丟貨銷毀文件：
    • 船長和行為人各罰3至15萬元，船也可能被沒收。
舉個例子
例1（界內拋貨）
  • 海關緝私艇於高雄港外海15海里處發現一艘可疑漁船，該船發現緝私艇靠近後，立即將船上數箱貨物拋入海中。
  • 海關攔截該船後，經調查認定其係為避免緝獲而拋棄貨物。
  • → 符合第25條（於沿海二十四海里界內拋棄貨物以避免緝獲，處管領人及行為人罰鍰，並得沒入船舶）。
例2（經追緝逃出界外）
  • 海關緝私艇於基隆港外海20海里處發現可疑船舶，該船加速逃逸， 經追緝至30海里處，船上人員將艙單等文件撕毀丟入海中。
  • → 符合第25條（經追緝逃出界外，毀壞文件以避免緝獲）。
例3（未達避免緝獲之意圖）
  • 某漁船於航行中因風浪過大，船上貨物不慎掉落海中，經海關調查確認係屬意外，非為避免緝獲而拋棄。
  • → 不符合第25條（無「以避免緝獲」之意圖，不構成本條）。
一句話總結
    第25條是「船舶湮滅證據以逃避查緝之處罰」——
  • 船舶於沿海24海里內（或被追至界外）為逃避查緝而毀壞或拋棄貨物文件者：
    • 管領人及行為人各罰3至15萬元，並得沒入船舶。
第26條 發遞走私信號或傳送消息之處罰
  • 「發遞有關走私信號，傳送消息於私運貨物進口或出口之運輸工具者，處新臺幣三萬元以下罰鍰。」
這一條是關於？
  • 本條處罰「發遞走私信號」或「傳送消息」予走私運輸工具之行為，
    • 用以阻斷走私者之間的通風報信或接應聯繫，確保查緝行動之有效性。
  • 簡單說：打信號或傳消息給走私船（或其他運輸工具）的人，罰三萬元以下。
這一條的核心
  • 本條係《海關緝私條例》關於「阻斷走私通訊與聯繫」之處罰規定，
    • 其立法目的在於「防止走私集團透過信號或通訊方式互通有無，規避查緝」。
  • 走私行為常涉及岸上接應人員、瞭望哨或共犯，利用燈光、旗號、無線電等方式， 向海上或空中之運輸工具傳遞消息（如通知海關動態、指示接駁地點等）。
    • 本條即針對此類「輔助走私」之通訊行為設有獨立罰則。
白話文
  • 如果有人打信號（例如閃燈、揮旗）或傳消息（例如打電話、用無線電）給正在走私的船或車輛，
    • 幫助他們躲避海關查緝，就會被罰新臺幣三萬元以下。
  • 簡單說：通風報信幫助走私者，罰三萬元以下。
舉個例子
例1（發遞信號）
  • 海關查獲某走私集團，其岸上人員於海關緝私艇出港時， 以手電筒燈光信號通知海上等候之走私漁船，該行為經錄影存證。
  • → 符合第26條（發遞有關走私信號，處三萬元以下罰鍰）。
例2（傳送消息）
  • 某人以無線電通報走私貨車前方有海關路檢點，指示其繞道行駛，經海關監聽查獲。
  • → 符合第26條（傳送消息於私運貨物進口或出口之運輸工具者，處三萬元以下罰鍰）。
一句話總結
    第26條是「發遞走私信號或傳送消息之處罰」——
  • 發送信號或傳消息給走私運輸工具者，處三萬元以下罰鍰。
第27條 運輸工具私運貨物之處罰與停止結關
  1. 「以船舶、航空器、車輛或其他運輸工具，私運貨物進口、出口、起岸或搬移者，處管領人新臺幣五萬元以上五十萬元以下罰鍰；其情節經查明前述運送業者有包庇、唆使或以其他非正當方法，使其運輸工具之工作人員私運貨物進口或出口者，除依本條例或其他法律處罰外，並得停止該運輸工具三十天以內之結關出口。」
  2. 「前項運輸工具以載運槍砲、彈藥或毒品為主要目的者，沒入之。」
這一條是關於？
  • 本條針對「運輸工具」被用於私運貨物之行為，對其「管領人」處以罰鍰。
    • 若運送業者（如航運公司）有包庇、唆使等不正當行為，則可對該運輸工具施以「停止結關出口」之行政制裁。
    • 若該運輸工具係以載運槍砲彈藥或毒品為主要目的，則直接「沒入」。
  • 簡單說：
    • 用船、飛機、車輛等走私貨物，管領人罰5至50萬元。
    • 運送業者若包庇或教唆，該運輸工具可被停止出口結關30天；若專門用來運槍毒，則沒收。
這一條的核心
  • 本條係《海關緝私條例》關於「運輸工具私運貨物之處罰」之核心規定，
    • 其立法目的在於「對利用運輸工具從事走私之行為施以嚴厲制裁」及「追究運送業者之監督責任」。
  • 與第23條（抗命）及第24條（擅入非通商口岸）不同，
    • 本條係針對運輸工具「實際用於私運貨物」之行為（即第3條所定義之私運行為），屬實體走私行為之處罰。
  • 本條之法律意義如下：
    • 罰鍰：運輸工具被用於私運貨物者，對「管領人」處以罰鍰5萬元至50萬元。
      • 此為「行為責任」，不以管領人明知或參與為必要（惟實務上仍須有過失）。
    • 停止結關出口：若「運送業者」（如航運公司、貨運公司）有包庇、唆使等不正當行為：
      • 除罰鍰外，尚得對該運輸工具施以「停止結關出口」30天以內之制裁。
      • 此為對「業者」而非對「管領人」之制裁，目的在於施壓業者強化內部管理。
    • 沒入：若該運輸工具係「以載運槍砲、彈藥或毒品為主要目的」：
      • 不問情節，直接「沒入」。
      • 此為對「專業走私工具」之最嚴厲制裁。
白話文
  • 如果有人用船、飛機、車輛等運輸工具來走私貨物（無論是進口、出口、卸貨或搬運）：
    • 該運輸工具的管領人（如船長、司機）將被處以新臺幣5萬元到50萬元的罰款。
    如果進一步查明，背後的運送業者（例如航運公司）有包庇、教唆或其他不正當手段，讓旗下員工參與走私：
    • 除了原本的罰款外，海關還可以下令該運輸工具「停止結關出口」30天以內，也就是暫時不能載貨出口。
    如果這艘船或這輛車「專門用來載運槍砲彈藥或毒品」，那就直接沒收。
  • 簡單說：
    • 用運輸工具走私，管領人罰5至50萬元。
    • 運輸業者若包庇教唆，可停止該運輸工具出口結關30天。
    • 運輸工具專門運槍毒者，直接沒收。
舉個例子
例1（管領人罰鍰）
  • A公司貨輪船長明知貨櫃內藏有私菸，仍予載運進口，經海關查獲。
  • 海關對該船長處以罰鍰新臺幣30萬元。
  • → 符合第27條第1項前段（以運輸工具私運貨物進口者，處管領人罰鍰）。
例2（停止結關出口）
  • 經調查發現，B航運公司長期包庇旗下船員走私，多次以提供暗艙等方式協助私貨運送。
  • 海關除對船長處以罰鍰外，另對該貨輪處以停止結關出口20天。
  • → 符合第27條第1項後段（運送業者包庇走私，得停止該運輸工具結關出口）。
例3（載運毒品——沒入）
  • C漁船經多次改造暗艙，專門用於自海上接駁毒品進口。
  • 海關查獲後，除對船長處以罰鍰外，並將該漁船依法沒入。
  • → 符合第27條第2項（以載運毒品為主要目的者，沒入之）。
一句話總結
    第27條是「運輸工具私運貨物之處罰」——
  • 運輸工具用於私運者，管領人罰5至50萬元。
  • 運送業者包庇教唆者，得停止該運輸工具結關出口30天。
  • 運輸工具專門載運槍毒者，直接沒入。
第28條 擅行起卸貨物及擅自轉載收受之處罰
  1. 「船舶、航空器、車輛或其他運輸工具未到達通商口岸之正當卸貨地點，未經許可而擅行起卸貨物或自用物品者，處管領人貨價二倍以下之罰鍰，並得將該貨物及物品沒入之。」
  2. 「擅自轉載、放置或收受前項貨物、物品或幫同裝卸者，依前項規定處罰。」
這一條是關於？
  • 本條處罰運輸工具「未經許可」且「未到達正當卸貨地點」即擅自起卸貨物或自用物品之行為。
    • 並對協助轉載、放置、收受或裝卸者一併處罰，以防止私貨在合法通商口岸以外之地點流入市面。
  • 簡單說：船、飛機或車輛還沒到合法的卸貨地點，就擅自把貨物或自用物品卸下來：
    • 管領人罰貨價二倍以下，貨物沒收。
    • 幫忙轉載、收受或裝卸的人，也一樣處罰。
這一條的核心
  • 本條係《海關緝私條例》關於「擅行起卸貨物」之處罰規定，
    • 其立法目的在於「確保所有進口貨物均經由通商口岸之正當卸貨地點接受海關監管」， 防止私貨在非通商口岸或未經許可之地點卸載，規避檢查與課稅。
    • 本條之法律意義如下：
  • 處罰對象與行為：針對「未到達通商口岸之正當卸貨地點」且「未經許可」即「擅行起卸」貨物或自用物品之行為。
    • 此處之「自用物品」係指運輸工具本身所需之補給品或船員個人物品，原則上亦須於正當地點卸載。
  • 罰鍰基準：以「貨價二倍以下」為範圍，由海關裁量。
  • 沒入：對該擅行起卸之貨物及物品，「得」沒入之（裁量權）。
  • 共犯處罰：對「轉載」、「放置」、「收受」或「幫同裝卸」該等貨物之協助者，亦同受處罰。
白話文
  • 如果船、飛機或車輛還沒到達通商口岸的指定卸貨地點，也沒有經過許可，就擅自把貨物或自用物品卸下來：
    • 管領人將被處以貨物價值二倍以下的罰款，這些貨物也可能被沒收。
    • 如果有人幫忙轉載、存放、收受或協助裝卸這些貨物，也一樣會受到處罰。
  • 簡單說：未到合法卸貨點就擅自卸貨：
    • 管領人罰貨價二倍以下，貨物可沒收。
    • 協助轉載、收受者亦同。
舉個例子
例1（擅行起卸）
  • 某貨輪未駛入高雄港指定碼頭，即於港外錨地擅自將貨物卸至接駁小船，經海關查獲。
  • → 符合第28條第1項（未到達正當卸貨地點，未經許可擅行起卸貨物）。
例2（共犯處罰）
  • A協助將該批擅行起卸之貨物轉載至岸上貨車，B則負責收受該批貨物。
  • → 符合第28條第2項（擅自轉載、收受前項貨物者，依前項規定處罰）。
例3（自用物品）
  • 某漁船未進港，於港外擅自將船上自用之補給品（如燃油、飲用水）卸至岸邊。
  • 雖為自用物品，仍屬擅行起卸。 → 符合第28條第1項（擅行起卸自用物品者，亦同受處罰）。
一句話總結
    第28條是「擅行起卸貨物及協助者之處罰」——
  • 未到正當卸貨地點即擅行起卸者，管領人罰貨價二倍以下，貨物得沒入；協助轉載、收受者亦同。
