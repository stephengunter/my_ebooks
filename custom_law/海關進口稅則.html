海關進口稅則

解釋準則

  • 看號列名稱與註解：標題僅供參考
  • 半成品/拆散品：完成品主要特性分類
  • 多種材料或混合物：用主要特徵材料分類
  • 同時可歸列多號別：具體號優先 → 主要特徵 → 最後號
  • 特殊容器/包裝：一般與所裝物品同號別
  • 特殊或無法分類： 類似貨品或目下規定
準則一：標題僅供參考
標題不決定分類，重點看「內容與註解」
項目 效力 重點
類、章標題 僅供查考，無拘束力 不能只看標題就分類
稅則號別、章註、類註 強制優先適用 有規定 → 照規定
前兩者皆無規定 進到準則二以後 沒寫才往後找
準則二：半成品、零件與混合材料
不完整或未完成貨品
  • 若具備完整貨品的主要特性 → 視為完整貨品
  • 未組合或拆散的完整品 → 仍按完整品分類
材料或物質混合
  • 單一材料貨品 → 照該材料稅號
  • 部分由該材料構成 → 亦歸入該材料稅號
  • 超過一種材料 → 進入準則三（不在此條處理）
準則三：三種衝突解法
適用在：貨品可歸入兩個以上稅號時
  1. 最特定：描述最具體優先
  2. 主要特性：混合物、組合物、組裝貨品，以貨品的「主要特徵材料或組件」分類
  3. 號別最後：仍無法分類時，選擇可考慮的號別中最後列的號別
準則四：無法分類貨品
若依前述準則仍找不到號別 → 適用「最類似貨品」的號別
準則五：特殊容器與包裝
特殊容器 相機盒、樂器盒、槍盒等：與所裝物品歸列同一稅則號別
  • 特殊形狀／專門規格(量身訂做概念)
  • 與所裝物品同時進口
  • 適於長期使用(不是一次性包裝)
例外：容器本身已構成主要特質
普通包裝材料
  • 正常情況下用以包裝該物品 -> 與所裝物品同稅號
  • 顯然可重複使用 -> 分開歸類（如：瓦斯鋼瓶、啤酒桶）
準則六：合法用途與目下規定
  • 同一目下物品 → 按目及目註規定分類
  • 適用範圍：僅限同層次目之比較
  • 相關類、章註解可引用（除非另有規定）

總則

分類依據
依據有順序：
  1. 類、章及章註：強制優先
  2. 各號別貨名：正文規定
  3. 解釋準則：前6條準則
  4. HS註解：可參據，不強制（關稅合作理事會編）
  5. 其他有關文件：補充參考
三欄稅率
欄位 適用對象 重點
第1欄 WTO會員、有互惠待遇國家 基本盤、最常用
第2欄 低度開發國家、FTA/ECA簽署國 特定優惠、要核定
第3欄 不適用前兩欄者 一般稅率（最高）
  • 同時符合第1欄＋第2欄 → 適用較低者
  • 協定終止 → 優惠收回
關稅配額——量價雙軌
  • 配額內：低稅率
  • 配額外：回歸原稅號稅率（較高）
  • 適用對象核定：財政部會商→行政院核定→立法院查照
有條件免稅／減稅
某些品目：
  • 需符合特定用途
  • 需主管機關證明
  • 章內增註規定條件
例如：研究用途、特定產業用途
旅客零星物品——5％簡化稅
適用對象：
  • 旅客自用行李以外之零星物品
  • 郵包零星物品
排除：關稅配額物品不適用
稅率：5％（從價）
條約優於稅則：取最低
稅則規定與條約／FTA規定不同時：適用「較低稅率」
