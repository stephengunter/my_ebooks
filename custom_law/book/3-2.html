3-2 稅款之優待-保稅

保稅倉庫制度

  • 進口貨物在還沒報關繳稅之前，可以先申請存入海關監管的「保稅倉庫」。
  • 在規定的存倉期限內（通常是一年，可延長一次）：
    • 如果貨物原封不動或經過整理、分類、裝配等簡單加工後再出口，就可以完全免稅。
  • 國產的保稅貨物進到保稅倉庫後，可以辦理除帳銷案。
    • 國產的非保稅貨物如果是為了重整而進倉，出口後還可以申請退還原料關稅。
  • 存倉期間，貨主可以申請在倉庫裡進行整理、分類、分割、裝配或重裝等作業。
  • 經營保稅倉庫的業者必須向海關登記並繳交保證金，詳細的資格、設備、保證金金額等規定， 則由財政部另外訂定《保稅倉庫設立及管理辦法》來規範。
簡單說：
  • 進口貨物先存進海關監管的保稅倉庫，暫免繳稅。
  • 若在期限內出口（不論是否經簡易加工），即可免稅。
  • 國產貨亦可納入此保稅體系運作。
詳情解析
進口貨物提領前，得向海關申請存入保稅倉庫
  • 「提領前」：即尚未完成通關放行、尚未提領出倉前。
  • 「向海關申請」：必須先向海關申請並核准。
  • 「存入保稅倉庫」：將進口貨物存入經登記之保稅倉庫。
在規定存倉期間內，原貨出口或重整後出口者，免稅
  • 「規定存倉期間內」：依《保稅倉庫設立及管理辦法》規定，原則為一年內，得申請延長一次。
  • 「原貨出口」：未經任何處理，直接復運出口。
  • 「重整後出口」：經整理、分類、裝配等作業後再出口。
  • 「免稅」：法律效果宣示。存入保稅倉庫時為「暫免繳納」，符合條件出口後確定「免稅」效果。
國產保稅貨物與國內重整貨物
國產保稅貨物進儲保稅倉庫後，得依規定辦理除帳
  • 「國產保稅貨物」：國內生產之保稅貨物（如保稅工廠產品）。
  • 「除帳」：貨物從保稅帳冊中註銷，不再列管。
供重整之國內貨物進儲保稅倉庫後，得於出口後辦理沖退稅
  • 「供重整之國內貨物進儲保稅倉庫」：國內貨物（非保稅貨物）進儲保稅倉庫進行重整。
  • 「得於出口後辦理沖退稅」：若進儲貨物之進口原料已繳納關稅，重整後出口仍可適用沖退原料關稅之規定。
    • 財政部公告取消退稅之項目除外。
倉庫範圍內之作業
保稅倉庫存倉貨物：經海關核准，得於倉庫範圍內進行重整
  • 「保稅倉庫存倉貨物」：包括前兩項：「進口貨物」進儲與「國產保稅貨物」進儲。
    • 需為「規定存倉期間內」合法存倉狀態，使得適用。
  • 「經海關核准」：程序要求：申請 + 海關核准。
    • 申請人：貨物所有人或倉單持有人。
      • 申請時應說明：貨物名稱、數量；重整範圍及工作人員名單等。
    • 海關核准：經海關發給准單後，由海關派員駐庫監視辦理重整。
  • 「倉庫範圍內」：重整行為在倉庫範圍內進行。
  • 「進行重整」：重整行為限定為「檢驗、測試、整理、分類、分割、裝配、重裝」。
    • 限制原則：不得改變原來性質或形狀、不得使用複雜大型機器設備、重整過程中不發生損耗或損耗甚微。
保稅倉庫業者之管理
  • 業者應向所在地海關申請登記及繳納保證金。
  • 詳細規範依財政部訂定之《保稅倉庫設立及管理辦法》。
舉個例子
例1：外貨進儲後原貨出口
  • A公司自日本進口一批電子零件，申請存入保稅倉庫，暫免繳納關稅。
  • 三個月後，因國外客戶訂單，A公司將該批零件原貨復運出口。海關核准免徵進口關稅。
  • → 符合第58條第1項前段（原貨出口者免稅）。
例2：重整後出口
  • B公司自德國進口一批機械零件，存入保稅倉庫後，申請於倉庫內進行「裝配」作業，將零件組合成完整之機械設備，再行出口至東南亞。
  • 海關核准重整作業及出口免稅。
  • → 符合第58條第1項後段及第3項（重整後出口者免稅，且得於倉庫範圍內進行裝配）。
例3：保稅倉庫業者設立
  • C公司擬經營保稅倉庫業務，應先向所在地海關申請登記，並繳納保證金（依規定為新臺幣30萬元）， 且須符合實收資本額2,000萬元以上、設置電腦連線設備及24小時監視系統等條件。
  • → 符合第58條第4項（保稅倉庫業者應向海關申請登記及繳納保證金，相關條件由子法規範）。
相關規定
  • 第58條
    1. 進口貨物於提領前得申請海關存入保稅倉庫。
      • 在規定存倉期間內，原貨出口或重整後出口者，免稅。
      • 國產保稅貨物進儲保稅倉庫後，得依規定辦理除帳。
      • 供重整之國內貨物進儲保稅倉庫後，除已公告取消退稅之項目外，得於出口後依第63條規定辦理沖退稅。
    3. 前二項存倉之貨物在規定存倉期間內，貨物所有人或倉單持有人得申請海關核准於倉庫範圍內整理、分類、分割、裝配或重裝。
    4. 保稅倉庫業者應向所在地海關申請登記及繳納保證金。詳細規範依財政部訂定之《保稅倉庫設立及管理辦法》。
記憶口訣
  • 進口貨物進保倉，暫免關稅減壓力。
  • 原貨重整都可出，出口免稅是核心。
  • 倉內可整可分裝，期限兩年要牢記。

保稅倉庫設立及管理辦法

保稅倉庫是暫免關稅的「貨物停車場」
  • 業者須登記、繳保證金，受海關嚴格監管。
  • 進口貨物可暫存2年，
  • 期間可整理、重整、裝配，出口免稅。
存儲期限 2年（原則不得延長，特殊情況經核准者除外）
保證金 一般30萬元；自主管理依營業年限300～600萬元
設立條件 股份有限公司，實收資本額2,000萬元以上
倉內作業 可重整：檢驗、整理、分類、分割、裝配、重裝
出口免稅 原貨或重整後出口者，免稅
設立
設立條件
  • 實收資本額2000萬元以上股份有限公司（經財政部專案核准者不在此限）
  • 倉庫建築設備經主管機關核定（安全防盜）
  • 監視系統海關可隨時調閱（24小時錄影存檔30日以上）
  • 電腦能連線通關系統
倉庫位置
  • 應設於港區、機場、鄰近港口地區、科技產業園區、科學園區、農業科技園區
  • 或經海關核准之區域內
保證金
  • 一般：30萬元
  • 自主管理且設立滿3年：300萬元（未滿3年600萬元）
  • 自用保稅倉庫（免稅商店）：2000萬元
申請自主管理
  • 應具備自主管理條件
  • 實收資本額5000萬元以上
發給執照
  • 經核准登記之保稅倉庫，由海關發給執照
  • 每2年校正一次
  • 登記事項變更應於30日內向海關辦理換照
管理
人員與稽核管理
海關可隨時抽查
  • 海關得定期或不定期稽核保稅貨物
  • 進出貨物應於海關辦公時間內為之（自主管理除外）
專人專責
  • 應指定至少2名正職人員（含1名主管級）辦理保稅事項
  • 並向海關報備
帳冊管理
  • 應設置存貨簿冊
  • 進出倉應於翌日起2日內登帳
  • 海關得隨時檢查、盤點
每月存貨表報
  • 存貨表報每月20日前報請海關查核
  • 海關可電腦系統遠端查核，或由業者印製表報請海關驗印
保管責任
  • 倉庫業者負保管責任，貨物損失應賠繳進口稅捐
配合扣押義務
  • 海關得憑扣押憑單隨時扣存貨物，業者不得拒絕
貨物進出倉管理
進儲程序
  • 外貨進儲：填具申請書，憑放行通知會同監視關員核對後進倉
  • 飛機用燃料物料得先卸存，3日內補辦手續
買賣聯名申報
  • 自用保稅倉庫購買保稅貨物：買賣雙方聯名填具報單
出倉進口
  • 由貨物所有人向海關申報，憑海關放行通知出倉
出倉課稅
  • 售與課稅區：視同進口，按出倉形態徵稅
退運程序
  • 退運出口：填具申請書，核發出倉准單，海關押運或加封
貨物堆置與存放管理
分區管理
  • 貨物應標記朝外，按種類分區堆置，標明區號
  • 重整前後貨物應不同倉間存放
露天存放
  • 包件過重或體積過大者，得經核准存儲露天處所（須鄰接倉庫）
存倉期限
  • 存倉期限2年（原則不得延長）
  • 逾期加徵滯報費（滿20日仍未申報者依法處理）
重整作業管理
重整範圍
  • 檢驗、測試、整理、分類
  • 分割、裝配、重裝（須經核准）
重整限制
  • 不得改變原來性質或形狀
  • 不得使用複雜大型機器設備
申請核准
  • 重整前應向海關報明
  • 經海關發給准單後辦理（自主管理免派員監視）
運出檢驗 貨物運出倉庫檢驗測試：
  • 須經監管海關核准
  • 必要時，海關得隨時派員查核。
  • 應於出倉翌日起3個月內運回（得延長一次，合計6個月）
銷帳核價 貨物重整後出倉進口：
  • 按「重整前」貨物狀況銷帳。
  • 依「重整後」貨物狀況核定完稅價格、稅則號別
損耗與廢料
  • 重整損耗經海關核明屬實者准予核銷
  • 廢料有利用價值者徵免稅捐，無利用價值者監督銷毀
帳冊與單證管理
即時登帳
  • 存貨簿冊經海關驗印後使用
  • 進出倉翌日起2日內登帳
定期報表
  • 電腦處理帳務者，次月20日前印製表報報請驗印
運送單證 貨物進出倉：
  • 應簽收／開立貨櫃（物）運送單
  • 並追蹤確認貨物運抵
出倉流向與稅務處理
售與課稅區
  • 視同進口，按出倉形態徵稅
售與保稅區
  • 買賣雙方聯名填具報單，憑放行通知出倉
出口
  • 填具報單，運至出口地海關辦理通關
移至免稅商店
  • 繕具移倉申請書，傳輸至關港貿單一窗口
按月彙報
  • 經核准者，於次月15日前彙總報關
記憶口訣
  • 保稅倉庫管理嚴，專責人員至少二。
  • 貨物分區標記明，帳冊兩日要登錄。
  • 存倉二年為上限，重整需經海關准。
  • 出倉課稅視同進，貨物損失業者賠。

保稅工廠制度

  • 專門做外銷產品的製造廠商，可以向海關申請登記成為「保稅工廠」。
  • 核准以後，保稅工廠為了製造外銷產品而進口的原料，就可以「免徵關稅」。
    • 不用先繳稅再申請退稅，手續簡單很多。
  • 但是，保稅工廠生產的產品和免稅進口的原料：
    • 如果沒有經過海關核准並繳稅，是不能隨便運出工廠的。
  • 另外，保稅工廠進口自己用的機器設備也可以免稅。
    • 但這些機器在進口後的「五年內」如果轉賣到國內市場，就必須補繳關稅。
  • 經營保稅工廠的詳細資格、條件、最低資本額和管理規定，則由財政部另外訂定《海關管理保稅工廠辦法》來規範。
簡單說：
  • 外銷製造廠經核准為保稅工廠後，進口原料及自用機器設備可免稅。
  • 但產品及免稅原料不得擅自出廠，機器設備五年內轉內銷須補稅。
保稅工廠的效益
  • 原料進口免稅： 減輕資金積壓，提升資金周轉效率。
  • 機器設備免稅： 降低建廠及設備購置成本。
  • 簡化退稅手續： 按實際用料逕行銷帳，免除核計退稅標準之繁雜手續。
  • 提升國際競爭力： 降低生產成本，強化外銷接單能力。
詳情解析
外銷品製造廠商，得經海關核准登記為海關管理保稅工廠
  • 適用主體：以製造外銷品為目的之「製造廠商」。
  • 程序要件：須經海關「核准登記」，始取得保稅工廠資格。
其進口原料存入保稅工廠製造或加工產品外銷者，得免徵關稅
  • 原則：出口外銷，原料免稅。
  • 要件：「原料存入保稅工廠」，進行製造或加工後，產品外銷。
出廠限制
保稅工廠產品及免稅原料：非經海關核准並按貨品出廠形態報關繳稅，不得出廠
  • 「出廠」：保稅貨物離開保稅工廠，進入課稅區或其他區域。
  • 管制規定：保稅工廠之產品及免稅原料，均受海關監管，未經核准不得擅自出廠。
  • 若欲出廠（如轉內銷），須經海關核准，並按出廠時之貨品形態報關繳稅。
自用機器免稅
保稅工廠進口自用機器、設備，免徵關稅
  • 自用機器設備免稅：保稅工廠為製造外銷品所需之自用機器、設備，進口時亦免徵關稅，以降低廠商建置生產線之成本。
但自用機器、設備於輸入後五年內輸往課稅區者，應依進口貨品之規定，補繳關稅
五年管制期與補稅規定：
  • 免稅進口之機器設備，須於輸入後受海關監管「五年」。
  • 若於五年內將該機器設備「輸往課稅區」（即轉入國內市場），應依進口貨品之規定補繳關稅。
舉個例子
例1：保稅工廠進口原料免稅
  • A公司為經海關核准登記之保稅工廠，自日本進口一批電子零組件作為生產外銷產品之原料。
  • 該批原料存入保稅工廠時，免徵進口關稅。
  • → 符合第59條第1項（保稅工廠進口原料用於製造外銷產品者，免徵關稅）。
例2：產品出廠管制——須報關繳稅
  • B保稅工廠擬將一批產品在國內銷售，未經海關核准即逕行運出工廠。
  • → 違反第59條第2項（保稅工廠產品非經海關核准並報關繳稅，不得出廠）。
例3：機器設備五年內轉內銷補稅
  • C保稅工廠於110年1月進口一台免稅機器設備。
  • 113年6月（輸入後約3.5年），C公司擬將該機器出售予國內廠商。
  • 因仍在五年管制期內，C公司應向海關申報並補繳關稅後始得轉讓。
  • → 符合第59條第3項但書（五年內輸往課稅區者，應補繳關稅）。
相關規定
  • 第59條
    1. 外銷品製造廠商，得經海關核准登記為海關管理保稅工廠。
      • 進口原料存入保稅工廠製造或加工產品外銷者，得免徵關稅。
    2. 保稅工廠所製造或加工之產品及依前項規定免徵關稅之原料：
      • 非經海關核准並按貨品出廠形態報關繳稅，不得出廠。
    3. 保稅工廠進口自用機器、設備，免徵關稅。
      • 但五年內輸往課稅區者，應依進口貨品之規定，補繳關稅。
    4. 保稅工廠業者應向所在地海關申請登記。
      • 業者管理規定由財政部另定《海關管理保稅工廠辦法》。
記憶口訣
  • 保稅工廠外銷用，原料進口免關稅。
  • 產品出口沖銷帳，出廠必須先繳稅。

物流中心制度

  • 如果業者經營的是保稅貨物的「倉儲、轉運和配送」業務：
    • 就可以向海關申請登記成為「物流中心」。
  • 貨物進到物流中心後：
    • 可以進行重整和簡單加工（例如貼標籤、改包裝、組合等），以因應國際物流需求。
  • 進口貨物存入物流中心後：
    • 無論是原封不動出口，還是經過重整或簡單加工後再出口，都可以「免徵關稅」。
  • 國內的貨物進到物流中心：
    • 如果含有已繳稅的進口原料，出口時可以申請退還原料關稅，但財政部公告取消退稅的項目除外。
  • 經營物流中心的業者必須向海關登記並繳交保證金。
    • 詳細規定由財政部另外訂定《物流中心貨物通關辦法》來規範。
簡單說：
  • 物流中心是比保稅倉庫功能更強大的保稅場所，可進行重整及簡單加工。
  • 進口貨在此加工後出口免稅，國內貨亦可沖退稅。
詳情解析
經營保稅貨物倉儲、轉運及配送業務之保稅場所，其業者得向海關申請登記為物流中心
  • 適用主體：已經營保稅貨物「倉儲」、「轉運」及「配送」業務之業者。
  • 程序要件：須向海關「申請登記」，經核准後始取得物流中心資格。
進儲物流中心之貨物，得進行重整及簡單加工
  • 得進行「重整」及「簡單加工」，以因應物流業務需要。較保稅倉庫得進行之行為更為廣泛。
  • 重整：指貨物之整理、分類、分割、裝配、重裝等作業。
  • 簡單加工：指不改變貨物基本特性之輕度加工作業（如貼標籤、改包裝、組合等）
進口貨物存入物流中心，原貨出口或重整及加工後出口者，免稅
  • 進口貨物存入物流中心後，無論係「原貨出口」或經「重整及加工」後出口，均「免徵關稅」。
國內貨物進儲物流中心，除已公告取消退稅之項目外，得於出口後辦理沖退稅
  • 「國內貨物」：非保稅貨物。若其內含已繳納關稅之進口原料，於出口時得依規定申請「沖退稅」（退還原料關稅）。
舉個例子
例1：進口貨物加工後出口免稅
  • A公司為經海關核准登記之物流中心業者。
  • 一批自日本進口之電子零件存入物流中心後，進行簡單加工（如貼標籤、組合），再出口至東南亞。
  • 海關核准免徵進口關稅。
  • → 符合第60條第3項前段（進口貨物存入物流中心，重整及加工後出口者免稅）。
例2：國內貨物進儲後沖退稅
  • B物流中心進儲一批國內產製之機械零件，該零件使用之進口原料已繳納關稅。
  • 該批零件出口後，B公司依第63條規定申請沖退原料關稅。
  • → 符合第60條第3項後段（國內貨物進儲物流中心，得於出口後辦理沖退稅）。
例3：物流中心設立登記與保證金
  • P公司將進口C公司擬經營物流中心業務，應先向所在地海關申請登記，並繳納保證金 ，且須符合實收資本額1億5,000萬元以上、設置電腦連線設備及24小時監視系統等條件。
  • → 符合第60條第4項（物流中心業者應向海關申請登記及繳納保證金，相關條件由子法規範）。
相關規定
  • 第60條
    1. 經營保稅貨物倉儲、轉運及配送業務之保稅場所，其業者得向海關申請登記為物流中心。
    2. 進儲物流中心之貨物，因前項業務需要，得進行重整及簡單加工。

免稅商店制度

  • 在機場、港口賣東西給出入境的旅客的商店，可以向海關申請登記成為「免稅商店」。
  • 免稅商店賣的貨物（例如香水、化妝品、菸酒等）因為是存放在保稅倉庫裡：
    • 所以進貨時不用先繳關稅、營業稅、貨物稅等。
  • 只要在規定的時間內賣給「要出境的旅客」，而且旅客也確實把貨物帶出國，就可以免稅。
    • 如果旅客買了之後沒有帶出境（例如在國內送人），那就不能免稅，必須補稅。
  • 免稅商店的貨物必須存放在「專門給免稅商店用的保稅倉庫」裡。
  • 免稅商店詳細的管理規定則由財政部訂定《免稅商店設置管理辦法》來規範。
簡單說：
  • 機場免稅店的貨物進口時免稅，但只賣給「要帶出境」的旅客。
  • 旅客必須把貨物攜帶出境才能真正享受免稅優惠。
詳情解析
經營銷售貨物予入出境旅客之業者，得向海關申請登記為免稅商店
  • 適用主體：以「銷售貨物予入出境旅客」為業之業者。
  • 程序要件：須向海關「申請登記」，經核准始取得免稅商店資格。
  • 免稅商店實務上分為「機場、港口免稅商店」（設於管制區內）及「市區免稅商店」（設於市區，須於機場或港口設提貨處）二類。
免稅商店進儲供銷售之保稅貨物，在規定期間內銷售予旅客，原貨攜運出口者，免稅
  • 「進儲供銷售之保稅貨物」：進儲時暫免繳納關稅等稅費。
  • 「在規定期間內銷售」：免稅商店之保稅貨物，其存儲期限以2年為限。屆期仍未售出，應退運出口。
  • 「旅客」：
    • 機場、港口免稅商店：以出境、過境及入境旅客為限。
    • 市區免稅商店：以出境旅客為限。
  • 「原貨攜運出口」：旅客購買後須原封不動攜帶出境，不得在境內使用或轉售。
免稅商店之保稅貨物，應存儲於專供存儲免稅商店銷售貨物之保稅倉庫
  • 貨物存儲地點之強制規定：免稅商店之保稅貨物須存儲於「專供存儲免稅商店銷售貨物之保稅倉庫」。
  • 實務上為「同一法人自用保稅倉庫」，須領有海關核發之保稅倉庫執照。
舉個例子
例1：出境旅客購買免稅品攜帶出境
  • A旅客於桃園機場免稅商店購買香水一瓶，結帳時出示護照及登機證，確認其為出境旅客。
  • 免稅商店將香水以保稅方式銷售予A旅客，A旅客將香水隨身攜帶登機出境。
  • 該香水免徵關稅、營業稅及貨物稅。
  • → 符合第61條第2項（免稅商店之保稅貨物銷售予旅客，原貨攜運出口者免稅）。
例2：旅客購買後未攜帶出境
  • B旅客於免稅商店購買酒類數瓶，結帳後未攜帶出境，而將酒類交予在臺親友攜離機場。
  • 因該酒類未隨同B旅客出境，已脫離「原貨攜運出口」之要件。
  • → 不符合第61條第2項（旅客未將原貨攜運出口，該貨物應補繳關稅及相關稅費）。
例3：免稅商店設立登記
  • C公司擬於高雄國際機場設立免稅商店，應先依公司法登記為股份有限公司， 實收資本額達新臺幣5,000萬元以上，並領有自用保稅倉庫執照， 向所在地海關（高雄關）申請登記，經海關核准發給執照後始得營業，執照有效期間3年，得申請延期3年。
  • → 符合第61條第1項及第4項（免稅商店業者應向海關申請登記，並符合子法規定之設立條件）。
相關規定
  • 第61條
    1. 經營銷售貨物予入出境旅客之業者，得向海關申請登記為免稅商店。
    2. 免稅商店進儲供銷售之保稅貨物，在規定期間內銷售予旅客，原貨攜運出口者，免稅。
    3. 免稅商店之保稅貨物，應存儲於專供存儲免稅商店銷售貨物之保稅倉庫。
    4. 授權財政部訂定管理辦法。
記憶口訣
  • 免稅商店賣免稅，入出境旅客限定。
  • 保稅貨物專倉存，旅客攜運出口免。

免稅商店設置管理辦法

二種免稅商店區別
機場/港口免稅商店 市區免稅商店
設置地點
  • 國際機場、港口管制區內。
  • 經海關核准者，並得在市區內設置預售中心。
  • 國際機場或港口鄰近之都市區內，或經海關核准之區域內。
銷貨對象
  • 出境、過境及入境旅客。
  • 需持有護照、旅行證件或外僑居留證。
  • 出境旅客。
  • 需持有護照、旅行證件或外僑居留證。
出境提貨
  • 市區預售中心出售之貨物，比照市區免稅商店規定辦理提貨。
  • 購貨人於出境時，向機場或港口提貨處提貨。
  • 監管海關得隨時派員查核。
收款原則
  • 以收外幣為原則。
  • 臺幣可以收，但有限額。（中央銀行公告限額）
  • 臺幣外幣都能收。
  • 找零以新臺幣為限。
總則要點
  • 得出售商品：
    1. 外國商品
    2. 保稅倉庫、物流中心、保稅工廠產品
    3. 四區產品
    4. 課稅區之產品
  • 非屬經濟部公告准許輸入之大陸地區物品：不得進儲、不得銷售。
  • 免稅範圍：
    1. 關稅
    2. 貨物稅
    3. 營業稅
    4. 菸酒稅
    5. 菸品健康福利捐
  • 售予入境旅客：視同入境旅客自國外採購攜帶入境。
    • 通關時，依入境旅客攜帶行李物品報驗稅放辦法辦理。
    • 超過免稅限額部分，應依法繳納關稅、貨物稅、菸酒稅、菸品健康福利捐及營業稅。
設置要點
  • 申請條件：
    • 股份有限公司，實收資本額5000萬元以上。
    • 專營銷售旅客商品。
    • 領有海關核發之同一法人自用保稅倉庫執照。
    • 合格之電腦連線傳輸能力。
    • 合格之監視系統。
  • 執照：
    • 有效期間3年，得申請延期3年。
    • 期滿前2個月，重新申請，由海關重新審核發照。
    • 登記事項如有變更，30日內檢送有關證件向監管海關辦理換照。
    • 所在地變更，應於變更前先報請監管海關核准。
    • 如需停業者，應於一個月前報請監管海關核備。
管理要點
  • 專人辦理保稅： 應指定專人代表免稅商店辦理有關保稅事項，並報經監管海關核備。
  • 得自主管理： 符合實施自主管理規定標準者，得向海關申請核准實施自主管理。
  • 保稅貨物應存儲於專屬自用保稅倉庫： 保稅貨物，應存儲於專供存儲其免稅商店銷售貨物之同一法人自用保稅倉庫。
  • 下架移運保稅倉庫： 保稅貨物，如需維修、退貨、轉售及退運出口等，應移運至其自用保稅倉庫辦理。
  • 永續盤存制，逐日逐筆建檔：
    • 憑證報表、各項會計簿籍，應以電腦處理。
    • 應採永續盤存制存貨制度。
    • 應逐日逐筆即時登載進、銷貨資料，以備稽查。
  • 貨物移倉應申請：
    • 免稅商店、自用保稅倉庫間貨物之移運， 應傳輸「移倉申請書」至關港貿單一窗口。
    • 未得海關核准或系統回應記錄有案，不得自行移運。
  • 移倉運送應以保稅運貨工具為之：
    • 例外：免稅商店及其自用保稅倉庫均設於同一機場、港口管制區內者。
  • 保稅貨物存儲以2年（得延長一年）為限。屆期仍未售出，應退運出口或辦理補稅銷帳：
    • 存儲以2年為限：自貨物最初進儲其自用保稅倉庫之日起算。
    • 得延長一年：需監管海關核准。除天災、事變或其他不可抗力之事由外，以延長一次為限。
    • 屆期仍未售出，應退運出口。或自期限屆滿之翌日起30日內，辦理補稅銷帳。
