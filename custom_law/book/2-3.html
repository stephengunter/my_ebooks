2-3 通關程序-納稅期限與行政救濟

關稅等款項之繳納期限

  • 海關的稅單、罰單或費用通知單，繳納期限都是從收到通知的隔天起算14天內。其中：
    1. 如果是關稅本稅，從「稅單送達」的隔天起算14天。
    2. 如果是罰鍰或追繳貨價，要等到「處分確定」（即不能再打官司）且「收到海關通知」後，從隔天起算14天。
    3. 如果是貨物變賣或銷毀的費用，從「通知書送達」的隔天起算14天。
  • 超過14天沒繳，就會被加徵滯納金，甚至被移送強制執行。
簡單說：
  • 稅單、罰單、費用單，都是從收到隔天起算14天內要繳，逾期就會被加錢或強制執行。
起算點 繳納期限
關稅 稅款繳納證送達之翌日 14日內
罰鍰及追繳貨價 處分確定，收到海關通知之翌日 14日內
變賣或銷毀費用 通知書送達之翌日 14日內
舉個例子
例1：關稅本稅
  • A公司於113年7月1日收到海關核發之稅款繳納證（稅單）。
  • A公司應於113年7月2日起算14日內（即113年7月15日前）繳納。若7月15日為假日，則順延至次一工作日。
  • → 符合第43條第1項（關稅自稅款繳納證送達之翌日起14日內繳納）。
例2：罰鍰處分確定後
  • B公司因申報不實遭海關處以罰鍰新臺幣10萬元，B公司未申請復查，處分於113年6月30日確定。
  • 海關於113年7月10日寄發繳納通知，B公司於113年7月12日收到。
  • B公司應自113年7月13日起算14日內（即113年7月26日前）繳納。
  • → 符合第43條第2項（罰鍰自處分確定且收到通知之翌日起14日內繳納）。
例3：貨物變賣費用
  • C公司進口貨物逾期未報關，海關依法變賣該批貨物，並於113年8月1日將費用通知書送達C公司。
  • C公司應自113年8月2日起算14日內（即113年8月15日前）繳納變賣費用。
  • → 符合第43條第3項（變賣費用自通知書送達之翌日起14日內繳納）。
相關規定
  • 第43條
    • 第1項：關稅之繳納，自稅款繳納證送達之翌日起十四日內為之。
    • 第2項：依本法所處罰鍰及追繳貨價之繳納，應自處分確定，收到海關通知之翌日起十四日內為之。
    • 第3項：處理貨物變賣或銷毀貨物應繳之費用，應自通知書送達之翌日起十四日內繳納。
記憶口訣
  • 稅款罰鍰變賣費，送達翌日起算天。
  • 十四日內要繳清，逾期加徵滯納金。

繳稅後放行原則與擔保放行制度

  • 進口貨物原則上要先繳完關稅，海關才會放行讓你領貨。但以下情況例外：
    1. 法律有其他規定。
    2. 納稅義務人提供擔保給海關，經海關核准後，就可以先把貨領走，之後再補繳稅款。
      • 這套機制在實務上稱為「先放後稅」。
  • 至於擔保要怎麼辦理、可以用什麼方式擔保、擔保責任什麼時候解除等細節，由財政部另外訂辦法來規範。
    • 簡單說：
    • 繳完稅才能領貨是原則；但提供擔保後，可以先領貨、後繳稅。
    進口貨物先放後稅實施辦法
    • 定義：以擔保替代現金、保證金之繳納，先行驗放貨物。
      • 其他稅費、滯納金等，得由進口人申請海關核准後比照辦理。
    • 擔保方式：現金、公債、銀行定存單、授信機構保證等7種。
    • 擔保額度：限區擔保（單一關別）／通區擔保（各關別）
      • 額度內可循環使用。
    • 申請人：納稅義務人、報關業者或其負責人。
    • 申請方式：現金或授信機構保證者可線上申請（關港貿單一窗口）。
    • 違約後果：逾期未繳清者，海關得停止其1年以下先放後稅。
    舉個例子
    例1：繳稅後放行
    • A公司進口一批貨物，完稅價格及應納關稅均已核定，海關核發稅款繳納證。
    • A公司於收到稅單後，於14日內繳清關稅。海關確認稅款入庫後，予以放行，A公司提領貨物。
    • → 符合第44條本文（應於繳納關稅後，予以放行）。
    例2：擔保放行
    • B公司進口一批機器設備，因該貨物之稅則號別尚有爭議，無法立即核定應納稅額。
    • 惟該機器設備為B公司生產線所急需，遲延提領將造成重大損失。
    • B公司依規定提供銀行保證書作為擔保，經海關核准後，先行提領貨物（即「先放後稅」）。
    • 嗣後稅額確定，B公司再依限補繳稅款。
    • → 符合第44條但書（經海關核准已提供擔保者，應先予放行）。
    例3：擔保種類與額度控管
    • C公司向海關申請辦理「先放後稅」，並以定期存單設定質權予海關作為擔保。
    • 海關核給一定擔保額度。
    • C公司進口貨物時，海關自該擔保額度內扣減應納稅額，放行貨物。
    • C公司嗣後於14日內繳清稅款，電腦自動恢復擔保額度，循環使用。
    • → 符合第44條但書及第2項（擔保之方式及範圍，依財政部訂定之辦法辦理）。
    相關規定
    • 第44條
      • 第1項：應徵關稅之進口貨物，應於繳納關稅後，予以放行。
        • 但本法另有規定或經海關核准已提供擔保者，應先予放行。
      • 第2項：提供擔保之手續、擔保之範圍或方式等相關辦法，由財政部定之。
    記憶口訣
    • 海關調查核完稅，四項權限要記牢。
    • 買賣文件全可查，價格紀錄比對清。
    • 同業帳簿也能調，概括條款無遺漏。
    • 被調查人不得拒，否則罰鍰跑不掉。

    復查申請程序

    • 如果納稅義務人對海關核定的稅則號別、完稅價格、補繳稅款或特別關稅不服：
      • 可以在收到稅單的隔天起30天內，依照規定的格式寫一份「復查申請書」向海關提出申請，請求海關重新審查。
    • 納稅義務人可以在申請復查時，選擇：
      • 「繳清全部稅款」或「提供擔保」（例如銀行保證書、定存單等）
      ，就可以先把貨物領走，不用等到復查結果出來。
    簡單說：
    • 對海關核定不服，可在收到稅單後30天內申請復查；同時繳稅或提供擔保後，可以先領貨。
    適用情況：納稅義務人對海關所為之核定「不服」者
    限於下列四類核定：
    1. 稅則號別
    2. 完稅價格
    3. 應補繳稅款
    4. 特別關稅（反傾銷稅、平衡稅等）
    申請期間：30日內
    • 起算點：自「收到稅款繳納證」之「翌日」起算。
    • 逾期未申請者，該核定即告確定。
    申請方式：以書面向海關申請復查
    • 受理機關：原核定之海關。
    貨物提領：繳稅或提供擔保後提領
    • 申請復查之同時，納稅義務人得選擇「繳納全部稅款」或「提供相當擔保」。
    • 無論選擇何者，均得先行提領貨物，無須等待復查結果確定。
    舉個例子
    例1：申請復查
    • A公司進口一批貨物，海關核定其稅則號別為稅率10%之項目，A公司認為應歸屬稅率5%之項目。
    • A公司於收到稅款繳納證之翌日起30日內，依規定格式填具復查申請書，向原核定海關申請復查，並於申請時繳納全部稅款後提領貨物。
    • → 符合第45條（納稅義務人得於30日內申請復查，並得於繳稅後提領貨物）。
    例2：提供擔保提領貨物
    • B公司對海關核定之完稅價格不服，申請復查。
    • B公司認為全額繳稅將造成資金壓力，爰提供銀行保證書作為擔保（金額相當於應納稅額），經海關核准後，先行提領貨物。
    • → 符合第45條（提供相當擔保後，得提領貨物）。
    例3：逾期申請之效果
    • C公司於收到稅款繳納證後第40日始向海關提出復查申請。
    • 海關以逾30日法定期間為由，不予受理該復查申請，該核定即告確定。
    • → 不符合第45條（應於收到稅款繳納證之翌日起30日內申請，逾期即喪失復查權）。
    相關規定
    • 第45條
      • 納稅義務人不服海關對其進口貨物核定之稅則號別、完稅價格或應補繳稅款或特別關稅者：
        • 得於收到稅款繳納證之翌日起三十日內，依規定格式，以書面向海關申請復查。
        • 並得於繳納全部稅款或提供相當擔保後，提領貨物。
    記憶口訣
    • 不服核定稅則價，收到稅單三十天，書面申請提復查，繳稅擔保先領貨。

    復查決定之期限與決定書送達

    • 納稅義務人申請復查後：
      • 海關原則上必須在「收到申請書的隔天起2個月內」作出復查決定。
      • 並作成書面決定書通知納稅義務人。
      如果案情複雜：
      • 海關可以延長一次，但最多只能再延「2個月」。
      • 而且延長時必須通知納稅義務人
    • 決定書作成後，海關必須在「決定後15天內」將正本送達納稅義務人。
      • 這樣納稅義務人才知道復查的結果，也才能決定要不要繼續提起訴願。
    簡單說：
    • 申請復查後，海關應在2個月內作出決定（必要時可再延2個月），並在決定後15天內將決定書送達申請人。
    審查期限：2個月內做出復查決定
    • 起算點：自海關「收到」復查申請書之「翌日」起算。
    • 期限：原則上為「2個月」內須作成復查決定（必要時可延長2個月）。
    • 逾期之效果：雖未明定逾期之法律效果，惟若海關逾越期限，納稅義務人得據此主張程序違法。
      • 並得依訴願法規定，於法定期間屆滿後視為已提起訴願。
    必要時，得延長2個月
    • 延長要件：僅於「必要時」始得延長（如案情複雜、須調查證據等）。
    • 延長次數：以「一次」為限。
    • 延長期間：最長不得逾2個月。
    • 通知義務：海關應將延長之事由及期間「通知」納稅義務人。
    應做成決定書，通知納稅義務人
    • 決定書：指海關就復查申請所為之書面決定，應載明理由及法律依據。
    • 通知納稅義務人：指將決定書送達予納稅義務人，使其知悉復查結果。
    復查決定書正本，應於15日內送達納稅義務人
    • 送達期限：15日內。 。
    • 起算點：自「決定之翌日」起算。
    舉個例子
    例1：二個月內作成決定
    • A公司於113年5月1日向海關提出復查申請書，海關當日收到。
    • 海關應於113年5月2日起算2個月內（即113年7月1日前）作成復查決定，並於決定後15日內將決定書送達A公司。
    • → 符合第46條第1項（海關應於收到申請書之翌日起二個月內為復查決定）。
    例2：延長決定期限
    • B公司申請復查，因案情涉及複雜之原產地認定，須向國外查證相關產地證明文件。
    • 海關於法定期間內通知B公司，因調查需要延長復查決定期間二個月，總計四個月內作成決定。
    • → 符合第46條第1項但書（必要時得延長一次，最長不得逾二個月）。
    例3：決定書送達期限
    • 海關於113年7月1日作成復查決定，應於113年7月2日起算15日內（即113年7月16日前）將決定書正本送達納稅義務人。
    • 惟該貨物因欠稅遭海關扣押，Q公司為倉庫業者，實際持有該批貨物。
    • → 符合第46條第2項（復查決定書之正本，應於決定之翌日起十五日內送達納稅義務人）。
    相關規定
    • 第46條
      • 第1項：海關對復查之申請，應於收到申請書之翌日起二個月內為復查決定，並作成決定書，通知納稅義務人。
        • 必要時，得予延長，並通知納稅義務人。延長以一次為限，最長不得逾二個月
      • 第2項：復查決定書之正本，應於決定之翌日起十五日內送達納稅義務人。
    記憶口訣
    • 復查申請海關收，兩個月內要決定。
    • 必要可延兩個月，延長以一次為限。
    • 決定書正本作成，十五日內送達你。

    復查後之救濟與確定案件之退補稅及利息

    • 如果納稅義務人對海關的復查決定還是不服：
      • 可以繼續向財政部提起「訴願」。
      • 對訴願決定仍不服，還可以再向行政法院提起「行政訴訟」。
    • 等整個救濟程序跑完，確定下來後：
      • 如果確定應該「退稅」： 海關必須在確定的隔天起10天內把錢退還，並加計利息。
      • 如果確定應該「補稅」： 海關必須在確定的隔天起10天內通知補繳，並加計利息。
    簡單說：
    • 不服復查決定可續行訴願及行政訴訟。
    • 確定退稅者，海關10天內退還並加計利息。
    • 確定補稅者，海關10天內通知補繳並加計利息。
    不服復查決定者，得依法提起訴願及行政訴訟
    • 復查決定後，納稅義務人若不服，得續行救濟。
    • 救濟程序依序為：
      1. 訴願：向「財政部」提起訴願。
      2. 行政訴訟：對訴願決定不服者，向「行政法院」提起行政訴訟。
    「確定」應退稅者：10日內退還並加計利息
    • 「確定」應退稅：經復查、訴願或行政訴訟程序「確定」應退還稅款。
    • 10日內退還：自「確定之翌日」起算。
    • 利息計算方式：
      • 計息期間：自納稅義務人「繳納」該項稅款之「翌日」起，至海關「填發收入退還書或國庫支票之日」止。
      • 計息利率：以「繳納稅款之日」郵政儲金一年期定期儲金「固定利率」為準（而非退稅日之利率）。
      • 計息方式：按退稅額「按日」加計利息，一併退還。
    「確定」應補稅者：10日內通知補稅並加計利息
    • 「確定」應補稅：經復查、訴願或行政訴訟程序「確定」應補繳稅款。
    • 10日內：自「確定之翌日」起算。
    • 通知補稅：填發「補繳稅款繳納通知書」，通知納稅義務人繳納。
    • 利息計算方式：
      • 計息期間：自該項稅款「原應繳納期間屆滿之翌日」起，至海關「填發補繳稅款繳納通知書之日」止。
      • 計息利率：以「原應繳納稅款之日」郵政儲金一年期定期儲金「固定利率」為準。
      • 計息方式：按補繳稅額「按日」加計利息，一併徵收。
    舉個例子
    例1：續行救濟——訴願
    • A公司不服海關之復查決定，於收到復查決定書之翌日起30日內，依訴願法之規定，向財政部提起訴願。
    • → 符合第47條第1項（納稅義務人得依法提起訴願）。
    例2：確定退稅加計利息
    • B公司因關稅爭議，於112年1月15日繳納稅款100萬元。
    • 其後提起復查、訴願、行政訴訟，最終於113年6月30日判決確定應退還全部稅款。
    • 海關應於113年7月1日起算10日內（即113年7月10日前）退還100萬元， 並自112年1月16日起至填發退稅支票日止，按112年1月15日之郵政儲金一年期定期儲金固定利率， 按日加計利息一併退還。
    • → 符合第47條第2項（確定退稅者，海關應於10日內退還並加計利息）。
    例3：確定補稅加計利息
    • C公司原應於112年3月15日前繳納關稅50萬元，因提起行政救濟而暫緩繳納。
    • 最終於113年8月31日判決確定應補繳該筆稅款。

    • 第47條
      • 第1項：納稅義務人不服前條復查決定者，得依法提起訴願及行政訴訟。
      • 第2項：經依復查、訴願或行政訴訟確定應退還稅款者，海關應於確定之翌日起十日內，按日加計利息，一併退還。
      • 第3項：經依復查、訴願或行政訴訟確定應補繳稅款者，海關應於確定之翌日起十日內，按日加計利息，一併填發補繳稅款繳納通知書，通知納稅義務人繳納。

    復查程序總整理

    申請人 受理機關
    復查限制：限於「不服」下列四類核定：
    1. 稅則號別
    2. 完稅價格
    3. 應補繳稅款
    4. 特別關稅（反傾銷稅、平衡稅等）
    申請復查
    • 申請人：納稅義務人或其代理人。
    • 申請期間：30日內。自「收到稅款繳納證」之「翌日」起算。
    • 以書面向原核定之海關申請復查。
    貨物提領：繳稅或提供擔保後提領
    • 申請復查之同時，納稅義務人得「繳納全部稅款」或「提供相當擔保」後先行提領貨物。
    • 復查機關：原核定之海關。
    審查期限：2個月內做出復查決定
    • 起算點：自海關「收到」復查申請書之「翌日」起算。
    • 期限：原則上「2個月」內作成復查決定。
    必要時，得延長2個月
    • 以延長「一次」為限。最長不得逾2個月。
    • 通知義務：海關應將延長之事由及期間「通知」納稅義務人。
    應做成決定書
    • 決定書：指海關就復查申請所為之書面決定，應載明理由及法律依據。
    復查決定書正本，應於15日內送達納稅義務人
    • 15日內：自「決定之翌日」起算。
    • 將正本送達納稅義務人：使其知悉復查結果。
    復查後之救濟與確定案件之退補稅
    納稅義務人 海關
    不服復查決定者，得依法提起訴願及行政訴訟
    • 復查決定後，納稅義務人若不服，得續行救濟。
    • 救濟程序依序為：
      1. 訴願：向「財政部」提起訴願。
      2. 行政訴訟：對訴願決定不服者，向「行政法院」提起行政訴訟。
    		「確定」應退稅者：10日內退還並加計利息
    • 「確定」應退稅：經復查、訴願或行政訴訟程序「確定」應退還稅款。
    • 10日內退還：自「確定之翌日」起算。
    • 利息計算方式：
      • 計息期間：自「繳納翌日」起，至海關「填發收入退還書」止。
      • 計息利率：以「繳納之日」郵政儲金一年期定期儲金「固定利率」為準。
      • 計息方式：按退稅額「按日」加計利息，一併退還。
    「確定」應補稅者：10日內通知補稅並加計利息
    • 「確定」應補稅：經復查、訴願或行政訴訟程序「確定」應補繳稅款。
    • 10日內：自「確定之翌日」起算。
    • 通知補稅：填發「補繳稅款繳納通知書」，通知納稅義務人繳納。
    • 利息計算方式：
      • 計息期間：自該項稅款「原應繳納期間屆滿之翌日」起，至海關「填發補繳稅款繳納通知書之日」止。
      • 計息利率：以「原應繳納稅款之日」郵政儲金一年期定期儲金「固定利率」為準。
      • 計息方式：按補繳稅額「按日」加計利息，一併徵收。
