納稅義務人

  • 納稅義務人，就是「依法必須繳納關稅的人」。
    • 白話說：貨物進到台灣，政府要收稅，總要有人負責繳這筆錢，那個人就是納稅義務人。
  • 關稅法第6條：「關稅納稅義務人為收貨人、提貨單或貨物持有人。」
    • 原則：有「收貨人」就找收貨人 → 收貨人找不到／搞不定，就抓「提貨單持有人」 → 再不行，誰「拿著貨」就找誰。
三種納稅義務人
  • 關稅法第6條規定，以下三種人都是納稅義務人：
順位 身分 說明 舉例
① 收貨人 提單上寫的「貨物受領人」
  • 台灣的A公司向日本B公司買了100台工具機，海運提單上 Consignee（受貨人） 寫A公司。
  • => A就是收貨人，也就是納稅義務人。
② 提貨單持有人 拿著提貨單、有權去領貨的人
  • A公司把這100台工具機轉賣給C公司，並把提貨單背書轉讓給C。
  • 貨到港後，C拿著提貨單去報關領貨。 => C就是提貨單持有人，這批貨的關稅由C繳。
③ 貨物持有人 實際「拿著」或「管著」貨物的人
  • 海關在某工廠查到一批來路不明的進口貨物，沒有完稅證明。
  • 工廠老闆D說「這批貨不是我的，我只是幫朋友保管」。
  • 海關不管，誰拿著貨、誰管著貨，誰就要負責 => D就是貨物持有人。
  • 海關追稅的邏輯是：有「收貨人」就找收貨人 → 收貨人找不到／搞不定，就抓「提貨單持有人」 → 再不行，誰「拿著貨」就找誰。
為什麼要規定三種人？
  • 因為實務上貨物不一定始終在同一個人手上：
舉例 海關找誰
正常情況 A公司進口貨物，自己報關、自己繳稅、自己領貨 收貨人＝A（沒爭議）
貨物被轉賣 A把貨賣給C，提貨單也轉讓了 提貨單持有人＝C
收貨人倒閉 A公司倒了，但貨還在港口沒人領 提貨單持有人（銀行或買家）
走私查緝 貨物在D的倉庫被查到，D說不是他的 貨物持有人＝D
對應法條
  • 第6條：「納稅義務人為收貨人、提貨單或貨物持有人。」
  • 第16條：「進口貨物之報關，由收貨人為之。」
加強記憶
口訣：
  • 有收貨找收貨，收貨不見找持單，持單不見找持貨——總有一個人要繳。

稅則號列

  • 稅則號列：（或稱「進口稅則」、「稅則編號」）
    • 是貨物的身分證號碼對照表，決定這批貨要課多少稅。
    • 一類貨物對應一個稅則編號。從「稅則編號 + 產地」可以查到對應的稅率。
範例
稅則編號 貨名 第1欄稅率 第2欄稅率 第3欄稅率
2103.1090.00-1 其他醬油 15% 12%（GT）/ 13.5%（NI）/ 0%（PA）/ 14%（SV）/ 0%（LDCs） 25%
  • 第2欄的英文字母代表不同國家（GT＝瓜地馬拉、NI＝尼加拉瓜、PA＝巴拿馬、SV＝薩爾瓦多、LDCs＝低度開發國家），適用不同優惠稅率。
稅率有幾種？——三欄稅率
  • 台灣的進口稅則採「三欄稅率」，依貨物原產地不同，適用不同稅率。
欄位 名稱 適用對象 稅率高低
第1欄 最惠國稅率 WTO會員國、與我國有互惠待遇的國家 中等（最常見）
第2欄 優惠稅率 與我簽訂FTA或經濟合作協定的國家 較低
第3欄 普通稅率 不適用第1、2欄的國家 最高
舉例
  • 從美國進口工具機 → 美國是WTO會員 → 適用第1欄稅率
  • 從新加坡進口特定貨物 → 台星有經濟合作協議 → 可能適用第2欄較低稅率（若有列明）
  • 從北韓進口貨物 → 不符合第1、2欄條件 → 適用第3欄最高稅率
補充
  • 如果同一批貨同時符合第1欄和第2欄，適用較低者。
編碼結構（從國際到國內）
  • 進口稅則的編號不是隨便編的，有嚴格的層級邏輯：
位數 意義 說明 舉例（工具機）
前2位 章（Chapter） 貨物的「大分類」 84章（機器及機械用具）
前4位 品目（Heading） 章底下的細分類 8458（車床）
前6位 子目（Subheading） 國際通用的HS編碼 845811（數值控制車床）
第7、8位 稅則號列 我國自行增加的稅率編號 84581100（決定稅率）
第9、10位 商品編號 因反傾銷、檢疫等需求拆分 84581100.10（如有反傾銷稅）
HS編碼是什麼？
  • HS是「國際商品統一分類制度」（Harmonized System）的簡稱，由世界海關組織制定，全球200多個國家共同使用。
  • 前6位全球統一，確保各國對同一貨物有一致的認知。
  • 比如：「845811」 無論哪一國，看到這6碼就知道是「數值控制車床」。
台灣的8位碼怎麼來的？
  • 前6位照抄國際HS編碼。
  • 第7、8位是台灣根據自己的關稅政策和產業需求，在HS分類基礎上增加的「本國子目」。

進口稅則

  • 《海關進口稅則》是《關稅法》的附件，是一本專門用來查「貨物編號和對應稅率」的法律。
  • 《海關進口稅則》：
    • 是法律：不是行政規則或參考書，而是另經立法程序制定公布的法律文件。
    • 是《關稅法》的附件：關稅法本身規定原則，而「貨物怎麼分類、稅率多少」的細節，都寫在《進口稅則》這本附件裡。
    • 主要內容是稅目稅率表：裡面主要內容就是「貨物名稱、稅則號列、對應稅率」這張對照表。
  • 法條依據： 關稅法第3條「關稅之徵收及進出口貨物稅則之分類...依海關進口稅則之規定。海關進口稅則，另經立法程序制定公布之。」

貨物通關自動化

  • 貨物通關自動化：用電腦連線取代人工紙本作業的通關制度。
    • 它是制度：是海關推動通關現代化的政策與法律架構。
    • 法律授權：關稅法第10條第1、2項賦予法律基礎。
    • 核心效力：電腦連線申報，經海關電腦記錄者，與紙本申報具同等法律效力。
  • 白話說：以前報關要填紙本、送文件、人工審核。
    • 現在直接在電腦上傳資料，海關系統自動接收、自動比對、自動篩選（C1/C2/C3）。
    • 整個過程以電子化、標準化、系統化方式進行。
通關自動化的核心內涵
  • 申報方式：透過電腦連線或電子資料傳輸辦理，取代紙本申報。
  • 法律效力：經海關電腦記錄有案者，視為已依法辦理或提出。
  • 通關方式：由電腦依風險評估自動篩選C1、C2、C3。
  • 貨物管控：以電子封條、衛星定位等技術輔助監管。
  • 稅費作業：電腦自動核算稅費、線上繳納。
通關自動化的三大支柱
  • 法律效力：電腦申報與紙本申報同等有效。
  • 強制連線：海關得要求通關相關業者全面電腦連線。
  • 電子送達：海關之核定、處分、通知得以電子方式送達。
通關自動化的效益
  • 加速通關：C1案件秒放，大幅縮短通關時間。
  • 降低成本：減少紙本文件、人工遞送、倉儲等成本。
  • 提升正確性：電腦比對降低人為錯誤。
  • 強化風險管理：電腦自動篩選高風險貨物，精準查緝。
  • 透明化：業者可即時查詢通關狀態。
相關規定
  • 第10條
    • 第1項：電腦連線申報與紙本申報同等法律效力。
    • 第2項：海關得要求通關相關業者電腦連線處理業務。
    • 第3項：連線申報之登記、管理辦法，由財政部定之。
    • 第4項：海關之核定、處分、通知得以電子方式送達。
    • 第5項：通關網路業者須經財政部許可。

關港貿單一窗口

  • 關港貿單一窗口：是進出口通關的「一站式線上櫃台」。 整合海關、航港、貿易簽審、檢驗、檢疫等機關，提供一站式線上通關服務。
    • 辦理通關的線上櫃台：報關人透過這個平台，向海關申報進出口貨物資料。
    • 它是跨機關平台：整合海關、航港、貿易簽審、檢驗、檢疫等機關，一次申辦、多機關同步處理。
    • 它已基本取代紙本：傳統紙本報關已全面轉為數位化，透過平台連線申報，與書面文件具有同等法律效力（第10條）。
    • 通關自動化的核心：通關自動化是制度，關港貿單一窗口是具體實現的重要工具。
  • 白話說：以前報關要跑好多地方、交好多紙本文件。現在全部整合到一個網站上。
    • 進口商、報關行、運輸業者、海關、簽審機關都在同一個平台上作業。
    • 只要上傳一次資料，海關和相關機關就能同步處理，不用重複送件。
法律效力：數位申報＝紙本申報
  • 關稅法第10條第1項規定：「依本法應辦理之事項、應提出之報單及其他相關文件， 採與海關電腦連線或電子資料傳輸方式辦理，並經海關電腦記錄有案者，視為已依本法規定辦理或提出。」
  • 換句話說：經由關港貿單一窗口連線申報的報單，其效力與書面文件相同。
    • 你在平台上傳的報單，跟以前送紙本報單給海關是一樣有效的。
    • 海關在電腦系統裡記錄的資料，在法律上等同於收到你的書面文件。
  • 數位申報已經基本取代傳統紙本作業： 目前絕大多數進出口報關案件都是透過關港貿單一窗口連線申報，只有少數例外情況才使用紙本。
各機關整合在同一平台
  • 關稅法第10-1條第1項規定：「依關務、航港、貿易簽審、檢驗及檢疫相關規定提出之資料，採與相關機關或其受託機構電腦連線或電子資料傳輸方式辦理者，得經由海關建置之關港貿單一窗口為之。」
  • 白話說：
    • 關港貿單一窗口不只是給海關用的。
    • 經濟部（貿易簽審）、農業部（檢疫）、標準檢驗局（檢驗）、航港局（航港）…… 所有跟進出口有關的機關，都整合到同一個平台上。
    • 你上傳一次資料，所有相關機關同步接收、同步處理。
業者「必須」使用
  • 關稅法第10-1條第2項規定： 「海關得依貨物通關自動化實施情形，要求經營報關、運輸、承攬、倉儲、貨櫃集散站及其他與通關有關業務之業者，以電腦連線或電子資料傳輸方式處理業務。」
  • 白話說：海關有權強制要求報關行、船公司、倉儲業者等通關相關業者，全部改用電腦連線作業，不能再走紙本。
為什麼可以強制業者使用？
  • 自動化是通關管制的必要工具：
    • 海關每天處理數十萬筆貨物資料，不可能靠人工一本一本翻。通關自動化是讓海關「做得到」法律賦予任務的前提。
    • 業者沒有「選擇用哪種方式申報」的權利，只有「配合」的義務。
海關的送達也可以用電子方式
  • 關稅法第10條第4項規定： 「海關所為各項核定、處分、通知或決定之送達，得以電腦連線或電子資料傳輸方式行之，並於電腦記錄。」
  • 白話說：
    • 以前海關的稅單、處分書、通知函，都要郵寄掛號給你。
    • 現在海關可以直接在系統裡發送，電腦記錄存證就算送達了。
    • 你在系統裡看到核定通知的那一刻，在法律上等同於你已經收到紙本公文。
通關網路業者須經財政部許可
  • 關稅法第10條第5項規定： 「經營與海關電腦連線或電子資料傳輸通關資料業務之通關網路業者，應經財政部許可。」
  • 白話說：提供通關網路服務的公司（如關貿網路），不是隨便誰都能做的，必須經過財政部許可才能經營。
    • 財政部會規範其資本額、收費標準、營業時間等事項。
保密義務
  • 關稅法第10-1第2項規定： 「關務人員對於經由前項關港貿單一窗口傳輸之資料，應嚴守秘密。」
  • 白話說：海關人員透過單一窗口看到的進出口資料（如價格、交易對象、貨物品項），不能對外洩漏。
    • 這是對報關人的隱私與商業機密保護。
它可以做什麼？（功能總覽）
  • 線上報關：進出口人／報關行透過平台送出報單。
  • 通關狀態查詢：查詢貨物目前在哪個階段（收單、查驗、放行）。
  • 主動通知服務：設定後，海關主動發送「放行通知」、「查驗通知」、「應補辦事項通知」到Email或APP。
  • 稅費繳納：線上查詢稅額並繳納。
  • 免證查詢：民眾可免登入查詢貨物通關紀錄（防詐騙用）

② 另外向防檢署送檢疫申請書 系統自動轉送農業部動植物防疫檢疫署審查檢疫

④ 各機關分別審查、分別通知 所有機關同步審查、同步回覆
⑤ 業者等各機關都過關才能放行 平台整合所有審查結果，統一放行
  • 關鍵：上傳一次資料，海關、防檢署、貿易署全部同步處理。
情境2：出口貨物（出貨給國外客戶）
  • 台灣的B公司要出口一批電子零件到美國，貨物要從桃園機場空運。
步驟 用關港貿單一窗口做什麼？

關稅配額

  • 關稅配額，就是政府對特定進口貨物設定一個數量上限：
    • 上限內用便宜的稅率，超過上限就用貴的稅率。
  • 例如：政府說「香蕉可以進口，前13,338噸只課12.5%的稅，超過的每噸課100%的稅」。
    • 進口商可以選擇繼續進口超過配額的香蕉，但要繳很重的稅——划不划算，自己算。
為什麼要有關稅配額？
  • 保護國內產業
    • 讓進口貨在價格上不具優勢，國內農民／廠商不會被低價進口貨打垮。
  • 履行國際承諾
    • 台灣加入WTO時承諾開放部分農產品市場，關稅配額是「有限度開放」的工具。
  • 平衡國內供需
    • 國內生產不足時，配額內低稅率確保基本供應；國內生產過剩時，配額外高稅率防止過度進口。
具體例子：香蕉
配額數量 13,338公噸
配額內稅率 12.5%
配額外稅率 100%
差多少 配額外稅率是配額內的8倍
  • 進口商可以選擇進口超過13,338噸的香蕉，但要繳100%的關稅——除非真的非常需要，否則一般不會這樣做。
關稅配額的主管機關
  • 關稅法第5條授權財政部制定《關稅配額實施辦法》：規範配額之分配方式、分配資格、權利金、保證金等實施辦法。
    • 《關稅配額實施辦法》由財政部會同有關機關（經濟部、農業部等）擬訂，報請行政院核定之。
誰實際負責分配
  • 《關稅配額實施辦法》規定：「關稅配額之核配，由財政部為之，並得委任所屬機關或委託其他機關（構）辦理。」
    • 「核配」：決定「配額分給誰」。即實際分配關稅配額給進口商。
  • 財政部委託臺灣銀行辦理關稅配額核配：由臺灣銀行負責受理申請、核發配額證等事項。
配額怎麼分配？（兩種核配方式）
  • 《關稅配額實施辦法》第4條規定兩種核配方式：
核配方式 說明 分配程序
先到先配 誰先報關進口，誰先拿到配額 按進口日先後順序
事先核配 事先申請分配配額，拿到證明書才能用 申請順序、抽籤、進口實績、標售關稅配額權利

轉運與轉口貨物通關

  • 轉運：貨物入境卸貨後，轉送同一關區科學園區、科技產業園區（四區）或其他關區辦理進口通關。
    • 貨物最終要進口，只是換個地方通關。
    • 要繳關稅。在目的地關區辦理進口通關時繳。
      • 如目的地為「四區」，則暫免關稅（保稅）。
    • 例如：貨物從國外運來，先在高雄港卸貨，然後轉送到基隆港辦理進口通關。
  • 轉口：貨物入境卸存後，辦理轉船（機）出口。
    • 貨物最終不進口，只是路過。
    • 不用繳關稅（不進口）。
    • 例如：日本的貨櫃到了高雄港，但它最終要賣給越南。 貨櫃在高雄港卸下來，先放在轉口櫃專區等幾天，下一班去越南的船來了，再裝上去運走。
  • 要申報：轉運與轉口都要準備艙單及轉運申請書向海關申報。
  • 可暫存：貨物可暫存於貨棧或貨櫃集散站。
  • 受監管：轉運與轉口貨物全程受海關監管。確保貨物於過境期間不致非法流入國內市場。
    • 轉運監管重點：運輸過程（保稅運貨工具、指定路線、電子封條）。
    • 轉口監管重點：貨物應存儲於海關指定區域。

四區：暫免關稅
  • 四區：科學園區、科技產業園區、農業科技園區、自由貿易港區。
  • 四區是「境內關外」的特別區域——貨物進到這裡，雖然在台灣境內，但：
    • 在關稅上視同「還沒進到台灣」，所以暫免關稅。
  • 貨物從國外進到這四區時，暫時不課關稅（保稅狀態）。
    • 如果貨物從園區賣到台灣國內市場時，才辦理進口通關、繳關稅。
    例如：台積電從國外買一台昂貴的半導體設備進到竹科，不用繳關稅。
    • 但如果這台設備要賣到台灣國內的其他公司，就要補繳關稅。
  • 優惠目的：鼓勵出口、扶植特定產業。
