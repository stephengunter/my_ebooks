2-2 通關程序-報關及查驗

完稅價格之核估原則與交易價格制度

  • 進口貨物如果是按價格來課關稅：
    • 其「完稅價格」原則上就是買賣雙方「實際交易的價格」。
    • 「實際交易的價格」是指：從出口國賣到台灣來，買方已經付或應該付的全部價款。
  • 不過，發票上的價格通常不會包含所有成本。所以法律規定，下面這些費用如果沒有算進去，必須「加」到交易價格裡面：
    1. 買方付的佣金、包裝費。
    2. 買方免費或打折提供給賣方用於生產的原料、工具、設計等。
    3. 權利金。
    4. 運到台灣港口的運費、裝卸費和保險費等。
  • 計入交易價格之費用（如佣金、權利金、保險費等）須有「客觀、可計量」之資料為依據。
    • 如果沒有「客觀、可計量」的資料，則應放棄交易價格方法，而改用其他方法來估價。
  • 如果海關對你提供的交易文件有「合理懷疑」，你無法說明清楚：
    • 那海關就可以不用交易價格來核估完稅價格，而改用其他方法來估價。
簡單說：
  • 進口貨物的關稅稅基，原則上就是買賣雙方實際交易的價格，再加上特定應計入的費用。
  • 若海關對文件真實性有合理懷疑，可改用其他方法核估。
完稅價格以交易價格為計算根據
  • 「交易價格」為核估完稅價格之首要基準。
  • 完稅價格為計算關稅之「稅基」，其計算公式為：完稅價格 × 關稅稅率 = 應納關稅額。
  • 若無法依交易價格核估，則應依序適用：
    1. 同樣貨物之交易價格（第31條）
    2. 類似貨物之交易價格（第32條）
    3. 國內銷售價格（第33條）
    4. 計算價格（第34條）
    5. 合理方法（第35條）
交易價格之計算
交易價格：指進口貨物由輸出國銷售至我實付或應付之價格
  • 「實付或應付之價格」：指買方為進口貨物已付或應付予賣方之全部價款，不以實際支付為限 。
應計入交易價格之費用
  • 以下費用應計入交易價格之費用。此等費用雖未直接反映於發票價格中，但實際上為買方取得該進口貨物所付出之成本，故應計入完稅價格。
    1. 買方付的佣金、包裝費。
    2. 買方免費或打折提供給賣方用於生產的原料、工具、設計等。
    3. 權利金。
    4. 運到台灣港口的運費、裝卸費和保險費等。
客觀可計量原則
  • 計入交易價格之費用（如佣金、權利金、保險費等）須有「客觀、可計量」之資料為依據。
  • 如果沒有「客觀、可計量」的資料，則應放棄交易價格方法，改依第31條至第35條之次順位方法核估。
估價審查權與納稅義務人之協力義務
  • 納稅義務人有義務提出完整、真實的交易文件。
  • 若納稅義務人未能提供充分之交易文件或說明，或海關對其說明仍有「合理懷疑」，則「視為無法按交易價格核估」。
  • 此為海關得依其他方法核估完稅價格之「程序要件」。
舉個例子
例1：以交易價格核估
  • A公司自日本進口汽車一批，買賣合約載明每輛CIF基隆港價格為新臺幣100萬元。
  • 該價格已包含運費、保險費及賣方之利潤，且無其他應加計之費用。
  • 海關即以每輛新臺幣100萬元作為完稅價格，乘以適用稅率課徵關稅。
  • → 符合第29條第1項及第2項（完稅價格以交易價格為計算根據）。
例2：加計權利金
  • B公司自美國進口電腦軟體，支付賣方軟體費用新臺幣500萬元，另依合約支付權利金新臺幣50萬元。
  • 該權利金為取得軟體使用權之條件，與進口貨物有關且未計入原交易價格。
  • 海關將該權利金50萬元計入完稅價格。
  • → 符合第29條第3項第3款（權利金應計入完稅價格）。
例3：合理懷疑而無法核估
  • C公司自中國進口電子零組件，申報交易價格為每件新臺幣10元。
  • 海關查核發現，該同類貨物之國際市場行情約為每件新臺幣50元，且C公司無法提出合理說明及完整交易文件。
  • 海關合理懷疑其交易價格之真實性，爰認定無法依本條核估，改依第35條合理方法核估完稅價格。
  • → 符合第29條第5項（海關對交易文件真實性有合理懷疑，納稅義務人未提出說明者，視為無法按本條核估）。
相關規定
  • 第29條
    • 第1項：從價課徵關稅之進口貨物，其完稅價格以該進口貨物之交易價格作為計算根據。
    • 第2項：交易價格，指進口貨物由輸出國銷售至中華民國實付或應付之價格。
    • 第3項：列舉應計入交易價格之費用。
    • 第4項：計入完稅價格之費用，應根據客觀及可計量之資料。無客觀及可計量之資料者，視為無法按本條規定核估其完稅價格。
    • 第5項：海關對發票或交易文件有合理懷疑，得視為無法按本條規定核估其完稅價格。
記憶口訣
  • 交易價格為基礎，實付應付都算數。
  • 六項費用要加計，佣金包裝運保費，權利金與轉售利，買方提供物品勞。
  • 客觀計量要具體， 無則無法用此法。
  • 海關懷疑可拒絕，另行核估完稅價。

交易價格之排除適用事由與特殊關係之認定

  • 不是所有的「交易價格」都可以拿來當作關稅的稅基。 如果有以下四種情況，海關就不能用這個交易價格來算關稅：
    1. 買方對貨物的使用或處分受到限制（除非是我國法律規定的限制、轉售地區的限制，或該限制對價格影響不大）
    2. 這個交易附帶了條件，導致無法算出這批貨物真正的價格
    3. 買方轉賣貨物後要把部分收益分給賣方，但這筆錢到底有多少不清楚
    4. 買賣雙方有「特殊關係」，而且因為這個關係影響了價格
  • 至於什麼叫「特殊關係」，法律也明確列出八種情況，包括：
    • 一方是另一方的董事、經理人、持有對方5%以上股份、控制關係、僱傭關係、合夥關係
    • 或是配偶、三親等以內親屬等
簡單說：
  • 當交易價格被操控、受限或附帶不明條件時，海關不能拿它來課稅。
  • 買賣雙方有特殊關係時，除非能證明價格不受影響，否則也不能用。
一句話總結
  • 當進口貨物之交易價格受限制、附條件、收益不明或受特殊關係影響時：
    • 不得作為完稅價格之計算根據，應改用其他方法核估。
為什麼要有這條規定？
  • 確保完稅價格之真實性與正確性：排除受限制、附條件、收益不明或受特殊關係影響之交易價格，確保完稅價格反映貨物之真實價值。
  • 遵循WTO關稅估價協定之國際規範：我國為WTO會員，關稅估價制度須與該協定一致，本條之規範內容與該協定第1條及相關註釋完全接軌。
  • 防止藉由特殊關係規避關稅：關係企業或關聯企業間之交易，可能透過人為操縱價格以降低關稅負擔，本條透過特殊關係之認定與價格影響之審查，防止此類規避行為。
  • 建立明確之法律要件：本條將不得採用交易價格之事由及特殊關係之具體態樣予以明文化，使納稅義務人與海關均有明確之法律依據可資遵循。
舉個例子
例1：使用限制致價格不採用
  • A公司向國外供應商購買一批機械設備，合約約定該設備僅得於A公司之特定廠房內使用，不得移轉或出租予第三人。
  • 海關認定此使用限制影響價格之正常決定，爰依本條第一款規定，不採用該交易價格為完稅價格。
  • → 符合第30條第1項第1款（買方對貨物使用受有限制，且非屬我國法令限制、轉售地區限制或對價格無重大影響）。
例2：附條件交易
  • B公司向國外供應商購買一批化學原料，合約約定B公司須同時向該供應商購買另一批滯銷庫存品，始得以該價格購入原料。
  • 海關認定該交易附有條件，致原料價格無法與庫存品價格分離核定。
  • → 符合第30條第1項第2款（交易附有條件，致價格無法核定）。
例3：特殊關係且影響價格
  • C公司為台灣進口商，其母公司持有C公司百分之百之股份。
  • C公司向母公司進口一批電子零組件，申報價格僅為國際市場行情之60%。
  • 海關認定雙方為特殊關係（持股關係），且該關係致價格偏低，爰不採用該交易價格。
  • → 符合第30條第1項第4款及第2項第4款（買賣雙方為特殊關係且致影響交易價格，交易價格不得採用）

同樣貨物之交易價格核估法

  • 如果進口貨物沒有辦法用第29條的「實際交易價格」來估關稅（例如價格不透明、有特殊關係、海關有合理懷疑等）時：
    • 海關可以用「同樣貨物」的交易價格來核估。
  • 所謂「同樣貨物」，是指生產國、物理特性、品質和商譽都完全一樣的貨物。
  • 不過，即使是同樣貨物，交易條件也可能不同（例如買的數量不一樣、運費不一樣）：
    • 海關在核估時，可以針對這些影響價格的因素做合理的調整。
簡單說：
  • 無法用實際交易價格估稅時：
    • 海關會參考「完全相同」貨物的交易價格，並就數量、運費等差異做合理調整。
一句話總結
  • 無法用實際交易價格估稅時，「同樣貨物法」是完稅價格核估之「第一順位替代方法」：
    • 海關參考「生產國、物理特性、品質及商譽完全相同」的貨物之交易價格， 並就數量、運費等差異做合理調整。
使用前提與核估方法
使用前提：未能依交易價格核定
  • 例如：
    • 納稅義務人未能提供交易價格資料。
    • 交易雙方有特殊關係（排除事由）價格不得採用。
    • 海關對交易價格有合理懷疑且納稅義務人未能釋明
    • 應計入完稅價格之費用無法依客觀資料計量
核估方法：參照同樣貨物之交易價格
  • 同樣貨物之交易價格須為「銷售至中華民國」之價格，即該同樣貨物須已實際進口至我國。
  • 交易時間點為系爭貨物「出口時或出口前、後」， 即同樣貨物之交易時間須與系爭貨物之出口時間相近，以反映合理之價格水準。
合理調整之權限與義務
  • 海關參照「同樣貨物」之交易價格核定時， 應就交易型態、數量及運費等影響價格之因素作合理調整。
  • 調整須有「客觀及可計量之資料」為依據，不得恣意為之。
  • 調整因素包括但不限於：
    • 交易型態（如批發與零售之差異）
    • 數量（大量與小量之差異）、
    • 運費（不同運輸方式或距離之費用差異）
同樣貨物之定義
同樣貨物： 指其生產國別、物理特性、品質及商譽等均與該進口貨物相同者
  • 同樣貨物須同時符合以下要件：
    1. 生產國別相同：須為同一國家生產。
    2. 物理特性相同：如材質、規格、尺寸、功能等物理屬性相同。
    3. 品質相同：如等級、純度、耐用性等品質水準相同。
    4. 商譽相同：如品牌、商標、市場知名度等商業信譽相同。
  • 此為「完全相同」之貨物，標準極為嚴格，於實務上較為罕見。
舉個例子
例1：以同樣貨物之交易價格核估
  • A公司自日本進口一批「某型號數位相機」。
  • 因A公司與賣方有特殊關係且價格偏低，海關認定無法依第29條核定。
  • 海關查得B公司於前一個月自日本進口「相同型號、相同產地、相同品質、相同品牌」之數位相機， 其交易價格為每台新臺幣10,000元。
  • 海關即以該價格為基礎，並考量A公司進口數量較B公司為多，合理調整價格為每台新臺幣9,500元。
  • → 符合第31條（以同樣貨物之交易價格核定，並就數量差異為合理調整）。
例2：同樣貨物之定義
  • C公司自中國進口一批「某品牌手機」，海關未能以交易價格核定，擬依本條參照同樣貨物之價格。
  • 惟海關查得市場上僅有「同品牌但不同型號」之手機，或「同型號但產地為越南」之手機，均不符合「同樣貨物」之定義。
  • → 不符合第31條（同樣貨物須生產國別、物理特性、品質及商譽均相同，不同型號或不同產地均非同樣貨物）。
例3：合理調整交易型態
  • D公司自德國進口一批「汽車零組件」。
  • 海關查得同樣貨物前一個月之交易價格為每件新臺幣500元，惟該交易為「零售」交易，而D公司係「大量批發」進口。
  • 海關考量交易型態及數量之差異，將價格合理調整為每件新臺幣420元。
  • → 符合第31條（應就交易型態及數量等影響價格之因素作合理調整）。
相關規定
  • 第29條
    • 第1項：進口貨物完稅價格無法用交易價格核估時，改用「同樣貨物」的交易價格。
    • 第2項：「同樣貨物」生產國別、物理特性、品質、商譽都要相同。
記憶口訣
  • 交易價格不能用，改用同樣貨物價。
  • 同樣貨物四要件，產地特性品質譽。
  • 出口前後皆可參，交易數量運費調。
