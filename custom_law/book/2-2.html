2-2 通關程序-完稅價格

完稅價格之核估原則與交易價格制度

  • 進口貨物如果是按價格來課關稅：
    • 其「完稅價格」原則上就是買賣雙方「實際交易的價格」。
    • 「實際交易的價格」是指：從出口國賣到台灣來，買方已經付或應該付的全部價款。
  • 不過，發票上的價格通常不會包含所有成本。所以法律規定，下面這些費用如果沒有算進去，必須「加」到交易價格裡面：
    1. 買方付的佣金、包裝費。
    2. 買方免費或打折提供給賣方用於生產的原料、工具、設計等。
    3. 權利金。
    4. 運到台灣港口的運費、裝卸費和保險費等。
  • 計入交易價格之費用（如佣金、權利金、保險費等）須有「客觀、可計量」之資料為依據。
    • 如果沒有「客觀、可計量」的資料，則應放棄交易價格方法，而改用其他方法來估價。
  • 如果海關對你提供的交易文件有「合理懷疑」，你無法說明清楚：
    • 那海關就可以不用交易價格來核估完稅價格，而改用其他方法來估價。
簡單說：
  • 進口貨物的關稅稅基，原則上就是買賣雙方實際交易的價格，再加上特定應計入的費用。
  • 若海關對文件真實性有合理懷疑，可改用其他方法核估。
完稅價格以交易價格為計算根據
  • 「交易價格」為核估完稅價格之首要基準。
  • 完稅價格為計算關稅之「稅基」，其計算公式為：完稅價格 × 關稅稅率 = 應納關稅額。
  • 若無法依交易價格核估，則應依序適用：
    1. 同樣貨物之交易價格（第31條）
    2. 類似貨物之交易價格（第32條）
    3. 國內銷售價格（第33條）
    4. 計算價格（第34條）
    5. 合理方法（第35條）
交易價格之計算
交易價格：指進口貨物由輸出國銷售至我國實付或應付之價格
  • 「實付或應付之價格」：指買方為進口貨物已付或應付予賣方之全部價款，不以實際支付為限 。
應計入交易價格之費用
  • 以下費用應計入交易價格之費用。此等費用雖未直接反映於發票價格中，但實際上為買方取得該進口貨物所付出之成本，故應計入完稅價格。
    1. 買方付的佣金、包裝費。
    2. 買方免費或打折提供給賣方用於生產的原料、工具、設計等。
    3. 權利金。
    4. 運到台灣港口的運費、裝卸費和保險費等。
客觀可計量原則
  • 計入交易價格之費用（如佣金、權利金、保險費等）須有「客觀、可計量」之資料為依據。
  • 如果沒有「客觀、可計量」的資料，則應放棄交易價格方法，改依第31條至第35條之次順位方法核估。
估價審查權與納稅義務人之協力義務
  • 納稅義務人有義務提出完整、真實的交易文件。
  • 若納稅義務人未能提供充分之交易文件或說明，或海關對其說明仍有「合理懷疑」，則「視為無法按交易價格核估」。
  • 此為海關得依其他方法核估完稅價格之「程序要件」。
舉個例子
例1：以交易價格核估
  • A公司自日本進口汽車一批，買賣合約載明每輛CIF基隆港價格為新臺幣100萬元。
  • 該價格已包含運費、保險費及賣方之利潤，且無其他應加計之費用。
  • 海關即以每輛新臺幣100萬元作為完稅價格，乘以適用稅率課徵關稅。
  • → 符合第29條第1項及第2項（完稅價格以交易價格為計算根據）。
例2：加計權利金
  • B公司自美國進口電腦軟體，支付賣方軟體費用新臺幣500萬元，另依合約支付權利金新臺幣50萬元。
  • 該權利金為取得軟體使用權之條件，與進口貨物有關且未計入原交易價格。
  • 海關將該權利金50萬元計入完稅價格。
  • → 符合第29條第3項第3款（權利金應計入完稅價格）。
例3：合理懷疑而無法核估
  • C公司自中國進口電子零組件，申報交易價格為每件新臺幣10元。
  • 海關查核發現，該同類貨物之國際市場行情約為每件新臺幣50元，且C公司無法提出合理說明及完整交易文件。
  • 海關合理懷疑其交易價格之真實性，爰認定無法依本條核估，改依第35條合理方法核估完稅價格。
  • → 符合第29條第5項（海關對交易文件真實性有合理懷疑，納稅義務人未提出說明者，視為無法按本條核估）。
相關規定
  • 第29條
    • 第1項：從價課徵關稅之進口貨物，其完稅價格以該進口貨物之交易價格作為計算根據。
    • 第2項：交易價格，指進口貨物由輸出國銷售至中華民國實付或應付之價格。
    • 第3項：列舉應計入交易價格之費用。
    • 第4項：計入完稅價格之費用，應根據客觀及可計量之資料。無客觀及可計量之資料者，視為無法按本條規定核估其完稅價格。
    • 第5項：海關對發票或交易文件有合理懷疑，得視為無法按本條規定核估其完稅價格。
記憶口訣
  • 交易價格為基礎，實付應付都算數。
  • 六項費用要加計，佣金包裝運保費，權利金與轉售利，買方提供物品勞。
  • 客觀計量要具體， 無則無法用此法。
  • 海關懷疑可拒絕，另行核估完稅價。

交易價格之排除適用事由與特殊關係之認定

  • 不是所有的「交易價格」都可以拿來當作關稅的稅基。 如果有以下四種情況，海關就不能用這個交易價格來算關稅：
    1. 買方對貨物的使用或處分受到限制（除非是我國法律規定的限制、轉售地區的限制，或該限制對價格影響不大）
    2. 這個交易附帶了條件，導致無法算出這批貨物真正的價格
    3. 買方轉賣貨物後要把部分收益分給賣方，但這筆錢到底有多少不清楚
    4. 買賣雙方有「特殊關係」，而且因為這個關係影響了價格
  • 至於什麼叫「特殊關係」，法律也明確列出八種情況，包括：
    • 一方是另一方的董事、經理人、持有對方5%以上股份、控制關係、僱傭關係、合夥關係
    • 或是配偶、三親等以內親屬等
簡單說：
  • 當交易價格被操控、受限或附帶不明條件時，海關不能拿它來課稅。
  • 買賣雙方有特殊關係時，除非能證明價格不受影響，否則也不能用。
一句話總結
  • 當進口貨物之交易價格受限制、附條件、收益不明或受特殊關係影響時：
    • 不得作為完稅價格之計算根據，應改用其他方法核估。
為什麼要有這條規定？
  • 確保完稅價格之真實性與正確性：排除受限制、附條件、收益不明或受特殊關係影響之交易價格，確保完稅價格反映貨物之真實價值。
  • 遵循WTO關稅估價協定之國際規範：我國為WTO會員，關稅估價制度須與該協定一致，本條之規範內容與該協定第1條及相關註釋完全接軌。
  • 防止藉由特殊關係規避關稅：關係企業或關聯企業間之交易，可能透過人為操縱價格以降低關稅負擔，本條透過特殊關係之認定與價格影響之審查，防止此類規避行為。
  • 建立明確之法律要件：本條將不得採用交易價格之事由及特殊關係之具體態樣予以明文化，使納稅義務人與海關均有明確之法律依據可資遵循。
舉個例子
例1：使用限制致價格不採用
  • A公司向國外供應商購買一批機械設備，合約約定該設備僅得於A公司之特定廠房內使用，不得移轉或出租予第三人。
  • 海關認定此使用限制影響價格之正常決定，爰依本條第一款規定，不採用該交易價格為完稅價格。
  • → 符合第30條第1項第1款（買方對貨物使用受有限制，且非屬我國法令限制、轉售地區限制或對價格無重大影響）。
例2：附條件交易
  • B公司向國外供應商購買一批化學原料，合約約定B公司須同時向該供應商購買另一批滯銷庫存品，始得以該價格購入原料。
  • 海關認定該交易附有條件，致原料價格無法與庫存品價格分離核定。
  • → 符合第30條第1項第2款（交易附有條件，致價格無法核定）。
例3：特殊關係且影響價格
  • C公司為台灣進口商，其母公司持有C公司百分之百之股份。
  • C公司向母公司進口一批電子零組件，申報價格僅為國際市場行情之60%。
  • 海關認定雙方為特殊關係（持股關係），且該關係致價格偏低，爰不採用該交易價格。
  • → 符合第30條第1項第4款及第2項第4款（買賣雙方為特殊關係且致影響交易價格，交易價格不得採用）

同樣貨物之交易價格核估法

  • 如果進口貨物沒有辦法用第29條的「實際交易價格」來估關稅（例如價格不透明、有特殊關係、海關有合理懷疑等）時：
    • 海關可以用「同樣貨物」的交易價格來核估。
  • 所謂「同樣貨物」，是指生產國、物理特性、品質和商譽都完全一樣的貨物。
  • 不過，即使是同樣貨物，交易條件也可能不同（例如買的數量不一樣、運費不一樣）：
    • 海關在核估時，可以針對這些影響價格的因素做合理的調整。
簡單說：
  • 無法用實際交易價格估稅時：
    • 海關會參考「完全相同」貨物的交易價格，並就數量、運費等差異做合理調整。
一句話總結
  • 無法用實際交易價格估稅時，「同樣貨物法」是完稅價格核估之「第一順位替代方法」：
    • 海關參考「生產國、物理特性、品質及商譽完全相同」的貨物之交易價格， 並就數量、運費等差異做合理調整。
使用前提與核估方法
使用前提：未能依交易價格核定
  • 例如：
    • 納稅義務人未能提供交易價格資料。
    • 交易雙方有特殊關係（排除事由）價格不得採用。
    • 海關對交易價格有合理懷疑且納稅義務人未能釋明
    • 應計入完稅價格之費用無法依客觀資料計量
核估方法：參照同樣貨物之交易價格
  • 同樣貨物之交易價格須為「銷售至中華民國」之價格，即該同樣貨物須已實際進口至我國。
    • 實務上，從關務系統進口歷史資料中查找。
  • 交易時間點為系爭貨物「出口日前後30日內」，以反映合理之價格水準。
  • 有多筆同樣貨物交易價格可選時，依下列順序選定之：
    1. 同一廠商生產者
    2. 交易型態相同及交易數量相當者
    3. 較格較低者
合理調整之權限與義務
  • 海關參照「同樣貨物」之交易價格核定時， 應就交易型態、數量及運費等影響價格之因素作合理調整。
  • 調整須有「客觀及可計量之資料」為依據，不得恣意為之。
  • 調整因素包括但不限於：
    • 交易型態（如批發與零售之差異）
    • 數量（大量與小量之差異）、
    • 運費（不同運輸方式或距離之費用差異）
同樣貨物之定義
同樣貨物：指其生產國別、物理特性、品質及商譽等均與該進口貨物相同者
  • 同樣貨物須同時符合以下要件：
    1. 生產國別相同：須為同一國家生產。
    2. 物理特性相同：如材質、規格、尺寸、功能等物理屬性相同。
    3. 品質相同：如等級、純度、耐用性等品質水準相同。
    4. 商譽相同：如品牌、商標、市場知名度等商業信譽相同。
  • 此為「完全相同」之貨物，標準極為嚴格，於實務上較為罕見。
舉個例子
例1：以同樣貨物之交易價格核估
  • A公司自日本進口一批「某型號數位相機」。
  • 因A公司與賣方有特殊關係且價格偏低，海關認定無法依第29條核定。
  • 海關查得B公司於前一個月自日本進口「相同型號、相同產地、相同品質、相同品牌」之數位相機， 其交易價格為每台新臺幣10,000元。
  • 海關即以該價格為基礎，並考量A公司進口數量較B公司為多，合理調整價格為每台新臺幣9,500元。
  • → 符合第31條（以同樣貨物之交易價格核定，並就數量差異為合理調整）。
例2：同樣貨物之定義
  • C公司自中國進口一批「某品牌手機」，海關未能以交易價格核定，擬依本條參照同樣貨物之價格。
  • 惟海關查得市場上僅有「同品牌但不同型號」之手機，或「同型號但產地為越南」之手機，均不符合「同樣貨物」之定義。
  • → 不符合第31條（同樣貨物須生產國別、物理特性、品質及商譽均相同，不同型號或不同產地均非同樣貨物）。
例3：合理調整交易型態
  • D公司自德國進口一批「汽車零組件」。
  • 海關查得同樣貨物前一個月之交易價格為每件新臺幣500元，惟該交易為「零售」交易，而D公司係「大量批發」進口。
  • 海關考量交易型態及數量之差異，將價格合理調整為每件新臺幣420元。
  • → 符合第31條（應就交易型態及數量等影響價格之因素作合理調整）。
相關規定
  • 第31條
    • 第1項：進口貨物完稅價格無法用交易價格核估時，改用「同樣貨物」的交易價格。
    • 第2項：「同樣貨物」生產國別、物理特性、品質、商譽都要相同。
記憶口訣
  • 交易價格不能用，改用同樣貨物價。
  • 同樣貨物四要件，產地特性品質譽。
  • 出口前後皆可參，交易數量運費調。

類似貨物之交易價格核估法

  • 如果進口貨物沒有辦法用「實際交易價格」來估稅，也找不到「完全相同」的貨物來比價：
    • 海關就可以改用「類似貨物」的交易價格來核估。
  • 所謂「類似貨物」，是指：
    • 雖然不是完全一樣，但生產國相同、功能相同、特性和材料相似，而且在市場上可以互相替代的貨物。
    • 舉例來說，不同廠牌但功能相同的筆記型電腦，就可以算是類似貨物。
  • 同樣地，海關在比價時，也要針對數量、運費等差異做合理的調整。
簡單說：
  • 找不到「完全相同」的貨物比價時：
    • 海關可改用「功能相同、可互相替代」的「類似貨物」交易價格來估稅。
一句話總結
    「類似貨物」是完稅價格核估的第二順位替代方法 ——
  • 找不到「完全相同」的貨物比價時：
    • 海關可改用「生產國相同、功能相同、材料相似且可互為替代」的「類似貨物」交易價格來估稅。
      • 並就數量、運費等差異作合理調整。
使用前提與核估方法
使用前提：無法依「交易價格」、「同樣貨物」核定完稅價格時
  • 例如：納稅義務人未能提供交易價格資料（無法認定交易價格）且同樣的貨物過去一年內無人進口（無同樣貨物價格可參考）。
核估方法：參照「類似貨物」之交易價格
  • 「類似貨物」之交易價格須為「銷售至中華民國」之價格，即該類似貨物須已實際進口至我國。
  • 交易時間點為系爭貨物「出口時或出口前、後」，須與系爭貨物之出口時間相近。
合理調整之權限與義務
  • 海關參照「類似貨物」之交易價格核定時， 應就交易型態、數量及運費等影響價格之因素作合理調整。
  • 調整須有「客觀及可計量之資料」為依據，不得恣意為之。
  • 調整因素包括但不限於：
    • 交易型態（如批發與零售之差異）
    • 數量（大量與小量之差異）、
    • 運費（不同運輸方式或距離之費用差異）
類似貨物之定義
類似貨物：與生產國別及功能相同、特性及組成之原材料相似、可互為替代
  • 「類似貨物」之法定定義，須符合以下要件：
    1. 生產國別相同：須與系爭貨物為同一國家生產。
    2. 功能相同：須具有相同之主要功能或用途。
    3. 特性及組成之原材料相似：物理特性（如強度、硬度、導電性等）及構成材料（如鋼鐵、塑膠、木材等）須相似。
    4. 交易上可互為替代：在市場上可互相替換使用，例如不同廠牌但功能相同之電腦、不同型號但用途相同之工具機。
  • 此定義較「同樣貨物」為寬鬆，但仍須具備相當程度之相似性。

國內銷售價格核估法

  • 如果進口貨物沒辦法用「實際交易價格」、「同樣貨物」、「類似貨物」來估稅：
    • 海關可以改用「國內銷售價格」來推估。
  • 所謂「國內銷售價格」，是指這批貨（或同款、類似貨）在進口前後：
    • 於國內「第一次賣出」時，賣給「沒有特殊關係」的買方，且「銷售數量最多」的那個單位價格。
      • 然後再扣掉三類費用：
        1. 國內銷售的利潤、費用和佣金
        2. 進口時繳的關稅和其他稅
        3. 進口後發生的運費、保險費等
        剩下的金額就是完稅價格。
  • 如果進口時前後都沒有銷售紀錄，可以用進口後「90天內」的銷售紀錄來算。
  • 如果貨物是加工後才賣的，還要把加工增加的價值也扣掉。

  • 但納稅義務人得請求「變更順序」，即優先適用「計算價格法」。
國內銷售價格之定義與計算
國內銷售價格：指該進口貨物、同樣或類似貨物，於該進口貨物進口時或進口前、後，在國內按其輸入原狀於第一手交易階段，售予無特殊關係者最大銷售數量之單位價格核計後，扣減下列費用計算者
  • 國內銷售價格之「定義與計算框架」：
    • 該進口貨物、同樣或類似貨物 ：指系爭貨物本身，或與其相同或類似之貨物。
    • 進口時或進口前、後 ：按照細則規範是系爭貨物進口日「前後30日內」。
    • 輸入原狀 ：貨物未經加工，以進口時的狀態銷售。
    • 第一手交易階段 ：貨物第一次在國內銷售（進口商賣給國內買家），不是後續轉手。
    • 無特殊關係者 ：買賣雙方無關係人交易（如母子公司、親屬等），避免人為操縱價格。
    • 最大銷售數量之單位價格 ：以賣得最多件的價格為基準（不是平均價格）。
扣減項目：發生在我國的稅費及利潤
  1. 利潤、費用或佣金 ：銷售該貨物之一般利潤、管銷費用及支付之佣金。
  2. 關稅及其他稅捐 ：進口時繳納的關稅、營業稅等。
  3. 進口後運費、保險費 ：貨物進口後在國內運輸、倉儲等費用。
無即時國內銷售之處理
  • 適用前提：系爭貨物進口日「前後30日內」查無該進口貨物、同樣或類似貨物在國內銷售者。
  • 放寬標準：進口後90天內。
    • 原標準：系爭貨物進口日「前後30日內」。
    • 放寬後標準：系爭貨物進口之翌日起90日內。
「非按原狀銷售時」之特別規定
  • 當貨物進口後，不是原狀賣出，而是經過了加工、組裝、改裝、分裝等處理（也就是有「輸入後加工行為」）：
    • 此時國內售價已非單純貨物本身的價格，而是包含了「加工增值」。
    為了正確回推完稅價格，必須：
    • 把加工創造的附加價值也扣除，避免把國內加工後的利潤也誤算為進口貨物的價值。
  • 適用前提：沒有「按輸入原狀銷售」的樣本可採時。
    • 許多貨物必須加工才有銷售的市場價值。例如進口零組件，在國內組裝後銷售。
  • 啟動方式：依納稅義務人之申請。
  • 核價方式：除了一般扣除項目（利潤、費用、稅捐、運費）外，還要再扣掉加工所創造的價值。
例子：進口布料 → 製成成衣後銷售
  • 台灣B公司從義大利進口一批高級羊毛布料，因無法用交易價格、同樣貨物、類似貨物核估完稅價格，海關擬改用「國內銷售價格法」。 但這批布料不是直接原狀出售，而是在台灣加工製成西裝後才銷售。
    項目 金額
    加工後西裝在國內銷售價格（最大銷售數量之單位價格） 15,000元
    國內加工增值（含工資、管銷、利潤等） 8,000元
    國內銷售利潤及費用 1,500元

    • 加工後銷售扣減：完稅價格 ＝ 15,000元 － 8,000元（加工增值） － 1,500元 － 800元 － 200元 ＝ 4,500元
      • 關鍵： 多扣除了「加工增值」（8,000元），才是布料進口時的正確完稅價格

  • 海關依D公司申請，以加工後木材之國內銷售價格每立方公尺新臺幣10,000元為基礎， 扣除加工後之增值（每立方公尺3,000元）及第三項所列費用（利潤、稅費、運費共2,000元）， 計算出完稅價格為每立方公尺新臺幣5,000元。

計算價格核估法

  • 如果進口貨物沒辦法用「實際交易價格」、「同樣貨物」、「類似貨物」、「銷售價格」來估稅：
    • 海關可以改用「計算價格」來推估。
  • 所謂「計算價格」，就是把三類費用「全部加起來」：
    1. 生產成本（材料、人工、工廠費用等）
    2. 出口國銷售此類貨物到台灣的正常利潤和一般費用
    3. 運到台灣港口的運費、裝卸費和保險費
    這三項相加的總和，就是完稅價格。
  • 不過，這種方法需要知道貨物的生產成本，而這通常只有賣方（製造商）才清楚。
    • 如果賣方不願意提供生產成本，海關就無法用這個方法。
簡單說：
  • 所有比價方法都行不通時：
    • 海關就把「生產成本＋利潤費用＋運費保險費」全部加起來當作完稅價格。
一句話總結
    「計算價格」是完稅價格核估的第四順位替代方法 ——
  • 所有比價方法都行不通時，海關將「生產成本＋正常利潤費用＋運費保險費」全部加總，作為完稅價格。
  • 納稅義務人得請求優先於國內銷售價格法適用。
使用前提與核估方法
使用前提：無法依「交易價格」、「同樣貨物」、「類似貨物」、「銷售價格」核定完稅價格時
  • 若納稅義務人「請求變更順序」，則「計算價格」得優先於「銷售價格」適用。
核估方法：三類項目之「加總」
  1. 生產成本及費用 ：在出口國生產貨物的直接成本（原料、工資、製造費用等）。
  2. 正常利潤與一般費用 ：由輸出國生產銷售至我國的該貨物、同級或同類別貨物之正常利潤與一般費用。
  3. 運費、裝卸費、搬運費及保險費 ：貨物從輸出國運至我國口岸之運輸及保險費用。
核估邏輯
  • 生產成本 ＋ 費用 ＋ 利潤 ＋ 運費保險費
  • 與前面幾種方法相反——前面是「從售價倒推」，這裡是「從成本正加」。
舉個例子
例1：以計算價格核估
  • A公司自德國進口一批「特殊規格機械零件」，因該零件屬客製化產品， 市場上無交易價格、無同樣或類似貨物可供比價，亦無國內銷售紀錄。

  • A公司提供德國製造商之生產成本資料（材料費新臺幣10萬元、人工費5萬元、工廠費用3萬元）， 經海關查核屬實。
  • 另查得同類貨物出口至我國之正常利潤及一般費用為生產成本之20%（即3.6萬元）， 運費及保險費為1萬元。海關將上述各項加總，計算出完稅價格為新臺幣22.6萬元（10+5+3+3.6+1=22.6）。
  • → 符合第34條（以計算價格核定完稅價格）。
例2：納稅義務人請求變更順序——優先適用計算價格
  • B公司進口一批「化學品」，海關原應依第33條（國內銷售價格）核估，但國內銷售價格因市場波動而偏高。
  • B公司主張計算價格對其較有利，依第33條第2項請求海關變更適用順序，改依第34條計算價格核估。海關審查後同意變更。
  • → 符合第33條第2項及第34條（納稅義務人得請求變更本條與第33條之適用順序）。
例3：無法提供生產成本資料——無法適用計算價格
  • C公司自日本進口一批「精密儀器」，海關無法依前四條核估，擬以計算價格核定。
  • 惟C公司無法提供日本製造商之生產成本資料（製造商拒絕提供），海關亦無其他管道取得相關成本資訊。
  • → 無法依第34條核定（生產成本及費用為計算價格之必要構成項目，無法取得即無法適用本條，應改依第35條合理方法核估）。
相關規定
  • 第34條
    • 第1項：進口貨物完稅價格無法用交易價格、同樣貨物、類似貨物、銷售價格核估時，改用「計算價格」核定之。
    • 第2項：計算價格 = 生產成本 ＋ 費用 ＋ 利潤 ＋ 運費保險費
記憶口訣
  • 交易同樣類似都無用，國內銷售也算不出，最後手段計算價。
  • 成本利潤運保費，逐項加總核估價，完稅價格就出爐。

合理方法核估法

  • 如果進口貨物沒有辦法用前面五種方法（交易價格、同樣貨物、類似貨物、銷售價格、計算價格）來核定完稅價格：
    • 海關可以「根據查到的資料，用合理的方法」來核定。
    換句話說，這是萬不得已的最後一招。
  • 海關不能隨便亂估，必須有客觀的資料為基礎。
    • 使用的方法必須合理——不能規定一個「最低價格」或「隨便喊價」。
    • 舉例來說，海關可能參考國際市場行情、產業公會提供的價格資料，或是類似貨物在其他國家的交易價格，然後做合理的調整。
簡單說：
  • 當前面五種估價方法都用不上時：
    • 海關可根據查到的客觀資料，用合理的方法來核定完稅價格 ——這是估價制度的最後防線。
一句話總結
    「合理方法」是完稅價格核估的最後防線 ——
  • 當前面五種估價方法都用不上時，海關可根據查到的客觀資料，用合理的方法來核定完稅價格。
    • 但不得以最低限價或任意估價為之。
使用前提與核估方法
使用前提：無法依「交易價格」、「同樣貨物」、「類似貨物」、「銷售價格」、「計算價格」核定完稅價格時
  • 例如缺乏必要資料、無法取得生產成本資訊、無國內銷售紀錄等原因，致無法以前五條方法核定。
核估方法：依據查得之資料，以合理方法核定之
  • 依據查得之資料 ：海關須有「客觀之查得資料」為基礎，不得憑空臆測或恣意決定。
    • 例如：納稅義務人提供之補充資料、同類貨物之國際市場行情、產業公會之價格資訊、或其他公開可得之價格資料。
  • 以合理方法核定 ：海關得依個案情況，選擇適當之合理方法。該方法須：
    • 與WTO關稅估價協定之一般原則相容。
    • 以前五條估價方法之精神為基礎，作必要之彈性調整。
    • 不得以「最低限價」或「任意估價」為之。
    • 須有客觀及可驗證之依據。
合理方法實務
  • 參考公開市場價格：國際市場行情、同類貨物公開報價。
  • 參考其他國家的估價資料：該貨物在其他國家的完稅價格。
  • 參考國內其他進口商的價格：同業進口同類貨物的申報價格。
  • 調整已有資料：對現有資料作合理調整（如品質差異、數量差異）。
  • 其他客觀可計量之資料：任何與該貨物價值相關的客觀資料。
不得使用：
  • 出口國之國內銷售價格。
  • 最高或最低價格。
  • 任意或虛構的價格。
舉個例子
例1：以合理方法核估
  • A公司自某國進口一批「特殊客製化機械設備」，該設備屬獨一無二之設計，市場上無交易價格、無同樣或類似貨物、 無國內銷售紀錄，亦無法取得生產成本資料。
  • 海關無法依第29、31、32、33、34條核定完稅價格。
  • 海關查得國際上類似功能設備之市場行情資料，並參考設備之重量、複雜度、材料成本等因素，以合理方法核定完稅價格為新臺幣500萬元。
  • → 符合第35條（海關依據查得之資料，以合理方法核定）。
例2：不得以最低限價核定
  • B公司進口一批「電子零組件」，海關因無法以前五條方法核定，逕行以「進口最低限價表」之價格作為完稅價格。
  • 該限價表係海關內部參考資料，未經公開且未考量個案差異。
  • → 不符合第35條（依WTO關稅估價協定，合理方法不得以「最低限價」為基礎；海關應有具體查得之資料，並說明合理調整之依據）。
例3：以產業公會價格資訊為基礎
  • C公司進口一批「化學原料」，因缺乏比價對象及生產成本資料，無法依前五條核定。
  • 海關查得國內同業公會定期發布之「國際化學原料行情參考價格」，並參考該批貨物之純度、數量及交貨條件等因素， 以合理方法核定完稅價格。
  • → 符合第35條（海關依據查得之客觀資料，以合理方法核定）。
相關規定
  • 第35條 ：進口貨物完稅價格無法用交易價格、同樣貨物、類似貨物、銷售價格、計算價格核估時，始得改用「合理方法」核定之。
記憶口訣
  • 六種方法依序用，交易同樣與類似，國內銷售計算價，最後手段合理法。
  • 海關查得資料核，不得虛構或臆測。

完稅價格核估方法 — 總整理

  • 六種估價方法依序適用：交易價格 → 同樣貨物 → 類似貨物 → 國內銷售價格 → 計算價格 → 合理方法。
    • 前者不行才換後者，順序不能亂跳。
六種估價方法
順位 方法 說明 口訣
① 交易價格 實付或應付價格（最優先） 自己付多少算多少
② 同樣貨物價格 完全相同貨物的交易價格 找一模一樣的
③ 類似貨物價格 可互為替代貨物的交易價格 找差不多的
④ 國內銷售價格 國內售價 ➜ 扣減費用（倒推） 從賣價倒推
⑤ 計算價格 成本 ＋ 利潤 ＋ 運費（正加） 從成本正加
⑥ 合理方法 海關綜合查得資料核定 最後手段
核心要點
① 交易價格
  • 定義：貨物由輸出國銷售至我國，買方實付或應付之全部價款。
    • 包含：佣金、包裝費、權利金、輸出國至我國的運費、保險費等。
  • 客觀可計量原則：計入交易價格之費用須有「客觀、可計量」之資料為依據。
  • 納稅義務人應舉證：應提出完整、真實的交易文件。
    • 海關質疑真實性時，應清楚說明。
  • 海關審查權：可拒絕使用交易價格核估。
    • 可質疑交易文件真實性，要求納稅義務人說明或補件。
    • 納稅義務人未能提供充分之交易文件或說明，或海關對其說明仍有「合理懷疑」，則「視為無法按交易價格核估」。
② 同樣貨物價格
  • 定義：生產國、物理特性、品質及商譽等均與該進口貨物相同者（完全相同）。
  • 出口時間相近：與系爭貨物出口時間要盡量接近。
  • 合理調整：應就交易型態、數量及運費等影響價格之因素作合理調整。
    • 如批發與零售之差異、不同運輸方式或距離之費用差異。
③ 類似貨物價格
  • 定義：具備以下3項：
    1. 生產國相同、功能相同。
    2. 特性相似、原材料相似。
    3. 交易上可互為替代。
  • 出口時間相近：與系爭貨物出口時間要盡量接近。
  • 合理調整：應就交易型態、數量及運費等影響價格之因素作合理調整。
    • 如批發與零售之差異、不同運輸方式或距離之費用差異。
④ 國內銷售價格
  • 納稅義務人得請求「變更順序」，即改為優先適用「計算價格法」。
取樣規則：
  • 可採納貨物：該進口貨物、同樣或類似貨物。
  • 出口時間相近：與系爭貨物出口時間要盡量接近。
  • 按輸入原狀交易：貨物未經加工，以進口時的狀態銷售。
  • 第一手交易：貨物第一次在國內銷售（進口商賣給國內買家），不是後續轉手。
  • 無特殊關係：買賣雙方非關係人交易（如母子公司、親屬等），避免人為操縱價格。
  • 最大銷售數量之單位價格：以賣得最多件的價格為基準（不是平均價格）。
扣減項目：
  1. 利潤、費用或佣金。
  2. 關稅及其他稅捐。
  3. 進口後運費、保險費。
特別規定：
  • 放寬取樣標準至進口後90天內：
    • 適用前提：「進口時或進口前、後」查無該進口貨物、同樣或類似貨物在國內銷售者。
    • 原標準：進口時或進口前、後（與系爭貨物進口時間相近）。
    • 放寬後標準：系爭貨物進口之翌日起90日內。
  • 可採納「非按原狀銷售」價格。然須扣除「加工後之增值」：
    • 適用前提：沒有「按輸入原狀銷售」的樣本可採時。
    • 啟動方式：依納稅義務人之申請。
    • 核價方式：除了一般扣除項目（利潤、費用、稅捐、運費）外，還要再扣掉加工所創造的價值。
⑤ 計算價格
  • 若納稅義務人「請求變更順序」，則「計算價格」得優先於「銷售價格」適用。
  • 核估方法：三類項目之「加總」：
    1. 生產成本及費用 ：原料、工資、製造費用等。
    2. 正常利潤與一般費用：由海關以客觀之行業資料或市場行情為依據認定。
    3. 運費、裝卸費、搬運費及保險費：貨物從輸出國運至我國口岸之運輸及保險費用。
  • 核估邏輯：從生產成本出發（生產成本 ＋ 費用 ＋ 利潤 ＋ 運費保險費）。
⑥ 合理方法
  • 使用前提：其他核價方法都行不通時（最後手段）。
  • 核估方法：依據查得之資料，以合理方法核定之。
原則：
  • 須有「客觀查得資料」為基礎，不得憑空臆測或恣意決定。
  • 以前五條估價方法之精神為基礎，作必要之彈性調整。

核定方法之說明請求權

  • 當海關核定完稅價格後，納稅義務人若對其核定方式有疑慮：
    • 可以書面請求海關說明其核定方法，而海關必須以書面答復。
簡單說：
  • 簡單說：納稅義務人有權問海關「這筆稅是怎麼算出來的」，海關必須書面回覆。
為什麼要有這條規定？
  • 貫徹程序正當性與透明性：確保納稅義務人知悉核定結果是如何形成的，避免行政機關黑箱作業。
  • 協助納稅義務人準備行政救濟：釐清核定之法律依據與事實基礎，便於納稅義務人評估是否提起復查及撰寫理由。

進口貨物估價之預先審核制度

  • 納稅義務人可以在貨物「進口之前」，先向財政部關務署（或其所屬各關）申請「估價預審」。
    • 請海關預先審核：這批貨物在計算完稅價格時，除了發票上的金額外， 還有沒有其他費用需要加進去（例如權利金、運費、保險費、買方提供給賣方的協助等）？
    • 海關必須書面答復審核結果。
  • 如果海關事後想要變更原來的預審結果，必須書面通知並說明理由。
    • 納稅義務人如果已經信賴原結果訂了契約並進行交易，且變更後會造成損失：
      • 可以申請延長適用原結果，最長可延長90天。
  • 如果納稅義務人不服預審結果，在貨物進口前還可以申請「覆審」。
  • 至於預審的申請程序、文件、期限等細節，則由財政部訂定《進口貨物估價預先審核實施辦法》來規範。
簡單說：
  • 進口前可先向海關申請估價預審，確認哪些費用要算進完稅價格。
  • 海關若變更見解，已簽約者可申請延長原結果適用期限，最長90天。
  • 不服預審結果可申請覆審。
申請程序
  • 申請人：納稅義務人或其代理人。
  • 申請時點：貨物進口前。
  • 受理機關：財政部關務署。
預審內容：實付或應付價格是否包含法定應加計費用
  • 實付或應付價格：指買方為購買進口貨物而直接或間接支付之全部價款。
  • 法定應加計費用：如佣金、權利金、運費、保險費、買方提供之協助等。
  • 例如：進口商有付一筆「設計費」，不確定是否要算進去，於是申請預審讓海關解答。
海關應以書面答復
  • 海關須以正式書面（含電子公文）答復預審結果，以利後續信賴保護及查核。
  • 答覆期限：45日內。必要時延長至90日。
  • 效力期間：預審結果自發文通知之日起3年有效。
海關變更原預審結果之程序
  • 適用情況：海關變更原預審結果（例如原預審結果錯誤）。
  • 程序要求：應敘明理由，以書面通知納稅義務人或其代理人。
信賴保護之延長機制
  • 適用前提：海關事後變更原預審結果。
  • 要件：以下兩要件缺一不可，且納稅義務人須「提出證據」證明：
    1. 已訂定契約並據以進行交易。
    2. 適用變更後結果將導致損失。
  • 延長機制：納稅義務人得申請延長適用原預審結果，最多延長90天。
覆審救濟程序
  • 適用情況：納稅義務人不服海關之預審結果。
  • 申請主體：納稅義務人或其代理人。
  • 申請時點：貨物進口前。
  • 受理機關：向財政部關務署申請覆審。
舉個例子
例1：申請估價預審
  • A公司擬自日本進口一批機械設備，合約中包含權利金條款，A公司不確定該權利金是否應計入完稅價格。
  • A公司於貨物進口前，依規定格式填具申請書並檢附合約、權利金計算方式等文件， 向財政部關務署基隆關申請估價預審（該業務已委任基隆關辦理）。
  • 海關審查後以書面答復，確認該權利金依第29條第3項第3款規定應計入完稅價格。
  • → 符合第36-1條第1項（納稅義務人得於貨物進口前申請估價預審）。
例2：信賴保護——變更預審結果之延長適用
  • B公司依海關之預審結果，認定某項費用無須計入完稅價格，並據以簽訂長期進口契約。
  • 嗣後海關變更預審結果，認定該費用應予計入，並以書面通知B公司。
  • B公司收到通知後，提出已簽訂之契約及相關交易證明，向海關申請延長原預審結果之適用。
  • 海關核准延長90天，使B公司得於此期間內依原結果完成已訂定之交易。
  • → 符合第36-1條第2項（納稅義務人得申請延長原預審結果之適用，最長90日）。
例3：不服預審結果之覆審
  • C公司對海關之估價預審結果不服，認為海關不應將某項協助費用計入完稅價格。
  • C公司於貨物進口前，向財政部關務署申請覆審。
  • 財政部關務署重新審查後，以書面通知C公司覆審結果。
  • → 符合第36-1條第3項（納稅義務人得於貨物進口前申請覆審）。

  • 關務署應以書面通知申請人並敘明變更理由。

運往國外修理、裝配或加工貨物復運進口之完稅價格核估

  • 如果貨物先出口到國外去修理、組裝或加工，然後再運回來：
    • 關稅的計算方式跟一般進口不一樣：只針對國外新增的費用或價值課稅。
      • 如果只是修理或組裝，就只對「修理費或組裝費」課稅。
      • 如果是加工，就只對「加工後增加的價值」課稅。
  • 但這種優惠有時間限制：
    • 貨物必須在出口放行的隔天起一年內復運進口。
    如果因為特殊原因需要更長時間：
    • 可以在一年到期「之前」以書面向海關申請延長，最多再延六個月。
  • 如果超過期限才運回來，就不能享受這種優惠，必須按貨物的全額價值課徵關稅。
簡單說：
  • 出口修理或加工後復運進口：
    • 只針對修理費或加工增值課稅。
    • 須在一年內復運進口（得延長六個月），逾期全額課稅。
詳情解析
適用情況：運往國外修理、裝配或加工之貨物，復運進口者
  • 修理：貨物因損壞或故障運往國外修復。
  • 裝配：貨物運往國外進行組裝作業（如機械之組合）。
  • 加工：貨物運往國外進行生產、製造、變更形狀等作業，使貨物產生實質轉變或附加價值。
核估原則：僅就新增價值課稅
  • 修理、裝配：完稅價格 = 修理或裝配所需之費用
  • 加工：完稅價格 = 加工後復運進口時之完稅價格 – 原貨出口時同樣或類似貨物進口之完稅價格。
    • 僅就「加工所增加之價值」課稅。
期間限制：應於一年內復運進口（出口放行之翌日起算）
  • 確保貨物「暫時出口」性質。
得申請延長六個月
  • 須於期限屆滿前提出申請。
  • 須以書敘明理由。
逾期效果：全額課稅
  • 未於期限內復運進口，則不適用「復運進口」優惠。
  • 應就貨物之「全額價值」課徵關稅（視為一般進口）。
舉個例子
例1：修理費用核估
  • A公司將故障之發電機運往日本修理，修理費用為新臺幣20萬元。
  • 修理完成後於出口後8個月復運進口。海關以修理費用20萬元作為完稅價格。
  • → 符合第37條第1項第1款（修理貨物以修理費用為完稅價格，且於一年期限內復運進口）。
例2：加工增值核估
  • B公司將一批布料運往越南加工為成衣。
  • 復運進口時成衣之完稅價格為新臺幣100萬元，原布料出口時同樣或類似貨物進口之完稅價格為新臺幣40萬元。
  • 海關以差額60萬元作為完稅價格。
  • → 符合第37條第1項第2款（加工貨物以加工前後完稅價格之差額為完稅價格）。
例3：逾期復運進口全額課稅
  • C公司將機械設備運往德國加工，出口放行後14個月始復運進口，且未申請延長。
  • 海關認定已逾一年期限，不得適用本條優惠，應按該機械設備復運進口時之全額完稅價格（新臺幣500萬元）課徵關稅。
  • → 符合第37條第2項（逾期復運進口者，應全額課稅）。
相關規定
  • 第37條
    • 第1項：運往國外修理加工復運進口者，僅就新增價值課稅。
    • 第2項：應於一年內復運進口逾期。逾期者應全額課稅。
記憶口訣
  • 外貨復運進口時，修理加工分別算。
  • 修理僅課維修費，加工只課增值額。
  • 一年之內要回來，延長半年可申請。
  • 逾期復運全額課，優惠喪失要記牢。

租賃或負擔使用費貨物之完稅價格核估

  • 如果進口的機器設備不是買斷的，而是用租的或付使用費的方式引進：
    • 既然所有權沒有移轉，那麼完稅價格就不是按貨物的全額價值來算。
    • 而是按「租金或使用費」再加上運費和保險費來計算。
  • 不過，為了防止進口商故意把租金報很低來逃稅，法律規定：
    • 每年申報的租金「不得低於貨物全價的十分之一」。
    • 如果海關發現租金報得太低，可以重新核實調整。
  • 另外，除了按租金繳稅外，進口人還必須：
    • 就「全額關稅」和「租金關稅」的差額，繳交保證金或由銀行擔保
    ，確保國家稅收不會受損。
  • 最後，這種優惠不是所有租賃進口都能用，只限於以下情況之一：
    1. 因為專利或製程秘密「不能轉讓」的貨物。
    2. 經財政部專案核准的特殊情況。
    ，而且租期也由財政部核定。
簡單說：
  • 租賃進口的機器設備，關稅按租金計算，並須就差額提供擔保。
    • 僅限專利秘密或經財政部專案核准者適用。
    • 年租金不得低於全價的十分之一。
詳情解析
適用情況：貨物以「租賃」或「負擔使用費」之方式進口
  • 核心意義：貨物之「所有權未經轉讓」予進口人。即進口人僅取得使用收益權，未取得所有權。
  • 既然所有權沒有移轉，那麼完稅價格就不是按貨物的全額價值來算。
核估方式：根據租賃費或使用費加計運費及保險費估定之
  • 完稅價格 = 租賃費或使用費 + 運費 + 保險費。
  • 租賃費或使用費：進口人為使用該貨物而支付之對價。
  • 運費及保險費：指貨物自輸出國運至我國輸入口岸之運費及保險費。
限制條件
申報租金過低時，海關得核實估定之
  • 賦予海關「核實估定」之權限，防止納稅義務人以極低租金規避關稅。
  • 若納稅義務人申報之租金（或使用費）過低，海關得不採納申報金額，依調查所得之客觀資料（如同類貨物之市場租金行情）重新核實估定。
估定年租金不得低於貨價十分之一
  • 每年租金（或使用費）不得低於貨物本身完稅價格之「十分之一」（即10%）。
  • 此為租金之下限規定。
貨物以「不能轉讓」或財政部專案核准者為限
  • 不能轉讓：基於專利或製造上之秘密不能轉讓之貨物（如特殊配方之機器、專利製程設備）。
    • 意思是你想買都買不到，只能租。
  • 財政部專案核准：其他特殊原因，須經財政部「專案核准」。
差額保證金制度
保證金 = 全額關稅 - 租金關稅
  • 保證金目的：確保若貨物所有權嗣後移轉、或租賃期間屆滿貨物未復運出口時，國家仍得就該差額稅款獲得清償。
  • 保證金可由授信機構擔保替代。
  • 範例：A公司向國外租賃一部機械設備，租期3年：
    • 年租金：50萬
    • 運費：8萬，保險費：2萬
    • 關稅稅率：10%
    • 該設備本身完稅價格（全額）：1000萬
    計算：
    1. 已租金為基礎的關稅：
      • 完稅價格 ＝ 每年租金 ＋ 運保費攤提（10萬÷3年）＝ 50萬 ＋ 3.3萬 ＝ 53.3萬元
      • 關稅（每年）＝ 53.3萬 × 10% ＝ 5.33萬元
    2. 一般情況的關稅（全額） ＝ 1000萬 × 10% ＝ 100萬元
    3. 計算差額：全額關稅（總值）－ 租金關稅（總額）= 100萬 － 5.33萬 ＝ 94.67萬元
    4. 計算結果：A公司應提繳保證金94.67萬元
租賃或使用期限，由財政部核定之
  • 財政部保留最終核定權。
  • 租賃或使用期限由財政部依個案情況核定，非由進口人自行決定。
  • 期限之長短將影響租金總額之計算及保證金之金額。
舉個例子
例1：租賃進口
  • A公司自日本租賃一套專利製程設備，租期3年，每年租金新臺幣100萬元，運費及保險費共20萬元。
  • 該設備之完稅價格為1,000萬元。
  • 海關審查後認定每年租金100萬元未低於全價之十分之一（即100萬元）， 爰以每年租金100萬元加運保費20萬元，合計120萬元作為完稅價格。
  • → 符合第38條第1項（以租賃費加計運費及保險費為完稅價格，且租金符合下限規定）。
例2：申報偏低——海關核實估定
  • B公司自德國租賃一套加工設備，申報每年租金為新臺幣50萬元。
  • 惟該設備之完稅價格為1,200萬元（十分之一為120萬元）。
  • 海關調查同類設備之市場租金行情後，認定申報租金偏低， 爰依調查所得資料核實調整為每年120萬元，並據以計算完稅價格及關稅。
  • → 符合第38條第2項（申報偏低時，海關得核實估定，且估定之租金不得低於全價之十分之一）。
例3：差額擔保
  • C公司依第38條按租金繳納關稅，每年租金關稅為新臺幣10萬元（假設稅率10%，租金100萬元×10%）。
  • 該貨物全額完稅價格1,000萬元（所應繳之全額關稅為100萬元）。
  • C公司須就二者之差額90萬元（100萬-10萬）提供保證金或銀行擔保。
  • → 符合第38條第3項（應就差額提供保證金或擔保）。
相關規定
  • 第38條
    • 第1項：進口貨物所有權未經轉讓者，其完稅價格根據租賃費或使用費加計運費及保險費估定。
    • 第2項：申報之租賃費或使用費偏低時，海關得根據調查所得資料核實估定之，但不得低於貨物本身完稅價格之十分之一。
    • 第3項：進口人應就「全額關稅」與「租金關稅」間之差額，提供保證金或授信機構之擔保。
    • 第4項：適用租金關稅之貨物，以基於專利或製造上之秘密不能轉讓，或因特殊原因經財政部專案核准者為限。
    • 第5項：租賃或使用期限由財政部依個案情況核定。
記憶口訣
  • 租賃設備進口時，租金運保為稅基。
  • 租金不得過低廉，十分之一是底線。
  • 全額關稅與租金，差額提供保證金。
  • 專利秘密限適用，期限財政部核定。

外幣價格之折算與匯率公告

  • 如果進口貨物是用外幣（例如美金、日圓、歐元）計價：
    • 報關時必須換算成新臺幣才能計算關稅。
  • 至於用什麼匯率來換算，由財政部關務署參考銀行間的即期匯率，定期公告一個固定的匯率讓大家遵循。
    • 實務上，關務署每個月會公告三次，分別適用於上旬（1-10日）、中旬（11-20日）和下旬（21日至月底）報關的貨物。
    • 換句話說，同一個貨櫃的貨物，如果在不同旬報關，可能會適用不同的匯率。
簡單說：
  • 進口貨物用外幣報價時，海關依關務署定期公告的固定匯率折算為新臺幣來計算關稅。
    • 匯率每旬更新一次。
詳情解析
適用範圍：「從價課徵」、「外幣計價」
  • 「從價課徵」：以貨物之價格（完稅價格）乘以稅率來計算關稅之貨物。
  • 「外幣計價」：當進口貨物之交易價格是以外幣計價時，「必須」先將其折算為新臺幣，以作為完稅價格之基礎。
匯率由財政部關務署定期公告
  • 外幣折算之匯率，由財政部關務署參考外匯市場即期匯率，定期公告之。
  • 公告方式：「定期公告」。實務上為每月上、中、下旬各公告一次。
    • 掛牌部分：以報關前一旬中間日（每月5、15、25日，遇假日往前推算）台灣銀行掛牌公告即期匯率收盤價格為準。
    • 未掛牌部分：以經濟日報刊載紐約外幣兌換美元收盤價格，再以美元即期匯率折算。
舉個例子
例1：外幣折算
  • A公司自美國進口一批貨物，交易價格為10萬美元，於113年6月12日報關。
  • 該批貨物適用113年6月中旬之報關匯率（以6月5日台灣銀行即期賣出匯率為準，假設為1美元兌32.5新臺幣）。
  • 海關將10萬美元折算為新臺幣325萬元作為完稅價格之計算基礎。
  • → 符合第39條（外幣價格應折算為新臺幣，匯率依關務署公告之匯率為準）。
例2：不同旬報關適用不同匯率
  • B公司進口同一批貨物，若於6月8日（上旬）報關，適用6月上旬匯率； 若於6月12日（中旬）報關，適用6月中旬匯率；若於6月22日（下旬）報關，適用6月下旬匯率。
  • 因每旬匯率不同，同一批貨物之完稅價格可能因報關日期不同而有所差異。
  • → 符合第39條（外幣折算之匯率依報關日期所屬旬別而定）。
例3：進口與出口匯率不同
  • C公司進口貨物時，外幣折算適用「即期賣出匯率」；若為出口貨物申報離岸價格，則適用「即期買入匯率」。
  • → 符合第39條（進口與出口適用不同之即期匯率）。
相關規定
  • 第39條
    • 從價課徵關稅之進口貨物，其外幣價格應折算為新臺幣。
    • 匯率由財政部關務署參考外匯市場即期匯率，定期公告之。
記憶口訣
  • 外幣計價進口貨，須先折算新臺幣。
  • 匯率由關務署定，參考即期匯率訂。
  • 定期公告為基準，申報時適用為準。

整套機器拆散分裝進口之稅則號別適用

  • 如果進口的是「整套機器設備」，但因為體積太大或其他原因， 必須拆開分成好幾批、好幾個箱子運進來：
    • 進口人可以事先檢具機器圖說、裝箱單等文件向海關申報。
    海關審核確認這確實是同一套機器後：
    • 就可以按「整台機器」的稅則號別來課稅，而不是按各別零件的稅則分別課稅。
  • 這樣做的好處是，進口人不必擔心部分零件被課到比較高的稅率。
    • 但如果進口人事前沒有申報，或海關審核認為不是整套機器：
      • 那各批貨物就還是要「各自按各自的稅則」課稅。
簡單說：
  • 整套機器因太大必須分批進口時，只要事前向海關證明並經核明屬實：
    • 就可以按整套機器的稅則課稅，而不是按零件分別課稅。
詳情解析
適用情況：整套機器拆散、分裝報運進口者
  • 「整套機器」：具有完整功能、可獨立運作之機器設備。
    • 包含直接用於該項機器之「必須設備」。即該設備係該機器運作所不可或缺之配件或輔助設備。
  • 「分裝報運進口」：進口分為數批或數件報運進口，而非以完整整機方式進口。
    • 例如因體積過大或其他原因而拆散，分批進口。
  • 意思：其實它們應該是一整台機器，因運輸限制不得已把它拆散分批進口。
程序要件：進口人事前申報 + 海關核查屬實
  • 事前申報：進口人須「事前」檢具有關文件申報（如機器藍圖、裝箱單、組裝說明書、進口計畫等）。
  • 海關核查屬實：海關審核後認定「屬實」（確屬整套機器設備）。
效果：經海關核准者，適用整台機器之稅率
  • 經海關核准者，按「整套機器設備應列之稅則號別」徵稅，即適用整台機器之稅率。
未申報者：各按其應列之稅則號別徵稅
  • 若進口人未事前申報，或申報後海關認定不屬整套機器：無法適用整台機器之稅率。
    • 則各批貨物應「各按其應列之稅則號別」分別課稅，即按各零件或組件本身之稅則號別及稅率課徵關稅。
舉個例子
例1：事前申報獲准
  • A公司進口一套發電機組，因體積過大，拆解為渦輪機、發電機、控制盤三批貨物分別運送。
  • A公司於第一批貨物進口前，檢具機器藍圖、組裝說明書及裝箱單向海關申報。
  • 海關審核後確認屬整套發電機組，爰核准該三批貨物均按發電機組應列之稅則號別（稅率3%）課稅。
  • → 符合第40條（事前申報經海關核明屬實，按整套機器設備之稅則號別徵稅）。
例2：未事前申報——各按各稅則課稅
  • B公司進口一套生產線設備，亦須拆散分裝進口，惟B公司未事前檢具文件向海關申報，即逐批報運進口。
  • 第一批為傳動軸、第二批為控制箱、第三批為輸送帶。 因未事前申報，海關就各批貨物按其各自之稅則號別分別課稅（傳動軸稅率5%、控制箱稅率8%、輸送帶稅率6%）。
  • → 符合第40條但書（未事前申報或未經海關核明者，各按其應列之稅則號別徵稅）。
例3：事前申報但未核明屬實
  • C公司進口一批機械零件，申報稱屬整套機器設備之部分。
  • 惟海關審查後發現該批零件無法組合成完整之機器，或缺少關鍵核心組件，無法認定為整套機器。
  • 海關否准按整套機器稅則課稅之申請，各批貨物應按其個別稅則號別課稅。
  • → 符合第40條但書（海關核明不屬實者，各按其應列之稅則號別徵稅）。
相關規定
  • 第40條
    • 整套機器及其必須設備，因體積過大或其他原因，須拆散、分裝報運進口者：
      • 除事前檢同有關文件申報，海關核明屬實，按整套機器設備應列之稅則號別徵稅外，各按其應列之稅則號別徵稅。
記憶口訣
  • 整套機器拆散進，體積過大分批運。
  • 事前檢附文件報，海關核明屬實後，按整套機器課稅，未申報者各別算。

組合貨物拆散分裝進口之稅則號別適用

  • 如果進口的貨物是「由好幾樣東西組合在一起」的（例如一組家具、一組玩具、一組高爾夫球具）， 因為包裝或運輸需要拆開分成好幾批運進來：
    • 只要它不是機器設備，就不需要事先向海關申請核明。
    • 海關會直接按「整組貨物」的稅則號別來課稅。
      • 而不是按螺絲、木板、說明書等個別零件的稅則分別課稅。
      這樣一來，進口人不會因為分開運送而被課到比較高的稅率。
簡單說：
  • 組合貨物（非機器）若因故分批進口：
    • 一律按整套組合貨物的稅則課稅，不用按零件分別課稅。
詳情解析
適用情況：由數種物品組合而成之貨物，拆散、分裝報運進口者
  • 「由數種物品組合而成」：該貨物本質上為一組或多種物品之組合，共同構成一個完整之商品。
    • 例如：玩具套組：主體＋配件＋遙控器，組合後為「整套遙控玩具」。
    • 這些組成部分若分開進口，各自有不同稅則號別及稅率；若組合後整體進口，則歸入一個特定稅則號別。
  • 「拆散、分裝報運進口」：該組合貨物因運輸、包裝或其他原因，須拆散為數批或數件報運進口。
原則：按「整體貨物」徵稅
  • 該拆散分裝進口之各批貨物，均應按「整體貨物」應列之稅則號別及稅率課徵關稅。
  • 無須逐批按其個別組成物品之稅則號別分別課稅。
例外：排除機器設備
  • 「機器拆散分裝進口」另有專門規定（須事前申報經海關核明屬實）。
  • 只要不是機器，就不用申報。直接由海關按「整體貨物」徵稅。
舉個例子
例1：家具套組
  • A公司進口100組餐桌（含桌板、桌腳、螺絲包），因包裝因素將桌板、桌腳、螺絲分裝於不同貨櫃分批運送。
  • 該餐桌組整體之稅則號別為「木製餐桌」（稅率5%），桌板、桌腳、螺絲個別之稅率分別為6%、5%、3%。
  • 海關依本條規定，就該三批貨物均按整體餐桌組之稅則號別（5%）課稅。
  • → 符合第41條（組合貨物拆散分裝進口者，按整體貨物應列之稅則號別徵稅）。
例2：玩具套組
  • B公司進口一批「模型飛機套組」，內含塑膠零件、說明書、膠水、貼紙，因商業需求分裝為兩批進口。
  • 該套組整體歸列於「玩具模型」（稅率0%），惟說明書屬「印刷品」（稅率5%）。
  • 海關依本條規定，兩批貨物均按整體套組之稅率0%課稅。
  • → 符合第41條（組合貨物之整體稅則號別優先於個別零件稅則）。
例3：機器設備仍須適用第40條
  • C公司進口一套「自動化包裝機」（屬機器設備），拆散分裝為控制箱、傳動帶、機械手臂三批進口。
  • 因屬機器設備，應依第40條規定事前申報經海關核明，始得按整套機器之稅則課稅。
  • 若未事前申報，則各按其應列之稅則號別課稅，不適用本條。
  • → 不適用第41條（機器設備應依前條第40條辦理，非本條之適用範圍）。
相關規定
  • 第41條
    • 由數種物品組合而成之貨物，拆散、分裝報運進口者：
      • 除機器依前條規定辦理外，按整體貨物應列之稅則號別徵稅。
記憶口訣
  • 組合貨物拆散進，整體稅則來適用。
  • 機器須先報准許，一般組合免申報。
  • 確保稅負一致算，拆散不增稅額度。

海關調查權與被調查人之協力義務

  • 海關為了查清楚進口貨物到底值多少錢，依法可以採取下面這些調查動作：
    1. 檢查買賣雙方關於價格的其他文件（不限於這次交易的發票）
    2. 調查這批貨物、同樣貨物或類似貨物的交易價格或國內售價，也可以查閱這批貨物過去進口時的完稅價格紀錄
    3. 調查其他廠商賣這類貨物時的帳簿和單據
    4. 調查其他跟完稅價格有關的任何資料
  • 被調查的人（包括買方、賣方、其他廠商）不能躲避、不能妨礙、也不能拒絕。
簡單說：
  • 海關為了查稅，有權調閱買賣雙方及同業的價格資料，被調查者不得拒絕。
詳情解析
調查權：海關為查明進口貨物之正確完稅價格，得採取下列措施
  1. 檢查買賣雙方文件：
    • 得檢查買方及賣方「有關售價」之其他交易文件，不限於該批進口貨物。
    • 例如：買賣雙方間之其他交易發票、合約、付款證明、信用狀、內部報價單等。
  2. 調查價格：
    • 調查對象：該貨物本身、同樣貨物或類似貨物之交易價格或國內銷售價格。
    • 查閱紀錄：該貨物以往進口時之完稅價格紀錄，以比對價格變動是否合理。
  3. 調查其他廠商：
    • 得調查「其他廠商」（非買賣雙方）出售該貨物或同樣/類似貨物之帳簿及單證。
    • 目的：透過交叉比對同類貨物之市場價格，驗證進口人申報價格是否合理。
  4. 調查其他有關資料：
    • 概括條款。賦予海關調查其他一切與完稅價格核定有關之資料。
    • 如生產成本、權利金合約、市場行情報告等。
被調查人之協力義務
  • 被調查人包括：買方、賣方、其他廠商及相關人員。
  • 禁止行為：規避（如逃避調查）、妨礙（如阻撓調查進行）、拒絕（如不提供文件）。
  • 違反效果：
    • 罰鍰3千 ~ 3萬
    • 限期配合、得按次處罰
舉個例子
例1：檢查買賣雙方文件
  • A公司進口一批電子零組件，申報價格每件新臺幣50元。
  • 海關對價格存疑，依本條第一款檢查A公司與賣方間之其他交易發票及合約。
  • 海關檢查發現同類貨物於前一個月之交易價格為每件80元，A公司無法合理說明價格差異。
  • 海關認定申報價格不可信，依第29條第5項規定，視為無法按交易價格核估， 改依第35條合理方法，參考同類貨物之市場行情，核定完稅價格為每件75元，並據以補徵關稅。
  • → 符合第42條第1款（海關得檢查買賣雙方有關售價之其他文件；調查後如認申報價格不可信，得改依其他方法核估並補稅）。
例2：調查同類貨物價格
  • B公司進口一批化學原料，申報價格明顯低於市場行情。
  • 海關依本條第二款調查其他廠商進口同樣貨物之交易價格及國內銷售價格， 並查閱B公司以往進口該貨物之完稅價格紀錄。
  • 海關調查發現本次申報價格較前次大幅下降，且無合理理由。
  • 海關認定申報價格不實，乃依調查所得之同類貨物市場行情， 重新核實估定完稅價格，並發單通知B公司補繳差額關稅及滯納金。
  • → 符合第42條第2款（海關得調查同樣或類似貨物之價格及查閱以往完稅價格紀錄；調查後認定不實者，得核實估定並補稅）。
例3：調查其他廠商帳簿
  • C公司進口一批機械零件，海關為驗證申報價格之合理性，依本條第三款調查市場上其他廠商出售同類貨物之帳簿及單證。
  • 海關調查發現同類貨物之市場行情約為C公司申報價格之1.5倍。
  • 海關遂認定C公司涉有低報價格之情事，除依調查所得資料重新核定完稅價格並補徵關稅外， 另因其申報不實，可能涉有虛報貨物價值之情事， 海關另案依海關緝私條例第37條規定，處以所漏進口稅額二倍至五倍之罰鍰。
  • → 符合第42條第3款（海關得調查其他廠商出售同類貨物之帳簿及單證； 調查後如認涉有違章情事，除補稅外，另得依海關緝私條例處罰）。
相關規定
  • 第42條
    • 海關為查明進口貨物之正確完稅價格，得調查買賣雙方及其他廠商之相關文件單據。
      • 被調查人不得規避、妨礙或拒絕。
記憶口訣
  • 海關調查核完稅，四項權限要記牢。
  • 買賣文件全可查，價格紀錄比對清。
  • 同業帳簿也能調，概括條款無遺漏。
  • 被調查人不得拒，否則罰鍰跑不掉。
