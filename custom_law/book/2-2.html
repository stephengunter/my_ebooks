2-2 通關程序-完稅價格

完稅價格之核估原則與交易價格制度

  • 進口貨物如果是按價格來課關稅：
    • 其「完稅價格」原則上就是買賣雙方「實際交易的價格」。
    • 「實際交易的價格」是指：從出口國賣到台灣來，買方已經付或應該付的全部價款。
  • 不過，發票上的價格通常不會包含所有成本。所以法律規定，下面這些費用如果沒有算進去，必須「加」到交易價格裡面：
    1. 買方付的佣金、包裝費。
    2. 買方免費或打折提供給賣方用於生產的原料、工具、設計等。
    3. 權利金。
    4. 運到台灣港口的運費、裝卸費和保險費等。
  • 計入交易價格之費用（如佣金、權利金、保險費等）須有「客觀、可計量」之資料為依據。
    • 如果沒有「客觀、可計量」的資料，則應放棄交易價格方法，而改用其他方法來估價。
  • 如果海關對你提供的交易文件有「合理懷疑」，你無法說明清楚：
    • 那海關就可以不用交易價格來核估完稅價格，而改用其他方法來估價。
簡單說：
  • 進口貨物的關稅稅基，原則上就是買賣雙方實際交易的價格，再加上特定應計入的費用。
  • 若海關對文件真實性有合理懷疑，可改用其他方法核估。
完稅價格以交易價格為計算根據
  • 「交易價格」為核估完稅價格之首要基準。
  • 完稅價格為計算關稅之「稅基」，其計算公式為：完稅價格 × 關稅稅率 = 應納關稅額。
  • 若無法依交易價格核估，則應依序適用：
    1. 同樣貨物之交易價格（第31條）
    2. 類似貨物之交易價格（第32條）
    3. 國內銷售價格（第33條）
    4. 計算價格（第34條）
    5. 合理方法（第35條）
交易價格之計算
交易價格：指進口貨物由輸出國銷售至我國實付或應付之價格
  • 「實付或應付之價格」：指買方為進口貨物已付或應付予賣方之全部價款，不以實際支付為限 。
應計入交易價格之費用
  • 以下費用應計入交易價格之費用。此等費用雖未直接反映於發票價格中，但實際上為買方取得該進口貨物所付出之成本，故應計入完稅價格。
    1. 買方付的佣金、包裝費。
    2. 買方免費或打折提供給賣方用於生產的原料、工具、設計等。
    3. 權利金。
    4. 運到台灣港口的運費、裝卸費和保險費等。
客觀可計量原則
  • 計入交易價格之費用（如佣金、權利金、保險費等）須有「客觀、可計量」之資料為依據。
  • 如果沒有「客觀、可計量」的資料，則應放棄交易價格方法，改依第31條至第35條之次順位方法核估。
估價審查權與納稅義務人之協力義務
  • 納稅義務人有義務提出完整、真實的交易文件。
  • 若納稅義務人未能提供充分之交易文件或說明，或海關對其說明仍有「合理懷疑」，則「視為無法按交易價格核估」。
  • 此為海關得依其他方法核估完稅價格之「程序要件」。
舉個例子
例1：以交易價格核估
  • A公司自日本進口汽車一批，買賣合約載明每輛CIF基隆港價格為新臺幣100萬元。
  • 該價格已包含運費、保險費及賣方之利潤，且無其他應加計之費用。
  • 海關即以每輛新臺幣100萬元作為完稅價格，乘以適用稅率課徵關稅。
  • → 符合第29條第1項及第2項（完稅價格以交易價格為計算根據）。
例2：加計權利金
  • B公司自美國進口電腦軟體，支付賣方軟體費用新臺幣500萬元，另依合約支付權利金新臺幣50萬元。
  • 該權利金為取得軟體使用權之條件，與進口貨物有關且未計入原交易價格。
  • 海關將該權利金50萬元計入完稅價格。
  • → 符合第29條第3項第3款（權利金應計入完稅價格）。
例3：合理懷疑而無法核估
  • C公司自中國進口電子零組件，申報交易價格為每件新臺幣10元。
  • 海關查核發現，該同類貨物之國際市場行情約為每件新臺幣50元，且C公司無法提出合理說明及完整交易文件。
  • 海關合理懷疑其交易價格之真實性，爰認定無法依本條核估，改依第35條合理方法核估完稅價格。
  • → 符合第29條第5項（海關對交易文件真實性有合理懷疑，納稅義務人未提出說明者，視為無法按本條核估）。
相關規定
  • 第29條
    • 第1項：從價課徵關稅之進口貨物，其完稅價格以該進口貨物之交易價格作為計算根據。
    • 第2項：交易價格，指進口貨物由輸出國銷售至中華民國實付或應付之價格。
    • 第3項：列舉應計入交易價格之費用。
    • 第4項：計入完稅價格之費用，應根據客觀及可計量之資料。無客觀及可計量之資料者，視為無法按本條規定核估其完稅價格。
    • 第5項：海關對發票或交易文件有合理懷疑，得視為無法按本條規定核估其完稅價格。
記憶口訣
  • 交易價格為基礎，實付應付都算數。
  • 六項費用要加計，佣金包裝運保費，權利金與轉售利，買方提供物品勞。
  • 客觀計量要具體， 無則無法用此法。
  • 海關懷疑可拒絕，另行核估完稅價。

交易價格之排除適用事由與特殊關係之認定

  • 不是所有的「交易價格」都可以拿來當作關稅的稅基。 如果有以下四種情況，海關就不能用這個交易價格來算關稅：
    1. 買方對貨物的使用或處分受到限制（除非是我國法律規定的限制、轉售地區的限制，或該限制對價格影響不大）
    2. 這個交易附帶了條件，導致無法算出這批貨物真正的價格
    3. 買方轉賣貨物後要把部分收益分給賣方，但這筆錢到底有多少不清楚
    4. 買賣雙方有「特殊關係」，而且因為這個關係影響了價格
  • 至於什麼叫「特殊關係」，法律也明確列出八種情況，包括：
    • 一方是另一方的董事、經理人、持有對方5%以上股份、控制關係、僱傭關係、合夥關係
    • 或是配偶、三親等以內親屬等
簡單說：
  • 當交易價格被操控、受限或附帶不明條件時，海關不能拿它來課稅。
  • 買賣雙方有特殊關係時，除非能證明價格不受影響，否則也不能用。
一句話總結
  • 當進口貨物之交易價格受限制、附條件、收益不明或受特殊關係影響時：
    • 不得作為完稅價格之計算根據，應改用其他方法核估。
為什麼要有這條規定？
  • 確保完稅價格之真實性與正確性：排除受限制、附條件、收益不明或受特殊關係影響之交易價格，確保完稅價格反映貨物之真實價值。
  • 遵循WTO關稅估價協定之國際規範：我國為WTO會員，關稅估價制度須與該協定一致，本條之規範內容與該協定第1條及相關註釋完全接軌。
  • 防止藉由特殊關係規避關稅：關係企業或關聯企業間之交易，可能透過人為操縱價格以降低關稅負擔，本條透過特殊關係之認定與價格影響之審查，防止此類規避行為。
  • 建立明確之法律要件：本條將不得採用交易價格之事由及特殊關係之具體態樣予以明文化，使納稅義務人與海關均有明確之法律依據可資遵循。
舉個例子
例1：使用限制致價格不採用
  • A公司向國外供應商購買一批機械設備，合約約定該設備僅得於A公司之特定廠房內使用，不得移轉或出租予第三人。
  • 海關認定此使用限制影響價格之正常決定，爰依本條第一款規定，不採用該交易價格為完稅價格。
  • → 符合第30條第1項第1款（買方對貨物使用受有限制，且非屬我國法令限制、轉售地區限制或對價格無重大影響）。
例2：附條件交易
  • B公司向國外供應商購買一批化學原料，合約約定B公司須同時向該供應商購買另一批滯銷庫存品，始得以該價格購入原料。
  • 海關認定該交易附有條件，致原料價格無法與庫存品價格分離核定。
  • → 符合第30條第1項第2款（交易附有條件，致價格無法核定）。
例3：特殊關係且影響價格
  • C公司為台灣進口商，其母公司持有C公司百分之百之股份。
  • C公司向母公司進口一批電子零組件，申報價格僅為國際市場行情之60%。
  • 海關認定雙方為特殊關係（持股關係），且該關係致價格偏低，爰不採用該交易價格。
  • → 符合第30條第1項第4款及第2項第4款（買賣雙方為特殊關係且致影響交易價格，交易價格不得採用）

同樣貨物之交易價格核估法

  • 如果進口貨物沒有辦法用第29條的「實際交易價格」來估關稅（例如價格不透明、有特殊關係、海關有合理懷疑等）時：
    • 海關可以用「同樣貨物」的交易價格來核估。
  • 所謂「同樣貨物」，是指生產國、物理特性、品質和商譽都完全一樣的貨物。
  • 不過，即使是同樣貨物，交易條件也可能不同（例如買的數量不一樣、運費不一樣）：
    • 海關在核估時，可以針對這些影響價格的因素做合理的調整。
簡單說：
  • 無法用實際交易價格估稅時：
    • 海關會參考「完全相同」貨物的交易價格，並就數量、運費等差異做合理調整。
一句話總結
  • 無法用實際交易價格估稅時，「同樣貨物法」是完稅價格核估之「第一順位替代方法」：
    • 海關參考「生產國、物理特性、品質及商譽完全相同」的貨物之交易價格， 並就數量、運費等差異做合理調整。
使用前提與核估方法
使用前提：未能依交易價格核定
  • 例如：
    • 納稅義務人未能提供交易價格資料。
    • 交易雙方有特殊關係（排除事由）價格不得採用。
    • 海關對交易價格有合理懷疑且納稅義務人未能釋明
    • 應計入完稅價格之費用無法依客觀資料計量
核估方法：參照同樣貨物之交易價格
  • 同樣貨物之交易價格須為「銷售至中華民國」之價格，即該同樣貨物須已實際進口至我國。
  • 交易時間點為系爭貨物「出口時或出口前、後」， 即同樣貨物之交易時間須與系爭貨物之出口時間相近，以反映合理之價格水準。
合理調整之權限與義務
  • 海關參照「同樣貨物」之交易價格核定時， 應就交易型態、數量及運費等影響價格之因素作合理調整。
  • 調整須有「客觀及可計量之資料」為依據，不得恣意為之。
  • 調整因素包括但不限於：
    • 交易型態（如批發與零售之差異）
    • 數量（大量與小量之差異）、
    • 運費（不同運輸方式或距離之費用差異）
同樣貨物之定義
同樣貨物：指其生產國別、物理特性、品質及商譽等均與該進口貨物相同者
  • 同樣貨物須同時符合以下要件：
    1. 生產國別相同：須為同一國家生產。
    2. 物理特性相同：如材質、規格、尺寸、功能等物理屬性相同。
    3. 品質相同：如等級、純度、耐用性等品質水準相同。
    4. 商譽相同：如品牌、商標、市場知名度等商業信譽相同。
  • 此為「完全相同」之貨物，標準極為嚴格，於實務上較為罕見。
舉個例子
例1：以同樣貨物之交易價格核估
  • A公司自日本進口一批「某型號數位相機」。
  • 因A公司與賣方有特殊關係且價格偏低，海關認定無法依第29條核定。
  • 海關查得B公司於前一個月自日本進口「相同型號、相同產地、相同品質、相同品牌」之數位相機， 其交易價格為每台新臺幣10,000元。
  • 海關即以該價格為基礎，並考量A公司進口數量較B公司為多，合理調整價格為每台新臺幣9,500元。
  • → 符合第31條（以同樣貨物之交易價格核定，並就數量差異為合理調整）。
例2：同樣貨物之定義
  • C公司自中國進口一批「某品牌手機」，海關未能以交易價格核定，擬依本條參照同樣貨物之價格。
  • 惟海關查得市場上僅有「同品牌但不同型號」之手機，或「同型號但產地為越南」之手機，均不符合「同樣貨物」之定義。
  • → 不符合第31條（同樣貨物須生產國別、物理特性、品質及商譽均相同，不同型號或不同產地均非同樣貨物）。
例3：合理調整交易型態
  • D公司自德國進口一批「汽車零組件」。
  • 海關查得同樣貨物前一個月之交易價格為每件新臺幣500元，惟該交易為「零售」交易，而D公司係「大量批發」進口。
  • 海關考量交易型態及數量之差異，將價格合理調整為每件新臺幣420元。
  • → 符合第31條（應就交易型態及數量等影響價格之因素作合理調整）。
相關規定
  • 第31條
    • 第1項：進口貨物完稅價格無法用交易價格核估時，改用「同樣貨物」的交易價格。
    • 第2項：「同樣貨物」生產國別、物理特性、品質、商譽都要相同。
記憶口訣
  • 交易價格不能用，改用同樣貨物價。
  • 同樣貨物四要件，產地特性品質譽。
  • 出口前後皆可參，交易數量運費調。

類似貨物之交易價格核估法

  • 如果進口貨物沒有辦法用「實際交易價格」來估稅，也找不到「完全相同」的貨物來比價：
    • 海關就可以改用「類似貨物」的交易價格來核估。
  • 所謂「類似貨物」，是指：
    • 雖然不是完全一樣，但生產國相同、功能相同、特性和材料相似，而且在市場上可以互相替代的貨物。
    • 舉例來說，不同廠牌但功能相同的筆記型電腦，就可以算是類似貨物。
  • 同樣地，海關在比價時，也要針對數量、運費等差異做合理的調整。
簡單說：
  • 找不到「完全相同」的貨物比價時：
    • 海關可改用「功能相同、可互相替代」的「類似貨物」交易價格來估稅。
一句話總結
    「類似貨物」是完稅價格核估的第二順位替代方法 ——
  • 找不到「完全相同」的貨物比價時：
    • 海關可改用「生產國相同、功能相同、材料相似且可互為替代」的「類似貨物」交易價格來估稅。
      • 並就數量、運費等差異作合理調整。
使用前提與核估方法
使用前提：無法依「交易價格」、「同樣貨物」核定完稅價格時
  • 例如：納稅義務人未能提供交易價格資料（無法認定交易價格）且同樣的貨物過去一年內無人進口（無同樣貨物價格可參考）。
核估方法：參照「類似貨物」之交易價格
  • 「類似貨物」之交易價格須為「銷售至中華民國」之價格，即該類似貨物須已實際進口至我國。
  • 交易時間點為系爭貨物「出口時或出口前、後」，須與系爭貨物之出口時間相近。
合理調整之權限與義務
  • 海關參照「類似貨物」之交易價格核定時， 應就交易型態、數量及運費等影響價格之因素作合理調整。
  • 調整須有「客觀及可計量之資料」為依據，不得恣意為之。
  • 調整因素包括但不限於：
    • 交易型態（如批發與零售之差異）
    • 數量（大量與小量之差異）、
    • 運費（不同運輸方式或距離之費用差異）
類似貨物之定義
類似貨物：與生產國別及功能相同、特性及組成之原材料相似、可互為替代
  • 「類似貨物」之法定定義，須符合以下要件：
    1. 生產國別相同：須與系爭貨物為同一國家生產。
    2. 功能相同：須具有相同之主要功能或用途。
    3. 特性及組成之原材料相似：物理特性（如強度、硬度、導電性等）及構成材料（如鋼鐵、塑膠、木材等）須相似。
    4. 交易上可互為替代：在市場上可互相替換使用，例如不同廠牌但功能相同之電腦、不同型號但用途相同之工具機。
  • 此定義較「同樣貨物」為寬鬆，但仍須具備相當程度之相似性。
舉個例子
例1：以類似貨物之交易價格核估
  • A公司自日本進口一批「A品牌數位相機」。
  • 因無法依交易價格核定，亦無「完全相同」之同樣貨物可供參考（市場上無同品牌同型號之進口紀錄）。
  • 海關查得B公司前一個月自日本進口「B品牌數位相機」，該相機與A公司進口之相機功能相同 （同為1,200萬畫素、10倍光學變焦）、特性及組成材料相似（均為塑膠外殼、鋰電池）、在市場上可互為替代。
  • 海關即以B品牌相機之交易價格每台新臺幣8,000元為基礎，並就數量及運費為合理調整。
  • → 符合第32條（以類似貨物之交易價格核定，並為合理調整）。
例2：生產國別不同
  • C公司自中國進口一批「某型號工具機」，海關擬以類似貨物之交易價格核估。
  • 惟市場上雖有功能相同、材料相似之工具機，但均為「德國」生產，而非「中國」生產。
  • → 不符合第32條（類似貨物須「生產國別相同」，不同生產國別之貨物不得作為類似貨物）。
例3：功能不同
  • D公司自美國進口一批「醫療用超音波掃描儀」，海關擬以類似貨物之交易價格核估。
  • 惟市場上雖有相同生產國別、材料相似之貨物，但該貨物為「工業用超音波檢測儀」，功能與醫療用不同，且無法互為替代。
  • → 不符合第32條（類似貨物須「功能相同」且「交易上可互為替代」，工業用與醫療用功能不同，不得作為類似貨物）
相關規定
  • 第32條
    • 第1項：進口貨物完稅價格無法用交易價格、同樣貨物核估時，改用「類似貨物」的交易價格。
    • 第2項：「類似貨物」：生產國別、物理相同特性，特性及組成之原材料相似，且在交易上可互為替代者。
記憶口訣

  • 類似貨物四要件，產地功能要相同。特性原料需相似，交易可互為替代。

國內銷售價格核估法

  • 如果進口貨物沒辦法用「實際交易價格」、「同樣貨物」、「類似貨物」來估稅：
    • 海關可以改用「國內銷售價格」來推估。
  • 所謂「國內銷售價格」，是指這批貨（或同款、類似貨）在進口前後：
    • 於國內「第一次賣出」時，賣給「沒有特殊關係」的買方，且「銷售數量最多」的那個單位價格。
      • 然後再扣掉三類費用：
        1. 國內銷售的利潤、費用和佣金
        2. 進口時繳的關稅和其他稅
        3. 進口後發生的運費、保險費等
        剩下的金額就是完稅價格。
  • 如果進口時前後都沒有銷售紀錄，可以用進口後「90天內」的銷售紀錄來算。
  • 如果貨物是加工後才賣的，還要把加工增加的價值也扣掉。

使用前提：無法依「交易價格」、「同樣貨物」、「類似貨物」核定完稅價格時
  • 例如：納稅義務人未能提供交易價格資料（無法認定交易價格）且同樣的、類似的貨物過去一年內皆無人進口（無同樣、類似貨物價格可參考）。
核估方法：參照「國內銷售價格」
  • 「國內銷售價格」：用貨物在台灣境內第一次賣出的價格，再倒扣掉利潤、稅費、運費等項目，推算出完稅價格。
納稅義務人得請求改用「計算價格法」
  • 原則上「銷售價格法」（第三順位）優先於「計算價格法」（第四順位）適用。
  • 但納稅義務人得請求「變更順序」，即優先適用「計算價格法」。
國內銷售價格之定義與計算
國內銷售價格：指該進口貨物、同樣或類似貨物，於該進口貨物進口時或進口前、後，在國內按其輸入原狀於第一手交易階段，售予無特殊關係者最大銷售數量之單位價格核計後，扣減下列費用計算者
  • 國內銷售價格之「定義與計算框架」：
    • 該進口貨物、同樣或類似貨物 ：指系爭貨物本身，或與其相同或類似之貨物。
    • 進口時或進口前、後 ：指與系爭貨物進口時間相近之期間。
    • 輸入原狀 ：貨物未經加工，以進口時的狀態銷售。
    • 第一手交易階段 ：貨物第一次在國內銷售（進口商賣給國內買家），不是後續轉手。
    • 無特殊關係者 ：買賣雙方無關係人交易（如母子公司、親屬等），避免人為操縱價格。
    • 最大銷售數量之單位價格 ：以賣得最多件的價格為基準（不是平均價格）。
扣減項目（反向推算）
      利潤、費用或佣金 ：以賣得最多件的價格為基準（不是平均價格）。
      關稅及其他稅捐 ：進口時繳納的關稅、營業稅等。
      進口後運費、保險費 ：貨物進口後在國內運輸、倉儲等費用。
無即時國內銷售之處理
  • 適用前提：「進口時或進口前、後」查無該進口貨物、同樣或類似貨物在國內銷售者。
  • 放寬標準：進口後90天內。
    • 原標準：進口時或進口前、後（與系爭貨物進口時間相近）。
    • 放寬後標準：系爭貨物進口之翌日起90日內。
「非按原狀銷售時」之特別規定
  • 當貨物進口後，不是原狀賣出，而是經過了加工、組裝、改裝、分裝等處理（也就是有「輸入後加工行為」）：
    • 此時國內售價已非單純貨物本身的價格，而是包含了「加工增值」。
    為了正確回推完稅價格，必須：
    • 把加工創造的附加價值也扣除，避免把國內加工後的利潤也誤算為進口貨物的價值。
  • 適用前提：沒有「按輸入原狀銷售」的樣本可採時。
    • 許多貨物必須加工才有銷售的市場價值。例如進口零組件，在國內組裝後銷售。
  • 啟動方式：依納稅義務人之申請。
  • 核價方式：除了一般扣除項目（利潤、費用、稅捐、運費）外，還要再扣掉加工所創造的價值。
例子：進口布料 → 製成成衣後銷售
  • 台灣B公司從義大利進口一批高級羊毛布料，因無法用交易價格、同樣貨物、類似貨物核估完稅價格，海關擬改用「國內銷售價格法」。 但這批布料不是直接原狀出售，而是在台灣加工製成西裝後才銷售。
    項目 金額
    加工後西裝在國內銷售價格（最大銷售數量之單位價格） 15,000元
    國內加工增值（含工資、管銷、利潤等） 8,000元
    國內銷售利潤及費用 1,500元
    進口關稅、營業稅等稅捐 800元
    進口後運費、保險費等 200元
    • 一般扣減（按原狀銷售）：15,000元 － 1,500元 － 800元 － 200元 ＝ 12,500元（這個數字仍然包含加工增值，不正確）
    • 加工後銷售扣減：完稅價格 ＝ 15,000元 － 8,000元（加工增值） － 1,500元 － 800元 － 200元 ＝ 4,500元
      • 關鍵： 多扣除了「加工增值」（8,000元），才是布料進口時的正確完稅價格
舉個例子
例1：國內銷售價格核估
  • A公司自日本進口一批「電子零組件」，因無法依第29、31、32條核定完稅價格。
  • 該批零組件於進口後10日內，以每件新臺幣500元之價格（最大銷售數量）售予無特殊關係之B公司。
  • 海關以每件新臺幣500元為基礎，扣除國內銷售利潤及費用（每件80元）、進口關稅及其他稅捐（每件70元）、 進口後運費（每件20元），計算出完稅價格為每件新臺幣330元（500-80-70-20=330）。
  • → 符合第33條第1項及第3項（以國內銷售價格核估，並扣除相關費用）。
例2：納稅義務人請求變更順序
  • C公司進口一批「化學原料」，海關原應依第33條（國內銷售價格）核估。
  • 但C公司主張第34條（計算價格）之結果對其較有利，請求變更適用順序。
  • 海關依其請求，改以第34條計算價格核估。
  • → 符合第33條第2項（海關得依納稅義務人請求，變更本條與第34條之適用順序）。
例3：非按原狀銷售——扣除加工增值
  • D公司進口一批「原木」，進口後經裁切加工為「木材」始銷售。
  • 海關依D公司申請，以加工後木材之國內銷售價格每立方公尺新臺幣10,000元為基礎， 扣除加工後之增值（每立方公尺3,000元）及第三項所列費用（利潤、稅費、運費共2,000元）， 計算出完稅價格為每立方公尺新臺幣5,000元。
  • → 符合第33條第5項（非按原狀銷售者，應扣除加工後之增值及相關費用）。
相關規定
  • 第33條
    • 第1項：進口貨物完稅價格無法用交易價格、同樣貨物、類似貨物核估時，改用「國內銷售價格」核定之。
    • 第2項：納稅義務人得請求優先適用「計算價格法」。
    • 第3項：國內銷售價格之定義與計算原則。
    • 第4項：近期查無國內銷售紀錄時，得放寬至進口翌日起90日內之銷售紀錄。
    • 第5項：「非按原狀銷售」時，應扣除加工後之增值。
記憶口訣
  • 交易類似皆不能，改用國內銷售價。
  • 輸入原狀第一手，無特殊關係最大量。
  • 扣除利潤稅費運，反向推算完稅價。
  • 九十日內有銷售，同樣可用此方法。
  • 加工銷售也可行，扣除增值與費用。

計算價格核估法

  • 如果進口貨物沒辦法用「實際交易價格」、「同樣貨物」、「類似貨物」、「銷售價格」來估稅：
    • 海關可以改用「計算價格」來推估。
  • 所謂「計算價格」，就是把三類費用「全部加起來」：
    1. 生產成本（材料、人工、工廠費用等）
    2. 出口國銷售此類貨物到台灣的正常利潤和一般費用
    3. 運到台灣港口的運費、裝卸費和保險費
    這三項相加的總和，就是完稅價格。
  • 不過，這種方法需要知道貨物的生產成本，而這通常只有賣方（製造商）才清楚。
    • 如果賣方不願意提供生產成本，海關就無法用這個方法。
簡單說：
  • 所有比價方法都行不通時：
    • 海關就把「生產成本＋利潤費用＋運費保險費」全部加起來當作完稅價格。
一句話總結
    「計算價格」是完稅價格核估的第四順位替代方法 ——
  • 所有比價方法都行不通時，海關將「生產成本＋正常利潤費用＋運費保險費」全部加總，作為完稅價格。
  • 納稅義務人得請求優先於國內銷售價格法適用。
使用前提與核估方法
使用前提：無法依「交易價格」、「同樣貨物」、「類似貨物」、「銷售價格」核定完稅價格時
  • 若納稅義務人「請求變更順序」，則「計算價格」得優先於「銷售價格」適用。
核估方法：三類項目之「加總」
  1. 生產成本及費用 ：在出口國生產貨物的直接成本（原料、工資、製造費用等）。
  2. 正常利潤與一般費用 ：由輸出國生產銷售至我國的該貨物、同級或同類別貨物之正常利潤與一般費用。
  3. 運費、裝卸費、搬運費及保險費 ：貨物從輸出國運至我國口岸之運輸及保險費用。
核估邏輯
  • 生產成本 ＋ 費用 ＋ 利潤 ＋ 運費保險費
  • 與前面幾種方法相反——前面是「從售價倒推」，這裡是「從成本正加」。
舉個例子
例1：以計算價格核估
  • A公司自德國進口一批「特殊規格機械零件」，因該零件屬客製化產品， 市場上無交易價格、無同樣或類似貨物可供比價，亦無國內銷售紀錄。
  • 海關無法依第29、31、32、33條核定完稅價格。
  • A公司提供德國製造商之生產成本資料（材料費新臺幣10萬元、人工費5萬元、工廠費用3萬元）， 經海關查核屬實。
  • 另查得同類貨物出口至我國之正常利潤及一般費用為生產成本之20%（即3.6萬元）， 運費及保險費為1萬元。海關將上述各項加總，計算出完稅價格為新臺幣22.6萬元（10+5+3+3.6+1=22.6）。
  • → 符合第34條（以計算價格核定完稅價格）。
例2：納稅義務人請求變更順序——優先適用計算價格
  • B公司進口一批「化學品」，海關原應依第33條（國內銷售價格）核估，但國內銷售價格因市場波動而偏高。
  • B公司主張計算價格對其較有利，依第33條第2項請求海關變更適用順序，改依第34條計算價格核估。海關審查後同意變更。
  • → 符合第33條第2項及第34條（納稅義務人得請求變更本條與第33條之適用順序）。
例3：無法提供生產成本資料——無法適用計算價格
  • C公司自日本進口一批「精密儀器」，海關無法依前四條核估，擬以計算價格核定。
  • 惟C公司無法提供日本製造商之生產成本資料（製造商拒絕提供），海關亦無其他管道取得相關成本資訊。
  • → 無法依第34條核定（生產成本及費用為計算價格之必要構成項目，無法取得即無法適用本條，應改依第35條合理方法核估）。
相關規定

    • 第1項：進口貨物完稅價格無法用交易價格、同樣貨物、類似貨物、銷售價格核估時，改用「計算價格」核定之。
    • 第2項：計算價格 = 生產成本 ＋ 費用 ＋ 利潤 ＋ 運費保險費
記憶口訣
  • 交易同樣類似都無用，國內銷售也算不出，最後手段計算價。
  • 成本利潤運保費，逐項加總核估價，完稅價格就出爐。

合理方法核估法

  • 如果進口貨物沒有辦法用前面五種方法（交易價格、同樣貨物、類似貨物、銷售價格、計算價格）來核定完稅價格：
    • 海關可以「根據查到的資料，用合理的方法」來核定。
    換句話說，這是萬不得已的最後一招。
  • 海關不能隨便亂估，必須有客觀的資料為基礎。
    • 使用的方法必須合理——不能規定一個「最低價格」或「隨便喊價」。
    • 舉例來說，海關可能參考國際市場行情、產業公會提供的價格資料，或是類似貨物在其他國家的交易價格，然後做合理的調整。
簡單說：
  • 當前面五種估價方法都用不上時：
    • 海關可根據查到的客觀資料，用合理的方法來核定完稅價格 ——這是估價制度的最後防線。
一句話總結
    「合理方法」是完稅價格核估的最後防線 ——
  • 當前面五種估價方法都用不上時，海關可根據查到的客觀資料，用合理的方法來核定完稅價格。
    • 但不得以最低限價或任意估價為之。
使用前提與核估方法
使用前提：無法依「交易價格」、「同樣貨物」、「類似貨物」、「銷售價格」、「計算價格」核定完稅價格時
  • 例如缺乏必要資料、無法取得生產成本資訊、無國內銷售紀錄等原因，致無法以前五條方法核定。
核估方法：依據查得之資料，以合理方法核定之
  • 依據查得之資料 ：海關須有「客觀之查得資料」為基礎，不得憑空臆測或恣意決定。
    • 例如：納稅義務人提供之補充資料、同類貨物之國際市場行情、產業公會之價格資訊、或其他公開可得之價格資料。
  • 以合理方法核定 ：海關得依個案情況，選擇適當之合理方法。該方法須：
    • 與WTO關稅估價協定之一般原則相容。
    • 以前五條估價方法之精神為基礎，作必要之彈性調整。
    • 不得以「最低限價」或「任意估價」為之。
    • 須有客觀及可驗證之依據。
合理方法實務
  • 參考公開市場價格：國際市場行情、同類貨物公開報價。
  • 參考其他國家的估價資料：該貨物在其他國家的完稅價格。
  • 參考國內其他進口商的價格：同業進口同類貨物的申報價格。
  • 調整已有資料：對現有資料作合理調整（如品質差異、數量差異）。
  • 其他客觀可計量之資料：任何與該貨物價值相關的客觀資料。
不得使用：
  • 出口國之國內銷售價格。
  • 最高或最低價格。
  • 任意或虛構的價格。
舉個例子
例1：以合理方法核估
  • A公司自某國進口一批「特殊客製化機械設備」，該設備屬獨一無二之設計，市場上無交易價格、無同樣或類似貨物、 無國內銷售紀錄，亦無法取得生產成本資料。
  • 海關無法依第29、31、32、33、34條核定完稅價格。
  • 海關查得國際上類似功能設備之市場行情資料，並參考設備之重量、複雜度、材料成本等因素，以合理方法核定完稅價格為新臺幣500萬元。
  • → 符合第35條（海關依據查得之資料，以合理方法核定）。
例2：不得以最低限價核定
  • B公司進口一批「電子零組件」，海關因無法以前五條方法核定，逕行以「進口最低限價表」之價格作為完稅價格。
  • 該限價表係海關內部參考資料，未經公開且未考量個案差異。
  • → 不符合第35條（依WTO關稅估價協定，合理方法不得以「最低限價」為基礎；海關應有具體查得之資料，並說明合理調整之依據）。
例3：以產業公會價格資訊為基礎
  • C公司進口一批「化學原料」，因缺乏比價對象及生產成本資料，無法依前五條核定。
  • 海關查得國內同業公會定期發布之「國際化學原料行情參考價格」，並參考該批貨物之純度、數量及交貨條件等因素， 以合理方法核定完稅價格。
  • → 符合第35條（海關依據查得之客觀資料，以合理方法核定）。
相關規定
  • 第35條 ：進口貨物完稅價格無法用交易價格、同樣貨物、類似貨物、銷售價格、計算價格核估時，始得改用「合理方法」核定之。
記憶口訣
  • 六種方法依序用，交易同樣與類似，國內銷售計算價，最後手段合理法。
  • 海關查得資料核，不得虛構或臆測。

完稅價格核估方法 — 總整理

  • 六種估價方法依序適用：交易價格 → 同樣貨物 → 類似貨物 → 國內銷售價格 → 計算價格 → 合理方法。
    • 前者不行才換後者，順序不能亂跳。
六種估價方法
順位 方法 說明 口訣
① 交易價格 實付或應付價格（最優先） 自己付多少算多少
② 同樣貨物價格 完全相同貨物的交易價格 找一模一樣的
③ 類似貨物價格 可互為替代貨物的交易價格 找差不多的
④ 國內銷售價格 國內售價 ➜ 扣減費用（倒推） 從賣價倒推
⑤ 計算價格 成本 ＋ 利潤 ＋ 運費（正加） 從成本正加
⑥ 合理方法 海關綜合查得資料核定 最後手段
核心要點
① 交易價格
  • 定義：貨物由輸出國銷售至我國，買方實付或應付之全部價款。
    • 包含：佣金、包裝費、權利金、輸出國至我國的運費、保險費等。
  • 客觀可計量原則：計入交易價格之費用須有「客觀、可計量」之資料為依據。
  • 納稅義務人應舉證：應提出完整、真實的交易文件。
    • 海關質疑真實性時，應清楚說明。
  • 海關審查權：可拒絕使用交易價格核估。
    • 可質疑交易文件真實性，要求納稅義務人說明或補件。
    • 納稅義務人未能提供充分之交易文件或說明，或海關對其說明仍有「合理懷疑」，則「視為無法按交易價格核估」。
② 同樣貨物價格
  • 定義：生產國、物理特性、品質及商譽等均與該進口貨物相同者（完全相同）。
  • 出口時間相近：與系爭貨物出口時間要盡量接近。
  • 合理調整：應就交易型態、數量及運費等影響價格之因素作合理調整。
    • 如批發與零售之差異、不同運輸方式或距離之費用差異。
③ 類似貨物價格
  • 定義：生產國、物理特性、品質及商譽等均與該進口貨物相同者（完全相同）。
  • 出口時間相近：與系爭貨物出口時間要盡量接近。
  • 合理調整：應就交易型態、數量及運費等影響價格之因素作合理調整。
    • 如批發與零售之差異、不同運輸方式或距離之費用差異。
