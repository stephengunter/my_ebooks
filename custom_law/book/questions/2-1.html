報關查驗題目

事後審查

先行驗放與事後審查
  • 為加速通關，海關可先放貨、後審查。
  • 稅款會在放行後6個月內核定，逾期視為結案。
三種先行驗放機制
適用情況 處理方式
① 先行徵稅驗放 一般案件，海關可即時算稅
  • 先行徵稅驗放 ：海關先依業者申報內容算稅、收錢，然後放行貨物
  • 事後審查 ：放行後，海關仔細審查申報內容
  • 6個月內核定 ：自「放行翌日」起算，6個月內海關要決定是否要「補稅/退稅」
  • 逾期視為核定 ：超過6個月沒通知，視為「已核定」，不能再追稅
② 保證金驗放 海關無法即時核定稅額（例如價格資料不完整，需要查證）
  • 申請 + 檢具文件 ：須納稅義務人主動申請，並提供審查所需資料
  • 繳納保證金 ：納稅義務人須繳納保證金，金額由海關估算
  • 先行驗放 ：納稅義務人繳納保證金後，海關驗貨放行
  • 事後審查 ：放行後，海關仔細審查申報內容
  • 6個月內核定 ：自「放行翌日」起算，6個月內海關要核定最終稅額
  • 屆期視為核定 ：超過6個月沒核定，視為依納稅義務人申報的金額核定，不能再追稅
③ 保證金驗放 + 補辦手續 文件不齊（輸入許可證、免稅證明）
  • 納稅義務人申請 ：須納稅義務人主動申請
  • 繳納保證金 ：納稅義務人須繳納保證金，金額由海關估算
  • 限期補辦 ：納稅義務人應於期限內（4個月內）補辦手續
  • 屆期未補辦者，沒入其保證金
免稅證明補正與退稅
  • 適用情況：欠缺免稅證明，未申請繳納保證金而繳稅者。
  • 得於4個月內申請補正退稅：貨物放行前或放行後4個月內，檢具免稅證明文件申請補正，並退還已繳關稅。
提示
  • 先放後審、6個月內核定、逾期結案、不得再追
  • 無法即時、主動申請、繳保證金、6個月內核定、屆期視為核定
  • 文件不齊、主動申請、繳保證金、4個月內補辦、逾期沒入

進口貨物於貨櫃集散站進行看樣或抽取貨樣，為維護「貨物安全」之管理規則如何?

抽樣/看樣：貨主應「請領准單」
  • 請領准單 ：貨主應向海關請領准單
  • 關員監視 ：集散站業者須依准單指示，在關員監視下辦理
  • 由貨主恢復原狀 ：所拆動之包件，應由貨主恢復包封原狀
提示
  • 看樣/抽取要准單
  • 關員監視、業者操作、貨主原狀

不得進口貨物，放行前處置

適用貨物：管制物品（非違禁品），須備「輸入許可證」或主管機關同意文件
  1. 是否有申報?
    • 有：進入下一步審查
    • 沒有：涉及私運 => 依《海關緝私條例》處置
  2. 是「申報不實」還是「文件不全」?
    • 申報不實：有申報但內容虛偽（虛報品名、價格、產地等） => 依《海關緝私條例》處置
    • 文件不全：申報內容真實，但缺少法定文件
  3. 是否有補正機會？
    • 文件可補正：通知限期補正
    • 無法補正：限期退運。
無法補正/逾期未補正：責令限期退運
  • 未依限辦理退運或書面聲明放棄者，海關得變賣處置
本題情況
  1. 貨物非屬「絕對禁止進口」之違禁物品
  2. 無輸入許可證或主管機關同意文件
  3. 無申報不實情事
海關處理方式
  • 通知進口人「限期補正」：限期2個月內（自海關通知翌日起算）補送輸入許可文件
  • 逾期未補正，限期退運：逾期未補正輸入許可文件者，海關應責令「限期辦理退運」
未限期退運
  • 納稅義務人未限期辦理退運或書面聲明放棄者，海關得將貨物變賣
  • 變賣所得價款，扣除應納關稅及必要費用後，餘額繳歸國庫
提示
  • 限期2個月補正、未補正限期退運
  • 限期不退運變賣、扣除稅費後繳庫

納稅義務人未即時檢具減免關稅文件補正時，該進口貨物如何辦理通關？

文件不齊（免稅證明、輸入許可證等），繳「保證金」後放行
  • 納稅義務人申請 ：須納稅義務人主動申請
  • 繳納保證金 ：納稅義務人須繳納保證金，金額由海關估算
  • 限期補辦 ：納稅義務人應於期限內（4個月內）補辦手續
  • 屆期未補辦者，沒入其保證金
如果進口時沒有依上述保證金驗放，而是直接繳了稅：4個月內申請補正及退稅
  • 未申請保證金而繳稅：貨物本來可以免稅，但業者沒有申請保證金驗放，而是直接把稅繳了。
  • 放行前或放行後4個月內：在貨物放行前，或放行後4個月內，都可以補申請。
  • 檢具證明文件：拿出免稅證明文件。
  • 申請補正及退稅：申請更正為免稅，並要求退還已繳的關稅。
提示
  • 文件不齊、主動申請、繳保證金、4個月內補辦、逾期沒入

下列非適用海關進口稅則第二欄稅率之進口貨物，其原產地如何認定？1.中國籍漁船在菲律賓海域所捕撈之漁貨。2.加工、製造涉及二個以上國家或地區。

進口貨物原產地認定標準
  • 認定原則：「完全生產」或「實質轉型」之國家/地區
1.中國籍漁船在菲律賓海域所捕撈之漁貨 => 原產地「中國」
  • 漁獵：屬「完全生產」
  • 海洋漁獵：以「漁船註冊登記國家」為準
2.加工、製造涉及二個以上國家或地區 => 非「完全生產」=> 以「實質轉型」之國家/地區為準
  • 「非適用海關進口稅則第二欄稅率」=> 非「特定低度開發國家」、非「FTA國家」=> 採「一般標準」
  • 「實質轉型」一般標準：「稅則號別前6碼改變」或「附加價值率 > 35%」
  • 「稅則號別前6碼改變」：加工前加工後貨物，兩者稅則號列前6位碼不同。
  • 「附加價值率 > 35%」：在該國加工所增加之價值占貨物出口價格35%以上。
三種認定基準
實質轉型基準 附加價值率門檻
一般貨物 「稅則前6位碼改變」或「附加價值率＞35%」 ＞35%
低度開發國家 附加價值率＞50% ＞50%
FTA國家 依各協定或授權商定文件認定 依各協定
附加價值率
  • 定義：在該國加工所創造的價值占產品出口價格的百分比。
  • 計算公式：附加價值率 ＝（FOB －CIF）÷ FOB
    • FOB：貨物出口時的離岸價格
    • CIF：進口原料及零件的成本＋保險費＋運費
提示
  • 海洋漁獲看漁船
  • 實質轉型、6碼改變、附加三五
  • 低度開發、第二欄稅、附加五十
  • 附加價值率 ＝（FOB －CIF）÷ FOB

破壞性查驗

題目
  • 進口人A公司申報從緬甸進口二手農用搬運車一部，從B海關海運進口。
  • 該關查緝人員事先自刑事警察局獲得線報，得知可能夾帶毒品。經船舶到港後查緝人員至現場以緝毒犬嗅聞，果有不尋常之反應。
  • 查緝人員在報經該管長官同意後，將該二手農用搬運車支解徹底檢查，不料竟然未查出不法事證，貨物與申報內容相符。
  • 事後經了解，係該搬運車長期在緬甸北部金三角毒品產區作業，雖未有夾帶毒品，但沾染有氣息，導致緝毒犬誤判。
  • 該一遭支解之二手農用搬運車已經無法組合回復原狀，形同廢鐵。
  • 試說明前述案例中查緝程序所應遵守之相關規定為何？A公司之損失應如何填補？
破壞性查驗
  • 實施前提：有「可疑跡證」、「有必要」，經報請「一級單位主管核可」後。
  • 實施後：應於報單或相關文件「註明」破壞貨物之事實。
  • 請求補償：查驗結果「與申報內容相符」者，貨主「得向海關請求補償」。
破壞性查驗補償處理程序
  • 申請要件：經實施破壞性查驗結果「與報單原申報內容相符者」。
  • 海關應主動告知：海關於貨物查驗完成後，結果「符合申請要件者」，應即通知貨主「得向海關請求補償」。 （得通知報關業者後轉知或以書面通知進出口人）
  • 補償金額：依個案事實及受損程度認定。但以受破壞性查驗貨物「申報價格範圍內」為限。 （進口完稅價格或出口離岸價格）
  • 14日內辦結：海關受理申請補償案件，應於14日內辦結並以「書面通知」申請人審核結果 （自收受申請書之翌日起算）
結論
  • 查緝人員實施「破壞性查驗」符合程序要件。
  • 而查緝結果「與申報內容相符」，貨主A公司「得向海關請求補償」。
提示
  • 破壞查驗、可疑跡證、實施必要、一級主管、報單註明
  • 請求補償、申報相符、主動告知、十四日內

報關業設置之資格為何？報關人員在何種情況下應拒絕簽證，並向海關報告？如其違反前述義務時，應負如何之責任？

報關業採「許可制」：先許可、後登記
  • 報關業之設立程序為：向海關申請許可 → 辦理公司登記 → 向海關申請核發「報關業務證照」
申請條件
  • 資本額500萬元以上
  • 負責人應具有三年以上報關實務經驗
  • 員工應有一人以上具有「專責報關人員」之資格
  • 設置電腦及相關連線設備處理報關業務
專責報關人員規範
  • 拒絕造假義務：應「拒絕簽證」並向海關報告之情況：
    1. 意圖作不實簽證 ：委任人或所屬報關業意圖「使其作不實或不當之簽證」者。
    2. 不提供真實資料 ：委任人或所屬報關業故意「不提供真實或必要之資料」者。
    3. 隱瞞欺騙使審核錯誤 ：其他因委任人或所屬報關業之隱瞞或欺騙，致無法作正確之審核簽證者。
    違反罰則：違反「拒絕造假義務」（含「未向海關報告者」）之處罰：
    • 警告或處罰鍰2000 ~ 5000元
    • 並得命其限期改正；屆期未改正者，按次處罰
    • 處罰三次仍未完成改正者，得停止六個月以下之報關審核簽證業務或廢止其登記。
  • 說明義務：海關對專責報關人員「簽證之報單」或其他文件「有疑義」時，得通知專責報關人員到海關說明。
提示
  • 報關業、先許可、後登記
  • 電腦連線、負責3年、1人專責
  • 專責人員、審核簽證、各項申請、說明義務、憑證密碼、禁止共用
  • 拒絕簽證、報告海關、意圖造假、不實資料、隱瞞欺騙

何謂報關業？其執行業務之法令依據如何？

報關業定義
  • 報關業：經營「受託辦理」進出口貨物「報關納稅」等業務之營利事業。
報關業執行業務之法令依據：關稅法明定：
  • 貨物應辦之「報關」、「納稅」等手續，得「委託報關業者辦理」。
  • 報關業者向海關遞送之報單，應經「專責」報關人員「審核簽證」。
報關業採「許可制」：先許可、後登記
  • 報關業之設立程序為：向海關申請許可 → 辦理公司登記 → 向海關申請核發「報關業務證照」
提示
  • 報關業者、受託辦理、報關納稅
  • 關稅法、報關納稅、委託辦理
  • 專責人員、審核簽證、各項申請、說明義務、憑證密碼、禁止共用
  • 拒絕簽證、報告海關、意圖造假、不實資料、隱瞞欺騙

何謂快速報關？在何種情形下不得辦理？

關稅法授權
  • 為「加速通關」，「快遞貨物」、「郵包物品」得於特定場所辦理通關。
  • 為「加速進口貨物通關」，海關得先行徵稅驗放，事後審查。
快遞貨物
下列各款貨物「不得」在快遞貨物專區辦理通關：
  • 關稅法規定「不得進口」之物品
  • 其他法律規定不得出口或禁止輸出之物品
    • 管制品、侵害智慧財產權、生鮮農漁、活動植物、保育動植物及其製品
  • 每件毛重超過70公斤
  • 非密閉貨櫃裝運貨物(海運快遞限制)
郵包物品
下列各款貨物「不適用」郵包物品通關：
  • 關稅法規定「不得進口」之物品
  • 其他法律規定不得出口或禁止輸出之物品
    • 管制品、侵害智慧財產權、生鮮農漁、活動植物、保育動植物及其製品
  • 每件毛重超過30公斤
先行徵稅驗放，事後審查
進口貨物有下列情事之一者，不得先行徵稅驗放。但得「依納稅義務人之申請」，「繳納保證金」後先行驗放，並「限期補辦手續」。屆期未補辦者，沒入其保證金。
  1. 未檢具「減免關稅證明文件」而「能補正」。
  2. 未及申請「輸入許可文件」而「有即時報關提貨之需要」。但以「准許進口類貨物」為限。
  3. 其他海關認為有繳納保證金後先行驗放之必要者。
提示
  • 加速通關、快遞郵包、先稅後審
  • 快遞七十、郵包三十
  • 不得進口、管制侵權、生鮮農漁、活動植物、保育動植
  • 先稅後審、免稅證明、輸入許可、文件不齊、而能補正、繳保證金、限期補辦、屆期未補、沒入保金
