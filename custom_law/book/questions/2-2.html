完稅價格題目

「整套機器及其必須設備，拆散、分裝報運進口者，得按整套機器設備應列之稅則號別徵稅。」請依關稅法與其施行細則說明相關規定與適用範圍。

簡單說
  • 整套機器因太大必須分批進口時，只要「事前向海關證明」並「經核明屬實」：
    • 就可以按整套機器的稅則課稅，而不是按零件分別課稅。
適用情況：整套機器拆散、分裝報運進口者
  • 「整套機器」：包含操作過程中「直接」用於該項機器之「必須設備」。
  • 「分裝報運進口」：進口分為數批或數件報運進口，而非以完整整機方式進口。
    • 例如因體積過大或其他原因而拆散，分批進口。
程序要件：事前申報 + 海關核查屬實
  • 事前申報：應於機器設備進口「放行前」申報。
    • 分批進口時，應於「第一批」進口放行前申報。
  • 檢附文件：
    • 型錄、設計藍圖
    • 說明其「產製物品」及「生產能量」等資訊之相關文件
    • 向國外廠商訂購該項機器設備之「詳細合約」
    • 進口機器設備表一份，分別填列機器設備名稱、規格、單位、數量、單價、總價及詳細用途
  • 海關核查屬實：海關審核後認定「屬實」（確屬整套機器設備）。
效果：經海關核准者，適用整台機器之稅率
  • 經海關核准者，按「整套機器設備應列之稅則號別」徵稅，即適用整台機器之稅率。
  • 但書：所附機件設備以「正常所需數量」為限，「超量」部分各按其應列之稅則號別徵稅（不適用整台機器之稅率）。
未申報者：各按其應列之稅則號別徵稅
  • 若進口人未事前申報，或申報後海關認定不屬整套機器：無法適用整台機器之稅率。
    • 則各批貨物應「各按其應列之稅則號別」分別課稅，即按各零件或組件本身之稅則號別及稅率課徵關稅。
提示
  • 整套機器、分批進口、事前申報、海關核查
  • 放行前、第一批、型錄藍圖、生產說明、詳細用途、訂購合約
  • 操作過程、直接用於、必須設備、機件設備、正常數量

「由數種物品組合而成之貨物，拆散、分裝報運進口者，得按整體貨物應列之稅則號別徵稅。」請依關稅法與其施行細則說明相關規定與適用範圍。

簡單說
  • 組合貨物（非機器）若因故分批進口：
    • 一律按整套組合貨物的稅則課稅，不用按零件分別課稅。
適用情況：由「數種物品組合而成」之貨物，拆散、分裝報運進口者
  • 「由數種物品組合而成」：該貨物本質上為一組或多種物品之組合，共同構成一個完整之商品。
  • 「拆散、分裝報運進口」：該組合貨物因運輸、包裝或其他原因，須拆散為數批或數件報運進口。
原則：按「整體貨物」徵稅
  • 該拆散分裝進口之各批貨物，按「整體貨物」應列之稅則號別及稅率課徵關稅。
  • 無須逐批按其個別組成物品之稅則號別分別課稅。
例外：排除機器設備
  • 「機器拆散分裝進口」另有專門規定（須事前申報經海關核明屬實）。
  • 只要不是機器，就不用申報。直接由海關按「整體貨物」徵稅。
實行細則
  • 定義：申報「進口前」已屬「整體」貨物，經「拆解成組件」裝運進口者。
  • 認定標準：
    1. 同一提貨單：組合物品之名稱與數量，載入「同一提貨單」者。
    2. 數量合理：組合物品之數量於整體貨物正常所需之範圍內。
    3. 每套價值超過整體價值百分之50：組合物品之種類、名稱均為整體貨物之組件，雖其數量不足以裝配成整體貨物，但其每套價值超過整體貨物價值百分之五十者。
提示
  • 數種物品、組合而成、拆散進口、整體課稅、排除機器
  • 同一提單、數量合理、價值過半

運往國外修理、裝配的貨物，該貨物復運進口時的完稅價格應如何核估？

簡單說
  • 出口修理或加工後復運進口：
    • 只針對修理費或加工增值課稅。
    • 須在一年內復運進口（得延長六個月），逾期全額課稅。
適用情況：運往國外修理、裝配或加工之貨物，復運進口者
核估原則：僅就新增價值課稅
  • 修理、裝配：完稅價格 = 修理或裝配所需之費用（不包括運費及保險費）
    • 免費修理者，復運進口免稅（需提出證明）。
    • 費用「無法證明」者，海關得按貨物本身完稅價格「十分之一」認定之。
  • 加工：完稅價格 = 加工後復運進口時之完稅價格 – 原貨出口時「同樣或類似貨物」進口之完稅價格
    • 僅就「加工所增加之價值」課稅。
期間限制：應於一年內復運進口（出口放行之翌日起算）
  • 確保貨物「暫時出口」性質。
得申請延長六個月
  • 須於期限屆滿前提出申請。
  • 須以書面敘明理由。
逾期效果：全額課稅
  • 未於期限內復運進口，則不適用「復運進口」優惠。
  • 應就貨物之「全額價值」課徵關稅（視為一般進口）。
提示
  • 修理加工、復運進口、修理費用、加工增值、無法證明、十分之一
  • 出口放行、一年之內、復運進口、延長六月、逾期效果、全額課稅

運往國外修理、裝配的貨物，該貨物復運進口時報單應載明事項及復運進口期限為何？

簡單說
  • 出口修理或加工後復運進口：
    • 只針對修理費或加工增值課稅。
    • 須在一年內復運進口（得延長六個月），逾期全額課稅。
適用情況：運往國外修理、裝配或加工之貨物，復運進口者
核估原則：僅就新增價值課稅
實行細則
  • 出口及復運進口時：應於出口/進口報單「詳列品名、數量及規格」等，並「聲明」係運往國外修理、裝配或加工。
  • 運往國外修理、裝配：於出口報單載明「應修理或裝配」之「損毀缺失情形」。
  • 運往國外加工：於出口報單載明「加工後」之「物品名稱、規格及數量」。
期間限制：應於一年內復運進口（出口放行之翌日起算）
  • 確保貨物「暫時出口」性質。
得申請延長六個月
  • 須於期限屆滿前提出申請。
  • 須以書面敘明理由。
逾期效果：全額課稅
  • 未於期限內復運進口，則不適用「復運進口」優惠。
  • 應就貨物之「全額價值」課徵關稅（視為一般進口）。
提示
  • 修理加工、復運進口、修理費用、加工增值、無法證明、十分之一
  • 出口放行、一年之內、復運進口、延長六月、逾期效果、全額課稅
  • 報單聲明、係往國外、修理加工
  • 國外修理、出口載明、應修理之、損毀缺失
  • 國外加工、出口載明、加工後之、規格數量

進口貨物之交易價格，買、賣雙方具有特殊關係，致影響交易價格不得作為計算完稅價格之根據。特殊關係所指為何？

「特殊關係」指有下列情形之一：
  • 一方是另一方的董事、經理人、監察人
  • 持有對方5%以上表決權股份（直接或間接都算）
  • 合夥關係
  • 僱傭關係
  • 控制關係（直接或間接都算）
  • 親屬關係（配偶、三親等以內）
「特殊關係」交易價格排除原則
  • 買賣雙方有「特殊關係」時，原則上不能這個交易價格就不能採用，除非「交易價格不受影響」。
「交易價格不受影響」的標準：該價格與海關「已核定」同樣或類似貨物之交易價格「相接近」
  • 意思就是，這個交易價格確實是合理價格，就不能說「特殊關係」影響了價格。
提示
  • 特殊關係、董經監察、表決股份、百分之五、直接間接、控制關係、合夥僱傭、親屬關係、配偶三親
  • 原則排除、不受影響、例外但書、價格合理、已經核定、同樣類似、價格相近

交易價格及完稅價格之意涵?

交易價格：指進口貨物「由輸出國銷售至我國」實付或應付之價格
進口貨物「實付或應付之價格」包括以下費用（應計入完稅價格）：
  1. 買方付的佣金、包裝費。
  2. 買方無償或減價提供給賣方，用於生產或銷售的勞務、原料、工具、設計等。
  3. 權利金。
  4. 運到台灣口岸的運費、裝卸費和保險費等。
完稅價格：計算關稅的「稅基」
  • 關稅計算公式為：完稅價格 x 關稅稅率 = 應納關稅額
完稅價格以交易價格為計算根據
  • 「從價課徵」關稅的進口貨物，其完稅價格以「交易價格」作為計算根據。
客觀可計量原則
  • 計入交易價格之費用（如佣金、權利金、保險費等）需有「客觀、可計量」之資料為依據。
  • 如果沒有「客觀、可計量」的資料，則應放棄交易價格方法，改用次順位方法（同樣貨物之交易價格）核估。
提示
  • 交易價格、銷售我國、實付應付
  • 應該包括、買方支付、佣金包裝、無償減價、提供賣方、勞務原料、工具設計、權利保險、運費裝卸
  • 從價課徵、交易價格、計算根據、客觀計量、次順同樣

從價課徵關稅之進口貨物，其完稅價格之計算不包括那些項目？

「從價課徵」關稅的進口貨物，其完稅價格以「交易價格」作為計算根據。
交易價格：指進口貨物「由輸出國銷售至我國」實付或應付之價格
進口貨物「實付或應付之價格」包括以下費用（應計入完稅價格）：
  1. 買方付的佣金、包裝費。
  2. 買方無償或減價提供給賣方，用於生產或銷售的勞務、原料、工具、設計等。
  3. 權利金。
  4. 運到台灣口岸的運費、裝卸費和保險費等。
實行細則
  • 應計入交易價格之「佣金」：「不包括」買方支付其「代理商」在「國外採購」該進口貨物之報酬。
  • 應計入交易價格之「權利金及報酬」：
    • 指為取得「智慧財產權」（專利權、商標權、著作權）所支付與進口貨物有關之價款。
    • 「不包括」為取得於「國內複製」進口貨物之權利所支付之費用。
提示
  • 佣金不含、買方支付、其代理商、國外採購、貨物報酬
  • 權利報酬、指為取得、智慧財產、所支付之、進口貨物、有關價款
  • 權利報酬、並不包括、為取得於、國內複製、權利費用

進口貨物不能依關稅法第 29 條規定及同樣或類似貨物核定者，應如何核定其完稅價格？

「從價課徵」關稅的進口貨物，其完稅價格估算方式
  • 六種估價方法依序適用：交易價格 → 同樣貨物 → 類似貨物 → 國內銷售價格 → 計算價格 → 合理方法。
國內銷售價格
  • 以貨物在台灣境內「第一次賣出」的價格，「倒扣」利潤、稅費、運費等項目，推算出完稅價格。
  • 納稅義務人得請求「變更順序」，即改為優先適用「計算價格法」。
貨物取樣範圍：該進口貨物、同樣貨物、類似貨物
  • 優先取樣「該進口貨物」，如果沒有就依序取樣「同樣貨物」、「類似貨物」。
取樣時間範圍：系爭貨物進口「前後30天內」
價格取樣計算：取「銷售數量最大」的「單位價格」
  • 銷售數量最大：有好幾筆銷售資料可用時，取交易量最大的那個。
  • 單位價格：換算成單價。
扣除項目：發生在我國的稅費及利潤
  1. 利潤、費用或佣金：銷售該貨物之一般利潤、管銷費用及支付之佣金。
  2. 關稅及其他稅捐：進口時繳納之關稅、營業稅等。
  3. 進口後運費、保險費：貨物進口後在國內運輸、保險、倉儲等費用。
計算價格核估法
  • 以「生產成本 + 正常利潤費用 + 運費保險費」加總起來當作完稅價格。
  • 納稅義務人得請求優先於「國內銷售價格法」適用。
核估方法：到達我國口岸「之前」的所有「成本利潤費用」加總
  1. 生產成本及費用：在出口國生產貨物的直接成本。
  2. 正常利潤與一般費用：由輸出國生產銷售至我國的該貨物、同類貨物之正常利潤與一般費用。
  3. 運費、裝卸費、搬運費及保險費：貨物從輸出國運至我國口岸之運輸及保險費用。
核估邏輯：從生產成本正加
  • 生產成本 ＋ 費用 ＋ 利潤 ＋ 運費保險費
  • 與「國內銷售價格」方法相反——前面是「從售價倒推」，這裡是「從成本正加」。
提示
  • 銷售價格、台灣境內、首次賣出、正常利潤、稅費運保、反向倒扣、請求變更
  • 三十天內、數量最大、單位價格
  • 計算價格、到達之前、生產成本、正常利潤、運保費用、正向加總
