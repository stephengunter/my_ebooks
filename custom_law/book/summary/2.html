海關進口稅則
《海關進口稅則》是專門用來查「貨物編號和對應稅率」的法律
  • 是法律：須經「立法程序」制定公布，即須經立法院審議通過，總統公布，始生效力。
  • 修正程序：財政部會有關機關（如經濟部、農業部等）及學者專家研擬 → 報行政院 → 送立法院審議
  • 主要內容：「貨物名稱、稅則號列、對應稅率」對照表。
稅則號列（或稱「進口稅則」、「稅則編號」）
  • 是貨物的「身分證號碼」對照表，決定這批貨要課多少稅。
  • 一類貨物對應一個稅則編號。從「稅則編號 + 產地」可以查到對應的稅率。
  • 我國稅則號別為8碼。例如：「其他醬油」的稅則號別是 21031090
三欄稅率：依貨物原產地不同，適用不同稅率
欄位 適用對象 稅率高低
第1欄
  • WTO會員國
  • 與我國有互惠待遇的國家
中等（最常見）
第2欄
  • 與我簽訂FTA或經濟合作協定的國家
  • 特定低度開發、開發中國家(LDCS)
最低
第3欄 不適用第1、2欄的國家 最高
如果同一批貨同時符合第1欄和第2欄，適用較低者
範例：
  • 從美國進口工具機 → 美國是WTO會員 → 適用第1欄稅率
  • 從新加坡進口特定貨物 → 台星有經濟合作協議 → 可能適用第2欄較低稅率（若有列明）
  • 從北韓進口貨物 → 不符合第1、2欄條件 → 適用第3欄最高稅率
編碼結構（從國際到國內）
  • 進口稅則的編號不是隨便編的，有嚴格的層級邏輯：
位數 意義 舉例（數控車床）
前2碼 章（大分類） 84章（機器及機械用具）
第3、4碼 節（中分類） 8458（切削金屬用車床）
第5、6碼 目（細分類） 845811（數值控制車床）
第7、8碼 款（最細分類） 84581100（數值控制臥式車床）
第9、10碼 統計號別
第11碼 檢查號
HS Code 是什麼？
  • HS Code（國際商品統一分類代碼）是全球通用的商品身分證號碼。
  • 由世界海關組織（WCO）制定，前 6 碼世界各國完全相同。
  • 比如：「845811」 無論哪一國，看到這6碼就知道是「數值控制車床」。
台灣的8位碼怎麼來的？
  • 前6位照抄國際HS編碼。
  • 第7、8位是台灣根據自己的關稅政策和產業需求，在HS分類基礎上增加的「本國子目」。
