進/出口申報

進口報關 出口報關
申報人 納稅義務人（收貨人） 貨物輸出人
申報期限 15日內（運輸工具進口日之翌日起算） 結關或開駛前（24小時前）
應附文件
  • 進口報單、發票、裝箱單
  • 其他文件：如輸入許可證（管制品）、檢疫證明（農產品）等
  • 出口報單、裝貨單／託運單、裝箱單
  • 輸出許可證：管制品才需要（如戰略性高科技貨品）
預先申報 ✅ 可（進口前） ✅ 可（出口前）
申請錯誤：檢附證明文件向海關申請更正
  • 申請錯誤：報關後發現申報有誤（如稅則號列、數量、價值）。
  • 檢附證明文件：不是想改就改，必須附上證明文件說明理由。
  • 申請更正：海關核准才能更正。
報關文件不齊：得於放行前補附
  • 報關時文件不齊全，可以先報關，只要在海關放行前補齊即可。
  • 舉例：貨物已到港，但輸出許可證還在申請中 => 可以先報關，等許可證下來再補附，海關再放行。
2個月內未補齊文件：退運出口/退關領回
  • 2個月內：自海關通知補送文件隔天起算。
  • 逾期未補：海關責令「限期」退運出口/退關領回。
  • 再不辦理：海關可變賣或銷毀貨物。

轉運/轉口申報

  • 轉運：貨物入境卸貨後，轉送「其他關區」或「同一關區科學園區（四區）」辦理進口通關。
    • 貨物最終要進口，只是換個地方通關。
    • 例如：貨物從國外運來，先在高雄港卸貨，然後轉送到基隆港辦理進口通關
  • 轉口：貨物入境卸存後，辦理轉船（機）出口。
    • 貨物最終不進口，只是路過。
    • 例如：日本的貨櫃到了高雄港，但它最終要賣給越南。貨櫃在高雄港卸下來，換一艘去越南的船，裝上去運走。
    • 要申報：應申報貨物艙單
    • 申報義務人：運輸業者或承攬業者
      • 轉運貨物運送至四區者，得由所屬四區業者申報
    • 應備文件：貨物艙單
    可暫存：貨物可暫存貨棧/貨櫃集散站
    • 需經海關核准，儲存於指定位置。
    受監管：轉運/轉口貨物全程受海關監管
    • 確保貨物於過境期間不致非法流入國內市場。
    • 轉運監管重點：依海關轉運准單指定方式、路線及時限運輸（保稅運貨工具、指定路線、電子封條）。
    • 轉口監管重點：內陸運送應向海關申請派員押運或核准加封電子封條載運。

先行驗放與事後審查

  • 為加速通關，海關可先放貨、後審查——
    • 稅款會在放行後6個月內核定，逾期視為結案。
三種先行驗放機制
  • 一般案件：先行徵稅驗放：海關先依業者申報的內容算稅、收錢，然後放行貨物。
    • 事後審查：放行後，海關回頭仔細審查申報內容是否正確。
    • 6個月內核定：放行隔天起算，6個月內海關要決定是補稅還是退稅。
    • 逾期視為核定：超過6個月沒通知 → 視為已核定，不能再追稅。
      • 例外：如果納稅義務人或關係人已經被海關通知要實施事後稽核，就不受6個月的限制。
  • 稅額無法即時核定：保證金驗放：由納稅義務人申請，繳納保證金後，先行驗放。
    • 無法即時核定：海關沒辦法馬上決定這批貨到底值多少錢（例如價格資料不完整、需要查證）。
    • 納稅義務人申請：由納稅義務人主動申請，並提供審查所需的資料。
    • 繳納保證金：先繳一筆錢（金額由海關估算）作為擔保。
    • 6個月內核定：放行隔天起算，6個月內海關要核定最終稅額。
    • 屆期視為核定：超過6個月沒核定 → 視為依業者申報的金額核定，海關不能再追。
  • 缺件待補正：保證金驗放 + 限期補辦：由納稅義務人申請，繳納保證金後，先行驗放。
    • 缺件待補正：例如：
      • 貨物本來可以免稅，但證明文件還沒拿到。
      • 輸入許可證還沒辦好，但急需提貨。
      • 其他情況，由海關個案認定。
    • 納稅義務人申請：需由納稅義務人主動申請。
    • 繳納保證金：先繳一筆錢（金額由海關估算）作為擔保。
    • 限期補辦：海關會限期補辦手續。
    • 屆期未補辦：保證金沒入。

  • 適用情況：貨物本來可以免稅，但業者「沒有申請保證金驗放」，而是直接把稅繳了。
  • 4個月內：在貨物「放行前，或放行後4個月內」，都可以補申請。
  • 檢具證明文件：拿出免稅證明文件。
  • 申請補正及退稅：申請更正為免稅，並要求退還已繳的關稅。

優質企業認證（AEO）

  • 優質企業認證是海關頒發的「安全信用金牌」——
    • 通過認證的業者可享有：貨物低查驗率、快速通關、按月彙總繳稅等優惠。
    • 出口到有簽署MRA的國家還能享受同等優惠。
兩種認證類型
認證類型 適用對象 核心效益 國際適用性
一般優質企業 符合基本條件的進出口業者 較低抽驗比率、按月彙總繳稅 國內適用
安全認證優質企業（AEO） 符合安全驗證標準的供應鏈業者 最低查驗比率、優先查驗、出口至MRA國家享同等優惠 可與他國相互承認
誰可以申請？
  • 進出口業者（納稅義務人、貨物輸出人）
  • 供應鏈相關業者：包括：
    • 製造業、報關業、承攬業
    • 船務代理業、倉儲業、運輸業（海運、空運、公路運輸）
申請資格
一般優質企業 安全認證優質企業
  • 成立3年以上：最近3年平均每年進出口實績總額達100萬美元以上
    • 符合特定條件者可免受成立滿3年限制
  • 無欠稅欠費：無積欠已確定之稅費及罰鍰
  • 電腦化控管：進出口流程及財務均以電腦化控管
  • 已辦理連線申報：已與海關連線申報，或委託之報關行已連線
除符合一般優質企業條件外，尚須符合：
  • 具償債能力：最近3年總資產＞總負債，且流動資產＞流動負債
  • 3年無重大違章：申請日起回溯3年無以下情況：
    1. 私運
    2. 虛報漏稅額、罰鍰逾新臺幣50萬元
    3. 沒入貨物價值逾新臺幣100萬元
  • 通過安全驗證：符合「優質企業安全審查項目及驗證基準」
  • 配置安全專員：配置2名以上經海關訓練合格的供應鏈安全專員
通關優惠措施
  • 核心優惠：
    • 自行具結：業者以自身信用代替保證金，免繳現金擔保。
    • 先予放行：稅款已有擔保，可以先提領貨物。
    • 稅費按月彙總繳納：每個月結算一次該月的稅費總額，一次繳清，不必逐筆繳稅。
一般優質企業 安全認證優質企業
出口業
  • 較低之抽驗比率
  • 抽中查驗者，或優先查驗
  • 最低文件審查及貨物查驗比率
  • 抽中查驗者，得改為免驗或優先查驗
  • 離岸價格一億元以上者，得免審免驗通關
  • 得申請使用非侵入方式查驗貨物
  • 設立未放行案件處理單一窗口，協助解決通關問題
進口業
  • 較低之抽驗比率
  • 抽中查驗者，得適用簡易查驗
  • 提供擔保先予放行者，得按月彙總繳納稅費
  • 最低文件審查及貨物抽驗比率
  • 抽中查驗者，得適用簡易查驗，並得優先查驗
  • 提供擔保先予放行者，得按月彙總繳納稅費
  • 設立未放行案件處理單一窗口，協助解決通關問題
  • 得申請使用非侵入方式查驗貨物
  • 完稅價格一億元以上者，得免審免驗通關
國際相互承認（MRA）
  • 這是AEO認證的最大附加價值。我國已與以下國家簽署AEO相互承認協議：美國、新加坡、以色列、韓國、澳大利亞、日本、印度、紐西蘭、瓜地馬拉及加拿大。
  • 國內AEO業者貨物出口至上述國家，可享有與該國AEO業者同等的通關優惠——降低查驗比率、快速通關。

稅則號別預先審核

申請人 受理機關
申請階段：向海關申請
  • 申請人：納稅義務人或其代理人。
  • 申請期間：貨物進口前。
  • 應備文件：
    • 申請書：詳填貨物名稱、生產國別、型號、規格、成分、 材質、製程、主要功能、特性、用途、一次或分批進口..等資訊（盡可能詳細的提供貨物相關資料）。
    • 原廠型錄、說明書等相關資料或樣品
補件通知
  • 如收到補件通知，應於10日內完成補件。
  • 有正當理由，得向海關申請延長一次，最長不得逾20日。
向「關務署」申請覆審
  • 不服預審結果，得於貨物進口前向關務署申請覆審。
不服覆審：須等到貨物進口稅則號別核定後，走行政救濟程序 		通知補件：申請人提供之文件資料不全者，書面通知其補件
不受理條件：如有下列情形之一，以書面通知人「不予預先審核」
  • 文件資料不全，申請人未於期限內補件。
  • 假設性或仍在設計中之虛擬性貨物。
  • 與其他尚在「行政救濟審理中」之「稅則號別爭議案件」相同或類似貨物。
  • 廢料或其他經海關認定不適合預先審核之貨物。
海關預審階段：30日內答復
  • 30日內以書面答復。（收到申請或補件齊全之翌日起算）
  • 必要時得延長一次，並於原答復期間屆滿前，將延長之事由書面通知申請人。
    • 延長不得逾30日。例外：複雜案件須洽詢專家意見者，應於120日內答復之。
關務署覆審階段：30日內答復
  • 30日內通知覆審結果。（收到覆審申請書之翌日起算）
  • 必要時得延長一次，並於原答復期間屆滿前，將延長之事由書面通知申請人。
    • 延長不得逾30日。
變更預審結果特別程序
申請人 海關
信賴保護
  • 要件：以下兩要件缺一不可，且納稅義務人須「提出證據」證明：
    1. 已訂定契約並據以進行交易。
    2. 如適用變更後之審核結果，將導致損失。
申請延長適用
  • 前提：納稅義務人符合信賴保護要件。
  • 向海關申請延長適用原預審結果，最多延長90天（收到變更書面通知之翌日起算）。
但書：仍應遵守貨物進口時之相關輸入規定
  • 縱延長稅則號別之適用，若變更後之稅則號別涉及不同輸入規定， 仍應遵守貨物「進口時」之輸入規定，不受預審結果拘束。
  • 例如：原審稅則為「一般腳踏車」，後變更為「電動機動力腳踏車」（大陸產製禁止輸入）， 雖然延長適用原審稅則，仍應遵守「電動機動力腳踏車」之輸入限制。
    • 也就是說，如果該批貨物為中國大陸製，將無法進口。
書面通知並敘明理由
  • 海關應以書面通知申請人並敘明變更理由。

運輸工具通關申報

適用對象：載運客貨之「運輸工具」進出口通關
  • 載運客貨：指實際載運旅客或貨物進出口。
  • 運輸工具：船舶、飛機等交通工具。
  • 進出口通關：指運輸工具進入或離開我國國境時，應踐行之海關申報及查驗程序。
應申報「貨物艙單」、「旅客與服務人員名單」
應申報之文件：
  • 貨物艙單：詳細列出載運的所有貨物明細。
  • 旅客與服務人員名單：載有旅客及服務人員姓名、國籍、證件號碼等資訊之名冊。
  • 其他進出口必備之有關文件：如船舶進口報告單、飛機進口申報書等。
申報義務人：運輸工具負責人或所屬運輸業者
  • 運輸工具負責人：船長、機長，實際管領該運輸工具的人。
  • 運輸工具所屬運輸業者：即經營該運輸工具之航運、空運、鐵路或公路運輸公司。
貨物由「承攬業者」承攬運送者：承攬業者可代為申報
  • 適用前提：貨物是交給「經海關核准登記」的貨運承攬業者承攬運送。
  • 代為申報範圍：貨物艙單及辦理轉運轉口業務。

報關業設置管理辦法
  • 報關業：指經營「受託辦理」進、出口貨物「報關納稅」等業務之營利事業。
報關業採「許可制」：先許可、後登記
  • 報關業之設立程序為：向海關申請許可 → 辦理公司登記 → 向海關申請核發「報關業務證照」
  • 申請條件：
    • 資本額500萬元以上
    • 負責人應具有三年以上報關實務經驗
    • 員工應有一人以上具有「專責報關人員」之資格
    • 設置電腦及相關連線設備處理報關業務
專責報關人員規範
  • 考試及格：須經專責報關人員考試及格。
  • 核發報關證：
    • 執行業務前，應向所在地海關辦理登記並申請核發報關證。
    • 離職時，應向所在地海關申報並繳銷報關證。
  • 審核職責：
    • 審核並「簽證」申報之進出口報單。
    • 審核向海關提出之各項申請文件。
    • 負責向海關提供經其簽證之報單與文件之有關資料。
  • 禁止行為：
    • 容許他人假借其名義執行業務
    • 將供連線申報通關之「專屬憑證或憑證密碼借供他人使用」
    • 明知所申報之報單內容不實或錯誤而不予更正
    • 於空白報單預先簽名、蓋章或類似情事
    • 洩漏客戶所交付之貿易文件內容或工商秘密
    • 要求期約或收受不正當酬金
    • 其他違反關務法規情事
  • 拒絕造假義務：應「拒絕簽證」並向海關報告之情況：專責報關人員遇有下列情事之一者，應拒絕簽證，並向海關報告：
    1. 委任人或所屬報關業意圖「使其作不實或不當之簽證」者。
    2. 委任人或所屬報關業故意「不提供真實或必要之資料」者。
    3. 其他因委任人或所屬報關業之隱瞞或欺騙，致無法作正確之審核簽證者。
    違反罰則：違反「拒絕造假義務」（含「未向海關報告者」）之處罰：
    • 警告或處罰鍰2000 ~ 5000元
    • 並得命其限期改正；屆期未改正者，按次處罰
    • 處罰三次仍未完成改正者，得停止六個月以下之報關審核簽證業務或廢止其登記。
  • 說明義務：海關對專責報關人員簽證之報單或其他文件有疑義時， 得通知專責報關人員到海關說明。

貨物查驗取樣

  • 海關對進口、出口和轉口貨物：可自行決定要不要查驗。
    • 也可以因申請而查驗（如納稅義務人或貨物輸出人為證明貨物品質或規格而申請查驗）。
    • 對低風險貨物或經認證之優質企業貨物，得免查驗。
  • 必要時，海關可以抽取貨物樣品拿去化驗或鑑定。
    • 但只能抽技術上需要的最少數量，不能亂抽。
  • 查驗時所生之費用（如搬移、拆包或開箱、恢復原狀費用）：
    • 由進出口貨物之納稅義務人或貨物輸出人負擔。
    • 轉口貨物則由「負責申報之運輸業者或承攬業者」負擔。
查驗準則
  • 查驗以抽驗為原則。必要時得全部查驗。
  • 查驗方式：人工查驗或儀器查驗。
  • 查驗應會同報關人為之。但有下列情形之一者，不在此限：
    • 儀器查驗。
    • 出口貨物經海關核准船（機）邊驗放。
    • 貨櫃（物）經發現異常須人工查驗：
      • 報單上註明後請主管處理。
      • 必要時海關得會同倉庫或貨櫃集散站業主逕行查驗。
  • 報關人應檢附裝箱單、裝櫃明細表、型錄等供查驗。
  • 查驗地點：貨棧、貨櫃集散站或海關指定地點。
  • 查驗時間：辦公時間內為原則。特殊情形經海關核准者，得於辦公時間外辦理。
  • 人工查驗：
    • 分為簡易、一般、詳細三種方式。
      • 簡易查驗：抽驗一件，必要時得繼續開驗。
      • 一般查驗：開驗箱數百分之5以下為原則。
      • 詳細查驗：開驗箱數百分之10以下為原則。但開驗已達20件並未發現不符者，得免再開驗。
    • 查驗發現有虛報或其他違法時，以全部查驗為原則。
      • 但在繼續查驗中，已查驗部分足以推斷整批貨物之真實內容者，得免予繼續查驗。
  • 破壞性查驗：
    • 實施前提：有可疑跡證、有必要，經報請一級單位主管核可後。
    • 實施後：應於報單或相關文件註明破壞貨物之事實。
    • 請求補償：查驗結果與原申報內容相符者，納稅義務人或貨物輸出人得向海關請求補償。
  • 破壞性查驗補償處理程序：
    • 申請要件：經實施破壞性查驗結果「與報單原申報內容相符者」。
    • 海關應主動告知：海關於貨物查驗完成後，結果「符合申請要件者」，應即通知貨主「得向海關請求補償」。 （得通知報關業者後轉知或以書面通知進出口人）
    • 補償金額：依個案事實及受損程度認定。但以受破壞性查驗貨物「申報價格範圍內」為限。 （進口完稅價格或出口離岸價格）
    • 14日內辦結：海關受理申請補償案件，應於14日內辦結並以「書面通知」申請人審核結果 （自收受申請書之翌日起算）

保稅運貨工具與即時追蹤系統

受海關監管貨物
  • 未經海關放行之進口貨物：尚在通關程序中、待查驗或待補稅之進口貨物。
  • 經海關驗封之出口/轉口貨物：已完成驗關手續但尚未裝船（機）之出口/轉口貨物。
  • 其他應受海關監管之貨物：如轉口貨物、保稅貨物等。
保稅運貨工具
  • 指依規定向海關登記之下列運貨工具：
    1. 保稅卡車：專供國內載運海關監管貨物之卡車。
    2. 保稅貨箱：專供國內裝運海關監管貨物之貨箱。
    3. 駁船：在海運通商口岸內專供駁載海關監管貨物之船舶。
受海關監管貨物在國內運送
  • 適用情況：在國內運送。例如從港口、機場運往保稅倉庫、物流中心或其他海關監管場所。
應事先申請。經海關核准後，以保稅運貨工具運送
  • 海關核准：指定保稅運貨工具與時間、地點、路線等。
  • 以保稅運貨工具運送：凡海關監管貨物，必須以保稅運貨工具運送。
經海關指定之保稅運貨工具，應裝置即時追蹤系統
  • 即時追蹤系統：指物聯網全時監控服務平臺（以下簡稱監控平臺）入口網公告驗證通過之 「車機設備」及「車機封條」。
    • 車機設備應具備定期回傳車輛即時位置座標、速度、方向等訊息至監控平臺之通訊功能。
載運海關監管貨物時，應加封車機封條、維持即時追蹤系統正常運作
  • 車機封條：即電子封條。即時追蹤系統（車機設備 + 車機封條）的一部分。
  • 維持即時追蹤系統正常運作：定期回傳「封條狀態」及「即時位置座標」等訊息至海關監控平臺。
《保稅運貨工具管理辦法》
  • 保稅運貨工具定義：保稅卡車、保稅貨箱、駁船。
  • 保稅運貨工具要求：須具備堅固構造、封閉及加鎖設備。
申請登記
  • 由運貨工具所有人向當地海關申請核准登記。
  • 申請登記為保稅卡車或保稅貨箱之所有人，以交通運輸業或經海關完成登記之 貨櫃集散站、進出口貨棧、保稅倉庫、物流中心、報關業及保稅工廠等業者為限。
  • 經海關勘查符合規定者，准予登記。
  • 核准後10日內繳納保證金完成登記（政府機關免繳）。
  • 登記後發給執照；應每2年辦理複勘及校正。
使用管理
  • 車身/船身應油漆所有人名稱及海關編號；執照應懸掛或隨箱攜帶。
  • 不得任意改變構造及裝置；海關得隨時檢查。
  • 登記後可在其他關區間往返使用，不必另行登記。
  • 裝運監管貨物時，不得同時裝載其他非監管貨物（同一報單者除外）。
  • 貨物有非法提運、遺失、遭竊等短少者，所有人應書面報告並負責補繳進口稅捐。

進出口貨物之暫時儲存與貨棧管理

  • 未完成海關放行手續之進出口貨物，得經海關核准，暫時儲存於貨棧或貨櫃集散站
《海關管理進出口貨棧辦法》 《海關管理貨櫃集散站辦法》
  • 貨棧定義：存儲未完成海關放行手續之進出口、轉運、轉口貨物 。
  • 貨棧分兩種：進口貨棧（含轉運轉口）、出口貨棧。
  • 核准後10日內繳納保證金15萬元（政府機關免繳）
  • 發給貨棧登記證；每2年辦理複勘校正
  • 可實施自主管理（經核准者海關不派員常駐）。
  • 須堅固建築、防盜防火防水通風照明；地磅每年、油量計每2年檢定
  • 危險性貨物應設專用貨棧，須取得主管機關同意文件
  • 進口貨物卸存及放行出口貨物提領：上午6時至下午6時；出口存入及放行進口提領：海關辦公時間內
  • 應設置24小時錄影監控系統，存檔30日以上（必要時延長至90日）。
  • 門禁管制：警衛哨所、倉庫專人管理、放行憑條核對。
  • 提貨出棧應驗憑放行通知、提貨單、轉運准單；提貨單應保存2年。
  • 出口貨物進倉應出具進倉證明；放行後始得出棧裝運；退關貨物應隔離堆置。
  • 應具備存貨簿冊或電腦進倉總簿檔。
  • 公證、抽取貨樣、看樣須請領准單。
  • 存貨應分批分區堆置，標記朝外。
  • 對存棧貨物應善盡保管責任。
  • 集散站應提供關員辦公處所；可實施自主管理（經核准後海關不派員駐站）。
  • 應設置貨櫃集中查驗區域；設置電腦連線設備。
  • 申請登記應備保證金30萬元（AEO15萬元）。
  • 應設置24小時錄影監控系統，存檔30日以上（必要時延長至90日）。
  • 門禁管制：警衛哨所、倉庫專人管理、放行憑條核對。
  • 備具貨櫃及貨物存站紀錄簿冊；海關得隨時檢查。

業者自主管理制度

  • 符合條件的倉儲物流業者，經海關核准後可以「自主管理」。
    • 自己管自己的貨，海關不再派人常駐，改為事後稽核。
適用主體
  • 貨棧、貨櫃集散站
    • 保稅倉庫、物流中心
  • 其他經海關指定之業者（免稅商店）
海關得依職權或申請，核准實施自主管理
  • 依職權：海關主動指定。
  • 依申請：業者主動申請
自主管理範圍
  • 原本須由海關派員在場執行之查驗、監視、加封、核銷等事項。
業者設置「專責人員」之義務
  • 專責人員人數：依現行辦法規定，應置「二名以上」（含一名主管）。
  • 專責人員資格：通過專業訓練取得證書、最近五年內無走私違法紀錄。
  • 專責人員每年應接受在職進修講習，全年累積受訓時數不得低於八小時。
海關「事後監督」權限
  • 海關得對自主管理業者實施定期或不定期之稽核，以確保業者確實依規定辦理自主管理事項。
  • 若發現業者有違規情事，海關得命其限期改正，屆期未改正或情節重大者，得廢止其自主管理之核准。
《貨棧貨櫃集散站保稅倉庫物流中心及海關指定業者實施自主管理辦法》
要點 自主管理條件
  • 適用對象：貨棧、貨櫃集散站、保稅倉庫、物流中心、經海關指定之業者（免稅商店）。
  • 專責人員：2名以上（含主管）。5年內無走私紀錄；每年受訓8小時。
    • 資格不符者職務當然解除；因違規致貨物短少者應調離職務。
  • 違規報告：專責人員發現異常應即向海關報告。
  • 監控設備：24小時錄影，存檔30日以上（必要時延長至90日）。

  • 電腦連線：已設置電腦及相關連線設備
  • 電腦控管：貨櫃（物）進儲、提領、存放位置設有完整電腦控管（大宗裸裝除外）
  • 大門連線：警衛室設電腦連線控管，可供海關線上查核
  • 監控系統：24小時錄影，存檔30日以上（必要時延長至90日）
  • 無欠稅費：無積欠已確定之稅額及罰鍰
  • 三年無重大違規：連續3年無私運或嚴重失竊紀錄（有例外規定）
自主管理事項 異常報告義務
  • 貨棧／貨櫃集散站

    • 核簽運送單、監視退關貨物等
  • 保稅倉庫
    • 巡視倉庫、點驗進倉、查報短溢裝、監視重整、點驗出倉等
  • 物流中心

  • 免稅商店
    • 巡視商店、點驗進儲、加封作業、提貨處管理等
  • 貨棧／貨櫃集散站
    • 貨櫃逾期未進站、失竊調包、封條異常
    • 夾藏、放行貨物與提單不符等
  • 保稅倉庫
    • 封條異常、失竊夾藏、進倉不符、放行不符
    • 不得進儲貨物、放棄貨物等
  • 物流中心
    • 失竊調包、封條異常、夾藏、貨物進出與申報不符
    • 不得進儲貨物、天然災害損毀等
  • 免稅商店
    • 封條異常、失竊夾藏、進出不符、天然災害損毀等

郵包物品通關

  • 通關場所：由郵政機構提供並經海關核准。
  • 重量限制：每件毛重30公斤以下。
  • 價格限制：離岸價格逾等值美幣五千元不適用簡易通關。 => 按一般進出口報單辦理通關。
  • 低價免稅：完稅價格2000元以下，免徵關稅、貨物稅及營業稅（不包括菸酒及實施關稅配額之農產品）。
    • 緊急狀況時，財政部得公告於一定期間內進口之特定物品，不受完稅價格新臺幣2000元內免稅之限制（例如疫情時口罩）。
  • 次數頻繁取消免稅：半年度2000元以下郵包免稅最多6次。第7次起即使低於2000元也要繳稅。
    • 半年度，指每年1~6月及7~12月。
  • 零星物品稅率 5%：適用情形：郵包總值超過免稅額2000元，且包含多項物品，其中每一項物品價格低於2000元。
  • 進口郵包應隨附發票，供海關查核。
    • 未檢附者，海關認有審核必要時，由郵政機構以書面通知收件人檢送。

  • 實施關稅配額之物品。
  • 外貨進口報單（進口報單類別「G1」）適用範圍以外物品。
  • 財政部公告實施特別防衛措施之物品。
  • 依其他法令規定應辦理報關之郵包物品。
  • 離岸價格逾等值美幣五千元。
  • 需申請沖退稅、保稅用。
  • 復運出口案件。
  • 國貨出口報單（出口報單類別「G5」）和外貨復出口報單（出口報單類別「G3」）適用範圍以外。
  • 依相關法規有輸出規定。但有特殊情形經海關公告者，不在此限。
  • 其他依法令應向海關辦理報關之郵包物品。
零星物品稅率 5%
  • 適用情形：郵包物品總值超過免稅額2,000元，且包含多項物品，其中每一項物品價格低於2000元。
    • 「零星物品」的定義：零星＝零零星星、少量多樣。如果同一種商品（同一稅則號別）的完稅價格合計超過2,000元，就不算零星物品了。
  • 適用稅率：海關進口稅則總則五規定之稅率。目前為 5%
舉個例子
  • 例1：進口郵包內含物品：
    1. 3件T恤（不同款式）→ 1,500元
    2. 2條圍巾 → 800元
    3. 1頂帽子 → 600元
    => 合計：2900元（超過免稅額2000元）。但每一種商品都沒超過2,000元 → 屬於零星物品 → 適用優惠稅率 5%
  • 例2：進口郵包內含物品：
    1. 5件同款式 T恤 → 2,500元
    2. 1條圍巾 → 600元
    => 合計：3100元（超過免稅額2000元）。T恤同一種類合計超過2,000元 → 不是零星物品 → 不能適用優惠稅率，要按一般稅率課稅。
次數頻繁取消免稅
  • 半年度2000元以下郵包免稅最多6次。第7次起即使低於2000元也要繳稅。
    • 半年度，指每年1~6月及7~12月。

進口貨物原產地之認定

原產地之認定，依《進口貨物原產地認定標準》辦理
  • 《進口貨物原產地認定標準》由財政部會同經濟部訂定。
  • 核心認定標準：原產地 = 進行完全生產之國家；涉及多國者 = 最終實質轉型之國家。
必要時，得請納稅義務人提供產地證明文件
  • 產地證明文件：出口國政府或經其授權機關發給之原產地證明書、發票、裝貨單等。
  • 納稅義務人負有協力義務，應配合海關要求提供相關文件，以利原產地之認定。
爭議處理：納稅義務人得請求「貨物主管機關」或「專業機構」協助認定
  • 貨物主管機關：如經濟部國際貿易署；專業機構：如工業技術研究院
  • 所需費用由納稅義務人負擔，此為申請人應承擔之程序成本。
《進口貨物原產地認定標準》
  • 認定原則：「完全生產」或「實質轉型」之國家或地區。
  • 實質轉型：「稅則前6位碼改變」或「附加價值率＞35%」（低度開發國家＞50%）。
  • 低度開發國家：指適用海關進口稅則第二欄稅率之特定低度開發國家。
  • FTA國家：與我國簽定貿易協定、協議之國家或地區。
「實質轉型」：三種認定基準
實質轉型基準 附加價值率門檻
一般貨物 「稅則前6位碼改變」或「附加價值率＞35%」 ＞35%
低度開發國家 附加價值率 > 50% ＞50%
FTA國家 依各協定或授權商定文件認定 依各協定
完全生產
  • 定義：貨物的全部生產過程都在同一個國家/地區完成。
  • 包括：礦產品、植物產品、活動物、漁獵產品等。
    • 例：在越南種植的茶葉、在巴拉圭養殖的石斑魚。
  • 特殊情況：海洋漁獵以漁船註冊登記國家為準。
    • 例：中國籍漁船在菲律賓海域所捕撈之漁貨 => 原產地「中國」。
實質轉型
  • 適用情況：貨物非完全生產（涉及多國原材料或加工）。
  • 兩種判斷標準（符合其一即可）：
    1. 稅則號列改變：加工後貨物與原材料，兩者稅則號列前6位碼不同。
    2. 附加價值率＞35%：在該國加工所增加之價值占貨物出口價格35%以上（低度開發國家50%以上）。
  • 簡單作業（分裝、包裝、貼標籤等）不視為實質轉型。
附加價值率
  • 定義：在該國加工所創造的價值占產品出口價格的百分比。
  • 計算公式：附加價值率 ＝（FOB －CIF）÷ FOB
    • FOB：貨物出口時的離岸價格
    • CIF：進口原料及零件的成本＋保險費＋運費
舉個例子
  • 例1：台灣A公司從日本進口布料，在台灣加工製造成衣後出口：
    • 進口布料（C.I.F.）：100萬元
    • 台灣加工成本（人工、設備、利潤等）：120萬元
    • 成衣出口價格（F.O.B.）：220萬元
    • 附加價值率 ＝（220 － 100）÷ 220 ＝ 120 ÷ 220 ≈ 54.5%

  • 海關應以書面通知申請人並敘明變更理由。

貨物安全管控與業者自備封條制度

  • 為防止貨物在運送中被動手腳，海關可上封條。
  • 符合條件的供應鏈業者，可申請用自己的封條來封貨櫃或運貨工具。
海關加封封條之權限
  • 加封對象：保稅運貨工具、經海關核准之運貨工具（如可加封卡車或貨箱）、卸存碼頭之海運貨櫃。
  • 海關得依職權對上開對象加封，無須業者申請。
封條定義：以「單一識別碼」標記，可供海關查證並確保貨物安全之裝置
  • 涵蓋電子封條及機械封條。
業者可申請，經申請海關許可後：使用自備封條
  • 業者經申請海關許可後，得於所定運貨工具或海運貨櫃加封自備封條。
  • 許可對象：
    1. 經海關登記之海運運輸業及海運承攬業：加封所載運之海運貨櫃。
    2. 位於機場管制區外且經核准實施自主管理之航空貨物集散站業：加封自有之保稅運貨工具。
    3. 經核准實施自主管理之物流中心業：加封運出物流中心之海運貨櫃、保稅運貨工具或經海關核准之運貨工具。
    4. 經海關登記之內陸貨櫃集散站業：加封進儲該集散站或自該集散站轉運出站之海運轉口貨櫃。
《業者使用自備封條許可及管理辦法》
  • 封條種類：
    • 機械封條（高保安／一般）
    • 電子封條（被動式／主動式）
      • 主動式具備主動發射信號功能
  • 許可期限：2年，期滿須重新申請或校正。
  • 電子封條：須與海關物聯網全時監控系統相容。
  • 違規處罰：停止1年以下使用 或 廢止許可。
