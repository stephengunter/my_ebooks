通關程序總整理

進/出口申報

進口報關 出口報關
申報人 納稅義務人（收貨人） 貨物輸出人
申報期限 15日內（運輸工具進口日之翌日起算） 結關或開駛前（24小時前）
應附文件
  • 進口報單、發票、裝箱單
  • 其他文件：如輸入許可證（管制品）、檢疫證明（農產品）等
  • 出口報單、裝貨單／託運單、裝箱單
  • 輸出許可證：管制品才需要（如戰略性高科技貨品）
預先申報 ✅ 可（進口前） ✅ 可（出口前）
申請錯誤：檢附證明文件向海關申請更正
  • 申請錯誤：報關後發現申報有誤（如稅則號列、數量、價值）。
  • 檢附證明文件：不是想改就改，必須附上證明文件說明理由。
  • 申請更正：海關核准才能更正。
報關文件不齊：得於放行前補附
  • 報關時文件不齊全，可以先報關，只要在海關放行前補齊即可。
  • 舉例：貨物已到港，但輸出許可證還在申請中 => 可以先報關，等許可證下來再補附，海關再放行。
2個月內未補齊文件：退運出口/退關領回
  • 2個月內：自海關通知補送文件隔天起算。
  • 逾期未補：海關責令「限期」退運出口/退關領回。
  • 再不辦理：海關可變賣或銷毀貨物。

轉運/轉口申報

  • 轉運：貨物入境卸貨後，轉送「其他關區」或「同一關區科學園區（四區）」辦理進口通關。
    • 貨物最終要進口，只是換個地方通關。
    • 例如：貨物從國外運來，先在高雄港卸貨，然後轉送到基隆港辦理進口通關
  • 轉口：貨物入境卸存後，辦理轉船（機）出口。
    • 貨物最終不進口，只是路過。
    • 例如：日本的貨櫃到了高雄港，但它最終要賣給越南。貨櫃在高雄港卸下來，換一艘去越南的船，裝上去運走。
    • 要申報：應申報貨物艙單
    • 申報義務人：運輸業者或承攬業者
      • 轉運貨物運送至四區者，得由所屬四區業者申報
    • 應備文件：貨物艙單
    可暫存：貨物可暫存貨棧/貨櫃集散站
    • 需經海關核准，儲存於指定位置。
    受監管：轉運/轉口貨物全程受海關監管
    • 確保貨物於過境期間不致非法流入國內市場。
    • 轉運監管重點：依海關轉運准單指定方式、路線及時限運輸（保稅運貨工具、指定路線、電子封條）。
    • 轉口監管重點：內陸運送應向海關申請派員押運或核准加封電子封條載運。

先行驗放與事後審查

  • 為加速通關，海關可先放貨、後審查——
    • 稅款會在放行後6個月內核定，逾期視為結案。
三種先行驗放機制
  • 一般案件：先行徵稅驗放：海關先依業者申報的內容算稅、收錢，然後放行貨物。
    • 事後審查：放行後，海關回頭仔細審查申報內容是否正確。
    • 6個月內核定：放行隔天起算，6個月內海關要決定是補稅還是退稅。
    • 逾期視為核定：超過6個月沒通知 → 視為已核定，不能再追稅。
      • 例外：如果納稅義務人或關係人已經被海關通知要實施事後稽核，就不受6個月的限制。
  • 稅額無法即時核定：保證金驗放：由納稅義務人申請，繳納保證金後，先行驗放。
    • 無法即時核定：海關沒辦法馬上決定這批貨到底值多少錢（例如價格資料不完整、需要查證）。
    • 納稅義務人申請：由納稅義務人主動申請，並提供審查所需的資料。
    • 繳納保證金：先繳一筆錢（金額由海關估算）作為擔保。
    • 6個月內核定：放行隔天起算，6個月內海關要核定最終稅額。
    • 屆期視為核定：超過6個月沒核定 → 視為依業者申報的金額核定，海關不能再追。
  • 缺件待補正：保證金驗放 + 限期補辦：由納稅義務人申請，繳納保證金後，先行驗放。
    • 缺件待補正：例如：
      • 貨物本來可以免稅，但證明文件還沒拿到。
      • 輸入許可證還沒辦好，但急需提貨。
      • 其他情況，由海關個案認定。
    • 納稅義務人申請：需由納稅義務人主動申請。
    • 繳納保證金：先繳一筆錢（金額由海關估算）作為擔保。
    • 限期補辦：海關會限期補辦手續。
    • 屆期未補辦：保證金沒入。

符合減免關稅資格：可在4個月內檢具證明文件申請補正及退稅
  • 適用情況：貨物本來可以免稅，但業者「沒有申請保證金驗放」，而是直接把稅繳了。
  • 4個月內：在貨物「放行前，或放行後4個月內」，都可以補申請。
  • 檢具證明文件：拿出免稅證明文件。
  • 申請補正及退稅：申請更正為免稅，並要求退還已繳的關稅。

優質企業認證（AEO）

  • 優質企業認證是海關頒發的「安全信用金牌」——
    • 通過認證的業者可享有：貨物低查驗率、快速通關、按月彙總繳稅等優惠。
    • 出口到有簽署MRA的國家還能享受同等優惠。
兩種認證類型
認證類型 適用對象 核心效益 國際適用性
一般優質企業 符合基本條件的進出口業者 較低抽驗比率、按月彙總繳稅 國內適用
安全認證優質企業（AEO） 符合安全驗證標準的供應鏈業者 最低查驗比率、優先查驗、出口至MRA國家享同等優惠 可與他國相互承認
誰可以申請？
  • 進出口業者（納稅義務人、貨物輸出人）
  • 供應鏈相關業者：包括：
    • 製造業、報關業、承攬業
    • 船務代理業、倉儲業、運輸業（海運、空運、公路運輸）
申請資格
一般優質企業 安全認證優質企業
  • 成立3年以上：最近3年平均每年進出口實績總額達100萬美元以上
    • 符合特定條件者可免受成立滿3年限制
  • 無欠稅欠費：無積欠已確定之稅費及罰鍰
  • 電腦化控管：進出口流程及財務均以電腦化控管
  • 已辦理連線申報：已與海關連線申報，或委託之報關行已連線
除符合一般優質企業條件外，尚須符合：
  • 具償債能力：最近3年總資產＞總負債，且流動資產＞流動負債
  • 3年無重大違章：申請日起回溯3年無以下情況：
    1. 私運
    2. 虛報漏稅額、罰鍰逾新臺幣50萬元
    3. 沒入貨物價值逾新臺幣100萬元
  • 通過安全驗證：符合「優質企業安全審查項目及驗證基準」
  • 配置安全專員：配置2名以上經海關訓練合格的供應鏈安全專員
通關優惠措施
  • 核心優惠：
    • 自行具結：業者以自身信用代替保證金，免繳現金擔保。
    • 先予放行：稅款已有擔保，可以先提領貨物。
    • 稅費按月彙總繳納：每個月結算一次該月的稅費總額，一次繳清，不必逐筆繳稅。
一般優質企業 安全認證優質企業
出口業
  • 較低之抽驗比率
  • 抽中查驗者，或優先查驗
  • 最低文件審查及貨物查驗比率
  • 抽中查驗者，得改為免驗或優先查驗
  • 離岸價格一億元以上者，得免審免驗通關
  • 得申請使用非侵入方式查驗貨物
  • 設立未放行案件處理單一窗口，協助解決通關問題
進口業
  • 較低之抽驗比率
  • 抽中查驗者，得適用簡易查驗
  • 提供擔保先予放行者，得按月彙總繳納稅費
  • 最低文件審查及貨物抽驗比率
  • 抽中查驗者，得適用簡易查驗，並得優先查驗
  • 提供擔保先予放行者，得按月彙總繳納稅費
  • 設立未放行案件處理單一窗口，協助解決通關問題
  • 得申請使用非侵入方式查驗貨物
  • 完稅價格一億元以上者，得免審免驗通關
國際相互承認（MRA）
  • 這是AEO認證的最大附加價值。我國已與以下國家簽署AEO相互承認協議：美國、新加坡、以色列、韓國、澳大利亞、日本、印度、紐西蘭、瓜地馬拉及加拿大。
  • 國內AEO業者貨物出口至上述國家，可享有與該國AEO業者同等的通關優惠——降低查驗比率、快速通關。

稅則號別預先審核

申請人 受理機關
申請階段：向海關申請
  • 申請人：納稅義務人或其代理人。
  • 申請期間：貨物進口前。
  • 應備文件：
    • 申請書：詳填貨物名稱、生產國別、型號、規格、成分、 材質、製程、主要功能、特性、用途、一次或分批進口..等資訊（盡可能詳細的提供貨物相關資料）。
    • 原廠型錄、說明書等相關資料或樣品
補件通知
  • 如收到補件通知，應於10日內完成補件。
  • 有正當理由，得向海關申請延長一次，最長不得逾20日。
向「關務署」申請覆審
  • 不服預審結果，得於貨物進口前向關務署申請覆審。
不服覆審：須等到貨物進口稅則號別核定後，走行政救濟程序 		通知補件：申請人提供之文件資料不全者，書面通知其補件
不受理條件：如有下列情形之一，以書面通知人「不予預先審核」
  • 文件資料不全，申請人未於期限內補件。
  • 假設性或仍在設計中之虛擬性貨物。
  • 與其他尚在「行政救濟審理中」之「稅則號別爭議案件」相同或類似貨物。
  • 廢料或其他經海關認定不適合預先審核之貨物。
海關預審階段：30日內答復
  • 30日內以書面答復。（收到申請或補件齊全之翌日起算）
  • 必要時得延長一次，並於原答復期間屆滿前，將延長之事由書面通知申請人。
    • 延長不得逾30日。例外：複雜案件須洽詢專家意見者，應於120日內答復之。
關務署覆審階段：30日內答復
  • 30日內通知覆審結果。（收到覆審申請書之翌日起算）
  • 必要時得延長一次，並於原答復期間屆滿前，將延長之事由書面通知申請人。
    • 延長不得逾30日。
變更預審結果特別程序
申請人 海關
信賴保護
  • 要件：以下兩要件缺一不可，且納稅義務人須「提出證據」證明：
    1. 已訂定契約並據以進行交易。
    2. 如適用變更後之審核結果，將導致損失。
申請延長適用
  • 前提：納稅義務人符合信賴保護要件。
  • 向海關申請延長適用原預審結果，最多延長90天（收到變更書面通知之翌日起算）。
但書：仍應遵守貨物進口時之相關輸入規定
  • 縱延長稅則號別之適用，若變更後之稅則號別涉及不同輸入規定， 仍應遵守貨物「進口時」之輸入規定，不受預審結果拘束。
  • 例如：原審稅則為「一般腳踏車」，後變更為「電動機動力腳踏車」（大陸產製禁止輸入）， 雖然延長適用原審稅則，仍應遵守「電動機動力腳踏車」之輸入限制。
    • 也就是說，如果該批貨物為中國大陸製，將無法進口。
書面通知並敘明理由
  • 海關應以書面通知申請人並敘明變更理由。

運輸工具通關申報

適用對象：載運客貨之「運輸工具」進出口通關
  • 載運客貨：指實際載運旅客或貨物進出口。
  • 運輸工具：船舶、飛機等交通工具。
  • 進出口通關：指運輸工具進入或離開我國國境時，應踐行之海關申報及查驗程序。
應申報「貨物艙單」、「旅客與服務人員名單」
應申報之文件：
  • 貨物艙單：詳細列出載運的所有貨物明細。
  • 旅客與服務人員名單：載有旅客及服務人員姓名、國籍、證件號碼等資訊之名冊。
  • 其他進出口必備之有關文件：如船舶進口報告單、飛機進口申報書等。
申報義務人：運輸工具負責人或所屬運輸業者
  • 運輸工具負責人：船長、機長，實際管領該運輸工具的人。
  • 運輸工具所屬運輸業者：即經營該運輸工具之航運、空運、鐵路或公路運輸公司。
貨物由「承攬業者」承攬運送者：承攬業者可代為申報
  • 適用前提：貨物是交給「經海關核准登記」的貨運承攬業者承攬運送。
  • 代為申報範圍：貨物艙單及辦理轉運轉口業務。

    • 設置電腦及相關連線設備處理報關業務
專責報關人員規範
  • 考試及格：須經專責報關人員考試及格。
  • 核發報關證：
    • 執行業務前，應向所在地海關辦理登記並申請核發報關證。
    • 離職時，應向所在地海關申報並繳銷報關證。
  • 審核職責：
    • 審核並「簽證」申報之進出口報單。
    • 審核向海關提出之各項申請文件。
    • 負責向海關提供經其簽證之報單與文件之有關資料。
  • 禁止行為：
    • 容許他人假借其名義執行業務
    • 將供連線申報通關之「專屬憑證或憑證密碼借供他人使用」
    • 明知所申報之報單內容不實或錯誤而不予更正
    • 於空白報單預先簽名、蓋章或類似情事
    • 洩漏客戶所交付之貿易文件內容或工商秘密
    • 要求期約或收受不正當酬金
    • 其他違反關務法規情事
  • 拒絕造假義務：應「拒絕簽證」並向海關報告之情況：專責報關人員遇有下列情事之一者，應拒絕簽證，並向海關報告：
    1. 委任人或所屬報關業意圖「使其作不實或不當之簽證」者。
    2. 委任人或所屬報關業故意「不提供真實或必要之資料」者。
    3. 其他因委任人或所屬報關業之隱瞞或欺騙，致無法作正確之審核簽證者。
  • 說明義務：海關對專責報關人員簽證之報單或其他文件有疑義時， 得通知專責報關人員到海關說明。

貨物查驗取樣

  • 海關對進口、出口和轉口貨物：可自行決定要不要查驗。
    • 也可以因申請而查驗（如納稅義務人或貨物輸出人為證明貨物品質或規格而申請查驗）。
    • 對低風險貨物或經認證之優質企業貨物，得免查驗。
  • 必要時，海關可以抽取貨物樣品拿去化驗或鑑定。
    • 但只能抽技術上需要的最少數量，不能亂抽。
  • 查驗時所生之費用（如搬移、拆包或開箱、恢復原狀費用）：
    • 由進出口貨物之納稅義務人或貨物輸出人負擔。
    • 轉口貨物則由「負責申報之運輸業者或承攬業者」負擔。
查驗準則
  • 查驗以抽驗為原則。必要時得全部查驗。
  • 查驗方式：人工查驗或儀器查驗。
  • 查驗應會同報關人為之。但有下列情形之一者，不在此限：
    • 儀器查驗。
    • 出口貨物經海關核准船（機）邊驗放。
    • 貨櫃（物）經發現異常須人工查驗：
      • 報單上註明後請主管處理。
      • 必要時海關得會同倉庫或貨櫃集散站業主逕行查驗。
  • 報關人應檢附裝箱單、裝櫃明細表、型錄等供查驗。
  • 查驗地點：貨棧、貨櫃集散站或海關指定地點。
  • 查驗時間：辦公時間內為原則。特殊情形經海關核准者，得於辦公時間外辦理。
  • 人工查驗：
    • 分為簡易、一般、詳細三種方式。
    • 查驗發現有虛報或其他違法時，以全部查驗為原則。
      • 但在繼續查驗中，已查驗部分足以推斷整批貨物之真實內容者，得免予繼續查驗。
  • 破壞性查驗：
    • 實施前提：有可疑跡證、有必要，經報請一級單位主管核可後。
    • 實施後：應於報單或相關文件註明破壞貨物之事實。
    • 請求補償：查驗結果與原申報內容相符者，納稅義務人或貨物輸出人得向海關請求補償。
