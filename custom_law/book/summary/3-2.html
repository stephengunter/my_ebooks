保稅總整理

保稅倉庫制度

  • 進口貨物先存進海關監管的保稅倉庫，暫免繳稅。
  • 若在期限內「原貨出口」或「重整後出口」，即可免稅。
  • 國產貨亦可納入此保稅體系運作。
進口貨物「提領前」，得向海關申請存入保稅倉庫
  • 「提領前」：即尚未完成通關放行。仍在海關監管下。
  • 「向海關申請」：必須先向海關申請並核准。
  • 「存入保稅倉庫」：將進口貨物存入經登記之保稅倉庫。
在規定存倉期間內，原貨出口或「重整後出口」者，免稅
  • 「規定存倉期間內」：依《保稅倉庫設立及管理辦法》規定， 存倉期限以二年為限，不得延長。
  • 「原貨出口」：未經任何處理，直接復運出口。
  • 「重整後出口」：經整理、分類、裝配等作業後再出口。
  • 「免稅」：法律效果宣示。存入保稅倉庫時為「暫免繳納」，符合條件出口後確定「免稅」效果。
國產保稅貨物與國內重整貨物
「國產保稅貨物」進儲保稅倉庫後，得依規定辦理「除帳」
  • 「國產保稅貨物」：國內生產之保稅貨物（如保稅工廠產品）。
  • 「除帳」：貨物從保稅帳冊中註銷，不再列管。
供重整之「國內貨物」進儲保稅倉庫後，得於出口後辦理「沖退稅」
  • 「供重整之國內貨物進儲保稅倉庫」：國內貨物（非保稅貨物）進儲保稅倉庫進行重整。
  • 「得於出口後辦理沖退稅」：若進儲貨物之進口原料已繳納關稅，重整後出口仍可適用沖退原料關稅之規定。
    • 財政部公告取消退稅之項目除外。
倉庫範圍內之作業
保稅倉庫存倉貨物：「經海關核准」，得於倉庫範圍內「進行重整」
  • 「保稅倉庫存倉貨物」：包括前兩項：「進口貨物」進儲與「國產保稅貨物」進儲。
    • 需為「規定存倉期間內」合法存倉狀態，使得適用。
  • 「經海關核准」：程序要求：申請 + 海關核准。
    • 申請人：貨物所有人或倉單持有人。
      • 申請時應說明：貨物名稱、數量；重整範圍及工作人員名單等。
    • 海關核准：經海關發給准單後，由海關派員駐庫監視辦理重整。
  • 「倉庫範圍內」：重整行為僅可在倉庫範圍內進行。
  • 「進行重整」：重整行為限定為「檢驗、測試、整理、分類、分割、裝配、重裝」。
    • 限制原則：
      • 不得改變原來性質或形狀
      • 不得使用複雜大型機器設備
      • 重整過程中不發生損耗或損耗甚微。
保稅倉庫業者之管理
  • 業者應向所在地海關申請登記及繳納保證金。
  • 詳細規範依財政部訂定之《保稅倉庫設立及管理辦法》。

保稅工廠制度

  • 外銷製造廠經核准為保稅工廠後，進口原料及自用機器設備可免稅。
  • 但產品及免稅原料不得擅自出廠，機器設備五年內轉內銷須補稅。
外銷品製造廠商，得「經海關核准登記」為海關管理保稅工廠
  • 適用主體：以製造外銷品為目的之「製造廠商」。
  • 程序要件：須經海關「核准登記」，始取得保稅工廠資格。
其進口原料存入保稅工廠製造或加工產品外銷者，得免徵關稅
  • 原則：出口外銷，原料免稅。
  • 要件：「原料存入保稅工廠」，進行製造或加工後，產品外銷。
出廠限制
保稅工廠產品及免稅原料：非經海關核准並「按貨品出廠形態」報關繳稅，不得出廠
  • 「出廠」：保稅貨物離開保稅工廠，即「脫離監管」。
    • 例如進入課稅區或其他區域。
  • 管制規定：保稅工廠之產品及免稅原料，均受海關監管，未經核准不得擅自出廠。
  • 若欲出廠（如轉內銷），須經海關核准，並按出廠時之貨品形態報關繳稅。
自用機器免稅
保稅工廠進口自用機器、設備，免徵關稅
  • 自用機器設備免稅：保稅工廠為製造外銷品所需之自用機器、設備，進口時亦免徵關稅，以降低廠商建置生產線之成本。
但自用機器、設備於輸入後五年內輸往課稅區者，應依進口貨品之規定，補繳關稅
五年管制期與補稅規定：
  • 免稅進口之機器設備，須於輸入後受海關監管「五年」。
  • 若於五年內將該機器設備「輸往課稅區」（即轉入國內市場），應依進口貨品之規定補繳關稅。

物流中心制度

  • 物流中心是比保稅倉庫功能更強大的保稅場所，可進行重整及簡單加工。
  • 進口貨在此加工後出口免稅，國內貨亦可沖退稅。
經營保稅貨物倉儲、轉運及配送業務之保稅場所，其業者得向海關申請登記為物流中心
  • 適用主體：已經營保稅貨物「倉儲」、「轉運」及「配送」業務之業者。
  • 程序要件：須向海關「申請登記」，經核准後始取得物流中心資格。
進儲物流中心之貨物，得進行重整及簡單加工
  • 得進行「重整」及「簡單加工」，以因應物流業務需要。較保稅倉庫得進行之行為更為廣泛。
  • 重整：指貨物之整理、分類、分割、裝配、重裝等作業。
  • 簡單加工：指不改變貨物基本特性之輕度加工作業（如貼標籤、改包裝、組合等）
進口貨物存入物流中心，原貨出口或重整及加工後出口者，免稅
  • 進口貨物存入物流中心後，無論係「原貨出口」或經「重整及加工」後出口，均「免徵關稅」。
國內貨物進儲物流中心，得於出口後辦理沖退稅（已公告取消退稅之項目除外）
  • 「國內貨物」：非保稅貨物。若其內含已繳納關稅之進口原料，於出口時得依規定申請「沖退稅」（退還原料關稅）。

免稅商店制度

  • 免稅店的貨物進口時免稅，但只賣給「攜帶出境」的旅客。
  • 旅客必須把貨物攜帶出境才能真正享受免稅優惠。
經營銷售貨物予入出境旅客之業者，得向海關申請登記為免稅商店
  • 適用主體：以「銷售貨物予入出境旅客」為業之業者。
  • 程序要件：須向海關「申請登記」，經核准始取得免稅商店資格。
  • 免稅商店實務上分為「機場、港口免稅商店」（設於管制區內）及「市區免稅商店」（設於市區，須於機場或港口設提貨處）二類。
免稅商店進儲供銷售之保稅貨物，在規定期間內銷售予旅客，原貨攜運出口者，免稅
  • 「進儲供銷售之保稅貨物」：進儲時暫免繳納關稅等稅費。
  • 「在規定期間內銷售」：免稅商店之保稅貨物，其存儲期限以2年為限。屆期仍未售出，應退運出口。
  • 「旅客」：
    • 機場、港口免稅商店：以出境、過境及入境旅客為限。
    • 市區免稅商店：以出境旅客為限。
  • 「原貨攜運出口」：旅客購買後須原封不動攜帶出境，不得在境內使用或轉售。
免稅商店之保稅貨物，應存儲於「專用保稅倉庫」
  • 存儲於「專用保稅倉庫」：免稅商店之保稅貨物須存儲於「專供存儲免稅商店銷售貨物之保稅倉庫」。
  • 實務上為「同一法人自用保稅倉庫」，須領有海關核發之保稅倉庫執照。
二種免稅商店區別
機場/港口免稅商店 市區免稅商店
設置地點
  • 國際機場、港口管制區內。
  • 經海關核准者，並得在市區內設置預售中心。
  • 國際機場或港口鄰近之都市區內，或經海關核准之區域內。
銷貨對象
  • 出境、過境及入境旅客。
  • 需持有護照、旅行證件或外僑居留證。
  • 出境旅客。
  • 需持有護照、旅行證件或外僑居留證。
出境提貨
  • 市區預售中心出售之貨物，比照市區免稅商店規定辦理提貨。
  • 購貨人於出境時，向機場或港口提貨處提貨。
  • 監管海關得隨時派員查核。
收款原則
  • 以收外幣為原則。
  • 臺幣可以收，但有限額。（中央銀行公告限額）
  • 臺幣外幣都能收。
  • 找零以新臺幣為限。

誤裝、溢卸貨物之退運或轉運出口

  • 錯運或多運來的貨物，須在15天內申請核准，90天內退運或轉運。
  • 來不及者可申請存入保稅倉庫；逾期未處理者，海關得變賣處理。
適用情況：進口貨物報關前，因誤裝、溢卸或其他特殊原因須退運或轉運出口者
  • 「報關前」：限於貨物尚未完成申報（即尚未填具進口報單）之狀態。
  • 「誤裝」：裝船錯誤；「溢卸」：多卸貨物
  • 「退運或轉運出口」：不進口，將貨物運出。
申請核准：應於15日內向海關申請核准
  • 「15日內」：自「運輸工具進口日」之翌日起算。
  • 「海關申請核准」：須向海關檢具相關證明文件（如船公司證明、裝貨單、提單等），敘明退運或轉運之事由。
退運期限：90日內原貨退運或轉運出口
  • 「90日內」：自「運輸工具進口日」之翌日起算。
  • 「退運」：將貨物原路運回出口國。
  • 「轉運出口」：將貨物轉運至其他國家（非出口國）。
因故不及辦理者：應於期限屆滿前，向海關申請存儲於保稅倉庫
  • 若因故無法於90日內退運或轉運，須於90日「屆滿前」向海關申請。
  • 存入「保稅倉庫」，暫免繳關稅，並得於保稅倉庫內續行處理。
不依前項規定辦理者：準用「逾期不報關」變賣程序
  • 「不依前項規定辦理者」：未於15日內申請、或未於90日內退運轉運出口、或未於期限屆滿前申請存入保稅倉庫。
  • 準用「逾期不報關」變賣程序：變賣所得價款，扣除應納稅費及費用後，如有餘款，由海關暫代保管。 納稅義務人得於五年內申請發還，逾期繳歸國庫。

核心概念

  • 保稅 ＝「暫免」關稅：貨物處於「保稅」狀態。
  • 海關監管：保稅貨物全程處於海關監管下。
    • 相關業者進行倉儲、加工、轉運或銷售。
    • 最終出口 => 免稅（加工原料「沖銷」）
    • 流入國內市場 => 補稅（視同一般進口）
名詞定義
  • 「重整」：
    • 包含：檢驗、整理、分類、分割、裝配、重裝。
    • 重點強調與「加工」、「製造」的區隔。
    • 「重整」的限制：
      1. 不得改變原來之性質或形狀。
      2. 重整過程中不發生損耗或損耗甚微。
      3. 不得使用複雜大型機器設備。
  • 「貨主」：
    • 規定原文為「貨物所有人或倉單持有人」。即實際上的「貨主」。
    • 以下用「貨主」指代「貨物所有人或倉單持有人」。
  • 「需核准」：
    • 保稅貨物被海關監管，凡改變貨物狀態都必須「事先申請，經海關核准」。
    • 以下用「需核准」指代「申請海關核准」。
  • 「具備電腦連線處理通關業務能力」：
    • 原文：設置電腦及相關連線設備，能以電子資料傳輸方式處理貨物通關、帳務處理及貨物控管等作業（即：能正常使用關港貿單一窗口辦理通關業務）。
    • 重點在要求業者必須配合使用關港貿單一窗口辦理相關業務。
    • 以下用「具備電腦連線處理通關業務能力」指代此一要求。
  • 「具備24小時連線監視系統」：
    • 原文：具備提供海關隨時調閱查核功能、二十四小時連續錄影及存檔三十日以上之監視系統。
    • 重點在海關能隨時查看監控，24小時不中斷、存檔30日以上。
    • 以下用「具備24小時連線監視系統」指代此一要求。
  • 「盤虧」：
    • 指庫存盤點後，實際貨物比帳面少。
    • 原則上須說明短少原因、補繳進口稅費。
  • 「盤盈」：
    • 指庫存盤點後，實際貨物比帳面多。
    • 原則上須說明多出原因、經海關查明屬實後調整帳面。

  • 保稅貨物應存儲於專屬自用保稅倉庫
  • 保稅貨物存儲以2年（得延長一年）為限。屆期仍未售出，應退運出口或辦理補稅銷帳
  • 銷貨對象：
    • 機場/港口免稅商店：出境、過境及入境旅客
    • 市區免稅商店：出境旅客（出境時，向機場或港口提貨處提貨）
共通原則
  • 出口：免稅
    • 保稅貨物運往國外，免徵關稅，原保稅帳冊辦理沖銷（保稅貨物除帳）。
  • 內銷：補稅
    • 保稅貨物進入課稅區（國內市場），補徵關稅。
    • 按出倉／出廠／銷售時之形態及價格課稅。
  • 轉儲／移運：繼續保稅
    • 保稅貨物在不同保稅場所間移動，稅務狀態不變（繼續保稅）。
    • 須經海關核准，加封或押運，填具運送單。

共通原則
  • 執照每2年校正一次。（免稅商店3年）
