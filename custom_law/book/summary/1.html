總則總整理

納稅義務人

關稅納稅義務人為收貨人、提貨單或貨物持有人
  • 原則：有「收貨人」就找收貨人 → 收貨人找不到／搞不定，就抓「提貨單持有人」 → 再不行，誰「拿著貨」就找誰。
順位 身分 說明
① 收貨人 提單上寫的「貨物受領人」（Consignee）
② 提貨單持有人 拿著提貨單、有權去領貨的人
  • 例：A把貨賣給C，並把提貨單背書轉讓給C => C就是提貨單持有人
③ 貨物持有人 拿著提貨單、有權去領貨的人
  • 例：貨物在D的倉庫被查到，D說不是他的 => D是「貨物持有人」=> D是納稅義務人

未稅貨物短少之補繳責任

誰弄丟，誰負責（補繳稅費）
  • 短少原因：非法提運、遺失、遭竊或其他原因（基本上，不管什麼原因）
  • 補繳稅費：由弄丟業者負責補繳短少之進口稅費
責任跟著「管領人」走
情況1.「保稅運貨工具」載運之貨物短少：由運輸業者負責
  • 短少發生於保稅運貨工具運送保稅貨物過程中。由運輸業者負責
情況2.在「保稅場所」短少：由保稅場所業者負責
  • 「保稅場所」：貨棧、貨櫃集散站、保稅倉庫、物流中心、免稅商店
  • 短少發生於保稅貨物儲存於保稅場所階段。由保稅場所業者負責
情況3.運輸單獨由承攬業者「承攬運送」：由承攬業者負責
  • 指進口未稅貨物之陸上運輸，由承攬業者「單獨承攬」運送
    • 即非由運輸業者自行運送
  • 則該承攬業者為實際「管領人」，應負短少責任

海關進口稅則

《海關進口稅則》是專門用來查「貨物編號和對應稅率」的法律
  • 是法律：須經「立法程序」制定公布，即須經立法院審議通過，總統公布，始生效力。
  • 修正程序：財政部會有關機關（如經濟部、農業部等）及學者專家研擬 → 報行政院 → 送立法院審議
  • 主要內容：「稅則」的集合。
    • 一條稅則代表一類貨物。
    • 稅則內容：稅則號別、貨名、對應稅率、輸入/輸出規定等資訊。
稅則範例
稅則號別 貨名 第1欄稅率 第2欄稅率 第3欄稅率
21031090 其他醬油 15% 12%（GT）/ 13.5%（NI）/ 0%（PA）/ 14%（SV）/ 0%（LDCs） 25%

欄位 適用對象 稅率高低
第1欄
  • WTO會員國
  • 與我國有互惠待遇的國家
中等（最常見）
第2欄
  • 與我簽訂FTA或經濟合作協定的國家
  • 特定低度開發、開發中國家(LDCS)

第3欄 不適用第1、2欄的國家 最高

範例：
  • 從美國進口工具機 → 美國是WTO會員 → 適用第1欄稅率
  • 從新加坡進口特定貨物 → 台星有經濟合作協議 → 可能適用第2欄較低稅率（若有列明）
  • 從北韓進口貨物 → 不符合第1、2欄條件 → 適用第3欄最高稅率
稅則號別（或稱「稅則編號」、「稅則號列」）
  • 是貨物的「身分證號碼」對照表，決定這批貨要課多少稅。
  • 一類貨物對應一個稅則編號。從「稅則編號 + 產地」可以查到對應的稅率。
  • 我國稅則號別為8碼。例如：「其他醬油」的稅則號別是 21031090
編碼結構（從國際到國內）
  • 稅則號別不是隨便編的，有嚴格的層級邏輯：

前2碼 章（大分類） 84章（機器及機械用具）
第3、4碼 節（中分類） 8458（切削金屬用車床）
第5、6碼 目（細分類） 845811（數值控制車床）
第7、8碼 款（最細分類） 84581100（數值控制臥式車床）
第9、10碼 統計號別
第11碼 檢查號
HS Code 是什麼？
  • HS Code（國際商品統一分類代碼）是全球通用的商品身分證號碼。
  • 由世界海關組織（WCO）制定，前 6 碼世界各國完全相同。
  • 比如：「845811」 無論哪一國，看到這6碼就知道是「數值控制車床」。
台灣的8位碼怎麼來的？
  • 前6位照抄國際HS編碼。
  • 第7、8位是我國依自身需求，在HS分類基礎上增加的「本國子目」。

關稅配額制度

  • 關稅配額，就是政府對特定進口貨物設定一個數量上限：
    • 數量內適用配額內稅率，超過適用配額外稅率。
    • 白話：上限內用便宜的稅率，超過上限就用貴的稅率。
  • 目的：調節進口量並保護國內產業。
例如：政府說「香蕉可以進口，前13,338噸只課12.5%的稅，超過的每噸課100%的稅」。
配額數量 13,338公噸
配額內稅率 12.5%
配額外稅率 100%
差多少 配額外稅率是配額內的8倍
關稅配額的主管機關：財政部
  • 《關稅配額實施辦法》由財政部會同有關機關（經濟部、農業部等）擬訂，報請行政院核定之。
配額核配：財政部委託「台灣銀行」辦理
  • 台灣銀行實際負責「配額核配」並「核發配額證」。
  • 廠商配額應向台灣銀行申請。
我國目前實施關稅配額的貨品
  • 依據WTO會員協議：現有16項農產品實施關稅配額（椰子、大蒜等）。
  • 依各國自貿協定：例如台巴自由貿易協定（雞肉、鯖魚等）。

《關稅配額實施辦法》

核配方式一：先到先配
  • 按進口日先後順序自動核配（先搶先贏）。
  • 無須事先申請。
核配方式二：事先核配
  • 提出申請：廠商須在公告期間內申請，由台灣銀行依「核配方法」決定分配。
  • 核配方法：（由台灣銀行決定，採行以下任一種）
    1. 先申請先分配
    2. 按進口實績核配
    3. 標售進口權利
    4. 抽籤
  • 核配證明：獲配權利人應繳納履約保證金或權利金，繳納後核發關稅配額證明書。
  • 配額轉讓：得於證明書「有效期限內」全部或部分轉讓。
轉讓申請人 受理機關
限於有效期限內
  • 有效期限內：以配額證明書為準
  • 限於「事先核配」配額：只有「事先核配」配額有證明書跟有效期限
聯名填具申請書
  • 應由權利人及受讓人聯名填具關稅配額申請書
檢附下列文件
  1. 原關稅配額證明書
  2. 配額轉讓同意書（雙方簽署）
  3. 履約保證金移轉同意書（雙方簽署）
向原核配之機關辦理
  • 即台灣銀行
按轉讓數量比例辦理「履約保證金移轉」手續
  • 例如轉讓40%的配額，保證金也移轉40%過去
得重新核發關稅配額證明書
  • 證明書之有效期限，同原關稅配額證明書所載

保密義務與例外

關務人員對於各項報關資料，應嚴守秘密
  • 「各項報關資料」：納稅義務人、貨物輸出人向海關所提供之各項報關資料
    • 包括進/出口報單、發票、裝貨單、提貨單、產地證明、價格資料、交易對象等一切相關資訊
  • 「應嚴守秘密」：不得以任何方式（口頭、書面、電子傳輸等）將報關資料洩漏予無權知悉之人
違者應予處分。涉有觸犯刑法規定者，並應移送偵查
  • 行政責任：依公務員懲戒法或相關人事法規予以處分
  • 刑事責任：涉犯刑法（如：公務員洩漏國防以外秘密罪）者，移送檢察機關偵查
但對下列各款人員及機關提供者，不在此限：
  • 納稅義務人/貨物輸出人
    • 包括本人、繼承人、代理人、辯護人
  • 海關、稅捐稽徵機關
  • 監察機關
  • 受理有關關務訴願、訴訟機關
  • 依法從事調查關務案件之機關（如法務部調查局、廉政署等）
  • 其他依法得向海關要求提供報關資料之機關或人員
  • 經財政部核定之機關或人員
可提供「去識別化」資料給政府機關做「統計用途」
  • 「去識別化」：不洩漏納稅義務人、貨物輸出人之姓名或名稱
接收資料之機關人員，亦負保密義務
  • 接收資料之機關人員，如有洩漏情事，準用對關務人員洩漏秘密之規定

事後稽核制度

三個核心時限（自「放行」翌日起算）
時限 要做什麼 錯過會怎樣
6個月內 海關須通知業者要實施事後稽核 沒通知 → 不能再稽核
2年內 2年「調查期間」，海關須於此期間內完成稽核程序 超過2年 → 不能再查
3年內 海關須核定退稅或補稅 超過3年 → 補稅處分無效
稽核對象：納稅義務人、貨物輸出人或其「關係人」
  • 關係人：涵蓋所有參與通關流程之業者及個人
    • 包括報關業、運輸業、承攬業、倉儲業、快遞業及其他企業、團體或個人
海關有合理調查權，被調查人不得規避、妨礙或拒絕
  • 合理：為調查證據之必要
  • 調查權：
    • 要求提供文件：不限於書面，亦包含電腦檔案及資料庫
    • 通知被調查人至海關備詢
    • 至被調查人營業處所實地查核
    • 請求相關機關及機構提供資料：例如向稅捐機關、金融機構調取交易資料
  • 被調查人不得規避、妨礙或拒絕。違者得處罰：
    • 罰鍰3千 ~ 3萬
    • 限期配合、得按次處罰
《海關事後稽核實施辦法》
通知書應記載事項 通知後的作業程序
  • 事由及法令依據
  • 被稽核人基本資料
  • 稽核期日及場所
  • 應備妥之資料
  • 得委任代理人
  • 拒絕稽核之處理
  • 稽核機關
  • 召開稽核會議：必要時召集相關人員及被稽核人參加
  • 填答問卷：視案件需要請被稽核人填寫。
  • 至場所調查：
    • 稽核人員不得少於2人
    • 應出示稽查證
    • 製作談話紀錄並請被稽核人簽認
  • 文件發還：提供之文件資料，應於提送齊全之翌日起14日內發還；特殊情形可延長
  • 製作稽核報告：查案結束後繕具稽核報告
向「金融機構」調取資料時，先請被稽核人提供「承諾書」同意之
  • 若不同意：敘明案由及理由，逐案報經財政部核准後，始得向金融機構調取資料
結案處理
稽核結果 處理方式
有應補稅費 依規定辦理補徵
有應退稅費 依規定辦理退還
違反關稅法／緝私條例 依規定論處（罰鍰、沒入等）
違反其他法令 移請有關單位處理（如逃漏營業稅 → 移國稅局）
不得洩漏商業機密、不得侵犯合法權益

通關自動化

  • 貨物通關自動化：用電腦連線取代人工紙本作業的通關制度
    • 它是制度：是海關推動通關現代化的政策與法律架構
    • 法律授權：關稅法賦予法律效力與強制力
    • 核心效力：電腦連線申報，經海關電腦記錄者，與紙本申報具同等法律效力
  • 白話說：以前報關要填紙本、送文件、人工審核
    • 現在直接在電腦上傳資料，海關系統自動接收、自動比對、自動篩選
    • 整個過程以電子化、標準化、系統化方式進行
核心內涵
  • 申報方式：透過電腦連線或電子資料傳輸辦理，取代紙本申報
  • 法律效力：經海關電腦「記錄有案」者，視為已依法辦理或提出
  • 通關方式：由海關「專家系統」篩選為3種通關方式：
    • C1（免審免驗通關）
    • C2（文件審核通關）
    • C3（貨物查驗通關）
  • 貨物管控：以電子封條、衛星定位等技術輔助監管
  • 稅費作業：電腦自動核算稅費、線上繳納
通關自動化的三大支柱
  • 法律效力：電腦申報與紙本申報同等有效
  • 強制連線：海關得要求通關相關業者全面電腦連線
  • 電子送達：海關之核定、處分、通知得以電子方式送達
通關自動化的效益
  • 加速通關：C1案件秒放，大幅縮短通關時間
  • 降低成本：減少紙本文件、人工遞送、倉儲等成本
  • 提升正確性：電腦比對降低人為錯誤
  • 強化風險管理：電腦自動篩選高風險貨物，精準查緝
  • 透明化：業者可即時查詢通關狀態

關港貿單一窗口

  • 關港貿單一窗口：是進出口通關的「一站式線上櫃台」
    • 辦理通關的線上櫃台：報關人透過這個平台，向海關申報進出口貨物資料
    • 整合海關、航港、貿易簽審、檢驗、檢疫等機關。一次申辦，多機關同步處理
  • 白話說：以前報關要跑好多地方、交好多紙本文件。現在全部整合到一個網站上
    • 進口商、報關行、運輸業者、海關、簽審機關都在同一個平台上作業
    • 只要上傳一次資料，海關和相關機關就能同步處理，不用重複送件
法律效力：數位申報＝紙本申報
  • 經由關港貿單一窗口連線申報的報單，其效力與書面文件相同
  • 海關在電腦系統裡記錄的資料，在法律上等同於收到你的書面文件
一次申辦，多機關同步處理
  • 關港貿單一窗口不只是給海關用的，經濟部（貿易簽審）、農業部（檢疫）、標準檢驗局（檢驗）、航港局（航港）…… 所有跟進出口有關的機關，都整合到同一個平台上
  • 只要上傳一次資料，海關和相關機關就能同步處理，不用重複送件
業者「必須」使用
  • 海關有權強制要求通關相關業者，全部改用電腦連線作業，不能再走紙本
海關的「處分」也可以用電子方式送達
  • 以前海關的稅單、處分書、通知函，都要郵寄掛號給你
  • 現在海關可以直接在系統裡發送，電腦記錄存證就算送達了
  • 你在系統裡看到核定通知的那一刻，在法律上等同於你已經收到紙本公文
通關網路業者須經財政部許可
  • 提供通關網路服務的公司（如關貿網路），不是隨便誰都能做的，必須經過財政部許可才能經營
保密義務
  • 海關人員透過單一窗口看到的進出口資料（如價格、交易對象、貨物品項），不能對外洩漏
它可以做什麼？（功能總覽）
  • 線上報關：進出口人／報關行透過平台送出報單
  • 通關狀態查詢：查詢貨物目前在哪個階段（收單、查驗、放行）
  • 主動通知服務：設定後，海關主動發送「放行通知」、「查驗通知」、「應補辦事項通知」到Email或APP
  • 稅費繳納：線上查詢稅額並繳納
  • 免證查詢：民眾可免登入查詢貨物通關紀錄（防詐騙用）

關稅擔保及保證金

擔保或保證金，得以下列方式為之：
  • 現金
  • 公債
  • 定期存單（銀行或信用合作社）
  • 信託憑證（信託投資公司一年以上普通信託憑證）
  • 授信機構之保證
    • 由銀行等授信機構出具「保證書」，承諾於納稅義務人未履行義務時，由該機構代為清償
    • 無須設定抵押權或質權，程序較簡便
    • 實務上多採此方式，由銀行開立擔保信用狀或保證函
  • 其他經財政部核准，「易於變價及保管」，且「無產權糾紛」之財產
除「現金」及「授信機構之保證」外，應依法設定抵押權或質權於海關
  • 抵押權：適用於不動產
  • 質權：適用於動產、有價證券、權利

關稅優先清償義務

法人解散清算時，應優先清償關稅債務
  • 適用對象：法人（或合夥、非法人團體）
  • 適用情形：因解散而進入清算程序
  • 清償義務：應優先清償關稅債務，再分配賸餘財產
    • 強調關稅債務較一般債務之「優先權」。必須先清償完畢後才能分配賸餘財產
    • 「關稅債務」：包括關稅、滯納金、滯報費、利息、罰鍰、應追繳之貨價
    • 清償順序：關稅 → 滯納金 → 滯報費 → 利息 → 罰鍰 → 應追繳之貨價
違反效果：由「清算人」負繳納義務
  • 違反：即清算人未將關稅債務繳清，就將賸餘財產分配
  • 清算人：負責執行清算事務之人
  • 負繳納義務：應由清算人負責繳納未清償之款項。
    • 此為「法定代償責任」，無須訴訟，海關得逕對清算人發單課徵

關稅等款項之徵收與執行期間

原則：五年徵收期間內徵起。五年內未經徵起者，不再徵收
  • 五年徵收期間：
    • 一般情況：自處分「確定」之翌日起算
    • 分期繳納：自「分期應繳日」之翌日起算
  • 適用範圍：關稅、滯納金、滯報費、利息、罰鍰、應追繳之貨價
    • 即依《關稅法》處分所生之一切「金錢給付義務」
中斷事由：移送執行、聲明參與分配、申報債權
  • 移送執行：依關稅法規定，欠稅案件屆期未繳納者，移送強制執行
  • 聲明參與分配：指於民事強制執行程序中，就債務人財產聲明參與分配
  • 申報債權：指於破產程序中向破產管理人申報債權
  • 凡五年期間屆滿前有以上積極追徵行為：
    1. 時效中斷，不發生「不再徵收」之效果
    2. 再加五年時間來「開始執行」（第2個五年）
移送執行者，應於徵收期屆滿後五年內「開始執行」。五年內未經執行者，不再執行
  • 適用情況：徵收期間屆滿前已移送執行者
  • 五年內：自「徵收期間屆滿」之翌日起（第2個五年）
  • 「開始執行」：如已發動扣款、查封等實際「執行行為」
  • 凡徵收期間屆滿後五年（第2個五年）內有「開始執行」：
    1. 時效中斷，不發生「不再執行」之效果
    2. 再加五年時間來「執行終結」（第3個五年）
執行案件必須在「第3個五年」內終結。如未執行終結，不得再執行
  • 第1個五年：徵收期間（處分確定後5年）
  • 第2個五年：執行期間（徵收期間屆滿後5年）
  • 第3個五年：執行終結期間（徵收期間屆滿後5年 + 5年 = 處分確定後15年）

絕對不得進口物品

下列物品，不得進口
  • 「絕對禁止」進口，無論數量多寡、用途為何，均不得進口
一、偽造或變造之貨幣、有價證券及印製偽幣印模
  • 如偽鈔、假股票、印製假鈔的模板
二、侵害專利權、商標權及著作權之物品
  • 如仿冒包包、盜版光碟、未經授權的專利產品
三、法律規定不得進口或禁止輸入之物品
例如：
  • 毒品、槍砲、彈藥、未經檢疫動植物
  • 保育類野生動物及其產製品（《野生動物保育法》）
  • 未經核准之藥品（《藥事法》）
違反效果
  1. 是否有「申報」?
    • 有：如涉及虛報逃避管制，依《海關緝私條例》處置。
    • 沒有：涉及私運。依《海關緝私條例》處置。
  2. 查獲的物品是哪一款?
    • 偽造貨幣：沒入 + 移送刑事偵查。
    • 侵權物品：沒入 + 貨價1~3倍罰鍰。
    • 管制物品：如涉及虛報逃避管制，依《海關緝私條例》處置。
