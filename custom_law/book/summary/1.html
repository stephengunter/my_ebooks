總則總整理

海關進口稅則
《海關進口稅則》是專門用來查「貨物編號和對應稅率」的法律
  • 是法律：須經「立法程序」制定公布，即須經立法院審議通過，總統公布，始生效力。
  • 修正程序：財政部會有關機關（如經濟部、農業部等）及學者專家研擬 → 報行政院 → 送立法院審議
  • 主要內容：「稅則」的集合。
    • 一條稅則代表一類貨物。
    • 稅則內容：稅則號別、貨名、對應稅率、輸入/輸出規定等資訊。

範例：
  • 從美國進口工具機 → 美國是WTO會員 → 適用第1欄稅率
  • 從新加坡進口特定貨物 → 台星有經濟合作協議 → 可能適用第2欄較低稅率（若有列明）
  • 從北韓進口貨物 → 不符合第1、2欄條件 → 適用第3欄最高稅率
稅則號別（或稱「稅則編號」、「稅則號列」）
  • 是貨物的「身分證號碼」對照表，決定這批貨要課多少稅。
  • 一類貨物對應一個稅則編號。從「稅則編號 + 產地」可以查到對應的稅率。
  • 我國稅則號別為8碼。例如：「其他醬油」的稅則號別是 21031090
編碼結構（從國際到國內）
  • 稅則號別不是隨便編的，有嚴格的層級邏輯：

HS Code 是什麼？
  • HS Code（國際商品統一分類代碼）是全球通用的商品身分證號碼。
  • 由世界海關組織（WCO）制定，前 6 碼世界各國完全相同。
  • 比如：「845811」 無論哪一國，看到這6碼就知道是「數值控制車床」。
台灣的8位碼怎麼來的？
  • 前6位照抄國際HS編碼。
  • 第7、8位是我國依自身需求，在HS分類基礎上增加的「本國子目」。
關稅配額制度
  • 關稅配額，就是政府對特定進口貨物設定一個數量上限：
    • 數量內適用配額內稅率，超過適用配額外稅率。
    • 白話：上限內用便宜的稅率，超過上限就用貴的稅率。
  • 目的：調節進口量並保護國內產業。
例如：政府說「香蕉可以進口，前13,338噸只課12.5%的稅，超過的每噸課100%的稅」。
配額數量 13,338公噸
配額內稅率 12.5%
配額外稅率 100%
差多少 配額外稅率是配額內的8倍
關稅配額的主管機關：財政部
  • 《關稅配額實施辦法》由財政部會同有關機關（經濟部、農業部等）擬訂，報請行政院核定之。
配額核配：財政部委託「台灣銀行」辦理
  • 台灣銀行實際負責「配額核配」並「核發配額證」。
  • 廠商配額應向台灣銀行申請。
我國目前實施關稅配額的貨品
  • 依據WTO會員協議：現有16項農產品實施關稅配額（椰子、大蒜等）。
  • 依各國自貿協定：例如台巴自由貿易協定（雞肉、鯖魚等）。
《關稅配額實施辦法》
核配方式一：先到先配
  • 按進口日先後順序自動核配（先搶先贏）。
  • 無須事先申請。
核配方式二：事先核配
  • 提出申請：廠商須在公告期間內申請，由台灣銀行依「核配方法」決定分配。
  • 核配方法：（由台灣銀行決定，採行以下任一種）
    1. 先申請先分配
    2. 按進口實績核配
    3. 標售進口權利
    4. 抽籤
  • 核配證明：獲配權利人應繳納履約保證金或權利金，繳納後核發關稅配額證明書。
  • 配額轉讓：得於證明書「有效期限內」全部或部分轉讓。
轉讓申請人 受理機關
限於有效期限內
  • 有效期限內：以配額證明書為準
  • 限於「事先核配」配額：只有「事先核配」配額有證明書跟有效期限
聯名填具申請書
  • 應由權利人及受讓人聯名填具關稅配額申請書
檢附下列文件
  1. 原關稅配額證明書
  2. 配額轉讓同意書（雙方簽署）
  3. 履約保證金移轉同意書（雙方簽署）
向原核配之機關辦理
  • 即台灣銀行
按轉讓數量比例辦理「履約保證金移轉」手續
  • 例如轉讓40%的配額，保證金也移轉40%過去
得重新核發關稅配額證明書
  • 證明書之有效期限，同原關稅配額證明書所載
納稅義務人
關稅納稅義務人為收貨人、提貨單或貨物持有人
  • 原則：有「收貨人」就找收貨人 → 收貨人找不到／搞不定，就抓「提貨單持有人」 → 再不行，誰「拿著貨」就找誰。
順位 身分 說明
① 收貨人 提單上寫的「貨物受領人」（Consignee）
② 提貨單持有人 拿著提貨單、有權去領貨的人
  • 例：A把貨賣給C，並把提貨單背書轉讓給C => C就是提貨單持有人
③ 貨物持有人 拿著提貨單、有權去領貨的人
  • 例：貨物在D的倉庫被查到，D說不是他的 => D是「貨物持有人」=> D是納稅義務人
未稅貨物短少之補繳責任
誰弄丟，誰負責（補繳稅費）
  • 短少原因：非法提運、遺失、遭竊或其他原因（基本上，不管什麼原因）
  • 補繳稅費：由弄丟業者負責補繳短少之進口稅費
責任跟著「管領人」走
情況1.「保稅運貨工具」載運之貨物短少：由運輸業者負責
  • 短少發生於保稅運貨工具運送保稅貨物過程中。由運輸業者負責
情況2.在「保稅場所」短少：由保稅場所業者負責
  • 「保稅場所」：貨棧、貨櫃集散站、保稅倉庫、物流中心、免稅商店
  • 短少發生於保稅貨物儲存於保稅場所階段。由保稅場所業者負責
情況3.運輸單獨由承攬業者「承攬運送」：由承攬業者負責
  • 指進口未稅貨物之陸上運輸，由承攬業者「單獨承攬」運送
    • 即非由運輸業者自行運送
  • 則該承攬業者為實際「管領人」，應負短少責任
關稅等款項之徵收與執行期間
原則：五年徵收期間內徵起。五年內未經徵起者，不再徵收
  • 五年徵收期間：
    • 一般情況：自處分「確定」之翌日起算
    • 分期繳納：自「分期應繳日」之翌日起算
  • 適用範圍：關稅、滯納金、滯報費、利息、罰鍰、應追繳之貨價
    • 即依《關稅法》處分所生之一切「金錢給付義務」
中斷事由：移送執行、聲明參與分配、申報債權
  • 移送執行：依關稅法規定，欠稅案件屆期未繳納者，移送強制執行
  • 聲明參與分配：指於民事強制執行程序中，就債務人財產聲明參與分配
  • 申報債權：指於破產程序中向破產管理人申報債權
  • 凡五年期間屆滿前有以上積極追徵行為：
    1. 時效中斷，不發生「不再徵收」之效果
    2. 再加五年時間來「開始執行」（第2個五年）
移送執行者，應於徵收期屆滿後五年內「開始執行」。五年內未經執行者，不再執行
  • 適用情況：徵收期間屆滿前已移送執行者
  • 五年內：自「徵收期間屆滿」之翌日起（第2個五年）
  • 「開始執行」：如已發動扣款、查封等實際「執行行為」
  • 凡徵收期間屆滿後五年（第2個五年）內有「開始執行」：
    1. 時效中斷，不發生「不再執行」之效果
    2. 再加五年時間來「執行終結」（第3個五年）
執行案件必須在「第3個五年」內終結。如未執行終結，不得再執行
  • 第1個五年：徵收期間（處分確定後5年）
  • 第2個五年：執行期間（徵收期間屆滿後5年）
  • 第3個五年：執行終結期間（徵收期間屆滿後5年 + 5年 = 處分確定後15年）
關稅優先清償義務
法人解散清算時，應優先清償關稅債務
  • 適用對象：法人（或合夥、非法人團體）
  • 適用情形：因解散而進入清算程序
  • 清償義務：應優先清償關稅債務，再分配賸餘財產
    • 強調關稅債務較一般債務之「優先權」。必須先清償完畢後才能分配賸餘財產
    • 「關稅債務」：包括關稅、滯納金、滯報費、利息、罰鍰、應追繳之貨價
    • 清償順序：關稅 → 滯納金 → 滯報費 → 利息 → 罰鍰 → 應追繳之貨價
違反效果：由「清算人」負繳納義務
  • 違反：即清算人未將關稅債務繳清，就將賸餘財產分配
  • 清算人：負責執行清算事務之人
  • 負繳納義務：應由清算人負責繳納未清償之款項。
    • 此為「法定代償責任」，無須訴訟，海關得逕對清算人發單課徵
關稅擔保及保證金
擔保或保證金，得以下列方式為之：
  • 現金
  • 公債
  • 定期存單（銀行或信用合作社）
  • 信託憑證（信託投資公司一年以上普通信託憑證）
  • 授信機構之保證
    • 由銀行等授信機構出具「保證書」，承諾於納稅義務人未履行義務時，由該機構代為清償
    • 無須設定抵押權或質權，程序較簡便
    • 實務上多採此方式，由銀行開立擔保信用狀或保證函
  • 其他經財政部核准，「易於變價及保管」，且「無產權糾紛」之財產
除「現金」及「授信機構之保證」外，應依法設定抵押權或質權於海關
  • 抵押權：適用於不動產
  • 質權：適用於動產、有價證券、權利
保密義務與例外
關務人員對於各項報關資料，應嚴守秘密
  • 「各項報關資料」：納稅義務人、貨物輸出人向海關所提供之各項報關資料
    • 包括進/出口報單、發票、裝貨單、提貨單、產地證明、價格資料、交易對象等一切相關資訊
  • 「應嚴守秘密」：不得以任何方式（口頭、書面、電子傳輸等）將報關資料洩漏予無權知悉之人
違者應予處分。涉有觸犯刑法規定者，並應移送偵查
  • 行政責任：依公務員懲戒法或相關人事法規予以處分
  • 刑事責任：涉犯刑法（如：公務員洩漏國防以外秘密罪）者，移送檢察機關偵查
但對下列各款人員及機關提供者，不在此限：
  • 納稅義務人/貨物輸出人
    • 包括本人、繼承人、代理人、辯護人
  • 海關、稅捐稽徵機關
  • 監察機關
  • 受理有關關務訴願、訴訟機關
  • 依法從事調查關務案件之機關（如法務部調查局、廉政署等）
  • 其他依法得向海關要求提供報關資料之機關或人員
  • 經財政部核定之機關或人員
