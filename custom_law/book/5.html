5 罰則

涉及私運或違法漏稅，依《海關緝私條例》等相關法律處理

  • 進出口貨物如果被發現有走私（完全沒報關）或虛報、逃漏稅等其他違法情形：
    • 就不依照《關稅法》本身的罰則處理，而是要依照《海關緝私條例》或其他相關法律的規定來調查、處罰。
簡單說：
  • 進出口涉及私運或違法漏稅案件，依《海關緝私條例》等相關法律處理。
詳情解析
進出口貨物如有私運或其他違法漏稅情事
  • 「私運」：指未經向海關申報而運輸貨物進出國境（海關緝私條例第3條）。
  • 「其他違法漏稅情事」：指除私運外，其他違反關稅法規致生逃漏關稅之行為（如虛報貨名、數量、價值等，海關緝私條例第37條）。
依海關緝私條例及其他有關法律之規定處理
  • 優先適用《海關緝私條例》之規定（如處罰鍰、沒入貨物）。
  • 若涉及刑事犯罪，則依《懲治走私條例》、《毒品危害防制條例》等特別刑法辦理。
舉個例子
例1（虛報）
  • A公司進口貨物申報為「塑膠粒」，實際為「電子產品」， 涉有虛報貨名逃漏稅情事，海關依海關緝私條例第37條規定處罰。
  • → 符合第94條（其他違法漏稅情事，依海關緝私條例處理）。
例2（私運）
  • B公司未向海關申報，將管制貨物藏匿於貨櫃中企圖進口， 經海關查獲，依海關緝私條例第36條規定處理。
  • → 符合第94條（私運，依海關緝私條例處理）。
相關規定
  • 第94條
    • 進出口貨物如有私運或其他違法漏稅情事，依海關緝私條例及其他有關法律之規定處理。
記憶口訣
  • 私運漏稅不歸關稅法，緝私條例來處理。
  • 申報不實或走私，沒入罰款加刑責。

罰則總整理

  • 一、逾期報關/繳納關稅
    • 滯報費/滯納金 => 徵滿20日/30日仍不報關 => 變賣
  • 二、逾期補稅/沖銷
    • 滯納金上限：15%
  • 三、保稅貨物違規流出
    • 以私運貨物進口論。
  • 四、業者非管理違規
  • 五、業者管理違規
    逐步升級處罰
    1. 警告或處罰鍰，並得命其限期改正。
    2. 屆期未改正者，按次處罰。
    3. 處罰三次仍未改正（或違規情節重大）者，得停止六個月以下之業務（或廢止其登記/許可）。
一、逾期報關/繳納關稅
  • 特點：貨還在海關手上，所以有「變賣」做為最後手段。
變賣前提要件
  • 滯納金/滯報費「已徵滿」。
    • 滯納金：徵滿30日。
    • 滯報費：徵滿20日。
變賣價款處理方式
  1. 先扣除欠稅及必要之費用
  2. 如有餘款，由海關暫代保管。
  3. 納稅義務人得於五年內申請發還，逾期繳歸國庫。
違規行為/規定 處罰主體 處罰
逾期報關
  • 納稅義務人應於進口日之翌日起15日內，向海關申報。
納稅義務人
  • 滯報費（按日加徵200元）
  • 滯報費徵滿20日仍不報關 => 變賣。餘款5年內申請發還，逾期繳歸國庫。
逾期繳納關稅
  • 關稅應於稅款繳納證送達之翌日起14日內繳納。
納稅義務人
  • 滯納金（按日萬分之五）
  • 滯納金加徵滿30日仍不繳納 => 變賣。餘款5年內申請發還，逾期繳歸國庫。
二、逾期補稅/沖銷
  • 滯納金設有上限：15%
違規行為/規定 處罰主體 處罰
記帳稅款未如期沖銷
  • 外銷品應沖退之原料進口關稅，應於進口放行之翌日起一年六個月內申請沖退。
  • 不能於規定期限內申請沖銷者，應即補繳稅款。 除有不可抗力之事由外，並加徵滯納金。
外銷廠商
  • 滯納金（按日加徵萬分之五）
  • 滯納金上限：15%
免徵/記帳/分期繳納關稅延不繳納 納稅義務人 除依法移送強制執行外：
  • 滯納金（按日加徵萬分之五）
  • 滯納金上限：15%
三、保稅貨物違規流出
  • 性質嚴重。以私運貨物進口論。
違規行為/規定 處罰主體 處罰
保稅產品/原料違規出廠
  • 保稅工廠產品及免稅原料，非經海關核准並按貨品出廠形態報關繳稅，不得出廠。
免稅機器設備5年內未補稅而輸往課稅區
  • 免稅機器設備5年內輸往課稅區者，依進口規定，補繳關稅。
保稅工廠 以私運貨物進口論，依海關緝私條例有關規定處罰。
四、業者非管理違規
違規行為/規定 處罰主體 處罰
不配合調查
  • 海關為執行事後稽核，有調查權。被調查人不得規避、妨礙或拒絕。
  • 海關為查明正確完稅價格，有調查權。被調查人不得規避、妨礙或拒絕。
被調查人
  • 罰鍰3千 ~ 3萬
  • 限期配合、得按次處罰
減免貨物年限內轉讓未補稅
  • 減免關稅之進口貨物，規定年限內轉讓或變更用途者， 應於30日內申報補繳關稅。
  • 前項應補關稅， 應自稅款繳納證送達之翌日起14日內繳納。
納稅義務人/現貨物持有人 兩種違規態樣：
  1. 有申報，但逾期繳納 => 滯納金（按日加徵萬分之五）
  2. 未申報，被海關查出 => 處以應補稅額一倍之罰鍰
五、業者管理違規
逐步升級處罰
  1. 警告或處罰鍰，並得命其限期改正。
  2. 屆期未改正者，按次處罰。
  3. 處罰三次仍未改正（或違規情節重大）者，得停止六個月以下之業務（或廢止其登記/許可）。
通關網路業者由財政部處罰
  • 監管層級高：通關網路業者由財政部直接監管，處罰目的是確保整個通關自動化系統的穩定與安全。
  • 罰則效果重：確保國家關鍵基礎設施安全，罰鍰上限高於一般業者。
違規行為/規定 處罰主體 處罰
違反電子資料傳輸規定
  • 通關有關業務之業者， 違反有關辦理電腦連線或電子資料傳輸通關資料之登記、管理或通關程序之規定。
通關有關業務之業者
  • 警告或處罰鍰6千~3萬，並得命其限期改正。
  • 屆期未改正者，按次處罰。
  • 處罰三次仍未改正者，得停止六個月以下之連線報關
通關網路業者違反營運管理規定
  • 通關網路業者， 違反《通關網路經營許可及管理辦法》
通關網路業者
  • 由財政部予以警告或處罰鍰10萬~50萬，並得命其限期改正。
  • 屆期未改正者，按次處罰。
  • 處罰三次仍未改正者，得停止六個月以下之傳輸通關資料業務或廢止其許可。
  • 違反轉運、轉口貨物之申報通關規定
  • 違反運輸業者管理規定
運輸工具負責人/運輸業者

  • 適用情況：因報單申報錯誤而違規。
  • 免罰要件：海關發現前主動申請更正，經海關准予更正者，免依前項規定處罰。
