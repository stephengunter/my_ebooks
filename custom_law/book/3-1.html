3-1 稅款之優待-免稅

進口貨物免稅規定

  • 以下十九種情況進口貨物不必繳關稅：
    • 總統副總統用的東西、外國外交官自用物品、軍事武器裝備、救濟物資、學校研究用品、無商業價值的廣告樣品
    • 旅客自用行李、低價郵包、防疫物資、救難器材、船員自用物品、國際賽事體育用品
  • 如果不是上面列的那些貨物，只要：
    • 同批進口貨物的完稅價格總計在財政部公告的限額（目前新臺幣2,000元）以下，也免稅。
  • 但要注意，如果進口次數太頻繁（例如半年超過6次），就不能適用低價免稅優惠。以免有人故意拆成小包裹逃稅。
簡單說：
  • 總統、外交、軍事、救濟、教育、旅客行李、低價包裹等十九類貨物進口免稅。
  • 一般低價貨物（2,000元以下）也免稅，但半年進口超過6次就沒有了。

舉個例子
例1：外交免稅——互惠原則
  • A國駐台大使館進口一批辦公家具（公用物品），經查A國對我國駐該國使領館進口辦公家具亦給予免稅待遇。
  • 海關依第一項第二款規定免稅放行。
  • → 符合第49條第1項第2款（外交機關公用物品免稅，且符合互惠條件）。
例2：低價免稅一般貨物
  • B君自國外網購一件衣服，完稅價格（貨物價格＋運費＋保險費）合計新臺幣1,500元。
  • B君半年內進口次數僅2次。
  • 海關依第二項規定免稅放行。
  • → 符合第49條第2項（低價貨物完稅價格在限額以下，且進口次數未達頻繁標準）。
例3：進口次數頻繁——不適用低價免稅
  • C君半年內自國外網購進口7次，每次完稅價格均為新臺幣1,800元（低於2,000元）。
  • 因進口次數頻繁（半年逾6次），第七次進口時，海關不適用低價免稅，應按一般進口貨物課徵關稅及營業稅。
  • → 符合第49條第2項但書（進口次數頻繁者，不適用低價免稅）。
相關規定
  • 第49條
    1. 列舉19款法定免稅貨品。
    2. 前項貨物以外之進口貨物，其同批完稅價格合併計算在財政部公告之限額以下者，免稅。
      • 但進口次數頻繁或經財政部公告之特定貨物，不適用之。
    3. 授權財政部就特定免稅項目及「低價免稅」之細部規範訂定子法。
記憶口訣
  • 免稅項目十九款，總統外交與軍事；教育救濟研究用。
  • 旅客郵包低價品；兩千限額內免稅，頻繁進口不適用。
  • 特定貨物排除外，授權子法訂細節。

進口貨物因損壞、滅失或退運之免稅

  • 進口貨物如果在通關完成「之前」發生以下五種情況，就不必繳關稅：
    1. 貨物還在船上或剛卸貨時，因為損失、變質、損壞而變得沒有價值，而且進口時有向海關申報。
    2. 貨物卸下來以後、海關查驗放行以前，因為颱風、地震等天災或不可抗力而損失或損壞到沒有價值。
    3. 海關查驗時，貨物已經破漏、損壞或腐爛到沒有價值，而且不是因為倉庫或貨主保管不小心造成的。
    4. 在海關放行「之前」，納稅義務人申請退運出口，而且海關核准了。
    5. 在海關放行「之前」，貨物因為本身性質自然減少（例如液體揮發），短少的部分經海關查證屬實。
簡單說：
  • 貨物在放行前若因意外損壞、天災滅失、自然耗損或申請退運而失去價值，就不必繳關稅。
詳情解析
五種免稅情形：
情形 關鍵要件
運輸途中或起卸時損失、變質、損壞致無價值 進口時向海關聲明 （即主動申報）
起卸後、驗放前，因天災、事變或不可抗力致無價值 須屬不可抗力
海關查驗時業已破漏、損壞或腐爛致無價值 非因倉庫管理人或貨物關係人保管不慎
海關放行前，申請退運出口經海關核准 須經海關核准
海關驗放前，因貨物性質自然短少
  • 短少部分經海關查明屬實
  • 僅「短少部分」免稅
舉個例子
例1：運輸途中損壞
  • A公司自美國進口一批玻璃製品，貨物於海運途中因船舶遭遇大浪，導致部分貨物破損完全無法使用。
  • 貨物抵達台灣後，A公司於報關時檢附公證報告，向海關聲明該批貨物已損壞致無價值。
  • 海關查證屬實後，就該損壞部分免徵關稅。
  • → 符合第50條第1款（運輸途中損壞致無價值，於進口時向海關聲明者免稅）。
例2：天災致貨物滅失
  • B公司進口一批電子產品，貨物卸存於碼頭後，遭逢颱風引發海水倒灌，整批貨物浸泡海水全數損壞，無法修復。
  • B公司檢附相關證明文件，向海關說明係因天災所致。海關查證屬實後，就該批貨物免徵關稅。
  • → 符合第50條第2款（起卸後驗放前，因天災致損壞無價值者免稅）。
例3：退運出口
  • C公司進口一批貨物，因品質不符契約要求，納稅義務人於海關放行前，向海關申請將該批貨物退運出口。
  • 經海關核准後將貨物裝船運回出口國。
  • → 符合第50條第4款（於海關放行前，申請退運出口經核准者免稅）。
相關規定
  • 第50條：進口貨物有下列情形之一，免徵關稅：
    1. 在國外運輸途中或起卸時，因損失、變質、損壞致無價值，於進口時，向海關聲明者。
    2. 起卸以後，驗放以前，因天災、事變或不可抗力之事由，而遭受損失或損壞致無價值者。
    3. 在海關查驗時業已破漏、損壞或腐爛致無價值，非因倉庫管理人員或貨物關係人保管不慎所致者。
    4. 於海關放行前，納稅義務人申請退運出口經海關核准者。
    5. 於海關驗放前，因貨物之性質自然短少，其短少部分經海關查明屬實者。
記憶口訣
  • 進口貨物遇損失，五種情形免關稅。
  • 運輸途中起卸損，進口聲明即免稅。
  • 天災事變不可抗，查驗損壞非保管。
  • 放行前申請退運，自然短少也免稅。

損壞或規格不符貨物之賠償或調換免稅

  • 如果進口的貨物已經繳了關稅，後來發現壞掉、或規格、品質跟合約不一樣，國外廠商願意補送或換一批新的來，那麼：
    • 這批補送或換來的貨物「免徵關稅」。
    不過：
    • 必須在原貨物進口的隔天起一個月內向海關申請，並附上相關證明文件，經海關查證屬實才行。
  • 如果進口的是「機器設備」，因為要安裝試車才會發現問題：
    • 申請期限可以延長到「安裝試車的隔天起三個月內」。
  • 海關核准後，補送或換來的貨物必須在海關通知核准的隔天起六個月內運進來。
    • 如果有特殊原因，可以在期限到期前申請延長，最多再延六個月。
簡單說：
  • 進口貨物有瑕疵，國外廠商補送或換貨進口時可以免關稅。
    • 但須在法定期限內申請並完成進口，逾期則喪失優惠。
三個核心時限：
  • 申請期限：1個月內。原貨物進口之翌日起算。
    • 機器設備為3個月內。安裝試車之翌日起算。
  • 復運進口：6個月內。海關通知核准之翌日起算。
  • 延長期限：得申請延長一次，最多延6個月。
詳情解析
適用前提：已稅進口貨物有瑕疵，國外廠商賠償或換貨進來
  • 「已稅」：該進口貨物已課徵關稅完畢（即已完稅進口）。
  • 「瑕疵」：貨物「損壞」或「規格、品質與原訂合約規定不符」等情形。
  • 「賠償或換貨」：因上述瑕疵，國外廠商同意「賠償」（另送相同貨物）或「調換」（更換為合格貨物）。
法律效果：賠償或調換進口之貨物，免徵關稅
申請程序
原貨進口1個月內附相關證明，向海關申請
  • 申請期限：1個月內。自「原貨物進口」之翌日起算。
    • 特別期限：若該貨物屬「機器設備」，申請期限放寬為3個月內，自「安裝就緒試車」之翌日起算。
  • 附相關證明：須提供有關證件（如合約、公證報告、檢驗證明、國外廠商同意賠償或調換之文件等）。
經海關查明屬實後核准，限期6個月內換貨進口，始得享有免稅優惠
換貨進口期限
賠償換貨應於6個月內進口
  • 「賠償換貨」：因賠償或瑕疵而補送的貨物。
  • 「6個月內進口」：應於6個月內進口報運進口。自「海關通知核准」之翌日起算。
必要時得申請海關延長，最多延長6個月
  • 「必要時」：需有「必要之事實」（如製造時程、船期等因素）。
  • 「申請海關延長」：必須在6個月「期限屆滿前」向海關申請延長。

舉個例子
例1：一般貨物一個月內申請
  • A公司進口一批電子零件，完稅進口後發現部分零件損壞，國外廠商同意無償賠償。
  • A公司於原貨物進口之翌日起第20日，檢具合約、公證報告及廠商同意賠償文件向海關申請免稅，經海關查明屬實核准。
  • → 符合第51條第1項（於一個月內申請並經核准，賠償進口之貨物免徵關稅）。
例2：機器設備——三個月內申請
  • B公司進口一套生產設備，安裝試車後發現規格與合約不符，國外廠商同意調換。
  • B公司於安裝試車之翌日起第70日，檢具相關證件向海關申請免稅，經海關查明屬實核准。
  • → 符合第51條第2項（機器設備得於安裝試車之翌日起三個月內申請）。
例3：逾期申請——喪失免稅優惠
  • C公司進口一批化學原料，發現品質不符，惟C公司遲至原貨物進口之翌日起第40日始向海關申請免稅，已逾一個月之法定期間。
  • 海關否准其申請。C公司只能就賠償或調換進口之貨物，按一般進口程序申報繳納關稅。
  • → 不符合第51條（逾一個月申請期限，不得適用免稅優惠）。
相關規定
  • 第51條
    1. 課徵關稅之進口貨物，發現損壞或規格、品質與原訂合約規定不符，由國外廠商賠償或調換者：
      • 該項賠償或調換進口之貨物，免徵關稅。
      • 但以在原貨物進口之翌日起一個月內申請核辦，並提供有關證件，經查明屬實者為限。
    2. 前項貨物如係機器設備，得於安裝就緒試車之翌日起三個月內申請核辦。
    3. 第一項賠償或調換進口之貨物，應自海關通知核准之翌日起六個月內報運進口。
      • 如因事實需要，於期限屆滿前，得申請海關延長之，其延長，以六個月為限。
記憶口訣
  • 進口貨物若有損，規格品質不符約。
  • 國外賠償或調換，免稅進口有期限。
  • 一般貨物一個月，機器設備三個月。
  • 核准半年內運來，延長一次限半年。

特定貨物暫准進口免稅與復運出口期限

  • 有些貨物進口只是「暫時進來一下」，不是要賣或留在台灣的——例如：
    • 商業樣品、展覽品、科研用品
    • 攝影器材、維修工具、空容器等
    這些貨物如果：
    • 在進口的隔天起六個月內（或財政部核定的期限內）「原貨復運出口」，就可以免徵關稅。
  • 如果因為特殊原因需要延長期限，必須：
    • 在期限到期「之前」以書面向海關申請，說明理由並檢附證明文件。
      • 若原期限是財政部核定的，則向財政部申請。
簡單說：
  • 特定貨物暫時進口後原貨出口，免關稅。
    • 期限可申請延長，但須事先申請。
詳情解析
貨樣、科研用品、展覽物品、攝影器材等特定貨物，進口後6個月內原貨復運出口者免徵關稅
  • 「特定貨物」包括：
    • 貨樣（商業樣品）、科學研究用品、試驗用品
    • 展覽物品、遊藝團體服裝、道具、攝製電影電視之攝影製片器材
    • 安裝修理機器必需之儀器、工具、盛裝貨物用之容器（如空貨櫃、包裝箱）
    • 進口整修、保養之成品（如運回原廠維修之成品）
    • 其他經財政部核定之物品（如專業設備、比賽用器材等）
  • 「6個月內」：進口之翌日起算。
    • 例外：經財政部核定者，得依核定之「特定日期」為準（如展覽期間可能超過六個月）。
  • 「原貨復運出口」：須為同一批貨物原狀出口（不得加工、變更）。
  • 「免徵關稅」：符合要件者，進口時免徵關稅。
必要時，可申請延長復運出口之期限
  • 「必要時」：需有「必要之事實」。
  • 「申請延長」：
    • 須於出口期限「屆滿前」提出申請。
    • 須以「書面」敘明理由，並檢附有關證件（證明必要之事實）。
    • 向原進口地海關申請核辦。
      • 例外：若原期限係經財政部「核定」者（非一般六個月期限），延長申請應向「財政部」為之。

例1：六個月內復運出口
  • A公司自德國進口一批商業貨樣，參加國內國際展覽。

  • → 符合第52條第1項（六個月內原貨復運出口，免徵關稅）。
例2：財政部核定較長期限
  • B機構舉辦為期八個月之國際藝術展覽，展覽品無法於六個月內復運出口。
  • B機構於進口前向財政部申請核定展期為八個月，經財政部核准。
  • → 符合第52條第1項但書（經財政部核定之日期前復運出口，免徵關稅）。
例3：申請延長期限
  • C公司進口一批攝影製片器材，原應於進口翌日起六個月內復運出口。
  • 惟因拍攝進度延宕，C公司於期限屆滿前30日，以書面向原進口地海關申請延長三個月，並檢附拍攝合約及進度說明，經海關核准。
  • → 符合第52條第2項（因事實需要，得於期限屆滿前申請延長）。
相關規定
  • 第52條
    1. 應徵關稅之貨樣、科學研究用品、試驗用品、展覽物品..等特定物品：
      • 於進口之翌日起六個月內或於財政部核定之日期前，原貨復運出口者，免徵關稅。
    2. 前項貨物，因事實需要，須延長復運出口期限者，應於出口期限屆滿前，以書面敘明理由，檢附有關證件，向原進口地海關申請核辦。
      • 其復運出口期限如原係經財政部核定者，應向財政部申請核辦。
記憶口訣
  • 貨樣科研展覽品，攝影器材與容器。
  • 進口半年內復運，原貨出口免關稅。
  • 期限屆滿前延長，書面理由附證件。
  • 海關財政部權限，視原核定機關定。

特定貨物暫准出口免稅與復運進口期限

  • 有些貨物出口只是「暫時出去一下」，不是要賣掉或留在國外的——例如：
    • 貨物貨樣、科研用品、工程機械、攝影器材
    • 展覽品、藝術品、空容器等。
    這些貨物如果：
    • 在出口的隔天起一年內（或財政部核定的期限內）「原貨復運進口」，就可以免徵關稅。
  • 如果因為特殊原因需要延長期限，必須：
    • 在期限到期「之前」以書面向原出口地海關申請（說明理由並檢附證明文件）。
    • 若原期限是財政部核定的，則向財政部申請。
簡單說：
  • 特定貨物暫時出口後原貨復運進口，免關稅。
    • 期限可申請延長，但須事先申請。
詳情解析
貨樣、科研用品、工程機械、攝影器材等特定貨物，出口後1年內原貨復運進口者免徵關稅
  • 「特定貨物」包括：
    • 貨樣、科學研究用品、工程機械
    • 攝影製片器材、安裝修理機器必需之儀器工具
    • 展覽物品、藝術品、盛裝貨物用之容器
    • 遊藝團體服裝道具、政府機關寄往國外之電影片與錄影帶。
    • 概括條款：其他經財政部核定之類似物品。
  • 「1年內」：出口之翌日起算。
    • 例外：經財政部核定者，得依核定之「特定日期」為準（如國外展覽期間超過一年）。
  • 「原貨復運進口」：須為同一批貨物原狀進口（不得加工、變更）。
  • 「免徵關稅」：符合要件者，復運進口時「免徵關稅」。
必要時，可申請延長復運進口之期限
  • 「必要時」：需有「必要之事實」。
  • 「申請延長」：
    • 須於復運進口期限「屆滿前」提出申請。
    • 須以「書面」敘明理由，並檢附有關證件（證明必要之事實）。
    • 向原出口地海關申請核辦。
      • 例外：若原期限係經財政部「核定」者（非一般1年期限），延長申請應向「財政部」為之。
復運出口 vs 復運進口
進口後復運出口 出口後復運進口
範例 A公司自德國進口一批商業貨樣，參加國內國際展覽。 展覽完畢該批貨樣原貨復運出口。 美術館將一批藝術品運往國外參展，展覽完畢同一批藝術品復運進口。
貨物流向 進口 → 復運出口 出口 → 復運進口
適用客體 貨樣、科研用品、展覽品、攝影器材等 貨樣、科研用品、工程機械、藝術品、政府機關電影片等
免稅期限 六個月（或財政部核定日期） 一年（或財政部核定日期）
延長申請機關 原進口地海關（財政部核定者則向財政部） 原出口地海關（財政部核定者則向財政部）
舉個例子
例1：一年內復運進口
  • A公司將一批工程機械運往東南亞參與工程建設，於113年1月1日出口。
  • 工程於113年10月完工，A公司於113年11月15日將該批機械原貨復運進口（未逾一年期限）。
  • → 符合第53條第1項（一年內原貨復運進口，免徵關稅）。
例2：財政部核定較長期限
  • B美術館將一批藝術品運往國外參展，展期預計為14個月，無法於一年內復運進口。
  • B美術館於出口前向財政部申請核定展期為14個月，經財政部核准。
  • → 符合第53條第1項但書（經財政部核定之日期前復運進口，免徵關稅）。
例3：申請延長期限
  • C研究機構將科學研究用品運往國外進行為期一年之合作研究。
  • 惟因研究時程延長，C機構於一年期限屆滿前60日，以書面向原出口地海關申請延長三個月，並檢附合作協議及進度說明，經海關核准。
  • → 符合第53條第2項（因事實需要，得於期限屆滿前申請延長）。
相關規定
  • 第53條
    1. 貨樣、科學研究用品、試驗用品、展覽物品..等特定物品：
      • 於出口之翌日起一年內或於財政部核定之日期前，原貨復運進口者，免徵關稅。
    2. 前項貨物，因事實需要，須延長復運進口期限者，應於復運進口期限屆滿前，以書面敘明理由，檢附有關證件，向原出口地海關申請核辦。
      • 其復運進口期限如原係經財政部核定者，應向財政部申請核辦。
記憶口訣
  • 貨物出口到國外，一年之內要回來。
  • 貨樣科研工程機，展覽藝術攝影器。
  • 原貨復運進口時，免徵關稅有期限。
  • 期限屆滿前申請，書面理由附證件。
  • 海關財政部分管，視原核定機關定。

暫准通關證制度

  • 「暫准通關證」就像是一本貨物的護照。 廠商要把展覽品、商業樣品或專業器材暫時運到國外或從國外運進來時：
    • 持「暫准通關證」通關，就可以不用填寫進出口報單，也不用先繳關稅保證金，大幅簡化通關手續。
  • 只要在通關證的有效期限內（通常是一年）把貨物原貨復運出口或復運進口，就可以免徵關稅。
    • 如果逾期沒有復運出去，通關證上記載的保證機構（在我國是外貿協會）就要代為繳納稅款。
  • 通關證的有效期限最長一年，不能延長。
簡單說：
  • 持「貨物護照」通關，可免填報單、免繳保證金，期限內復運出口或進口即可免稅。
  • 逾期未復運者，由保證機構代繳稅款。
什麼是暫准通關證？
  • 暫准通關證（ATA Carnet）是一本國際通用的海關文件，被稱為貨物的「通關護照」。
    • 專為「暫時」進出口貨物而設計。
    • 核心機制（以我國為例）
    • 適用於特定貨物暫時進/出口。
    • 發證機構兼保證機構：中華民國對外貿易發展協會（外貿協會）
      • 保證機構是「進口擔保人」。
    • 持證通關免申報。
      • 暫准通關證視同通關申報文件。
    • 有效期限內原貨復運出/進口：免關稅。
    • 逾期效果：
      • 逾期未復運出口：應納稅款由保證機構代為繳納。
      • 逾期未復運進口：依法課徵關稅。（保證機構是「進口擔保人」，不是「出口擔保人」）
貨物暫准通關辦法
適用貨物範圍
  • 根據《貨物暫准通關辦法》，以下貨物得使用暫准通關證：
    • 專業器材、設備：如攝影器材、工程機械、維修工具。
    • 展覽會、商展陳列或使用之貨物：如展覽品、展示設備。
    • 為招攬交易而供展示或示範之商業樣品：業務推廣用之樣品。
排除項目
  • 菸酒
  • 易腐壞物及因使用而消耗之貨物
  • 不擬復運出口之貨物
  • 在我國列入管制進出口之貨物
  • 進口為加工或修理之貨物
有效期與保證機制
  • 有效期限：最長1年。自發證機構簽發之日起算。
  • 發證及保證機構：我國為中華民國對外貿易發展協會（外貿協會）
  • 保證責任上限：以貨物進口時海關核定之稅費金額再加 10% 為限。
法律效果
  • 有效期限內原貨復運出口：免徵關稅。
    • 免徵關稅及各種稅費，但不包括依《海關徵收規費規則》應徵收之規費。
  • 逾期未復運出口：
    1. 海關通知保證機構：六個月內提出貨物已於有效期限內復運出口之證明。
    2. 屆期未提出證明：保證機構代為繳納全部稅費。
  • 發現不法使用：通關證有效期限屆滿之日起1年內，海關得通知保證機構補繳稅費。
舉個例子
例1：持通關證進口展覽品後復運出口
  • A公司自德國進口一批機械展覽品，持有效之暫准通關證向海關申報，免填進口報單、免繳關稅保證金。
  • 展覽結束後，A公司於通關證有效期限（一年）內將該批展覽品原貨復運出口，免徵關稅。
  • → 符合第54條第1項前段（通關證有效期限內原貨復運出口者，免徵關稅）。
例2：逾期未復運出口——保證機構代繳
  • B公司持通關證進口一批商業樣品，惟逾期未於通關證有效期限內復運出口。
  • 海關通知保證機構外貿協會於六個月內提出復運證明或補繳稅款。
  • 外貿協會屆期未提出證明，海關填發稅款繳納證命其於14日內補繳全部稅費。
  • → 符合第54條第1項中段（逾期未復運出口者，其應納稅款由保證機構代為繳納）。
例3：逾期復運進口——依法課稅
  • C公司將一批工程機械持通關證出口至日本，惟逾通關證有效期限始復運進口，且亦逾第53條之一年期限。
  • → 不得適用免稅優惠，應依一般進口貨物規定課徵關稅。
  • → 符合第54條第1項後段（逾期復運進口者，依法課徵關稅）。
相關規定
  • 第54條
    1. 納稅義務人得以暫准通關證替代進口或出口報單辦理貨物通關。
      • 該貨物於暫准通關證有效期限內原貨復運出口或復運進口者，免徵關稅。
      • 逾期未復運出口者，其應納稅款由該證載明之保證機構代為繳納。
      • 逾期復運進口者，依法課徵關稅。
    2. 授權財政部訂定《貨物暫准通關辦法》，就貨物範圍、保證責任、通關證簽發管理等為細部規範。
記憶口訣
  • 暫准通關通行證，免填報單免關稅。
  • 樣品展覽專業器材，一年之內要回來。
  • 逾期未返保證賠，外貿協會來擔保。

減免關稅貨物轉讓或變更用途之補稅與免補稅

  • 如果進口時享有免關稅優惠的貨物（例如科學研究設備、投資計畫機器）， 在監管年限內賣給別人或挪作他用：
    • 原進口人或現在的持有人必須在轉讓或變更用途的隔天起三十天內，主動向海關申報補稅。
    • 補稅的金額是按「轉讓或變更用途當時」的貨物價值和稅率來計算。
  • 但有四種情況可以不用補稅：
    1. 已經超過法定的監管年限（一般貨物三年）
    2. 經海關核准把貨物原封不動運出口
    3. 經原核准機關證明貨物已運出口
    4. 轉讓給同樣可以享受免稅優惠的對象
  • 另外，如果是分期繳稅或記帳進口的貨物，在稅款還沒繳完之前，原則上不能轉讓。
    • 但如果是法院強制執行或海關專案核准，就可以轉讓，並且由受讓人繼續分期繳稅或記帳。
簡單說：
  • 免稅進口的貨物，在監管年限內轉賣或改作他用，要主動申報補稅。
    • 但已超過年限、復運出口或轉給同樣可免稅者，則免補稅。
詳情解析
適用情況：減免關稅之進口貨物，轉讓或變更用途時
  • 「減免關稅之進口貨物」：例如科學研究設備、投資計畫機器， 附有特定用途與監管年限。
  • 「轉讓」：指所有權移轉予他人，無論有償或無償（如出售、贈與）。
  • 「變更用途」：指改變原核准之使用目的，例如原核准供自用生產設備，卻移作出租或出售之用。
補稅義務：納稅義務人應於30日內補繳關稅
  • 補稅義務人：進口時之納稅義務人，或現貨物持有人。
  • 「30日內」：自「轉讓或變更用途」之翌日起算。
  • 「補繳關稅」：
    • 受理機關：原進口地海關。
    • 計算基準：依「轉讓或變更用途時」之價格與稅率計算。
      • 新品參照前後30日交易價格；舊品扣除折舊；廢品按廢料估算。
例外：有下列情事之一者，免予補稅
  1. 轉讓或變更用途時已逾財政部規定年限
  2. 經海關核准原貨復運出口
  3. 經原核發同意或證明文件之機關核轉海關查明原貨復運出口
  4. 轉讓予同具免稅資格者
分期或記帳貨物之轉讓限制
分期繳稅或稅款記帳之進口貨物，於關稅未繳清前，不得轉讓
例外：強制執行或經海關專案核准者，不在此限。並准由受讓人繼續分期繳稅或記帳
  • 若經強制執行或專案核准而轉讓，受讓人得繼續按原分期或記帳條件繳納稅款。
舉個例子
例1：轉讓須補稅
  • A公司以科學研究設備名義免稅進口一套儀器，監管年限為3年。
  • 進口後第2年，A公司將該儀器出售予B公司（非免稅資格者）。
  • A公司應於出售之翌日起30日內，向原進口地海關申報，按出售時之價格與稅率補繳關稅。
  • → 符合第55條第1項本文（轉讓時應補繳關稅）。
例2：免補稅——已逾監管年限
  • C公司以投資計畫名義免稅進口一批機器設備，監管年限為3年。
  • C公司於進口後第4年將該批機器出售予D公司。
  • 因已逾財政部規定之監管年限（3年），該批機器已自動解除監管。
  • → 符合第55條第1項第1款（轉讓時已逾監管年限，免予補稅）。
例3：免補稅——原貨復運出口
  • E公司以免稅方式進口一批展覽品，展覽結束後經海關核准原貨復運出口。
  • E公司於出口報單「申請審驗方式」欄填報代碼「8」，並於「其他申報事項」欄註明原進口報單號碼及復運出口原因，經海關查明屬實。
  • → 符合第55條第1項第2款及財政部實務規定（經海關核准原貨復運出口，免予補稅）。
相關規定
  • 第55條
    1. 減免關稅之進口貨物，轉讓或變更用途時：應由原進口時之納稅義務人或現貨物持有人自轉讓或變更用途之翌日起三十日內，向原進口地海關按轉讓或變更用途時之價格與稅率，補繳關稅。 但有下列情事之一者，免予補稅：
      1. 轉讓或變更用途時已逾財政部規定年限
      2. 經海關核准原貨復運出口
      3. 經原核發同意或證明文件之機關核轉海關查明原貨復運出口
      4. 轉讓與具有減免關稅條件
    2. 分期繳稅或稅款記帳之進口貨物，於關稅未繳清前，除強制執行或經海關專案核准者外，不得轉讓。
    3. 依前項規定經強制執行或專案核准者，准由受讓人繼續分期繳稅或記帳。
    4. 授權財政部就補稅、免補稅年限、申辦程序、完稅價格核估等事項訂定辦法。
記憶口訣
  • 免稅貨物要轉讓，三十日內補稅款，價格稅率用當時。
  • 四種情形可免補；年限屆滿或復運，受讓同免稅條件。
  • 分期記帳未繳清，原則轉讓被禁止。

加工外銷原料復運出口免稅

  • 如果廠商進口原料本來是要加工後再出口外銷，但因故（例如訂單取消、市場變化）決定不做了，想把原料原封不動運回國外：
    • 只要在原料進口放行的隔天起一年內復運出口，並經財政部核准，就可以免徵關稅。
    • 不過，免稅手續必須在原料出口的隔天起六個月內向海關申請辦理，超過期限就不能免稅了。
簡單說：
  • 加工外銷的原料若因故未加工而復運出口，一年內經核准可免稅，但須在出口後六個月內辦妥手續。
詳情解析
進口供加工外銷之原料
  • 適用客體：「進口供加工外銷之原料」：本來原則就是免稅，但是要有外銷事實再「沖銷/退稅」。
一年內，經財政部核准復運出口者，免稅
  • 「一年內」：自該原料「進口放行之翌日」起算。
  • 「經財政部核准復運出口者，免稅」：必須經財政部核准才可免稅（實務上係由進口地海關受理申請後報請財政部核准）。
免稅手續申辦期限：原料復運出口後六個月內
  • 「六個月內」：自該原料「原料復運出口日」之翌日起算。
  • 逾期申請者，不得適用本條免稅。
舉個例子
例1：一年內復運出口並於期限內申辦
  • A公司進口一批紡織原料，原計畫加工後出口。
  • 惟因國外客戶取消訂單，A公司於進口放行後第8個月將該批原料復運出口，並於出口後第3個月向海關申請辦理免稅手續。
  • → 符合第56條（於一年內復運出口，且於六個月內申辦免稅手續，免徵關稅）。
例2：逾一年復運出口——不得免稅
  • B公司進口一批電子原料，因市場變化遲未加工，於進口放行後第14個月始復運出口。已逾一年法定期限。
  • → 不符合第56條第1項（逾一年復運出口，不得適用免稅，應補繳進口關稅）。
例3：出口後逾六個月申辦——不得免稅
  • C公司於進口放行後第6個月將原料復運出口，惟C公司遲至出口後第8個月始向海關申請辦理免稅手續，已逾六個月申辦期限。
  • → 不符合第56條第2項（逾六個月申辦免稅手續，不得適用免稅，應補繳進口關稅）。
相關規定
  • 第56條
    1. 進口供加工外銷之原料，於該原料進口放行之翌日起一年內，經財政部核准復運出口者，免稅。
    2. 前項復運出口之原料，其免稅手續應在出口日之翌日起六個月內申請辦理。
記憶口訣
  • 外銷原料進口後，一年內可復運走。
  • 免稅需經財政部，出口半年內申請。

外銷品退貨復運進口免稅與補稅

  • 如果台灣廠商外銷的產品在出口後「三年內」被國外客戶退貨、運回台灣，那麼：
    • 這批成品運回來時不用再繳成品關稅。
    • 但是，當初出口時已經退還給廠商的「原料關稅」（即進口原料時繳的關稅），必須按原金額補繳回來。
  • 不過，如果廠商在貨物運回來時先提供擔保：
    • 並在進口的隔天起六個月內把貨物整修或保養好、再運出去出口，那麼就可以不用補繳這筆原料關稅。
    • 如果因為天災等不可抗力因素，六個月內無法完成，可以延長，但最長不得超過一年。
簡單說：
  • 外銷品被退貨運回來，成品免稅，但已退還的原料關稅要補繳。
  • 若六個月內整修好再出口，可免補繳原料關稅。
詳情解析
適用情況：外銷品在出口3年內，因故退貨申請復運進口者
  • 「外銷品」：外銷品出口時，其使用之進口原料已繳納之關稅，依法得申請退還（即「原料關稅退稅」）。
  • 「出口3年內」：自「出口放行之翌日」起算。
  • 「因故退貨」：如品質不符、規格錯誤、市場滯銷等被退貨，運回台灣。
  • 「申請復運進口」：退貨進口通關時需主動向海關申請（需提供原出口報單號碼）。
原則：免徵成品關稅。但應補徵出口時已退還之原料關稅
  • 復運進口時，對該「成品」本身不課徵進口關稅（避免重複課稅）。
  • 若該外銷品出口時，其使用之進口原料已申請退還關稅（即「原料關稅退稅」），則復運進口時，應「按原稅額補徵」該原料關稅。
    • 簡單說：納稅義務人要「返還」外銷出口時的退稅款。
免補徵原料關稅之特別規定
前項復運進口之外銷品，經提供擔保，於6個月內（最多延長至1年）整修完畢並復運出口者，免予補徵已退還之原料關稅
  • 「前項復運進口之外銷品」：指外銷品在出口3年內，因故退貨復運進口者。
  • 「經提供擔保」：廠商提供足額擔保後（保證金或銀行保證）。
  • 「6個月內」：自「復運進口之翌日」起算。
    • 「最多延長至1年」：必須是「天災、事變或不可抗力之事由」導致無法於6個月內復運出口，才得延長。
  • 「整修完畢」：有實際的維修、更換零件、保養等事實。
  • 「免予補徵已退還之原料關稅」：有外銷的事實就沒有「溢領原料退稅」問題了。 此為鼓勵業者將退貨整修後再出口，避免因補稅而放棄再出口之機會。
舉個例子
例1：退貨復運進口補繳原料關稅
  • A公司於112年1月出口一批電子產品，出口時已退還原料關稅新臺幣50萬元。
  • 該批產品於113年6月（出口後約1.5年）因品質不符遭國外客戶退貨，復運進口。
  • 海關免徵成品關稅，惟通知A公司補繳原退還之原料關稅50萬元。
  • → 符合第57條第1項本文及但書（三年內退貨復運進口，免成品關稅，但補徵已退還之原料關稅）。
例2：整修後復運出口免補徵
  • B公司於112年3月出口一批機械零件，出口時已退還原料關稅30萬元。
  • 該批零件於113年8月（出口後約1.5年）因規格不符遭退貨復運進口。
  • B公司提供擔保後，於進口後4個月內完成整修並復運出口。
  • 海關免予補徵原料關稅30萬元。
  • → 符合第57條第2項前段（六個月內整修完畢並復運出口者，免補徵已退還之原料關稅）。
例3：逾三年退貨復運進口——不適用本條
  • C公司於109年1月出口一批化學品，於112年5月（出口後約3年4個月）因故退貨復運進口，已逾三年期限。
  • → 不符合第57條第1項（逾三年退貨復運進口，不適用本條免徵成品關稅及補徵原料關稅之規定，應依一般進口貨物課徵關稅）。
相關規定
  • 第57條
    1. 外銷品在出口放行之翌日起三年內，因故退貨申請復運進口者，免徵成品關稅。
      • 但出口時已退還之原料關稅，應仍按原稅額補徵。
    2. 前項復運進口之外銷品，經提供擔保，於進口之翌日起六個月內整修或保養完畢並復運出口者，免予補徵已退還之原料關稅。
      • 但因天災、事變或不可抗力之事由致無法如期復運出口者，其復運出口期限不得超過一年。
記憶口訣
  • 外銷退貨三年內，成品免稅原料補。
  • 提供擔保六個月，整修再出免補稅。
  • 天災不可抗力者，最長可延至一年。
