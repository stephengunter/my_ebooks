構成要件該當性之意義
  • 構成要件該當性，是指行為人之具體事實，是否完全符合刑法各條所定之犯罪構成要件。
  • 若行為與刑法條文所描述之構成要件完全相符，即具備構成要件該當性。
    • 若不相符，則犯罪不成立，無須繼續檢驗違法性與罪責。
客觀構成要件（行為、結果、因果關係）
定義 說明 實例
行為 行為人主觀上所認知並有意為之之身體動作。 須為有意之行為（非反射動作、非睡眠中行為）。 甲持刀揮向乙（有意之行為）。
結果 行為所造成之外界變動（如他人死亡、財物毀損）。 結果須為可歸責於行為人。 乙因甲之揮刀而死亡（結果）。
因果關係 行為與結果間之因果關聯。 須有條件因果關係（若無該行為，即無該結果）及相當因果關係（行為通常會導致該結果）。 甲之揮刀行為與乙之死亡間，有因果關係（若無甲之揮刀，乙不會死亡）。
客觀構成要件之實例判斷
案例 行為 結果 因果關係 是否該當客觀構成要件？
甲持刀刺傷乙，乙送醫後不治。 持刀刺傷 乙死亡
  • 若無甲之刺傷，乙不會死亡（條件因果）。
  • 刺傷通常會導致死亡（相當因果）。
該當
甲毆打乙，乙於送醫途中因車禍死亡。 毆打 乙死亡
  • 若無甲之毆打，乙仍可能因車禍死亡（因果關係中斷？）
  • => 毆打與死亡間無相當因果關係。
不該當（因果關係不成立）
因果關係之重要理論（補充說明）
理論 說明 判斷方式 實例
條件理論（條件因果關係）
  • 若無該行為，即無該結果。
  • => 行為與結果間有因果關係。
「若無X，即無Y」
  • 甲下毒殺乙。
  • 若無甲之下毒，乙不會死亡。
  • => 有因果關係。
相當因果關係理論（相當性） 行為與結果間須有相當性（即行為通常會導致該結果）。 依社會一般經驗判斷
  • 甲刺傷乙，通常會導致死亡 => 有相當因果關係。
  • 若甲刺傷乙，但因醫院火災燒死乙，則無相當因果關係。
客觀歸責理論 若行為人所製造之風險，實現於構成要件結果中，則可歸責。 風險製造＋風險實現
  • 甲酒駕，乙因甲之撞擊而死。
  • 甲製造了風險（酒駕），且該風險實現於乙之死亡 => 可歸責。
客觀構成要件之特別問題
說明 實例
不作為犯 行為人應作為而不作為，且其不作為與結果間有因果關係。
  • 甲為救生員，見乙溺水而不施救，乙死亡。
  • => 甲之不作為與乙之死亡有因果關係（因甲有救生義務）。
加重結果犯 行為人故意犯某罪，因過失致生加重結果。 甲故意毆打乙，過失致乙死亡（傷害致死罪，刑法第277條第2項）。
參照
  • 罪刑法定主義：構成要件須由法律明確規定。
  • 故意與過失：主觀構成要件之核心。
  • 違法性：構成要件該當後之下一階層。
  • 因果關係：民法侵權行為之因果關係與刑法之比較。
小測驗（自我檢視）
  • 犯罪三階層理論之三階層為何？
    • 解答：
      1. 構成要件該當性
      2. 違法性
      3. 罪責
  • 客觀構成要件之三要素為何？
    • 解答：行為、結果、因果關係。
  • 甲刺傷乙，乙送醫途中因車禍死亡，甲之行為與乙之死亡間有無相當因果關係？
    • 解答：無（刺傷與死亡間無相當因果關係，因車禍介入）。
  • 條件理論之判斷公式為何？
    • 解答：「若無X，即無Y」公式。

構成要件該當性（下）——主觀構成要件（故意與過失）

核心概念：行為人的內心狀態
  • 客觀構成要件檢驗「行為人做了什麼」，主觀構成要件則檢驗「行為人想什麼」或「應注意而未注意什麼」。
  • 刑法原则上處罰故意犯，過失犯則須法律有明文規定始處罰之（刑法第12條）。
故意（刑法第13條）
  • 直接故意：明知且有意；間接故意：預見且容任。
    定義 實例
    直接故意（確定故意） 行為人明知並有意使其發生。 甲欲殺乙，持刀朝乙心臟刺入（明知會死亡，且有意使其發生）。
    間接故意（未必故意） 行為人預見其發生，而其發生不違背其本意。 甲在人群中開槍，明知可能擊中路人，但仍開槍（雖非有意，但發生也不違背其本意）。
過失（刑法第14條）
定義 實例
無認識過失 行為人應注意，能注意，而不注意，致發生構成要件結果。 甲駕車時未注意車前狀況，撞傷行人。
  • 應注意且能注意，卻未注意。
有認識過失 行為人預見其發生，但確信其不發生，致發生構成要件結果。 甲酒後駕車，預見可能肇事，但自認「應該不會出事」，結果仍撞傷人。
故意 vs. 過失（綜合比較）
故意（第13條） 過失（第14條）
認識程度 明知或預見構成要件結果 應注意能注意而未注意；或預見但確信不發生
意欲程度 有意使其發生（直接）；或容任其發生（間接） 不希望發生（違反其本意）
可非難性 較高 較低
處罰依據 原則上處罰（刑法第12條第1項） 須法律有明文規定始處罰（刑法第12條第2項）
實例 持刀殺人（殺人故意） 駕車不慎撞死人（過失致死）
構成要件該當性之綜合判斷（客觀＋主觀）
案例 客觀構成要件（行為、結果、因果關係） 主觀構成要件（故意或過失） 構成要件該當性
甲持刀朝乙心臟刺入，乙死亡。 行為（刺入）、結果（死亡）、因果關係（有） 直接故意（明知且有意） 該當（殺人既遂）
甲在人群中開槍，擊中路人乙致死。 行為（開槍）、結果（死亡）、因果關係（有） 間接故意（預見且容任） 該當（殺人既遂）
甲駕車未注意車前狀況，撞傷乙。 行為（駕車）、結果（受傷）、因果關係（有） 無認識過失（應注意能注意而未注意） 該當（過失傷害）
甲酒後駕車，自認不會出事，仍撞傷乙。 行為（駕車）、結果（受傷）、因果關係（有） 有認識過失（預見但確信不發生） 該當（過失傷害）
參照
  • 犯罪論：構成要件該當性為犯罪三階層之第一階層。
  • 客觀構成要件：行為、結果、因果關係。
  • 違法性：構成要件該當後之下一階層。
  • 罪責：構成要件該當且違法後之第三階層。
小測驗（自我檢視）
  • 故意之兩種類型為何？其區別為何？
    • 解答：
      1. 直接故意（明知且有意）
      2. 間接故意（預見且容任）。
  • 過失之兩種類型為何？其區別為何？
    • 解答：
      1. 無認識過失（應注意能注意而未注意）
      2. 有認識過失（預見但確信不發生）。
  • 刑法原則上處罰故意犯或過失犯？
    • 解答：故意犯（過失犯須法律有明文規定始處罰之，刑法第12條第2項）。
  • 甲朝乙開槍，子彈擊中乙致死，甲主觀上應屬何種故意？
    • 解答：直接故意（明知且有意）。
