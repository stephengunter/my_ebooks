3 - 3 行政法基礎 - 行政作用法（上）——行政處分

行政處分之定義、要件與類型

核心概念：什麼是「行政處分」？
  • 行政處分，是指行政機關就公法上具體事件所為之決定或其他公權力措施，而對外直接發生法律效果之單方行政行為。（行政程序法第92條第1項）
  • 行政處分是行政法上最重要、最核心的行政行為類型。人民與行政機關之間的爭議，絕大多數都圍繞著行政處分而發生。
行政處分之五大要件
要件 說明 實例
① 行政機關所為 須由行政機關（非立法、司法機關）作成。 警察開罰單（警察機關）、國稅局核稅（稅捐機關）。
② 公法上之行為 須行使公權力，非私法行為。 核發建照（公法） vs. 採購辦公用品（私法）。
③ 具體事件 針對特定人、特定事，非抽象規範。 對甲核發建照（具體） vs. 訂定建築法規（抽象）。
④ 對外直接發生法律效果 對人民之權利義務產生直接影響。
  • 罰單直接使人民負繳款義務。
  • 駁回申請直接使人民無法取得許可。
⑤ 單方行為 由行政機關單方決定，無須人民同意。 稅單直接送達生效，不須納稅人簽署同意。
行政處分之類型
  • （一）依對相對人之效果分類
    類型 定義 實例
    授益處分 對人民創設、確認權利或法律上利益之處分。 核發建照、發給補助、核准歸化國籍。
    負擔處分 對人民課予義務或限制權利之處分。 課稅處分、罰單、駁回申請、徵收土地。
    混合效力處分 同時對相對人產生授益與負擔效果。 附條件或附負擔之許可（如核准設廠但須設置防污設備）。
    第三人效力處分 不僅對相對人發生效力，亦同時影響第三人權益。 核發建照（對申請人授益；對鄰居可能產生負擔效果）。
  • （二）依內容分類
    類型 定義 實例
    下命處分 課予人民作為、不作為或忍受義務。 罰單、命拆除違建。
    形成處分 創設、變更或消滅法律關係。 核發建照、撤銷駕照。
    確認處分 確認權利或法律關係之存否。 確認公職人員資格、確認地目。
行政處分與其他行政行為之區別
行為類型 定義 與行政處分之區別 實例
法規命令 行政機關對不特定人所訂定之抽象規範。 抽象規範（不針對具體個案）。 道路交通管理處罰條例施行細則。
行政規則 行政機關規範內部秩序之抽象規定。 僅拘束內部，不對外發生效力。 稅務違章案件裁罰參考表。
行政指導 行政機關為實現特定目的，對人民所為之建議或輔導。 無法律強制力，不直接發生法律效果。 環保機關輔導工廠改善設備。
行政契約 行政機關與人民以雙方合意設定法律關係。 雙方行為（非單方）。 公費醫學生契約。
事實行為 行政機關所為之非法律行為（如單純執行、通知、告知）。 不直接發生法律效果。 政府發布颱風警報、清運垃圾。
行政處分之附款（附加條件）
  • 行政機關得於行政處分中附加附款（條件），以確保處分之合法性或達成特定行政目的（行政程序法第93條）。
    附款類型 說明 實例
    期限 處分之效力始於或終於特定時間點。 核發臨時建照，有效期間一年。
    條件 處分之效力繫於未來不確定之事實。 核准設廠，但須於三個月內完成消防檢查始得營運（停止條件）。
    負擔 課予相對人一定之作為、不作為或忍受義務。 核發建照，但須設置隔音牆。
    保留廢止權 行政機關保留將來廢止處分之權限。 核發許可，但保留若違反環保規定得廢止之權。
行政處分之實例綜合判斷
案例 是否為行政處分？ 理由
國稅局寄發所得稅核定通知書 是 行政機關（國稅局）就具體事件（甲之所得）對外直接發生法律效果（應納稅額）。
警察指揮交通（手勢） 否（事實行為） 未直接發生法律效果（僅為現場管制措施）。
環保署訂定空污排放標準 否（法規命令） 針對不特定人訂定之抽象規範。
縣政府公告某道路為單行道 是 行政機關就具體事件（特定道路）對外直接發生法律效果（用路人須遵守）。
行政院發布颱風警報 否（事實行為） 僅為資訊告知，未直接發生法律效果。
參照
  • 行政機關：行政處分之作成主體。
  • 行政程序法第92條：行政處分之法定定義。
  • 法規命令與行政規則：與行政處分之區別。
  • 行政契約：與行政處分之區別。
小測驗（自我檢視）
  • 行政程序法第92條第1項所定之行政處分五大要件為何？
    • 解答：
      1. 行政機關所為。
      2. 公法上行為。
      3. 具體事件。
      4. 對外直接發生法律效果。
      5. 單方行為。
  • 核發建照對申請人而言，屬於何種行政處分？
    • 解答：授益處分（對申請人創設權利）。
  • 行政處分與法規命令最大的不同點為何？
    • 解答：屬違法行為，得撤銷（但若屬輕微瑕疵，可能僅得轉換或補正）。
  • 行政程序法第11條第1項規定之「管轄法定原則」係指何意？
    • 解答：
      • 行政處分針對「具體事件」（特定人、特定事）。
      • 法規命令針對「不特定人」訂定「抽象規範」。
  • 警察指揮交通的手勢，是否屬於行政處分？其定性為何？
    • 解答：否；屬於事實行為（未直接發生法律效果）。

行政處分之效力——存續力、執行力與構成要件效力

核心概念：行政處分作成後，發生何種效力？
  • 行政處分一經合法送達或公告，即發生一定之法律效力。
  • 這些效力是行政處分與其他行政行為最大的不同之處，也是行政處分在實務運作中最核心的機制。
  • 行政處分之效力，主要包含以下四種：存續力、執行力、構成要件效力與確認效力。
存續力（形式的存續力 vs. 實質的存續力）
定義 核心意涵 實例
形式的存續力（不可爭力） 行政處分在法定救濟期間經過後，不得再以通常救濟程序（訴願、行政訴訟）加以爭執。 相對人逾期未提起救濟，處分即告「確定」。 甲收到罰單後未於30日內提起訴願，該罰單即具有形式存續力，甲不得再爭執。
實質的存續力（確定力） 行政處分之內容，對於行政機關本身亦具有拘束力，行政機關不得任意變更或撤銷。 處分所形成之法律關係，行政機關亦須尊重（除非依法撤銷或廢止）。 核發建照後，發照機關不得任意撤銷（須有法定事由）。
  • 【一點就通】：
    • 形式的存續力是「對人民」的拘束（人民不能再爭執）。
    • 實質的存續力是「對機關」的拘束（機關不能再任意變更）。
執行力
說明
定義 行政處分所課予人民之義務，若人民不履行，行政機關得以自己之權力強制執行，無須另行提起訴訟。
法源依據 行政執行法（公法上金錢給付義務之強制執行、行為或不行為義務之強制執行）。
與民事執行之區別
  • 行政執行：由行政機關自行執行（或移送法務部行政執行署）。
  • 民事執行：須向民事法院聲請強制執行（強制執行法）。
執行之種類
  1. 公法上金錢給付義務：欠稅、罰鍰 → 移送行政執行署執行（如扣押財產）。
  2. 行為或不行為義務：命拆除違建、命停止營業 → 由行政機關自行執行（代履行、怠金）。
執行之停止 若處分經訴願或行政訴訟撤銷，執行即應停止。
構成要件效力
說明
定義
  • 行政處分對於其他行政機關或法院具有拘束力。
  • 其他機關應以該處分之存在與內容作為本身決定之基礎或前提。
核心意涵 其他機關不得否定該處分之效力，應「尊重」其存在。
適用對象 對「其他行政機關」及「普通法院」均有拘束力。
實例一（行政機關間）
  • 經濟部核發工廠登記證。
  • 環保署於審查該工廠之環保許可時，應以該工廠已合法登記為前提，不得否定該登記之效力。
實例二（行政機關對法院）
  • 普通法院審理車禍侵權賠償時，應以交通監理機關所核發之駕照有效為前提。
  • 不得否定該駕照之效力（除非該駕照已遭撤銷）。
確認效力（或稱「確認作用」）
說明
定義 行政處分對於其所確認之法律關係或權利狀態，具有一定之確認功能，作為後續相關程序之基礎。
與構成要件效力之區別
  • 構成要件效力：處分本身對其他機關產生拘束。
  • 確認效力：處分所確認之事實或法律關係，可作為其他程序之證據或基礎。
實例 戶政機關核發之身分證（確認身分），可作為辦理護照、駕照、投票等事務之基礎文件。
四種效力之綜合比較
效力類型 拘束對象 核心內容 實務意義
形式的存續力 處分之相對人（人民） 不得再以訴願、訴訟爭執。 確保法律關係之安定性（禁反言）。
實質的存續力 作成處分之機關 不得任意變更或撤銷。 防止行政機關恣意反覆。
執行力 處分之相對人（人民） 不履行時，機關得強制執行。 確保行政目的之實現。
構成要件效力 其他行政機關及法院 應以該處分之存在為前提。 維護行政一體性與法秩序統一。
確認效力 其他行政機關及法院（輔助性） 處分所確認之事實可作為其他程序之基礎。 簡化行政程序，避免重複認定。
行政處分效力之時點（何時發生效力？）
說明
原則 行政處分自送達相對人（或公告）時起，對其發生效力（行政程序法第110條第1項）。
溯及效力 行政處分原則上不溯及既往，但有例外（如補正程序、更正處分等）。
無效處分 自始無效（行政程序法第111條）——自始不生效力。
得撤銷處分 在撤銷前仍屬有效（行政程序法第117條）——未撤銷前仍具效力。
參照
  • 行政處分之定義與要件：效力發生之前提。
  • 行政處分之撤銷與廢止：效力之消滅。
  • 行政執行法：執行力之具體化。
  • 訴願與行政訴訟：撤銷存續力（形式的存續力）之救濟程序。
小測驗（自我檢視）
  • 行政處分在法定救濟期間經過後，不得再以通常救濟程序加以爭執，此為何種效力？
    • 解答：形式的存續力（不可爭力）。
  • 行政機關核發建照後，發照機關不得任意撤銷，此為何種效力？
    • 解答：實質的存續力（確定力）。
  • 經濟部核發工廠登記證後，環保署審查環保許可時應以該登記為前提，此為何種效力？
    • 解答：構成要件效力。
  • 行政處分自何時起發生效力？
    • 解答：自送達相對人或公告時起發生效力（行政程序法第110條第1項）。

行政處分之瑕疵——無效、得撤銷與補正

核心概念：行政處分違法時，如何處理？
  • 行政處分如有違法或不當，並非一律無效。
  • 依其瑕疵之嚴重程度，法律設有不同之法律效果：
    • 無效（最嚴重）。
    • 得撤銷（中等）。
    • 得補正（輕微）。
    • 轉換（變更為其他合法處分）。
無效之行政處分（行政程序法第111條）
說明
定義 行政處分有重大明顯之瑕疵，自始、當然、確定不發生效力。
判斷標準
  1. 瑕疵須重大（違反重要法律規定）。
  2. 瑕疵須明顯（任何人一望即知）。
法律效果 自始無效（無須請求撤銷，當然無效）。
列舉事由 行政程序法第111條列舉七款無效事由：
  1. 不能由書面處分中得知處分機關者。
  2. 應以證書方式作成而未給予證書者。
  3. 內容對任何人均屬不能實現者。
  4. 所要求或許可之行為構成犯罪者。
  5. 內容違背公共秩序、善良風俗者。
  6. 未經授權而違背法規有關專屬管轄之規定或缺乏事務權限者。
  7. 其他具有重大明顯之瑕疵者（概括條款）。
實例 警察機關核發「營業執照」（缺乏事務權限——非其管轄事務），即屬無效。
  • 【一點就通】：無效處分就像「廢紙一張」，自始沒有任何法律效力，任何人都可以不遵守。
得撤銷之行政處分（行政程序法第117條）
說明
定義
  • 行政處分有違法（包括實質違法與程序違法），但尚未達無效程度者。
  • 得由原處分機關或其上級機關依職權或依申請撤銷之。
判斷標準
  1. 處分違法（非僅不當）。
  2. 瑕疵非重大明顯（未達無效程度）。
法律效果
  1. 除斥期間：原則上自原處分機關知有撤銷原因時起2年內為之（行政程序法第121條）。
  2. 信賴保護：若人民有值得保護之信賴，且信賴利益大於撤銷之公益，則不得撤銷（行政程序法第117條但書）。
實例
  • 國稅局計算稅額錯誤（法律適用有誤），稅額過高。
  • 此屬違法但未達無效程度，國稅局得依職權撤銷原處分，重新核課。
得補正之行政處分（行政程序法第114條）
說明
定義
  • 行政處分有程序上或形式上的輕微瑕疵。
  • 得於事後補正，使其成為合法處分。
補正事由 行政程序法第114條第1項列舉五款得補正之事由：
  1. 須經申請始得作成之處分，當事人於事後補正申請。
  2. 必須記明之理由，於事後記明。
  3. 應給予當事人陳述意見之機會，於事後給予。
  4. 應參與行政處分作成之委員會，於事後參與。
  5. 應經其他機關之同意或會簽，於事後補正。
補正時限 須於訴願程序終結前（或行政訴訟事實審言詞辯論終結前）為之（行政程序法第114條第2項）。
法律效果 補正後，處分之瑕疵視為已治癒，處分成為合法。
實例
  • 核發建照時，未給予鄰人陳述意見之機會。
  • 若於訴願前補正（給予鄰人陳述意見），則瑕疵即治癒。
行政處分之轉換（行政程序法第116條）
說明
定義 違法之行政處分，若符合另一合法處分之要件，且轉換後不違反原處分之目的，得轉換為另一合法處分。
要件
  1. 原處分違法（得撤銷）。
  2. 原處分若轉換為另一處分，須符合該處分之要件。
  3. 轉換後之目的與原處分相同。
  4. 對當事人無不利之影響。
實例
  • 行政機關欲作成「裁罰處分」（罰款），但誤以「命補繳稅款」之方式為之。
  • 若事實符合罰款之要件，得轉換為罰款處分。
四種瑕疵態樣之綜合比較
案例 法條依據 瑕疵程度 法律效果 補救方式
無效 行政程序法第111條 重大明顯 自始當然無效 確認無效訴訟
得撤銷 行政程序法第117條 違法（非重大明顯） 撤銷前仍有效 訴願／行政訴訟撤銷
得補正 行政程序法第114條 輕微程序瑕疵 補正後治癒 於訴願終結前補正

無效與得撤銷之區別實例
案例 瑕疵類型 判斷理由
警察機關核發「醫師執業執照」 無效 警察機關完全無核發醫師執照之權限（缺乏事務管轄權），任何人一望即知。

環保機關核發建照，卻未依規定送請都市計畫委員會審查 得補正 屬程序瑕疵，可於事後補送委員會審查。
行政機關對甲公司作成處分，卻誤送達給乙公司 得撤銷（送達瑕疵） 未合法送達，處分尚未生效，須重新送達。
參照
  • 行政程序法第111條、第114條、第117條、第116條：本節核心法條。
  • 信賴保護原則：撤銷處分時須考量信賴利益。
  • 訴願與行政訴訟：對得撤銷處分之救濟程序。
  • 行政處分之效力：處分瑕疵與效力之關聯。
小測驗（自我檢視）
  • 行政程序法第111條所定之「無效」處分，其判斷標準為何？
    • 解答：重大且明顯之瑕疵（任何人一望即知）。
  • 得撤銷之行政處分，其撤銷有無時間限制？
    • 解答：原則上自原處分機關知有撤銷原因時起2年內為之（除斥期間）。
  • 行政處分未給予當事人陳述意見之機會，此屬何種瑕疵？應如何補救？
    • 解答：屬得補正之程序瑕疵；得於訴願程序終結前給予陳述意見之機會以補正。
  • 無效處分與得撤銷處分之最大區別為何？
    • 解答：
      • 無效處分自始當然無效（不生任何效力）。
      • 得撤銷處分在撤銷前仍屬有效，須經撤銷始失其效力。
