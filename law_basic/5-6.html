5 - 6 刑法基礎 - 刑法分則（與公務員職務相關之犯罪）

概說與犯罪主體

核心概念：什麼是「公務員職務犯罪」？
  • 公務員職務犯罪，是指公務員利用其職務上之權力、機會或方法，或違背其職務上之義務，所實施之犯罪行為。 此類犯罪不僅侵害國家法益，亦嚴重損害人民對政府之信賴。
  • 職務犯罪主要規定於刑法分則之「瀆職罪章」（第120條至第134條）及「貪污治罪條例」等特別法中，係刑法規範中極為重要之一環。
刑法分則中與公務員職務相關之犯罪類型
類型 核心內容 說明
純正職務犯罪 僅公務員始能構成之犯罪（如受賄罪、濫用職權罪）。 犯罪主體須具備「公務員」身分。
非純正職務犯罪 一般人亦能構成，但公務員犯之者加重其刑（刑法第134條）。 公務員假借職務上權力、機會或方法犯罪者，加重其刑至二分之一。
公務員職務犯罪之主體——「公務員」之認定
  • 職務犯罪之核心，在於行為人是否具備「公務員」身分。刑法第10條第2項對公務員有明確定義，可分為三類：
    類型 定義 說明 實例
    身分公務員 依法令服務於國家、地方自治團體所屬機關，而具有法定職務權限者。 最典型之公務員，即一般所稱之「國家機關人員」。 警察、法官、檢察官、各級政府機關之公務人員。
    授權公務員 其他依法令從事於公共事務，而具有法定職務權限者。 非機關編制內人員，但依法行使公共事務職權。
    • 依政府採購法辦理採購之公立學校、公營事業人員。
    • 受託行使公權力之團體或個人（如代檢驗車之民間代檢廠人員）。
    委託公務員 受國家、地方自治團體所屬機關依法委託，從事與委託機關權限有關之公共事務者。 因「委託」而取得公權力行使資格。 受環保機關委託執行廢棄物稽查之民間業者。
  • 判斷關鍵：是否為公務員，核心在於是否「從事公共事務」或「行使公權力」，而非僅以是否有「公務員任用資格」為唯一標準。
  • 刑法第10條第2項之立法意旨：
    • 為避免公務員定義過於狹隘，刑法第10條第2項採取「實質認定」之立場，以「從事公共事務」及「行使公權力」為核心， 將非機關編制內但實際從事公共事務之人員納入規範。
    • 此立法模式，旨在因應現代國家行政職能之多元化，避免非典型公務員利用職務漏洞規避刑責。
公務員職務犯罪之主要類型
犯罪類型 法條依據 核心行為 說明
賄賂罪（收賄） 刑法第121條、第122條 公務員對於職務上之行為（或違背職務之行為），要求、期約或收受賄賂。 最典型之貪污犯罪，須有「對價關係」。
圖利罪 刑法第131條 公務員對於主管或監督之事務，明知違背法令，直接或間接圖自己或其他私人不法利益。 須有「不法利益」之結果。
濫用職權罪 刑法第125條等 公務員濫用職權，違法逮捕、羈押、追訴、處罰。 侵害人民自由權利。
廢弛職務釀成災害罪 刑法第130條 公務員廢弛職務，釀成災害。 須有「災害」之實害結果。
洩密罪 刑法第132條 公務員洩漏或交付國防以外應秘密之文書、圖畫、消息或物品。 侵害國家機密與行政機密。
參照
  • 公務員法：行政法上公務員之定義，與刑法公務員定義之差異。
  • 瀆職罪章：各罪之具體構成要件與實例。
小測驗（自我檢視）
  • 刑法第10條第2項所定之公務員分為哪三類？
    • 解答：身分公務員、授權公務員、委託公務員。
  • 公務員職務犯罪之「純正」與「非純正」如何區分？
    • 解答：
      • 純正職務犯罪僅公務員始能構成。
      • 非純正職務犯罪一般人亦能構成，但公務員犯之者加重其刑（刑法第134條）。
  • 公務員圖利罪規定於刑法第幾條？
    • 解答：刑法第131條。

瀆職罪章（上）——賄賂罪與圖利罪

核心概念：最核心之職務犯罪類型
  • 瀆職罪章（刑法第120條至第134條）係刑法分則中規範公務員職務犯罪最主要之章節。本章介紹其中最常見且最重要之兩類犯罪：賄賂罪（收受賄賂）與圖利罪。
賄賂罪（收受賄賂罪，刑法第121條、第122條）
說明
定義 公務員或仲裁人對於職務上之行為，要求、期約或收受賄賂或其他不正利益者，構成賄賂罪。（刑法第121條第1項）
行為態樣
  1. 要求：向相對人索賄（尚未取得）。
  2. 期約：雙方達成合意（尚未交付）。
  3. 收受：已實際收受賄賂或不正利益。
對價關係 賄賂須與公務員之職務行為間有對價關係（即「以金錢換取職務行為」）。
刑度
  • 不違背職務之受賄罪（§121）：處7年以下有期徒刑，得併科罰金。
  • 違背職務之受賄罪（§122Ⅰ）：處無期徒刑或10年以上有期徒刑，得併科罰金。
行賄罪（對向犯）
  • 對公務員行賄者，亦構成犯罪（§122Ⅲ、§122Ⅳ）。
  • 行賄者若自首或於偵審中自白，得減輕或免除其刑。
實例
  • 甲為建商，為求快速取得建照，交付100萬元予承辦公務員乙（職務上行為）。
  • 乙收受後，加速審查核發建照。
  • => 乙構成收賄罪，甲構成行賄罪。
圖利罪（刑法第131條）
說明
定義 公務員對於主管或監督之事務，明知違背法令，直接或間接圖自己或其他私人不法利益，因而獲得利益者。（刑法第131條第1項）
構成要件
  1. 行為主體：公務員（對主管或監督之事務）。
  2. 客觀行為：明知違背法令，直接或間接圖利。
  3. 結果：自己或他人獲得不法利益。
  4. 主觀：須有直接故意（明知違背法令）。
要件分析
  1. 明知違背法令：須對「法令」有明確認知（非過失或不知）。
  2. 不法利益：須為「不法」之利益（合法利益不構成）。
  3. 結果犯：須有「獲得利益」之實害結果，始成立犯罪（未遂不罰）。
與賄賂罪之區別
  • 圖利罪：無對價關係，重點在於「違背法令圖利自己或他人」。
  • 賄賂罪：須有「對價關係」。（以金錢換取職務行為）。
實例
  • 甲為承辦採購之公務員，明知乙公司不符合投標資格，仍違法使其得標，使乙公司獲取1000萬元之利益。
  • => 甲構成圖利罪。
賄賂罪 vs. 圖利罪（綜合比較）
賄賂罪 圖利罪
行為態樣 要求、期約或收受賄賂 直接或間接圖利
對價關係 有（賄賂與職務行為間） 無（無對價關係）
行為人 公務員或仲裁人 公務員（主管或監督事務）
主觀要件 故意 直接故意（明知違背法令）
結果要件 不要求實害結果（行為犯） 須有「不法利益」之結果（結果犯）
法條依據 刑法第121條、第122條 刑法第131條
實例 收受賄賂加速核發建照 違法圖利特定廠商得標
行賄罪之特別規定
說明
對向犯 行賄罪與收賄罪係「對向犯」（雙方對立之行為）。
減免規定 犯行賄罪者，若於犯罪後自首或於偵審中自白，得減輕或免除其刑（刑法第122條第4項）。
立法目的 鼓勵行賄者供出收賄者，以利偵查貪污犯罪。
參照
  • 公務員身分：賄賂罪與圖利罪之犯罪主體。
  • 貪污治罪條例：特別法與刑法之適用關係（特別法優於普通法）。
小測驗（自我檢視）
  • 賄賂罪之三種行為態樣為何？
    • 解答：要求、期約、收受。
  • 賄賂罪與圖利罪最大的不同點為何？
    • 解答：賄賂罪須有「對價關係」；圖利罪無對價關係，重點在於「違背法令圖利」。
  • 圖利罪之構成要件中，行為人主觀上須具備何種要件？
    • 解答：直接故意（明知違背法令）。
  • 行賄者自首或於偵審中自白，其法律效果為何？
    • 解答：得減輕或免除其刑（刑法第122條第4項）。

瀆職罪章（下）——濫用職權罪、廢弛職務罪與洩密罪

核心概念：其他重要職務犯罪類型
  • 除賄賂罪與圖利罪外，瀆職罪章尚規範其他類型之職務犯罪。以下介紹其中最重要者：濫用職權罪、廢弛職務釀成災害罪及洩密罪。
濫用職權罪（刑法第125條）
說明
定義
  • 公務員對於追訴或處罰之職務，明知為無罪之人，而使其受追訴或處罰。
  • 或明知為有罪之人，而使其不受追訴或處罰。（刑法第125條第1項）
行為態樣
  • 明知無罪之人，而使其受追訴或處罰。
  • 明知有罪之人，而使其不受追訴或處罰。
  • 違法逮捕、羈押或取供。
構成要件
  • 行為主體：有追訴或處罰職務之公務員（如檢察官、法官、司法警察）。
  • 客觀行為：濫用職權，為違法之追訴、處罰或不追訴、不處罰。
  • 主觀要件：故意（明知其行為違法）。
刑度 處1年以上7年以下有期徒刑。
實例
  • 檢察官甲明知乙未犯罪，因私人恩怨，仍對乙提起公訴（濫用追訴權）。
  • => 甲構成濫用職權罪。
廢弛職務釀成災害罪（刑法第130條）
說明
定義 公務員廢弛職務，釀成災害者。（刑法第130條）
構成要件
  1. 行為主體：公務員（不問職務種類）。
  2. 客觀行為：廢弛職務（應作為而不作為，或怠於執行職務）。
  3. 結果：須釀成災害（須有實害結果）。
  4. 因果關係：災害須與廢弛職務間有因果關係。
主觀要件 故意或過失（實務上多為過失）。
刑度 處3年以上10年以下有期徒刑。
實例
  • 甲為水庫管理員，明知水庫閘門故障，卻怠於修繕（廢弛職務）。
  • 其後豪雨來襲，水庫無法洩洪，致下游村莊淹水（釀成災害）。
  • => 甲構成廢弛職務釀成災害罪。
洩密罪（刑法第132條）
說明
定義 公務員洩漏或交付關於國防以外應秘密之文書、圖畫、消息或物品者。（刑法第132條第1項）
構成要件
  1. 行為主體：公務員。
  2. 客體：國防以外應秘密之文書、圖畫、消息或物品。
  3. 客觀行為：洩漏或交付。
  4. 主觀要件：故意（過失不罰）。
刑度 處3年以下有期徒刑。
  • 若因過失犯之，處1年以下有期徒刑、拘役或罰金（刑法第132條第2項）。
實例
  • 甲為警察，將偵查中案件之筆錄內容洩漏予媒體（國防以外應秘密之文書）。
  • => 甲構成洩密罪。
公務員犯罪之加重規定——刑法第134條
說明
定義 公務員假借職務上之權力、機會或方法，以故意犯本章以外各罪者，加重其刑至二分之一。（刑法第134條前段）
要件
  1. 行為人須為公務員。
  2. 須「假借」職務上之權力、機會或方法。
  3. 所犯之罪須為「本章以外」之罪（即非瀆職罪章之罪）。
  4. 須為故意犯（過失犯不加重）。
例外 若該罪已有特別規定，則不適用本條。
  • 如公務員犯職務上之罪已有加重規定。
實例
  • 警察甲假借臨檢職務之機會（職務上機會），對民眾乙施以強制猥褻（妨害性自主罪）。
  • => 甲構成刑法第134條之加重事由，應加重其刑至二分之一。
瀆職罪章各罪之綜合比較
法條刑度 行為主體 行為態樣 結果要件
賄賂罪 §121、§122：7年以下／無期徒刑或10年以上 公務員或仲裁人 要求、期約或收受賄賂 行為犯（無須結果）

  • 貪污治罪條例：特別法與刑法之適用關係（特別法優於普通法）。

  • 刑法第125條之濫用職權罪，其行為主體為何？
    • 解答：有追訴或處罰職務之公務員（如檢察官、法官、司法警察）。
  • 廢弛職務釀成災害罪之主觀要件為何？
    • 解答：故意或過失（實務上多為過失）。

    • 解答：①公務員；②假借職務上之權力、機會或方法；③犯瀆職罪章以外之故意罪。
  • 洩密罪之客體為何？
    • 解答：國防以外應秘密之文書、圖畫、消息或物品。
