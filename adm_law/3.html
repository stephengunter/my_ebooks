3 行政契約

第135條 行政契約之容許性（契約自由原則與限制）
  • 「公法上法律關係得以契約設定、變更或消滅之。但依其性質或法規規定不得締約者，不在此限。」
這一條是關於？
  • 政府與人民之間的「公法上的法律關係」（例如補助關係、許可關係、使用關係）， 原則上可以用「契約」的方式來「建立、改變或消滅」——
    • 也就是說，政府不一定只能用「行政處分」單方面命令， 也可以用「雙方約定」的方式來處理。
    • 但是，如果「法律關係的性質」不適合用契約（例如涉及國家主權、軍隊指揮）， 或者「法律有特別規定」不能用契約，那就不能締結行政契約。
  • 簡單講：公法關係，原則上可以用契約來處理；但有些事不適合或法律不准，就不能用。
這一條的核心
  • 第135條宣示了一個重要原則：行政契約作為行政行為的一種形式，與行政處分並行，受到法律的承認與保障。
  • 公法上法律關係：指受公法規範的法律關係（而非私法關係，如政府買文具）。
    • 例如：補助關係、公費生培養關係、公共設施使用關係、土地開發協議、行政和解契約等。
  • 得以契約設定、變更或消滅：行政機關可以選擇用「契約」代替「行政處分」來形成法律關係。
    • 契約內容可以創設新的法律關係（設定）、修改現有關係（變更）、或終止關係（消滅）。
    • 這體現了「行政契約自由原則」——行政機關在法定範圍內，有選擇締約與否、與誰締約、約定什麼內容的自由。
  • 但書限制（不得締約的情形）：
    • 依其性質不得締約：某些公法關係的「本質」不適合用契約。
      • 例如：國家主權行為（宣戰、締結條約）、軍隊指揮關係、 刑事追訴、租稅核定（稅額依法計算，無協商空間）。
    • 法規規定不得締約：法律或法規命令明文禁止以契約方式為之。
      • 例如：某些法律規定只能以行政處分為之，不得締結契約。
  • 行政契約與行政處分的關係：
    • 行政處分是「單方」行為；行政契約是「雙方」行為（須經雙方合意）。
    • 行政契約的當事人（人民）有較高的參與權與協商空間，更能體現「合作行政」的精神。
  • 本條的設計精神是：在依法行政的前提下，引進契約自由原則，
    • 鼓勵行政機關與人民透過合作、協商的方式解決公法爭議或形成法律關係，以取代傳統的單方高權行為。
條文拆解
  • 「公法上法律關係」 ：政府與人民之間「不是買賣、租賃那種私法關係」，而是涉及公共事務的關係。
    • 指受公法（憲法、行政法、稅法、環境法等）規範的法律關係。
    • 特徵：至少有一方當事人為行政機關，且涉及公共利益的實現。
    • 例子：
      • 補助關係（機關補助民間團體）
      • 公費生培養關係（國家出資培養學生，學生畢業後服務）
      • 公共設施使用關係（停車場、游泳池使用契約）
      • 行政和解契約（代替行政處分）
      • 土地開發協議（都市更新、區段徵收）
  • 「得以契約設定、變更或消滅之」 ：政府跟你可以坐下來談，用簽約的方式來決定雙方的權利義務。
    • 設定：創建一個原本不存在的公法關係（例如簽訂補助契約）。
    • 變更：修改已存在的公法關係的內容（例如變更補助金額或用途）。
    • 消滅：終止一個公法關係（例如合意解除契約）。
    • 契約：雙方意思表示合致，以書面為原則（第139條）。
  • 「但依其性質或法規規定不得締約者，不在此限」 ：有些事（如宣戰、徵稅）不適合用簽約的，或者法律說不能用簽約的，那就不能簽。
    • 依其性質不得締約：
      • 涉及「高權核心領域」的事項（如國家安全、軍事指揮、刑罰權行使、稅額核定）。
      • 法律關係的性質要求「單方決定」而非「雙方協商」（如警察對於突發危害的即時處置）。
    • 法規規定不得締約：法律明文禁止以契約方式為之。
      • 例如：某些法規規定特定事項「應以行政處分為之」，即排除契約。
    • 不在此限：在上述情形下，不得締結行政契約，仍應以行政處分或其他法定方式為之。
為什麼要有這條規定？
  • 引進契約自由原則於公法領域：改變傳統「行政機關單方高權」的思維，鼓勵合作行政。
  • 提升人民參與與程序正義：透過雙方協商，人民更能接受行政決定，減少後續爭訟。
  • 明確行政契約的容許性：過去對於行政契約是否合法有爭議，本條明文承認其為行政行為的一種形式。
  • 設定契約界限：但書排除不適合締約的事項，避免契約自由被濫用，影響公共利益。
  • 與德國行政程序法第54條接軌：我國行政程序法參考德國法制，本條即對應德國聯邦行政程序法第54條。
白話文
  • 政府跟人民之間的公法關係（例如補助、許可、公共設施使用）：
    • 原則上可以用「簽約」的方式來建立、修改或消滅——也就是雙方坐下來談，達成協議，而不是政府單方面說了算。
    • 但是，如果這個法律關係的「性質」不適合用簽約的（例如國家主權行為、軍事指揮、稅務核定），或者法律「明文規定」不能用簽約的，那就不能簽約，還是要用行政處分或其他法定方式處理。
  • 簡單記：公法關係，原則可以簽約處理；但性質不適合或法律禁止的，就不能簽。
舉個例子
例1：得締結行政契約——補助契約
  • 文化部為推廣藝術活動，與某藝文團體簽訂「補助契約」， 約定文化部補助100萬元，藝文團體須舉辦10場公開演出，並於活動結束後提交成果報告。
  • → 符合第135條本文。公法上之補助關係，得以契約設定、變更或消滅。
例2：得締結行政契約——公費生契約
  • 教育部與某醫學生簽訂「公費生契約」，約定國家負擔學費及生活費，學生畢業後須至偏鄉服務6年。
  • → 符合第135條本文。公費生培養關係，得以契約設定。
例3：得締結行政契約——行政和解契約
  • 某工廠因排放廢水被環保局調查，雙方為避免訴訟，簽訂「行政和解契約」， 約定工廠自願設置污染防治設備並繳納一定金額，環保局則不再追究行政責任。
  • → 符合第135條本文。公法上爭議得以和解契約解決。
例4：性質不得締約——稅額核定
  • 稅捐稽徵機關核定納稅義務人的所得稅額， 法律規定應依稅捐稽徵法核定，不得與納稅人「協商稅額」後簽約。
  • → 適用第135條但書「依其性質不得締約」。稅額核定涉及法定計算，不適合以契約方式為之。
例5：法規規定不得締約——兵役徵集
  • 兵役法規定，役男應依徵集令入營服役。 主管機關不得與役男簽訂「自願入營契約」來代替徵集令。
  • → 適用第135條但書「法規規定不得締約」（或性質不得締約）。兵役徵集涉及國家高權，應以行政處分為之。

一句話總結
    第135條是「行政契約原則容許」條款——
  • 公法關係可以用簽約的方式來處理，除非性質不適合或法律禁止。
第136條 行政和解契約（代替行政處分）
  • 「行政機關對於行政處分所依據之事實或法律關係，經依職權調查仍不能確定者，為有效達成行政目的，並解決爭執，得與人民和解，締結行政契約，以代替行政處分。」
這一條是關於？
  • 當政府想要作一個行政處分（例如裁罰、許可），但對於「事實到底是怎樣」 或「法律關係該怎麼解釋」——政府自己已經盡力調查了，還是沒辦法確定。
    • 這時候，為了「有效達成行政目的」和「解決爭議」，政府可以跟人民「和解」
    • 雙方各退一步，簽一個行政契約，來代替原本的行政處分。
  • 簡單講：政府查不清楚，乾脆跟人民談條件、簽契約，代替單方處分。
這一條的核心
  • 第136條是第135條的特別類型——「行政和解契約」。
    • 它允許行政機關在事實或法律關係「不明確」的情況下，
    • 放棄單方作成行政處分，改以「協商和解」的方式與人民達成協議。
  • 適用前提（要件）：
    • 行政機關「依職權調查」事實及法律關係（第36條以下）。
    • 調查後「仍不能確定」——也就是事實真偽不明、法律關係有爭議。
    • 但注意：不能是機關「故意不調查」就說不能確定；必須是「已盡調查義務仍無法確定」。
  • 目的：
    • 「為有效達成行政目的」：和解仍須符合行政目的，不能違背公共利益。
    • 「並解決爭執」：避免後續的訴願、訴訟，節省行政及司法資源。
  • 代替行政處分：
    • 原本機關可以作成行政處分（可能是授益處分或負擔處分）。
    • 但機關選擇以「和解契約」來取代處分——雙方互相讓步，達成協議。
  • 法律效果：
    • 一旦締結和解契約，機關即不得再就同一事件作成行政處分（除非契約另有約定或事後情事變更）。
    • 雙方應依契約內容履行；若有爭議，依行政契約之救濟途徑（給付訴訟、確認訴訟），而非撤銷訴訟。
  • 與民事和解的區別：
    • 民事和解（民法第736條）解決私法爭議；行政和解解決公法爭議。
    • 行政和解須受「依法行政原則」拘束，不得違反法律強制規定。
  • 本條的設計精神是：
    • 在事實不明、法律關係爭議的情況下，用「合作、協商」代替「對抗、裁決」，
    • 既能達成行政目的，又能減少訟源，實現雙贏。
條文拆解
  • 「行政機關對於行政處分所依據之事實或法律關係」 ：就是政府作決定時，需要先弄清楚的那些「事實」和「法律問題」。
    • 行政處分所依據之事實：例如：裁罰處分所需認定的違規行為是否發生、發生在何時何地、行為人是誰。
    • 法律關係：例如：雙方之間是否存在公法上債權債務關係、是否適用特定法規、是否有管轄權等。
  • 「經依職權調查仍不能確定者」 ：政府已經盡力查了，還是查不清楚。
    • 依職權調查：行政機關應依第36條以下，主動調查事實及證據，不受當事人主張拘束。
    • 仍不能確定：
      • 事實真偽不明（如證據不足、證人記憶不清、關鍵文件遺失）。
      • 法律關係有重大爭議（如法規解釋有分歧、最高法院見解尚未統一）。
    • 注意：機關不能「故意不調查」；必須已盡合理調查義務（如調閱資料、詢問證人、鑑定）。
  • 「為有效達成行政目的，並解決爭執」 ：簽約是為了「把事情解決掉」，同時要符合政府的政策目標。
    • 為有效達成行政目的：和解之內容須符合行政機關原本所欲達成之公益目的，不得背離。
    • 並解決爭執：和解旨在終結雙方對事實或法律關係的爭議，避免進入訴訟。
    • 兩者缺一不可：不能只為解決爭執而犧牲行政目的；也不能只為行政目的而強迫人民接受不合理條件。
  • 「得與人民和解，締結行政契約，以代替行政處分」 ：政府可以跟你「談條件」，簽一份契約，代替原本要發給你的那張「處分書」。
    • 得：裁量權。機關可以選擇和解，也可以選擇不作成處分、或作成就爭議的處分（讓人民去訴願、訴訟）。
    • 和解：雙方互相讓步。人民可能放棄部分權利、負擔部分義務；機關也可能減免處罰或給付。
    • 締結行政契約：須以書面為之（第139條），內容不得違反強制規定或公序良俗（第142條）。
    • 以代替行政處分：一旦締約，機關即不得再就同一事件作成行政處分（除非契約另有保留）。
為什麼要有這條規定？
  • 節省行政與司法資源：避免案件因事實不明進入冗長的訴願、訴訟程序。
  • 促進合作行政：鼓勵行政機關與人民以協商、對話方式解決爭議，減少對抗。
  • 保障人民權益：在不確定的情況下，人民可透過協商獲得較有利的結果（而非被動接受行政處分）。
  • 與民事訴訟法之和解制度呼應：民事訴訟允許當事人成立訴訟上和解；行政程序亦應允許行政和解。
  • 填補依法行政與實質正義間的縫隙：當事實無法查明時，僵硬的依法處分可能造成不公平；和解提供彈性解決方案。
白話文
  • 政府本來要作一個行政處分（例如罰你、或發許可給你）， 但是在調查事實或法律問題時，已經盡力查了還是「查不清楚」。
    • 為了「把事情解決掉」並且「符合行政目的」，政府可以跟你「和解」——
    • 雙方各自讓一步，簽一份行政契約，來代替原本的行政處分。
  • 例如政府懷疑你違規，但證據不足：
    • 你可以同意繳一筆較少的罰款，政府就不再追究；
    • 或者雙方約定某種條件，取代原本的許可或裁罰。
  • 簡單記：政府查不清楚，乾脆跟你談條件、簽契約，代替處分。
舉個例子
例1：事實不明——和解契約
  • 環保局稽查某工廠，發現河川有污染物，懷疑是該工廠排放， 但監視器未拍到、科學鑑定也無法100%確定污染源。
  • 雙方為避免訴訟，達成和解：工廠自願繳納60萬元（法定最高可能為100萬元） 作為環境改善基金，環保局則不再追究。
  • → 符合第136條。
    • 事實經調查仍不能確定，
    • 為達成行政目的（環境保護）並解決爭執， 締結行政和解契約，代替裁罰處分。
例2：法律關係爭議——和解契約
  • 某財團法人與文化部對於補助契約之法律關係發生爭議 （契約是否有效、補助款是否應返還）。
  • 雙方經協商達成和解：財團法人返還部分補助款，文化部同意不再追討其餘部分， 並重新簽訂新補助契約。
  • → 符合第136條。法律關係經調查仍有爭議，以和解契約解決。
例3：不得和解——事實已明確
  • 警察取締酒駕，酒測值明確超標（0.55mg/L），事實已確定。 警察不得與駕駛人「和解」說「你繳一半罰款，我們就不移送」。
  • → 不適用第136條（事實已確定，無「不能確定」）。仍應依法作成行政處分（罰單）。
例4：不得和解——機關未盡調查義務
  • 機關未進行任何調查，逕以「事實不能確定」為由，要求人民和解。
  • → 不適用第136條。機關須先依職權調查，不得故意不調查即和解。

第137條 雙務行政契約之要件（互負給付義務）
  1. 「行政機關與人民締結行政契約，互負給付義務者，應符合下列各款之規定︰」
    • 一、契約中應約定人民給付之特定用途。
    • 二、人民之給付有助於行政機關執行其職務。
    • 三、人民之給付與行政機關之給付應相當，並具有正當合理之關聯。
  2. 「行政處分之作成，行政機關無裁量權時，代替該行政處分之行政契約所約定之人民給付，以依第九十三條第一項規定得為附款者為限。」
  3. 「第一項契約應載明人民給付之特定用途及僅供該特定用途使用之意旨。」
這一條是關於？
  • 政府跟人民簽「行政契約」，而且雙方都「互負給付義務」（你給我東西，我也給你東西）， 這種契約叫「雙務契約」。
  • 為了避免政府濫用權力，法律設了三個限制：
    • 第一，契約要寫清楚「人民給付的東西要拿來做什麼特定用途」；
    • 第二，人民的給付「必須有助於政府執行職務」；
    • 第三，人民的給付跟政府的給付「要相當」，而且要有「正當合理的關聯」（不能亂掛鉤）。
  • 另外，如果政府原本要作一個行政處分，而且這個處分政府「沒有裁量權」（只能依法照做），
    • 那麼用契約代替這個處分時，要求人民給付的內容， 只能相當於「如果作行政處分時可以附加的附款」的範圍。
  • 最後，契約一定要寫明「人民給付的特定用途」，而且只能用在這個用途。
  • 簡單講：雙務行政契約不能亂簽，人民的付出必須跟政府的付出有正當連結，不能過度。
這一條的核心
  • 第137條是行政契約中「雙務契約」的特別規定。行政契約可以分為：
    • 「單務契約」（僅一方負給付義務，如補助契約——政府給錢，人民無對待給付）
    • 「雙務契約」（雙方互負給付義務）。
    本條規範的是雙務契約。
  • 雙務契約的三項要件（第1項）：
    • 第1款（特定用途）：人民的給付必須約定「特定用途」，不能是「隨機關使用」。
      • 這是為了避免政府將人民的給付挪作他用或濫用。
    • 第2款（有助於執行職務）：人民的給付必須與機關的職務有關，不能是「無關的捐贈」或「不當利益輸送」。
    • 第3款（相當且正當關聯）：
      • 相當：比例原則——人民的給付與政府的給付不能顯失均衡。
      • 正當合理之關聯：不當連結禁止原則——人民的給付必須與政府給付的「目的」有合理關聯。
  • 羈束處分替代契約之限制（第2項）： 如果政府原本要作的行政處分是「羈束處分」（無裁量權，只能依法照做）：
    • 那麼用契約代替這個處分時，要求人民的給付， 只能相當於「如果作行政處分時可以附加的附款」（依第93條第1項）。
    • 目的：避免機關利用契約，要求人民給付法律所不允許的內容，規避羈束處分的限制。
  • 書面記載義務（第3項）：
    • 契約應載明「人民給付之特定用途」及「僅供該特定用途使用」。
    • 這是第1項第1款的具體化與強化。
  • 本條的設計精神是：在允許行政機關與人民締結雙務契約的同時，
    • 透過「目的限制」、「功能關聯」、「比例原則」及「羈束處分不得擴權」等機制，
    • 防止機關濫用契約形式，規避依法行政與不當連結禁止原則。
條文拆解
第一項本文：雙務契約之要件
  • 「行政機關與人民締結行政契約，互負給付義務者」 ：雙方都要付出，不是單方面給好處。
    • 互負給付義務：雙方各自負有給付義務（如政府給補助款，人民提供勞務或服務）。
    • 不包括「單務契約」（僅一方給付）。
  • 「應符合下列各款之規定」 ：以下三件事都要做到，否則契約無效。
  • 第一款：契約中應約定人民給付之特定用途 ：要寫清楚「你給的錢或東西，只能用在某個特定目的上」。
    • 特定用途：必須具體明確，例如「供環境保護基金使用」、「作為偏鄉教育推廣經費」。
    • 不得為「由機關自行運用」或「供機關業務費使用」等概括用途。
  • 第二款：人民之給付有助於行政機關執行其職務 ：你給的東西，要能幫助政府做事，不能只是「討好」政府。
    • 有助於執行其職務：人民的給付須與機關的法定職務有關，且對職務之執行有積極幫助。
    • 不得是「無關的捐贈」或「單純的利益輸送」。
  • 第三款：人民之給付與行政機關之給付應相當，並具有正當合理之關聯 ：你付出的跟政府付出的要差不多對等，而且要有合理的關係，不能亂掛鉤。
    • 相當：比例原則——給付與對待給付之間不能顯失公平。
      • 例如：政府給1,000萬元補助，要求人民提供價值僅1萬元的服務 → 可能不相當。
    • 正當合理之關聯：不當連結禁止原則—— 人民的給付必須與行政機關給付的「目的」有合理關聯。
      • 例如：政府發建照（目的：合法建築）， 要求人民捐贈公園用地（有合理關聯，因涉及都市計畫）→ 正當關聯。
      • 要求人民捐獻給某政黨 → 不當關聯，違反本款。
第二項：羈束處分替代契約之限制
  • 「行政處分之作成，行政機關無裁量權時」 ：如果法律規定政府只能「照做」，沒有選擇空間。
    • 無裁量權：即「羈束處分」——法律規定機關只能為特定處分，別無選擇。
  • 「代替該行政處分之行政契約所約定之人民給付，以依第九十三條第一項規定得為附款者為限」 ：如果政府本來只能依法照做、不能亂加條件，那麼用簽約的方式， 也不能要求人民做超過「原本可以附加的附款」的事情。
    • 代替該行政處分之行政契約：用契約來取代原本應作成的羈束處分。
    • 以依第93條第1項規定得為附款者為限：
      • 第93條第1項規定：無裁量權時，僅於「法律有明文規定」 或「為確保行政處分法定要件之履行」時，始得附加款。
      • 本項將此限制延伸至行政契約：契約要求人民的給付， 不得超過「如果作行政處分時可以附加的附款」的範圍。
第三項：特定用途之書面記載義務
  • 「第一項契約應載明人民給付之特定用途及僅供該特定用途使用之意旨」 ：合約上要白紙黑字寫清楚「你給的錢只能用在○○○，不能挪作他用」。
    • 應載明：強制書面記載，違反者，依第142條第2款，契約無效。
    • 特定用途：同第1項第1款，須具體明確。
    • 僅供該特定用途使用之意旨：須明確表示「該給付不得移作他用」。
為什麼要有這條規定？
  • 防止行政機關濫用契約形式規避法律限制：避免機關利用雙務契約，要求人民給付法律所不允許的內容。
  • 落實不當連結禁止原則：第1項第3款確保人民的給付與政府的給付有正當關聯。
  • 保障人民權益：避免政府利用優勢地位，要求顯不相當的給付。
  • 維護羈束處分之規範效力：第2項確保機關不能透過契約，規避羈束處分的限制。
  • 強化契約透明度：第3項要求載明特定用途，使人民知悉其給付之去向。
白話文
  • 政府跟人民簽「行政契約」，如果雙方「都要付出」（例如政府給錢，人民提供服務），這種契約要符合三個條件：
    1. 要寫清楚人民付出的東西「只能用在哪個特定用途」（不能讓政府亂用）。
    2. 人民的付出必須「有助於政府執行職務」（不能是無關的捐贈）。
    3. 人民的付出跟政府的付出要「相當」，而且要有「正當合理的關聯」（不能顯失公平，也不能亂掛鉤）。
  • 如果政府本來要作一個「行政處分」，而且這個處分政府「沒有裁量權」（只能依法照做）， 那麼用契約代替這個處分時，要求人民的付出：
    • 只能相當於「如果作處分時可以附加的附款」的範圍，不能超出。
  • 另外，契約一定要寫清楚「人民付出的特定用途」，而且只能用在這個用途。
  • 簡單記：雙方都要付錢/東西的行政契約，要有限制——
    • 用途特定、有助公務、對等關聯；
    • 羈束處分替代契約不能亂要東西。
舉個例子
例1：合法雙務契約——符合三款
  • 市政府與某民間停車場管理公司簽訂契約，約定： 市政府將公有停車場委託公司經營（政府的給付）， 公司每年繳納權利金100萬元（人民的給付），該權利金「專用於停車場周邊環境改善」（特定用途）。
  • 公司之給付有助於市府執行停車場管理職務，且100萬元與停車場經營權價值相當，具有正當關聯。
  • → 符合第137條第1項各款。
例2：未約定特定用途
  • 同上例，契約僅記載公司繳納100萬元，未約定該款項之用途。
  • → 違反第137條第1項第1款、第3項。契約無效（依第142條第2款）
例3：不當關聯
  • 環保局核發某工廠操作許可，要求工廠每年「捐贈10萬元給環保局員工旅遊基金」。
  • → 違反第137條第1項第3款（不當關聯，且可能構成不當利益輸送）。契約無效。
例4：羈束處分替代契約超限
  • 依法律規定，符合特定條件者，機關「應」發給某種許可（羈束處分）。
  • 機關與申請人簽約，要求申請人額外「提供100萬元回饋金」作為締約條件， 而該條件並非第93條第1項所允許之附款。
  • → 違反第137條第2項。該契約無效（依第142條第2款）。
例5：合法羈束處分替代契約
  • 同上例，但法律規定「為確保許可之法定要件（如維護環境）， 得要求申請人提供保證金」。
  • 機關要求申請人提供保證金50萬元。
  • → 符合第137條第2項（保證金屬第93條第1項「為確保法定要件履行」之附款）。契約有效。

第138條 行政契約之競爭程序（甄選公告與陳述意見）
  • 「行政契約當事人之一方為人民，依法應以甄選或其他競爭方式決定該當事人時，行政機關應事先公告應具之資格及決定之程序。決定前，並應予參與競爭者表示意見之機會。」
這一條是關於？
  • 當政府要跟人民簽「行政契約」，而且依法「必須用甄選或其他競爭方式」 來決定跟誰簽約時（例如BOT案、公共服務委託）：
    • 政府必須「事先公告」參加甄選需要的「資格條件」和「評選程序」，讓大家公平競爭。
    • 在正式決定人選「之前」，還要給所有參與競爭的人「表達意見的機會」（例如說明自己的方案、回答問題）。
  • 簡單講：競爭式行政契約，要公開、公平、給大家說話的機會。
這一條的核心
  • 第138條是行政契約的「程序正義」條款。當行政契約的締結涉及「競爭機制」時 （即有多個潛在的締約對象，須經由甄選、招標、評選等方式決定）：
    • 行政機關必須遵守一定的程序要求，以確保公平、公開、公正。
  • 適用前提：
    • 行政契約「當事人之一方為人民」。
    • 依法「應以甄選或其他競爭方式」決定該人民當事人。
    • 常見情形：促進民間參與公共建設法（BOT）、 政府採購法（但採購法原則上屬私法契約，本條適用於公法契約）、 其他法律規定須經遴選、評審、競標之行政契約。
  • 事前公告義務：
    • 公告應具之資格：參加甄選者須具備的條件（如資本額、實績、專業能力）。
    • 公告決定之程序：評選的方式、標準、流程（如初審、複審、評分項目、權重）。
    • 事先：須在甄選程序開始前公告，不得事後補正。
  • 決定前之陳述意見機會：
    • 應予參與競爭者表示意見之機會：例如舉辦說明會、簡報會議、答詢、書面補充說明等。
    • 目的：讓競爭者有機會說明自己的優勢、澄清疑問、回應評選委員的問題。
    • 決定前：須在正式決定人選「之前」給予機會，而非事後。
  • 法律效果：違反本條（未公告或未給陳述意見）可能導致甄選程序違法，進而使締結的行政契約無效或得撤銷。
    • 實務上，受損害的競爭者得提起訴訟（如確認契約無效、請求損害賠償）。
  • 本條的設計精神是：在涉及競爭的行政契約締約程序中：
    • 確保公平競爭、資訊透明、程序參與，防止黑箱作業或圖利特定對象。
條文拆解
  • 「行政契約當事人之一方為人民」 ：政府要找一個民間單位來簽約。
    • 指行政契約的「人民當事人」須透過競爭方式決定（例如民間投資廠商、受託機構）。
  • 「依法應以甄選或其他競爭方式決定該當事人時」 ：法律規定要「比一比」才能決定跟誰簽約。
    • 依法：須有法律或法規命令規定應以競爭方式決定（如《促進民間參與公共建設法》第42條、第46條）。
    • 甄選或其他競爭方式：
      • 甄選：如評審委員會評選。
      • 招標：如公開招標、限制性招標。
      • 競標：如拍賣、競價。
      • 其他：如公開徵求、競爭性對話。
  • 「行政機關應事先公告應具之資格及決定之程序」 ：要事先公開「條件」和「怎麼評選」。
    • 事先公告：在競爭程序開始前，以適當方式（如政府公報、機關網站、新聞紙）公告。
    • 應具之資格：參與競爭者須符合的條件（如公司登記、財務能力、技術能力、實績）。
    • 決定之程序：評選的流程、方式、標準、評分項目、權重、決標方式等。
    • 目的：確保所有潛在參與者獲得相同資訊，公平競爭。
  • 「決定前，並應予參與競爭者表示意見之機會」 ：在決定人選之前，要讓每個參加者都有機會「說清楚、講明白」。
    • 決定前：在行政機關正式決定人選之前。
    • 參與競爭者：已經遞件參與甄選的廠商或個人。
    • 表示意見之機會：
      • 例如：簡報、面試、答詢、提出書面補充資料、說明會。
      • 應有「雙向溝通」的實質意義，而非僅形式上的收件。
為什麼要有這條規定？
  • 確保公平競爭：避免行政機關在黑箱中決定人選，圖利特定廠商。
  • 提升行政透明度：透過公告程序，使社會大眾得以監督。
  • 保障參與者程序權：給予表示意見的機會，使甄選決定更具正當性。
  • 減少後續爭議：公平公開的程序，可降低未獲選者提起訴訟的意願。
  • 與政府採購法、促參法之精神一致：公共建設及服務委外，應以公平競爭為原則。
白話文
  • 如果政府要跟人民簽行政契約，而且法律規定「必須透過甄選、招標等競爭方式」 來決定跟誰簽約（例如BOT案、公共服務委外），政府必須：
    • 事先公告：把「參加甄選需要的資格條件」和「評選的程序、標準」都事先公開，讓大家知道。
    • 給競爭者說話的機會：在決定人選「之前」，要讓每一個參加甄選的人都有機會說明自己的方案、回答問題。
    這樣才能確保公平、公開，避免黑箱作業。
  • 簡單記：競爭式簽約，要公開條件程序，還要讓參賽者說話。
舉個例子
例1：合法程序——BOT案公告甄選
  • 市政府欲推動「污水處理廠BOT案」，依《促進民間參與公共建設法》第42條規定， 應以甄選方式決定民間機構。
  • 市政府於政府公報及網站公告：參與甄選者須具備資本額1億元以上、 有污水處理實績，甄選程序分為資格審查、綜合評審、議約三階段， 評分項目包括技術能力、財務計畫、回饋方案等。
  • 並於評審會議中，給予各參與廠商30分鐘簡報及10分鐘答詢。
  • → 符合第138條。
例2：違反事先公告——未公告資格條件
  • 同上例，市政府未事先公告資格條件及甄選程序，逕行邀請三家特定廠商投標，並於收件後自行評選。
  • → 違反第138條「應事先公告」義務。甄選程序違法，所締結之行政契約可能無效或得撤銷。
例3：違反表示意見機會——未給予說明機會
  • 同上例，市政府有公告資格及程序，但評審過程中僅書面審查廠商送件資料， 未給予任何廠商簡報、答詢或補充說明之機會。
  • → 違反第138條「決定前，應予參與競爭者表示意見之機會」。程序違法。
例4：不適用本條——無競爭程序要求
  • 某文化部與特定藝文團體簽訂補助契約，該補助契約依法無須經甄選或競爭程序（如依申請審查）。
  • → 不適用第138條（無「依法應以甄選或其他競爭方式」之要求）。
一句話總結
    第138條是「競爭式行政契約的公開公平條款」——
  • 依法須甄選的契約，要事先公告資格程序，並在決定前給競爭者說話的機會。
第139條 行政契約之書面要式性
  • 「行政契約之締結，應以書面為之。但法規另有其他方式之規定者，依其規定。」
這一條是關於？
  • 行政機關跟人民簽訂「行政契約」，原則上「必須用書面」—— 也就是要寫成正式文件，不能用口頭約定。
    • 但是，如果其他法律有特別規定可以用其他方式（例如電子文件、公證書、或其他特定形式），就依那個法律的規定。
  • 簡單講：行政契約要白紙黑字寫下來，除非其他法律說可以用別的方式。
這一條的核心
  • 第139條是行政契約的「形式要件」條款。它確立了「書面要式性」作為行政契約的成立要件之一。
  • 書面要式原則：
    • 行政契約「應以書面為之」——未以書面作成者，依第141條第1項準用民法第73條，契約「無效」。
    • 書面：指雙方當事人（行政機關與人民）在「同一份文件」上簽名或蓋章，或以「交換書面」方式達成合意（雙方分別簽署相同內容之文件）。
  • 立法目的：
    • 明確性：避免口頭約定內容不明確，產生爭議。
    • 證據保存：書面契約易於保存、證明，便於後續履行及爭訟。
    • 慎重性：行政契約涉及公共利益，應以正式形式為之，防止機關輕率締約。
    • 監督機制：書面契約便於上級機關監督及審計。
  • 但書例外：「法規另有其他方式之規定者，依其規定」—— 其他法律或法規命令得規定行政契約得以書面以外之方式為之。
    • 例如：電子簽章法規定，經相對人同意，得以電子文件取代書面（電子簽章法第4條）。
  • 書面之形式：
    • 同一書面：雙方在同一份契約書上簽名或蓋章。
    • 交換書面：雙方分別簽署內容相同之文件，互寄對方。
    • 電子文件：依電子簽章法，經相對人同意且符合相關技術規範者，得視為書面。
  • 違反效果：
    • 未以書面締結之行政契約，「無效」（第141條第1項準用民法第73條）。
    • 無效為自始、當然、確定無效，不得補正（但實務上若雙方嗣後補簽書面，可能被認定為重新締約）。
  • 本條的設計精神是： 行政契約之締結須慎重明確，以書面形式確保契約內容之固定、可證明及可監督，避免口頭約定之爭議與不確定性。
條文拆解
  • 「行政契約之締結，應以書面為之」 ：一定要寫下來、簽名蓋章，不能用講的。
    • 行政契約：依第135條所締結之公法上契約。
    • 締結：雙方意思表示合致時。
    • 應以書面為之：強制規定。書面為「成立要件」，而非僅「證據方法」。
    • 書面之定義：一般指紙本文件，經雙方簽名或蓋章。
      • 依電子簽章法，電子文件經相對人同意且符合規定者，視為書面。
  • 「但法規另有其他方式之規定者，依其規定」 ：如果其他法律說可以用別的方式（例如電子簽約），就照那個法律辦。
    • 法規：包括法律及法規命令。
    • 其他方式：例如電子文件（電子簽章法）、公證書、或以其他特定形式（如錄音錄影，但實務罕見）。
    • 依其規定：優先適用特別法之規定。
為什麼要有這條規定？
  • 確保契約內容明確：避免口頭約定之內容模糊、遺忘或各說各話。
  • 便於事後舉證：書面契約可作為履行及爭訟時之證據。
  • 促使締約雙方慎重：書面形式使雙方在簽約前有充分思考機會，避免輕率決定。
  • 便利行政監督：上級機關或審計機關得審查書面契約之合法性。
  • 與民法第73條（要式行為）一致：違反法定方式者無效，維護法律行為之嚴肅性。
白話文
  • 政府跟人民簽「行政契約」，一定要「寫成書面」—— 也就是要有紙本文件，雙方簽名或蓋章。
    • 不能用口頭約定，也不能只靠錄音或LINE訊息（除非法律特別允許）。
  • 如果其他法律有特別規定可以用其他方式（例如電子簽章法允許用電子文件），就依那個法律的規定。
  • 簡單記：行政契約要白紙黑字簽名蓋章，口頭約定不算數。
舉個例子
例1：合法書面契約
  • 市政府與某公司簽訂「污水處理廠BOT契約」，雙方在契約書上蓋章，一式兩份，各執一份。
  • → 符合第139條。行政契約以書面為之。
例2：違反書面要式——口頭約定
  • 文化局承辦人口頭承諾補助某藝文團體50萬元，雙方未簽訂任何書面文件。
  • 後續文化局以經費不足為由拒絕給付。藝文團體主張口頭契約有效。
  • → 違反第139條。
    • 行政契約未以書面為之，依第141條第1項準用民法第73條，契約無效。
    • 藝文團體不得請求給付。
例3：違反書面要式——僅傳真未補正
  • 機關與廠商以傳真方式交換契約草稿，雙方未在正式書面上簽名蓋章。
  • → 原則上不符合「書面」要件（傳真可作為證據，但非正式簽約）。
    • 實務上若事後補簽書面，可認為重新締約；若未補正，契約無效。
例4：但書例外——電子文件
  • 機關依《電子簽章法》第4條規定，經相對人同意， 以電子文件締結行政契約，並使用數位簽章。
  • → 符合第139條但書。電子文件視為書面，契約有效。
一句話總結
    第139條是「行政契約要白紙黑字」條款——
  • 行政契約必須以書面簽名蓋章，口頭約定無效；
  • 但法律允許電子文件等替代方式者，從其規定。
第140條 行政契約之第三人效力與須經其他機關參與之要件
  1. 「行政契約依約定內容履行將侵害第三人之權利者，應經該第三人書面之同意，始生效力。」
  2. 「行政處分之作成，依法規之規定應經其他行政機關之核准、同意或會同辦理者，代替該行政處分而締結之行政契約，亦應經該行政機關之核准、同意或會同辦理，始生效力。」
這一條是關於？
  • 政府跟人民簽的行政契約，如果履行的結果會「侵害到第三人的權利」（例如隔壁地主的權利）：
    • 那麼這個契約必須經過「該第三人的書面同意」，才會發生效力。
  • 另外，如果本來要作一個行政處分，而且這個處分依法「必須經過其他行政機關的核准、同意或會同辦理」（例如需要上級機關點頭） ，那麼用「行政契約」來代替這個處分時：
    • 這個契約也「必須經過那個行政機關的核准、同意或會同辦理」，才會生效。
  • 簡單講：
    • 契約不能侵害第三人權利，除非第三人同意；
    • 代替須經核准的處分而簽的契約，也須經核准。
這一條的核心
  • 第140條是行政契約的「效力限制」條款。它處理兩種情形：
    • 一是契約內容可能侵害第三人權利；
    • 二是契約代替了一個須經其他機關參與的行政處分。
    在這兩種情形下，契約不能隨便生效，必須獲得「第三人同意」或「其他機關核准」。
  • 第三人效力契約（第1項）：
    • 行政契約的履行，會「侵害」第三人的「權利」（不僅是反射利益或經濟上影響）。
    • 為保護第三人，契約須經該第三人「書面同意」，始生效力。
    • 未經同意者，契約「效力未定」（非無效，而是得經同意後生效）。
    • 第三人不同意者，契約確定不生效力（或應調整內容）。
  • 須經其他機關參與之處分的替代契約（第2項）：
    • 原應作成的行政處分，依法須經其他行政機關的「核准、同意或會同辦理」（例如：下級機關作處分須上級核准；或須會同其他機關辦理）。
    • 若機關選擇以「行政契約」代替該處分，則該契約也「必須經過同樣的機關參與程序」，始生效力。
    • 目的：避免以契約形式規避法規要求的多機關參與機制。
  • 本條的設計精神是：行政契約不得架空法律對第三人權利保護及多機關參與程序的要求——
    • 契約的彈性不能逾越法規的強制規定。
條文拆解
第一項：第三人權利保護
  • 「行政契約依約定內容履行將侵害第三人之權利者」 ：契約履行會「踩到」第三人的權利。
    • 第三人：非契約當事人，但其「權利」可能因契約履行而受侵害。
    • 侵害：對第三人的權利造成「不利影響」或「損害」。
      • 不包括「反射利益」或「經濟上競爭關係」（如隔壁商家生意受影響）。
      • 須為「法律上權利」（如所有權、抵押權、租賃權、相鄰權、人格權等）。
    • 權利：例如：
      • 土地所有權（契約約定在第三人土地上施工）。
      • 抵押權（契約約定處分抵押物）。
      • 相鄰權（契約約定建築物遮擋第三人日照）。
      • 債權（契約約定第三人應為給付，但未經其同意）。
  • 「應經該第三人書面之同意，始生效力」 ：要那個被影響的第三人「白紙黑字同意」，契約才算數。
    • 應經：強制要求，無裁量空間。
    • 該第三人：權利受侵害的特定第三人。
    • 書面之同意：須以書面為之（簽名或蓋章），口頭同意無效。
    • 始生效力：未經同意前，契約「效力未定」（非無效，亦非有效）。
      • 第三人同意 → 契約自同意時起生效（或溯及？學說有爭議，實務多採自同意時生效）。
      • 第三人拒絕 → 契約確定不生效力（或契約當事人應調整內容）。
第二項：代替須經其他機關參與之處分的契約
  • 「行政處分之作成，依法規之規定應經其他行政機關之核准、同意或會同辦理者」 ：本來要作的處分，依法需要別的機關點頭或一起作。
    • 依法規之規定：法律或法規命令明文要求。
    • 其他行政機關：非原處分機關之其他行政機關。
    • 核准、同意或會同辦理：
      • 核准：上級機關對下級機關之處分有審查權（如訴願法第4條）。
      • 同意：其他機關對處分之內容有同意權。
      • 會同辦理：須兩個以上機關共同作成。
  • 「代替該行政處分而締結之行政契約，亦應經該行政機關之核准、同意或會同辦理，始生效力」 ：用簽約代替處分，還是要經過同樣的機關批准流程。
    • 代替該行政處分而締結之行政契約：機關選擇以契約取代原本的處分。
    • 亦應經該行政機關之核准、同意或會同辦理：同樣須經過原處分所要求的機關參與程序。
    • 始生效力：未經核准、同意或會同辦理前，契約效力未定。
為什麼要有這條規定？
  • 保障第三人權利：避免行政機關與人民透過契約，侵害未參與締約的第三人權益。
  • 維護多機關參與程序：防止機關以契約形式，規避法規要求的核准、同意、會辦機制。
  • 貫徹依法行政原則：契約不能架空法律對特定程序的強制要求。
  • 與民法第269條（第三人利益契約）呼應：第三人負擔契約須經第三人同意。
  • 避免契約成為脫法行為的工具：確保契約的合法性與正當性。
白話文
  • 政府跟人民簽的行政契約，有兩種情況需要「特別同意」才能生效：
    1. 會侵害第三人權利：如果契約履行的結果，會侵犯到「第三者」的權利（例如隔壁地主的土地權），必須經過那個第三人的「書面同意」，契約才算數。
    2. 代替需要其他機關核准的處分：如果本來要作的行政處分，依法需要經過「其他機關的核准、同意或會同辦理」（例如需要上級批准），那麼用契約來代替這個處分時，也必須經過同樣的機關核准，契約才算數。
  • 簡單記：契約不能侵害第三人，除非他同意；代替須核准的處分而簽約，也須核准。
舉個例子
例1：須經第三人同意
  • 市政府與A公司簽訂BOT契約，約定在B土地上興建停車場。
  • 該土地部分為C所有（第三人），契約履行將占用C之土地。
  • → 適用第140條第1項。
    • 契約須經C之書面同意，始生效力。
    • 未經C同意前，契約效力未定。
例2：無須第三人同意
  • 市政府與A公司簽訂BOT契約，在公有土地上興建停車場。
  • 相鄰地主B的生意可能因停車場競爭而受影響（僅經濟利益，非法律上權利）。
  • → 不適用第140條第1項（非侵害「權利」）。無須B同意。
例3：須經上級機關核准
  • 依某法律規定，下級機關作某授益處分須經上級機關核准。
  • 下級機關未作處分，而與人民締結行政契約代替該處分。
  • → 適用第140條第2項。該契約須經上級機關核准，始生效力。
例4：須經其他機關同意
  • 依某法規，甲機關作處分須經乙機關同意。
  • 甲機關以行政契約代替處分，未經乙機關同意即簽約。
  • → 違反第140條第2項。契約未經乙機關同意，效力未定（或無效）。
例5：無須其他機關參與
  • 機關依職權得自行作成處分，無須其他機關核准、同意或會辦。
  • 機關以行政契約代替處分。
  • → 不適用第140條第2項。無須其他機關參與，契約簽訂即生效（須符合其他要件）。
未經第三人同意之法律效果
情況 法律效果 說明
未經第三人同意即履行 契約對第三人「不生效力」 第三人得主張其權利不受拘束
第三人嗣後同意 自同意時起契約生效 學說有爭議（是否溯及），實務多採向後生效
第三人拒絕同意 契約確定不生效力 當事人應調整契約內容或放棄履行
契約當事人強行履行 第三人得依民法（侵權行為）請求損害賠償 與行政契約效力問題併行
一句話總結
    第140條是「行政契約的第三人同意與機關核准條款」——
  • 契約履行若侵害第三人權利，須經其書面同意；
  • 代替須核准處分的契約，也須經該機關核准。
第141條 行政契約之無效事由（民法準用與特定違反）
  1. 「行政契約準用民法規定之結果為無效者，無效。」
  2. 「行政契約違反第一百三十五條但書或第一百三十八條之規定者，無效。」
這一條是關於？
  • 行政契約的「無效」（自始、當然、確定不生效力），來自於兩種情況：
    1. 民法裡面關於契約無效的規定（例如違反強制規定、違反公序良俗、欠缺法定方式），「準用」到行政契約上。
      • 如果依照民法的標準判斷是無效，那就是無效。
    2. 行政契約違反了第135條但書（不得締約的情形）或第138條（競爭程序的要求），也是直接無效。
  • 簡單講：民法規定的無效事由，行政契約也適用；另外，違反第135條但書或第138條，也無效。
這一條的核心
  • 第141條是行政契約「無效」的總則性規定，統合了「民法規定之準用」與「行政程序法特定之無效事由」。
  • 民法規定之準用（第1項）：
    • 行政契約「準用」民法關於契約之規定（主要是民法債編）。
    • 若依民法規定判斷為無效，則行政契約亦無效。
      • 如違反民法第71條強制規定、第72條公序良俗、第73條法定方式、第246條不能給付等
    • 這是「間接」無效事由——透過準用民法而發生。
  • 行政程序法特定無效事由（第2項）：
    • 直接明文規定兩種情形無效：
      • 違反第135條但書：依性質或法規規定不得締約，卻仍締約。
      • 違反第138條：依法應以競爭方式決定當事人，卻未公告資格程序或未給參與競爭者陳述意見。
    • 這是「直接」無效事由，不須透過民法。
  • 本條的設計精神是：
    • 將民法成熟的契約無效理論引入行政契約，
    • 同時針對行政契約的特殊性（締約限制、競爭程序），明定直接無效事由。
    以維護依法行政與程序正義。
條文拆解
第一項：準用民法規定之結果為無效者，無效
  • 「行政契約準用民法規定之結果為無效者」 ：如果按照民法的標準，這個契約是無效的，那行政契約也跟著無效。
    • 準用民法規定：行政程序法第149條規定「行政契約，本法未規定者，準用民法相關之規定」。
    • 民法規定：主要指民法債編（第153條以下），以及民法總則中關於法律行為之規定（第71條至第74條）。
    • 為無效者：依民法規定判斷，該契約（或條款）符合無效事由。
  • 「無效」 ：從頭到尾都不算數。
    • 指行政契約「自始、當然、確定」不生效力。
    • 不待當事人主張，法院得依職權審酌。
    • 無效之契約，不得強制履行；已履行之給付，得依不當得利請求返還（第127條）。
第二項：違反第135條但書或第138條者，無效
  • 「行政契約違反第一百三十五條但書之規定者，無效」 ：不能簽約的事（性質或法律禁止），硬要簽約，契約無效。
    • 第135條但書：「依其性質或法規規定不得締約者，不在此限」。
    • 違反情形：對於「依性質不得締約」或「法規規定不得締約」之事項，仍締結行政契約。
    • 例子：
      • 性質不得締約：稅額核定、兵役徵集、刑事追訴（以契約代替）。
      • 法規不得締約：某法條明定「應以行政處分為之，不得締約」。
  • 「行政契約違反第一百三十八條之規定者，無效」 ：依法應該公開競爭、給大家說話機會，卻黑箱作業，契約無效。
    • 第138條規定：依法應以甄選或其他競爭方式決定契約當事人時，應事先公告資格及程序，並於決定前給予參與競爭者表示意見之機會。
    • 違反情形：
      • 未事先公告應具之資格。
      • 未事先公告決定之程序。
      • 未給予參與競爭者表示意見之機會。
為什麼要有這條規定？
  • 將民法成熟的無效理論引入行政契約：避免行政契約無效事由之認定產生分歧。
  • 維護依法行政原則：確保行政契約不得牴觸法律強制規定或公序良俗。
  • 保障人民權益：違反競爭程序（第138條）所締結之契約，通常圖利特定對象，應宣告無效。
  • 明確無效事由：第2項明定兩種直接無效情形，減少爭議。
  • 與民法體系一致：便於法律適用者（行政機關、法院、律師）操作。
白話文
  • 行政契約在兩種情況下會「無效」（從頭到尾都不算數）：
    1. 民法規定的無效事由（第1項）：因為行政契約「準用」民法的規定，所以民法裡面哪些情況契約無效，行政契約也一樣無效。
      • 例如違反法律強制規定、違反公序良俗、沒有依照法定方式簽約
    2. 違反第135條但書或第138條（第2項）：
      • 違反第135條但書：明明「不能簽約的事」（性質不適合或法律禁止），卻硬要簽約。
      • 違反第138條：依法應該公開競爭、公告資格程序、給競爭者說話的機會，卻沒有這麼做（黑箱作業）。
  • 簡單記：民法說無效的，行政契約也無效；另外，不能簽的事硬要簽，或黑箱競爭簽約，也無效。
舉個例子
例1：違反民法第71條強制規定
  • 某行政契約約定，人民給付100萬元，機關則「免除該人民依法應繳納之稅捐」。
  • 依稅法規定，稅捐不得任意免除。
  • → 違反民法第71條（違反強制規定），依第141條第1項準用，行政契約無效。
例2：違反民法第72條公序良俗
  • 行政契約約定，人民給付機關首長「政治獻金」，機關則核發許可。
  • → 違反公序良俗（賄賂），依第141條第1項準用民法第72條，契約無效。
例3：違反民法第73條法定方式
  • 行政機關與人民口頭約定補助契約，未依第139條以書面為之。
  • → 違反法定方式，依第141條第1項準用民法第73條，契約無效。
例4：違反第135條但書
  • 稅捐機關與納稅人簽約「約定稅額」，代替依法應核定之稅額處分（稅額核定性質上不得締約）。
  • → 違反第135條但書，依第141條第2項，契約無效。
例5：違反第138條
  • 某BOT案依法應以甄選方式決定民間機構，但機關未公告資格及程序，逕行與特定廠商簽約。
  • → 違反第138條，依第141條第2項，契約無效。

  • 另外，不能簽的事硬要簽，或黑箱競爭簽約，也無效。
第142條 代替行政處分之行政契約之特別無效事由
  • 「代替行政處分之行政契約，有下列各款情形之一者，無效︰」
    • 一、與其內容相同之行政處分為無效者。
    • 二、與其內容相同之行政處分，有得撤銷之違法原因，並為締約雙方所明知者。
    • 三、締結之和解契約，未符合第一百三十六條之規定者。
    • 四、締結之雙務契約，未符合第一百三十七條之規定者。
這一條是關於？
  • 當政府用「行政契約」來「代替」一個原本應該作成的「行政處分」時，這種契約有四種情況會「無效」：
    1. 如果「同內容的行政處分」本來就是「無效」的（第111條），那契約也無效；
    2. 如果「同內容的行政處分」有「得撤銷」的違法原因，而且「簽約的雙方都知道這個違法」，那契約也無效；
    3. 如果這個契約是「和解契約」，卻不符合第136條的要件；
    4. 如果這個契約是「雙務契約」，卻不符合第137條的要件。
  • 簡單講：用來取代處分的行政契約，不能比處分更「不合法」——
    • 處分無效或雙方明知違法，契約也無效；
    • 和解或雙務契約違反規定，也無效。
這一條的核心
  • 第142條是行政契約「無效事由」的特別規定，專門針對「代替行政處分之行政契約」。 與第141條（一般無效事由）不同，本條處理的是「與行政處分相關」的無效情形。
  • 第1款（處分無效，契約亦無效）：
    • 如果與契約內容相同的行政處分，依第111條是「無效」的（如欠缺機關名稱、內容不能實現等）， 那麼用契約來代替這個處分，契約也無效。
    • 理由：不能透過契約形式，讓一個本應無效的處分「復活」。
  • 第2款（雙方明知處分有得撤銷之違法原因）：
    • 如果與契約內容相同的行政處分，有「得撤銷」的違法原因（非無效，但違法）， 而且「締約雙方（機關與人民）都明知」這個違法，那麼契約無效。
    • 理由：不能讓雙方「合謀」用契約來包裝一個明知違法的處分。
    • 若僅一方明知，不適用本款（契約可能有效或得撤銷）。
  • 第3款（和解契約違反第136條）：
    • 第136條規定和解契約的要件：事實或法律關係經調查仍不能確定、為達成行政目的、解決爭執。
    • 若不符合這些要件（例如事實已明確仍和解、無爭執卻和解），契約無效。
  • 第4款（雙務契約違反第137條）：
    • 第137條規定雙務契約的要件：特定用途、有助職務、相當且正當關聯；羈束處分替代契約之限制；書面載明特定用途。
    • 若不符合，契約無效。
  • 本條的設計精神是：行政契約不得成為規避行政處分合法性要求的工具——
    • 如果處分本身無效或雙方明知違法，不能以契約取代；
    • 和解或雙務契約必須嚴格遵守第136條、第137條之要件，否則無效。
條文拆解
  • 「代替行政處分之行政契約」 ：這種契約是用來「頂替」處分的。
    • 指行政機關以契約「取代」原本應作成之行政處分（例如以和解契約取代裁罰處分、以雙務契約取代許可處分）。
    • 若非「代替處分」之契約（如單純之補助契約、公物使用契約），不適用本條（但仍適用第141條）。
  • 「有下列各款情形之一者，無效︰」
  • 第一款：與其內容相同之行政處分為無效者 ：如果處分本身就是廢紙一張（無效），那用來代替它的契約也是廢紙。
    • 與其內容相同之行政處分：假設機關作一個處分，其內容與契約相同。
    • 為無效者：該假設的處分依第111條（無效事由）為無效。
    • 契約無效：不能透過契約形式，使一個本應無效的處分「有效化」。
    • 例子：處分因「不能由書面得知處分機關」（第111條第1款）而無效，代替該處分之契約亦無效。
  • 第二款：與其內容相同之行政處分，有得撤銷之違法原因，並為締約雙方所明知者 ：雙方都知道這個處分是違法的，還故意簽約來代替它，契約無效。
    • 有得撤銷之違法原因：處分違法，但尚未達到無效程度（例如違反程序規定、事實認定錯誤）。
    • 並為締約雙方所明知：
      • 行政機關「明知」該處分違法。
      • 人民（他方當事人）「明知」該處分違法。
      • 雙方均明知。若僅一方明知，不適用本款。
    • 契約無效：雙方「合謀」以契約包裝違法處分，契約無效。
    • 例子：機關明知某裁罰處分已逾時效（不得裁罰），仍與人民簽約約定「繳納一定金額代替裁罰」。
  • 第三款：締結之和解契約，未符合第一百三十六條之規定者 ：不符合和解契約的法定要件（例如事實明明很清楚了還和解），契約無效。
    • 和解契約：依第136條締結，用以代替行政處分。
    • 未符合第136條之規定：
      • 事實或法律關係「未經依職權調查」或「已能確定」卻仍和解。
      • 非為「有效達成行政目的」或「解決爭執」。
    • 契約無效：不符合法定要件，和解契約無效。
    • 例子：事實已明確（如酒測值超標），機關卻與人民和解「繳一半罰款了事」。
  • 第四款：締結之雙務契約，未符合第一百三十七條之規定者 ：雙務契約違反第137條的規定（例如用途不明、不對等、亂掛鉤），契約無效。
    • 雙務契約：雙方互負給付義務之行政契約，用以代替行政處分。
    • 未符合第137條之規定：
      • 未約定人民給付之特定用途（第1項第1款、第3項）。
      • 人民之給付無助於機關執行職務（第1項第2款）。
      • 給付與對待給付不相當或無正當合理關聯（第1項第3款）。
      • 羈束處分替代契約違反第137條第2項（人民給付超出附款範圍）。
    • 契約無效：不符合雙務契約要件，契約無效。
    • 例子：機關發許可（羈束處分），要求人民「捐贈100萬元給機關員工旅遊基金」（不當關聯，違反第137條第1項第3款）。
為什麼要有這條規定？
  • 避免以契約形式規避行政處分之合法性要求：處分無效或雙方明知違法，不能以契約取代。
  • 確保和解契約之正當性：避免機關在事實明確時仍濫用和解，損害公益。
  • 確保雙務契約之公平性與正當關聯：防止機關利用優勢地位要求顯不相當或不當連結之給付。
  • 維護依法行政原則：行政契約不得比行政處分更「寬鬆」或「違法」。
  • 保護人民權益：防止人民被機關誘導簽下不公平或違法之契約。
白話文
  • 用來「代替行政處分」的行政契約（例如本來要罰你，改成簽約和解），在以下四種情況「無效」：
    1. 同內容的處分本身是無效的（例如處分連機關名稱都沒有）——契約也無效。
    2. 同內容的處分有違法（得撤銷），而且「雙方都知道」——不能明知違法還用契約包庇。
    3. 和解契約不符合第136條的規定（例如事實已經很明確，卻還要和解）。
    4. 雙務契約不符合第137條的規定（例如沒寫明用途、給付不對等、亂掛鉤）。
  • 簡單記：用來代替處分的契約，不能比處分更「黑」——
    • 處分無效或雙方明知違法，契約也無效；
    • 和解或雙務契約違反規定，也無效。
舉個例子
例1處分無效，契約無效
  • 依第111條第1款，某許可處分因無機關名稱而無效。
  • 機關與人民簽訂「代替該許可處分之行政契約」，內容相同。
  • → 適用第142條第1款。契約無效。
例2：雙方明知處分違法
  • 機關明知某裁罰處分已逾3年時效（不得裁罰），人民亦明知。
  • 雙方仍簽訂「和解契約」，約定人民繳納一半罰款了事。
  • → 適用第142條第2款。雙方明知得撤銷之違法原因（逾時效），契約無效。
例3：僅機關明知，人民不知
  • 同上例，但人民不知該處分已逾時效（善意）。
  • → 不適用第142條第2款（非雙方明知）。契約可能有效（或得撤銷），人民得主張信賴保護。
例4：和解契約違反第136條
  • 警察取締酒駕，酒測值明確超標（事實已確定），仍與駕駛人簽訂「和解契約」，約定「繳納較低罰款，不移送法辦」。
  • → 適用第142條第3款。未符合第136條「事實經調查仍不能確定」之要件，契約無效。
例5：雙務契約違反第137條
  • 環保局發給某工廠許可（羈束處分），卻要求工廠「每年捐贈10萬元給環保局員工旅遊基金」作為對待給付（不當關聯）。
  • → 適用第142條第4款。未符合第137條第1項第3款（正當合理關聯），契約無效。
一句話總結
    第142條是「代替處分之行政契約的特別無效條款」——
  • 處分無效或雙方明知違法，契約無效；
  • 和解或雙務契約違反第136、137條，也無效。
第143條 行政契約一部無效之效力
  • 「行政契約之一部無效者，全部無效。但如可認為欠缺該部分，締約雙方亦將締結契約者，其他部分仍為有效。」
這一條是關於？
  • 行政契約如果「有一部分」無效（例如某個條款違反強制規定而無效）：
    • 原則上「整個契約都無效」。
    但是，如果「可以合理地認為」——就算少了這個無效的部分，締約雙方「還是會簽這個契約」，
    • 那麼「其他的部分仍然有效」。
  • 簡單講：
    • 契約一部分爛掉，原則整張報廢；
    • 但如果沒了那部分雙方還是會簽約，那就只爛那部分，其他繼續有效。
這一條的核心
  • 第143條是行政契約「一部無效」的效力規定，與民法第111條（法律行為一部無效之效力）相對應， 但兩者的「原則與例外」正好相反。
  • 原則：一部無效，全部無效（前段）
    • 行政契約中只要有任何「一部分」無效（依第141條或第142條），整個契約全部無效。
    • 這是基於行政契約的「整體性」與「不可分性」——當事人通常是以「整體」來考量契約，不願意接受殘缺不全的契約。
    • 立法政策：相對於民法第111條（一部無效，全部無效為例外），行政契約更重視契約的「完整性」與「功能關聯」。
  • 例外：可分性保留（但書）
    • 如果「可以認為」欠缺該無效部分，締約雙方「仍然會締結契約」（即雙方願意接受「沒有那部分」的契約），則其他部分「仍為有效」。
    • 判斷標準：客觀上，從締約當時的狀況，是否可合理推斷雙方「寧可要一個沒有該條款的契約，也不要完全沒契約」。
    • 舉證責任：主張其他部分有效者，應負舉證責任（通常是想維持契約有效的當事人）。
  • 與民法第111條的差異：
    • 民法第111條：原則「一部無效，全部無效」（例外：除去該部亦可成立者，其他部分有效）。
    • 行政程序法第143條：原則「一部無效，全部無效」，但書「如可認為欠缺該部分，雙方亦將締約者，其他部分有效」。
  • 本條的設計精神是：維護契約的整體性與當事人真意——
    • 原則上不允許「殘缺契約」存在，
    • 但若雙方顯然願意接受，則尊重當事人意思，維持其他部分的效力。
條文拆解
  • 「行政契約之一部無效者，全部無效」 ：只要契約裡面有某個地方爛掉了，整張契約都報廢。
    • 一部無效：契約中的某個條款或某部分，依第141條或第142條（或準用民法）為無效。
    • 全部無效：整個行政契約自始、當然、確定不生效力。
    • 理由：行政契約通常具有整體性，各條款間互有關聯；一部分無效可能破壞整體的公平性或功能。
  • 「但如可認為欠缺該部分，締約雙方亦將締結契約者，其他部分仍為有效」 ：如果你可以合理推斷——就算少了這個爛掉的部分，雙方還是會簽約，那就只爛那一塊，其他繼續算數。
    • 可認為：客觀判斷，以締約時之情況為準（而非事後當事人的主觀意願）。
    • 欠缺該部分：將無效的條款刪除後，剩餘的契約內容。
    • 締約雙方亦將締結契約：雙方在締約時，如果知道該部分會無效，是否「仍然願意」簽訂「沒有該部分的契約」？
      • 判斷因素：該部分是否為契約的核心要素？刪除後是否嚴重影響契約目的？雙方是否有其他替代安排？
    • 其他部分仍為有效：僅無效之條款失效，其餘條款繼續有效。
為什麼要有這條規定？
  • 尊重契約當事人真意：如果雙方顯然願意接受「沒有該條款」的契約，法律不應強迫整份契約失效。
  • 維護契約安定性：避免因一個次要條款無效，導致整份契約報廢，影響公共利益。
  • 與民法第111條一致：民法已有相同規定，行政契約準用民法，本條再予明定，以杜爭議。
  • 提供明確判斷標準：以「雙方亦將締結契約」為例外要件，兼顧當事人意思與客觀合理推斷。
  • 防止脫法行為：避免當事人刻意放入無效條款，再主張「其他部分有效」；法院應嚴格審查。

舉個例子
例1：原則——一部無效，全部無效
  • 甲市政府與乙公司簽訂BOT契約，其中第10條約定「乙公司每年捐贈100萬元給市長私人帳戶」（違反公序良俗，無效）。
  • 該條款為契約之核心對價之一，刪除後雙方顯然不會簽約（因為市府可能因此不給BOT案）。
  • → 適用第143條前段。一部無效，全部無效。
例2：例外——其他部分仍為有效
  • 丙機關與丁團體簽訂補助契約，其中第5條約定「丁團體應於活動結束後15日內提交成果報告」，但該條款因違反某程序規定而無效。
  • 若刪除該條款，剩餘契約仍完整（補助金額、活動內容等均不受影響），且可認為雙方即使沒有該條款，仍會簽訂補助契約。
  • → 適用第143條但書。其他部分仍為有效（僅第5條無效）。
例3：例外——可認為雙方仍會締約
  • 行政契約中一個無效的條款是「管轄法院約定」（違反專屬管轄規定）。
  • 刪除後，契約其他部分（給付義務、履行方式等）仍完整。可合理推斷雙方即使沒有管轄約定，仍會簽約（因管轄問題可依法解決）。
  • → 適用第143條但書。其他部分有效。
例4：不適用但書——條款為核心要素
  • 雙務行政契約中，人民的對待給付條款（如「繳納權利金100萬元」）因違反第137條而無效。
  • 刪除後，人民無須給付，機關仍須給付（顯失公平）。顯然雙方不可能接受「無對價」的契約。
  • → 適用第143條前段。一部無效，全部無效。

  • 原則上整份契約都無效；但若沒了無效部分雙方還是會簽約，則其他部分仍有效。
第144條 行政機關對人民履行契約之指導與協助
  • 「行政契約當事人之一方為人民者，行政機關得就相對人契約之履行，依書面約定之方式，為必要之指導或協助。」
這一條是關於？
  • 政府跟人民簽了行政契約之後，為了確保契約能夠順利履行：
    • 政府可以在「書面約定的方式」範圍內，對人民提供「必要的指導或協助」。
    • 例如：指導人民如何操作設施、協助取得相關許可、提供技術諮詢等。
  • 簡單講：政府可以當「教練」和「幫手」，指導、協助人民履行契約，但要有書面約定。
這一條的核心
  • 第144條是行政契約的「履行輔助」條款。
    • 行政契約通常涉及公共任務的執行（如BOT建設、公共服務委託、補助計畫），
    • 行政機關除了「監督」人民履行外，也負有某種程度的「協力義務」——指導、協助人民順利履約，以達成行政目的。
  • 適用範圍：行政契約當事人之一方為「人民」（不含雙方均為行政機關之契約）。
    • 例如：BOT契約、補助契約、公費生契約、委託行使公權力契約。
  • 指導或協助之目的：
    • 確保人民能夠「正確、有效率」地履行契約義務。
    • 避免因人民能力不足或資訊不對稱，導致履約障礙或失敗。
  • 「必要」之限制：
    • 指導或協助不得逾越「必要」範圍——與履約相關、合理且適當。
    • 不得無償要求人民接受「額外」的服務或負擔。
  • 「依書面約定之方式」：
    • 指導或協助的「方式」（如何進行、何時進行、由誰進行）須在契約中以「書面」約定。
    • 未經書面約定者，機關不得單方強行指導或協助（但人民自願接受者不在此限）。
    • 目的：避免機關濫用指導權，干預人民履約自由。
  • 法律性質：
    • 本條是「授權條款」——賦予機關得為指導或協助之權限。
    • 若機關違反本條（如無書面約定即強行指導），該指導行為可能不具法律拘束力，或構成不當干預。
  • 與監督權之區別：
    • 機關通常有「監督」人民履約的權限（依契約或法律）。
    • 本條是「積極」的指導協助，而非「消極」的監督檢查。
  • 本條的設計精神是： 行政機關在行政契約中，不應只是「監督者」或「制裁者」，也應扮演「協力者」的角色，
    • 協助人民順利履約，以實現公共利益；
    • 但此種協助須基於書面約定，且限於必要範圍。
條文拆解
  • 「行政契約當事人之一方為人民者」 ：只要是政府跟民間簽的契約，就有本條適用。
    • 指契約一方為行政機關，他方為「人民」（自然人、私法人、非法人團體）。
    • 不包括「雙方均為行政機關」之行政契約（如中央與地方之協議）。
  • 「行政機關得就相對人契約之履行」 ：針對人民要做的部分，政府可以提供協助。
    • 得：裁量權。機關「可以」提供指導或協助，但不是義務。
    • 相對人：契約的他方當事人（人民）。
    • 契約之履行：指人民依契約應負擔的義務（如興建設施、提供服務、繳交報告）。
  • 「依書面約定之方式」 ：要在合約上白紙黑字寫清楚「政府可以怎麼幫你」。
    • 書面約定：指導或協助的「方式」必須在契約條款中「以書面」約定。
      • 例如：約定機關得派員提供技術諮詢、得協助辦理相關許可、得提供教育訓練。
    • 未經書面約定者，機關不得單方為指導或協助（但人民自願接受者，不在此限）。
  • 「為必要之指導或協助」 ：只做「必要的」教導和幫助，不能亂幫或硬幫。
    • 必要：須與履約相關、合理且適當，不得逾越範圍。
      • 例如：指導人民操作設備 → 必要；要求人民接受與履約無關的訓練 → 非必要。
    • 指導：提供資訊、建議、技術指導、方向指引。
    • 協助：實際幫助，如代辦文件、協調其他機關、提供場地或設備。
為什麼要有這條規定？
  • 促進契約履行：透過機關的指導與協助，減少人民因能力或資訊不足而產生的履約障礙。
  • 落實行政機關的協力義務：行政契約不僅是「許可-義務」關係，機關也負有促成契約目的實現的責任。
  • 避免機關濫用監督權：明定指導協助須有書面約定且限於必要，防止機關藉指導之名行干預之實。
  • 提升行政效率：減少因履約爭議而產生的訴訟或違約處理成本。
  • 平衡雙方地位：人民在行政契約中通常處於相對弱勢，機關的協助有助於實質平等。
白話文
  • 政府跟人民簽了行政契約之後，為了幫助人民順利履行契約（例如把工程做好、把服務辦好）：
    • 政府可以在「合約書有寫清楚的方式」範圍內，提供「必要的指導或協助」
    • 例如教人民怎麼做、幫忙跑文件、提供技術支援。
  • 但政府不能「亂指導」或「硬要幫」：
    • 必須是「必要的」（跟履約相關且合理）。
    • 必須在「書面合約中有約定」方式。
  • 簡單記：政府可以當「教練」幫人民履約，但要在合約寫清楚，且只能做必要的事。
舉個例子
例1：合法指導——有書面約定
  • 市政府與BOT廠商簽約，契約第15條約定「乙方（廠商）興建停車場期間，甲方（市府）得派員提供工程技術諮詢及協助辦理相關許可」。
  • 市府依約派員指導廠商處理地質問題。
  • → 符合第144條。有書面約定，且屬必要指導。
例2：合法協助——有書面約定
  • 文化部與某藝文團體簽訂補助契約，契約第8條約定「甲方（文化部）得協助乙方（團體）向場地管理機關申請使用場地」。
  • 文化部協助團體發函協調。
  • → 符合第144條。有書面約定，且屬必要協助。
例3：未經書面約定——不得為之
  • 環保局與某工廠簽訂行政契約，契約中未約定機關得提供指導。
  • 環保局承辦人自行前往工廠「指導」操作流程，工廠拒絕。
  • → 不符合第144條（無書面約定）。機關不得強行指導。工廠有權拒絕。
例4：逾越必要範圍
  • 機關與人民簽訂補助契約，約定機關得「指導」人民履約。
  • 機關要求人民接受與履約完全無關的「政令宣導課程」每週5小時。
  • → 逾越「必要」範圍。人民得拒絕，該指導不具拘束力。
例5：機關之裁量——得不為指導
  • 契約雖有書面約定機關得提供指導，但機關認為人民已具備履約能力，無須額外協助，決定不提供。
  • → 符合第144條（「得」為指導，非義務）。機關不提供指導，不構成違約。
指導與協助之具體態樣
態樣 內容 是否須書面約定
技術指導 提供工程、操作、服務之專業建議 ✅ 須書面約定
行政協助 代辦許可、協調其他機關、提供文件範本 ✅ 須書面約定
教育訓練 舉辦與履約相關之培訓課程 ✅ 須書面約定
資訊提供 提供相關法規、標準、指引 ✅ 須書面約定
經費協助 預付或補助部分款項（非對待給付） 另須契約授權
一句話總結
    第144條是「政府可以指導協助人民履約」條款——
  • 政府可以在書面約定範圍內，做必要的指導或協助，但不能亂幫或硬幫。
第145條 行政機關行使公權力致人民履約費用增加之損失補償
  1. 「行政契約當事人之一方為人民者，其締約後，因締約機關所屬公法人之其他機關於契約關係外行使公權力，致相對人履行契約義務時，顯增費用或受其他不可預期之損失者，相對人得向締約機關請求補償其損失。但公權力之行使與契約之履行無直接必要之關聯者，不在此限。」
  2. 「締約機關應就前項請求，以書面並敘明理由決定之。」
  3. 「第一項補償之請求，應自相對人知有損失時起一年內為之。」
  4. 「關於補償之爭議及補償之金額，相對人有不服者，得向行政法院提起給付訴訟。」
這一條是關於？
  • 政府跟人民簽了行政契約之後，如果：
    • 「同一個政府體系內的其他機關」（不是簽約的那個機關），在「契約關係以外」行使公權力（例如訂定新法規、管制措施、徵收等）
    • 導致人民在「履行契約義務時」成本明顯增加或受到其他無法預期的損失
    那麼人民可以向「簽約的機關」請求「補償」。
  • 但是，如果那個公權力的行使跟契約的履行「沒有直接必要的關聯」，就不能請求。
  • 簽約機關收到請求後，要用「書面」附理由來決定。
  • 人民要在「知道損失起1年內」提出請求。如果對補償金額或爭議不服，可以直接向行政法院提起「給付訴訟」。
  • 簡單講：
    • 其他機關的「新政策」害你履約成本大增，可以跟簽約機關要補償；
    • 但要跟履約有直接關聯才行，且要在1年內請求。
這一條的核心
  • 第145條是行政契約的「損失補償」條款，處理的是「同一公法人內部不同機關的行為」，對人民履約造成的「額外損失」。
    • 這是一種「情事變更」的特別類型——不是契約本身的情事變更，而是「外部公權力行為」導致的情事變更。
  • 適用前提：
    • 行政契約「當事人之一方為人民」。
    • 締約後，「締約機關所屬公法人之其他機關」（如同一直轄市的不同局處、或中央部會的不同單位）「於契約關係外行使公權力」。
    • 該公權力行使「導致」人民「履行契約義務時」「顯增費用」或「受其他不可預期之損失」。
  • 排除事由（但書）：公權力之行使「與契約之履行無直接必要之關聯」者，不得請求補償。
  • 請求對象與程序（第2項）：
    • 人民應向「締約機關」請求（而非行使公權力之機關）。
    • 締約機關應以「書面並敘明理由」決定是否補償及金額。
  • 請求時效（第3項）：自知有損失時起「1年內」為之。
  • 救濟途徑（第4項）：人民不服補償決定（包括拒絕補償或金額不合理），得直接向行政法院提起「給付訴訟」（行政訴訟法第8條），無須經訴願程序。
  • 本條的設計精神是：
    • 當同一政府體系內的不同機關「左手簽約、右手打臉」時，不應由人民承擔損失
    • 應由締約機關代表政府承擔補償責任；但補償僅限於與履約有「直接必要關聯」的損失，避免浮濫。
條文拆解
第一項本文：補償請求權之發生
  • 「行政契約當事人之一方為人民者，其締約後」：政府與民間簽約之後。
    • 契約當事人：一方為行政機關，他方為人民。
    • 締約後：指契約成立後（含履行期間）。
  • 「因締約機關所屬公法人之其他機關於契約關係外行使公權力」 ：同一個政府（國家或地方自治團體）裡，不是簽約的那個單位，在契約以外行使公權力。
    • 締約機關所屬公法人：
      • 若締約機關為中央部會，所屬公法人為「國家」。
      • 若締約機關為地方政府（如臺北市政府），所屬公法人為「該地方自治團體」。
    • 其他機關：同一個公法人的「不同機關」。
      • 如締約機關是環保局，其他機關可能是建管處、交通局。
      • 或中央：經濟部與環保署。
    • 於契約關係外：該公權力行為不是基於本契約，而是基於其他法規或權限。
    • 行使公權力：包括法規命令、行政處分、事實行為、行政執行等。
  • 「致相對人履行契約義務時，顯增費用或受其他不可預期之損失者」 ：害你履約成本大增，或受到其他沒想到的損失。
    • 相對人：人民。
    • 履行契約義務時：須與履約行為有時間或原因上的關聯。
    • 顯增費用：成本明顯增加（如因新法規須購置額外設備、支付額外費用）。
    • 其他不可預期之損失：非費用增加，但屬損失（如因管制而延誤履約，產生違約金）。
      • 不可預期：締約時無法合理預見。
第一項但書：排除事由
  • 「但公權力之行使與契約之履行無直接必要之關聯者，不在此限」 ：如果那個公權力行為跟你的履約沒有「直接必要」的關係，就不能要補償。
    • 無直接必要之關聯：公權力行使與契約履行之間，欠缺「直接」且「必要」的因果關係。
      • 例如：新法規要求所有工廠增設汙水處理設備，但你簽的是「公園委託管理契約」——無直接關聯。
    • 不在此限：不得請求補償。
第二項：締約機關之決定
  • 「締約機關應就前項請求，以書面並敘明理由決定之」 ：簽約的機關收到請求後，必須用書面回覆，寫清楚理由。
    • 應：強制義務，機關不得置之不理。
    • 以書面並敘明理由：須作成書面，附理由（准駁及金額計算）。
    • 決定之：可能為「同意補償（若干金額）」或「駁回請求」。
第三項：請求時效
  • 「第一項補償之請求，應自相對人知有損失時起一年內為之」 ：從你知道有損失的那天起，1年內要提出請求。
    • 自知有損失時起：主觀標準——人民「知道」有損失（非損失客觀發生時）。
    • 一年內：期間較短（一般公法請求權為5年或10年），目的在於儘速確定。
第四項：救濟途徑
  • 「關於補償之爭議及補償之金額，相對人有不服者，得向行政法院提起給付訴訟」 ：不服補償決定，可以直接告法院，不用先訴願。
    • 補償之爭議：包括機關拒絕補償、補償金額不合理、補償範圍爭議。
    • 得向行政法院提起給付訴訟：依行政訴訟法第8條，直接提起一般給付訴訟。
    • 無須訴願：本條特別規定，免除訴願程序。
為什麼要有這條規定？
  • 防止政府「左手簽約、右手打臉」：避免因政府內部不同機關的行為，使人民承擔不可預期的損失。
  • 落實信賴保護原則：人民信賴契約有效履行，不應因其他機關的公權力行使而受損。
  • 明確補償責任歸屬：由締約機關負補償責任，而非讓人民自行向行使公權力之機關求償（簡化程序）。
  • 確保契約目的達成：透過補償機制，使人民仍有意願繼續履約，避免契約破裂。
  • 提供快速救濟管道：第4項允許直接提起給付訴訟，免除訴願，加速紛爭解決。

舉個例子
例1：得請求補償——有直接關聯
  • 甲市政府環保局與某廢棄物處理廠商簽訂「廢棄物處理行政契約」。
  • 契約履行期間，甲市都市發展局將該廠商所在區域劃設為「環境敏感地區」，要求所有工廠增設汙染防制設備。 廠商因此增加設備支出500萬元。
  • → 適用第145條第1項本文。
    • 都市發展局為締約機關（環保局）所屬公法人（甲市）之其他機關，行使公權力（劃設環境敏感地區）
    • 致廠商顯增費用，且與契約履行有直接關聯（處理廢棄物須符合環保標準）。
    • 廠商得向環保局請求補償。
例2：不得請求——無直接必要關聯
  • 乙機關與某廠商簽訂「公園清潔維護契約」。
  • 締約後，財政部（同屬國家）修正營業稅法，提高該廠商之稅負。
  • → 適用第145條第1項但書。稅法修正與契約履行（公園清潔）無直接必要之關聯，不得請求補償。
例3：時效——逾1年不得請求
  • 丙廠商於110年3月1日知悉因其他機關之公權力行使而受有損失，遲至111年4月1日始向締約機關請求補償。
  • → 違反第145條第3項。
    • 自知有損失時起已逾1年，請求權消滅（或時效完成）。
    • 機關得拒絕補償。
例4：救濟途徑——直接提起給付訴訟
  • 丁廠商向締約機關請求補償，機關駁回其請求。
  • 丁不服，直接向行政法院提起給付訴訟，請求判命機關給付補償金。
  • → 適用第145條第4項。
    • 補償之爭議及補償之金額，相對人有不服者，得向行政法院提起給付訴訟（無須先經訴願）。
一句話總結
    第145條是「政府其他單位害你履約成本大增，要補償」條款——
  • 同政府的其他機關行使公權力，導致你履約成本明顯增加或受損失，可向簽約機關請求補償；
  • 須有直接關聯，且1年內請求；不服可直接告法院。
第146條 行政機關為防止或除去公益重大危害之契約調整與終止
  1. 「行政契約當事人之一方為人民者，行政機關為防止或除去對公益之重大危害，得於必要範圍內調整契約內容或終止契約。」
  2. 「前項之調整或終止，非補償相對人因此所受之財產上損失，不得為之。」
  3. 「第一項之調整或終止及第二項補償之決定，應以書面敘明理由為之。」
  4. 「相對人對第一項之調整難為履行者，得以書面敘明理由終止契約。」
  5. 「相對人對第二項補償金額不同意時，得向行政法院提起給付訴訟。」
這一條是關於？
  • 政府跟人民簽了行政契約之後，如果為了「防止或消除對公共利益的重大危害」 （例如突然發現契約履約會造成重大環境污染、公共安全風險）：
    • 政府可以在「必要範圍內」「調整契約內容」或「終止契約」。
    • 但是，政府必須「補償人民因此受到的財產損失」，否則不能調整或終止。
  • 政府調整、終止或補償的決定，都要用「書面附理由」為之。
  • 如果人民覺得調整後的契約「難以履行」，可以自己「書面終止契約」。
  • 如果人民對補償金額「不同意」，可以直接向行政法院提起「給付訴訟」。
  • 簡單講：
    • 政府為了公益可以強制改約或解約，但要賠錢；
    • 人民覺得改約後做不下去，也可以自己解約；
    • 補償金額談不攏，可以直接告法院。
這一條的核心
  • 第146條是行政契約中「基於公益之調整與終止」條款，賦予行政機關在「重大公益危害」發生或有發生之虞時， 單方調整契約內容或終止契約的權限。
    • 這是行政契約與民事契約最大的不同之一——行政契約強調公益優先。
  • 機關的調整或終止權（第1項）：
    • 要件：「防止或除去對公益之重大危害」。
    • 範圍：「必要範圍內」。
    • 對象：與人民締結之行政契約（一方為人民）。
    • 方式：調整契約內容（如修改履約條件）或終止契約（全部終止）。
  • 補償義務（第2項）：
    • 機關調整或終止契約，「必須」補償人民因此所受的「財產上損失」。
    • 不補償 → 不得調整或終止。
    • 補償範圍：僅限「財產上損失」，不含非財產損失。
  • 書面與理由（第3項）：
    • 調整、終止、補償決定均須以「書面」為之，並「敘明理由」。
    • 目的：確保程序透明，便於人民救濟。
  • 人民的終止權（第4項）：
    • 若機關調整契約內容，人民認為「難以履行」（例如調整後條件過苛），人民得主動「終止契約」（書面、附理由）。
    • 這是對機關調整權的「制衡機制」。
  • 救濟途徑（第5項）：
    • 人民對「補償金額」不服，得直接向行政法院提起「給付訴訟」（免訴願）。
    • 對於調整或終止本身不服，應提起「撤銷訴訟」或「確認訴訟」。
  • 本條的設計精神是：公益優先
    • 機關為防止重大公益危害，得單方調整或終止契約；但必須補償人民損失，以平衡公益與私益。
    • 同時，人民對調整有「忍受義務」，若無法忍受，可選擇終止契約。
條文拆解
第一項：機關之調整或終止權
  • 「行政契約當事人之一方為人民者」：政府與民間簽的契約。
    • 契約一方為行政機關，他方為人民。
  • 「行政機關為防止或除去對公益之重大危害」：為了阻止或消除會嚴重傷害公共利益的事。
    • 防止：危害尚未發生，但可預見將發生。
    • 除去：危害已發生，需要停止。
    • 對公益之重大危害：
      • 公益：不特定多數人的利益（如公共安全、環境保護、國民健康）。
      • 重大：危害程度嚴重，非輕微。
      • 須有具體事實或科學證據，不得空言。
  • 「得於必要範圍內調整契約內容或終止契約」：政府可以在必要的範圍內，把合約內容改掉，或直接解約。
    • 得：裁量權。機關「可以」調整或終止，但不是義務。
    • 必要範圍內：須符合比例原則——調整或終止的程度，應與危害程度相當。
    • 調整契約內容：修改履約條件、期限、給付內容等（不消滅契約）。
    • 終止契約：使契約向後失效（不溯及既往）。
第二項：補償義務
  • 「前項之調整或終止，非補償相對人因此所受之財產上損失，不得為之」 ：政府要改約或解約，必須賠償人民的財產損失，否則不能改、不能解約。
    • 非補償…不得為之：補償是「要件」——不補償就不能調整或終止。
    • 相對人：人民。
    • 因此所受之財產上損失：因調整或終止而直接導致的損失。
      • 如已投入的成本。
      • 須有因果關係。
第三項：書面與理由
  • 「第一項之調整或終止及第二項補償之決定，應以書面敘明理由為之」 ：政府的決定要寫成書面文件，寫清楚為什麼要改、為什麼賠這個數字。
    • 應以書面：強制書面形式。
    • 敘明理由：須說明調整/終止之原因（公益重大危害）、必要性、補償金額之計算依據。
第四項：人民之終止權（對調整之反應）
  • 「相對人對第一項之調整難為履行者，得以書面敘明理由終止契約」 ：政府把合約改得太硬，人民做不下去的話，可以自己提解約。
    • 相對人：人民。
    • 對第一項之調整難為履行者：機關調整後的新契約內容，對人民而言「難以履行」（如成本過高、技術不可行、違反商業常理）。
    • 得以書面敘明理由終止契約：人民得主動終止契約（向後失效）。
      • 須以書面為之，附理由。
    • 注意：此項終止不影響人民依第2項請求補償的權利（因機關的調整已造成損失）。
第五項：補償金額之救濟
  • 「相對人對第二項補償金額不同意時，得向行政法院提起給付訴訟」 ：對賠償金額不滿，可以直接告法院，不用先訴願。
    • 補償金額不同意：包括機關拒絕補償、補償金額過低、補償範圍爭議。
    • 得向行政法院提起給付訴訟：依行政訴訟法第8條，直接提起一般給付訴訟。
    • 無須訴願：本條特別規定，免除訴願程序。
為什麼要有這條規定？
  • 確保公益優先：當契約履行將對公益造成重大危害時，機關不能坐視不管，必須有權介入。
  • 平衡人民權益：機關調整或終止契約，必須補償人民損失（第2項），避免人民獨自承擔公益成本。
  • 提供人民退出機制：若調整後契約難以履行，人民可選擇終止契約（第4項），不受強制拘束。
  • 確保程序透明：書面附理由（第3項）便於人民理解及救濟。
  • 提供快速救濟：第5項允許直接提起給付訴訟，免除訴願，加速紛爭解決。
白話文
  • 政府跟人民簽了行政契約後，如果為了「防止或消除對公共利益的重大危害」 （例如會造成重大污染、公共安全風險），政府可以「調整契約內容」或「終止契約」。但是：
    • 政府必須「賠償人民因此受到的財產損失」，否則不能改、不能解。
    • 政府的決定要「書面寫理由」。
  • 如果政府調整契約後，人民覺得「太硬、做不下去」，人民可以自己「終止契約」（書面、寫理由）。
  • 如果人民對「賠償金額」不滿意，可以直接去行政法院提「給付訴訟」（不用先訴願）。
  • 簡單記：
    • 政府為公益可改約或解約，但要賠錢；
    • 人民覺得改約後做不下去，可自己解約；
    • 賠償金額談不攏，直接告法院。
舉個例子
例1：機關終止契約——補償損失
  • 甲市政府與某化學廠商簽訂「廢棄物處理契約」。
  • 締約後，科學研究發現該化學物質有劇毒，若繼續處理將對周邊居民健康造成重大危害。
  • 市政府依第146條第1項終止契約，並補償廠商已投入的設備成本500萬元。
  • → 符合第146條第1項、第2項。為防止公益重大危害，終止契約並補償。
例2：機關調整契約——補償損失
  • 乙機關與某停車場經營廠商簽訂BOT契約。
  • 締約後，因應環保法規提高，機關調整契約要求廠商增設電動車充電設備（增加成本200萬元）。
  • 機關承諾補償該200萬元。
  • → 符合第146條第1項、第2項。調整契約內容，並補償損失。
例3：機關未補償——調整無效
  • 同上例，機關調整契約要求增設設備，但拒絕補償。
  • → 違反第146條第2項。未補償不得調整，該調整不生效力（或得撤銷）。
例4：人民終止契約——調整難為履行
  • 同上例，機關調整契約要求增設設備，但補償金額不足。
  • 廠商評估後認為增設設備後仍將虧損，「難以履行」，遂依第146條第4項以書面終止契約。
  • → 符合第146條第4項。人民得終止契約。
例5：補償金額救濟
  • 丙廠商對機關之補償金額（100萬元）不服，認為應為300萬元。
  • → 適用第146條第5項。丙得直接向行政法院提起給付訴訟，請求判命機關給付300萬元。
一句話總結
    第146條是「政府為公益可改約解約，但要賠錢」條款——
  • 政府為防止重大公益危害，可調整或終止契約，但須補償人民損失；
  • 人民覺得改約後做不下去，可自己解約；
  • 賠償金額不服，直接告法院。
第147條 行政契約之情事變更（調整、終止與公益維持）
  1. 「行政契約締結後，因有情事重大變更，非當時所得預料，而依原約定顯失公平者，當事人之一方得請求他方適當調整契約內容。如不能調整，得終止契約。」
  2. 「前項情形，行政契約當事人之一方為人民時，行政機關為維護公益，得於補償相對人之損失後，命其繼續履行原約定之義務。」
  3. 「第一項之請求調整或終止與第二項補償之決定，應以書面敘明理由為之。」
  4. 「相對人對第二項補償金額不同意時，得向行政法院提起給付訴訟。」
這一條是關於？
  • 政府跟人民簽了行政契約之後，如果因為「客觀情事發生重大變更」
    • 例如法規突然改變、經濟環境劇變、天災
    • 而且這種變更是「簽約時無法預料」的，導致「依照原來的契約內容會顯失公平」
    那麼：
    • 「任何一方」（政府或人民）都可以「請求他方適當調整契約內容」；
    • 如果無法調整，就可以「終止契約」。
  • 但是，如果契約當事人之一是人民，政府為了「維護公共利益」，
    • 可以在「補償人民的損失之後」「命令人民繼續履行原來的義務」（也就是不讓人民終止，強迫繼續做）。
  • 調整、終止或補償的決定，都要用「書面附理由」。
  • 人民如果對「補償金額」不同意，可以直接向行政法院提起「給付訴訟」。
  • 簡單講：
    • 客觀情勢大變，顯失公平時，雙方都可要求改約或解約；
    • 但政府為了公益，可以補償後強迫人民繼續履約。
這一條的核心
  • 第147條是行政契約的「情事變更原則」條款，與民法第227條之2（情事變更原則）相對應。
    • 但本條增加了第二項的「公益維持」機制——政府可以「補償後強制人民繼續履行」， 這是行政契約與民事契約最大的不同。
  • 情事變更之調整與終止（第1項）：
    • 要件：
      • 「情事重大變更」（客觀事實或法律狀態改變）。
      • 「非當時所得預料」（締約時無法合理預見）。
      • 「依原約定顯失公平」（如一方履行成本暴增，或給付與對待給付嚴重失衡）。
    • 效果：
      • 當事人「得請求他方適當調整契約內容」（協商調整）。
      • 如不能調整，「得終止契約」（向後失效）。
  • 公益維持之強制繼續履行（第2項）：
    • 適用前提：契約當事人之一方為「人民」，且已發生第1項之情事變更。
    • 機關權限：為「維護公益」，得「於補償相對人之損失後」，「命其繼續履行原約定之義務」。
    • 本質：這是機關的「強制繼續履行權」——人民不能依第1項終止契約，機關可強迫人民繼續履約，但必須補償其損失。
  • 書面與理由（第3項）：調整、終止、補償決定均須以「書面」為之，並「敘明理由」。
  • 補償金額之救濟（第4項）：人民對補償金額不服，得直接提起「給付訴訟」（免訴願）。
  • 本條與第146條的區別：
    • 第146條：機關「主動」為防止公益重大危害而調整或終止（公益主動防護）。
    • 第147條：因「客觀情事變更」導致顯失公平，雙方「被動」因應；但機關可為公益「強制人民繼續履行」。
  • 本條的設計精神是：
    • 尊重情事變更原則，允許調整或終止以避免顯失公平；
    • 但當公益受影響時，政府得強制人民繼續履約（須補償），以確保公共任務不中斷。
條文拆解
第一項：情事變更之調整與終止
  • 「行政契約締結後，因有情事重大變更」 ：簽約後，外在環境發生重大變化。
    • 行政契約締結後：契約成立後（含履行期間）。
    • 情事重大變更：客觀基礎事實（如法律、經濟、自然環境、技術）發生重大改變。
      • 不包括「當事人主觀上不想履行」或「商業風險」。
  • 「非當時所得預料」 ：簽約時想不到會發生這種事。
    • 非當時所得預料：締約時，依一般理性人之標準，無法合理預見該變更。
    • 若變更屬可預見（如物價波動、法規可能修正），不適用本條。
  • 「而依原約定顯失公平者」 ：照原來的合約走會很不公平。
    • 依原約定：按原契約條款履行。
    • 顯失公平：給付與對待給付嚴重失衡，或一方履行成本暴增，或契約目的無法達成。
  • 「當事人之一方得請求他方適當調整契約內容」 ：任何一方都可以要求對方把合約內容改一改。
    • 當事人之一方：人民或行政機關均得請求。
    • 得請求：請求權，非單方決定權（須他方同意或協議）。
    • 適當調整：按變更後之情事，合理修改契約內容（如調整給付金額、期限、方式）。
  • 「如不能調整，得終止契約」 ：如果不能改，就可以解約。
    • 不能調整：雙方無法達成調整協議，或調整後仍顯失公平。
    • 得終止契約：任一方得終止契約（向後失效）。
第二項：行政機關為公益強制繼續履行
  • 「前項情形，行政契約當事人之一方為人民時」 ：政府跟民間簽的契約。
    • 當事人一方為行政機關，他方為人民。
  • 「行政機關為維護公益，得於補償相對人之損失後，命其繼續履行原約定之義務」 ：為了公共利益，政府可以賠錢後強迫你照原合約繼續做。
    • 為維護公益：若人民終止契約或調整內容，將影響公共利益（如公共服務中斷、安全風險）。
    • 得：裁量權。機關「可以」選擇強制繼續履行。
    • 於補償相對人之損失後：必須先補償人民因情事變更所受的損失（實際損失，非預期利益）。
    • 命其繼續履行原約定之義務：機關以「行政處分」命人民依「原契約內容」繼續履行（不得調整）。
第三項：書面與理由
  • 「第一項之請求調整或終止與第二項補償之決定，應以書面敘明理由為之」 ：政府的決定要寫下來、說清楚。
    • 機關對於人民的請求（第1項）之回應，或機關主動為強制繼續履行（第2項），均應以書面為之，附理由。
第四項：補償金額之救濟
  • 「相對人對第二項補償金額不同意時，得向行政法院提起給付訴訟」 ：對賠償金額不滿，直接告法院。
    • 適用第2項之強制繼續履行時，人民對補償金額不服。
    • 得直接提起給付訴訟（免訴願）。
為什麼要有這條規定？
  • 引進情事變更原則於行政契約：避免因客觀環境改變，導致一方遭受顯失公平的結果。
  • 確保公益不因情事變更而受損：第2項允許機關在補償後強制人民繼續履約，避免公共服務中斷。
  • 平衡雙方權益：第一項賦予雙方調整或終止的權利，非僅機關單方受益。
  • 提供明確程序：書面、理由、補償、救濟等均有明文。
  • 與民法第227條之2呼應：但增加公益維持之特別規定。
白話文
  • 簽了行政契約之後，如果：
    • 發生「重大情事變更」（例如法規突然改了、經濟崩盤、天災），而且這是「簽約時無法預料」的，
    • 導致「照原契約履行會很不公平」，
    那麼：
    • 任何一方（政府或人民）都可以「要求對方調整契約內容」；
    • 如果無法調整，就可以「終止契約」。
  • 但是，如果契約一方是「人民」，政府為了「維護公共利益」：
    • 可以在「補償人民的損失之後」，「命令人民繼續照原契約履行」——
    • 也就是不讓你解約，強迫你繼續做，但會賠你錢。

例1：人民請求調整
  • 甲與市政府簽訂BOT契約興建停車場。
  • 締約後，政府突然將該區域劃為「徒步區」，禁止車輛進入（情事重大變更，非可預料）。
  • 甲經營停車場已無意義，依原約定顯失公平。甲請求市政府調整契約內容（如變更為商場），或終止契約。
  • → 符合第147條第1項。甲得請求調整或終止。
例2：機關請求調整
  • 乙機關與某廠商簽訂「廢棄物處理契約」。
  • 締約後，環保法規大幅提高處理標準，機關處理成本暴增（原約定機關付費）。機關請求調整處理費用。
  • → 符合第147條第1項。機關得請求調整。
例3：機關強制繼續履行
  • 同上例1，但該停車場為該區域唯一大型停車場，若終止將導致周邊交通癱瘓（重大公益）。
  • 市政府依第147條第2項，補償甲之損失後，命甲繼續經營停車場（原約定）。
  • → 符合第147條第2項。機關得為維護公益，補償後命繼續履行。
例4：未補償不得強制
  • 同上例3，市政府命甲繼續經營，但拒絕補償。
  • → 違反第147條第2項。未補償不得命繼續履行。甲得請求撤銷該命令。
例5：給付訴訟
  • 同上例3，市政府補償甲100萬元，甲認為應補償500萬元。
  • → 適用第147條第4項。甲得直接向行政法院提起給付訴訟，請求判命給付500萬元。
