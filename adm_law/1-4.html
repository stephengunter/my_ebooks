1-4 總則 - 迴避

第32條 公務員應自行迴避之事由
  • 「公務員在行政程序中，有下列各款情形之一者，應自行迴避︰」
    • 一、本人或其配偶、前配偶、四親等內之血親或三親等內之姻親或曾有此關係者為事件之當事人時。
    • 二、本人或其配偶、前配偶，就該事件與當事人有共同權利人或共同義務人之關係者。
    • 三、現為或曾為該事件當事人之代理人、輔佐人者。
    • 四、於該事件，曾為證人、鑑定人者。
這一條是關於？
  • 這一條是「公務員自己閃邊」條款——當公務員（例如承辦人、審查委員、處分決定者）在處理案件時，
    • 如果他自己或他的家人與案件當事人有特定關係（例如是當事人本人、配偶、親戚），
    • 或者他曾經在這個案件中扮演過其他角色（例如當過當事人的代理人、證人、鑑定人），
    就「必須」主動自行迴避，不得參與該案件的處理。這是為了確保行政決定的「公正性」與「無偏頗」。
  • 簡單說：公務員只要跟案子或當事人有特定關係，就要自己主動請辭，不能辦這個案子。
這一條的核心
  • 本條規範的是「公務員應自行迴避」的四種事由，屬「絕對迴避事由」—— 只要符合該款情形，公務員「必須」迴避，無裁量空間，也不問有無「偏頗之虞」的實際證據。
    • 這是為了「客觀上」確保行政程序的公正性，避免「球員兼裁判」或「利益衝突」。
  • 四款「絕對迴避事由」可歸納為三大類型：
    • 身分關係（第1款、第2款）：公務員本人或其親屬、共同權利義務人與事件當事人之間的特定關係。
    • 角色衝突（第3款）：公務員曾為當事人之代理人、輔佐人（從「幫當事人」轉變為「裁判者」）。
    • 程序角色混亂（第4款）：公務員曾為該事件之證人、鑑定人（證人/鑑定人與裁判者角色不能並存）。
  • 本條的適用主體為「公務員」，依刑法第10條第2項及相關解釋，包括：
    • 依法令服務於國家、地方自治團體所屬機關而具有法定職務權限者（即一般稱之「身分公務員」）。
    • 其他依法令從事於公共事務，而具有法定職務權限者（「授權公務員」，如受託行使公權力之私人，在第16條委託範圍內，視為行政機關，其人員亦有本條適用）。
    • 受機關委託行使公權力之私人或團體，於受託範圍內，其執行職務之人員亦視同本條之「公務員」（第2條第3項、第16條）。
  • 違反本條「應自行迴避」而未迴避之效果：
    • 若公務員明知有迴避事由卻不迴避，繼續參與程序，
    • 所為之行政處分或其他行政行為，可能構成「程序重大瑕疵」，得撤銷（甚至無效，如偏頗已達重大明顯程度）；
    • 該公務員亦可能受行政懲處。
條文拆解
  • 「公務員在行政程序中」 ：只要是政府機關的人（或受託行使公權力的民間人士），在處理行政案件時。
    • 公務員：依刑法第10條第2項及行政程序法第2條第3項、第16條，包括：
      • 機關編制內之公務人員（身分公務員）。
      • 依法令或受託行使公權力之私人、團體之成員（授權公務員），於受託範圍內視為公務員。
    • 行政程序中：指本法所稱之行政程序（第2條第1項），包括作成行政處分、締結行政契約、訂定法規命令與行政規則、確定行政計畫、實施行政指導、處理陳情等。亦包括附屬程序（如調查、聽證、審議）。
  • 「有下列各款情形之一者，應自行迴避」 ：只要符合下面四種情況之一，公務員就要自己主動退出，不辦這個案子。
    • 應自行迴避：強制義務，無裁量空間。公務員一旦知悉有迴避事由，即應「主動」退出該案件的處理程序，不得參與任何環節（包括收件、審查、調查、決定、簽核、核定、送達等）。
    • 自行：不待當事人申請，不待上級指示，公務員自己就要主動迴避。
    • 迴避的方式：
      • 若為「承辦人」：應簽請將案件移由其他無迴避事由之公務員辦理。
      • 若為「合議制委員會之委員」：應於會議中說明迴避事由，並離席不參與討論及表決。
      • 若為「機關首長」：應指定其他首長或代理人處理（若全機關皆有迴避事由，應報請上級機關處理）。
  • 第一款（親屬關係）：「本人或其配偶、前配偶、四親等內之血親或三親等內之姻親或曾有此關係者為事件之當事人時 ：公務員自己、現任配偶、前配偶、四等親以內的家人（父母子女兄弟姐妹堂表兄弟姐妹等），三等親以內的姻親（岳父母、公婆、配偶的兄弟姐妹等），甚至是「曾經」有這些關係的人，如果是案件的當事人，公務員就要迴避。
    • 四親等內之血親：
      • 血親：有血緣關係（包括自然血親與法定血親，如養父母、養子女）。
      • 親等計算（民法第967條至第970條）：
        • 一親等：父母、子女。
        • 二親等：祖父母、外祖父母、孫子女、外孫子女、兄弟姐妹。
        • 三親等：曾祖父母、曾外祖父母、曾孫、外曾孫、伯叔姑、舅姨、姪、甥。
        • 四親等：高祖父母、玄孫、堂兄弟姐妹、表兄弟姐妹、姪孫、外甥孫等。
      • 注意：四親等範圍頗廣，包括堂兄弟姊妹、表兄弟姊妹。
    • 三親等內之姻親：
      • 姻親：因婚姻關係而發生的親屬（民法第969條）：配偶之血親、血親之配偶、配偶之血親之配偶。
      • 親等計算：姻親之親等依其配偶與該血親之親等定之（民法第970條）。
      • 三親等內姻親例如：配偶之父母（二親等）、配偶之兄弟姊妹（二親等）、兄弟之妻（二親等）、父母之兄弟之妻（三親等，較複雜）。
    • 或曾有此關係者：即使該親屬關係已消滅（如離婚、前配偶、已解除之收養關係），仍然構成迴避事由（避免曾為姻親、血親而仍有偏頗之虞）。
    • 為事件之當事人：該親屬是該行政程序的當事人（第20條）。例如：
      • 承辦人的兒子（一親等）申請建照 → 應迴避。
      • 承辦人的前妻（前配偶）為處分相對人 → 應迴避。
      • 承辦人的堂兄弟（四親等血親）為陳情人 → 應迴避。
      • 承辦人的岳母（配偶之母，二親等姻親）為契約相對人 → 應迴避。
  • 第二款（共同權利義務關係）：「本人或其配偶、前配偶，就該事件與當事人有共同權利人或共同義務人之關係者」 ：公務員本人、現任配偶、前配偶，如果在這件案子裡，跟當事人是「一起享受權利」或「一起負擔義務」的關係（例如合夥人、連帶債務人），就要迴避。
    • 共同權利人：與當事人共同享有權利（例如：公同共有人、連帶債權人、合夥人）。
    • 共同義務人：與當事人共同負擔義務（例如：連帶債務人、共同侵權行為人、共同納稅義務人）。
    • 就該事件：該共同權利或義務關係，必須與「本案行政程序之標的」直接相關。
    • 適用範圍：僅限於「本人、配偶、前配偶」，不包含其他親屬（已較第一款限縮）。
    • 例如：
      • 甲與乙為連帶債務人（共同義務人），稅捐機關向甲追討欠稅（甲為當事人）， 承辦公務員是乙（共同義務人）→ 應迴避（因承辦人與當事人有共同義務關係）。
      • A與B為土地公同共有人（共同權利人），B申請土地分割登記，承辦公務員是A（共同權利人）→ 應迴避。
    • 不構成迴避的情形：單純的「普通債權人」（非共同權利人）、「保證人」（非連帶債務人）、「上下游廠商」（無共同權利義務關係）。
  • 第三款（曾為當事人之代理人、輔佐人）：「現為或曾為該事件當事人之代理人、輔佐人者」 ：公務員如果現在或曾經在這個案件中，當過當事人的代理人（例如律師）或輔佐人（例如帶去幫忙的人），就要迴避。
    • 現為：目前仍擔任該事件當事人之代理人（第24條）或輔佐人（第31條）。
    • 曾為：過去曾擔任（即使現在已終止委任關係）。避免「球員兼裁判」或「程序角色混淆」。
    • 該事件：同一個行政事件。若僅曾代理當事人之「其他事件」，非本款（但可能依第33條第1項第2款「有偏頗之虞」聲請迴避）。
    • 代理人：依第24條委任之代理人。
    • 輔佐人：依第31條到場之輔佐人。
    • 例如：
      • 承辦公務員兩年前曾擔任本案申請人甲之律師（代理人）→ 應迴避。
      • 承辦公務員曾受甲之邀，以輔佐人身分陪同出席某次協調會 → 應迴避。
  • 第四款（曾為證人、鑑定人）：「於該事件，曾為證人、鑑定人者」 ：公務員如果曾經在這個案件中當過證人（例如親眼看到事實）或鑑定人（例如出具專業報告），就不能再當承辦人或決定者。
    • 於該事件：同一個行政事件。
    • 曾為證人：曾就該事件之事實，提供證言（不論是依第40條自願或依第41條被通知）。
    • 曾為鑑定人：曾就該事件之專業事項，提供鑑定意見（第41條）。
    • 立法理由：證人、鑑定人與裁判者角色不能並存。證人或鑑定人已有既定立場（或已被詢問過特定內容），不宜再由同一人擔任審查或決定者。
    • 例如：
      • 承辦公務員曾在本案的現場會勘中，以「證人」身分描述他所見的事實。
      • 承辦公務員曾受機關選任為「鑑定人」，就本案工程結構安全出具鑑定報告。
    • 注意：本款僅限「曾為證人、鑑定人」，不包括「曾為當事人」或 「曾為其他機關之承辦人」（後者可能依第33條第1項第2款「有偏頗之虞」聲請迴避）。
為什麼要有這條規定？
  • 確保行政程序之公正性：避免公務員因身分關係（自己、親屬、共同權義人）或角色混淆（曾為代理人、輔佐人、證人、鑑定人）而產生偏頗，影響行政決定之正確性。
  • 維護人民對行政之信賴：若公務員與當事人有上述關係卻不迴避，人民會質疑「官官相護」或「利益輸送」，損害第1條所稱「增進人民對行政之信賴」。
  • 落實「任何人不得為自己之法官」之自然正義原則：公務員不得在自己的案件或與自己有利害關係的案件中擔任決定者。
  • 建立客觀、明確之迴避標準：本條採「列舉」方式，使公務員及當事人得以明確判斷「哪些情形應自行迴避」，避免模糊空間。
  • 減輕當事人聲請迴避之負擔：透過「應自行迴避」機制，使明顯有偏頗之虞的情形，由公務員主動排除，無需當事人費時申請（第33條則處理非本條情形之偏頗疑慮）。
白話文
  • 公務員（承辦人、審查委員）在處理案件時，如果遇到以下四種情況，就「必須」自己主動退出，不能辦這個案子：
    1. 他自己、現任配偶、前配偶、四等親以內的家人（父母子女兄弟姐妹堂表兄弟姐妹等）、 三等親以內的姻親（岳父母、公婆、配偶兄弟姐妹等），甚至是「曾經」有這些關係的人，是這個案件的當事人。
    2. 他自己、現任配偶、前配偶，在這件案子裡跟當事人是 「共同享受權利」或「共同負擔義務」的關係（例如合夥人、連帶債務人）。
    3. 他現在或曾經在「這個案件」中，當過當事人的代理人（如律師）或輔佐人。
    4. 他在「這個案件」中，曾經當過證人或鑑定人。
  • 簡單記：公務員跟案子有關係（自己、家人、曾扮演角色），就要自己閃邊。
舉個例子
例1：本人為當事人
  • 甲是市政府建管處公務員，甲自己向建管處申請建築執照。甲應否迴避？
  • → 適用第32條第1款（本人為當事人）。甲應自行迴避，不得參與自己申請案的審查。
例2：配偶為當事人
  • 乙是環保局公務員，乙的配偶丙被環保局裁罰。乙應否迴避？
  • → 適用第32條第1款（配偶為當事人）。乙應自行迴避，不得參與丙的裁罰案件。
例3：四親等血親
  • 丁是經濟部公務員，丁的堂兄弟戊（四親等血親）向經濟部申請公司登記。丁應否迴避？
  • → 適用第32條第1款（四親等內血親為當事人）。丁應自行迴避。
例4：共同義務人
  • 己是稅捐處公務員，己與庚為連帶債務人（共同義務人）。
  • 稅捐處向庚追討欠稅，己為承辦人。己應否迴避？
  • → 適用第32條第2款（本人與當事人有共同義務人關係）。己應自行迴避。
例5：曾為代理人
  • 辛是內政部營建署公務員，辛在進入公職前， 曾受託擔任某建設公司（現在是營建署某案件的申請人）的律師（代理人）。辛應否迴避？
  • → 適用第32條第3款（曾為該事件當事人之代理人）。辛應自行迴避。
例6：曾為證人
  • 壬是農委會公務員，在某農地爭議事件中，曾受機關通知以「證人」身分 到場說明他所見的事實。嗣後，壬被指定為同一事件之承辦人。壬應否迴避？
  • → 適用第32條第4款（曾為該事件之證人）。壬應自行迴避。
常見爭議案例
案情 法院認定
  • 承辦公務員為當事人（甲）之堂兄弟（四親等血親），未自行迴避，仍參與處分之作成。
    違反第32條第1款：
  • 處分程序違法，予以撤銷。
  • 承辦公務員曾為當事人之代理人（律師）， 但主張「案件已事隔多年，且代理事項與本案無關」。
  • 事後當事人主張「輔佐人陳述內容錯誤，非其本意」。
  • 第32條第3款不問「代理事項是否相關」，只要「曾為該事件當事人之代理人」，即應迴避。
  • 處分違法撤銷。
  • 合議制委員會之委員，其配偶為當事人（第1款），委員未迴避，仍參與投票。
    該委員之投票行為違法，影響決議結果，委員會決議撤銷。
一句話總結
    第32條是「公務員自己閃邊」條款——
  • 如果公務員自己、配偶、前配偶、四等親家人、三等親姻親是當事人，
  • 或與當事人有共同權義關係，或曾當過當事人的代理人/輔佐人，或曾當過證人/鑑定人，
  • 就必須主動退出，不得辦案。
第33條 聲請迴避與命令迴避
    • 一、有前條所定之情形而不自行迴避者。
    • 二、有具體事實，足認其執行職務有偏頗之虞者。
  2. 「前項申請，應舉其原因及事實，向該公務員所屬機關為之，並應為適當之釋明；被申請迴避之公務員，對於該申請得提出意見書。」
  3. 「不服行政機關之駁回決定者，得於五日內提請上級機關覆決，受理機關除有正當理由外，應於十日內為適當之處置。」
  4. 「被申請迴避之公務員在其所屬機關就該申請事件為准許或駁回之決定前，應停止行政程序。但有急迫情形，仍應為必要處置。」
  5. 「公務員有前條所定情形不自行迴避，而未經當事人申請迴避者，應由該公務員所屬機關依職權命其迴避。」
這一條是關於？
    這一條是「當事人要求換人」與「上級主動換人」條款——
  • 當公務員沒有依照第32條自行迴避時，當事人可以「申請」要求該公務員迴避。
  • 此外，即使不屬於第32條的情形，只要有具體事實讓當事人覺得這個公務員「會偏袒」 （例如與對造有私交、曾發表不當言論），當事人也可以申請迴避。
  • 申請時要寫明原因事實，並提出初步證據。
  • 如果機關駁回申請，當事人可以在5天內向上級機關要求「覆決」。
  • 在申請結果出來前，被申請的公務員「必須停止」處理案件（緊急情況例外）。
  • 最後，即使當事人沒申請，機關如果發現公務員有第32條的情形卻沒迴避，也「必須」依職權命令該公務員迴避。
  • 簡單說：
    • 公務員該閃沒閃，你可以申請要他閃；
    • 你覺得他會偏，也可以申請要他閃；
    • 上級也可以主動命令他閃；
    • 申請期間他先停工。
這一條的核心
  • 本條是迴避制度的「發動機制」，與第32條（應自行迴避）共同構成完整的迴避規範。
    • 第32條是「公務員主動」；本條則是「當事人被動發動」及「機關職權發動」。
  • 本條五項的架構：
    • 第1項：當事人申請迴避的事由——包括第32條情形而未迴避（第1款），以及「有偏頗之虞」的概括事由（第2款）。
    • 第2項：申請的方式——書面（或言詞記明筆錄），載明原因事實，並為適當釋明；被申請人得提出意見書。
    • 第3項：救濟程序——機關駁回申請後，當事人得於5日內向上級機關請求「覆決」，上級應於10日內處置。
    • 第4項：停止程序——在被申請迴避的公務員所屬機關作成決定前，該公務員應停止參與行政程序（緊急必要處置除外）。
    • 第5項：職權命令迴避——機關若知悉公務員有第32條情形而未迴避，且當事人未申請，機關應依職權命其迴避。
條文拆解
第一項（當事人申請迴避之事由）
  • 「公務員有下列各款情形之一者，當事人得申請迴避」 ：當事人如果覺得這個公務員不應該辦這個案子，可以正式要求他迴避。
    • 公務員：同第32條之定義（含受託行使公權力之私人或團體之成員）。
    • 當事人：依第20條定義（申請人、處分相對人、契約相對人、指導相對人、陳情人、參加人）。
    • 得申請迴避：當事人的權利（得選擇申請或不申請）。申請應向公務員所屬機關提出（第2項）。
  • 第一款：「有前條所定之情形而不自行迴避者」 ：公務員有第32條的情況（例如他的家人是當事人），但他自己沒有主動退出，你就可以申請要他迴避。
    • 前條所定之情形：第32條所列四款（親屬關係、共同權義關係、曾為代理人/輔佐人、曾為證人/鑑定人）。
    • 而不自行迴避：公務員明知有第32條情形，卻未主動迴避。
    • 立法理由：若公務員已自行迴避，當事人無需申請；本款處理公務員「該閃不閃」的情況。
  • 第二款：「有具體事實，足認其執行職務有偏頗之虞者」 ：即使沒有第32條的那些關係，只要你拿出「具體證據」讓一般人覺得這個公務員可能會偏袒（例如他跟對方吃飯、他曾說會偏袒誰），你就可以申請他迴避。
    • 具體事實：不能空泛指摘，必須提出「客觀、可驗證」的事實（如對話錄音、書信、證人、行為紀錄）。例如：
      • 公務員與對造當事人私下聚餐、頻繁聯繫。
      • 公務員曾公開（或在社群媒體）發表「本案我一定會判他贏」等預斷言論。
      • 公務員與當事人間有金錢借貸、投資往來、僱傭關係（非第32條之親屬關係）。
      • 公務員曾為該事件之他造當事人提供諮詢意見（但非正式代理人）。
    • 足認：以「合理第三人」的客觀標準判斷，該具體事實是否足以讓一般人產生「該公務員可能不公正」的懷疑。不以「公務員實際偏頗」為必要。
    • 執行職務有偏頗之虞：偏頗之虞，不限於「對當事人不利」，也包括「對當事人過度有利」（如公務員與申請人有私交，可能給予不當優惠）。
    • 與第1款的區別：第1款是「客觀列舉」事由（法律推定絕對有偏頗之虞）；第2款是「概括」事由，須由當事人舉出具體事實，由機關認定是否已達「偏頗之虞」。
第二項（申請方式與程序）
  • 「前項申請，應舉其原因及事實，向該公務員所屬機關為之，並應為適當之釋明」 ：申請時要寫清楚「為什麼要換人」，並附上初步證據（例如照片、對話紀錄），不能只說「我覺得他會偏」。
    • 應舉其原因及事實：申請書（或言詞記明筆錄）應載明：
      • 申請人（當事人）基本資料。
      • 被申請迴避之公務員姓名、職稱。
      • 申請迴避之原因（第1項第1款或第2款）。
      • 具體事實（如為第2款，尤應詳細記載）。
    • 向該公務員所屬機關為之：向公務員任職的機關（而非公務員本人）提出。例如：經濟部某科員，應向經濟部提出申請。
    • 並應為適當之釋明：當事人應提出「初步證據」或「可供調查的線索」，使機關能合理相信申請非空泛濫訴。釋明程度不必達到「證明」程度，但須超越單純臆測（例如：提出聚餐照片、LINE對話截圖、證人姓名等）。
  • 「被申請迴避之公務員，對於該申請得提出意見書」 ：被點名的公務員可以寫報告解釋
    • 得提出意見書：被申請的公務員有權（非義務）提出書面說明，為自己辯護（例如：說明聚餐是公開場合、發言被斷章取義等）。
    • 意見書應附入卷宗，供機關決定時參考。
第三項（對駁回決定之救濟——覆決）
  • 「不服行政機關之駁回決定者，得於五日內提請上級機關覆決」 ：如果機關說「不用換」，你可以在5天內向他的上級機關要求「覆決」。
    • 不服行政機關之駁回決定：當事人申請後，公務員所屬機關審查後，可能作出「駁回申請」（認定無迴避事由）的決定。
    • 得於五日內：自駁回決定送達後起算5日（日曆日，含假日），屬「法定不變期間」，逾期不得補正。
    • 提請上級機關覆決：向該機關的直接上級機關（如經濟部商業司→經濟部；經濟部→行政院）申請「覆決」（即再次審查）。
    • 覆決的性質：類似訴願的先行程序（或特別救濟程序）。上級機關應重新實質審查有無迴避事由。
  • 「受理機關除有正當理由外，應於十日內為適當之處置」 ：上級機關收到覆決申請後，原則上10天內要給答案。
    • 受理機關：指上級機關（受理覆決的機關）。
    • 除有正當理由外：例如案情複雜需調查、等待補充資料等。若無正當理由，不得拖延。
    • 應於十日內：自收到覆決申請之日起算10日（日曆日）。
    • 為適當之處置：包括：
      • 維持原駁回決定（認定無須迴避）。
      • 撤銷原駁回決定，並命所屬機關准許迴避（即命令該公務員迴避）。
      • 自行命該公務員迴避。
第四項（停止程序）
  • 「被申請迴避之公務員在其所屬機關就該申請事件為准許或駁回之決定前，應停止行政程序」 ：在你申請之後、機關決定之前，這個公務員要「先停工」，不能繼續辦這個案子。
    • 應停止行政程序：從「申請送達所屬機關時」起，至「所屬機關作成准許或駁回決定時」止，該公務員「必須暫停」參與該案件的任何程序行為（不得審查、簽擬、開會、表決、決行等）。
    • 目的：避免在被申請期間，公務員搶先作出不利（或有利）處分，造成既成事實，影響迴避審查的實益。
    • 所屬機關：第二項的「該公務員所屬機關」（即第一審決定機關）。
  • 「但有急迫情形，仍應為必要處置」 ：如果事情很緊急（例如有毒物質洩漏），即使被申請迴避，他還是可以先做緊急處置（例如先關掉閥門），但不能做最終決定。
    • 有急迫情形：如不立即處置，將發生難以回復的損害或程序將無從進行。例如：
      • 證據即將滅失（證物即將銷毀、證人即將出國）。
      • 時效即將屆滿（申請期限、行政處分時效）。
      • 公共安全危害（污染持續擴大、危險物洩漏）。
    • 仍應為必要處置：即使被申請迴避，仍可為「保全、防止損害擴大」等必要行為（如查封、勒令停工、採樣檢驗），但不得為最終決定（如裁罰處分、核發許可）。
第五項（職權命令迴避）
  • 「公務員有前條所定情形不自行迴避，而未經當事人申請迴避者，應由該公務員所屬機關依職權命其迴避」 ：即使當事人沒申請，機關如果發現公務員有該閃沒閃的情況，也必須主動命令他迴避。
    • 公務員有前條所定情形：公務員有第32條各款情形（親屬關係等）。
    • 不自行迴避：公務員未主動迴避。
    • 而未經當事人申請迴避：當事人不知情、未申請，或雖知情但選擇不申請。
    • 應由該公務員所屬機關依職權命其迴避：機關「必須」（應）主動調查，若發現有第32條情形且公務員未迴避，應以「命令」方式強制該公務員迴避。這是機關的法定義務，不得以「當事人沒申請」為藉口推託。
為什麼要有這條規定？
  • 落實迴避制度的實效性：第32條「應自行迴避」若無監督機制，可能形同具文。本條賦予當事人申請權及機關職權命令權，確保迴避義務被遵守。
  • 保障當事人的公正程序請求權：當事人有權要求在「無偏頗之虞」的公務員面前進行程序。本條第1項第2款特別納入「偏頗之虞」概括事由，填補第32條列舉之不足。
  • 建立迅速有效的救濟管道：第3項的5日內覆決、10日內處置，展現立法者對「程序從速」的重視，避免因迴避爭議延宕太久。
  • 防止被申請迴避之公務員搶辦案件：第4項「停止程序」的設計，避免公務員在被申請後、決定前，搶先作出處分，架空迴避審查。
  • 課予機關主動監督義務：第5項要求機關依職權命迴避，避免「公務員不閃、當事人不知」的漏洞，確保行政體系內部自我淨化。
白話文
  • 這一條是「申請換人」與「上級換人」的規定：
    • 第一項：當事人可以在兩種情況下「申請」公務員迴避：①公務員有第32條的情況（例如家人是當事人）卻沒自己閃；②你拿出具體證據（例如照片、對話），讓一般人覺得這個公務員「可能會偏袒」。
    • 第二項：申請時要寫明原因事實，附上初步證據，向公務員所屬機關提出。被點名的公務員也可以寫說明書辯解。
    • 第三項：如果機關駁回你的申請，你可以在5天內向上級機關要求「覆決」，上級機關原則上要在10天內處理。
    • 第四項：在你申請之後、機關決定之前，被申請的公務員「必須停工」，不能繼續辦這個案子（緊急情況除外，例如先做必要處置）。
    • 第五項：即使當事人沒申請，機關如果發現公務員有第32條情況卻沒閃，也「必須」主動命令他迴避。
舉個例子
例1：申請迴避
  • 甲是某案件的當事人，發現承辦公務員乙的兒子（一親等血親）是該案的對造當事人， 乙卻未自行迴避（違反第32條第1款）。
  • 甲向乙所屬機關提出申請，要求乙迴避。
  • → 符合第33條第1項第1款。機關應受理，並命乙迴避。
例2：偏頗之虞
  • 丙是申請人，發現承辦公務員丁與對造當事人戊頻繁私下聚餐， 並在社群媒體上發文「戊是個好人，希望他贏」。丙截圖保存，並向機關申請丁迴避。
  • → 符合第33條第1項第2款。丙提出「具體事實」（聚餐照片、貼文截圖）， 足認有偏頗之虞。機關應審查，若屬實應命丁迴避。
例3：提出意見書
  • 承例2，被申請迴避的丁向機關提出意見書， 辯稱「聚餐是公務餐會，發文是私人抒發，不影響職務公正」。
  • → 符合第33條第2項。機關應審酌雙方意見，作成准否迴避之決定。
例4：覆決
  • 承例2，機關審查後駁回丙的申請（認定無偏頗之虞）。
  • 丙不服，於收到駁回決定後3日內，向上級機關（如經濟部→行政院）申請覆決。
  • 上級機關於收到申請後8日內，認定丁確有偏頗之虞，撤銷原駁回決定，並命丁迴避。
  • → 符合第33條第3項。丙在5日內申請，上級在10日內處置，合法。
例5：停止程序
  • 承例2，丙提出申請後，機關尚未作成決定。
  • 丁原訂於明日簽擬對丙不利的裁罰處分。依第33條第4項，丁應立即停止該簽擬行為。
  • → 符合第33條第4項本文。丁不得繼續程序。
例6：急迫情形
  • 承例2，但在申請後，發現丙的工廠正在洩漏有毒氣體，若不立即處置將危害公眾安全。
  • 丁雖被申請迴避，仍立即下令該工廠停工並封鎖現場。
  • → 符合第33條第4項但書。丁得為「必要處置」（制止危害），但不得作成最終裁罰決定。
例7：職權命令迴避
  • 某機關首長發現所屬公務員己，其配偶為某案件當事人（第32條第1款）， 己未自行迴避，且當事人亦未申請。
  • 機關首長依職權命令己迴避該案件。
  • → 符合第33條第5項。機關應主動命迴避。
常見爭議案例
案情 法院認定
  • 當事人申請迴避，主張承辦公務員「與對造有密切私人情誼」，提出兩人頻繁共同出入餐廳之照片。
  • 機關駁回，上級覆決亦維持。
  • 法院審理實體處分時，認定該等事實「客觀上已足使一般人懷疑公正性」，應准予迴避，原處分撤銷。
  • 當事人申請迴避，未附任何具體事證，僅泛稱「承辦人態度不佳」。
  • 機關駁回，上級覆決維持。
  • 當事人未為「適當釋明」，駁回合法。
  • 公務員在被申請迴避後，未停止程序，仍簽擬處分。
違反第33條第4項：
    該簽擬行為違法，據此作成之處分撤銷。
一句話總結
    第33條是「申請換人」與「上級換人」條款——
  • 公務員該閃沒閃，或你有證據他會偏袒，就可以申請要他迴避；
  • 申請要寫理由、附證據，駁回可於5天內向上級覆決；
  • 申請後他先停工（緊急除外）；
  • 即使沒人申請，上級發現他該閃沒閃，也要主動命令他迴避。
