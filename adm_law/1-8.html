1-8 總則 - 期日與期間

第48條 期間之計算
  1. 「期間以時計算者，即時起算。」
  2. 「期間以日、星期、月或年計算者，其始日不計算在內。但法律規定即日起算者，不在此限。」
  3. 「期間不以星期、月或年之始日起算者，以最後之星期、月或年與起算日相當日之前一日為期間之末日。但以月或年定期間，而於最後之月無相當日者，以其月之末日為期間之末日。」
  4. 「期間之末日為星期日、國定假日或其他休息日者，以該日之次日為期間之末日；期間之末日為星期六者，以其次星期一上午為期間末日。」
  5. 「期間涉及人民之處罰或其他不利行政處分者，其始日不計時刻以一日論；其末日為星期日、國定假日或其他休息日者，照計。但依第二項、第四項規定計算，對人民有利者，不在此限。」
這一條是關於？
  • 這一條是「時間怎麼算」條款——當法律或行政程序規定「幾天內要完成某事」 （例如：收到處分書後30天內要提起訴願），這個「期間」要怎麼計算，就是本條的規範。
    • 包括：從哪天開始算？遇到假日怎麼辦？最後一天是假日怎麼處理？對人民不利的處分（例如裁罰）算法有什麼不同？
    簡單說：法律上的天數怎麼算，從哪天起算、假日怎麼辦，這條都有規定。
這一條的核心
  • 本條規範「期間」的計算方法。
    • 例如訴願期間、申請補正期間、機關處理期間。
    與民法第119條至第124條（期間計算）精神一致，但考量行政程序之特殊性（尤其是對人民不利處分）而有若干調整。
  • 本條五項的架構：
    • 第一項：以「時」計算（例如「24小時內」）→ 即時起算。
    • 第二項：以「日、星期、月、年」計算（例如「30日內」）→ 始日不計（但法律另有規定者除外）。
    • 第三項：期間末日之計算（非從星期、月、年之始日起算者）→ 以「相當日之前一日」為末日；無相當日者，以該月末日為末日。
    • 第四項：末日遇假日之處理（有利於人民之延長）→ 順延至次日（星期六則順延至次週一上午）。
    • 第五項：涉及處罰或其他不利處分之特別規定（對人民不利）→ 始日「不計時刻以一日論」； 末日逢假日「照計」（不順延）；
      • 但若依第二項、第四項計算對人民「有利」，則從有利之算法。
  • 本條的核心原則：
    • 有利人民原則：期間計算若有疑義，應採對人民有利之解釋（第五項但書）。
    • 避免失權：期間經過可能導致人民喪失權利（如訴願逾期），因此計算規則應明確、合理（如假日順延）。
條文拆解
第一項（以「時」計算）
  • 「期間以時計算者，即時起算」：算「小時」的，從事件發生那個時刻就開始算。
    • 期間以時計算：法律規定「幾小時內」須完成某行為。例如：「情況急迫時，得於24小時內補具聲請書」。
    • 即時起算：自「事件發生之時」起算，不扣除任何時間。
      • 例如：上午9時收到處分書，24小時內應提起救濟 → 至翌日上午9時屆滿。
第二項（以日、星期、月、年計算——始日不計）
  • 「期間以日、星期、月或年計算者，其始日不計算在內」：算「天數」的，收到當天不算，從「隔天」開始算第一天。
    • 以日、星期、月、年計算：例如「15日內」、「2個月內」、「1年內」。
    • 始日不計算在內：起算日（始日）不計入期間。
      • 例如：3月1日收到處分書，期間為30日 → 從3月2日開始算第1天，至3月31日為第30天（末日）。
    • 立法理由：使人民有完整之準備期間（因收到通知當日可能已無時間處理）。
  • 「但法律規定即日起算者，不在此限」：如果法律特別規定「從當天就開始算」，那就從當天算。
    • 但：例外。若「法律」明文規定「自即日起算」，則始日算入。
    • 注意：此處「法律」指立法院通過之法律，不包括法規命令、行政規則。
第三項（期間末日之計算——相當日原則）
  • 「期間不以星期、月或年之始日起算者」：如果期間不是從月初、週一開始算。
    • 例如：3月5日收到處分書，期間為「2個月」→ 非從3月1日（月之始日）起算。
  • 「以最後之星期、月或年與起算日相當日之前一日為期間之末日」 ：從哪天開始算，就找到下個月/下週的同一天，它的「前一天」是最後一天。
    • 相當日：與「起算日」日期相同的那一天。 非從3月1日（月之始日）起算。
    • 前一日：相當日之「前一天」為末日。例如：
      • 3月5日收到處分書，期間為1個月 → 起算日為3月5日（始日不計，3月6日第1天），相當日為4月5日，末日為4月4日（前一日）。
        • 亦即：3月6日至4月4日共30天。
  • 「但以月或年定期間，而於最後之月無相當日者，以其月之末日為期間之末日」 ：如果下個月沒有同一天（例如1月31日起算，2月沒有31日），就以那個月的最後一天（2月28或29日）為末日。
    • 無相當日：例如：
    • 1月31日收到處分書，期間為1個月 → 2月無31日，則以2月28日（或29日，閏年）為末日。
第四項（末日遇假日之順延）
  • 「期間之末日為星期日、國定假日或其他休息日者，以該日之次日為期間之末日」 ：如果最後一天是假日，就順延到第二天（非假日）。
    • 星期日：週日。
    • 國定假日：如元旦、春節、228、國慶日等（依《紀念日及節日實施辦法》）。
    • 其他休息日：如颱風假（地方政府宣布停班）彈性放假、補假
    • 以該日之次日為期間之末日：順延至下一個「非假日」。
      • 例如：末日為週日 → 順延至週一。
  • 「期間之末日為星期六者，以其次星期一上午為期間末日」 ：如果最後一天是星期六，就順延到下星期一上午。
    • 星期六：特別規定（因星期六在台灣多為「休息日」，但部分機關有上班）。
      • 為明確起見，本法規定「以其次星期一上午為期間末日」。
    • 次星期一上午：通常解釋為「星期一上班時間結束前」即可。
    • 注意：若星期一亦為假日（如國定假日），則再順延至星期二（依前段規則）。
第五項（涉及處罰或其他不利處分之特別規定）
  • 「期間涉及人民之處罰或其他不利行政處分者」：如果是「政府要處罰你」或「要你做不利的事」的期限。
    • 涉及人民之處罰：如裁罰處分之繳納期限、改善期限。
    • 其他不利行政處分：如命拆除違建、命停止營業、命回復原狀等期限。
    • 不包括：人民「申請」之期間（如申請補助、申請執照，屬有利人民，不適用本項不利規則）。
  • 「其始日不計時刻以一日論」：對你不利的期限，收到當天「不算」，從隔天開始算第一天（同一般原則）。
  • 「其末日為星期日、國定假日或其他休息日者，照計」：對你不利的期限，最後一天碰到假日，「不順延」，還是算那天到期。
  • 「但依第二項、第四項規定計算，對人民有利者，不在此限」：總之，算法要選對人民「比較有利」的那一種。
    • 立法精神：期間計算有疑義時，應採對人民有利之解釋（有利原則）。
    • 例如：
      • 不利處分之繳納期限，若依第四項假日順延（末日為週日 → 順延至週一）對人民有利（多一天），則應順延。
      • 若依本項「照計」對人民有利，則採對人民有利者。
為什麼要有這條規定？
  • 明確法律關係，避免爭議：統一期間計算規則，避免因起算日、末日、假日之認定不同，導致權利義務不明。
  • 保障人民程序權益：透過「始日不計」、「假日順延」等規定，給予人民完整之準備期間，避免因行政作業不及而喪失權利。
  • 兼顧行政效率與公正：對於不利處分之期間（如繳納罰鍰），原則上不假日順延，以督促人民儘速履行；但同時設有有利原則之但書，避免過苛。
  • 與民法、訴訟法調和：本條與民法第119條至第124條、民事訴訟法第161條至第164條、訴願法第14條至第17條之期間計算精神一致。
  • 因應現代社會需求：第四項特別規定星期六之處理（因週六多為休息日，但部分機關有上班），避免爭議。
白話文
    這一條是「法律上的天數怎麼算」：
  • 第一項：算「小時」的，從事情發生的那個時刻就開始算。
  • 第二項：算「天數」的（例如30天內），收到通知「當天不算」，從「隔天」開始算第一天。除非法律特別規定「從當天算」。
  • 第三項：如果不是從月初、週一開始算（例如3月5日收到，算1個月），那就找到下個月同一天（4月5日）的「前一天」（4月4日）為最後一天。
    • 如果下個月沒有同一天（例如1月31日起算，2月沒有31日），就以那個月的最後一天（2月28或29日）為最後一天。
  • 第四項：如果最後一天是「星期日、國定假日、其他休息日」→ 順延到隔天（非假日）。
    • 如果最後一天是「星期六」→ 順延到下週一。
  • 第五項：如果是「政府要處罰你」或「要你做不利的事」的期限： 順延到隔天（非假日）。
    • 收到當天「不算」，從隔天算第一天（同第二項）。
    • 最後一天碰到假日，「不順延」（照樣算那天到期）。
    • 但是，如果用一般算法（假日順延）對你「比較有利」，就採用對你有利的算法。
舉個例子
例1：第一項——以時計算
  • 法規規定「應於24小時內向警察機關報備」。
  • 甲於3月1日上午10時完成某行為，則報備期限至3月2日上午10時屆滿。
  • → 符合第48條第1項。即時起算。
例2：第二項——始日不計
  • 甲於3月1日收到處分書，訴願期間為30日。
  • 甲得提起訴願之末日為3月31日（3月2日起算第1天，3月31日第30天）。
  • → 符合第48條第2項。始日（3月1日）不計。
例3：第二項但書——法律規定即日起算
  • 假設某法律明文規定「自收到通知即日起算」
  • 甲於3月1日收到通知，期間15日。則末日為3月15日（3月1日算第1天）。
  • → 符合第48條第2項但書。
例4：第三項——相當日之前一日
  • 甲於3月5日收到處分書，期間為「2個月」。
  • 起算日為3月5日（始日不計，3月6日第1天），相當日為5月5日，末日為5月4日。
  • → 符合第48條第三項前段。期間：3月6日至5月4日。
例5：第三項但書——無相當日
  • 甲於1月31日收到處分書，期間為「1個月」。
  • 起算日1月31日（始日不計，2月1日第1天），相當日為2月31日（不存在），以2月28日（非閏年）為末日。
  • → 符合第48條第三項但書。末日為2月28日。
例6：第四項——末日為星期日
  • 甲訴願期間末日為6月12日（星期日）。則順延至6月13日（星期一）。
  • → 符合第48條第四項前段。
例7：第四項——末日為星期六
  • 甲訴願期間末日為6月11日（星期六）。則順延至6月13日（星期一）上午（實務上為星期一整天）。
  • → 符合第48條第四項後段。
例8：第五項——不利處分，末日逢假日「照計」
  • 環保局裁處甲罰鍰，繳納期限為7月11日（星期日）。
  • 依本項「照計」，甲仍應於7月11日前繳納（但銀行未開？實務會有爭議）。
  • 但若依第四項順延至7月12日對甲有利，則應適用有利之算法（但書）。
  • → 適用第48條第五項但書，應採對甲有利之算法（順延至7月12日）。故實際末日為7月12日。
常見爭議案例
案情 法院認定
  • 訴願期間末日為星期六，訴願人於次星期一提出訴願。
  • 原訴願決定以「逾期」駁回。
  • 適用第48條第4項後段，認定末日為星期六者，順延至次星期一上午。
  • 訴願人於星期一提出未逾期。
  • 撤銷原訴願決定。
  • 裁罰繳納期限末日為星期日，受處分人於星期一繳納。
  • 原處分機關以「逾期」加徵滯納金。
  • 適用第48條第5項但書。
  • 依第四項假日順延對人民有利，應予順延，不得加徵滯納金。
  • 機關通知補正期限為7日，始日（送達日）是否計入？
  • 適用第48條第2項
  • 始日不計，故補正期限為送達翌日起算7日。
一句話總結
    第48條是「時間怎麼算」條款——
  • 算小時從當下起算；算天數從隔天起算；
  • 最後一天是假日原則順延（但對你不利的期限，假日原則不順延）；遇到星期六順延到下週一；
  • 總之，算法要選對你比較有利的那一種。
第49條 郵寄申請之送達時點
  • 「基於法規之申請，以掛號郵寄方式向行政機關提出者，以交郵當日之郵戳為準。」
這一條是關於？
  • 這一條是「郵戳為憑」條款——當你依法要向政府提出申請（例如申請補助、執照、補件），
    • 如果你是用「掛號郵寄」的方式，
    • 那麼你的申請「何時送出」，不是以政府「何時收到」為準，而是以你「寄出當天的郵戳日期」為準。
  • 簡單說：用掛號寄申請，郵戳日期就是你的申請日期，不是政府收到的那天。
這一條的核心
  • 本條是行政程序法關於「申請之提出時點」的特殊規定，解決了「郵寄申請」因郵遞時間落差， 可能導致人民因「送達較晚」而被認定「逾期」的不公平問題。
  • 一般原則（民法）：
    • 非對話之意思表示（如書面申請），原則上以「到達相對人（行政機關）」時發生效力。
    • 若採此原則，人民以郵寄申請，須待郵件送達機關時，申請才生效。若郵遞延誤（如逢假日、天災），可能導致申請「逾期」，而人民無從控制。
  • 本條之特別規定（有利人民之例外）：
    • 本條明定：以「掛號郵寄」提出申請者，以「交郵當日之郵戳」為準。
    • 換言之，只要郵戳日期在法定期限內，縱使機關收到時已逾期限，申請仍屬「合法（未逾期）」。
  • 本條之適用要件：
    1. 基於法規之申請：須有法律或法規命令之依據（與第34條但書之「依法規申請」同）。
    2. 以掛號郵寄方式：限「掛號」（含掛號信件、掛號包裹），不包括普通郵件（平信）、快遞、宅配、親自送達（因無郵戳）。
    3. 向行政機關提出：須送達至有管轄權之行政機關（或其指定之收件單位）。
  • 立法精神：
    1. 保護人民權益：避免因郵遞過程之不可抗力（如郵局延誤、天氣、交通），導致人民喪失申請權。
    2. 鼓勵使用掛號郵寄：掛號有郵戳可稽，平信無法證明交寄日期，故本條僅限掛號。
    3. 明確化：以郵戳為客觀標準，減少爭議。
條文拆解
  • 「基於法規之申請」 ：只要你依法有權向政府申請某件事（不是陳情、不是檢舉）。
    • 基於法規：有「法律或法規命令」之依據，人民享有申請權（與第34條但書、第35條「依法」同義）。
      • 不包括單純陳情、檢舉（無申請權）。
    • 申請：指向行政機關請求為特定行政行為（如核發許可、給付補助、作成處分）之意思表示。例如：
      • 申請建築執照（《建築法》）。
      • 申請專利（《專利法》）。
      • 申請社會補助（《社會救助法》）。
  • 「以掛號郵寄方式向行政機關提出者」 ：你用「郵局掛號」寄申請書給政府。
    • 以掛號郵寄方式：透過郵政機關（中華郵政）之「掛號」服務寄送（含掛號信件、掛號包裹、限時掛號）。不包括：
      • 普通郵件（平信）：無郵戳可稽，無法證明交寄日期。
      • 快遞、宅配（如黑貓、DHL、順豐）：非郵政掛號，無郵戳，不適用本條（但仍可能以「送達時點」認定，或依其他法規）。
    • 向行政機關提出：收件人為行政機關（或其指定之承辦單位、信箱號碼）。地址須正確。
  • 「以交郵當日之郵戳為準」 ：郵戳上的日期，就是你的申請日期（不是政府收到的日期）。
    • 以交郵當日之郵戳為準：申請之時點，以「郵局蓋在信封上的郵戳日期」為準，而非行政機關「收受日期」。
    • 法律效果：
      • 若郵戳日期在法定期限內（例如補助申請截止日為3月31日，郵戳為3月31日），即使機關4月2日才收到，申請仍屬合法（未逾期）。
      • 若郵戳日期已逾期限（郵戳為4月1日，期限為3月31日），即使機關尚未收到，申請仍屬逾期。
為什麼要有這條規定？
  • 保護人民免受郵遞延誤之不利益：人民將申請書交郵後，郵遞時間非其所能控制（如逢假日、天災、郵務延誤）。本條使人民承擔「交寄」之風險（須在期限前寄出），但不承擔「送達」之風險。
  • 建立客觀、明確之判斷標準：郵戳日期為客觀事實，易於證明（掛號收據），避免機關與人民對「何時送達」之爭議。
  • 鼓勵使用掛號郵寄：掛號有郵戳可稽，平信無法證明交寄日期，故本條僅限掛號，實務上鼓勵人民使用掛號以保障權益。
  • 與訴願法、行政訴訟法一致：訴願法第14條第3項：「訴願之提起，以原行政處分機關或受理訴願機關收受訴願書之日期為準。但以掛號郵寄方式提起者，以交郵當日之郵戳為準。」本條與之相同。行政訴訟法第89條第1項亦有類似規定。
  • 減輕行政機關之收件壓力：避免人民在期限最後一天「親自送達」造成機關擁擠，郵寄可分散人流。
白話文
  • 如果你依法要向政府申請某件事（例如申請補助、執照），而且你是用「郵局掛號」寄申請書，
    • 那麼你的申請日期，不是以政府「收到」的那天為準，而是以你「寄出當天郵戳上的日期」為準。
  • 簡單說：用掛號寄申請，郵戳日期就是你的申請日期。
舉個例子
例1：郵戳在期限內——合法
  • 某補助申請截止日為3月31日。
  • 甲於3月31日到郵局以「掛號」寄出申請書，郵戳日期為3月31日。市政府於4月3日收到。
  • → 適用第49條。以郵戳3月31日為準，甲之申請未逾期，合法。
例2：郵戳逾期限——逾期
  • 同上例，甲於4月1日寄出，郵戳為4月1日。
  • 市政府於4月3日收到。
  • → 適用第49條。以郵戳4月1日為準，已逾3月31日，申請逾期，機關得駁回。
例3：非掛號——不適用本條
  • 甲以「平信」寄出申請書，無法取得郵戳證明（或平信郵戳僅為處理戳記，非交寄證明）。
  • 市政府於4月3日收到。甲主張「我3月31日就寄了」。
  • → 不適用第49條（非掛號）。原則上以「到達機關」時為準（4月3日）， 可能被認定逾期（除非甲能提出其他證明，如證人、監視器）。建議使用掛號。
常見爭議案例
案情 法院認定
  • 申請人於期限末日以掛號寄出申請書，郵戳為期限末日，機關以「收件日已逾期」駁回。
  • 適用第49條，認定郵戳為憑，申請未逾期，撤銷原處分。
  • 申請人以平信寄出，無法證明交寄日期，機關以收件日為準認定逾期。
  • 平信不適用第49條。
  • 以到達時為準，申請逾期成立。
  • 申請人以民間快遞寄送，快遞簽收單顯示「3月31日交寄、4月1日送達」。
  • 機關以4月1日收件日為準認定逾期。
  • 申請人主張類推適用第49條。
  • 第49條限「掛號郵寄」，民間快遞不適用，仍以送達日為準（除非另有法規）。
  • 駁回申請。
一句話總結
    第49條是「郵戳為憑」條款——
  • 用掛號寄申請書，郵戳日期就是你的申請日期，不是政府收到的那天；
  • 期限內寄出（郵戳在期限內）就算合法，即使政府晚收到也沒關係。
第50條 回復原狀
  1. 「因天災或其他不應歸責於申請人之事由，致基於法規之申請不能於法定期間內提出者，得於其原因消滅後十日內，申請回復原狀。如該法定期間少於十日者，於相等之日數內得申請回復原狀。」
  2. 「申請回復原狀，應同時補行期間內應為之行政程序行為。」
  3. 「遲誤法定期間已逾一年者，不得申請回復原狀。」
這一條是關於？
  • 這一條是「錯過期限怎麼辦」條款——如果你
    • 因為「天災」（例如地震、颱風）或其他「不是你自己的錯」的原因（例如重病住院、突然被隔離），
    • 導致你沒能在法定期間內（例如30天訴願期間、7天補正期間）向政府提出申請，
    • 你可以在「原因消滅後10天內」，向政府申請「回復原狀」，
    • 也就是請政府「把過去的時間補回來」，讓你的申請視同「沒有逾期」。
  • 申請回復原狀的同時，你要立刻把之前沒做的程序行為（例如補交文件、提起訴願）一起補做。
  • 如果錯過期間已經超過「一年」，就不能再申請回復了。
  • 簡單說：不是你故意拖延，而是不可抗力讓你錯過期限，可以在原因消失後10天內申請「補救」，把失去的時間補回來。
這一條的核心
  • 本條是行政程序法中的「回復原狀」制度（與民事訴訟法第164條、行政訴訟法第91條類似）， 旨在救濟因「不可歸責於當事人」之事由，而遲誤法定期間之情形。
  • 核心概念：
    • 適用對象：「基於法規之申請」（與第34條、第49條同），即人民依法享有申請權之事件（如訴願、申請補助、申請執照）。 不包括「機關依職權發動」之程序。
    • 事由：須為「天災」或「其他不應歸責於申請人之事由」（即不可歸責於申請人之不可抗力或意外）。
    • 申請期間：須於「原因消滅後10日內」申請（若原法定期間少於10日，則於「相等之日數」內申請）。
    • 補行行為：申請回復原狀時，應「同時」補行期間內應為之行政程序行為（例如：補交申請書、提起訴願）。
    • 除斥期間：遲誤法定期間「已逾一年者」，不得申請回復原狀（絕對失權）。
  • 本條之立法精神：
    • 保障人民權益：避免因不可抗力（如天災、急病）導致人民錯過法定期間，而喪失實體權利。
    • 督促儘速行使：要求原因消滅後10日內申請，避免拖延。
    • 法律安定性：遲誤逾一年者，不得回復（避免過久後再爭執）。
條文拆解
第一項（申請回復原狀之要件與期間）
  • 「因天災或其他不應歸責於申請人之事由」 ：因為天災（颱風、地震）或其他「不是你錯」的原因（例如突然重病住院）。
    • 天災：自然災害，如地震、颱風、洪水、土石流、海嘯、火山爆發等（客觀上無法預見、無法避免）。
    • 其他不應歸責於申請人之事由：
      • 不可抗力：戰爭、瘟疫、大規模傳染病（如COVID-19疫情期間封城、隔離）。
      • 意外事件：申請人突發重病、車禍、住院、昏迷、被羈押、服刑（非因自己故意犯罪？須個案判斷）。
      • 第三人行為：郵局、快遞公司因不可抗力延誤（非申請人可控制），但若選用平信（非掛號），可能被認定有過失。
      • 行政機關之錯誤：機關通知錯誤、送達錯誤，導致申請人誤判期限（但此可能另依其他規定救濟）。
    • 不包含：可歸責於申請人之事由（如忘記、記錯日期、出國旅遊、因工作繁忙、自己生病但可委任代理人）。
      • 若有「代理人」（第24條），代理人之過失視同本人過失（類推適用民法第224條）。
  • 「致基於法規之申請不能於法定期間內提出者」 ：導致你沒能在法定的時間內提出申請。
    • 基於法規之申請：同第49條，指有法律或法規命令依據之申請（訴願、申請執照、申請補助等）。
    • 不能於法定期間內提出：
      • 法定期間：法律或法規命令規定之「申請期間」，如訴願期間（30日）、申請補正期間（機關指定，但須合理）。
      • 不能提出：因上述事由，事實上無法於期間內提出申請（例如：因颱風郵局停業、因重病住院無法書寫、因隔離無法外出寄信）。
    • 不適用：機關依職權發動之程序、或非法定期間（如陳情無期間限制）。
  • 「得於其原因消滅後十日內，申請回復原狀」 ：在原因消失後的10天內，可以申請「補救」（回復原狀）。
    • 得：申請人之權利（非義務，可選擇不申請）。
    • 其原因消滅後：天災結束、疾病痊癒出院、解除隔離、郵局恢復營業等。
    • 十日內：自「原因消滅」之翌日起算（第48條第2項，始日不計），共10日（日曆日，含假日）。
    • 申請回復原狀：向「受理原申請之行政機關」提出書面申請（建議掛號），請求准予「回復原狀」（即視為未逾期）。
    • 回復原狀之效果：經准許後，申請人之申請「視為已在法定期間內提出」（類推適用第17條第2項之法理）。機關不得以逾期為由駁回。
  • 「如該法定期間少於十日者，於相等之日數內得申請回復原狀」 ：如果原本的期限不到10天（例如只有5天），那麼申請回復的期限也是5天（不是10天）。
    • 法定期間少於十日：例如某法規規定申請期間僅「5天」。
    • 於相等之日數內：申請回復原狀之期間，不是10天，而是「與原期間相同天數」（例如5天）。
    • 立法理由：若原期間很短（如5天），不宜給予過長之回復期間（10天反而比原期間更長），故以「相等之日數」為限。
第二項（補行程序行為）
  • 「申請回復原狀，應同時補行期間內應為之行政程序行為」 ：申請補救的同時，就要把原本該做的事（例如遞訴願書）一起做了。
    • 應同時補行：申請回復原狀之「同時」（同一份書面或同一時間），申請人必須「補做」 原來應該在法定期間內做、但沒做的事情。例如：
      • 若原本是要「提起訴願」：應同時提出訴願書。
      • 若原本是要「申請補助」：應同時提出補助申請書及相關文件。
      • 若原本是要「補正文件」：應同時補正該文件。
    • 不得分開：不得先申請回復原狀，事後再補行行為。若未同時補行，機關得駁回回復原狀之申請（或視為未申請）。
    • 法律效果：若回復原狀經准許，該補行行為「視為已於法定期間內提出」。
第三項（除斥期間——逾一年不得申請）
  • 「遲誤法定期間已逾一年者，不得申請回復原狀」 ：如果錯過期限已經超過一年，就不能再申請補救了。
    • 遲誤法定期間已逾一年：從「法定期間屆滿日」起算，至「申請回復原狀時」，已超過「一年」（365天）。
      • 例如：訴願期間於113年3月1日屆滿，申請人於114年3月2日才申請回復原狀 → 已逾一年。
    • 不得申請回復原狀：絕對失權，無論不可歸責事由為何，均不得再申請。
    • 立法理由：維護法律安定性，避免當事人長期不作為後，再以陳年舊事為由申請回復，造成程序不安定。
為什麼要有這條規定？
  • 保障人民之實體權益：避免因不可抗力（天災、急病）導致人民錯過法定期間，而喪失申請權或救濟權（如訴願權）。
  • 平衡法律安定性與個案正義：設有嚴格之申請期間（原因消滅後10日內）及除斥期間（逾一年不得申請），避免浮濫。
  • 要求人民儘速補救：第二項要求「同時補行行為」，避免回復原狀制度被濫用為「先搶救濟、拖延實體」。
  • 與訴訟法一致：民事訴訟法第164條、行政訴訟法第91條均有回復原狀制度，本條與之精神相同。
  • 明確不可歸責事由之範圍：「天災」及「其他不應歸責於申請人」之標準，由實務案例累積判斷。
白話文

    • 你可以在「原因消失後的10天內」向政府申請「回復原狀」（也就是請政府「把時間補回來」，當作你沒有逾期）。

舉個例子
例1：天災——颱風
  • 甲提起訴願之30日期間，末日為7月25日。
  • 7月25日當天因颱風來襲，行政機關停止上班（且郵局亦停業），甲無法寄出訴願書。
  • 7月26日颱風離開，恢復上班。甲於7月30日（原因消滅（7/26）後4日）向原處分機關申請回復原狀，並同時提出訴願書。
  • → 符合第50條第1項、第2項。甲應准予回復原狀，訴願視為未逾期（7月25日提出）。
例2：重病住院——不應歸責
  • 乙申請補助之法定期間為30日（至3月31日止）。 乙於3月20日因車禍重傷昏迷住院，至4月10日始清醒。
  • 乙於4月15日（原因消滅（4/10）後5日）向機關申請回復原狀，並同時補提申請書。
  • → 符合第50條第1項、第2項。乙因重病昏迷，不可歸責，准予回復原狀。
例3：自己忘記——可歸責，不得回復
  • 丙因工作忙碌，忘記訴願期間（30日）。
  • 至第35日始想起，向機關申請回復原狀，主張「忙碌」為不可歸責事由。
  • → 不符合第50條第1項。「忙碌、忘記」屬可歸責於申請人（應自設提醒、委任代理人）。 機關應駁回回復原狀之申請。
例4：法定期間少於10日——回復期間相等
  • 法規規定申請補正期間僅「5日」。丁因地震（天災）無法於5日內補正，地震後第3日補正。
  • 丁於地震後第4日申請回復原狀（因原期間5日，回復期間亦為5日，未逾期）。
  • → 符合第50條第1項後段。回復期間為5日（相等之日數）。
例5：未同時補行行為——違反第二項
  • 戊因颱風錯過訴願期間。
  • 原因消滅後第3日，僅向機關申請回復原狀，但未同時提出訴願書（主張「先回復，再補訴願」）。
  • → 違反第50條第2項。機關得駁回回復原狀之申請（或要求限期補正訴願書）。
例6：遲誤逾一年——不得回復
  • 己之訴願期間於112年3月1日屆滿。
  • 己因重病住院，至113年3月15日始申請回復原狀（距屆滿日已逾一年）。
  • → 適用第50條第3項。不得申請回復原狀（已逾一年）。訴願逾期確定。

第51條 處理期間
  1. 「行政機關對於人民依法規之申請，除法規另有規定外，應按各事項類別，訂定處理期間公告之。」
  2. 「未依前項規定訂定處理期間者，其處理期間為二個月。」
  3. 「行政機關未能於前二項所定期間內處理終結者，得於原處理期間之限度內延長之，但以一次為限。」
  4. 「前項情形，應於原處理期間屆滿前，將延長之事由通知申請人。」
  5. 「行政機關因天災或其他不可歸責之事由，致事務之處理遭受阻礙時，於該項事由終止前，停止處理期間之進行。」
這一條是關於？
  • 這一條是「政府辦案要多久」條款——當你依法向政府提出申請（例如申請執照、補助），政府必須在一定的時間內處理完畢。
    • 原則上政府要先自行公告「各類案件的處理期間」。
      • 例如建照審查30天、補助審查45天。
    • 如果政府沒有公告，那麼法定的處理期間就是「兩個月」。
    • 如果政府沒辦法在期限內辦完，可以延長一次。
      • 但延長的時間「不能超過原來的期限」（例如原2個月，最多再延2個月）
      • 而且要在原期限屆滿前「通知你」延長的理由。
    • 如果因為天災或其他不可歸責的事由（例如颱風停班），導致政府無法處理，那段時間可以「暫停計算」，不計入處理期間。
  • 簡單說：
    • 政府收件後必須在公告期限（或2個月）內辦完；
    • 辦不完可延長一次（不能超過原期限），但要提前通知你；
    • 天災等不可抗力期間暫停計算。
這一條的核心
  • 本條是行政程序法關於「行政機關處理期間」的規定，旨在課予行政機關「迅速處理人民申請」的義務，避免行政怠惰。
  • 本條五項的架構：
    • 第一項：公告處理期間義務——機關應按事項類別，訂定處理期間並公告。
    • 第二項：備位期間（二個月）——若機關未公告，則法定處理期間為「二個月」。
    • 第三項：延長（一次為限）——若無法於期間內辦完，得延長一次，但延長時間不得超過原期間。
    • 第四項：延長之通知義務——應於原期間屆滿「前」通知申請人，並說明理由。
    • 第五項：不可抗力之停止——因天災等不可歸責事由，處理期間「停止」進行。
  • 本條的立法精神：
    • 保障人民「迅速獲得決定」的權利：避免申請案被無限拖延。
    • 提升行政效能：透過法定期限之壓力，促使機關積極處理。
    • 程序透明：要求公告處理期間、延長時通知理由，使人民知悉進度。
    • 例外彈性：允許延長（但限制一次）及不可抗力停止，兼顧實務需求。
條文拆解
第一項（公告處理期間）
  • 「行政機關對於人民依法規之申請」：只要你依法有權向政府申請某件事。
    • 人民依法規之申請：與第49條、第50條之「基於法規之申請」同義，指人民有法律或法規命令依據之申請權（如申請執照、補助、許可）。
      • 不包括陳情、檢舉。
  • 「除法規另有規定外」：如果其他法律已經規定要多久辦完，就依那個法律。
  • 「應按各事項類別，訂定處理期間公告之」：政府要自己先公告「每種案件需要幾天」。
    • 應：強制義務。
    • 按各事項類別：不同類型之申請（如建照、營利登記、補助）得訂定不同期間（例如建照30天、補助45天）。
    • 訂定處理期間：機關自行訂定合理之期間（不得過長）。若過長，人民得請求縮短（依一般法律原則）。
    • 公告之：應刊登於政府公報、機關網站、佈告欄等，使人民知悉。未公告者，視同未訂定（適用第二項2個月）。
第二項（備位期間——二個月）
  • 「未依前項規定訂定處理期間者，其處理期間為二個月」：如果政府沒有公告，就一律以「兩個月」為準。
    • 未依前項規定訂定：機關完全未公告，或公告內容不明確（如「視案件複雜度而定」未給具體天數），或公告未生效。
    • 其處理期間為二個月：法定備位期間為「二個月」（60天，日曆日？實務多以「日」計算，第48條）。
    • 注意：若法規另有規定（但機關未公告），仍應依法規（不得逕用2個月）。本項僅適用於「無法規規定、機關也未公告」之情形。
第三項（延長一次為限）
  • 「行政機關未能於前二項所定期間內處理終結者」 ：如果政府沒能在期限內辦完。
    • 前二項所定期間：第一項公告之期間，或第二項之2個月。
    • 處理終結：作成准駁之決定（如核發許可、駁回申請），並送達申請人（或通知）。單純內部簽核未送達，不算終結。
    • 注意：若法規另有規定（但機關未公告），仍應依法規（不得逕用2個月）。本項僅適用於「無法規規定、機關也未公告」之情形。
  • 「得於原處理期間之限度內延長之，但以一次為限」 ：可以延長一次，但延長的時間不能超過原來的期限（例如原2個月，最多再延2個月）。
    • 得：機關有裁量權（可以延長，也可以不延長，但若不延長又辦不完，則構成逾期違法）。
    • 於原處理期間之限度內延長：延長之長度「不得超過原處理期間」。例如：
      • 原期間2個月 → 最多再延2個月（總共4個月）。
      • 原期間30天 → 最多再延30天（總共60天）。
    • 但以一次為限：只能延長「一次」，不得多次延長。若延長後仍辦不完，即屬逾期（違法）。
    • 注意：若法規另有規定（但機關未公告），仍應依法規（不得逕用2個月）。本項僅適用於「無法規規定、機關也未公告」之情形。
第四項（延長之通知義務）
  • 「前項情形，應於原處理期間屆滿前，將延長之事由通知申請人」 ：要延長，必須在原期限「到期前」通知你，並說明為什麼要延。
    • 應於原處理期間屆滿前：必須在「原期限到期之前」通知，不得於逾期後才補通知。
    • 將延長之事由通知申請人：應以書面（或得公告？實務建議書面）告知申請人：
      • 延長之決定（准予延長）。
      • 延長之期間（例如「延長30日」）。
      • 延長之事由（例如「案情複雜、須待他機關回覆、須現場勘驗」等具體理由，不得空泛）。
    • 未通知之效果：若機關未通知（或逾期後始通知），該延長不生效力，視同原期間屆滿未辦完 → 構成逾期違法。
第五項（不可抗力之停止）
  • 「行政機關因天災或其他不可歸責之事由，致事務之處理遭受阻礙時」 ：那段時間暫停計算，不計入處理期間。
    • 天災：颱風、地震、洪水等（同第50條）。
    • 其他不可歸責之事由：非可歸責於機關之事由，例如：
      • 大規模停電、網路中斷（非機關過失）。
      • 關鍵證人、鑑定人因不可抗力無法配合。
      • 他機關因不可抗力遲未回覆（協助）。
      • 申請人自己因不可抗力未配合（如未到場勘驗）。
    • 致事務之處理遭受阻礙：客觀上無法進行處理（如機關因颱風停止上班、系統當機無法操作）。
  • 「於該項事由終止前，停止處理期間之進行」：那段時間暫停計算，不計入處理期間。
    • 停止處理期間之進行：期間「暫停計算」，事由消滅後，期間「接續」進行（不是重新起算）。類似民法第139條之時效中斷。
    • 例如：原處理期間為60天，已進行30天，第31天起因颱風停止上班5天，則期間「停止」5天，恢復後剩餘30天（而非從頭算）。
    • 注意：機關應「通知」申請人停止事由及恢復時間（非強制規定，但實務建議通知）。
為什麼要有這條規定？
  • 保障人民「迅速獲得決定」之權利：避免機關無限拖延申請案，使人民權益懸而未決。
  • 提升行政效能：透過法定期限之壓力，促使機關積極處理。
  • 程序透明：要求公告處理期間、延長時通知理由，使人民知悉進度。
  • 兼顧實務需求：允許延長（但限制一次）及不可抗力停止，避免過於僵化。
  • 與訴願法、行政訴訟法之審理期間一致：訴願法第85條（訴願決定期間3個月）、行政訴訟法第107條（審判期間）亦有類似規定。
白話文
  • 第一項：你依法向政府申請東西，政府要事先公告「每一種案件需要幾天」。
  • 第二項：如果政府沒有公告，就一律以「兩個月」為準。
  • 第三項：如果政府沒辦法在期限內辦完，可以延長「一次」，但延長的時間不能超過原來的期限（例如原2個月，最多再延2個月）。
  • 第四項：要延長，必須在原期限「到期前」通知你，並說明為什麼要延。
  • 第五項：如果因為天災（颱風、地震）或其他不是政府錯的原因，導致無法辦案，那段時間「暫停計算」，不計入處理期間。
  • 簡單記：
    • 政府收件後要在公告期限（或2個月）內辦完；
    • 辦不完可延長一次（不超過原期限），但要提前通知你；
    • 天災期間暫停計算。
舉個例子
例1：有公告期限——依公告
  • 某市政府公告「建築執照審查處理期間為30天」。
  • 甲申請建照，機關收件後應於30天內准駁（送達甲）。
  • → 符合第51條第1項。依公告之30天。
例2：未公告——適用2個月
  • 某機關未公告處理期間。乙申請補助，機關應於2個月內准駁。
  • → 符合第51條第2項。備位期間2個月。
例3：延長一次為限
  • 丙申請營業許可，公告處理期間為45天。
  • 機關因案情複雜，無法於45天內辦完，於第40天通知丙「延長45天」，並說明理由。
  • → 符合第51條第3項、第4項。延長一次，期限內通知，合法。
例4：延長超過原期間——違法
  • 丁申請建照，公告期間30天。
  • 機關通知「延長40天」（超過30天）。
  • → 違反第51條第3項。延長不得超過原期間（30天）。該延長無效，機關仍應於30天內辦完（逾期即違法）。
例5：未提前通知——違法
  • 戊申請補助，公告期間2個月。
  • 機關未於2個月內辦完，亦未通知延長，至第70天才通知「延長30天」。
  • → 違反第51條第4項（未於原期間屆滿前通知）。 該延長不生效力，機關已逾期違法。戊得提起課予義務訴願（訴願法第2條）。
例6：不可抗力停止
  • 己申請某許可，處理期間2個月（6月1日至7月31日）。
  • 6月10日至6月15日因颱風來襲，機關停止上班5天。期間停止進行，於6月16日恢復，剩餘期間順延5天（末日變為8月5日）。
  • → 符合第51條第5項。停止期間不計入。
常見爭議案例
案情 法院認定
  • 機關未公告處理期間，亦未於2個月內處理。
  • 申請人提起課予義務訴願。
  • 適用第51條第2項，認定處理期間為2個月 。
  • 機關逾期違法，應速為決定。
  • 機關以「承辦人請假」為由延長，未通知申請人。
  • 承辦人請假屬可歸責於機關（應有職務代理人），不得延長。
  • 且未通知，違反第4項。
  • 機關因颱風停班3天，但已於第2個月內辦完（扣除停班日未逾期）。
  • 申請人主張「應順延3天」。
  • 適用第51條第5項，認定停班期間停止進行，順延合法。
一句話總結
    第51條是「政府辦案期限」條款——
  • 政府要公告處理期間（否則2個月）；
  • 辦不完可延長一次（不超過原期限），但要提前通知你；
  • 天災期間暫停計算。
