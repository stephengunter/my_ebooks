1-5 總則 - 程序之開始

第34條 行政程序之開始
  • 「行政程序之開始，由行政機關依職權定之。但依本法或其他法規之規定有開始行政程序之義務，或當事人已依法規之規定提出申請者，不在此限。」
這一條是關於？
    這一條是「政府何時開始辦案」條款——它告訴我們，
  • 行政程序（例如審查申請案、進行稽查、核發處分）什麼時候「啟動」，原則上由政府自己決定。
  • 但是，
    • 如果法律規定政府「必須」啟動（例如有人檢舉污染，環保局依法必須稽查），
    • 或者人民已經依法提出申請（例如申請建照、補助）
    政府就不能說「我不想辦」，而「必須」開始程序。
    • 簡單說：政府原則上可以自己決定何時開工，但法律規定要辦、或人民依法申請了，就不能不辦。
這一條的核心
  • 本條是確立了行政程序開始的兩個原則：
    • 職權進行原則（又稱職權主義）：行政程序原則上由行政機關「依職權」決定是否開始、何時開始。這是基於行政權的「主動性」與「公共利益維護」的考量。
      • 例如：環保局可以主動排定稽查期程；警察局可以主動臨檢。
    • 申請原則（例外）：當法律（或法規）課予行政機關「開始程序的義務」時，或當事人「依法規提出申請」時，行政機關即「必須」開始程序，不得裁量不作為。
條文拆解
  • 「行政程序之開始」：政府決定要開始處理一件行政業務的那個「起點」。
    • 行政程序：依第2條第1項，指行政機關作成行政處分、締結行政契約、訂定法規命令與行政規則、 確定行政計畫、實施行政指導、處理陳情等行為之程序。
    • 開始：指行政機關「啟動」上述程序的「第一個行為」。例如：
      • 行政處分程序：發出「通知陳述意見書」、「進行稽查」、「分案掛號」。
      • 行政契約程序：發出「締約要約」、「進行協商會議」。
      • 法規命令程序：發布「預告公告」。
      • 行政指導程序：發出「指導通知書」或進行「口頭勸導」。
  • 「由行政機關依職權定之」：政府可以自己決定「什麼時候開工」，不必等人民來催。
    • 依職權：行政機關可「主動」、「自行決定」是否開始程序、何時開始程序，無待人民申請或上級指示。這是行政權主動性的展現。
    • 定之：機關有「裁量權」——可以選擇開始，也可以選擇暫不開始（在不違反法律義務的前提下）。
    • 適用範圍：機關依職權主動發動的程序，例如：
      • 警察局主動實施路檢（職權）。
      • 環保局主動排定工廠稽查（職權）。
      • 稅捐機關主動選案查核（職權）。
      • 行政機關依職權訂定法規命令（第150條以下）。
  • 「但……不在此限」：以下兩種情況，政府不能說「我不想辦」，而「必須辦」。
    • 但：例外條款，當「但書」情形發生時，行政機關「不得」再主張「依職權定之」的裁量權，而是「必須」開始程序。
    • 不在此限：指不受前開「由行政機關依職權定之」的限制，即：機關有開始程序的義務，不得裁量不作為。
  • 但書類型一：「依本法或其他法規之規定有開始行政程序之義務」 ：如果法律規定「政府必須辦」，政府就不能說「我不想辦」。
    • 依本法之規定：行政程序法本身課予機關開始義務的條文。例如：
      • 第17條：機關認無管轄權時，應移送有管轄權機關（移送本身也是一種程序行為，但開始義務源於此）。
      • 第19條：被請求協助機關，若有能力且無拒絕事由，應協助（協助行為開始程序？此較間接）。
      • 第36條：行政機關應依職權調查證據（調查程序開始義務）。
      • 第102條：作成限制或剝奪自由權利之處分前，應給予陳述意見機會（開始陳述意見程序）。
    • 依其他法規之規定：其他法律或法規命令明定行政機關有開始程序的義務。例如：
      • 警察職權行使法第6條：警察於公共場所，若有「合理懷疑」犯罪嫌疑，得開始查證身分程序（非「應」，此為職權；但若法律用「應」，則為義務）。
      • 土壤及地下水污染整治法第7條：主管機關「應」查證污染情形（有開始調查義務）。
      • 家庭暴力防治法第48條：警察人員「應」即時處理家庭暴力案件（有開始處理義務）。
    • 義務的來源：須是「法規」明定（法律或法規命令），行政規則或內部作業要點不足以創設義務。
  • 但書類型二：「或當事人已依法規之規定提出申請者」 ：只要你依法（例如申請建照、補助）提出申請，政府就「必須」開始審查，不能說「我不想辦」。
    • 當事人：依第20條定義之申請人。
    • 依法規之規定提出申請：指人民「基於法律或法規命令的授權」，向行政機關提出「請求作成特定行政行為」的意思表示。例如：
      • 依建築法申請建築執照。
      • 依專利法申請專利。
      • 依社會救助法申請低收入戶補助。
      • 依戶籍法申請戶籍謄本。
    • 不是「依法規申請」的情形（不觸發本款義務）：
      • 單純陳情（第168條以下）：陳情不是「依法規申請」，機關得依陳情程序處理，不當然有開始義務（但仍應處理，只是程序不同）。
      • 檢舉（若檢舉法律未賦予檢舉人「申請權」，僅為「事實通知」，不屬本款）。
      • 無法律依據的請求（如「請求政府送我100萬」）。
    • 當事人已提出申請：申請到達行政機關時，機關即「必須」開始程序，不得以「裁量不開始」拒絕。
為什麼要有這條規定？
  • 確立職權進行主義：行政程序原則上由行政機關主動發動，以維護公共利益（如環保稽查、稅務查核），無待人民申請。
  • 保障人民的「程序請求權」：當法律賦予人民「申請權」時（如申請執照、補助），行政機關不得以「我不想辦」為由拒絕開始程序，否則形同剝奪人民的實體權利。
  • 課予行政機關法定義務：當法律明定行政機關「應」開始程序（如知悉犯罪應調查、發現污染應處理），機關不得怠惰，否則構成「怠於執行職務」。
  • 避免裁量濫用：本條的「但書」限制了行政機關的裁量權，防止機關以「職權定之」為名，行「應辦不辦」之實。
  • 與程序開始後的調查義務銜接：程序一旦開始，行政機關即負有第36條以下之「職權調查義務」，不得消極不作為。
白話文
  • 政府要開始處理一件行政業務（例如審查申請、進行稽查），原則上可以自己決定「什麼時候開始」。
  • 但是，如果有以下兩種情況，政府就不能自己決定，而「必須」開始：
    • 法律規定政府必須辦（例如：接到家暴通報，警察必須處理）。
    • 人民已經依法提出申請（例如：你依法申請建照、補助，政府就要開始審查）。
  • 簡單記：原則政府自己決定，例外法律規定或人民申請時，政府不得拒絕開工。
舉個例子
例1：依職權開始——合法
  • 環保局依其年度稽查計畫，主動派員至某工廠進行廢水排放稽查，即使無人檢舉。
  • → 符合第34條本文（依職權定之）。環保局有裁量權決定何時稽查，程序合法開始。
例2：有開始義務——法令規定
  • 《家庭暴力防治法》第48條規定：「警察人員處理家庭暴力案件，應即時調查……」。
  • 警察局接獲家暴通報後，不得以「人力不足」或「依職權定之」為由拖延。
  • → 適用第34條但書（其他法規規定有開始義務）。警察局必須立即開始程序。
例3：有開始義務——當事人申請
  • 甲依《建築法》規定，檢具相關文件向市政府申請建築執照。
  • 市政府收件後，不得以「我們最近案件太多，先不審」為由，拒絕開始程序。
  • → 適用第34條但書（當事人依法規申請）。市政府必須開始審查程序（例如分案、通知補正、排定會勘）。
例4：非屬「依法規申請」——不觸發開始義務
  • 乙以陳情書向市政府反映「隔壁鄰居違建」，未依據任何法律授予的「申請權」（陳情權非本條之申請權）。
  • 市政府收件後，得選擇依陳情程序處理（第168條以下），不一定須啟動「違建拆除程序」 （拆除程序通常依職權或檢舉後發動，但檢舉不當然有開始義務）。
  • → 不適用第34條但書（非依法規申請）。市政府無「必須開始拆除程序」之義務，得依陳情程序處理或依職權裁量是否稽查。
例5：申請不合法定程式——機關得命補正
  • 丙申請營業登記，但未附必要文件。 經濟部收件後，應先命丙補正（程序已開始？補正通知本身就是程序開始的一部分）。
  • 若丙逾期未補正，機關得駁回申請，但不得以「未開始程序」為由直接退件。
  • → 適用第34條但書（申請已提出）。機關必須開始程序（至少進行形式審查、通知補正）。 不能說「因為你不完整，所以我根本不理你」。
常見爭議案例
案情 法院認定
  • 人民依《政府資訊公開法》申請閱覽卷宗，機關以「申請人未檢附利害關係證明」為由，拒絕開始程序（退件）。
    違反第34條但書：
  • 機關應先受理（開始程序），審查後若認申請不符要件，應以「駁回處分」為之，
  • 不得以「不開始程序」方式處理。
  • 檢舉人依《水污染防治法》檢舉工廠排放廢水。
  • 環保局以「檢舉非申請」為由，不啟動稽查程序。
  • 《水污染防治法》保護「當地居民」之健康權，
  • 檢舉人為當地居民，檢舉屬「依法規申請」，
  • 環保局應開始程序。判決環保局應開始稽查。
  • 機關對於人民申請，以「申請書未使用機關指定格式」為由，直接退件未掛號。
違反第34條但書：
    機關應先收件（開始程序），再通知補正；直接退件。
一句話總結
    第34條是「開工條款」——
  • 政府原則上可以自己決定何時開始辦案，
  • 但如果法律規定必須辦、或人民依法提出申請了，政府就必須開工，不能說「我不想辦」。
第35條 申請之方式與程式
  • 「當事人依法向行政機關提出申請者，除法規另有規定外，得以書面或言詞為之。以言詞為申請者，受理之行政機關應作成紀錄，經向申請人朗讀或使閱覽，確認其內容無誤後由其簽名或蓋章。」
這一條是關於？
    這一條是「如何向政府遞件」條款——當你依法要向政府申請某件事（例如申請執照、補助、許可），
  • 除非其他法律有特別規定，否則你可以用「書面」（寫信、填表）或「口頭」（直接去政府說）的方式提出申請。
  • 如果你是口頭申請，政府必須幫你把你說的話做成「紀錄」，唸給你聽或讓你看，確認沒錯後，由你簽名或蓋章。
  • 簡單說：申請可以寫信也可以用講的；用講的政府要幫你寫下來，讓你確認簽名。
這一條的核心
  • 本條規範「申請」這個程序行為的「方式」與「程式」。確立了兩個原則：
    • 方式自由原則：申請原則上得以「書面」或「言詞」為之，不強制要求書面。這是為了便民，避免不懂法律或無法書寫的民眾被排除在程序之外。
    • 言詞申請之要式性：為確保法律明確性與證據保全，言詞申請時，受理機關有義務「作成紀錄」，並經申請人確認、簽名或蓋章。
  • 「除法規另有規定外」是重要的但書：
    • 如果其他法律或法規命令「明文規定」必須以書面為之（例如專利法規定申請專利應檢具說明書及圖式）， 則應從其規定，不得以言詞為之。
條文拆解
  • 「當事人依法向行政機關提出申請者」 ：當你依法有權向政府申請某件事的時候。
    • 當事人：依第20條定義之申請人（含其代理人，第24條）。
    • 依法：依「法律或法規命令」之授權，享有申請權（與第34條但書之「依法規之規定提出申請」同義）。
    • 向行政機關提出申請：將申請的意思表示送達至有管轄權之行政機關（或其指定之收件單位）。
  • 「除法規另有規定外」 ：除非其他法律說「一定要書面」，否則你可以用講的。
    • 除法規另有規定：如果其他法律或法規命令「明文規定」必須以「書面」為之（或禁止以言詞為之），則優先適用該規定，不得以言詞申請。
    • 法規：指法律或法規命令。行政規則（如內部作業要點）不得限制言詞申請。
    • 常見「應以書面為之」的規定：
      • 《專利法》第25條：申請專利應備申請書、說明書、圖式等（書面）。
      • 《商標法》第19條：申請商標註冊應備申請書（書面）。
      • 《建築法》第30條：申請建築執照應備申請書、設計圖等（書面）。
    • 若法規未明文規定：則回歸本條，得以言詞申請。
  • 「得以書面或言詞為之」 ：你可以寫信/填表，也可以直接跑去（或打電話）跟政府用講的。
    • 得以……為之：當事人有選擇權（可以選書面，也可以選言詞）。機關不得強制要求「僅能書面」或「僅能言詞」。
    • 書面：包括紙本文件（申請書、信函、傳真）以及經機關認可之電子文件（如電子郵件、線上申辦系統）。書面應載明申請人、申請事項、事實、理由（若有法定格式，從其格式）。
    • 言詞：口頭陳述。包括：
      • 親自到機關當面陳述。
      • 電話口頭陳述（實務上較少用於正式申請，因紀錄困難；但法未明文禁止）。
      • 視訊、語音留言（實務上需機關同意）。
  • 「以言詞為申請者，受理之行政機關應作成紀錄」 ：你用講的，政府要幫你「寫成筆錄」。
    • 應作成紀錄：機關「必須」（應）製作書面紀錄，不得僅憑記憶或錄音而未轉成文字。
    • 紀錄內容：至少應記載：
      • 申請人姓名、身分證字號（或統一編號）、地址、聯絡方式。
      • 申請之事項（想要政府做什麼）。
      • 申請之事實與理由（為什麼可以申請、依據何法規）。
      • 申請之年月日時。
      • 受理機關、紀錄人（承辦人）姓名。
    • 紀錄形式：紙本或電子檔均可。
  • 「經向申請人朗讀或使閱覽，確認其內容無誤後由其簽名或蓋章」 ：政府寫完後，要唸給你聽或讓你看，你確認沒錯後，要簽名或蓋章。
    • 經向申請人朗讀或使閱覽：機關完成紀錄後，應讓申請人「聽一遍」（若申請人在場且能聽）或「看一遍」（若申請人在場且能看）。若申請人為聽障、視障，應以適當方式（如手語翻譯、點字）使其確認。
    • 確認其內容無誤：申請人應確認紀錄與其口頭陳述一致。若有錯誤，應即時更正。
    • 由其簽名或蓋章：
      • 申請人確認無誤後，應在紀錄上「簽名」或「蓋章」。若申請人無法簽名（如不識字、肢體障礙），得以「按指印」代之，並由紀錄人載明其事由。
      • 若申請人拒絕簽名或蓋章，機關應記明其事由（該申請是否仍有效？實務上，若申請人拒絕簽名，機關得不受理該言詞申請，或要求改以書面提出）。
    • 立法目的：確保申請內容的真實性與明確性，避免事後爭執「我沒有這樣講」、「政府亂記」。
為什麼要有這條規定？
  • 落實便民原則：降低申請門檻，使不諳文字、行動不便、資訊能力弱勢之民眾仍能有效行使申請權。
  • 確保程序明確性：言詞申請容易產生「有講沒講」、「講了什麼」的爭議。本條強制機關作成紀錄並經申請人確認簽名，以確保申請內容明確、可稽核。
  • 保護申請人權益：避免機關「聽錯」、「記錯」或「刻意扭曲」申請人陳述，導致申請案被誤駁。
  • 兼顧行政效能：對於大量、簡單、例行性的申請（如臨櫃申請戶籍謄本），言詞申請可加速處理；但透過紀錄與簽名，仍不失慎重。
  • 與其他法規調和：「除法規另有規定外」的但書，尊重其他法規（如專利、商標）對書面申請之特別要求，避免衝突。
白話文
  • 你要依法向政府申請東西（例如申請補助、執照）， 除非其他法律規定「一定要寫書面」（例如申請專利），否則你可以用「寫信」或「用講的」兩種方式。
  • 如果你是用「講的」（口頭申請），政府必須幫你把你說的話「寫成紀錄」， 然後唸給你聽或讓你看，你確認沒錯之後，在上面簽名或蓋章。
  • 簡單記：申請可寫可講；用講的，政府要幫你筆錄，你確認簽名才算數。
舉個例子
例1：書面申請——合法
  • 甲要申請建築執照，依《建築法》第30條規定， 檢具申請書、設計圖、地籍圖等書面文件，郵寄掛號至市政府工務局。
  • → 符合第35條本文。以書面為之，合法。
例2：言詞申請——合法
  • 乙（70歲、不識字）要申請中低收入戶老人生活津貼， 親自到區公所社會課，以口頭方式告知承辦人其家庭狀況、收入、財產。
  • → 符合第35條本文（言詞申請）。承辦人應作成紀錄，朗讀給乙聽，乙確認後簽名（或蓋章、按指印）。申請有效。
例3：言詞申請——機關應作成紀錄而未作
  • 丙以電話向環保局口頭申請「補發某稽查報告」， 承辦人口頭答應「好，我幫你查」，但未作成任何紀錄，也未要求丙簽名。
  • 嗣後承辦人忘記處理，丙追問時無紀錄可稽。
  • → 違反第35條後段。機關應作成紀錄而未作，程序違法。丙得請求補正或申訴。
例4：法規另有規定——不得言詞申請
  • 丁要申請發明專利，依《專利法》第25條規定，申請應備申請書、說明書、圖式等（書面）。
  • 丁僅以口頭向智慧局告知發明內容，未提書面文件。
  • → 適用第35條但書（除法規另有規定外）。《專利法》已規定須書面，丁不得以言詞為之。 智慧局應告知丁改以書面提出。
常見爭議案例
案情 法院認定
  • 申請人以言詞向區公所申請低收入戶補助，承辦人作成紀錄後，未經申請人簽名即歸檔。
  • 嗣後申請人否認曾申請（主張「我沒申請過」），區公所因無簽名紀錄，無法證明申請存在。
    違反第35條後段：
  • 該申請視為不存在（或區公所應負舉證責任）。區公所敗訴。
  • 申請人以電話向勞工局申請勞資爭議調解，承辦人以「電話申請非法定方式」為由拒絕。
  • 法規（勞資爭議處理法）未明文規定「須書面」。
  • 依行政程序法第35條，得以言詞為之（電話屬言詞之一種），機關不得拒絕。但申請人應事後補簽名紀錄。
  • 判決勞工局應受理。
  • 申請人言詞申請後，於紀錄簽名。
  • 事後申請人主張「紀錄內容與其陳述不符」，請求更正。
  • 申請人簽名前有機會閱覽/朗讀確認，簽名後推定為真實。
  • 申請人應舉證證明機關故意記錯（如錄音、證人），否則不得任意推翻。
一句話總結
    第35條是「怎麼遞件」條款——
  • 申請可以寫書面，也可以用講的（除非其他法律規定一定要書面）；
  • 用講的，政府要幫你寫成筆錄，讓你確認簽名，才算完成申請。
