1-7 總則 - 資訊公開

第46條 卷宗閱覽權
  1. 「當事人或利害關係人得向行政機關申請閱覽、抄寫、複印或攝影有關資料或卷宗。但以主張或維護其法律上利益有必要者為限。」
  2. 「行政機關對前項之申請，除有下列情形之一者外，不得拒絕︰」
    • 一、行政決定前之擬稿或其他準備作業文件。
    • 二、涉及國防、軍事、外交及一般公務機密，依法規規定有保密之必要者。
    • 三、涉及個人隱私、職業秘密、營業秘密，依法規規定有保密之必要者。
    • 四、有侵害第三人權利之虞者。
    • 五、有嚴重妨礙有關社會治安、公共安全或其他公共利益之職務正常進行之虞者。
  3. 「前項第二款及第三款無保密必要之部分，仍應准許閱覽。」
  4. 「當事人就第一項資料或卷宗內容關於自身之記載有錯誤者，得檢具事實證明，請求相關機關更正。」
這一條是關於？
  • 這一條是「人民有權看政府檔案」條款——當事人（例如申請人、被處罰人）或利害關係人（例如權益受影響的第三人）， 如果為了「主張或維護自己的法律上利益」而有必要時：
    • 可以向行政機關申請「閱覽、抄寫、複印或攝影」相關的資料或卷宗（也就是政府手上跟這個案件有關的文件）。
    • 政府「原則上」不能拒絕。只有五種例外情況（例如：內部擬稿、涉及國家機密、個人隱私、營業秘密、妨害治安等）才可以拒絕。
    • 而且，即使是機密文件，如果可以分割（無保密必要的部分），還是要讓人看。
    • 最後，如果卷宗裡關於「當事人自己」的記載有錯誤，當事人可以請求更正。
  • 簡單說：你有權看政府手上跟你的案子有關的文件，只有少數例外不能看；看到自己的資料有誤，可以請求更正。
這一條的核心
  • 本條賦予「特定當事人」及「利害關係人」在「個案行政程序」中，閱覽機關所持有之相關卷宗的權利。
  • 本條的幾個核心概念：
    • 主體：當事人（第20條）及「利害關係人」（未具當事人地位，但權益受影響之第三人）。
    • 目的限制：須以「主張或維護其法律上利益有必要者」為限（不得濫用）。
    • 標的：「有關資料或卷宗」——機關因該行政程序所蒐集、製作、持有之文書、照片、電磁紀錄等。
    • 原則准許、例外拒絕（五款）：類似政府資訊公開法之豁免公開事由，但範圍略有不同。
    • 分離原則（第三項）：即使文件有機密部分，若可分割，無保密必要之部分仍應准許閱覽。
    • 更正請求權（第四項）：當事人對「關於自身之記載」有錯誤者，得請求更正（類似個資法之更正權）。
  • 本條與《政府資訊公開法》的區別：
    行政程序法第46條（卷宗閱覽） 政府資訊公開法（一般公開）
    申請人 「當事人」或「利害關係人」（限於個案程序相關者） 任何人（不限當事人）
    目的 須為「主張或維護法律上利益有必要」 無須特定目的（知的權利）
    標的 該行政程序之「有關資料或卷宗」 政府機關「持有或保管」之所有資訊（含非個案者）
    時點 行政程序進行中（或程序終結後？） 隨時
    法律依據 行政程序法 政府資訊公開法
條文拆解
第一項（申請權人、標的、目的限制）
  • 「當事人或利害關係人得向行政機關申請閱覽、抄寫、複印或攝影有關資料或卷宗」 ：案件的當事人（或利害關係人），可以跟政府申請「看、抄、印、拍」跟這個案件有關的文件。
    • 當事人：依第20條定義（申請人、處分相對人、契約相對人、指導相對人、陳情人、參加人）。
    • 利害關係人：非當事人，但權利或法律上利益受該行政程序影響之第三人。
      • 如處分相對人之配偶、相鄰地主、競爭同業
      • 其範圍與第23條之「第三人」相同。
    • 得向行政機關申請：向「持有該資料或卷宗之行政機關」提出申請（書面為原則，言詞亦可，但建議書面）。
    • 閱覽、抄寫、複印或攝影：
      • 閱覽：當場翻閱、檢視。
      • 抄寫：手抄筆記。
    • 有關資料或卷宗：指「與該行政程序有關」之全部資料，包括：
      • 申請書、陳情書、陳述意見紀錄。
      • 調查筆錄、勘驗筆錄、鑑定報告。
      • 公文、簽呈（但「行政決定前之擬稿」有例外，見第2項第1款）。
      • 照片、錄音、錄影、電磁紀錄。
      • 其他機關函復之資料（如回函、附件）。
  • 「但以主張或維護其法律上利益有必要者為限」 ：你必須是為了維護自己的權益（例如準備打官司），而且有必要，才能申請。不能純粹好奇。
    • 但：目的限制。申請人必須說明「為什麼要看」——是為了「主張或維護其法律上利益」，且「有必要」。
    • 法律上利益：與第23條之「法律上利益」同義（非單純反射利益）。例如：
      • 為了準備答辯（被處分人）。
      • 為了核對調查結果是否正確（申請人）。
      • 為了準備訴願或行政訴訟。
      • 為了確認機關有無違法。
    • 「有必要」之判斷：機關得審查。若申請人已可從其他管道取得相同資訊、或顯與其權益無關，機關得拒絕（但應附理由）。
第二項（拒絕事由——五款例外）
  • 「行政機關對前項之申請，除有下列情形之一者外，不得拒絕」 ：原則上應准許。只有以下五款情形，機關「得」（或有時「應」）拒絕。
  • 第一款：「行政決定前之擬稿或其他準備作業文件」 ：政府內部還沒定案的草案、簽呈、草稿，可以不給看。
    • 行政決定前之擬稿：承辦人草擬之「簽呈」、「稿」、「初稿」、「內部意見」。
      • 這是「內部決策過程」之保護（避免洩漏幕僚意見，導致決策者不敢暢所欲言）。
    • 其他準備作業文件：如內部會議紀錄（尚未核定）、參考資料、幕僚單位之評估報告、他機關會辦意見（尚未決行）。
    • 不包括：已核定之正式公文（非「準備作業」）、外部專家之鑑定報告（原則應准許）。
    • 注意：若該準備文件已不具「決策前」性質（如已核定、已送達當事人），則不得拒絕。
  • 第二款：「涉及國防、軍事、外交及一般公務機密，依法規規定有保密之必要者」 ：涉及國家機密、國防外交、或依法應保密的公務秘密，可以不給看。
    • 涉及國防、軍事、外交：高度政治性、國家安全相關之機密。
    • 一般公務機密：其他依法規應保密之公務秘密（如《國家機密保護法》、《文書處理手冊》之「密」件）。
    • 依法規規定有保密之必要：須有「法律或法規命令」之明文依據（不能僅憑機關主觀認定）。
      • 例如：《國家機密保護法》核定之機密；《個人資料保護法》之特種個資。
  • 第三款：「涉及個人隱私、職業秘密、營業秘密，依法規規定有保密之必要者」 ：涉及他人隱私、營業秘密、職業秘密，且依法應保密的，可以不給看。
    • 個人隱私：如病歷、性生活、家庭背景、財務狀況（非與案情相關部分）。
    • 職業秘密：如律師、醫師、會計師因業務知悉之秘密。
    • 營業秘密：如生產配方、客戶名單、成本結構（《營業秘密法》第2條）。
    • 依法規規定有保密之必要：須有法律或法規命令依據（如《個人資料保護法》、《營業秘密法》）。
    • 注意：若當事人申請閱覽「自己」的隱私資料（如自己的病歷），原則應准許（因無侵害他人隱私之虞）。
  • 第四款：「有侵害第三人權利之虞者」 ：如果讓你看了，會害到別人（例如洩漏檢舉人身分），可以不給看。
    • 有侵害第三人權利之虞：若提供閱覽，可能導致第三人（非申請人）之權利受損（如名譽權、隱私權、財產權、智慧財產權）。
    • 例如：卷宗內含檢舉人之姓名住址（若公開可能遭報復）；含第三人營業秘密（如供應商報價）；含第三人不欲公開之個人資料。
    • 注意：若已遮蔽（去識別化）可避免侵害，機關應採遮蔽方式提供，不得全部拒絕。
  • 第五款：「有嚴重妨礙有關社會治安、公共安全或其他公共利益之職務正常進行之虞者」 ：如果讓你看，會嚴重影響警察辦案、政府稽查等公共利益，可以不給看。
    • 嚴重妨礙：須達到「嚴重」程度，非輕微影響。
    • 社會治安、公共安全：如犯罪偵查（尚未偵結）、反恐措施、維安部署。
    • 其他公共利益之職務正常進行：如稅務稽查（若洩漏可能導致逃漏稅）、環保稽查（若預告可能湮滅證據）。
    • 注意：須有「具體事證」足認有妨礙之虞，不得空言。
第三項（分離原則）
  • 「前項第二款及第三款無保密必要之部分，仍應准許閱覽」 ：即使是機密文件，如果可以「遮掉秘密部分」後給你看，政府還是要給你看（不能全部拒絕）。
    • 前項第二款及第三款：指涉及國家機密、公務機密、個人隱私、職業秘密、營業秘密之文件。
    • 無保密必要之部分：若該文件「部分」內容應保密、「部分」無保密必要（例如：將姓名、地址遮蔽後，其餘事實可公開），機關應將「無保密必要之部分」提供閱覽（例如：遮蔽後影印）。
第四項（更正請求權）
  • 「當事人就第一項資料或卷宗內容關於自身之記載有錯誤者，得檢具事實證明，請求相關機關更正」 ：如果你在政府檔案裡發現關於你的資料寫錯了（例如名字打錯、金額寫錯），你可以拿證明要求政府更正。
    • 當事人：限「當事人」（不含「利害關係人」，因利害關係人非記載對象）。
    • 關於自身之記載：限於「記載當事人自己」的部分（如姓名、身分證字號、地址、事實描述中涉及當事人者）。
    • 有錯誤者：事實錯誤（如日期錯誤、金額誤植、身分資料錯誤），不包括「價值判斷」或「法律評價」之不同意（如「你覺得不應該罰」非本項更正範圍）。
    • 得檢具事實證明：申請人須提出「證明」（如戶籍謄本、契約書、照片），證明記載錯誤。
    • 請求相關機關更正：機關應於審查後，若確屬錯誤，應予更正（並通知已知之利害關係人）。若拒絕更正，當事人得提起訴願、行政訴訟。
為什麼要有這條規定？
  • 保障當事人之「知之權利」與防禦權：當事人有權知悉機關所持有之與其權益相關之資訊，以便有效陳述意見、提出證據、準備救濟。
  • 提升行政透明度與公正性：公開卷宗使行政決定受到檢視，減少黑箱作業、偏頗、恣意之可能。
  • 平衡「資訊公開」與「機密保護」：透過五款例外及分離原則，兼顧國家機密、個人隱私、營業秘密、行政決策品質。
  • 落實「當事人自己資訊之正確性」：第四項賦予更正請求權，確保檔案正確，避免因錯誤記載損害當事人權益。
  • 與政府資訊公開法相輔相成：本條為「個案程序」之閱覽權，政府資訊公開法為「一般性」之公開請求權，兩者併行不悖。
白話文
  • 第一項：如果你是案件當事人（或利害關係人），為了維護自己的權益（例如準備打官司），可以跟政府申請「看、抄、印、拍」跟這個案件有關的文件。
  • 第二項：政府「原則上」要給你，只有以下五種情況可以拒絕：
    1. 政府內部的草稿、未定案的文件。
    2. 涉及國家機密、國防外交、依法應保密的公務秘密。
    3. 涉及他人隱私、營業秘密、職業秘密，且依法應保密。
    4. 給你看了會害到第三人（例如洩漏檢舉人個資）。
    5. 給你看了會嚴重妨害社會治安、公共安全、或政府正常辦案。
  • 第三項：即使是機密文件，如果可以「遮掉機密部分」，剩下能公開的部分還是要給你。
  • 第四項：如果你在檔案裡發現關於你自己的資料寫錯了（例如名字打錯），你可以拿證明要求政府更正。
舉個例子
例1：合法申請閱覽
  • 甲因違規停車被開罰單，甲向交通裁決所申請閱覽「警方取締時所拍攝之照片」及「舉發通知單」，以確認是否有違規事實。
  • → 符合第46條第1項。甲為當事人，為維護自身權益（答辯），有必要閱覽。機關應准許。
例2：拒絕閱覽——行政決定前之擬稿
  • 乙申請建照，市政府內部承辦人簽擬「擬駁回」之簽呈，尚未決行。乙申請閱覽該簽呈。
  • → 適用第46條第2項第1款。機關得拒絕（屬行政決定前之擬稿）。乙可於處分作成後，閱覽「已核定」之公文（非擬稿）。
例3：拒絕閱覽——涉及營業秘密
  • 丙檢舉某工廠排放廢水，環保局調查時取得該工廠之「生產配方」（營業秘密）。丙申請閱覽該配方。
  • → 適用第46條第2項第3款。機關得拒絕（涉及營業秘密，依法有保密必要）。 若可遮蔽配方數字（分離原則），其餘部分（如生產流程）仍應准許。
例4：分離原則適用
  • 丁申請閱覽某卷宗，內含一份文件，其中一段記載「檢舉人：王○○，住址：台北市○○路○號」，另一段為「違規事實：排放廢水」。
  • 機關認為檢舉人個資應保密，但違規事實無保密必要。機關將「檢舉人姓名、地址」塗黑後，提供塗黑版影本予丁閱覽。
  • → 符合第46條第3項。分離原則，無保密必要部分仍應准許。
例5：更正錯誤記載
  • 戊收到處分書，發現處分書將其姓名誤載為「戊OO」（少一個字），身分證字號亦誤植。
  • 戊檢附身分證影本，向機關申請更正。
  • → 符合第46條第4項。機關應予更正，並重新送達正確處分書。
例6：拒絕更正——非「錯誤」
  • 己認為處分書記載之「違規事實」與其認知不符（己主張「當時未超速」，但警方認定有超速）。己申請更正為「未超速」。
  • → 不符合第46條第4項（此為事實認定之爭議，非「記載錯誤」）。己應循訴願、行政訴訟救濟，不得以更正方式處理。
常見爭議案例
案情 法院認定
  • 機關以「該文件為行政決定前之擬稿」（第2項第1款）拒絕閱覽。
  • 法院審查後發現，該文件為「已決行並送達之正式公文」，非擬稿。
  • 認定拒絕違法，應准許閱覽。
  • 申請人為利害關係人（相鄰地主），申請閱覽建照審查卷宗。
  • 機關以其「非當事人」拒絕。
  • 相鄰地主之日照權、景觀權受法律保護，屬利害關係人。
  • 應准許閱覽（但仍須審查有無拒絕事由）。
  • 機關拒絕閱覽，理由僅寫「涉及公務機密」，未指出「依法規」之具體條文。
  • 拒絕違法（理由不備），撤銷拒絕決定，命機關重為處分。
一句話總結
    第46條是「人民有權看政府檔案」條款——
  • 當事人或利害關係人為維護權益，可申請看、抄、印、拍相關卷宗；
  • 政府只有五種例外（內部草稿、國家機密、他人隱私/營業秘密、會害到第三人、會妨害治安）才能拒絕；
  • 即使是機密，可遮蔽後提供；
  • 看到自己的資料有錯，可要求更正。
第47條 程序外接觸之禁止與公開
  1. 「公務員在行政程序中，除基於職務上之必要外，不得與當事人或代表其利益之人為行政程序外之接觸。」
  2. 「公務員與當事人或代表其利益之人為行政程序外之接觸時，應將所有往來之書面文件附卷，並對其他當事人公開。」
  3. 「前項接觸非以書面為之者，應作成書面紀錄，載明接觸對象、時間、地點及內容。」
這一條是關於？
  • 這一條是「禁止私下溝通」條款——
    • 公務員在處理行政案件的過程中，除非是「職務上必要」（例如：通知開會、依法送達、公開聽證），
    • 否則不得與當事人（或其代理人、利益代表）有「行政程序外」的接觸（例如：私下吃飯、打電話、傳LINE）。
    • 如果不小心（或必要）有了程序外接觸，公務員必須把所有的書面文件（如信件、傳真）附到卷宗裡，並對「其他當事人」公開。
    • 如果不是書面（例如是電話或當面談話），就要自己做成書面紀錄（寫下跟誰、何時、何地、談了什麼），附卷並公開。
  • 簡單說：公務員不能跟當事人私下來往；如果不得已有了，必須全部記錄公開，讓對方也知道。
這一條的核心
  • 本條是行政程序法為了確保「行政程序公正性」與「武器平等原則」的重要規定，通常被稱為「禁止片面接觸」（或「程序外接觸之禁止」）條款。
  • 本條的立法背景：在行政程序中，若承辦公務員與某一方當事人（例如申請人、相對人）私下接觸、溝通、交換意見， 而未讓其他當事人（尤其是利益相反的他方）知悉，將造成以下弊端：
    • 資訊不對等：一方當事人獲得了額外的說明機會、提前知悉決策方向，而另一方被蒙在鼓裡。
    • 程序不公正：公務員可能因私下接觸而產生偏頗，或感受到人情壓力。
    • 違反武器平等：雙方當事人應有平等的陳述意見、接觸決策者之機會。私下接觸破壞了此一平衡。
    • 黑箱作業之虞：人民會懷疑「是不是關說」、「是不是利益輸送」。
    本條因此嚴格限制程序外接觸，並透過「公開」機制（附卷、對他方公開、製作紀錄）來達成監督與透明化。
  • 本條的三個層次：
    • 第一項：原則禁止——除「職務上必要」外，不得為程序外接觸。
      • 所謂「職務上必要」指依法必須為之的行為（如通知送達、安排聽證、依申請閱覽卷宗），而非可任意裁量之私下溝通。
    • 第二項：書面接觸之公開——若已發生（或必要發生）書面接觸，應將文件附卷，並對「其他當事人」公開（亦即他方當事人有權閱覽）。
    • 第三項：非書面接觸之紀錄義務——若非書面（如電話、面談），公務員應「主動」作成書面紀錄，載明對象、時間、地點、內容，附卷並公開。
  • 本條與迴避制度（第32條、第33條）的區別：
    • 迴避處理的是「公務員與事件之關係」（身分、角色衝突）。
    • 本條處理的是「公務員與當事人之互動方式」（禁止私下來往，要求公開透明）。
條文拆解
第一項（禁止程序外接觸）
  • 「公務員在行政程序中」：公務員正在辦這個案子的期間。
    • 公務員：依第32條之定義（含受託行使公權力之私人或團體之成員）。
    • 在行政程序中：自第34條程序開始，至程序終結（如處分送達、契約簽訂）為止。
      • 包括程序終結後，若該公務員仍參與後續救濟程序（如訴願答辯），仍應遵守。
  • 「除基於職務上之必要外」：除非是「公事公辦」的必要行為（例如寄通知、開會），否則不能私下接觸。
    • 職務上之必要：指依法規、依程序所「必須」為之的行為，而非公務員可自由裁量之私下聯絡。包括：
      • 依法送達文書（第67條以下）。
      • 依法通知陳述意見（第39條、第102條、第104條）。
      • 依法通知勘驗、聽證（第42條、第55條）。
      • 依法公開之會議、公聽會。
      • 依法令所為之調查（如現場勘驗、詢問證人，但應通知他方當事人）。
    • 不包括：
      • 與當事人私下餐敘、電話聊天。
      • 當事人透過「長官」、「民意代表」關說、請託。
      • 以非正式方式（LINE、簡訊）傳遞未公開之訊息。
  • 「不得與當事人或代表其利益之人為行政程序外之接觸」 ：不能私下跟當事人（或他的律師、家人、關說者）吃飯、打電話、傳LINE談案子。
    • 不得：禁止規定。違反者可能受行政懲處，並影響行政處分之合法性。
    • 當事人：依第20條定義。
    • 代表其利益之人：包括：
      • 代理人、輔佐人、律師、會計師、顧問
      • 親屬、朋友（若係為當事人利益而接觸）、民意代表（若係為當事人關說、請託）
    • 行政程序外之接觸：指「非依法定程序所為」之接觸。包括：
      • 私下會面、餐敘、電話、電子郵件、簡訊、LINE、社群媒體私訊、傳真、信件。
      • 在非公開場合（如公務員家中、私下約在咖啡廳）討論案情。
      • 透過第三人（如長官、秘書）傳遞訊息（若該第三人非依法定程序）。
    • 合法之接觸（非屬「程序外」）：
      • 公開之聽證、會議、說明會。
      • 依法通知到場之陳述意見、勘驗、詢問。
      • 依申請之卷宗閱覽（在場有公務員陪同）。
第二項（書面接觸之公開義務）
  • 「公務員與當事人或代表其利益之人為行政程序外之接觸時」 ：如果已經有私下接觸了（不管是不得已還是故意的）。
    • 指「已發生」程序外接觸（不論是公務員主動或被動，或基於職務上必要但未循正式程序）。
  • 「應將所有往來之書面文件附卷」 ：要把私下往來的書面資料（信件、傳真、訊息）全部放到案卷裡。
    • 應：強制義務。
    • 所有往來之書面文件：信件、傳真、電子郵件（列印出來）、LINE對話紀錄（截圖或列印）、簡訊、備忘錄、便條等。
    • 附卷：將該文件歸入該行政程序之案卷中，成為卷宗之一部分。
  • 「並對其他當事人公開」 ：要讓「另一方」（沒參加這次私下見面的人）也知道這件事。
    • 並：除了附卷，還要「公開」。
    • 對其他當事人公開：指提供給「其他未參與該次接觸之當事人」閱覽（依第46條）。
      • 例如：公務員與申請人私下接觸，則應對「相對人」或其他共同申請人公開。
    • 公開方式：依第46條，當事人得申請閱覽；或機關主動將該文件影本送達其他當事人（實務上較少，多以閱覽方式為之）。
第三項（非書面接觸之紀錄義務）
  • 「前項接觸非以書面為之者」：如果私下接觸是用講的（不是寫信）。
  • 「應作成書面紀錄」：公務員要自己把這件事寫下來。
  • 「載明接觸對象、時間、地點及內容」：要把「跟誰、什麼時候、在哪裡、聊了什麼」全部寫下來，放到案卷裡，讓另一方也知道。
    • 法律效果：
      • 該紀錄應附卷（同第二項之「附卷」）。
      • 應對其他當事人公開（同第二項之「公開」）。
      • 若公務員未作成紀錄，或紀錄不實，構成違法。
為什麼要有這條規定？
  • 確保行政程序之公正性：避免公務員因私下接觸而產生偏頗，或受不當影響。
  • 維護武器平等原則：確保所有當事人（尤其是利益相反者）有相同之資訊接觸機會，不會有一方透過「私下溝通」獲得優勢。
  • 防止關說與黑箱作業：透過「公開」機制，使私下接觸無所遁形，減少關說、請託、利益輸送之空間。
  • 落實程序透明：所有與案情相關之溝通（即使是私下發生），最終都應歸入卷宗、對他方公開，使程序可受公評。
  • 課予公務員自我監督義務：要求公務員主動作成紀錄，使其在接觸前即意識到「事後必須公開」，從而減少不當接觸。
白話文
  • 第一項：公務員在辦案的過程中，除非是「公事上必要」（例如寄通知、開會）， 否則「不能」跟當事人（或他的律師、家人、關說者）私下接觸（例如吃飯、打電話、傳LINE）。
  • 第二項：如果不小心（或不得已）有了私下接觸，而且有「書面資料」（例如信件、傳真、LINE對話）， 公務員要把這些資料「放到卷宗裡」，並且讓「另一方當事人」（沒參加的人）也能看到。
  • 第三項：如果私下接觸是「用講的」（例如電話、當面談），公務員要自己「寫成書面紀錄」， 記下「跟誰、何時、何地、談了什麼」，放到卷宗裡，也讓另一方知道。
  • 簡單記：不能跟當事人私下來往；不得已有了，必須全部記錄公開，讓對方也知道。
舉個例子
例1：合法職務上必要——非程序外接觸
  • 承辦人甲依法以掛號郵寄「通知書」給當事人乙，告知陳述意見時間地點。
  • 乙回傳「委任書」給甲。甲將委任書附卷。
  • → 符合第47條第1項但書（職務上必要）。此為法定送達、收受文書，非「程序外接觸」。 無須依本條公開（已依法送達，他方當事人亦得閱覽）。
例2：違法程序外接觸——書面
  • 承辦人丙與申請人丁私下以電子郵件討論案情（丙未同時通知相對人戊）。
  • 丙應將該電子郵件「列印附卷」，並對戊「公開」（例如讓戊申請閱覽）。
  • → 若未附卷、未公開，違反第47條第2項。該私下溝通內容不得作為處分基礎；處分可能因程序違法而撤銷。
例3：違法程序外接觸——非書面
  • 承辦人己與當事人庚在咖啡廳「巧遇」，庚向己陳述案情、請求通融。己未作成任何紀錄。
  • → 違反第47條第3項。己應「作成書面紀錄」（載明對象庚、時間、地點、談話內容），附卷並對他方公開。 未作成紀錄，構成違法。
例4：透過第三人（民意代表）關說
  • 民意代表辛（代表當事人壬之利益）打電話給承辦人癸，為壬之案件請託。
  • 癸未作成紀錄。
  • → 違反第47條第3項（辛為「代表當事人利益之人」）。 癸應作成電話紀錄（對象辛、時間、地點（電話）、內容（請託事項）），附卷並對他方（如相對人）公開。
例5：合法職務上必要但非書面——仍應紀錄
  • 承辦人子因緊急情況，以電話通知當事人丑「明日到場勘驗」（屬職務上必要）。
  • 子應依第47條第3項作成電話紀錄（對象丑、時間、地點（電話）、內容（通知勘驗）），附卷。
  • → 符合第47條第3項。雖為職務上必要，但非書面，仍應作成紀錄（以證明已通知）。
常見爭議案例
案情 法院認定
  • 承辦人與申請人私下會面（未作成紀錄），會面後作成有利於申請人之處分。
  • 他方當事人主張「程序外接觸，處分違法」。機關無法提出紀錄證明會面未影響處分。
  • 違反第47條第3項
  • 推定該接觸影響處分公正性，撤銷處分。
  • 承辦人與當事人代理人以LINE通訊，討論案情。
  • 承辦人將LINE對話截圖列印附卷，但未主動通知他方。
  • 他方於處分後申請閱卷發現該對話，主張未獲「公開」。
  • 附卷已足（他方得依第46條申請閱覽），機關無須主動送達他方。
  • 但若他方不知情，機關應於處分前提醒他方有閱覽權。
  • 民意代表以電話關說，承辦人未作成紀錄。
  • 事後他方檢舉，機關調查屬實。
  • 承辦人違反第47條第3項，予以懲處。
  • 處分因程序違法（無法證明未受影響）撤銷。
一句話總結
    第47條是「禁止私下溝通」條款——
  • 公務員辦案時不能跟當事人私下來往（吃飯、電話、LINE）；
  • 不得已有了私下來往，必須把所有書面資料或談話紀錄放到卷宗裡，讓另一方也能看到。
