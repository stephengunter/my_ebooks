5 單一行為及數行為之處罰

第24條 一行為不二罰與競合之裁處
  1. 「一行為違反數個行政法上義務規定而應處罰鍰者，依法定罰鍰額最高之規定裁處。但裁處之額度，不得低於各該規定之罰鍰最低額。」
  2. 「前項違反行政法上義務行為，除應處罰鍰外，另有沒入或其他種類行政罰之處罰者，得依該規定併為裁處。但其處罰種類相同，如從一重處罰已足以達成行政目的者，不得重複裁處。」
  3. 「一行為違反社會秩序維護法及其他行政法上義務規定而應受處罰，如已裁處拘留者，不再受罰鍰之處罰。」
這一條是關於？
  • 一個行為如果同時違反好幾條行政法規，原則上只罰一次，按罰得最重的那條來罰，但不能低於各條的最低罰鍰；
  • 如果還有沒收或其他處罰，可以一併裁處，但同種類的處罰不能重複；如果已經被裁處拘留，就不再罰鍰！
這一條的核心
  • 本條是《行政罰法》中關於「一行為不二罰」與「競合裁處」的規定，處理的是同一行為違反數個行政法上義務時，應如何裁處的問題。本條體現了「一行為不二罰」原則，與《刑法》第55條的想像競合犯有相似的法理，目的是避免對同一行為重複處罰，違反比例原則。
  • 本條第1項規定，一行為違反數個行政法上義務規定而應處罰鍰者，依法定罰鍰額最高之規定裁處。但裁處之額度，不得低於各該規定之罰鍰最低額。這是「從一重處罰」的原則，但設有最低額的限制，避免裁處低於各該規定的最低額。第2項則規定，除罰鍰外，另有沒入或其他種類行政罰者，得依該規定併為裁處。但若處罰種類相同，如從一重處罰已足以達成行政目的者，不得重複裁處。第3項則規定，一行為違反《社會秩序維護法》及其他行政法上義務規定而應受處罰，如已裁處拘留者，不再受罰鍰之處罰。
  • 從憲法角度來看，本條體現了比例原則與一事不再理的精神。國家對同一行為不應重複處罰，避免過苛；但若不同處罰種類可達成不同行政目的，則可併為裁處。同時，本條也保障了人民對法律的可預見性，讓人民知悉競合時的裁處標準。在整個行政罰法體系中，本條是競合裁處的核心條文，與第25條的數行為違反同一規定、第26條的刑罰與行政罰競合共同構成行政罰的競合體系。
條文拆解
  • 「一行為違反數個行政法上義務規定而應處罰鍰者」：
    • 指同一行為同時違反數個行政法上義務規定，且各該規定均應處罰鍰。
  • 「依法定罰鍰額最高之規定裁處」：
    • 指依各該規定中法定罰鍰額最高的規定裁處。這是從一重處罰原則。
  • 「但裁處之額度，不得低於各該規定之罰鍰最低額」：
    • 指裁處的罰鍰不得低於各該規定的罰鍰最低額。這是最低額限制。
  • 「除應處罰鍰外，另有沒入或其他種類行政罰之處罰者」：
    • 指除罰鍰外，另有沒入或其他種類行政罰的規定。
  • 「得依該規定併為裁處」：
    • 指得依該規定併為裁處沒入或其他種類行政罰。這是併罰規定。
  • 「但其處罰種類相同，如從一重處罰已足以達成行政目的者，不得重複裁處」：
    • 指若處罰種類相同，且從一重處罰已足以達成行政目的，則不得重複裁處。這是禁止重複裁處規定。
  • 「一行為違反社會秩序維護法及其他行政法上義務規定而應受處罰」：
    • 指同一行為同時違反《社會秩序維護法》及其他行政法上義務規定。
  • 「如已裁處拘留者，不再受罰鍰之處罰」：
    • 指若已依《社會秩序維護法》裁處拘留，則不再受罰鍰之處罰。這是拘留優先於罰鍰的規定。
為什麼要有這條規定？
  • 避免重複處罰：同一行為不應重複處罰，避免違反比例原則。
  • 從一重處罰：依法定罰鍰額最高的規定裁處，避免處罰過輕。
  • 設最低額限制：裁處不得低於各該規定的最低額，避免處罰過輕。
  • 允許併罰：若不同處罰種類可達成不同行政目的，得併為裁處。
  • 拘留優先於罰鍰：若已裁處拘留，不再罰鍰，避免過苛。
白話文
  • 簡單說：一個行為如果同時違反好幾條行政法規，原則上只罰一次，按罰得最重的那條來罰，但不能低於各條的最低罰鍰。
  • 如果還有沒收或其他處罰，可以一併裁處，但同種類的處罰不能重複。
  • 如果已經被裁處拘留，就不再罰鍰。
舉個例子
例1（從一重處罰）
  • 小明一個行為同時違反《廢棄物清理法》與《環境基本法》，前者法定罰鍰最高額為6,000元，後者為3,000元。 → 依第24條第1項，依《廢棄物清理法》裁處，但不得低於3,000元。
例2（併罰）
  • 某公司一個行為同時違反《水污染防治法》與《空氣污染防制法》，前者應處罰鍰並得沒入設備，後者應處罰鍰。 → 依第24條第2項，得依《水污染防治法》併為裁處沒入。
例3（禁止重複裁處）
  • 某甲一個行為同時違反兩條法規，均規定「吊扣證照」。 → 依第24條第2項但書，從一重處罰已足以達成行政目的，不得重複裁處。
例4（拘留優先）
  • 某乙一個行為同時違反《社會秩序維護法》與《廢棄物清理法》，已依《社會秩序維護法》裁處拘留。 → 依第24條第3項，不再受罰鍰之處罰。
一句話總結
  • 一行為違反數個行政法上義務而應處罰鍰者，依法定罰鍰額最高之規定裁處，但不得低於各該規定之最低額；另有沒入或其他種類行政罰者，得併為裁處，但同種類處罰不得重複；已裁處拘留者，不再受罰鍰之處罰。
第25條 數行為分別處罰
  • 「數行為違反同一或不同行政法上義務之規定者，分別處罰之。」
這一條是關於？
  • 如果你做了好幾個不同的違規行為，不管是違反同一條法規還是不同法規，每個行為都要分別處罰，不是只罰一次！
這一條的核心
  • 本條是《行政罰法》中關於「數行為分別處罰」的規定，處理的是行為人實施數個行為，分別違反同一或不同行政法上義務時，應如何處罰的問題。本條與第24條的「一行為不二罰」形成對比：第24條處理一行為違反數個規定的競合，本條則處理數行為違反規定的情形。
  • 本條的核心在於：數行為違反同一或不同行政法上義務之規定者，分別處罰之。這意味著，若行為人實施了數個獨立的行為，每個行為各自違反行政法上義務，則應分別處罰，而非合併為一罰。這裡的「數行為」是指自然意義上的數個行為，而非法律評價上的單一行為。例如，小明今天亂丟垃圾，明天又亂丟垃圾，這是數行為，應分別處罰；若小明在同一天、同一地點連續亂丟垃圾，則可能被評價為一行為。
  • 從憲法角度來看，本條體現了責任自負與比例原則的精神。行為人實施數個違規行為，應對每個行為負責，分別處罰符合責任自負原則。同時，本條也保障了人民對法律的可預見性，讓人民知悉數行為的處罰後果。在整個行政罰法體系中，本條是競合裁處的補充條文，與第24條的一行為不二罰、第26條的刑罰與行政罰競合共同構成行政罰的競合體系。
條文拆解
  • 「數行為」：
    • 指行為人實施了數個獨立的行為。這裡的「數行為」是自然意義上的數個行為，而非法律評價上的單一行為。
  • 「違反同一或不同行政法上義務之規定者」：
    • 指這些數行為分別違反同一行政法上義務規定，或不同行政法上義務規定。
    • 例如，數次亂丟垃圾（同一規定），或一次亂丟垃圾、一次超速（不同規定）。
  • 「分別處罰之」：
    • 指對每個行為分別處罰。若數行為違反同一規定，則各行為分別裁處；若數行為違反不同規定，則各依該規定分別裁處。
為什麼要有這條規定？
  • 貫徹責任自負：行為人實施數個違規行為，應對每個行為分別負責。
  • 避免處罰過輕：若數行為僅處罰一次，將導致處罰過輕，無法達成行政目的。
  • 符合比例原則：數行為分別處罰，使處罰與行為數相當。
  • 與一行為不二罰區別：本條與第24條形成對比，明確區分一行為與數行為的處理。
  • 保障人民權益：讓人民知悉數行為的處罰後果，保障人民對法律的可預見性。
白話文
  • 簡單說：如果你做了好幾個不同的違規行為，不管是違反同一條法規還是不同法規，每個行為都要分別處罰。
  • 例如，你今天亂丟垃圾被罰一次，明天又亂丟垃圾再被罰一次，兩次是分開罰的。
舉個例子
例1（數行為違反同一規定）
  • 小明今天在公園亂丟垃圾，明天又在公園亂丟垃圾。 → 依第25條，分別處罰之。
例2（數行為違反不同規定）
  • 老王今天超速，明天又違規停車。 → 依第25條，分別處罰之。
例3（一行為與數行為之區別）
  • 小華在同一天、同一地點連續亂丟10個垃圾。 → 若被評價為一行為，則依第24條處理；若被評價為數行為，則依第25條分別處罰。
例4（數行為與一行為之區別）
  • 某公司同一天排放廢水，同時違反《水污染防治法》與《空氣污染防制法》。 → 若為一行為，依第24條從一重處罰；若為數行為，依第25條分別處罰。
一句話總結
  • 數行為違反同一或不同行政法上義務之規定者，分別處罰之；此與第24條的一行為不二罰形成對比。
第26條 刑罰與行政罰之競合
  1. 「一行為同時觸犯刑事法律及違反行政法上義務規定者，依刑事法律處罰之。但其行為應處以其他種類行政罰或得沒入之物而未經法院宣告沒收者，亦得裁處之。」
  2. 「前項行為如經不起訴處分、緩起訴處分確定或為無罪、免訴、不受理、不付審理、不付保護處分、免刑、緩刑之裁判確定者，得依違反行政法上義務規定裁處之。」
  3. 「第一項行為經緩起訴處分或緩刑宣告確定且經命向公庫或指定之公益團體、地方自治團體、政府機關、政府機構、行政法人、社區或其他符合公益目的之機構或團體，支付一定之金額或提供義務勞務者，其所支付之金額或提供之勞務，應於依前項規定裁處之罰鍰內扣抵之。」
  4. 「前項勞務扣抵罰鍰之金額，按最初裁處時之每小時基本工資乘以義務勞務時數核算。」
  5. 「依第二項規定所為之裁處，有下列情形之一者，由主管機關依受處罰者之申請或依職權撤銷之，已收繳之罰鍰，無息退還：」
    1. 因緩起訴處分確定而為之裁處，其緩起訴處分經撤銷，並經判決有罪確定，且未受免刑或緩刑之宣告。
    2. 因緩刑裁判確定而為之裁處，其緩刑宣告經撤銷確定。
這一條是關於？
  • 一個行為同時觸犯刑法和行政法規時，原則上先依刑法處罰，但如果還有沒收或其他行政罰，也可以一併裁處。
  • 如果刑事部分後來不起訴、無罪、緩刑等，就可以再依行政法規裁處，但已支付的緩起訴金或緩刑金可以扣抵罰鍰！
這一條的核心
  • 本條是《行政罰法》中關於「刑罰與行政罰競合」的規定，處理的是同一行為同時觸犯刑事法律及違反行政法上義務時，應如何裁處的問題。本條體現了「刑罰優先原則」與「一行為不二罰」的法理，目的是避免對同一行為重複處罰，並協調刑事處罰與行政處罰的關係。
  • 本條第1項規定，一行為同時觸犯刑事法律及違反行政法上義務規定者，依刑事法律處罰之。這是刑罰優先原則。但但書規定，若該行為應處以其他種類行政罰或得沒入之物而未經法院宣告沒收者，亦得裁處之。這是併罰的例外。第2項則規定，若該行為經不起訴處分、緩起訴處分確定或為無罪、免訴、不受理、不付審理、不付保護處分、免刑、緩刑之裁判確定者，得依違反行政法上義務規定裁處之。這是刑罰優先的例外。第3項規定，若經緩起訴處分或緩刑宣告確定且經命支付一定金額或提供義務勞務者，其所支付之金額或提供之勞務，應於依前項規定裁處之罰鍰內扣抵之。第4項則規定勞務扣抵罰鍰的計算方式。第5項則規定，若緩起訴處分或緩刑宣告經撤銷確定，則已收繳之罰鍰應無息退還。
  • 從憲法角度來看，本條體現了比例原則與一事不再理的精神。國家對同一行為不應重複處罰，避免過苛；但若刑事處罰不足以達成行政目的，則可例外併處行政罰。同時，本條也保障了人民對法律的可預見性，讓人民知悉競合時的裁處標準。在整個行政罰法體系中，本條是競合裁處的核心條文，與第24條的一行為不二罰、第25條的數行為分別處罰共同構成行政罰的競合體系。
條文拆解
  • 「一行為同時觸犯刑事法律及違反行政法上義務規定者」：
    • 指同一行為同時構成刑事犯罪與行政法上義務的違反。
  • 「依刑事法律處罰之」：
    • 指原則上依刑事法律處罰。這是刑罰優先原則。
  • 「但其行為應處以其他種類行政罰或得沒入之物而未經法院宣告沒收者，亦得裁處之」：
    • 指若該行為應處以其他種類行政罰（如吊扣證照），或得沒入之物未經法院宣告沒收者，仍得裁處。這是併罰的例外。
  • 「前項行為如經不起訴處分、緩起訴處分確定」：
    • 指刑事部分經檢察官為不起訴處分或緩起訴處分確定。
  • 「或為無罪、免訴、不受理、不付審理、不付保護處分、免刑、緩刑之裁判確定者」：
    • 指刑事部分經法院為無罪、免訴、不受理、不付審理、不付保護處分、免刑、緩刑之裁判確定。
  • 「得依違反行政法上義務規定裁處之」：
    • 指得依行政法上義務規定裁處。這是刑罰優先的例外。
  • 「經緩起訴處分或緩刑宣告確定且經命向公庫或指定之公益團體...支付一定之金額或提供義務勞務者」：
    • 指經緩起訴處分或緩刑宣告確定，且經命支付一定金額或提供義務勞務。
  • 「其所支付之金額或提供之勞務，應於依前項規定裁處之罰鍰內扣抵之」：
    • 指所支付的金額或提供的勞務，應於依第2項裁處的罰鍰內扣抵。
  • 「前項勞務扣抵罰鍰之金額，按最初裁處時之每小時基本工資乘以義務勞務時數核算」：
    • 指勞務扣抵罰鍰的金額，按最初裁處時的每小時基本工資乘以義務勞務時數計算。
  • 「依第二項規定所為之裁處，有下列情形之一者，由主管機關依受處罰者之申請或依職權撤銷之，已收繳之罰鍰，無息退還」：
    • 指依第2項所為的裁處，若有下列情形之一，應撤銷並無息退還已收繳的罰鍰。
  • 「一、因緩起訴處分確定而為之裁處，其緩起訴處分經撤銷，並經判決有罪確定，且未受免刑或緩刑之宣告」：
    • 指因緩起訴處分確定而為的裁處，若緩起訴處分經撤銷，並經判決有罪確定，且未受免刑或緩刑宣告。
  • 「二、因緩刑裁判確定而為之裁處，其緩刑宣告經撤銷確定」：
    • 指因緩刑裁判確定而為的裁處，若緩刑宣告經撤銷確定。
為什麼要有這條規定？
  • 協調刑罰與行政罰：避免對同一行為重複處罰，並協調刑事處罰與行政處罰的關係。
  • 刑罰優先原則：刑事處罰較為嚴厲，原則上優先適用。
  • 允許例外併罰：若刑事處罰不足以達成行政目的，得例外併處行政罰。
  • 扣抵機制：避免行為人因同一行為受雙重金錢負擔，設有扣抵機制。
  • 撤銷退還機制：若緩起訴或緩刑經撤銷，則已收繳的罰鍰應退還，避免不當得利。
白話文
  • 簡單說：一個行為同時觸犯刑法和行政法規時，原則上先依刑法處罰。但如果還有沒收或其他行政罰，也可以一併裁處。
  • 如果刑事部分後來不起訴、無罪、緩刑等，就可以再依行政法規裁處，但已支付的緩起訴金或緩刑金可以扣抵罰鍰。
  • 如果緩起訴或緩刑後來被撤銷，則已收繳的罰鍰應無息退還。
舉個例子
例1（刑罰優先）
  • 小明酒駕，同時觸犯《刑法》公共危險罪與《道路交通管理處罰條例》。 → 依第26條第1項，依刑事法律處罰之。
例2（併罰例外）
  • 老王酒駕，同時觸犯《刑法》公共危險罪與《道路交通管理處罰條例》，該條例規定吊扣駕照。 → 依第26條第1項但書，得裁處吊扣駕照。
例3（不起訴後裁處）
  • 小李涉嫌違反《公平交易法》，經檢察官為不起訴處分確定。 → 依第26條第2項，得依《公平交易法》裁處。
例4（扣抵）
  • 小陳經緩起訴處分確定，支付公庫10萬元，後依《水污染防治法》裁處罰鍰20萬元。 → 依第26條第3項，10萬元應於20萬元內扣抵。
例5（撤銷退還）
  • 小華因緩起訴處分確定而經裁處罰鍰，後緩起訴處分經撤銷並經判決有罪確定。 → 依第26條第5項第1款，應撤銷裁處並無息退還已收繳的罰鍰。
一句話總結
  • 一行為同時觸犯刑事法律及違反行政法上義務者，依刑事法律處罰之，但得併處其他種類行政罰或沒入；若經不起訴、緩起訴、無罪、緩刑等，得依行政法規裁處，並得扣抵已支付金額或勞務；若緩起訴或緩刑經撤銷，則撤銷裁處並無息退還罰鍰。
