7 管轄機關

第29條 行政罰之土地管轄
  1. 「違反行政法上義務之行為，由行為地、結果地、行為人之住所、居所或營業所、事務所或公務所所在地之主管機關管轄。」
  2. 「在中華民國領域外之中華民國船艦或航空器內違反行政法上義務者，得由船艦本籍地、航空器出發地或行為後在中華民國領域內最初停泊地或降落地之主管機關管轄。」
  3. 「在中華民國領域外之外國船艦或航空器於依法得由中華民國行使管轄權之區域內違反行政法上義務者，得由行為後其船艦或航空器在中華民國領域內最初停泊地或降落地之主管機關管轄。」
  4. 「在中華民國領域外依法得由中華民國行使管轄權之區域內違反行政法上義務者，不能依前三項規定定其管轄機關時，得由行為人所在地之主管機關管轄。」
這一條是關於？
  • 違反行政法規時，哪個機關有權開罰？原則上看行為地、結果地、行為人的住所、居所、營業所、事務所或公務所所在地；
  • 如果是在台灣地區的船艦或航空器上違規，則看船艦本籍地、航空器出發地或最初停泊地、降落地！
這一條的核心
  • 本條是《行政罰法》中關於「土地管轄」的規定，處理的是違反行政法上義務的行為，應由哪個主管機關管轄的問題。本條體現了「管轄法定」與「便利人民」的法理，目的是明確各主管機關的管轄權限，避免管轄爭議，並便利人民救濟。
  • 本條第1項規定，違反行政法上義務之行為，由行為地、結果地、行為人之住所、居所或營業所、事務所或公務所所在地之主管機關管轄。這是土地管轄的基本規定，採併列管轄的方式，讓行政機關有選擇權。第2項則規定，在中華民國領域外之中華民國船艦或航空器內違反行政法上義務者，得由船艦本籍地、航空器出發地或行為後在中華民國領域內最初停泊地或降落地之主管機關管轄。第3項則規定，在中華民國領域外之外國船艦或航空器於依法得由中華民國行使管轄權之區域內違反行政法上義務者，得由行為後其船艦或航空器在中華民國領域內最初停泊地或降落地之主管機關管轄。第4項則規定，在中華民國領域外依法得由中華民國行使管轄權之區域內違反行政法上義務者，不能依前三項規定定其管轄機關時，得由行為人所在地之主管機關管轄。這是補充管轄的規定。
  • 從憲法角度來看，本條體現了管轄權明確性與正當法律程序的精神。管轄機關的明確讓人民知悉向哪個機關救濟，保障人民的程序權。同時，本條也保障了人民對法律的可預見性，讓人民知悉管轄機關的認定標準。在整個行政罰法體系中，本條是管轄規定的核心條文，與第30條的管轄競合、第31條的管轄移轉共同構成行政罰的管轄體系。
條文拆解
  • 「違反行政法上義務之行為」：
    • 指違反行政法上義務的行為。
  • 「由行為地、結果地、行為人之住所、居所或營業所、事務所或公務所所在地之主管機關管轄」：
    • 指由下列地點的主管機關管轄：
      • 行為地：指實施違規行為的地點。
      • 結果地：指違規行為結果發生的地點。
      • 行為人之住所、居所：指行為人的住所或居所。
      • 營業所、事務所：指行為人的營業所或事務所。
      • 公務所：指行為人的公務所。
  • 「在中華民國領域外之中華民國船艦或航空器內違反行政法上義務者」：
    • 指在中華民國領域外，於中華民國船艦或航空器內違反行政法上義務。
  • 「得由船艦本籍地、航空器出發地或行為後在中華民國領域內最初停泊地或降落地之主管機關管轄」：
    • 指得由下列地點的主管機關管轄：
      • 船艦本籍地：指船艦的登記港。
      • 航空器出發地：指航空器的起飛地。
      • 最初停泊地：指船艦在中華民國領域內最初停泊的港口。
      • 最初降落地：指航空器在中華民國領域內最初降落的機場。
  • 「在中華民國領域外之外國船艦或航空器於依法得由中華民國行使管轄權之區域內違反行政法上義務者」：
    • 指在外國船艦或航空器上，於中華民國得行使管轄權的區域內違反行政法上義務。
  • 「得由行為後其船艦或航空器在中華民國領域內最初停泊地或降落地之主管機關管轄」：
    • 指得由行為後該船艦或航空器在中華民國領域內最初停泊地或降落地的主管機關管轄。
  • 「在中華民國領域外依法得由中華民國行使管轄權之區域內違反行政法上義務者」：
    • 指在中華民國領域外，依法得由中華民國行使管轄權的區域內違反行政法上義務。
  • 「不能依前三項規定定其管轄機關時」：
    • 指不能依第1項至第3項規定定其管轄機關時。
  • 「得由行為人所在地之主管機關管轄」：
    • 指得由行為人所在地的主管機關管轄。這是補充管轄的規定。
為什麼要有這條規定？
  • 明確管轄權限：明定各主管機關的管轄權限，避免管轄爭議。
  • 便利人民救濟：讓人民知悉向哪個機關救濟，便利人民行使權利。
  • 處理域外管轄：對於在中華民國領域外的船艦、航空器或行使管轄權區域內違規，明定管轄機關。
  • 補充管轄規定：若不能依前三項定管轄機關，則由行為人所在地主管機關管轄。
  • 符合法安定性：管轄規定的明確讓法律狀態安定，符合法安定性。
白話文
  • 違反行政法規時，哪個機關有權開罰？原則上看行為地、結果地、行為人的住所、居所、營業所、事務所或公務所所在地。
  • 如果是在台灣地區的船艦或航空器上違規，則看船艦本籍地、航空器出發地或最初停泊地、降落地。
  • 如果是在外國船艦或航空器上，於台灣地區得行使管轄權的區域內違規，則看最初停泊地或降落地。
  • 如果都不能定管轄機關，就由行為人所在地的主管機關管轄。
舉個例子
例1（行為地管轄）
  • 小明在台北市亂丟垃圾。 → 依第29條第1項，由台北市環保局管轄。
例2（結果地管轄）
  • 某公司在桃園市排放廢水，污染結果發生在新北市。 → 依第29條第1項，得由桃園市或新北市主管機關管轄。
例3（船艦管轄）
  • 某台灣地區籍漁船在公海上違反漁業法規。 → 依第29條第2項，得由船艦本籍地或行為後最初停泊地之主管機關管轄。
例4（航空器管轄）
  • 某台灣地區籍航空器在飛越日本上空時，旅客違反《民用航空法》。 → 依第29條第2項，得由航空器出發地或行為後最初降落地之主管機關管轄。
例5（補充管轄）
  • 某外國船艦在台灣地區得行使管轄權的區域內違規，但無法依前三項定管轄機關。 → 依第29條第4項，得由行為人所在地之主管機關管轄。
一句話總結
  • 違反行政法上義務之行為，由行為地、結果地、行為人之住所、居所、營業所、事務所或公務所所在地之主管機關管轄；在中華民國領域外之船艦或航空器內違規者，得由船艦本籍地、航空器出發地或最初停泊地、降落地之主管機關管轄；不能依前三項定管轄機關時，得由行為人所在地之主管機關管轄。
第30條 共同違法之管轄競合
  • 「故意共同實施違反行政法上義務之行為，其行為地、行為人之住所、居所或營業所、事務所或公務所所在地不在同一管轄區內者，各該行為地、住所、居所或所在地之主管機關均有管轄權。」
這一條是關於？
  • 如果好幾個人一起故意違規，而他們的行為地、住所、營業所等分散在不同縣市，那麼每個相關地點的主管機關都有管轄權，都可以開罰！
這一條的核心
  • 本條是《行政罰法》中關於「共同違法之管轄競合」的規定，處理的是故意共同實施違反行政法上義務之行為，若行為地、行為人之住所、居所、營業所、事務所或公務所所在地不在同一管轄區內時，各該地點之主管機關是否均有管轄權的問題。本條體現了「管轄競合」的法理，目的是避免因共同違法者分散各地而產生管轄漏洞，並便利行政機關行使管轄權。
  • 本條的核心在於：故意共同實施違反行政法上義務之行為，其行為地、行為人之住所、居所或營業所、事務所或公務所所在地不在同一管轄區內者，各該行為地、住所、居所或所在地之主管機關均有管轄權。這意味著，若數人共同違法，且其行為地或住所地分散在不同管轄區，則各該管轄區的主管機關均有管轄權，形成管轄競合。此時，各主管機關得依職權或依申請，協調由其中一機關管轄，或依第31條規定移轉管轄。
  • 從憲法角度來看，本條體現了管轄權明確性與正當法律程序的精神。管轄競合的規定讓人民知悉哪些機關有管轄權，保障人民的程序權。同時，本條也保障了人民對法律的可預見性，讓人民知悉共同違法時的管轄機關。在整個行政罰法體系中，本條是管轄規定的補充條文，與第29條的土地管轄、第31條的管轄移轉共同構成行政罰的管轄體系。
條文拆解
  • 「故意共同實施違反行政法上義務之行為」：
    • 指二人以上基於共同故意，一起實施違反行政法上義務的行為。
    • 這是第14條第1項所稱的共同違法。
  • 「其行為地、行為人之住所、居所或營業所、事務所或公務所所在地不在同一管轄區內者」：
    • 指共同違法者的行為地、住所、居所、營業所、事務所或公務所所在地，分散在不同管轄區內。
  • 「各該行為地、住所、居所或所在地之主管機關均有管轄權」：
    • 指各該地點的主管機關均有管轄權。這是管轄競合的規定，各機關均得行使管轄權。
為什麼要有這條規定？
  • 避免管轄漏洞：共同違法者分散各地，若僅由其中一機關管轄，可能產生管轄漏洞。
  • 便利行政機關行使管轄權：各該地點的主管機關均有管轄權，便利行政機關行使管轄權。
  • 保障人民權益：讓人民知悉哪些機關有管轄權，保障人民的程序權。
  • 符合管轄法定原則：管轄競合的規定讓管轄權明確，符合管轄法定原則。
  • 銜接管轄移轉：本條與第31條的管轄移轉共同構成管轄體系。
白話文
  • 簡單說：如果好幾個人一起故意違規，而他們的行為地、住所、營業所等分散在不同縣市，那麼每個相關地點的主管機關都有管轄權，都可以開罰。
  • 例如，小王在台北市、小李在台中市共同違規，台北市和台中市的主管機關都有管轄權。
舉個例子
例1（共同違法管轄競合）
  • 小王在台北市、小李在台中市共同違規。 → 依第30條，台北市與台中市主管機關均有管轄權。
例2（住所地不同）
  • 小陳住新北市、小林住桃園市，共同在台北市違規。 → 依第30條，新北市、桃園市、台北市主管機關均有管轄權。
例3（營業所不同）
  • 甲公司營業所在高雄市、乙公司營業所在台南市，共同在嘉義市違規。 → 依第30條，高雄市、台南市、嘉義市主管機關均有管轄權。
例4（非故意共同實施）
  • 小華與小美因過失共同違規。 → 不適用第30條，應依第29條定管轄機關。
一句話總結
  • 故意共同實施違反行政法上義務之行為，其行為地、行為人之住所、居所或營業所、事務所或公務所所在地不在同一管轄區內者，各該行為地、住所、居所或所在地之主管機關均有管轄權。
第31條 管轄競合之處理
  1. 「一行為違反同一行政法上義務，數機關均有管轄權者，由處理在先之機關管轄。不能分別處理之先後者，由各該機關協議定之；不能協議或有統一管轄之必要者，由其共同上級機關指定之。」
  2. 「一行為違反數個行政法上義務而應處罰鍰，數機關均有管轄權者，由法定罰鍰額最高之主管機關管轄。法定罰鍰額相同者，依前項規定定其管轄。」
  3. 「一行為違反數個行政法上義務，應受沒入或其他種類行政罰者，由各該主管機關分別裁處。但其處罰種類相同者，如從一重處罰已足以達成行政目的者，不得重複裁處。」
  4. 「第一項及第二項情形，原有管轄權之其他機關於必要之情形時，應為必要之職務行為，並將有關資料移送為裁處之機關；為裁處之機關應於調查終結前，通知原有管轄權之其他機關。」
這一條是關於？
  • 一個行為如果好幾個機關都有管轄權，原則上由「先處理的機關」管；如果分不出先後，就協議或由上級指定；
  • 如果同時違反好幾條法規要罰錢，就由「罰得最重的那個機關」管；其他種類的行政罰則分別裁處，但同種類不能重複罰！
這一條的核心
  • 本條是《行政罰法》中關於「管轄競合之處理」的規定，處理的是一行為違反行政法上義務，而數機關均有管轄權時，應如何決定管轄機關的問題。本條體現了「管轄競合解決機制」的法理，目的是避免數機關重複管轄或互踢皮球，確保行政效率與人民權益。
  • 本條第1項規定，一行為違反同一行政法上義務，數機關均有管轄權者，由處理在先之機關管轄。不能分別處理之先後者，由各該機關協議定之；不能協議或有統一管轄之必要者，由其共同上級機關指定之。第2項則規定，一行為違反數個行政法上義務而應處罰鍰，數機關均有管轄權者，由法定罰鍰額最高之主管機關管轄。法定罰鍰額相同者，依第1項規定定其管轄。第3項則規定，一行為違反數個行政法上義務，應受沒入或其他種類行政罰者，由各該主管機關分別裁處。但其處罰種類相同者，如從一重處罰已足以達成行政目的者，不得重複裁處。第4項則規定，第1項及第2項情形，原有管轄權之其他機關於必要之情形時，應為必要之職務行為，並將有關資料移送為裁處之機關；為裁處之機關應於調查終結前，通知原有管轄權之其他機關。
  • 從憲法角度來看，本條體現了管轄權明確性與正當法律程序的精神。管轄競合的解決機制讓人民知悉由哪個機關管轄，保障人民的程序權。同時，本條也保障了人民對法律的可預見性，讓人民知悉管轄機關的認定標準。在整個行政罰法體系中，本條是管轄規定的核心條文，與第29條的土地管轄、第30條的共同違法管轄共同構成行政罰的管轄體系。
條文拆解
  • 「一行為違反同一行政法上義務，數機關均有管轄權者」：
    • 指同一行為違反同一行政法上義務，而數機關均有管轄權。
  • 「由處理在先之機關管轄」：
    • 指由最先處理該案件的機關管轄。這是優先管轄原則。
  • 「不能分別處理之先後者」：
    • 指無法分辨哪個機關先處理。
  • 「由各該機關協議定之」：
    • 指由各該機關協議決定管轄機關。
  • 「不能協議或有統一管轄之必要者」：
    • 指各該機關不能達成協議，或有統一管轄的必要。
  • 「由其共同上級機關指定之」：
    • 指由其共同上級機關指定管轄機關。
  • 「一行為違反數個行政法上義務而應處罰鍰，數機關均有管轄權者」：
    • 指同一行為違反數個行政法上義務，均應處罰鍰，而數機關均有管轄權。
  • 「由法定罰鍰額最高之主管機關管轄」：
    • 指由法定罰鍰額最高的主管機關管轄。這是從重管轄原則。
  • 「法定罰鍰額相同者，依前項規定定其管轄」：
    • 指若法定罰鍰額相同，則依第1項規定定管轄。
  • 「一行為違反數個行政法上義務，應受沒入或其他種類行政罰者」：
    • 指同一行為違反數個行政法上義務，應受沒入或其他種類行政罰。
  • 「由各該主管機關分別裁處」：
    • 指由各該主管機關分別裁處。這是分別裁處原則。
  • 「但其處罰種類相同者，如從一重處罰已足以達成行政目的者，不得重複裁處」：
    • 指若處罰種類相同，且從一重處罰已足以達成行政目的，則不得重複裁處。
  • 「原有管轄權之其他機關於必要之情形時，應為必要之職務行為」：
    • 指原有管轄權的其他機關於必要時，應為必要的職務行為。
  • 「並將有關資料移送為裁處之機關」：
    • 指將有關資料移送為裁處之機關。
  • 「為裁處之機關應於調查終結前，通知原有管轄權之其他機關」：
    • 指為裁處之機關應於調查終結前，通知原有管轄權的其他機關。
為什麼要有這條規定？
  • 解決管轄競合：避免數機關重複管轄或互踢皮球，確保行政效率。
  • 保障人民權益：讓人民知悉由哪個機關管轄，保障人民的程序權。
  • 從重管轄原則：一行為違反數個法規而應處罰鍰，由法定罰鍰額最高的機關管轄，避免處罰過輕。
  • 分別裁處原則：沒入或其他種類行政罰，由各該主管機關分別裁處，但同種類不得重複。
  • 資訊共享：原有管轄權之其他機關應移送資料，為裁處之機關應通知其他機關，確保資訊共享。
白話文
  • 簡單說：一個行為如果好幾個機關都有管轄權，原則上由「先處理的機關」管；如果分不出先後，就協議或由上級指定。
  • 如果同時違反好幾條法規要罰錢，就由「罰得最重的那個機關」管。
  • 其他種類的行政罰則分別裁處，但同種類不能重複罰。
  • 原有管轄權的其他機關必要時應為必要行為並移送資料，為裁處之機關應於調查終結前通知其他機關。
舉個例子
例1（處理在先）
  • 小明在台北市與新北市交界處亂丟垃圾，台北市與新北市環保局均有管轄權，台北市環保局先處理。 → 依第31條第1項，由台北市環保局管轄。
例2（協議定之）
  • 某公司違規，經濟部與環保署均有管轄權，無法分辨先後。 → 依第31條第1項，由兩機關協議定之。
例3（從重管轄）
  • 某公司一行為同時違反《水污染防治法》與《空氣污染防制法》，前者法定罰鍰最高額為300萬元，後者為100萬元。 → 依第31條第2項，由環保局（水污染防治法）管轄。
例4（分別裁處）
  • 某公司一行為同時違反《水污染防治法》與《空氣污染防制法》，前者應處罰鍰並得沒入設備，後者應處罰鍰。 → 依第31條第3項，得由各該主管機關分別裁處沒入。
例5（資訊共享）
  • 某公司違規，經濟部與環保署均有管轄權，經濟部為裁處機關。 → 依第31條第4項，環保署應為必要職務行為並移送資料，經濟部應於調查終結前通知環保署。
一句話總結
  • 一行為違反同一行政法上義務，數機關均有管轄權者，由處理在先之機關管轄；不能分別先後者，協議或由上級指定；一行為違反數個行政法上義務而應處罰鍰者，由法定罰鍰額最高之主管機關管轄；應受沒入或其他種類行政罰者，分別裁處，但同種類不得重複；原有管轄權之其他機關應為必要職務行為並移送資料，為裁處之機關應於調查終結前通知之。
第32條 刑罰與行政罰競合之移送
  1. 「一行為同時觸犯刑事法律及違反行政法上義務規定者，應將涉及刑事部分移送該管司法機關。」
  2. 「前項移送案件，司法機關就刑事案件為不起訴處分、緩起訴處分確定或為無罪、免訴、不受理、不付審理、不付保護處分、免刑、緩刑、撤銷緩刑之裁判確定，或撤銷緩起訴處分後經判決有罪確定者，應通知原移送之行政機關。」
  3. 「前二項移送案件及業務聯繫之辦法，由行政院會同司法院定之。」
這一條是關於？
  • 一個行為同時觸犯刑法和行政法規時，行政機關要把刑事部分移送給司法機關處理；
  • 司法機關後來如果做出不起訴、無罪、緩刑等決定，要通知原本移送的行政機關，讓行政機關知道能不能再開罰！
這一條的核心
  • 本條是《行政罰法》中關於「刑罰與行政罰競合之移送」的規定，處理的是一行為同時觸犯刑事法律及違反行政法上義務時，行政機關應如何處理刑事部分，以及司法機關應如何通知行政機關的問題。本條是第26條的程序配套規定，目的是落實「刑罰優先原則」，並確保行政機關能及時知悉刑事案件的結果，以決定是否依行政法規裁處。
  • 本條第1項規定，一行為同時觸犯刑事法律及違反行政法上義務規定者，應將涉及刑事部分移送該管司法機關。這是移送義務的規定，行政機關發現同一行為涉及刑事責任時，應主動將刑事部分移送司法機關。第2項則規定，司法機關就刑事案件為不起訴處分、緩起訴處分確定或為無罪、免訴、不受理、不付審理、不付保護處分、免刑、緩刑、撤銷緩刑之裁判確定，或撤銷緩起訴處分後經判決有罪確定者，應通知原移送之行政機關。這是通知義務的規定，讓行政機關知悉刑事結果，以決定是否依第26條第2項裁處行政罰。第3項則規定，移送案件及業務聯繫之辦法，由行政院會同司法院定之。這是授權訂定辦法的規定。
  • 從憲法角度來看，本條體現了權力分立與正當法律程序的精神。行政機關與司法機關各司其職，行政機關負責行政罰，司法機關負責刑罰。同時，本條也保障了人民對法律的可預見性，讓人民知悉刑事與行政程序的銜接。在整個行政罰法體系中，本條是刑罰與行政罰競合的程序規定，與第26條的實體規定共同構成行政罰的競合體系。
條文拆解
  • 「一行為同時觸犯刑事法律及違反行政法上義務規定者」：
    • 指同一行為同時構成刑事犯罪與行政法上義務的違反。
  • 「應將涉及刑事部分移送該管司法機關」：
    • 指行政機關應將涉及刑事部分移送該管司法機關。這是移送義務。
  • 「前項移送案件」：
    • 指依第1項移送的案件。
  • 「司法機關就刑事案件為不起訴處分、緩起訴處分確定」：
    • 指司法機關就刑事案件為不起訴處分或緩起訴處分確定。
  • 「或為無罪、免訴、不受理、不付審理、不付保護處分、免刑、緩刑、撤銷緩刑之裁判確定」：
    • 指司法機關為無罪、免訴、不受理、不付審理、不付保護處分、免刑、緩刑、撤銷緩刑之裁判確定。
  • 「或撤銷緩起訴處分後經判決有罪確定者」：
    • 指撤銷緩起訴處分後經判決有罪確定。
  • 「應通知原移送之行政機關」：
    • 指司法機關應通知原移送之行政機關。這是通知義務。
  • 「前二項移送案件及業務聯繫之辦法，由行政院會同司法院定之」：
    • 指移送案件及業務聯繫之辦法，由行政院會同司法院定之。這是授權訂定辦法。
為什麼要有這條規定？
  • 落實刑罰優先原則：同一行為涉及刑事責任時，應先由司法機關處理。
  • 確保行政機關知悉刑事結果：司法機關應通知行政機關，讓行政機關決定是否裁處行政罰。
  • 避免重複處罰：透過移送與通知，避免對同一行為重複處罰。
  • 保障人民權益：讓人民知悉刑事與行政程序的銜接，保障人民權益。
  • 建立業務聯繫機制：由行政院會同司法院訂定辦法，建立移送與聯繫機制。
白話文
  • 簡單說：一個行為同時觸犯刑法和行政法規時，行政機關要把刑事部分移送給司法機關處理。
  • 司法機關後來如果做出不起訴、無罪、緩刑等決定，要通知原本移送的行政機關，讓行政機關知道能不能再開罰。移送和聯繫的辦法由行政院會同司法院訂定。
舉個例子
例1（移送）
  • 小明酒駕，同時觸犯《刑法》公共危險罪與《道路交通管理處罰條例》。 → 依第32條第1項，行政機關應將刑事部分移送司法機關。
例2（通知）
  • 某甲涉嫌違反《公平交易法》，經檢察官為不起訴處分確定。 → 依第32條第2項，司法機關應通知原移送之行政機關。
例3（緩刑通知）
  • 某乙經法院為緩刑裁判確定。 → 依第32條第2項，司法機關應通知原移送之行政機關。
例4（撤銷緩起訴後有罪）
  • 某丙經緩起訴處分確定，後撤銷緩起訴處分並經判決有罪確定。 → 依第32條第2項，司法機關應通知原移送之行政機關。
例5（業務聯繫辦法）
  • ：行政院會同司法院訂定「行政罰法第32條移送案件及業務聯繫辦法」。 → 依第32條第3項，授權訂定辦法。
一句話總結
  • 一行為同時觸犯刑事法律及違反行政法上義務者，應將刑事部分移送司法機關；司法機關為不起訴、緩起訴、無罪、緩刑等裁判確定，或撤銷緩起訴後經判決有罪確定者，應通知原移送之行政機關；移送及業務聯繫辦法由行政院會同司法院定之。
