3 共同違法及併同處罰

第14條 共同違法與身分關係之處理
  1. 「故意共同實施違反行政法上義務之行為者，依其行為情節之輕重，分別處罰之。」
  2. 「前項情形，因身分或其他特定關係成立之違反行政法上義務行為，其無此身分或特定關係者，仍處罰之。」
  3. 「因身分或其他特定關係致處罰有重輕或免除時，其無此身分或特定關係者，仍處以通常之處罰。」
這一條是關於？
  • 兩個人以上一起故意違規，會按照每個人參與的程度分別處罰；
  • 就算違規行為需要特定身分才能成立，沒有身分的人參與了也照罰；
  • 身分只影響處罰輕重時，沒身分的人就罰一般的規定！
這一條的核心
  • 本條是《行政罰法》中關於「共同違法」與「身分關係」的規定，處理的是多數人共同實施違反行政法上義務行為時，應如何處罰的問題。本條體現了「共同違法分別處罰」的原則，與《刑法》第28條至第31條的規定相呼應，是行政罰法中的多數行為人規範。
  • 本條第1項確立了共同違法的基本原則：故意共同實施違反行政法上義務之行為者，依其行為情節之輕重，分別處罰之。這與刑法的「共同正犯」概念類似，但行政罰法採取「分別處罰」而非「連帶處罰」，即每個行為人依其參與程度各自受罰。第2項處理身分犯的問題：若違規行為因身分或其他特定關係而成立，無此身分或特定關係者仍應處罰。第3項則處理身分加減的問題：若身分導致處罰有重輕或免除，無此身分者仍處以通常之處罰。
  • 從憲法角度來看，本條體現了責任自負與比例原則的精神。每個行為人只對自己的行為負責，處罰應與其參與程度相當。同時，本條也保障了人民對法律的可預見性，讓人民知悉共同違規時的處罰依據。在整個行政罰法體系中，本條是多數行為人的規範基礎，與第15條的法人併罰、第16條的機關責任共同構成行政罰的處罰對象體系。
條文拆解
  • 「故意共同實施違反行政法上義務之行為者」：
    • 指二人以上基於共同故意，一起實施違反行政法上義務的行為。
    • 這裡強調故意，若僅有過失，則不適用本條。
  • 「依其行為情節之輕重，分別處罰之」：
    • 指按每個行為人參與的程度、角色、影響力等，分別決定其處罰。
    • 這是分別處罰原則，而非連帶處罰。
  • 「因身分或其他特定關係成立之違反行政法上義務行為」：
    • 指某些違規行為的成立，須行為人具備特定身分或關係（如負責人、管理人）。
    • 這是身分犯的規定。
  • 「其無此身分或特定關係者，仍處罰之」：
    • 指無特定身分者若參與該違規行為，仍應處罰。
    • 這是身分犯的擴張處罰。
  • 「因身分或其他特定關係致處罰有重輕或免除時」：
    • 指某些違規行為因行為人的身分而導致處罰輕重不同或免除。
    • 這是身分加減的規定。
  • 「其無此身分或特定關係者，仍處以通常之處罰」：
    • 指無特定身分者，不因身分加減而受影響，仍處以通常的處罰。
為什麼要有這條規定？
  • 規範共同違法：多數人共同違規時，明定如何處罰，避免適用疑義。
  • 貫徹責任自負：每個行為人依其參與程度分別處罰，符合責任自負原則。
  • 處理身分犯問題：明定無身分者參與身分犯時仍應處罰，避免處罰漏洞。
  • 區分身分加減：明定身分加減不影響無身分者，避免處罰失衡。
  • 符合比例原則：處罰應與行為人參與程度相當，避免過苛或過寬。
白話文
  • 簡單說：如果兩個人以上一起故意違規，會按照每個人參與的程度分別處罰。
  • 如果某個違規行為需要特定身分才能成立，沒有身分的人參與了也照罰。
  • 如果身分只影響處罰輕重，沒身分的人就罰一般的規定。
舉個例子
例1（共同違法）
  • 小王和小李一起在公園亂丟垃圾。 → 依第14條第1項，依其行為情節分別處罰。
例2（身分犯）
  • 某公司員工與負責人一起違反《水污染防治法》，該法規定處罰負責人。 → 依第14條第2項，無負責人身分的員工仍應處罰。
例3（身分加減）
  • 某法規規定「負責人違規加重處罰」，但一般員工違規則處通常罰鍰。 → 依第14條第3項，無負責人身分的員工仍處通常處罰。
例4（過失不適用）
  • 小陳和小林因過失共同違反行政法規。 → 不適用第14條第1項的故意共同實施，應依各自過失情形處理。
一句話總結
  • 故意共同實施違反行政法上義務的行為，依參與情節分別處罰；無身分者參與身分犯仍應處罰，身分加減不影響無身分者。
第15條 私法人之代表權人與負責人之併罰
  1. 「私法人之董事或其他有代表權之人，因執行其職務或為私法人之利益為行為，致使私法人違反行政法上義務應受處罰者，該行為人如有故意或重大過失時，除法律或自治條例另有規定外，應並受同一規定罰鍰之處罰。」
  2. 「私法人之職員、受僱人或從業人員，因執行其職務或為私法人之利益為行為，致使私法人違反行政法上義務應受處罰者，私法人之董事或其他有代表權之人，如對該行政法上義務之違反，因故意或重大過失，未盡其防止義務時，除法律或自治條例另有規定外，應並受同一規定罰鍰之處罰。」
  3. 「依前二項並受同一規定處罰之罰鍰，不得逾新臺幣一百萬元。但其所得之利益逾新臺幣一百萬元者，得於其所得利益之範圍內裁處之。」
這一條是關於？
  • 公司違規被罰，除了公司本身要繳罰鍰，公司的董事長、負責人如果有故意或重大過失，也要一起被罰，但罰鍰有100萬元的上限，除非他們賺得更多！
這一條的核心
  • 本條是《行政罰法》中關於「私法人併罰」的規定，處理的是私法人（如公司）違反行政法上義務時，其董事或其他有代表權之人是否應一併受罰的問題。本條體現了「法人與負責人併罰」的原則，目的是透過對負責人的處罰，督促其善盡監督義務，避免法人違規。
  • 本條第1項規定，私法人的董事或其他有代表權之人，因執行職務或為私法人利益而為行為，致使私法人違反行政法上義務應受處罰者，該行為人如有故意或重大過失，除法律或自治條例另有規定外，應並受同一規定罰鍰之處罰。第2項則規定，若私法人的職員、受僱人或從業人員因執行職務致使私法人違規，而董事或其他有代表權之人對該違反因故意或重大過失未盡防止義務時，亦應並受同一規定罰鍰之處罰。第3項則設有罰鍰上限：併罰的罰鍰不得逾新臺幣100萬元，但若所得利益逾100萬元者，得於其所得利益範圍內裁處。
  • 從憲法角度來看，本條體現了責任自負與比例原則的精神。負責人只對自己的故意或重大過失負責，且罰鍰有上限，避免過苛。同時，本條也保障了人民對法律的可預見性，讓負責人知悉其監督責任。在整個行政罰法體系中，本條是法人處罰的核心規定，與第14條的共同違法、第16條的機關責任共同構成行政罰的處罰對象體系。
條文拆解
  • 「私法人之董事或其他有代表權之人」：
    • 指私法人（如公司）的董事、董事長、總經理等具有代表權之人。
  • 「因執行其職務或為私法人之利益為行為」：
    • 指行為人是在執行職務或為私法人利益的情況下所為的行為。
  • 「致使私法人違反行政法上義務應受處罰者」：
    • 指因該行為導致私法人違反行政法上義務，應受處罰。
  • 「該行為人如有故意或重大過失時」：
    • 指行為人主觀上有故意或重大過失。若僅有輕過失，則不適用本條。
  • 「除法律或自治條例另有規定外」：
    • 指若其他法律或自治條例有特別規定，則從其規定。這是特別法優先的體現。
  • 「應並受同一規定罰鍰之處罰」：
    • 指行為人應與私法人一起受同一規定的罰鍰處罰。這是併罰的規定。
  • 「私法人之職員、受僱人或從業人員」：
    • 指私法人的員工、受僱人、從業人員等。
  • 「如對該行政法上義務之違反，因故意或重大過失，未盡其防止義務時」：
    • 指董事或其他有代表權之人，對該違反有故意或重大過失，且未盡防止義務。
  • 「不得逾新臺幣一百萬元」：
    • 指併罰的罰鍰上限為100萬元。
  • 「但其所得之利益逾新臺幣一百萬元者，得於其所得利益之範圍內裁處之」：
    • 指若行為人所得利益超過100萬元，則可在其所得利益範圍內裁處，不受100萬元上限限制。
為什麼要有這條規定？
  • 督促負責人善盡監督義務：透過併罰，讓負責人重視法規遵循，避免法人違規。
  • 貫徹責任自負：負責人只對自己的故意或重大過失負責，符合責任自負原則。
  • 避免法人脫免責任：若僅處罰法人，負責人可能藉此脫免責任，併罰可避免此漏洞。
  • 符合比例原則：罰鍰有100萬元上限，避免過苛，但若所得利益超過100萬元，則可在其所得利益範圍內裁處。
  • 尊重特別法規定：若其他法律有特別規定，則從其規定，避免法規衝突。
白話文
  • 公司違規被罰，如果公司的董事長或負責人有故意或重大過失，他們也要一起被罰。
  • 如果是員工違規，董事長或負責人因為故意或重大過失沒有盡到防止義務，也要一起被罰。
  • 但這個一起罰的罰鍰最多100萬元，除非他們賺超過100萬元，那就可以罰到他們賺的那麼多。
舉個例子
例1（董事併罰）
  • 某公司董事長明知公司排放廢水違法，仍決定排放，導致公司被罰。 → 董事長有故意，依第15條第1項，應並受同一規定罰鍰處罰。
例2（負責人未盡防止義務）
  • 某公司員工偷排廢水，董事長因重大過失未盡防止義務，導致公司被罰。 → 董事長依第15條第2項，應並受同一規定罰鍰處罰。
例3（罰鍰上限）
  • 某公司負責人因故意導致公司違規，公司被罰50萬元，負責人也被罰50萬元。 → 依第15條第3項，併罰罰鍰不得逾100萬元。
例4（所得利益超過100萬元）
  • 某公司負責人因違規獲得200萬元利益，公司被罰100萬元，負責人也被罰。 → 依第15條第3項但書，得於200萬元範圍內裁處。
一句話總結
  • 私法人違規，其董事或有代表權之人如有故意或重大過失，應並受同一規定罰鍰處罰；併罰罰鍰不得逾100萬元，但所得利益超過100萬元者，得於其所得利益範圍內裁處。
第16條 責任能力
  • 「前條之規定，於設有代表人或管理人之非法人團體，或法人以外之其他私法組織，違反行政法上義務者，準用之。」
這一條是關於？
  • 第15條的「公司違規、負責人一起罰」規定，不只適用於公司，還適用於管委會、合夥、其他私法組織等沒有法人資格的團體！
這一條的核心
  • 本條是《行政罰法》中關於「準用」的規定，目的是將第15條關於私法人併罰的規範，擴張適用於設有代表人或管理人之非法人團體及法人以外之其他私法組織。本條體現了「相同事物應為相同處理」的平等原則，避免因組織型態不同而產生處罰漏洞。
  • 所謂「準用」，是指法律明定將某一條文的規定，適用於原本未規範的事項。本條將第15條的併罰規定，準用於非法人團體（如公寓大廈管理委員會、合夥、宗教團體等）及其他私法組織（如獨資商號、非法人財團等）。這意味著，這些組織違反行政法上義務時，其代表人、管理人或負責人，若因故意或重大過失導致組織違規，也應並受同一規定罰鍰之處罰，且同樣適用100萬元上限及所得利益但書的規定。
  • 從憲法角度來看，本條體現了平等原則與責任自負的精神。無論組織是否具有法人資格，只要其代表人、管理人有故意或重大過失，就應承擔相應的行政責任。同時，本條也保障了人民對法律的可預見性，讓各類組織的負責人知悉其監督責任。在整個行政罰法體系中，本條是處罰對象的補充規定，與第14條的共同違法、第15條的私法人併罰、第17條的機關責任共同構成行政罰的處罰對象體系。
條文拆解
  • 「前條之規定」：
    • 指第15條關於私法人併罰的規定，包括第1項的董事併罰、第2項的負責人未盡防止義務併罰，以及第3項的罰鍰上限與所得利益但書。
  • 「於設有代表人或管理人之非法人團體」：
    • 指未取得法人資格，但設有代表人或管理人的團體，如公寓大廈管理委員會、合夥、宗教團體、同鄉會等。
  • 「或法人以外之其他私法組織」：
    • 指不屬於法人，但具有私法組織型態的團體，如獨資商號、非法人財團等。
  • 「違反行政法上義務者」：
    • 指上述團體或組織違反行政法上義務，應受處罰者。
  • 「準用之」：
    • 指第15條的規定，在此範圍內類推適用。準用的結果，與直接適用相同，但法律效果仍依第15條的規定。
為什麼要有這條規定？
  • 填補處罰漏洞：非法人團體與其他私法組織也可能違反行政法上義務，若無本條，將產生處罰漏洞。
  • 貫徹平等原則：相同事物應為相同處理，不因組織型態不同而異其處罰。
  • 督促負責人善盡監督義務：透過準用第15條，讓非法人團體的負責人也負起監督責任。
  • 符合比例原則：準用第15條的罰鍰上限與所得利益但書，避免過苛。
  • 尊重特別法規定：若其他法律有特別規定，仍從其規定。
白話文
  • 簡單說：第15條規定「公司違規，董事長要一起罰」，這條規定不只適用於公司，還適用於管委會、合夥、獨資商號等沒有法人資格的團體。
  • 也就是說，這些團體的負責人如果有故意或重大過失，也要一起被罰，而且罰鍰上限一樣是100萬元，除非賺超過100萬元。
舉個例子
例1（非法人團體）
  • 某公寓大廈管委會未依規定維護消防設備，違反《公寓大廈管理條例》被罰。 → 依第16條準用第15條，管委會主委如有故意或重大過失，應並受同一規定罰鍰處罰。
例2（合夥）
  • 某合夥商號違反《商業登記法》，被罰。 → 依第16條準用第15條，合夥人如有故意或重大過失，應並受同一規定罰鍰處罰。
例3（獨資商號）
  • 某獨資商號違反《勞動基準法》，被罰。 → 依第16條準用第15條，獨資商號負責人如有故意或重大過失，應並受同一規定罰鍰處罰。
例4（罰鍰上限）
  • 某非法人團體負責人因故意導致團體違規，團體被罰50萬元，負責人也被罰50萬元。 → 依第16條準用第15條第3項，併罰罰鍰不得逾100萬元。
一句話總結
  • 第15條私法人併罰的規定，準用於設有代表人或管理人之非法人團體及法人以外之其他私法組織，其負責人如有故意或重大過失，亦應並受同一規定罰鍰處罰。
第17條 不作為犯與危險前行為之防止義務
  • 「中央或地方機關或其他公法組織違反行政法上義務者，依各該法律或自治條例規定處罰之。」
這一條是關於？
  • 政府機關自己也會違反行政法規！這時候就按照各該法律或自治條例的規定來罰，不會因為它是政府機關就免責！
這一條的核心
  • 本條是《行政罰法》中關於「公法組織處罰」的規定，處理的是中央或地方機關或其他公法組織違反行政法上義務時，應如何處罰的問題。本條體現了「公法組織亦受行政罰法拘束」的原則，打破了傳統「國家不可罰」的觀念，彰顯了法治國原則下「法律之前人人平等」的精神。
  • 本條的核心在於：中央或地方機關，以及其他公法組織（如公法人、公營事業等），若違反行政法上義務，應依各該法律或自治條例的規定處罰之。這裡的「各該法律或自治條例」指的是該機關所違反的具體法規，例如《政府採購法》、《環境影響評估法》等。本條並未特別規定併罰，而是回歸各該法規的處罰規定。這是因為公法組織的處罰涉及機關權限與預算等特殊考量，故授權各該法規依其性質作適當規定。
  • 從憲法角度來看，本條體現了法治國原則與平等原則。國家機關的行為須依法為之，若違反行政法上義務，也應與人民一樣受處罰，不得享有特權。同時，本條也保障了人民對法律的信賴，讓人民知悉機關違規時亦有處罰機制。在整個行政罰法體系中，本條是處罰對象的補充規定，與第14條的共同違法、第15條的私法人併罰、第16條的非法人團體準用共同構成行政罰的處罰對象體系。
條文拆解
  • 「中央或地方機關」：
    • 指中央政府及其所屬機關，以及地方政府及其所屬機關。包括行政機關、立法機關、司法機關、考試機關、監察機關等。
  • 「或其他公法組織」：
    • 指中央或地方機關以外，具有公法性質的組織，如公法人（如農田水利會）、公營事業（如台灣地區自來水公司）、行政法人等。
  • 「違反行政法上義務者」：
    • 指上述機關或組織違反行政法上義務，應受處罰者。
  • 「依各該法律或自治條例規定處罰之」：
    • 指依該機關或組織所違反的具體法律或自治條例的規定處罰。若該法規有特別規定，則從其規定。
為什麼要有這條規定？
  • 貫徹法治國原則：國家機關的行為須依法為之，違反行政法上義務也應受處罰。
  • 體現平等原則：機關與人民一樣，違反行政法上義務時均應受處罰，不得享有特權。
  • 填補處罰漏洞：若無本條，機關違規可能無人受罰，產生處罰漏洞。
  • 尊重各該法規：機關違規涉及權限與預算等特殊考量，故回歸各該法規處罰。
  • 保障人民權益：讓人民知悉機關違規時亦有處罰機制，保障人民權益。
白話文
  • 簡單說：政府機關自己也會違反行政法規！這時候就按照各該法律或自治條例的規定來罰，不會因為它是政府機關就免責。
  • 例如市政府辦理採購違反《政府採購法》，就依該法處罰。
舉個例子
例1（機關違反採購法）
  • 某市政府辦理採購時違反《政府採購法》，被上級機關或審計單位處罰。 → 依第17條，依《政府採購法》規定處罰。
例2（機關違反環評法）
  • 某鄉公所開發案未依法實施環境影響評估，違反《環境影響評估法》。 → 依第17條，依《環境影響評估法》規定處罰。
例3（公營事業違規）
  • 某公營事業違反《水污染防治法》，排放廢水。 → 依第17條，依《水污染防治法》規定處罰。
例4（機關違反自治條例）
  • 某縣政府違反縣議會通過的自治條例。 → 依第17條，依該自治條例規定處罰。
一句話總結
  • 中央或地方機關或其他公法組織違反行政法上義務者，依各該法律或自治條例規定處罰之，不因機關身分而免責。
