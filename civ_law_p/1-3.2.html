1-3.2 總則 - 訴訟標的價額之核定及訴訟費用 - 訴訟費用之計算及徵收

第77條之13 財產權訴訟之裁判費徵收標準（級距累進制）
  • 「因財產權而起訴，其訴訟標的之金額或價額在新臺幣十萬元以下部分，徵收裁判費一千元；逾十萬元至一百萬元部分，每萬元徵收一百元；逾一百萬元至一千萬元部分，每萬元徵收九十元；逾一千萬元至一億元部分，每萬元徵收八十元；逾一億元至十億元部分，每萬元徵收七十元；逾十億元部分，每萬元徵收六十元；其畸零之數不滿萬元者，以萬元計算。」
這一條是關於？
  • 這條是民事訴訟「起訴要繳多少錢」的核心計算公式——官司標的（例如請求的金額）越高，要繳的裁判費也越高， 但不是「一塊錢一塊錢」等比增加，而是隨著級距增加，每萬元的收費率反而稍微降低（從100元遞減至60元），以減輕高額訴訟的負擔。
這一條的核心
  • 本條規定了我國民事訴訟法中最重要、最常用的裁判費計算方式，適用於所有「因財產權而起訴」的案件 （例如請求給付貨款、損害賠償、分割共有物、確認所有權等）。
  • 裁判費是當事人起訴時必須向法院預納的費用，原則上由敗訴方負擔（第78條）， 其計算方式是「分段累進」——先將訴訟標的金額切分成不同級距，每一段級距適用不同的「每萬元收費率」， 最後加總即為總裁判費。
  • 舉例來說，
    • 標的金額在10萬元以下，不論是1萬元還是9萬9999元，一律只收「基本費」1000元（實務上最低收費）。
    • 超過10萬元後，依各級距費率計算。
  • 特別注意的是，各級距的費率並非提高，而是從10萬至100萬元的「每萬元100元」，逐漸下降到10億元以上的「每萬元60元」， 呈現「累進但邊際費率遞減」的特色，以兼顧「使用者付費」與「避免過度阻礙高額訴訟」的立法政策。
  • 最後，不滿1萬元的零頭，無條件進位至1萬元計算（例如12萬3456元，其3456元以1萬元計）。
條文拆解
  • 「因財產權而起訴」：
    • 財產權：指具有經濟利益、得以金錢估價的權利，例如所有權、債權、股權、智慧財產權、租賃權等。
    • 非財產權訴訟（如離婚、親子、名譽回復）不適用本條，另依第77條之14計算（固定裁判費）。
  • 「其訴訟標的之金額或價額」：
    • 金額：當事人請求的具體金錢數額（如「被告應給付原告新臺幣500萬元」）。
    • 價額：請求標的無法直接以金錢表示時（如請求移轉土地所有權、確認專利權存在）， 須依第77條之1核定其交易價額或原告就該標的所得之利益。
  • 「新臺幣十萬元以下部分，徵收裁判費一千元」：
    • 10萬元以下（包括10萬元整），不論實際金額（例如1元、3萬元、10萬元），一律只收1000元。
    • 此為「最低起徵點」，避免小額案件過重負擔（符合小額訴訟之立法精神）。
  • 各級距費率：
    • 逾10萬元至100萬元部分，每萬元徵收100元：例如50萬元，其中10萬元部分收1000元，其餘40萬元每萬元收100元 → 40×100=4000元，總計5000元。
    • 逾100萬元至1000萬元部分，每萬元徵收90元：費率微降。
    • 逾1000萬元至1億元部分，每萬元徵收80元：費率再降。
    • 逾1億元至10億元部分，每萬元徵收70元。
    • 逾10億元部分，每萬元徵收60元：最高級距費率最低。
  • 「其畸零之數不滿萬元者，以萬元計算」：
    • 畸零之數：計算至每一級距時，若有不足1萬元的餘數，該餘數直接視為1萬元。
    • 例如：112萬3456元，計算至100萬元至112萬3456元的「12萬3456元」部分， 其中3456元不滿萬元 → 以1萬元計，故該段為13萬元。此為「無條件進位」，有利於法院（確保至少收到足額費用），但對當事人略有不利。
為什麼要有這條規定？
  • 實現使用者付費原則：司法資源（法官、書記官、法庭、行政人力）需由國家預算支應，起訴者繳納裁判費，可適度分擔成本，避免濫訴。
  • 防止因訴訟費用過高而阻礙訴訟權：若對高額訴訟也適用相同高費率（例如每萬元100元不變），10億元的訴訟將繳納1000萬元裁判費，嚴重違反比例原則。費率遞減可以緩和此問題。
  • 維持訴訟經濟與小額案件之可負擔性：10萬元以下僅收1000元，使小額權利人仍能尋求司法救濟（若收費過高，將違反憲法第16條訴訟權保障）。
  • 簡化計算並確保最低收益：「不滿萬元以萬元計」的規定，可避免逐元計算的繁瑣，並確保法院不會因零頭而損失微薄費用。
白話文
  • 如果你打官司是為了錢（請求給付金錢或跟錢有關的權利），起訴的時候要先算一下標的金額。級距是這樣：
    • 10萬元以內：一律繳1000元。
    • 超過10萬元到100萬元：「超過的部分」每1萬元繳100元。
    • 超過100萬元到1000萬元：「超過的部分」每1萬元繳90元。
    • 超過1000萬元到1億元：「超過的部分」每1萬元繳80元。
    • 超過1億元到10億元：「超過的部分」每1萬元繳70元。
    • 超過10億元：「超過的部分」每1萬元繳60元。
    每一段分開算，加起來就是總裁判費。另外，每段裡面如果有「不到1萬元」的零頭，直接算1萬元。
舉個例子
例1（8萬元）
  • 訴訟標的金額8萬元（在10萬元以下）。
  • → 裁判費：1000元（不因8萬元比10萬元少而打折）。
例2（50萬元）
  • 10萬元以下 → 1000元；超過10萬元至50萬元 = 40萬元 → 每萬元100元 → 40×100=4000元；
  • 總計1000+4000=5000元。→ 裁判費：5000元。
例3（500萬元）
  • 10萬元以下 → 1000元；10萬至100萬（90萬元） → 每萬元100元 → 90×100=9000元；
  • 100萬至500萬（400萬元） → 每萬元90元 → 400×90=36000元；
  • 總計1000+9000+36000=46000元。→ 裁判費：46000元。
一句話總結
  • 財產權官司的裁判費，依標的金額分段累進計算（級距愈高、費率愈低），10萬元以下一律1000元，零頭無條件進位至萬元。
第77條之14 非財產權訴訟之裁判費
  1. 「非因財產權而起訴者，徵收裁判費新臺幣三千元。」
  2. 「於非財產權上之訴，並為財產權上之請求者，其裁判費分別徵收之。」
這一條是關於？
  • 這條規定打官司不是為了錢（例如請求離婚、認領子女、回復名譽）的時候， 起訴要繳的裁判費是固定的「新臺幣三千元」。
  • 如果同一個訴訟裡，同時請求「非財產權」和「財產權」的事項（例如離婚 + 請求剩餘財產分配）， 那麼兩種請求的裁判費要「分開計算、分別徵收」，不能混在一起算。
這一條的核心
  • 本條體現了「不同性質的請求，適用不同的費用計算原則」的基本法理。 並不是所有的民事訴訟都涉及金錢或經濟利益，許多案件的核心是「身分關係」（如婚姻、親子、收養）或「人格權」 （如名譽、姓名、自由）。
  • 這類訴訟的目的不在於獲得金錢賠償，而在於確認或變動一種身分、地位或人格法益。 對於這類訴訟，不宜以「訴訟標的價額」這種經濟概念來計算裁判費（因為身分無價，也無法合理估價）， 因此採取「定額制」——不論案情簡單或複雜，統一徵收新臺幣3000元。
  • 第二項則處理「複合請求」的情形：原告在一次起訴中，同時提出非財產權的主請求（如離婚） 和財產權的附帶請求（如夫妻剩餘財產分配）。
    • 此時，兩種請求的本質與計算基礎完全不同，不能合併計算，必須「分別徵收」——非財產權部分收3000元， 財產權部分則依第77條之13的級距計算其金額或價額，兩者相加即為總裁判費。
條文拆解
第一項
  • 「非因財產權而起訴者」：
    • 非因財產權：指訴訟標的之權利或法律關係，無法以金錢估算其經濟價值，或雖有某種利益但非屬財產上之利益。
    • 常見類型：
      • 身分關係訴訟：離婚、撤銷婚姻、確認婚姻關係存在或不存在、認領子女、否認子女、收養關係終止等（主要依家事事件法，但仍適用本條之裁判費原則）。
      • 人格權訴訟：請求回復名譽（如刊登道歉啟事，但若合併請求損害賠償，則損賠部分屬財產權）、請求更正或刪除網路貼文（名譽權）、請求變更姓名等。
      • 其他非財產請求：如請求為一定行為（單純不行為，無對價），但不包括以金錢給付為替代者。
  • 「徵收裁判費新臺幣三千元」：
    • 三千元：固定金額，不分訴訟繁簡、不分當事人資力（但若有訴訟救助，仍可暫免）。
    • 相較於財產權訴訟最低1000元起跳，非財產權訴訟的起徵點略高（3000元 > 1000元）。
    • 注意：家事事件法對家事非訟事件另有不同費用標準（如聲請監護宣告、輔助宣告），不適用本條。
第二項
  • 「於非財產權上之訴，並為財產權上之請求者」：
    • 非財產權上之訴：指前項所述之非財產訴訟（例如離婚）。
    • 並為財產權上之請求：原告在同一個訴訟程序中，同時（合併）提出一個或多個財產權請求。最典型例子：
      • 請求離婚（非財產） + 請求夫妻剩餘財產分配（財產）。
      • 請求確認親子關係不存在（非財產） + 請求返還不當得利（財產，例如過去代墊的扶養費）。
      • 請求回復名譽（非財產） + 請求賠償精神慰撫金（財產，但精神賠償實務上仍屬財產權請求，因為可轉換為金錢）。
  • 「其裁判費分別徵收之」：
    • 分別徵收：不得將非財產權請求與財產權請求合併計算（例如不能把離婚「無價」變成「0」，然後只算財產部分）。必須：
      • 非財產權部分：依第一項徵收3000元。
      • 財產權部分：依第77條之13，按該財產請求之金額或價額，計算裁判費。
      • 兩者相加，即為總裁判費。
    • 例如：原告起訴請求「離婚」（非財產） + 「請求被告給付剩餘財產分配200萬元」（財產）。
      • 裁判費 = 3000元（離婚） + 200萬元之財產權裁判費（依第77條之13計算：10萬以下1000元 + 90萬×100=9000元 + 100萬×90=9000元， 總計1000+9000+9000=19000元） = 22000元。
為什麼要有這條規定？
  • 避免以金錢量化身分與人格價值：婚姻、親子、名譽等非財產權，若強行以金錢「估價」將極為荒謬（如「離婚一場價值多少？」）。定額制是最符合其本質的計算方式。
  • 防止財產權與非財產權請求之費用混淆：第二項明確區分，避免當事人企圖將財產權請求「包裝」在非財產訴訟中，以規避較高的財產權裁判費（3000元遠低於多數財產權案件的費用）。
  • 維持裁判費制度之公平性：非財產訴訟同樣耗費司法資源，定額3000元可合理分擔成本，又不會過度負擔當事人。
  • 與家事事件法及相關程序調和：本條第一項雖規定3000元，但家事事件法對於家事訴訟事件（如離婚、親子）通常仍予援用，且家事非訟事件另有不同標準，形成體系分工。
白話文
  • 第一項：如果你打官司不是為了錢（例如請求離婚、認小孩、回復名譽），起訴的時候要繳固定的裁判費，就是新臺幣3000元。不管你的案件有多複雜或多簡單，就是3000元。
  • 第二項：如果你在一個訴訟裡面，同時告「非財產」的事（例如離婚）和「財產」的事（例如請對方分給你200萬），那麼兩種請求的裁判費要「分開計算」：非財產的部分收3000元，財產的部分依照前面第77條之13的級距算錢，最後加起來一起繳。
舉個例子
例1（單純離婚）
  • 原告起訴請求判決離婚，未合併請求任何財產給付。
  • → 符合第77條之14第1項，非因財產權而起訴，裁判費3000元。
例2（回復名譽 + 刊登道歉啟事，無賠償）
  • 原告主張被告發表不實言論，請求法院判決被告於報紙刊登道歉啟事（未請求金錢賠償）。
  • → 符合第77條之14第1項，此為名譽權之非財產請求，裁判費3000元。
例3（離婚 + 剩餘財產分配200萬元）
  • 原告起訴請求「離婚」及「被告應給付夫妻剩餘財產分配200萬元」。
  • → 符合第77條之14第2項：非財產部分（離婚）徵收3000元；
  • 財產部分（200萬元）依第77條之13計算：1000元（10萬以下）+ 90萬×100=9000元（10萬至100萬）+ 100萬×90=9000元（100萬至200萬），共19000元；總裁判費 = 3000+19000=22000元。
例4（確認親子關係不存在 + 請求返還不當得利60萬元）
  • 原告請求確認與被告之親子關係不存在（非財產），並請求被告返還過去代墊之扶養費60萬元（財產）。
  • → 符合第77條之14第2項：非財產部分3000元；
  • 財產部分（60萬元）計算：1000元（10萬以下）+ 50萬×100=5000元（10萬至60萬），共6000元；總裁判費9000元。
一句話總結
  • 非財產官司（如離婚、認領、名譽）一律收3000元。
  • 如果同一個官司同時告非財產和財產的事（如離婚 + 分錢），兩種費用分開算、分別繳。
