假扣押假處分之執行 - 總覽

假扣押假處分執行之時間、送達與期限

三十日內聲請執行
債權人「收受」假扣押或假處分裁定後已「逾三十日」者，「不得聲請」執行
  • 收受：指「送達」。
  • 逾三十日：自「送達」予債權人之「次日」起算。
  • 不得聲請：逾期即「失權」。須「重新聲請」假扣押或假處分（另繳裁判費）。
原則：先執行、後送達
假扣押或假處分之執行，應於假扣押或假處分之裁定「送達同時」或「送達前」為之
  • 「應」：強制規定——執行「必須」在「送達前」或「送達同時」為之。
    • 不得「送達後」始執行？實務上仍可，但「突襲性」降低。
  • 「送達前」：即「先查封、後送達」（避免債務人「脫產」）。
無法送達：應撤銷
前項送達前之執行，於執行後「不能送達」，且債權人「無法公示送達」者，應「撤銷」其執行
  • 「不能送達」：如「債務人住居所不明」、「遷移」。
  • 「無法公示送達」：包括：
    • 「未聲請」公示送達：「債權人」未依民事訴訟法聲請公示送達。
    • 公示送達「聲請被駁回」確定：債權人公示送達之聲請經法院裁定「駁回確定」。
  • 「應撤銷」：強制義務。 一旦「裁定無法送達」，債務人法院須「撤銷查封」或「撤銷假扣押」。
例1.
  • 甲於7月1日「收受」假扣押裁定，至8月5日始「聲請執行」（已逾30日）。
  • 法院「駁回」其執行聲請。
  • → 債權人「收受」假扣押或假處分裁定後已「逾三十日」者，「不得聲請」執行
例2.
  • 甲對乙聲請假扣押，法院裁定「准許」。
  • 甲於「裁定送達乙之前」，即「聲請執行」查封乙之存款。
  • → 假扣押之執行，應於假扣押之裁定「送達同時」或「送達前」為之
例3.
  • 甲於送達前執行查封乙之財產。
  • 但法院「無法送達」裁定予乙（乙已遷移），甲「未聲請公示送達」。
  • 法院「撤銷」查封。
  • → 送達前之執行，於執行後「不能送達」，且債權人「無法公示送達」者，應「撤銷」其執行
例4.
  • 甲「聲請公示送達」，但法院「駁回」（如「乙之住址仍可得確定」）。
  • 法院亦應「撤銷」查封。
  • → 「無法公示送達」：包括：債權人公示送達之聲請經法院裁定「駁回確定」
一句話總結
  • 債權人「收受」假扣押或假處分裁定後已「逾三十日」者，「不得聲請」執行
  • 執行應於裁定送達同時或之前為之。
  • 送達前執行後若無法送達且未聲請公示送達，應撤銷執行。

假扣押假處分裁定經廢棄或變更後之撤銷執行

假扣押、假處分或定暫時狀態之處分裁定經「廢棄或變更」已「確定」者
  • 「廢棄」：上級法院「撤銷」原裁定（如「原准許假扣押之裁定廢棄」）。
  • 「變更」：上級法院「改變」原裁定內容（如「原准許100萬元，變更為50萬元」）。
  • 「已確定」：該廢棄或變更之裁定「不得再抗告」。
於其廢棄或變更之範圍內，法院得「依聲請」「撤銷」其已實施之執行處分
  • 廢棄或變更之範圍內：
    • 全部廢棄：全部執行處分均「失所附麗」→ 應「全部撤銷」。
    • 部分變更：僅「超過變更後範圍」之執行處分應撤銷。如「原查封100萬元財產，變更為50萬元」→ 僅撤銷「超過50萬元部分」。
  • 「依聲請」：須由「債務人」或「利害關係人」主動聲請（法院不得依職權）。
  • 撤銷已實施之執行處分：如「撤銷查封」、「撤銷扣押」、「塗銷查封登記」。
例1.
  • 甲對乙之假扣押裁定，經抗告法院「廢棄確定」。
  • 乙得「聲請」執行法院「撤銷」全部查封。
  • → 假扣押裁定經「廢棄」已「確定」者，法院得「依聲請」「撤銷」其已實施之執行處分
例2.
  • 原假扣押裁定准許「查封100萬元」之財產，經抗告法院「變更」為「僅得查封50萬元」確定。
  • 乙得「聲請」撤銷「超過50萬元部分」之查封。
  • → 假扣押裁定經「變更」已「確定」者，法院得「依聲請」，於變更之範圍內，「撤銷」其已實施之執行處分
例3.
  • 假扣押裁定「尚未確定」（仍在抗告中），債務人不得依本條聲請撤銷執行（須俟確定）。
  • → 裁定未確定，不得撤銷
一句話總結
  • 裁定經廢棄或變更確定後，於其範圍內，執行法院得「依聲請」撤銷已實施之執行處分。

自助行為後經法院命為假扣押假處分之管收

債權人「自助行為」後，經法院命為假扣押或假處分者，法院得「管收」債務人或為「其他限制自由之處分」
  • 「自助行為」：債權人於「急迫」情形下，自行「拘束債務人之自由」或「押收其財產」，並「即時」聲請法院處理。
  • 經法院命為假扣押或假處分：法院認「自助行為合法」且「有保全必要」，命為假扣押或假處分（即承認「自助行為」合法）。
  • 得管收：法院有裁量權。並應依照管收之規定程序（管收要件）。
  • 其他限制自由之處分：如「限制住居」。
例1.
  • 甲對乙有債權，乙準備搭機出境，甲「依民法第151條」將乙「暫時留置」並聲請法院處理。
  • 法院「命為假扣押」，執行法院認乙「有逃亡之虞」，「管收」乙。
  • → 債權人「自助行為」後，經法院命為假扣押處分者，法院得「管收」債務人
例2.
  • 甲拘束乙之自由後聲請法院處理，法院命為假處分。
  • 執行法院認「無管收必要」，得「限制乙住居」（如不得離開台北市）。
  • → 債權人「自助行為」後，經法院命為假處分者，法院得「管收」債務人或為「其他限制自由之處分」
一句話總結
  • 債權人「自助行為」後，經法院命為假扣押或假處分者：
    • 法院得「管收」債務人或為「其他限制自由之處分」。

假扣押收取金錢及分配金額之提存

因執行「假扣押」收取之金錢，及依分配程序「應分配」於假扣押債權人之金額，「應提存之」
  • 因執行假扣押收取之金錢：
    • 執行假扣押：依假扣押裁定所為之「扣押」或「收取」行為。
    • 收取之金錢：如「銀行存款」、「債務人對第三人之金錢債權」。
  • 依分配程序應分配於假扣押債權人之金額：
    • 分配程序：若債務人財產「不足清償」全部債權，執行法院「製作分配表」分配價金。
    • 應分配於假扣押債權人之金額：假扣押債權人依「分配表」應受分配之數額。
  • 應提存之：
    • 應：強制義務。 法院「必須」提存（不得直接發給債權人）。
    • 提存：將金錢「存入」法院提存所，待「本案訴訟確定」後再行「領取」。
例1.
  • 甲對乙聲請假扣押，法院「扣押」乙在A銀行之存款100萬元。
  • 該100萬元應「提存」於法院提存所。
  • → 因執行「假扣押」收取之金錢，「應提存之」
例2.
  • 乙之財產經拍賣得款1000萬元。
  • 參與分配之債權人中，甲為「假扣押債權人」，分配表應分配甲200萬元。
  • 該200萬元應「提存」（不得直接發給甲）。
  • → 依分配程序「應分配」於假扣押債權人之金額，「應提存之」
例3.
  • 甲對乙之「本案訴訟」勝訴確定，甲得「聲請」法院將「提存之100萬元」發給甲。
  • → 提存物於勝訴後領取
一句話總結
  • 因「假扣押」收取之金錢及應分配予假扣押債權人之金額，「應提存」之。

假扣押動產之拍賣與提存

假扣押之動產，得拍賣，提存其價金
假扣押之動產，如有價格減少之虞或保管需費過多時
  • 假扣押之動產：依假扣押裁定「查封」之動產（如「車輛」、「機械」、「珠寶」、「生鮮」）。
  • 價格減少之虞：如「易腐壞」、「折舊」、「市場價格下跌」。
  • 保管需費過多：如「倉儲費」、「保險費」、「維護費」、「停車費」。
法院得因聲請或依職權「拍賣」之，「提存」其賣得金
  • 因聲請：債權人或債務人任一方得「主動」聲請。
  • 依職權：法院得「主動」為之（無須聲請）。
  • 拍賣：應定拍賣期日並「公告」（準用動產拍賣程序）。
  • 提存：拍賣所得價金「提存」於法院提存所。
例1.
  • 甲對乙聲請假扣押，查封乙之「一批海鮮」（生鮮食品）。
  • 因海鮮「易腐壞」，法院「依職權」定期拍賣，賣得10萬元，提存於法院。
  • → 假扣押之動產，如有價格減少之虞，法院得依職權「拍賣」之，「提存」其賣得金
例2.
  • 查封乙之「大型機械」，每月保管費（倉儲）5萬元，而機械價值僅50萬元，保管費「過高」。
  • 債權人甲「聲請」拍賣，法院「定期拍賣」，賣得40萬元，提存。
  • → 假扣押之動產，如保管需費過多，法院得依職權「拍賣」之，「提存」其賣得金
例3.
  • 查封乙之「舊型電腦」，因技術「快速淘汰」，有「價格減少之虞」。
  • 債務人乙「聲請」拍賣，法院拍賣後提存價金。
  • → 假扣押之動產，如有價格減少之虞，法院得依職權「拍賣」之，「提存」其賣得金
一句話總結
  • 「假扣押之動產」若有價格減少之虞或保管需費過多時，法院得依聲請或依職權定期「拍賣」，「提存」其賣得金。

假扣押執行於債權或其他財產權之方法與準用

對於「債權」或其他財產權執行「假扣押」者
  • 「債權」：如「存款債權」、「薪資債權」、「應收帳款」。
  • 「其他財產權」：如「專利權」、「商標權」、「股權」、「礦業權」。
法院應分別發「禁止處分清償」之命令
  • 「應」：強制義務。
  • 「禁止處分」：禁止債務人「轉讓」、「設定負擔」。
  • 「禁止清償」：禁止第三人「向債務人清償」。
並準用對於其他財產權執行之規定
包括：
  • 「扣押命令」、「收取命令」、「移轉命令」、「支付轉給命令」
  • 「拍賣或變賣」、「通知登記機關」
例1.
  • 甲對乙聲請假扣押，欲扣押乙在A銀行之「存款債權」。
  • 執行法院發「禁止清償」命令予A銀行（不得向乙付款），及「禁止處分」命令予乙（不得轉讓該存款）。
例2.
  • 甲對乙之「專利權」聲請假扣押。
  • 執行法院發「禁止處分」命令予乙（不得轉讓專利權），並「通知」經濟部智慧財產局辦理「扣押登記」。
例3.
  • 甲對乙之「薪資債權」聲請假扣押。
  • 執行法院發「禁止清償」命令予雇主（不得將薪資支付予乙），並「禁止處分」命令予乙（不得轉讓薪資債權）。
一句話總結
  • 對債權或其他財產權執行假扣押時，應發禁止處分清償命令，並準用其他財產權執行規定。

假扣押執行程序之概括準用

假扣押之執行，除本章有規定外，準用關於動產、不動產、船舶及航空器執行之規定
  • 假扣押之執行：即依「假扣押裁定」所為之「保全執行」程序。
  • 「準用」：即「性質相容」者，得「比照適用」——如「查封程序」、「拍賣程序」、「保管程序」等。
例1.
  • 假扣押債務人乙之「汽車」，第五章「無」查封方法之特別規定。
  • 「準用」動產執行之「查封」規定（第46條、第47條）。
例2.
  • 假扣押乙之「土地」，第五章「無」鑑價規定，。
  • 「準用」不動產執行之「鑑價」規定（第80條）。
例3.
  • 假扣押執行之「提存」——第五章「有」特別規定（第133條、第134條）。
  • 應「優先適用」第133條、第134條，無庸「準用」其他章節。
一句話總結
  • 假扣押之執行，除本章有規定外，準用關於動產、不動產、船舶及航空器執行之規定。

假處分執行之管理人占有

假處分裁定，應選任管理人管理系爭物者，於執行時，法院應使管理人占有其物
  • 「應選任管理人」：裁定「主文」載明「選任管理人」。
  • 「管理系爭物」：如「管理公司」、「管理房屋」、「管理財產」。
  • 「使管理人占有」：執行法院應「解除」債務人（或第三人）之占有，將系爭物「交付」管理人。
例1.
  • 甲對乙公司聲請假處分，法院裁定「選任丙為管理人，管理乙公司之經營權」。
  • 執行法院應「解除」乙公司原經營者之占有，將公司「交付」管理人丙占有。
例2.
  • 甲對乙之房屋聲請假處分，法院裁定「選任丙管理人管理該房屋」。
  • 執行法院應「使丙占有」該房屋。
例3.
  • 法院裁定選任管理人，但執行法院「未」使管理人占有系爭物（仍由債務人占有），管理人無法管理。
一句話總結
  • 假處分裁定應選任管理人管理系爭物者，執行時法院應使管理人占有其物。

行為或不行為假處分之送達執行

假處分裁定，係命令或禁止債務人「為一定行為」者，法院應將該裁定「送達於債務人」
  • 「命令為一定行為」：如「命令債務人應容忍他人進入修繕」。
  • 「禁止為一定行為」：如「禁止債務人出售特定土地」、「禁止債務人拆除房屋」。
  • 應將該裁定「送達於債務人」：送達後，債務人「知悉」其義務，若「違反」——得「處怠金」。
例1.
  • 甲對乙聲請假處分，法院裁定「禁止乙出售A地」。
  • 執行法院將該裁定「送達」予乙。
  • 乙「知悉」後，若仍出售，甲得「聲請」法院「處以怠金」。
例2.
  • 甲對乙聲請假處分，法院裁定「命令乙應容忍甲進入修繕管線」。
  • 執行法院將裁定「送達」予乙。
一句話總結
  • 假處分裁定係命令或禁止債務人為一定行為者，執行法院應將該裁定送達於債務人。

不動產權利假處分之揭示執行

假處分裁定，係「禁止」債務人設定、移轉或變更「不動產上之權利」者，法院應將該裁定「揭示」
  • 「設定」：如「設定抵押權」、「設定地上權」。
  • 「移轉」：如「出售」、「贈與」。
  • 「變更」：如「變更權利內容」。
  • 「不動產上之權利」：如「所有權」、「抵押權」、「地上權」。
  • 「揭示」：包括「送達」予債務人、「通知地政機關」辦理「假處分登記」、「張貼公告」於不動產所在地。
  • 違反假處分之效果：若債務人「仍為處分」，該處分「對債權人不生效力」。
例1.
  • 甲對乙聲請假處分，法院裁定「禁止乙出售A地」。
  • 執行法院「通知」地政機關辦理「假處分登記」，並「送達」裁定予乙。
  • 乙「知悉」後，若仍出售，甲得「聲請」法院「處以怠金」。
例2.
  • 執行法院除「通知地政機關」外，並於A地「張貼公告」，載明「本土地已受假處分，禁止處分」。
一句話總結
  • 假處分裁定係禁止債務人設定、移轉或變更不動產上之權利者，執行法院應將該裁定揭示（通知地政機關登記）。

假處分執行之概括準用規定

假處分之執行，除前三條規定外，準用關於假扣押、金錢請求權及行為、不行為請求權執行之規定
  • 「前三條」：管理人占有、送達、揭示。此三條為「特別規定」，應「優先適用」。
  • 「假扣押」：查封、拍賣、提存等。
  • 金錢請求權：對債權及其他財產權之執行。
  • 行為、不行為請求權：代履行、怠金、除去結果。
例1.
  • 假處分係「查封」債務人之動產（如「車輛」）。
  • 第137-139條「無」查封之特別規定。
  • 「準用」假扣押之「查封」規定（第136條準用動產執行）。
例2.
  • 假處分係「禁止」第三人向債務人清償「存款債權」。
  • 「準用」金錢請求權之「扣押命令」
例3.
  • 假處分係「命令」債務人「容忍」他人進入修繕。
  • 債務人「違反」，債權人得「聲請」法院「處以怠金」——即「準用」準用行為不行為。
一句話總結
  • 假處分之執行，除前三條規定外，準用關於假扣押、金錢請求權及行為、不行為請求權執行之規定。
