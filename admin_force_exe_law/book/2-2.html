關於金錢請求權之執行 - 對於動產之執行 - 總覽

動產強制執行之方法

動產之強制執行，以查封、拍賣或變賣之方法行之
  • 動產：即「土地及其定著物」以外之「物」，且「可以移動」者。 包括：汽車、機車、家具、家電、古董、珠寶、現金等。
  • 「查封」為「前置保全程序」，後續「拍賣」或「變賣」為「變價程序」。
    • 查封後，原則上應「拍賣」；例外始得「變賣」。
一句話總結
  • 強制執行動產，必須先查封，再以拍賣（原則）或變賣（例外）方式換成現金清償債務。

動產查封之執行主體與協助

查封動產，由執行法官命「書記官督同執達員」為之。必要時得請有關機關或專家協助
  • 查封動產：指對債務人之動產實施「查封」行為，即「將該動產置於國家公權力支配之下」之保全處分。
  • 由執行法官命：由民事執行處之法官（司法事務官亦得為之）核發查封命令。
  • 書記官督同執達員為之：由書記官監督執達員之執行行為，並製作「查封筆錄」。
  • 必要時得請有關機關或專家協助：例如：
    • 債務人或第三人抗拒查封（請警察協助）。
    • 查封物為珠寶、古董，需請鑑定專家協助鑑定估價。
一句話總結
  • 查封動產由法官（或司法事務官）下令、書記官監督、執達員執行。
  • 必要時可請警察、公會或專家來協助。

動產查封之占有取得與公示方法

查封動產，由執行人員「實施占有」
  • 實施占有：指將該動產「置於執行法院之實力支配下」，具體方式包括：
    • 將動產「搬離」現場（如搬至法院倉庫）。
    • 將動產「留置」於現場但由執行人員控制（如派人看守）。
    • 將動產「交由保管人」保管（如債務人、第三人）。
將查封物交付保管者，應「標封」、「烙印」或實施其他「足以公示查封」之適當方法
  • 交付保管：指查封物「未搬離」現場，而「交由他人保管」之情形。保管人通常為「債務人本人」（最常見）或「第三人」（如倉庫業者、便利保管之人）。
  • 標封：即貼上「封條」，封條上載明「臺灣○○地方法院查封封條」字樣及日期。為最常用有效之公示方法。
  • 烙印：用燒熱之金屬印模於查封物上燙印記號（常見於木材、機械）。
  • 其他「足以公示查封」之適當方法：須「足以使第三人知悉」該物已遭查封。例如於查封物明顯處張貼「查封公告」。
一句話總結
  • 查封必須實際占有動產。
  • 若不搬走，須貼封條、烙印等公示方法讓外界知悉，必要時可合併使用。

查封處所之檢查進入權與在場人員

查封時，得檢查、啟視債務人居住所、事務所、倉庫、箱櫃及其他藏置物品之處所
  • 查封時，執行人員可以「檢查」和「打開」債務人的住家、辦公室、倉庫、櫃子、箱子等 「可能藏東西的地方」，來找可以查封的財產。
  • 此項權限之行使，須以「查封動產」為目的，不得為「無關」之搜索。
查封時，如債務人不在場，應命其「家屬」或鄰右「有辨別事理能力」者到場。必要時，得請警察到場
  • 應命：強制規定，執行人員須找見證人。
  • 家屬：與債務人同住之親屬（不限於民法上之家屬）。
  • 鄰右：鄰居或附近之人。
  • 必要時，得請警察到場：例如債務人或其家屬「抗拒」查封、現場有「暴力衝突」之虞、須「強制開啟」門鎖或箱櫃。
例1.
  • 執行人員至債務人甲之住處查封，發現甲之客廳有上鎖之抽屜。
  • 執行人員「啟視」該抽屜，發現內有現金及金飾，予以查封。 → 執行查封時，得啟視債務人箱櫃來找可以查封的財產
例2.
  • 執行人員至乙之住處查封，乙不在場。
  • 執行人員命乙之配偶（有辨別事理能力）到場，並於查封筆錄上簽名見證。 → 執行查封時，如債務人不在場，應命其「家屬」到場見證
例3.
  • 執行人員至丙之倉庫查封，丙及其家屬拒絕開門，且態度激動。
  • 執行人員即請管區警察到場，協助維持秩序及強制開啟倉庫。 → 執行查封時，如有必要，得請警察到場
一句話總結
  • 執行人員可進入債務人處所並打開箱櫃搜查財產。
  • 債務人不在須找家屬或鄰居見證；必要時可請警察協助。

動產查封之比例原則（禁止超額查封）

查封動產，以其價格「足以清償債權額及費用」者為限
  • 價格：指查封物之「客觀交易價值」或「市場價格」。執行名義所載之「本金」
  • 債權額：包括執行名義所載之「本金」、計算至查封時之「利息」及「違約金」（須有執行名義依據）。
  • 費用：指債務人應負擔之費用。 包括執行費、鑑價費、登報費、搬運費、將來可能發生之拍賣費用、變賣費用。
  • 為限：表示「禁止超額查封」，查封物之總值不得「超過」債權額及費用之總和。
    • 若超過，債務人得聲明異議，請求法院撤銷超額部分。
例1.
  • 甲欠乙100萬元（含利息及費用共計120萬元）。
  • 執行法院查封甲之汽車一輛（市價約80萬元）及現金40萬元，合計120萬元。 → 查封總值未超過債權額及費用
例2.
  • 丙欠丁50萬元（含費用共計60萬元）。執行法院查封丙之古董家具（市價200萬元）。
  • 查封物價值遠超過債權額及費用，丙得聲明異議請求撤銷超額部分。
一句話總結
  • 查封動產的總價值，必須以剛好足夠清償債權金額及費用為限，禁止超額查封。

無執行實益之禁止查封與撤銷查封

應查封動產之賣得價金，清償「強制執行費用」後，「無賸餘之可能」者：「不得查封」
  • 應查封動產：指執行法院「擬」查封（還沒查封）之動產。
  • 賣得價金：「預估」拍賣或變賣可能獲得之金額。
  • 清償強制執行費用後：先扣除「執行費用」（鑑價費、登報費、搬運費等）。
  • 無賸餘之可能：拍賣價金 ≤ 執行費用（即拍賣所得連費用都不夠付）
  • 不得查封：強制禁止，法院不得為查封行為。
查封物賣得價金，於「清償優先債權及強制執行費用」後，「無賸餘之可能」者：「應撤銷查封」
  • 查封物賣得價金：指「已查封」，而「預估」可賣得之價金。
  • 優先債權：對該動產有「優先受償權」之債權（如質權人、留置權人、稅捐優先權）。
  • 強制執行費用：鑑價費、登報費、搬運費等。
  • 無賸餘之可能：拍賣價金 ≤（優先債權 + 執行費用）
  • 應撤銷查封：強制義務，法院須立即撤銷查封（啟封、塗銷相關登記）。將查封物之占有返還予債務人。
債權人負擔費用之例外：前二項情形，法院應先「詢問債權人」之意見，如債權人聲明「願負擔其費用」者：得「續行查封拍賣」
  • 詢問債權人：法院須先徵詢債權人（通常為聲請執行之債權人）之意見。
  • 願負擔其費用：債權人「明示」願承擔不足之費用（即願意賠錢拍賣）。
    • 不足之費用：查封物賣得價金減去優先債權後，不足支付強制執行費用者。
  • 續行查封拍賣：若債權人同意負擔，則「不得查封」或「應撤銷查封」之規定即不適用，法院得續行查封拍賣。
例1.
  • 甲對乙有債權50萬元，執行法院擬查封乙之舊機車一輛。
  • 經查該機車市價僅值1萬元，而預估執行費用（鑑價、登報、搬運）約1.5萬元。 賣得價金清償費用後已無賸餘。
  • → 應查封動產之賣得價金，清償「強制執行費用」後，「無賸餘之可能」者：「不得查封」
例2.
  • 執行法院查封丙之錄影設備一批，市價約10萬元。
  • 但該設備上設有質權（優先債權）8萬元，預估執行費用3萬元。拍賣價金清償優先債權及費用後已無賸餘。
  • → 查封物賣得價金，於「清償優先債權及強制執行費用」後，「無賸餘之可能」者：法院「應撤銷查封」，返還設備予丙
例3.
  • 延續例1，債權人甲向法院表示「即使拍賣價金不足支付費用，我願意負擔該費用」。
  • 法院得續行查封拍賣。 → 債權人聲明「願負擔其費用」者：得「續行查封拍賣」
一句話總結
  • 查封拍賣若連費用和優先債權都不夠付：
    • 法院「不得查封」或「應撤銷查封」。
    • 但若債權人願意貼錢，則可續行。

查封之效力範圍與禁止處分

查封之效力及於查封物之天然孳息
  • 天然孳息：指「依物之用法所收穫之出產物」。如：果樹之果實、動物之產物（牛乳、羊毛、小牛）、土地之產物（農作物）。
  • 及於：查封效力自動擴張至天然孳息，無須另行查封。
    • 不包括「法定孳息」（如租金、利息）——法定孳息另依其他程序處理（如收取命令）。
查封後，債務人就查封物所為「移轉」、「設定負擔」或「其他有礙執行效果」之行為，「對於債權人不生效力」
  • 查封後：指查封行為「完成」之後（如貼封條、烙印）。
  • 移轉：例如買賣、贈與、交換。
  • 設定負擔：例如設定抵押權、質權、留置權。
  • 其他有礙執行效果之行為：例如毀損、隱匿、拋棄。
  • 對於債權人不生效力：該行為在「債權人與債務人間」不生效力，債權人仍得就查封物拍賣受償。
    • 若第三人「善意取得」查封物，則可能受民法保護，此時執行法院僅能對債務人求償。
查封後，第三人未經允許「占有查封物」或「其他有礙執行效果之行為」者，法院得「依職權或依聲請排除之」
  • 第三人：指「非債務人」之第三人（如債務人之友人、承租人）。
  • 未經允許：第三人須「事先」取得法院同意始得占有或使用查封物。
  • 依職權或依聲請：法院得「主動」排除（如強制取回查封物）。債權人得「請求」法院排除。
  • 排除之：包括「強制搬離」、「取回占有」、「除去障礙物」等。
例1.
  • 執行法院查封債務人甲之果園（果樹），查封後果樹長出水果。
  • 該水果亦屬查封效力所及，甲不得私自採收出售。 → 查封之效力及於查封物之「天然孳息」
例2.
  • 執行法院查封乙之汽車後，乙將該車出售予丙。
  • 嗣後法院拍賣該車，丙不得主張「車已賣給我」而拒絕交付，該買賣行為對債權人無效。 → 查封後，債務人就查封物所為「移轉」，「對於債權人不生效力」
例3.
  • 執行法院查封丁之電視，查封後丁之友人戊未經法院允許將電視搬至自己家中。
  • 法院依職權命戊返還電視，戊拒不返還，法院得強制取回。
  • → 查封後，第三人未經允許「占有查封物」，法院得「依職權或依聲請排除之」
一句話總結
  • 查封效力及於天然孳息。
  • 債務人對查封物的處分對債權人無效。
  • 第三人妨礙執行時，法院可依職權或依聲請排除之。

查封時應酌留債務人及家屬生活必需物

查封時，應酌留債務人及其「共同生活之親屬」2個月間「生活所必需」之食物、燃料及金錢
  • 應酌留：強制義務，法院「必須」保留，不得省略。
  • 共同生活之親屬：與債務人同住且「共同維持生計」之配偶、子女、父母、兄弟姐妹等。
  • 生活所必需：指維持「基本生存」所需之最低限度。
前項「2個月」期間，法官得審核債務人家庭狀況伸縮之。「但不得短於1個月或超過3個月」
  • 審核債務人家庭狀況：考量共同生活親屬之人數、有無年幼、年老、患病、殘障等需特殊照顧、有無其他收入來源。
  • 最低1個月：無論如何不得少於1個月。
  • 最高3個月：不得超過三個月。
例1.
  • 執行法院查封債務人甲之家中財物，甲與配偶及一名未成年子女同住。
  • 法院估算甲一家三口兩個月之食物、燃料及必要生活費共計6萬元，即保留6萬元現金及米、油、瓦斯等物資。
  • → 法院應酌留債務人及其「共同生活之親屬」2個月間「必要生活費」
例2.
  • 債務人乙單身，無家屬同住，且另有工作收入。
  • 執行法官審核後認乙之生活需求較低，將酌留期間縮短為一個月。
  • → 法官得審核債務人家庭狀況縮短酌留生活費期間，最短不得少於1個月
例3.
  • 執行法院查封丁之冰箱及全部現金，未保留任何食物或金錢予丁及其家屬。
  • → 法院未酌留必要之生活費，丁得聲明異議
一句話總結
  • 查封時必須給債務人保留2個月的必要生活費。
  • 法院得視情況調整，但最短不得少於1個月，最多不得超過3個月。

禁止查封之物與例外許可查封

以下物品不得查封：
  1. 生活必需之衣服、寢具及其他物品
  2. 職業、教育上所必需之器具、物品
  3. 勳章或其他「榮譽象徵」的物品
  4. 祖先遺像、牌位等「祭祀禮拜」物品
  5. 未與土地分離之天然孳息「不能於一個月內收穫者」
  6. 尚未發表之發明或著作
  7. 防災或安全設備
例外但書：1.不查封「顯失公平」2.債務人同意查封
  1. 不查封「顯失公平」：法院需斟酌債權人及債務人狀況、債權額與查封物價值。
    • 依債權人聲請，查封其全部或一部：須由「債權人」聲請，法院不得依職權為之。
  2. 債務人同意查封：若債務人自願同意查封，則無是否「顯失公平」之問題。
例1.
  • 乙為木匠，其所有之電鋸、刨刀等工具，為其賴以維生之生財器具。執行法院不得查封。
  • → 職業所必需之器具、物品，不得查封
例2.
  • 丁欠債500萬元，但其擁有價值300萬元之限量古董縫紉機（職業工具）。
  • 債權人聲請查封該縫紉機，並主張丁另有其他簡單工具仍可維生，若不得查封對債權人顯失公平。
  • 執行法院審酌後認有顯失公平，准予查封。
  • → 不查封「顯失公平」，法院得「依債權人聲請」而查封
一句話總結
  • 生活必需、職業工具、勳章、祭祀物、未成熟農作、未發表創作、安全設備物品，原則上不得查封
  • 但若顯失公平或債務人同意，可例外查封。

查封筆錄與查封物品清單之作成

查封時，書記官應作成「查封筆錄」及「查封物品清單」
  • 查封筆錄：記載查封過程之正式文書。
  • 查封物品清單：逐項記載查封物之明細表。
查封筆錄，應載明下列事項：
  1. 為查封原因之權利
    • 即「執行名義」。 例如「確定判決」、「本票裁定」等，使查封有法律依據。
  2. 動產之所在地、種類、數量、品質及其他應記明之事項
  3. 債權人及債務人
  4. 查封開始及終了之日時
    • 如「114年7月10日上午9時30分起至11時15分止」
  5. 查封之動產保管人
    • 查封物交由何人保管（通常為債務人本人或第三人）。
  6. 保管方法
    • 例如「由債務人保管」、「置於法院倉庫」、「由第三人保管」等。
查封筆錄應有「查封人員簽名」，如有查封「保管人」、「見證人」者，亦應簽名
  • 查封人員簽名：執行法官/司法事務官、書記官、執達員應於查封筆錄簽名。
  • 保管人：受託保管查封物之人。
  • 見證人：查封時債務人不在場時，被請到場之「家屬」或「鄰居」見證人。
例1.
  • 執行法院查封債務人甲之汽車及電視，書記官製作查封筆錄，載明： 執行名義（確定判決）、查封時間、地點、保管人（甲本人）、 保管方法（甲保管，不得移轉）。
  • 並製作清單逐項記載汽車廠牌型號、電視品牌尺寸。執行人員及甲均簽名。
例2.
  • 查封時債務人乙不在場，書記官請乙之配偶到場見證，並於查封筆錄簽名。
  • → 如有查封「見證人」者，亦應簽名
一句話總結
  • 查封時書記官要製作詳細筆錄及查封物品清單。
  • 筆錄載明執行名義、標的物、當事人、時間、保管人及方法，並由在場人員簽名確認。

查封時間之限制與夜間及假日執行之例外

「假日」、「夜間」不得進入「有人居住之住宅」實施查封
  • 假日：星期日或其他休息日。包括國定假日、補假、彈性放假、天然災害停止上班日等。
  • 夜間：日出前、日沒後。
  • 不得進入：禁止「進入」住宅，即不得於上開時間「侵入」債務人住宅。
  • 有人居住之住宅：包括「住家」、「公寓」、「透天厝」等供人居住之處所。
    • 不包括「無人居住」之倉庫、廠房、空屋。
  • 實施查封：包括檢查、啟視、貼封條、搬運等行為。
例外情況1：有急迫情事，經執行「法官許可」者，不在此限
  • 急迫情事：例如債務人正在搬運查封物準備脫產、查封物有立即毀損、滅失之虞。
  • 經執行法官許可：須由執行法官「事前」許可（書面或口頭），司法事務官無此權限。
  • 許可之命令，應於查封時提示債務人： 執行人員應向債務人「出示」該命令，使其知悉夜間或假日查封之合法性。
例外情況2：「日沒前已開始」為查封行為者，「得繼續」至日沒後
  • 若查封行為於「日落前」已「合法開始」，則即使已日落，仍得「繼續」完成，無須另經許可。
例1.
  • 執行法院獲知債務人丙將於當晚搭機出境，且其家中藏有大量現金。
  • 執行法官於「夜間」許可進入丙之住宅查封，並於查封時向丙提示許可命令。
  • → 有急迫情事，經執行法官許可者，不在此限。執行人員應向債務人「出示」許可命令
例2.
  • 執行法院於「下午4時30分」（日落前）進入債務人丁之住宅查封。
  • 至「晚上6時30分」（日沒後）仍未完成，繼續執行至完畢。
  • → 「日沒前已開始」為查封行為者，「得繼續」至日沒後
一句話總結
  • 假日及日出前日落後不得進入「有人居住」之住宅查封。
    • 有急迫且經法官許可例外，許可命令須提示債務人。
    • 日落前已開始可續行。

拍賣期日之指定與期間限制

查封後，執行法官應「速定拍賣期日」
  • 查封後：查封程序「完成」之後。
  • 拍賣期日：實際進行拍賣之「日期」及「時間」。
查封日至拍賣日期間：「最短7天，最長1個月」
  • 最短7天：自「查封日」之「次日」起算，至「拍賣日」之前一日，至少滿7日。
    • 例如查封日為7月10日，拍賣日最早為7月17日。
  • 最長1個月：例如查封日為7月10日，拍賣日最遲不得超過8月10日。
例外情況1：「經債權人及債務人之同意」，「迅速拍賣」者
  • 須「雙方」均同意7日內迅速拍賣。
例外情況2：「查封物之性質特殊」或有「不得已之事由」者，不在此限
  • 查封物之性質特殊：
    • 例如易腐敗之農產品、鮮花、冷凍食品、有保存期限之物，得於查封後「7天內」拍賣。
    • 例如須「專業鑑價」、「組裝測試」、「大型機械拆解」等需耗時準備，得於查封後「1個月後」拍賣。
  • 不得已之事由：如天災、鑑定人無法配合而延後。
例1.
  • 7月10日查封，債權人甲與債務人乙均「書面同意」於7月12日拍賣。
  • → 「經債權人及債務人之同意」，得於7日內「迅速拍賣」
例2.
  • 7月10日查封大型機械，需專業技師拆解鑑價，鑑定人排定至8月20日始能完成。
  • 執行法官指定拍賣期日為8月25日（逾一個月）。
  • → 「查封物之性質特殊」或有「不得已之事由」者，不在此限
一句話總結
  • 查封後應速訂拍賣日。
  • 查封日至拍賣日最短7天，最長1個月。
    • 「查封物之性質特殊」或有「不得已之事由」者，不在此限。
    • 經債權人及債務人同意，得迅速拍賣。

查封之撤銷與拍定後撤回執行之限制

「債務人」聲請撤銷查封
查封後，債務人得於「拍定前」提出現款，「聲請撤銷查封」
  • 拍定前：拍賣程序尚未「拍定」（即尚未有買受人出價得標）之前。
  • 提出現款：須以「現金」或「即時可兌現之票據」提出「全部」債權額及執行費用（含利息、違約金）。
  • 聲請撤銷查封：向執行法院聲請「啟封」並「塗銷查封登記」。
「債權人」聲請撤回強制執行
債權人於「拍定後、所有權移轉前」，聲請「撤回強制執行」者，「應得拍定人之同意」
  • 拍定後：拍賣程序已「拍定」（買受人已得標）。
  • 所有權移轉前：執行法院尚未核發「權利移轉證書」予拍定人（此時拍定人尚未取得所有權）。
  • 聲請撤回強制執行：債權人主動向執行法院請求「撤回」其執行聲請。
  • 應得拍定人之同意：須經「拍定人」明示同意，否則不得撤回。
    • 拍賣既已「拍定」，拍定人已取得「期待權」及「法律上之信賴」， 若債權人此時撤回執行，將影響拍定人權益。
例1.
  • 法院查封甲之汽車，訂於7月20日拍賣。
  • 甲於7月15日提出全部債權額及費用共計120萬元現金，聲請撤銷查封。
  • 法院即撤銷查封，返還汽車予甲。 → 債務人得於「拍定前」提出現款，「聲請撤銷查封」
例2.
  • 法院拍賣乙之電視，由丙拍定（7月10日），尚未核發權利移轉證書。
  • 債權人丁未經丙同意即向法院撤回執行。
  • 丁「聲請撤回」未經拍定人丙之同意。法院應駁回丁之撤回聲請。
  • → 「拍定後、所有權移轉前」，聲請「撤回強制執行」者，「應得拍定人之同意」，
一句話總結
  • 債務人可在拍定前繳清全部款項「撤銷查封」。
  • 拍定後，債權人「撤回執行」須得拍定人同意。

  • 得許：法院有裁量權。
  • 無損查封物價值之範圍內：
    • 例如查封汽車，債務人可繼續駕駛，但不得過度使用致折舊加劇。
    • 例如查封機械，可繼續運轉生產，但應定期維護保養。
例1.
  • 執行法院查封甲之大型機械，因體積龐大無法搬運。
  • 法院委託「倉儲公司」為保管人，並命其出具收據。
  • → 查封物得委託「保管人」保管，保管人應出具收據
例2.

  • → 經「債權人同意」或認為「適當時」，得由債務人保管。並得許可於「無損查封物價值」之範圍內，使用之
例3.

  • → 貴重物品不得交由債務人保管，應移置於法院指定之貯藏所
一句話總結
  • 查封動產之保管方法：
    1. 法院自行保管。
    2. 委託「保管人」保管。
      • 適當時，亦得以「債權人」為保管人

      • 應命保管人出具「收據」
    3. 由「債務人」保管。

      • 應命保管人出具「收據」

查封有價證券之權利行使與保全

查封之有價證券，若有「限期行使之權利或保全行為」，法院應在期限開始時「代債務人行使」，避免權利喪失
  • 有價證券：股票（上市公司、未上市公司）、公司債、政府債券、本票、支票等。
  • 限期行使之權利或保全行為：例如股票領取股息、票據於法定期限內「提示付款」等。
  • 應在期限開始時：強制義務，法院須「主動」為之，不得怠忽。
  • 代債務人行使：法院以「債務人名義」為該行為（如代為領取股息、提示票據），其法律效果歸屬於查封物之責任財產。
例1.
  • 執行法院查封債務人甲之上市公司股票100張。
  • 該股票即將於8月15日「除息」，法院於8月15日代甲向該公司領取現金股息，將股息納入查封物範圍。
  • → 查封之有價證券，法院應「代債務人行使」權利，避免權利喪失
例2.
  • 執行法院查封債務人乙之支票一張，發票日為7月1日，依票據法第130條應於「7月7日前」提示付款。
  • 法院於7月1日即代乙向付款銀行提示票據。
  • → 查封之有價證券，有「限期行使之權利」法院應「在期限開始時」代債務人行使權利，避免權利喪失
例3.
  • 執行法院查封債務人丙之公司債，該債券每年6月30日付息。
  • 法院未於6月30日代丙領取利息，致丙未於時效內領取，利息請求權消滅。
  • → 法院怠於行使義務，致查封物價值減損，應負相關責任。
一句話總結
  • 查封之有價證券若須於期限內行使權利：
    • 法院須在期限開始時代債務人為之，避免權利喪失。

查封天然孳息之拍賣限制與採收費用負擔

查封「未與土地分離之天然孳息」者，於「收穫期屆至後」，始得拍賣
  • 未與土地分離之天然孳息：指「仍附著於土地」之農作物（如稻穀、果樹之果實、甘蔗、茶葉）。
  • 收穫期屆至後，始得拍賣：禁止「提前」拍賣，避免未成熟之孳息無法變價。
前項拍賣，得於「採收後」為之。於「分離前拍賣」者，應由「買受人自行負擔採收費用」
  • 採收後拍賣：法院得選擇「先僱工採收」，將採收後之農作物作為「動產」拍賣（適用一般動產拍賣程序）。
  • 分離前拍賣：法院得「不採收」，直接以「現狀」（未分離）拍賣。
  • 由買受人自行負擔採收費用：分離前拍賣，買受人拍定後，須「自行負擔費用」僱工採收（費用包括：工資、搬運費、包裝費等）。
    • 若買受人拒絕負擔採收費用，視同不履行拍賣條件，執行法院得另行處理（如再拍賣）。
例1.
  • 執行法院於5月查封債務人甲田裡之稻作（預計7月收成）。
  • 法院必須等到7月收穫期「屆至」後，始得進行拍賣。
  • → 「未與土地分離之天然孳息」，於「收穫期屆至後」，始得拍賣
例2.
  • 收穫期屆至後，執行法院先僱工採收稻穀，再以「已採收之稻穀」為標的進行拍賣。
  • → 拍賣得於「採收後」為之
例3.
  • 執行法院於7月收穫期屆至後，直接以「未採收之果實」為標的進行拍賣。
  • 買受人乙拍定後，自行負擔費用僱工採收該批果實。
  • → 於「分離前拍賣」者，應由「買受人自行負擔採收費用」
一句話總結
  • 查封之農作物須待收穫期屆至始得拍賣。
  • 農作物拍賣可在採收前或採收後進行。
    • 採收前拍賣者，採收費用由買受人自行負擔。

拍賣原則與變賣例外

原則：查封物「應公開拍賣」之
  • 公開拍賣：以「公開競價」方式出售，使不特定人得參與投標。
例外：有下列情形之一者，法院得不經拍賣程序，將查封物「變賣」之
  1. 債權人及債務人「合意聲請」
    • 債權人及債務人雙方同意並「聲請變賣」。
  2. 債權人及債務人「已議定價格」
    • 債權人及債務人雙方對於「查封物之價格」已有協議。
  3. 金銀物品或「有市價」之物品
    • 黃金、白銀、外幣、公債、上市股票等。此類物品有「公開交易價格」，無需透過競價即可合理估價。
  4. 物品性質特殊
    • 易於腐壞、有減少價值之虞、保管困難、保管費用龐大
變賣不成時，法院應作價交債權人承受
  • 第71條：「拍賣物無人應買時，執行法院應作價交債權人承受……」。
  • 變賣時若無人應買或議價不成，準用該條，使債權人得承受查封物。
例1.
  • 執行法院查封債務人甲之一批鮮魚，因魚類易腐壞，法院逕行以「變賣」方式出售予市場魚販。
  • → 物品性質特殊，「易於腐壞虞」、「有減少價值之虞」，得不經拍賣程序，將查封物「變賣」之
例2.
  • 查封債務人乙之金條一批，因黃金有公開市價，法院以「當日黃金牌價」變賣。
  • → 金銀物品或「有市價」之物品，得不經拍賣程序，將查封物「變賣」之
例3.
  • 債權人丙與債務人丁均同意將查封之汽車以50萬元變賣，法院即依協議價格變賣。
  • → 債權人及債務人「已議定價格」，得不經拍賣程序，將查封物「變賣」之
一句話總結
  • 查封物原則上公開拍賣。
  • 但易腐壞、易減值、金銀有市價、保管困難或雙方協議時，可改為變賣。

有價證券之特別變價程序

查封之「有價證券」，法院認為適當時，得不經拍賣程序。準用第115條至第117條規定處理之
  • 法院認為適當：法院有「裁量權」，應審酌有價證券是否有「公開市價」（如上市櫃股票）、 有無「拍賣實益」（證券價值是否低於拍賣費用）、債務人及債權人有無異議。
第115條至第117條規定：扣押、收取、移轉、支付轉給
  • 第115條：對「金錢債權」之執行——發收取、移轉、支付轉給命令。
  • 第116條：對「物之交付或移轉請求權」之執行。
  • 第117條：對「其他財產權」之執行——概括準用。
  • 準用後，執行法院得：
    • 扣押：禁止發行公司或保管機構為移轉或交付。
    • 收取：由債權人直接領取股息、利息或本金。
    • 移轉：將證券移轉予債權人（債權人成為股東或債權人）。
    • 支付轉給：由第三人將價款支付予法院。
例1.
  • 執行法院查封債務人甲之上市公司股票100張。
  • 該股票即將發放現金股息，法院發「收取命令」，命該公司將股息直接支付予債權人。
  • → 查封之「有價證券」，法院認為適當時，得不經拍賣程序。準用「收取命令」
例2.
  • 執行法院查封債務人乙之未上市股票，經鑑價後價值100萬元。
  • 法院發「移轉命令」，將該股票移轉予債權人丙，以抵償丙之債權100萬元。
  • → 查封之「有價證券」，法院認為適當時，得不經拍賣程序。準用「移轉命令」
例3.
  • 執行法院查封債務人丁之公司債。
  • 法院發「支付轉給命令」，命發行公司將公司債之價款支付予法院，再由法院轉交債權人。
  • → 查封之「有價證券」，法院認為適當時，得不經拍賣程序。準用「支付轉給命令」
一句話總結
  • 查封之「有價證券」，法院認為適當時，得不經拍賣程序。
  • 準用對「其他財產權」執行的方式（收取、移轉、支付轉給）來處理。

動產拍賣之場所與委託拍賣

拍賣動產，由執行法官「命書記官督同執達員」於「執行法院」或「動產所在地」行之
  • 執行法官：負責「核發拍賣命令」及「訂定拍賣條件」。
  • 書記官：到場「監督」並「製作拍賣筆錄」。
  • 執達員：實際執行「拍賣進行」（如主持競價、收取保證金）。
  • 執行法院：通常於法院內之「拍賣室」或「公告場所」舉行。
  • 動產所在地：若查封物體積龐大（如大型機械）或搬運困難，得於其所在地就地拍賣。
法院認為必要時，得「委託」拍賣行或適當之人執行拍賣。但「應派員監督」
  • 必要時：例如查封物為「藝術品」、「古董」、「珠寶」等需專業拍賣經驗。
  • 委託適當之人：如專業鑑價師、公證人等具拍賣經驗者。
  • 應派員監督：法院須指派「書記官」或「執達員」到場監督。
    • 監督事項包括：是否依法院核定之「底價」及「拍賣條件」進行; 有無「圍標」、「詐標」等不法情事。
例1.
  • 執行法院查封債務人甲之汽車，訂於法院內「拍賣室」進行公開拍賣，由書記官督同執達員主持。
  • → 拍賣動產，由執行法官「命書記官督同執達員」於「執行法院」或「動產所在地」行之
例2.
  • 執行法院查封乙之一批大型機械，因搬運困難，於乙之「工廠」現場進行拍賣。
  • → 拍賣動產，由執行法官「命書記官督同執達員」於「執行法院」或「動產所在地」行之
例3.
  • 執行法院查封丙之藝術品一批。
  • 法院認該批藝術品需專業行銷及鑑價，遂「委託拍賣行」辦理拍賣，並派書記官到場監督。
  • → 法院認為必要時，得「委託」拍賣行或適當之人執行拍賣。但「應派員監督」
一句話總結
  • 拍賣由法院人員在法院或動產所在地進行。
  • 必要時可委託拍賣行辦理，但法院須派人監督。

貴重物品之鑑定

查封物為「貴重物品」而其「價格不易確定」者，法院應「命鑑定人鑑定之」
  • 貴重物品：例如珠寶、貴金屬、古董、藝術品、名錶、稀有收藏品。
  • 價格不易確定：例如古董之價值取決於年代、真偽、保存狀況; 藝術品之價值取決於作者、創作時期。
    • 若貴重物品「有公開市價」（如黃金、上市鑽石價格公開），則無須鑑定，直接參考市價即可。
  • 應命：強制義務，法院不得省略。
  • 鑑定人：須具備「專業知識及經驗」之第三人。 例如：寶石鑑定師、專業古董商或收藏家（須具公信力）。
  • 鑑定之：應出具「書面鑑定報告」，載明估價金額、鑑定方法及依據。
例1.
  • 執行法院查封債務人甲之鑽石戒指一枚。
  • 因鑽石價格取決於「4C」（克拉、成色、淨度、切工），法院即命「寶石鑑定師」出具鑑定報告。
  • → 查封物為「貴重物品」而其「價格不易確定」者，法院應「命鑑定人鑑定之」
例2.
  • 執行法院查封債務人乙之金條一批。
  • 因黃金有「國際牌價」，法院逕依「當日黃金牌價」估價，無須另聘鑑定人。
一句話總結
  • 查封物若為「貴重物品」而其「價格不易確定」者：
    • 法院必須命專業鑑定人鑑價，以確保拍賣價格合理。

拍賣期日通知與不到場之效力

法院「應通知」債權人及債務人於拍賣期日到場，無法通知或屆期「不到場者，拍賣不因而停止」
  • 應通知：法院有「主動通知」之義務，須以「書面」（通知書）合法送達。
  • 債權人及債務人：包括「聲請執行之債權人」及「參與分配之債權人」，以及「債務人本人」。
  • 無法通知：例如債務人住居所不明、遷移等情況。
  • 不到場者，拍賣不因而停止：無論不到場理由為何（如忘記、故意不到、出差等），均不影響拍賣進行。
例1.
  • 執行法院於拍賣期日前10日，合法送達拍賣通知予債務人甲。
  • 拍賣當日甲未到場，法院仍依期進行拍賣。
  • → 債權人/債務人拍賣期日「不到場者，拍賣不因而停止」
例2.
  • 債務人乙已遷移戶籍且新址不明，法院寄送拍賣通知遭退回，法院乃為「公示送達」（公告）。
  • 公告期滿後，法院即進行拍賣，不因乙未受通知而停止。
  • → 債權人/債務人「無法通知」或拍賣期日「不到場者，拍賣不因而停止」
一句話總結
  • 法院須通知債權人及債務人於拍賣期日到場。
  • 無法通知或不到場，拍賣仍照常進行，不停止。

動產拍賣之公告與應載事項

拍賣動產，應由執行法院「先期公告」
  • 先期公告：應於拍賣期日「前」合理期間公告（非當日始公告）。
  • 公告方式：張貼於「法院公告處」、登載於「新聞紙」或「法院網站」（實務上多透過「司法院拍賣公告系統」公告）。
動產拍賣公告，應載明下列事項：
  1. 拍賣物之種類、數量、品質及其他應記明之事項
  2. 拍賣之原因、日時及場所
    • 原因：如「清償債務」、「強制執行」
    • 日時：如114年7月20日上午10時
    • 場所：拍賣進行之場所（執行法院拍賣室或動產所在地）
  3. 閱覽拍賣物及查封筆錄之處所及日時
    • 應買人得於拍賣前「實地查看」查封物（如試車、檢視品質）。
    • 查封筆錄可供查閱，以了解查封時之物品狀態。
  4. 定有拍賣價金之交付期限者，其期限
    • 若要求拍定人應於「一定期限內」繳清價金（如拍定後3日內），應載明。
  5. 定有應買之資格或條件者，其資格或條件
    • 例如：拍賣「計程車牌照」時，限「計程車客運業」投標；拍賣「農地」時，限「具自耕農身分」者（惟動產拍賣較少見此限制）。
  6. 定有保證金者，其金額
    • 保證金為「投標擔保」，防止應買人「棄標」。
    • 金額通常為「底價之一定比例」（如20%）。
一句話總結
  • 拍賣前須先公告。
  • 公告上須載明物品明細、拍賣時地、看貨時地、付款期限、投標資格及保證金等事項。

拍賣公告之揭示場所與登載

拍賣公告之揭示
1.「應揭示於執行法院」及動產所在地之「鄉鎮市（區）公所或拍賣場所」
  • 應揭示於執行法院：執行法院之「公告處」為「法定」揭示場所，屬基本義務。
  • 應揭示於動產所在地之鄉鎮市（區）公所：如該動產位於台中市西區，應揭示於「台中市西區區公所」。
  • 或拍賣場所：若拍賣地點「非法院」（如動產所在地現場拍賣），則應於該「拍賣場所」揭示公告。
2.如「認為必要」或「因債權人或債務人之聲請」，並得「公告於法院網站」
  • 認為必要：法院得「依職權」決定上網公告。
  • 因聲請：債權人或債務人得「主動」請求法院將公告刊登於法院網站。
  • 法院網站：司法院「拍賣公告系統」為現行實務主要管道。
3.如「認為必要」，得命登載於「公報或新聞紙」
  • 公報：如「司法院公報」或「地方政府公報」。
  • 新聞紙：報紙（如中國時報、自由時報等，「全國性」或「地方性」報紙）。
  • 認為必要：如查封物「價值極高」、拍賣資訊需「廣泛傳播」以吸引應買人時。
一句話總結
  • 拍賣公告須在法院、區公所或拍賣場所張貼；必要時可上法院網站或登報。

拍賣公告後之等待期間與例外

拍賣，應於「公告五日後」行之
  • 公告五日後：自公告日之次日起算，至拍賣日之前一日，「至少滿5日」。
    • 例如：公告日為7月10日，則拍賣日「最早」為7月15日。
但因物之「性質特殊」須「迅速拍賣」者，不在此限
  • 「性質特殊」：例如易腐壞（生鮮食品、鮮花、冷凍食品）、易減值、不易保存等須「迅速拍賣」之情況。
  • 不在此限：得於「公告後未滿5日」即行拍賣（如公告後第2日或第3日拍賣）。
例1.
  • 執行法院於7月10日公告拍賣債務人甲之汽車，指定拍賣期日為7月15日（公告日＋5日）。
  • → 拍賣，應於「公告五日後」行之
例2.
  • 執行法院查封乙之一批鮮魚，於7月10日公告，因魚類易腐壞，指定拍賣期日為7月12日（公告後2日）。
  • → 物之「性質特殊」須「迅速拍賣」者，不在此限
例3.
  • 執行法院查封丙之電視，於7月10日公告，指定拍賣期日為7月12日（公告後2日），無任何急迫事由。
  • → 公告未滿5日即拍賣，拍賣程序有瑕疵，拍定可能遭撤銷
一句話總結
  • 公告後原則上須等5天才能拍賣；但易腐壞或易貶值之物可例外提前。

拍賣物之交付時點

拍賣物之「交付」，應於「價金繳足時」行之
  • 交付：指將「拍賣標的物」之「現實占有」移轉予「拍定人」（買受人）。
    • 限於「動產」拍賣（不動產交付另依「點交」等相關規定）。
  • 價金繳足時：買受人須將拍定價金「全數」繳納完畢。
例1.
  • 甲拍定法院查封之汽車，拍賣價金100萬元。
  • 甲於拍定當日繳清全部100萬元，法院即將汽車交付予甲。
  • → 拍賣物之「交付」，應於「價金繳足時」行之
例2.
  • 丙拍定後未於期限內繳足價金，執行法院依法再行拍賣（第70條第3項），並由丙負擔差額及費用。
  • → 因丙未繳足，不能交付
一句話總結
  • 買受人必須先繳清全部價金，法院才會將拍賣物交付給買受人（一手交錢，一手交貨）。

有價證券拍賣後之背書與名義變更

法院於「有價證券」拍賣後，得「代債務人為背書」或「變更名義」與買受人之必要行為，並「載明其意旨」
  • 有價證券：包括股票、公司債、票據（本票、支票、匯票）、受益憑證、存託憑證等。
  • 拍賣後：拍賣程序「已完成」（拍定人已繳足價金）。
  • 代債務人：法院以「債務人名義」為行為（非以「法院自己名義」）。
  • 背書：法院應於證券「背面」簽名或蓋章，並載明「受款人」為買受人。
    • 適用於「記名票據」或「記名股票」。
  • 變更名義：法院應發函通知發行公司將「債務人名義」變更為「買受人名義」。
    • 適用於「須向發行公司或登記機關辦理過戶」之證券。
  • 與買受人之必要行為：限於「為使買受人取得證券上權利」所「必要」之行為（如背書、過戶申請）。
  • 載明其意旨：法院應於「背書處」或「變更名義之文件」上，註明「本行為係依強制執行法第68條之1，由執行法院代債務人為之」。
    • 目的：使第三人（發行公司、付款人）知悉該行為之「合法代理」性質，並避免日後爭議。
例1.
  • 執行法院拍賣債務人甲之記名股票100張，拍定人乙已繳足價金。
  • 甲拒絕背書轉讓，法院即於股票背面「代甲為背書」，並載明「本背書係由臺灣臺北地方法院依強制執行法第68條之1代債務人甲為之」。
  • → 「有價證券」拍賣後，得「代債務人為背書」，並「載明其意旨」
例2.
  • 執行法院拍賣丙之記名公司債，拍定人丁已繳足價金。
  • 法院發函通知該公司將「丙之名義」變更為「丁之名義」，並載明「係依強制執行法第68條之1代為辦理」。
  • → 「有價證券」拍賣後，得代債務人為「變更名義」與買受人，並「載明其意旨」
一句話總結
  • 「有價證券」拍賣後：
    • 法院可代債務人為背書或變更名義，並載明代理意旨，以確保買受人取得完整權利。

拍定人未繳足價金之再拍賣與差額負擔

拍定人「未繳足價金」者，執行法院應「再拍賣」
  • 拍定人：拍賣時「得標」之應買人。
  • 未繳足價金：未於「指定期限內」繳清全部價金（含保證金不足之差額）。
  • 應再拍賣：法院須「重新」進行拍賣程序（不得因拍定人違約而終止執行）。
再拍賣時，原拍定人「不得應買」
  • 不得應買：禁止原拍定人「以任何形式」參與投標（含本人或他人代理）。
    • 若原拍定人違反規定參與應買，其投標無效。
原拍定人「負擔差額」之義務
再拍賣之價金「低於原拍賣價金及因再拍賣所生之費用」者，原拍定人「應負擔其差額」
  • 再拍賣之價金：再拍賣之「拍定價格」（或無人應買時之「承受價格」）。
  • 原拍賣價金：原拍定人之「得標價格」。
  • 因再拍賣所生之費用：如「再行公告費」、「鑑價費」、「保管費」等。
  • 差額 =（原拍賣價金 ＋ 再拍賣費用）－ 再拍賣價金
  • 原拍定人應負擔其差額：此為「損害賠償」性質，原拍定人須賠償此差額。
前項差額，執行法院應「依職權」以「裁定」確定之
  • 應依職權：法院須「主動」確定差額，無待債權人聲請。
  • 裁定：法院應以「書面裁定」載明差額計算方式及金額。
    • 原拍定人對該裁定得「抗告」（準用民事訴訟法）。
原拍定人繳納之「保證金不足抵償差額」時，得依前項裁定「對原拍定人強制執行」
  • 保證金：原拍定人投標時繳納之「擔保金」。
  • 不足抵償：保證金之數額「小於」差額。
  • 依前項裁定：該裁定即為「執行名義」。
  • 對原拍定人強制執行：得對原拍定人之「其他財產」為強制執行（如存款、薪資）。
例1.
  • 甲以100萬元拍定汽車，未繳足價金。法院再行拍賣，以80萬元拍定，再拍賣費用為5萬元。 → 再拍賣之價金「低於原拍賣價金及因再拍賣所生之費用」者，原拍定人「應負擔其差額」
  • 差額計算：（100萬＋5萬）－80萬 ＝ 25萬元。
  • 甲原繳保證金10萬元，不足15萬元，法院裁定確定差額，並對甲強制執行15萬元。 → 前項差額，執行法院應「依職權」以「裁定」確定之
  • → 原拍定人繳納之「保證金不足抵償差額」時，得依前項裁定「對原拍定人強制執行」
例2.
  • 再拍賣時，甲委託友人乙代為投標，意圖低價買回。
  • → 再拍賣時，原拍定人「不得應買」，含「本人或他人代理」，乙之投標無效
一句話總結
  • 拍定人未繳足價金，法院須再拍賣。
  • 再拍賣時，原拍定人不得再投標。
  • 再拍賣價差及費用由原拍定人賠償；保證金不足時，可依法院裁定強制執行。

拍賣物之瑕疵擔保責任免除

拍賣物買受人就「物之瑕疵」，「無擔保請求權」
  • 買受人：指於法院拍賣程序中「得標」之應買人（拍定人）。
    • 不包括「債權人承受」之情形（債權人承受係「抵償」，非「買賣」）。
  • 就物之瑕疵：包括「價值瑕疵」、「效用瑕疵」及「品質瑕疵」。
    • 例如：汽車引擎故障（效用瑕疵）、古董為贗品（價值瑕疵）、珠寶有缺損（品質瑕疵）。
  • 「擔保請求權」：民法「請求減少價金」、「解除契約」或「損害賠償」之權利。
    • 無擔保請求權：買受人「完全不得」主張此等權利。
    • 換言之：法院拍賣的物品，買受人須「自負風險」，不能因瑕疵而要求退貨或賠償。
例1.
  • 甲拍定法院拍賣之二手汽車，交車後發現引擎有重大故障，甲向法院主張「減少價金」或「退貨」。
  • → 拍賣物買受人無瑕疵擔保請求權，法院應駁回其主張
例2.
  • 拍賣公告已載明「本件查封物有明顯刮傷及功能異常，請應買人自行評估」，乙仍投標拍定，事後不得主張瑕疵。
  • → 買受人已受告知，風險自負
一句話總結
  • 法院拍賣的物品，買受人須自負風險，不能因瑕疵而主張退貨、減價或賠償（現狀拍賣，風險自負）。

動產拍賣之底價、保證金、拍定與再拍賣

預定底價
1.因債權人或債務人之「聲請預定」
  • 債權人或債務人得向法院聲請「預定拍賣物之底價」。
2.認為必要時，應「依職權預定」
  • 法院得依職權「主動」預定拍賣物之底價（原則上應預定底價）。
法院定底價時，應詢問債權人及債務人之意見。但無法通知或屆期不到場者，不在此限
  • 應詢問：須給予當事人陳述意見之機會（非「須經其同意」）。
  • 無法通知或屆期不到場者，不在此限：若無法送達或當事人不到場，仍得逕行定底價。
酌定保證金額
法院得酌定保證金額，命應買人「於應買前繳納之」。未照納者，其應買「無效」
  • 得酌定：由法院裁量是否收取保證金。
  • 保證金：通常為「底價之一定比例」（如20%）。
  • 於應買前繳納之：應買人需「先繳納保證金」，才能出價應買。
  • 未照納者，應買無效：未繳保證金者，其出價「不生效力」。
拍定程序
拍定，應就應買人所出之「最高價」，「高呼三次後」為之
  • 「高呼三次」：拍賣主持人（書記官或執達員）應將「最高出價」當眾「高聲宣讀三次」，使在場應買人有「最後加價」之機會。
    • 三次後無人再加價，即「拍定」。
「不為拍定」之情況
1. 最高價「低於底價」時，執行拍賣人應「不為拍定」
  • 最高價「未達底價」時，不得拍定。
2.「未定底價」者，如最高價經債權人或債務人「為反對之表示」時，執行拍賣人應「不為拍定」
  • 為反對之表示：債權人或債務人對於應買人所出之最高價，「認為不足而為反對之表示」。
不為拍定者，由執行法院定期「再行拍賣」。但債權人願「依底價承受」者，法院應「交債權人承受」
  • 以上2種情況「不為拍定」時，債權人得「按底價」承受查封物（以拍賣物抵償債務）。
再行拍賣程序
拍賣物依前項規定，再行拍賣時，應拍歸「出價最高」之應買人
  • 再拍賣時，原則上出價最高者得（不低於底價50%）。
但其最高價「不足底價百分之五十」或「未定底價，而其最高價顯不相當」者，法院應「作價交債權人承受」
  • 作價：以該最高價或其他合理價格交債權人承受。
債權人「不承受」時，法院應「撤銷查封」，將拍賣物返還債務人
  • 若債權人「不願承受」，則「撤銷查封」，「返還」查封物予債務人（執行程序終結）。
債務人「不得應買」
  • 禁止債務人本人參與投標，避免其「低價買回」自己之財產（損及債權人權益）。
例1.
  • 拍賣汽車，底價50萬元，甲出價60萬元，經高呼三次後無人加價，甲拍定。
  • → 拍定，應就應買人所出之「最高價」，「高呼三次後」為之
例2.
  • 拍賣電視，底價10萬元，應買人最高出價8萬元，低於底價，法院不拍定，定期再行拍賣。
  • → 最高價「低於底價」時，執行拍賣人應「不為拍定」
例3.
  • 延續例2，再行拍賣時最高價仍僅6萬元，低於底價50%
  • 法院作價10萬元交債權人承受，債權人同意。
  • → 再行拍賣最高價「不足底價百分之五十」者，法院應「作價交債權人承受」
例4.
  • 延續例3，債權人不願承受，法院即撤銷查封，將電視返還債務人。
  • → 再行拍賣流標而債權人「不承受」時，法院應「撤銷查封」，將拍賣物返還債務人
一句話總結
  • 法院得依職權或依聲請預定拍賣物之底價，並酌定保證金額。
    • 定底價時，應詢問債權人及債務人之意見。
    • 應買人應先繳保證金，才有資格應買。
  • 拍賣最高價經高呼三次後拍定。
  • 低於底價則再拍賣。
  • 再拍賣價格過低可交債權人承受。
  • 債權人不承受則撤封還債務人。
  • 債務人不得應買。

拍賣無人應買時之承受與撤銷查封

拍賣物「無人應買」時，法院應「作價交債權人承受」
  • 無人應買：指「拍賣期日」無人出價。
    • 若有人出價但「未達底價」，應再行拍賣，非本條之「無人應買」。
  • 應作價：法院有「義務」先詢問債權人是否承受（不得逕行撤封）。
    • 作價：法院應「評定」承受價格（通常以「底價」或「鑑定價格」為準）。
  • 承受：債權人以查封物「抵償」其債權（不足部分仍得繼續執行）。
債權人「不願承受」或「依法不能承受」者，法院應「撤銷查封」，將拍賣物返還債務人
  • 不願承受：債權人「明示」拒絕承受（須以書面或記明筆錄）。
  • 依法不能承受：例如債權人為「未成年人」且未經法定代理人同意。
  • 撤銷查封：解除查封之效力（啟封、塗銷登記）。
  • 返還債務人：解除查封物之「占有」，交還債務人。此後，該查封物「不再」為執行標的。
例外但書：拍賣物「顯有賣得相當價金之可能」者，得「再行拍賣」
  • 顯有賣得相當價金之可能：例如查封物為「熱門商品」、「稀有品」或「市場需求強勁」 ，只是因「拍賣公告不足」、「時機不佳」等因素暫時無人應買。
  • 再行拍賣：適用再拍賣之價格限制與承受程序。
例1.
  • 拍賣債務人甲之汽車，無人應買。
  • 法院作價50萬元（底價）交債權人乙承受，乙同意。該汽車即歸乙所有，抵償乙之債權50萬元。
  • → 拍賣物「無人應買」時，法院應「作價交債權人承受」
例2.
  • 拍賣債務人丙之冷氣機，無人應買，法院作價3萬元交債權人丁承受，丁拒絕。
  • 法院即撤銷查封，將冷氣機返還丙。
  • → 債權人「不願承受」者，法院應「撤銷查封」，將拍賣物返還債務人
例3.
  • 拍賣債務人戊之名錶，無人應買。
  • 但該名錶為限量款，市場行情極佳，法院認「顯有賣得相當價金之可能」，定期「再行拍賣」。
  • → 拍賣物「顯有賣得相當價金之可能」者，得「再行拍賣」
一句話總結
  • 無人應買時，法院應作價交債權人承受。
  • 債權人不承受或不能承受，則撤封還債務人。
    • 但若仍有賣高價可能，得再行拍賣。

拍賣之停止時機

拍賣於賣得價金「足以清償」債權額及費用時，「應即停止」
  • 賣得價金：指已拍定（已賣出）之查封物所獲得之「累計價金」。
  • 債權額：執行名義所載之「全部」債權（含本金、利息、違約金，至拍賣時止）。
  • 費用：指債務人應負擔之費用。包括「執行費用」、「鑑價費」、「保管費」、「再拍賣費用」等（以已發生或預估者為限）。
  • 足以清償：累計價金 ≥（債權額＋費用）
  • 應即停止：強制義務，法院「必須」立即停止拍賣，無裁量權。
例1.
  • 執行法院查封債務人甲之汽車（底價50萬元）及電視（底價10萬元），債權額及費用合計40萬元。
  • 拍賣汽車以50萬元拍定，已「足以」清償40萬元，法院應「即時停止」拍賣電視，並撤銷電視之查封，返還甲。
  • → 賣得價金「足以清償」債權額及費用時，「應即停止拍賣」
例2.
  • 查封乙之機車（底價5萬元）及電腦（底價3萬元），債權額及費用合計6萬元。
  • 先拍賣機車以5萬元拍定，尚不足1萬元。
  • 續拍賣電腦以3萬元拍定，累計8萬元已「足以」清償6萬元，法院應「即時停止」後續拍賣（若有其他查封物）。
一句話總結
  • 一旦拍賣所得已足夠清償全部債權及費用，法院必須立刻停止拍賣。

拍賣筆錄之作成與應載事項

「拍賣終結後」，書記官應作成「拍賣筆錄」，並由「執行拍賣人簽名」
  • 拍賣終結後：指拍賣程序「全部完成」。包括「拍定」、「無人應買」或「依法停止」之情形。
  • 拍賣筆錄：為正式之法院文書，應附於執行卷宗。
  • 執行拍賣人：即「主持拍賣」之人（通常為書記官，亦可能為委託之拍賣行人員）。
  • 簽名：表示「確認筆錄內容正確無誤」。
拍賣筆錄，應載明下列事項：
  1. 拍賣物之種類、數量、品質及其他應記明之事項
  2. 債權人及債務人
  3. 拍賣之買受人姓名、住址及其應買之最高價額
    • 買受人：即「拍定人」（得標者）。
    • 最高價額：即「拍定價格」（成交價格）。
    • 若為「債權人承受」，應載明「承受人」及「承受價格」。
  4. 拍賣不成立或停止時，其原因
    • 不成立：如無人應買、低於底價且無人承受。
    • 停止：如賣得價金已足清償、債權人撤回執行。
    • 應具體載明「原因事實」（如「無人投標」、「債權人承受」）。
  5. 拍賣之日時及場所
  6. 作成拍賣筆錄之處所及年、月、日
一句話總結
  • 拍賣結束後，書記官須製作拍賣筆錄。
  • 拍賣筆錄應記載標的物、當事人、買受人、價格、時地及不成立原因，並由執行拍賣人簽名。

拍賣價金之分配與餘額處理

拍賣物賣得價金，「扣除執行費用後」，應將「餘額交付債權人」
  • 扣除執行費用後：執行費用優先扣除。包括執行費、鑑價費、登報費、搬運費、保管費、再拍賣費用等。
  • 債權人：包括「聲請執行之債權人」及「參與分配之債權人」。
  • 交付：如有多數債權人參與分配，應依「分配表」進行分配。
交付債權人後「仍有餘額」時，應「返還債務人」
  • 交付債權人後「仍有餘額」：先扣除執行費用，再分配給債權人（全部清償）之後，仍有剩餘金額時。
  • 返還債務人：法院須將「剩餘金額」返還債務人。
例1.
  • 拍賣債務人甲之汽車得款100萬元，執行費用共計10萬元，甲之債權額（本金＋利息）為80萬元。
  • 扣除費用10萬元後，餘額90萬元，交付債權人80萬元。 → 拍賣物賣得價金，「扣除執行費用後」，應將「餘額交付債權人」
  • 剩餘10萬元（超過額）返還甲。 → 交付債權人後「仍有餘額」時，應「返還債務人」
例2.
  • 拍賣丙之財產得款200萬元，執行費用20萬元。
  • 債權人甲（債權100萬元）、乙（債權60萬元）參與分配，合計160萬元。
  • 扣除費用20萬元後，餘額180萬元，清償甲100萬元、乙60萬元（合計160萬元） → 拍賣物賣得價金，「扣除執行費用後」，應將「餘額交付債權人」
  • 剩餘20萬元返還丙。 → 交付債權人後「仍有餘額」時，應「返還債務人」
一句話總結
  • 拍賣價金先扣執行費用，再給債權人，若有多餘則還債務人。
