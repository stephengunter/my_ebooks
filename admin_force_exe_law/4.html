4 即時強制

第36條 即時強制之要件與方法
  1. 「行政機關為阻止犯罪、危害之發生或避免急迫危險，而有即時處置之必要時，得為即時強制。」
  2. 「即時強制方法如下：」
    1. 對於人之管束。
    2. 對於物之扣留、使用、處置或限制其使用。
    3. 對於住宅、建築物或其他處所之進入。
    4. 其他依法定職權所為之必要處置。
這一條是關於？
  • 情況火燒眉毛了，行政機關來不及走「先下命令、再給期限、還不聽才強制」的正常流程，可以直接動手處理——管束人、扣東西、進房子，先止血再說。
這一條的核心
  • 本條是行政執行法第四章「即時強制」的總則性規定，也是整個即時強制制度的入口條款。它與第二章（金錢給付執行）、第三章（行為或不行為義務執行）有一個根本性的區別：即時強制不以人民先有「義務不履行」為前提。法務部函釋明確指出：「即時強制並不以人民有違反行政法上義務為前提，此亦為即時強制與行政上強制執行主要區別所在。」
  • 換句話說，第二章和第三章的邏輯是「你先欠錢/該做不做，我來逼你」；第四章的邏輯是「事情正在發生或即將發生，我直接介入處理，不管你有沒有先違反什麼義務」。員警看到有人拿刀亂揮，不需要先開一張「命你放下刀」的處分書再等他逾期不履行，可以直接管束。
  • 從定位上看，本條是急迫性與必要性的雙重把關條款。第一項設下實體門檻：須為「阻止犯罪、危害之發生或避免急迫危險」，且有「即時處置之必要」。第二項列出四款方法，但這些方法不是菜單任你點——每一款方法在後續條文（第37條至第40條）都有更嚴格的特別要件。例如管束限於第37條的四種情形且不得逾24小時；進入住宅限於「人民之生命、身體、財產有迫切之危害，非進入不能救護者」。法務部112年函釋也強調，即時強制「對人民權益影響較大，除必須具備本條所定緊急性與必要性之一般要件外」，扣留物還須符合第38條「軍器、凶器及其他危險物」的特別要件。
條文拆解
第一項：即時強制之一般要件
  • 「行政機關」：
    • 指相關法令之主管機關或依法得為即時強制之機關。
    • 不限於行政執行分署，警察、消防、衛生主管機關等在各自職權範圍內均可能成為即時強制的主體。
  • 「為阻止犯罪、危害之發生或避免急迫危險」：
    • 三個目的並列，涵蓋犯罪預防（如有人正持械攻擊）、危害防止（如瓦斯外洩隨時可能爆炸）、急迫危險避免（如精神病患自傷）。
    • 意義：即時強制保護的是公共安全與個人重大法益，不是一般的行政秩序。
  • 「而有即時處置之必要時」：
    • 時間上的急迫性，客觀上無法等待正常的行政程序（下命、限期、告戒、執行）。
    • 要件：若尚有時間走第三章程序，就不符合「即時」的要件。
  • 「得為即時強制」：
    • 「得」表示有裁量權，但裁量須受第3條比例原則拘束——手段須有助於目的、選損害最小者、損害不得顯失均衡。
第二項：四款方法
  • 第1款「對於人之管束」：
    • 「酌定」：法院應「合理」估算（如「市場行情」、「工資」）。
  • 第2款「對於物之扣留、使用、處置或限制其使用」：
    • 扣留（如扣下刀械）、使用（如徵用民車救災）、處置（如銷毀腐壞食品）、限制使用（如封鎖危險設備）。
    • 特別限制：扣留依第38條限於「軍器、凶器及其他危險物」；使用/處置依第39條限於天災事變等情形。
  • 第3款「對於住宅、建築物或其他處所之進入」：
    • 侵入居住自由的領域。依第40條，限於「人民之生命、身體、財產有迫切之危害，非進入不能救護者」。
    • 典型：消防員破門進入火場救人。
  • 第4款「其他依法定職權所為之必要處置」：
    • 概括條款，但須有其他法律授權的職權為基礎，不是空白授權。
為什麼要有這條規定？
  • 填補正常程序的時間落差：第二章、第三章要求先下命、給期限、告戒，這些程序在急迫情況下緩不濟急。
  • 不以義務違反為前提：即時強制處理的是「危險狀態」，不是「義務人不聽話」，即使人民沒有違反任何義務，國家仍得介入。
  • 授權國家在緊急時直接以實力排除危險：火災、精神病患自傷、持刀亂揮等情形，需要的是立即的物理介入，不是公文往返。
  • 同時設下嚴格界限防止濫用：透過「急迫性」「必要性」以及後續第37至40條的特別要件，把即時強制壓縮在真正緊急的場景。
  • 銜接損失補償制度：合法即時強制造成人民特別犧牲時，依第41條給予補償，調和公益與私益。
白話文
  • 正常情況下，政府要對人民動手，得先下命令、給你時間、警告你、你還不聽才強制。
    • 但火已經在燒了、有人拿刀在砍人了、瓦斯已經漏滿整間屋子了——哪有時間等公文跑完？
  • 這條就是說：這種時候，行政機關不用先下命令，可以直接：
    • 把人抓起來管束一下（比如把爛醉的人帶走）、把危險的東西扣下來（比如奪下刀械）
    • 直接破門進入（比如進火場救人）、或者做其他必要的事。
  • 但這不是讓政府隨便就能闖你家或抓人——後面第37條到第40條會把每一種手段的具體條件寫得很死（管束不能超過24小時、進住宅要有「迫切危害」、扣東西限於凶器危險物）。
  • 而且就算合法，如果造成你特別大的損失，國家還是要補償你。
舉個例子
例1（對人管束——酗酒泥醉）
  • 員警巡邏發現甲爛醉如泥倒臥路邊，無法自行站立，且有被車撞的危險。員警依第36條第2項第1款將甲帶回管束至清醒。 → 適用第36條（連結第37條第1項第1款）。
例2（對物扣留——持刀滋事）
  • 乙在夜市持西瓜刀揮舞，嚇跑攤商與路人。員警到場後奪下西瓜刀並扣留。 → 適用第36條第2項第2款（連結第38條「凶器」）。
例3（進入住宅——火場救人）
  • 某公寓發生火警，消防人員判斷屋內有人受困，屋主不在場無法取得同意，直接破壞大門進入滅火救人。 → 適用第36條第2項第3款（連結第40條「生命迫切危害」）。
例4（不符合急迫性——不得即時強制）
  • 主管機關發現某工廠排放廢水超標，但無立即危害公共安全之急迫性。
  • 主管機關應依水污染防治法開罰並命限期改善，不得直接依第36條即時強制查封廠房設備。 → 不適用第36條（欠缺「即時處置必要」）。
例5（以扣留物抵罰鍰——違法）
  • 行為人未經許可採取土石被罰鍰，主管機關已扣留其挖土機。行為人不繳罰鍰，主管機關主張「繼續扣留挖土機直到繳清罰鍰再發還」。
  • 法務部函釋指出，罰鍰屬公法上金錢給付義務，應依第二章移送執行，不得以即時強制的扣留手段作為抵償或催繳工具。 → 違反第36條（混淆即時強制與金錢給付執行）。
一句話總結
  • 火燒眉毛時，行政機關不用先下命令，可以直接管人、扣物、進屋——但「急迫」不是隨便說了算，每一種手段後面都有更嚴的條件把關，合法造成特別損失的，國家還要補償。
第37條 對人管束之要件與期限
  1. 「對於人之管束，以合於下列情形之一者為限：」
    1. 瘋狂或酗酒泥醉，非管束不能救護其生命、身體之危險，及預防他人生命、身體之危險者。
    2. 意圖自殺，非管束不能救護其生命者。
    3. 暴行或鬥毆，非管束不能預防其傷害者。
    4. 其他認為必須救護或有害公共安全之虞，非管束不能救護或不能預防危害者。
  2. 「前項管束，不得逾二十四小時。」
這一條是關於？
  • 把人抓起來管束，不是警察高興就可以——必須符合四種「不抓不行」的具體情境，而且最多只能關24小時。
這一條的核心
  • 本條是行政執行法即時強制中「對人管束」的特別要件條款，也是第36條第2項第1款管束方法的具體化與限制。第36條給了即時強制的一般門檻（急迫性、必要性），第37條則進一步把「管束」這項對人身自由侵害最大的手段，壓縮在四款特定情境內。
  • 其法律意義在於：管束的本質是救護與預防，不是處罰。法務部函釋明確指出，即時強制「並不以人民有違反行政法上義務為前提」，管束的目的在於救護被管束人的生命身體，或預防他人生命身體的危險。這與刑事逮捕、行政罰完全不同——被管束的人不是「犯人」，而是「需要被保護或防止其傷人的人」。
  • 從定位上看，本條是第36條的特別限制。法務部函釋強調，即時強制「對人民權益影響較大，除必須具備上開所述之緊急性與必要性之一般要件外，本法第37條至第40條更規定須具備特別要件，始得實施」。換句話說，不是符合第36條的「急迫」就能管束，還必須落入第37條的四款情形之一。
  • 第2項的24小時上限是絕對上限，不是「通常不得逾24小時」——超過即屬違法拘禁。且依提審法，被管束人得聲請法院提審。
條文拆解
第1項：四款管束事由
  • 第1款「瘋狂或酗酒泥醉」：
    • 精神狀態陷於異常（瘋狂），或酒精作用致意識不清（泥醉）。須達到「非管束不能救護其生命、身體之危險，及預防他人生命、身體之危險」的程度。
    • 典型：爛醉倒臥馬路、精神失常持械自傷或傷人。
    • 注意：若屬罹患精神疾病之人，其緊急處置、送醫、強制鑑定等應優先適用精神衛生法相關規定。
  • 第2款「意圖自殺」：
    • 有自殺意念且「非管束不能救護其生命」。法務部函釋指出，具體個案是否符合要件，「應考量比例原則，依個案事實由行政機關本於權責審認」。
    • 要件：須有客觀事實顯示自殺意圖，不能僅憑一句氣話就管束。
  • 第3款「暴行或鬥毆」：
    • 正在實施暴力行為或互毆，非管束不能預防傷害。
    • 典型：街頭鬥毆、持械攻擊他人。
  • 第4款「其他認為必須救護或有害公共安全之虞」：
    • 概括條款，須達到「非管束不能救護或不能預防危害」的程度。
    • 限制：概括款不能無限擴張，仍須受比例原則拘束。
第2項：24小時上限
  • 「不得逾二十四小時」：
    • 從管束開始起算，滿24小時即須釋放或依法轉換其他處置（如送醫、移送社政單位）。
    • 法律效果：超時管束即屬違法剝奪人身自由，可能構成國家賠償責任。
為什麼要有這條規定？
  • 防止管束成為變相拘禁：管束是即時強制中對人身自由侵害最大的手段，必須以「救護」或「預防危害」為正當性基礎，不能作為處罰或便利行政的工具。
  • 明確化「急迫」的具體情境：第36條的「急迫危險」過於抽象，第37條把管束限於四種可辨識的情境，讓執行機關有明確依據，也讓司法有事後審查的標準。
  • 設定絕對時間上限：24小時的硬性規定，確保管束是「短暫的保護性拘束」，而非長期關押。
  • 區分管束與其他人身拘束：管束不是刑事逮捕、不是管收、不是行政罰，它有獨立的要件與目的，本條把這個界線劃清楚。
  • 銜接特別法優先適用：如涉及精神疾病患者，精神衛生法的緊急安置等規定優先適用，本條退居補充地位。
白話文
  • 警察可以把人「管束」起來——但不是想抓誰就抓誰。只有這四種情況才可以：
    • 這個人瘋了或醉到不省人事，不把他帶走他會傷到自己或別人；
    • 這個人想自殺，不看著他他會死；
    • 這個人正在打架或動手打人，不拉開會有人受傷；
    • 或者其他真的必須救他、或他會危害公共安全的情況。
  • 而且，管束最多24小時。時間一到，該放的放、該送醫的送醫、該轉其他程序的轉其他程序。不能因為「還沒問清楚」或「還沒處理完」就繼續關。
舉個例子
例1（酗酒泥醉——適用第1款）
  • 甲爛醉倒在快車道上，無法自行移動，夜間視線不良隨時可能被車撞。員警到場後將甲帶回派出所管束至其清醒。 → 適用第37條第1項第1款。
例2（意圖自殺——適用第2款）
  • 乙坐在橋欄杆上，情緒激動表示要跳河，經勸阻仍不下來。員警判斷有立即危險，將其拉下並管束送醫。 → 適用第37條第1項第2款（法務部函釋肯認此情形得管束）。
例3（暴行鬥毆——適用第3款）
  • 丙在夜市與人互毆，持酒瓶揮舞，旁人無法制止。員警到場制伏丙並管束。 → 適用第37條第1項第3款。
例4（超時管束——違法）
  • 丁因酒醉鬧事被帶回管束，至翌日同一時間已滿24小時，員警認為「等他完全清醒再說」繼續留置。 → 違反第37條第2項（逾24小時）。
例5（不符要件——不得管束）
  • 戊在路邊大聲咆哮、情緒激動，但未達瘋狂或泥醉程度，也無自傷或傷人跡象。
  • 員警僅因「他很吵」就將其管束帶回。 → 不適用第37條（未符合任何一款「非管束不能救護或預防」的要件）。
一句話總結
  • 管束是保護性拘束，不是處罰——限於瘋醉、自殺、暴行、或其他非得管束不可的救護/公共安全情境，而且24小時一到就必須放手或轉送。
第38條 對物扣留之要件、期間與發還
  1. 「軍器、凶器及其他危險物，為預防危害之必要，得扣留之。」
  2. 「扣留之物，除依法應沒收、沒入、毀棄或應變價發還者外，其扣留期間不得逾三十日。但扣留之原因未消失時，得延長之，延長期間不得逾兩個月。」
  3. 「扣留之物無繼續扣留必要者，應即發還；於一年內無人領取或無法發還者，其所有權歸屬國庫；其應變價發還者，亦同。」
這一條是關於？
  • 政府看到刀械、武器這類「會傷人的東西」，為了防止出事可以扣下來——但不能扣一輩子，原則上30天內要處理，必要時最多再延2個月，之後該還的還、該充公的充公。
這一條的核心
  • 本條是行政執行法即時強制中「對物扣留」的特別要件與期限規定。第36條第2項第2款概括授權行政機關得對物扣留，本條則把這項授權壓縮在特定標的與特定期間內。
  • 其法律意義在於雙重限縮。第一層是標的限縮：法務部函釋明確指出，依第36條及第38條得扣留之物，以軍器、凶器及其他危險物為限，並非任何物品都可以扣留。第二層是期間限縮：扣留原則上不得逾30日，延長以一次為限、不得逾2個月，合計最長約3個月（30日+2個月）。這與第37條管束的24小時上限一樣，都是對即時強制手段設下明確的時間煞車。
  • 從定位上看，本條是第36條「急迫性」與「必要性」一般要件之外的特別門檻。法務部112年函釋重申：「即時強制之方法對人民權益影響較大，除必須具備本法第36條所定緊急性與必要性之一般要件外，對於得扣留之物，本法第38條更規定須具備特別要件，即以軍器、凶器及其他危險物為限，始得實施。」
  • 須特別注意扣留與其他類似概念的區別。法務部函釋指出，水利法第93條第2項的「先行扣留」是處罰前的證據保全行為，與行政執行法的即時強制扣留要件不同，不適用第38條的程序。同樣地，不得以扣留的機具作為罰鍰的抵償或催繳工具——罰鍰是公法上金錢給付義務，應依第二章移送執行，不能拿扣留物來「抵債」或「續扣到繳清為止」。
條文拆解
第1項：扣留之標的與目的
  • 「軍器、凶器及其他危險物」：
    • 標的限於具有危險性的物品。軍器如槍砲彈藥，凶器如刀械，其他危險物如爆裂物、腐蝕性化學品。
    • 限制：不是「任何與危害有關的東西」都能扣，須屬危險物性質。
  • 「為預防危害之必要」：
    • 扣留的目的在於事前預防，不是處罰、不是證據保全、不是催繳工具。
    • 要件：須有預防危害的具體必要性，並受第36條急迫性門檻拘束。
第2項：扣留期間
  • 「除依法應沒收、沒入、毀棄或應變價發還者外」：
    • 若有其他法律規定應沒收、沒入等，依各該規定處理，不受本項期間限制。
    • 意義：本項期間限制適用於「單純因預防危害而扣留」的情形。
  • 「扣留期間不得逾三十日」：
    • 原則上限。
  • 「但扣留之原因未消失時，得延長之，延長期間不得逾兩個月」：
    • 延長以「原因未消失」為要件，且延長期間上限2個月。
    • 合計：30日 + 2個月（約60日）≈ 最長約3個月。
第3項：發還與歸屬國庫
  • 「無繼續扣留必要者，應即發還」：
    • 原因消失（如危害已排除）即應發還，不待期滿。
  • 「於一年內無人領取或無法發還者，其所有權歸屬國庫」：
    • 發還不能時，經1年期間，所有權歸國庫。
  • 「其應變價發還者，亦同」：
    • 應變價發還的情形，1年內無人領取或無法發還，變價所得歸國庫。
為什麼要有這條規定？
  • 限縮對物扣留的範圍：第36條概括授權「對物扣留」，若無本條限縮，可能變成任何物品都能扣。本條明定以危險物為限，防止濫用。
  • 設定明確的期間上限：扣留是對財產權的暫時限制，不能無限期。30日原則、2個月延長，讓人民有可預期的時間表。
  • 課予發還義務：原因消失就應發還，不是「扣到期滿再說」，保障人民的財產權。
  • 處理無人領取的歸屬問題：避免扣留物長期懸置、權屬不明，透過1年期間使法律關係確定。
  • 區分即時強制扣留與其他法律上的扣留：本條的嚴格要件與期間，不適用於證據保全（如水利法先行扣留）或行政罰上的沒入，各有各的法律依據。
白話文
  • 政府看到有人拿著刀、槍、爆裂物這些危險東西，為了防止他傷人或出事，可以把東西扣下來。但只能扣危險物，不能隨便什麼都扣。
  • 扣下來之後，原則上30天內要處理完。如果危害還沒消失（比如那把刀是某個案件的關鍵，或持有人隨時可能再拿來用），可以延長，但最多再2個月。
  • 如果危險已經沒了，隨時要還，不用等到期滿。如果通知持有人來領，1年內都沒人來領，或根本找不到人還，那這個東西就歸國庫。如果是應該賣掉還錢的那種，賣掉的錢1年內沒人領，也歸國庫。
  • 還有一個重要的觀念：不能拿扣留的東西來抵罰鍰。罰鍰是欠政府的錢，該走欠錢的執行程序；扣留是預防危害，兩件事不能混在一起。
舉個例子
例1（扣留凶器——標準情形）
  • 甲在街頭持西瓜刀追逐他人，員警到場制伏後扣留該西瓜刀。
  • 扣留30日內，警方將案件移送地檢署，該刀械後續依刑事程序處理。 → 適用第38條第1項（凶器，預防危害）。
例2（延長扣留——原因未消失）
  • 某工廠經查獲儲存大量易燃爆裂物，主管機關扣留後，因安全鑑定與清運程序尚未完成，危害狀態持續，於30日屆滿前報請延長扣留2個月。 → 適用第38條第2項但書（原因未消失，延長）。
例3（以扣留機具抵罰鍰——違法）
  • 行為人未經許可採取土石被處罰鍰，主管機關扣留其挖土機。行為人不繳罰鍰，主管機關主張「續扣挖土機直到繳清罰鍰再發還」。
  • 法務部函釋指出，罰鍰屬公法上金錢給付義務，應依第二章移送執行，不得以扣留機具作為抵償或續扣工具。 → 違反第38條（混淆扣留目的與金錢執行）。
例4（水利法先行扣留——不適用第38條）
  • 主管機關依水利法第93條第2項扣留行為人的機件、工具。
  • 法務部函釋認為，該「先行扣留」是處罰前的證據保全，與行政執行法即時強制的扣留要件不同，其處理方式無第38條適用。 → 不適用第38條。
一句話總結
  • 扣留只限於軍器、凶器、危險物，目的是預防危害；30天為原則，最多再延2個月；危險消失就還，1年沒人領歸國庫；扣留物不能拿來抵罰鍰，罰鍰走欠錢的執行程序。
第39 對物之使用、處置或限制使用
  • 「遇有天災、事變或交通上、衛生上或公共安全上有危害情形，非使用或處置其土地、住宅、建築物、物品或限制其使用，不能達防護之目的時，得使用、處置或限制其使用。」
這一條是關於？
  • 遇到天災、事變或重大危害，政府別無選擇時，可以直接「借用」或「處理」人民的土地、房子、物品，甚至限制你怎麼使用它——先度過難關再說。
這一條的核心
  • 本條是行政執行法即時強制中「對物之使用、處置或限制使用」的特別授權條款，對應第36條第2項第2款後段的手段。它與第38條的「扣留」不同：扣留是「把東西拿走保管」，本條則是「直接使用你的東西、或對它做出處置、或限制你對它的使用方式」。
  • 其法律意義在於：這是國家在極端緊急狀態下，對人民財產權最深入的介入。條文列舉五種事由——天災、事變、交通上危害、衛生上危害、公共安全上危害——每一種都指向「若不動用你的財產，就無法防止損害擴大」的情境。例如風災後徵用民間卡車運送物資、傳染病爆發時徵用旅館作為隔離處所、化學槽車翻覆時使用附近土地作為圍堵作業區。
  • 從定位上看，本條是第36條一般要件（急迫性、必要性）的特別具體化。法務部函釋強調，即時強制的方法對人民權益影響較大，除具備第36條的一般要件外，須具備第39條的特別要件始得實施，並非符合「急迫」就能隨便動用人民的財產。本條的「非……不能達防護之目的」是關鍵門檻：必須證明除了動用這筆財產之外，沒有其他方法可以達成防護目的。
  • 須特別注意：本條的合法行使，不等於免費。依第41條，人民因合法即時強制遭受特別損失時，得請求損失補償。最高行政法院曾有案例：機關因機場事故緊急使用民間設備，造成設備價值減損40萬餘元，法院肯認人民得請求此項補償。
條文拆解
  • 「遇有天災、事變或交通上、衛生上或公共安全上有危害情形」
    • 五種事由，涵蓋自然災害（天災）、人為突發事件（事變）、以及交通、衛生、公共安全三大領域的危害。
    • 意義：本條的適用場景比第37條管束更廣，不限於人身危險，而是擴及財產與公共秩序的危害。
  • 「非使用或處置其土地、住宅、建築物、物品或限制其使用，不能達防護之目的時」
    • 這是最後手段性的要件：必須證明別無他法，只能動用這筆特定財產。
    • 「使用」：如徵用卡車、借用場地。
    • 「處置」：如銷毀腐壞食品、拆除危險構造物。
    • 「限制其使用」：如禁止進入某區域、限制特定設備運轉。
    • 要件：手段與目的之間須有不可替代的關聯。
  • 「得使用、處置或限制其使用」
    • 「得」表示有裁量權，但裁量受第3條比例原則拘束：即使符合要件，也須選擇對人民損害最小的方式。
為什麼要有這條規定？
  • 賦予國家在緊急狀態下調動民間資源的法律依據：天災事變時，政府的物資與設備可能不足，需要徵用民間財產。
  • 填補「扣留」無法處理的場景：扣留是把東西拿走，但有些情況需要的是「當場使用」或「就地處置」，本條提供依據。
  • 以「非……不能」設下嚴格門檻：防止行政機關以「急迫」為名，隨意動用人民財產。
  • 銜接第41條的損失補償：合法動用造成特別犧牲時，國家給予補償，調和公益與私益。
  • 區分即時強制與一般行政處分：本條不要求先下命、限期、告戒，因為緩不濟急。
白話文
  • 颱風來了，橋斷了，政府需要卡車載救難物資，但一時調不到——它可以直接徵用路邊的民間卡車。傳染病爆發，醫院不夠用，政府可以直接指定某間旅館作為隔離場所。化工廠爆炸，毒氣外洩，政府可以直接使用旁邊的空地挖壕溝圍堵，或限制你進入某個區域。
  • 但這不是讓政府隨便就能用你的東西。法律要求它必須證明：除了用你的東西，沒有別的方法可以防止危害。而且，如果合法使用造成你特別大的損失（比如卡車被操壞、旅館被徵用期間無法營業），你可以依第41條向國家請求金錢補償。
舉個例子
例1（天災徵用車輛——使用）
  • 強烈颱風造成山區道路中斷，救援物資無法運送。
  • 鎮公所緊急徵用民間四輪傳動貨車，載送飲水與糧食進入災區。 → 適用第39條（天災，非使用不能達防護目的）。
例2（衛生危害徵用場所——使用/限制使用）
  • 某地區爆發大規模傳染病，公立醫院床位不足。
  • 衛生主管機關徵用附近一家民間飯店，作為輕症患者的收治場所，並限制該飯店於徵用期間不得對外營業。 → 適用第39條（衛生上危害）。
例3（公共安全危害處置物品——處置）
  • 某倉庫存放大量已過期且腐敗的食品，散發惡臭並有傳播病菌之虞。
  • 衛生主管機關為防止危害擴大，直接將該批食品銷毀。 → 適用第39條（公共安全危害，處置物品）。
例4（不符「非……不能」要件——違法）
  • 主管機關發現某工廠違規排放廢水，認為「用他們的廠房設備來做環保示範剛好」，於是使用該工廠的設備進行宣導活動。
  • 此舉與防止危害無關，欠缺「非使用不能達防護目的」的要件。 → 不適用第39條。
例5（合法使用後請求補償）
  • 機關因機場事故緊急使用民間公司的搶救設備，造成設備價值減損。
  • 該公司依第41條請求損失補償，法院肯認其得請求實際減損的金額。 → 適用第39條（合法即時強制）＋第41條（損失補償）。
一句話總結
  • 天災事變或重大危害發生時，政府若別無他法，可以直接使用、處置或限制使用人民的財產——但必須證明「非這樣做不可」，而且合法造成特別損失的，國家要補償。
第40條 對住宅、建築物或其他處所進入之嚴格限制
  • 「對於住宅、建築物或其他處所之進入，以人民之生命、身體、財產有迫切之危害，非進入不能救護者為限。」
這一條是關於？
  • 政府不能隨便進你家——除非裡面有人命關天或財產即將重大損失的「迫切危害」，而且不進去就救不了，才能破門而入。
這一條的核心
  • 本條是行政執行法即時強制中「進入住宅、建築物或其他處所」的特別要件條款，也是第36條第2項第3款進入處所方法的具體化與嚴格限縮。住宅是人民隱私與居住自由的核心領域，憲法第22條保障人民居住自由，因此立法者對這項手段設下了即時強制各款中最嚴格的門檻。
  • 其法律意義在於：第36條的「急迫性」只是入場券，第40條才是進入住宅的真正鑰匙。法務部函釋反覆強調：「即時強制之方法對人民權益影響較大，除必須具備上開所述之緊急性與必要性之一般要件外，本法第37條至第40條更規定須具備特別要件，始得實施」。換句話說，即使符合第36條「避免急迫危險」的一般要件，若要進入住宅，還必須額外滿足第40條的「迫切危害」與「非進入不能救護」兩道門檻。
  • 從定位上看，本條是居住自由的特別保護條款。它與第37條管束（人身自由）、第38條扣留（財產權）並列，但門檻最高。實務上最典型的適用場景是消防人員破門救災、救護——內政部消防署函釋明確指出，住宅內有需緊急救護之傷病患，房門上鎖無人開門時，得依本條於必要範圍內破壞門窗強行進入。
  • 須注意本條不能用來「調查」或「取締」。法務部曾針對主管機關想進入疑似未立案老人福利機構檢查的情形明確表示：這屬於行政調查，當事人沒有配合調查的「義務」，不得依第40條即時強制進入。第40條是「救護」條款，不是「搜查」條款。
條文拆解
  • 「對於住宅、建築物或其他處所之進入」：
    • 進入的客體不限於住宅，還包括建築物（如廠房、倉庫）及其他處所（如車輛、帳篷）。但住宅受到最嚴格的保護。
    • 意義：進入意味著物理上侵入人民支配的空間，是對居住自由與隱私的直接干預。
  • 「以人民之生命、身體、財產有迫切之危害」：
    • 須有迫切性的危害，不是「可能會有危險」或「將來可能出事」，而是當下或極短時間內即將發生損害。
    • 三種法益：生命（如有人受困火場）、身體（如傷病患需急救）、財產（如瓦斯外洩即將爆炸毀屋）。三者並列，不限於人身危險。
  • 「非進入不能救護者為限」：
    • 最後手段性。必須證明除了進入之外，沒有其他方法可以排除危害。
    • 如果有替代方案（如等待屋主回來開門、從其他入口進入），就不符合本要件。
    • 消防署函釋的具體操作：若「繞道搬運」比「破門進入」對傷病患更不利，則可破門；反之，若破門耗時更久、對救護更不利，則不宜即時強制。
  • 「為限」：
    • 列舉窮盡，沒有概括擴張空間。不符合這兩項要件，就不能進入。
為什麼要有這條規定？
  • 保護居住自由與隱私：住宅是人民最私密的領域，憲法保障人民有免於國家任意侵入的自由，本條設下最高門檻。
  • 區分「救護」與「調查」：第40條的正當性來自「救護迫切危害」，不是「方便政府辦案」。沒有迫切危害，就不能用這條進門。
  • 課予執行機關嚴格論證義務：須證明「迫切」與「非進入不能」，這個論證義務本身就是對濫權的制約。
  • 銜接特別法的搜索程序：若政府要的是「找證據」或「取締違法」，應循刑事訴訟法的搜索票程序或各該法律的特別授權，不能借第40條「偷渡」。
  • 提供緊急救援的法律依據：火災、急病、瓦斯外洩等真正需要破門的場景，有明確的授權基礎，讓消防、救護人員敢於行動。
白話文
  • 政府不能隨便進你家。就算發生火災、有人受傷，它也要先問自己：裡面是不是真的有人命危險、身體快不行了、或財產馬上要出大事？而且，是不是除了破門進去，沒有別的方法可以救人？
  • 如果答案是「是」，它可以破門。如果答案是「不確定」或「還有別的路」，它就不該破門。
  • 更重要的是：政府不能假借「救護」的名義來「搜查」。如果它想進你家查你有沒有違法（比如懷疑你經營未立案的安養院），那不屬於第40條的「救護」，它必須另外找法律依據或聲請搜索票，不能拿這條當萬用鑰匙。
舉個例子
例1（火場救人——適用）
  • 公寓發生火警，消防人員判斷屋內有人受困，屋主不在場，電話也連絡不上。消防人員破壞大門進入滅火救人。 → 適用第40條（生命迫切危害，非進入不能救護）。
例2（急病救護——適用）
  • 獨居老人多日未出門，里長會同警消前往查看，敲門無人回應，從門縫聞到異味。
  • 消防人員破門進入，發現老人倒臥在地需緊急送醫。 → 適用第40條（身體迫切危害）。
例3（取締未立案機構——不適用）
  • 主管機關懷疑某民宅內經營未立案老人福利機構，想進去檢查，屋主拒絕開門。主管機關主張依第40條「進入」。
  • 法務部函釋明確表示：這屬於行政調查，當事人無配合義務，不得依第40條即時強制進入；主管機關應另尋法律依據或修法增訂強制檢查規定。 → 不適用第40條。
例4（繞道更有利——不宜破門）
  • 傷病患在屋後防火巷，需從屋內借道搬運，但屋主抗拒。
  • 消防人員評估後發現：破門排除抵抗所需時間，比繞道搬運更長，對傷病患更不利。
  • 此時不宜依第40條強制進入，應採對傷病患最有利的方式。 → 不適用第40條（不符合「非進入不能救護」的最佳利益判斷）。
一句話總結
  • 進你家是即時強制裡門檻最高的事——必須有「迫切危害」（命、身體、財產），而且「不進去就救不了」，才能破門；想用這條來「調查」或「取締」，門都沒有。
第41條 即時強制之損失補償
  1. 「人民因執行機關依法實施即時強制，致其生命、身體或財產遭受特別損失時，得請求補償。但因可歸責於該人民之事由者，不在此限。」
  2. 「前項損失補償，應以金錢為之，並以補償實際所受之特別損失為限。」
  3. 「對於執行機關所為損失補償之決定不服者，得依法提起訴願及行政訴訟。」
  4. 「損失補償，應於知有損失後，二年內向執行機關請求之。但自損失發生後，經過五年者，不得為之。」
這一條是關於？
  • 政府合法地緊急動用了你的東西、傷到了你，你雖然有忍受的義務，但如果損失超過了一般人該忍的程度，國家要用錢補給你。
這一條的核心
  • 本條是行政執行法即時強制的損失補償條款，也是整個第四章的「出口」。前面第36條到第40條講的是國家在緊急時可以對人民做什麼（管束、扣留、使用、進入），本條講的是國家做完了之後，人民的損失怎麼辦。
  • 其法律意義在於區分「補償」與「賠償」。補償的前提是國家行為合法——執行機關依法實施即時強制，沒有故意或過失不法侵害。正因為行為合法，國家本來不需要賠錢；但即時強制往往讓特定人民承受了不成比例的犧牲（例如為了救災壓壞你的車、為了滅火踩壞你的稻田），如果完全不予填補，違反「特別犧牲」的法理：公共利益應該由全體負擔，不該只讓剛好站在旁邊的人倒楣。
  • 從定位上看，本條與第10條（國家賠償）形成互補：違法執行造成損害 → 走國家賠償；合法即時強制造成特別損失 → 走本條損失補償。最高行政法院曾有案例，機關因機場事故緊急使用民間設備，設備價值減損40萬餘元，法院肯認人民得依本條請求補償。
  • 第1項但書「可歸責於該人民」是重要的排除條款。如果損失是因為人民自己的過失所致（例如違規停車阻礙救災路線、不聽勸阻闖入警戒區），國家不予補償。
條文拆解
第1項：補償請求權之成立
  • 「執行機關依法實施即時強制」：
    • 前提是國家的行為合法。若執行機關有故意或過失不法侵害，屬於國家賠償問題，不適用本條。
  • 「致其生命、身體或財產遭受特別損失」：
    • 「特別損失」是關鍵概念——須超過一般人社會生活應忍受的程度。法務部函釋及學說稱之為「特別犧牲」。
  • 「但因可歸責於該人民之事由者，不在此限」：
    • 若損失是因人民自己的過錯所導致，排除補償請求。
第2項：補償方式與範圍
  • 「以金錢為之」：
    • 不能以「幫你修好」或「換一個新的」代替，原則上給錢。
  • 「以補償實際所受之特別損失為限」：
    • 填補實際損失，不是懲罰性賠償，也不是全額賠償（須扣掉人民本來就該忍受的部分）。
第3項：救濟程序
  • 「不服補償決定 → 訴願 → 行政訴訟」：
    • 對執行機關核定的補償金額不服，走行政爭訟救濟。
第4項：請求期間
  • 「知有損失後二年內」：
    • 主觀起算點，從人民知道有損失時起算2年。
  • 「自損失發生後，經過五年者，不得為之」：
    • 客觀上限，從損失發生時起算5年，不論知不知道，超過就不能請求。
為什麼要有這條規定？
  • 貫徹特別犧牲法理：公共利益應由全體負擔，若即時強制讓特定人民承受了不成比例的損失，國家應予填補，否則違反平等原則。
  • 區分合法補償與違法賠償：國家合法行使公權力造成的損失走補償，違法侵害走國賠，兩套制度各有所司。
  • 課予人民忍受義務的對價：即時強制要求人民在緊急時配合、忍受國家介入，補償制度是這種忍受義務的正當化基礎之一。
  • 排除可歸責於人民的損失：自己違規停車擋住救災路線導致車輛被壓壞，不能請求補償——這是風險自負。
  • 設定時效，避免法律關係長期不確定：2年請求權時效、5年客觀上限，讓補償爭議有明確的終結時點。
白話文
  • 政府為了救火、救災、防止爆炸，合法地壓壞了你的車、踩爛了你的田、徵用了你的倉庫。你知道國家不是故意的，但這個損失不該只由你一個人扛——因為政府是為了大家的利益才動用你的東西。所以法律說：你可以向政府請求金錢補償，補多少？補你實際損失的那個部分。
  • 但如果損失是你自己造成的——比如你把車違規停在消防通道上，消防車為了救火把它撞開——那就不能請求補償，因為是你自己可歸責。
  • 你要在知道有損失後2年內提出請求，而且從損失發生那天起算5年內沒請求，就再也沒辦法了。政府核定補償金額後你覺得太少，可以訴願、打行政訴訟。
舉個例子
例1（國軍救災壓壞民車——適用補償）
  • 颱風救災期間，國軍兩棲突擊車涉水通行，不慎壓損路邊拋錨的民用車輛。
  • 軍方人員無故意或過失，屬合法即時強制。車主無違規停車等可歸責事由，得依第41條請求金錢補償。 → 適用第41條。
例2（穿越稻田救災——特別犧牲）
  • 重大車禍引發大火，救援指揮官評估繞道會延誤救援，決定穿越旁邊即將收穫的稻田。
  • 稻米遭碾壓毀損，稻田主人並無可歸責事由，但為公共利益承受了逾越一般容忍程度的損失。 → 適用第41條，得請求補償。
例3（違規停車阻礙救災——可歸責，不補償）
  • 民眾將車違規停在消防通道上，消防車為趕赴火場強行通過，擦撞該車。
  • 損失的發生是因為車主自己違規停車所致，屬「可歸責於該人民之事由」。 → 不適用第41條（但書排除）。
例4（對補償金額不服——救濟）
  • 機關核定補償金額為10萬元，人民認為實際損失為30萬元。人民得對該補償決定提起訴願及行政訴訟。 → 適用第41條第3項。
例5（超過5年客觀上限——不得請求）
  • 某即時強制發生於2018年，人民直到2024年才請求補償。
  • 雖然他可能2023年才知道有損失（未逾2年主觀時效），但自損失發生後已逾5年，依第4項但書不得請求。 → 不適用第41條（逾越5年客觀期間）。
一句話總結
  • 政府合法地緊急動用你的東西造成特別損失，你可以請求金錢補償；但如果是你自己有錯，就不能要；請求要在知悉後2年、發生後5年內提出，對金額不服可以打行政訴訟。
