執行原則
公平合理、兼顧權益、適當方法、必要限度
  • 兼顧權益：兼顧債權人、債務人、其他利害關係人權益。
  • 適當方法：執行方法須與執行目的具有合理關聯性。
  • 必要限度：
    • 必要性（最小侵害）：在數種同樣有效之方法中，應選擇對債務人及第三人侵害最輕微者。
    • 狹義比例性（均衡性）：執行造成之損害（如營業損失、生計困難）不得與債權人獲得之利益顯不相當。
    • 例如：禁止超額查封（查封財產總值明顯超過債權額及執行費用總和）。
職務分工與授權
法官/司法事務官命令、書記官督同執達員辦理
  • 法官/司法事務官：下達命令。例如：「去查封這台車」。
  • 書記官督同執達員辦理：
    • 書記官應監督執達員之執行行為是否符合法令及命令內容，並製作執行筆錄（如查封筆錄、測量筆錄、點交筆錄）。
    • 「督同」即「監督並會同」，表示書記官居於監督者地位，而非單純陪同。
    • 執達員：實際動手貼封條、搬東西，其行為受書記官之監督。
除拘提、管收外，均得由司法事務官辦理之
  • 廣泛授權：強制執行法中各條文明定「由法官為之」之職權，除「拘提」、「管收」外，均得由司法事務官辦理之。
  • 舉例：
    • 核發執行命令 → 可由司法事務官辦理
    • 決定分配方法 → 可由司法事務官辦理
    • 裁定拘提債務人 → 必須由法官裁定
執行名義
執行名義 = 強制執行的依據
本法承認的執行名義如下：
  1. 確定判決：確定之終局判決。
    • 「確定」指判決已窮盡通常救濟途徑（上訴期間屆滿或經最高法院駁回），不得再聲明不服。
    • 「終局判決」指對訴訟標的之全部或一部為終結審判之判決（相對於「中間判決」或「裁定」）。
  2. 假扣押、假處分、假執行：及其他依民事訴訟法得為強制執行之裁判。
    • 假扣押：就金錢請求，為保全強制執行而為之暫時性裁定。
    • 假處分：就金錢以外之請求，為保全強制執行而為之暫時性裁定。
    • 假執行：判決確定前，法院為使債權人得預先執行而宣告之裁判。雖未確定，仍可作為執行名義。
  3. 依民事訴訟法成立之和解或調解
    • 「和解」：依民事訴訟法於訴訟繫屬中成立之「訴訟上和解」，與確定判決有同一效力。
    • 「調解」：依民事訴訟法由法院調解成立者，或依鄉鎮市調解條例成立並經法院核定者，均得為執行名義。
  4. 依公證法規定得為強制執行之公證書
    • 指公證人依公證法就特定事項（例如建築物定期租用）所製作之公證書（例如租約），且載明「應逕受強制執行」者。
    • 此類執行名義無須經法院判決，節省時間與勞費。
  5. 法院許可拍賣抵押物/質物之裁定
    • 抵押權人、質權人行使擔保物權時，得聲請法院為「許可拍賣抵押物/質物」之裁定。
    • 此為「非訟事件」，法院僅形式審查擔保物權是否合法成立，不審查實體債權是否存在。
    • 經裁定許可後，該裁定即為執行名義。
  6. 其他依法律之規定，得為強制執行名義者
    • 概括條款，以因應其他法律所規定之執行名義。
執行名義附條件/期限者，需條件已成就/期限已到
  • 「附條件」：
    • 例如判決主文載明「被告應於原告交付貨物後，給付價金」，則需先成就「交付貨物」條件。
    • 例如假執行宣告常附有「債權人供擔保後，得為假執行」， 則債權人須先提存擔保金，始得開始執行。
  • 「附期限」：
    • 例如判決載明「被告應於民國114年1月1日起按月給付贍養費」，則於114年1月1日前不得執行。
執行名義有對待給付者，債權人需「已經給付」
  • 對待給付：指雙務契約中，雙方互負給付義務，例如「被告應於原告交付房屋之同時，給付價金」。
  • 已經給付：債權人已完成自己之給付義務。 或已經提出而債務人拒絕受領或不能受領。
外國法院確定判決：要經過台灣法院「判決宣示許可」才行
  • 判決宣示許可：債權人須先提起「許可執行之訴」，取得我國法院之「許可執行判決」。
    • 這個「許可執行之訴」由債務人住所地之法院管轄。
  • 許可前提：無民事訴訟法第402條無效事由 ：外國法院之確定判決，有下列各款情形之一者，不認其效力：
    1. 欠缺管轄權：依中華民國法律，外國法院無管轄權者（採「管轄權有無之獨立審查」）。
    2. 敗訴之被告未應訴者：但「起訴通知或命令已於相當時期合法送達， 或依中華民國法律上之協助送達」者，不在此限。
    3. 違背公序良俗：判決之承認或執行，有背於中華民國公共秩序或善良風俗者（例如承認賭債判決）。
    4. 無相互承認：中華民國法院之判決，在外國亦不予承認者（「相互承認原則」之具體化）。
執行效力擴張
  • 執行力擴張：讓執行名義的效力在特定情形下，可擴張到「當事人以外的人」
  • 擴張目的：避免當事人藉移轉、人頭方式逃避執行
擴張對象一：「訴訟繫屬後」為「當事人之繼受人」
  • 「訴訟繫屬後」：指該訴訟事件起訴後（含上訴程序）。適用於以「確定終局判決」為執行名義者。
  • 「繼受人」：包括「一般繼受人」和「特定繼受人」。
    • 一般繼受人：自然人死亡之繼承人、法人合併後之存續公司等。
    • 特定繼受人：買受特定不動產、受讓特定債權之人。
    關鍵在於：只要是在訴訟繫屬後，從當事人那裡取得「請求之標的物」或「與請求標的物有關之權利」的人，都要受判決執行力的拘束。
  • 例子：
    • 甲對乙提起返還借款訴訟，判決確定命乙給付100萬元。
    • 判決確定後，乙死亡，其子丙繼承乙之遺產（包括該筆債務）。 → 丙於「訴訟繫屬後」為當事人乙之「繼受人」
    • 甲持確定判決聲請執行丙之財產 → 可以。丙為乙之繼受人，判決執行力及於丙。
擴張對象二：「訴訟繫屬後」為「當事人或其繼受人」而「占有請求之標的物」
  • 指非以自己之名義占有， 而係為債務人（或其繼受人）之利益而占有執行標的物。
  • 此等占有人縱非當事人，亦須容忍執行（例如交出標的物），且不得以自己占有為由排除執行。
  • 例子：
    • 法院確定判決命乙應返還其所有之古董花瓶予甲。
    • 判決確定後，乙將該花瓶交由員工丙保管，丙將花瓶置於公司倉庫。 → 丙於「訴訟繫屬後」為當事人乙之利益而占有請求之標的物（古董花瓶）
    • 甲持判決聲請執行，執行處命丙交出花瓶 → 丙不得拒絕交出。丙為甲之「占有輔助人」，判決執行力及於丙。
擴張對象三：「為他人而為原告或被告者」，效力及於「該他人」
  • 指判決書上記載的當事人（原告或被告），並非實質權利義務歸屬主體，而是「為他人」進行訴訟（即訴訟擔當）。
  • 此等被代理之「該他人」，雖非判決書上記載之當事人，仍應受判決執行力所及。債權人得持判決對「該他人」聲請強制執行，或由「該他人」持判決對債務人聲請強制執行（視具體情況而定）。
  • 常見類型：
    • 法定訴訟擔當：如法定代理人代理未成年人、破產管理人代理破產人、遺產管理人代理繼承人。
    • 任意訴訟擔當：如選定當事人、團體訴訟。
  • 例子一：法定代理人代理未成年人
    • 小明（7歲）借給老王100萬元，老王不還錢。
    • 小明的爸爸（法定代理人）以「小明之名義」起訴老王，法院判決老王應給付小明100萬元確定。
    • 判決確定後，爸爸過世，小明換了新的監護人（媽媽）。
    • 爸爸是「為他人（小明）而為原告」，判決執行力及於「該他人」小明本人。
    • → 小明本人（由媽媽代理）得持該確定判決，對老王聲請強制執行。
  • 例子二：破產管理人代理破產人對外追討債權
    • 甲公司破產，法院選任乙為破產管理人。乙發現丙公司積欠甲公司貨款300萬元，遂以「甲公司名義」對丙公司起訴。
    • 法院判決丙公司應給付甲公司300萬元確定。
    • 破產程序中，由乙（破產管理人）持判決對丙公司強制執行，執行所得歸入破產財團分配予債權人。
    • 若破產終結後甲公司復權，則由甲公司本人持判決續行執行。 → 乙是「為他人（甲公司）而為原告」，判決執行力及於「該他人」甲公司。
擴張對象四：「訴訟繫屬後」為「該他人」之繼受人或為其「占有請求之標的物」
  • 「該他人」：即「擴張對象三」所指的實質權利義務歸屬主體。
  • 繼受人：即「擴張對象一」所指的情況，也適用於「該他人」。
  • 為其占有：即「擴張對象二」所指的情況，也適用於「該他人」。
為何強調「訴訟繫屬後」：區隔善意取得者
  • 訴訟繫屬後取得的，推定非善意取得，不受保護，判決效力可以及於他。
無「訴訟繫屬」的執行名義：以「執行名義成立時」作為分界
  • 確定終局判決「執行力擴張」的規定，「準用」於其他執行名義。
  • 其他執行名義沒有「訴訟繫屬」的時間點，原則上以「執行名義成立時」作為分界。例子：
    • 本票裁定：以「裁定成立時」作為分界。
    • 公證書：用「公證書作成時」。
  • 例子：
    • 甲持本票向法院聲請對乙為本票裁定。
    • 裁定成立後，乙把房子過戶給丙。
    • 甲可持本票裁定對丙執行。 → 丙於「執行名義成立後」為當事人之繼受人
債權人聲請強制執行
  • 債權人聲請強制執行，應以書狀提出於執行法院
  • 書狀應表明：1.當事人 2.請求實現之權利
    1. 當事人：即債權人（聲請人）與債務人（執行相對人）。 應載明姓名、住所或營業所、身分證字號或統一編號等足資識別之資料。
    2. 請求實現之權利：指債權人欲實現之實體權利內容。應與執行名義所載之給付內容一致，且須具體明確，使執行法院得據以決定執行方法及標的。
      • 例如「給付新臺幣100萬元」、 「返還坐落某地號之房屋」、「交付特定型號之機器」等。
  • 書狀宜記載：執行之標的物、應為之執行行為或本法所定其他事項
    • 宜記載：「建議性」規定，非法定必要事項。惟實務上債權人若盡量提供，有助於執行法院迅速進行。
    • 執行之標的物：指債務人特定之財產（例如存款帳戶、不動產地號、車輛車號）。
    • 應為之執行行為：例如「查封債務人所有之A車」、「拍賣債務人所有之B地」、 「收取債務人對第三人之C債權」等。
    • 本法所定其他事項：例如是否聲請拘提管收、是否請求核發執行命令等。
債務人死亡不停止執行
強制執行開始後，債務人死亡者：得續行強制執行
  • 「開始後」：指執行法院已收受聲請書狀並繫屬（或已核發執行命令）之後，債務人始死亡。
    • 若聲請前債務人即已死亡，則應以其繼承人為債務人聲請執行。
  • 得續行強制執行：此為「執行程序不中斷原則」之明文。
    • 債務人死亡後，其權利義務由繼承人概括繼承， 故執行標的轉為繼承人之固有財產或遺產。
債務人死亡，而「繼承人不明」時：執行法院得依聲請，選任「特別代理人」
  • 繼承人不明：包括以下情況：
    • 繼承人有無不明者：例如債務人無配偶、子女，亦無法定順位繼承人，或無法確認是否有繼承人存在。
    • 繼承人所在不明者：繼承人存在但行蹤不明，無法送達或聯繫。
    • 繼承人是否承認繼承不明者：繼承人尚未為承認或拋棄繼承之表示，致其是否為債務人之概括繼受人不確定。
    • 繼承人因故不能管理遺產者：例如繼承人為未成年人、 受監護宣告人、或因疾病、出國等因素事實上無法管理遺產。
  • 依聲請：須由債權人或利害關係人（如遺產債權人、繼承人之債權人）主動向法院聲請。
  • 特別代理人：為執行程序之目的而暫時代理債務人遺產之地位。其權限僅限於執行程序中之行為（如收受執行命令、參與分配等），不及於遺產之管理或處分。
但有遺囑執行人或遺產管理人者，無庸另行選任
  • 若有遺囑執行人（依遺囑執行遺產相關事務）或遺產管理人（由法院選任）， 則該等人員本即得代表遺產進行執行程序，自無庸另行選任特別代理人。
「自助行為」與擬制執行聲請
自助行為：債權人依民法第151條，自行拘束債務人之自由或押收其財產，而聲請法院處理者
  • 合法自助行為要件：
    1. 急迫性：不及受法院或其他有關機關援助。
    2. 必要性：非此時為之則請求權無法實現。
    3. 即時性：儘速向法院聲請處理（最遲24小時內）。
債權人有執行名義者，其自助行為「視為強制執行之聲請」
  • 前提要件：實行「合法自助行為」之債權人，已有本法規定之有效執行名義（如確定判決、公證書、拍賣抵押物裁定等）。
  • 法律效果：
    1. 視為強制執行之聲請。
      • 若債權人於自助行為前「尚未」向法院提出書面執行聲請，則視同向法院聲請強制執行（聲請時間為其向法院「聲請處理」的時間）。
      • 若債權人之前已經聲請強制執行，其自助行為視為「執行程序」（即法律效果2）。
    2. 其自助行為視為「執行程序」。
      • 其實施之自助行為，法院得予追認，視為此一強制執行案件中，正式之執行程序。
      • 例如：債權人「押收財產」，法院得視為正式之查封程序。
強制執行之管轄法院
管轄法院：1.標的物所在地 2.應為執行行為地（債權人得擇一聲請）
  1. 標的物所在地：指執行名義所載之「特定標的物」之物理位置。
    • 不動產：土地或房屋之坐落所在地（以登記地為準）; 動產：查封時該動產之實際存放地點。
  2. 應為執行行為地：指執行法院實際進行某個執行動作（如查封、解交、訊問債務人）的地方，不一定是標的物所在地。
    • 例如：執行名義命債務人「應將汽車停放於某停車場返還」，該停車場即為執行行為地。
替代選項：債務人之住居所、營業所所在地法院
  • 適用前提：「無特定標的物」或「標的物所在不明」之情形（例如債權人僅知債務人有財產，但不知具體為何物或何處）。
同一強制執行，數法院有管轄權者，債權人擇一聲請即可
  • 例如：債務人於台北有不動產、於高雄有存款，則台北地院與高雄地院均有管轄權，債權人擇一向台北地院或高雄地院聲請即可。
受理法院須在「他法院管轄區」內實施執行行為時，應「囑託該他法院為之」
  • 若受理法院（例如台北地院）須在非其轄區（例如台中）為查封行為，應以「囑託」方式，委由台中地院代為執行。
  • 「囑託執行」之效果：受託法院所為之執行行為，視同囑託法院自己為之。
執行前「無庸傳訊當事人」之原則與例外
開始強制執行前，無庸傳訊當事人
  • 開始強制執行前：指執行法院受理聲請後，尚未核發執行命令或為查封行為之前之準備階段。
    • 一旦法院已核發執行命令（例如扣押命令）或已至現場查封，即屬「執行開始後」，非此適用範圍。
  • 無庸傳訊當事人：原則上不需要傳喚債權人或債務人來法院開庭或詢問。
    • 此即執行程序之「形式審查」、「書面審理」原則。
例外情況：為調查「法定要件」或「執行之標的物」，而有必要傳訊當事人時
  • 「法定要件」：指執行程序之合法性前提，例如：
    • 執行名義是否有效
    • 執行名義是否附有條件、期限，且條件已成就、期限已屆至
  • 「執行之標的物」：指執行之具體對象，例如：
    • 該標的物是否確實為債務人所有（例如第三人主張所有權）
    • 標的物之種類、數量、位置是否明確
延緩執行與變更執行期日
延緩執行：經債權人同意，一次最長延3個月，最多延兩次
  • 適用情況：「實施」強制執行時。例如：法院要查封債務人之房屋時。
  • 暫緩前提：經債權人同意。例如：債務人為避免查封而向債權人請求給予3個月時間籌款清償。
  • 「一次最長延3個月」：法院得定較短之期限（例如1個月），但不得逾3個月。
  • 「最多延兩次」：第一次延緩期滿後，債權人可聲請續行。之後得「再同意」延緩一次。亦即：最多延緩兩次。
延緩期滿後，債權人未於10日內聲請續行者，視同撤回
  • 延緩期間屆滿後，執行法院應「通知」債權人（書面通知）限期聲請續行。
  • 「10日內」：自債權人收到法院通知翌日起算。
  • 「聲請續行」：債權人向法院請求「繼續執行」。
  • 「視同撤回」：若逾期未聲請續行，視同債權人自行「撤回其強制執行之聲請」。執行法院應終結執行事件，已查封之財產應啟封或撤銷扣押。
「法院主動變更」執行期日：「有特別情事、繼續執行顯非適當者」
  • 例如：債務人或其家屬突發重病，若繼續執行顯非適當。此時可先將執行期日往後延。
