不動產強制執行之方法與合併拍賣

不動產之強制執行，以「查封」、「拍賣」、「強制管理」之方法行之。以上方法「得併行之」
  • 不動產：土地、建築物、其他定著物。
  • 查封：保全程序，禁止債務人處分。
  • 拍賣：公開競價變價。
  • 強制管理：委託管理人管理不動產，以收益（如租金）清償債務。
  • 得併行之：「性質上許可」且「認為適當」時，得合併使用。例如先強制管理「收取租金」以清償債務，若租金不足以清償，再行「拍賣」變價。
不動產合併拍賣原則
土地與建物合併拍賣：建築物及其基地「同屬債務人所有」者，得「合併查封、拍賣」
  • 若「建物」與「土地」均為「債務人所有」，應「合併拍賣」， 避免「土地所有權」與「建物所有權」分屬不同人。
動產與不動產合併拍賣：應拍賣之財產「有動產及不動產」者，執行法院得合併拍賣之。合併拍賣之動產，適用關於不動產拍賣之規定
  • 例如：拍賣「工廠」時，土地（不動產）與機器設備（動產）合併拍賣，以維持整體營運價值。
  • 得合併拍賣：法院有裁量權。
  • 適用關於不動產拍賣之規定：合併拍賣之動產，其程序應依「不動產拍賣」之規定 （如須公告、鑑價、訂底價等，程序較嚴謹），而非依動產拍賣之簡便程序。
例1.
  • 債務人甲所有出租之房屋，執行法院先以「強制管理」方法，委託管理人按月收取租金清償債務。 → 不動產之強制執行，以「查封」、「拍賣」、「強制管理」之方法行之
  • 若租金仍不足，再行「拍賣」房屋。 → 「查封」、「拍賣」、「強制管理」之執行方法「得併行之」
例2.
  • 債務人乙所有之房屋及基地（均為乙所有）。
  • 執行法院「合併查封、拍賣」，使拍定人取得完整產權。 → 建築物及其基地「同屬債務人所有」者，得「合併查封、拍賣」
例3.
  • 債務人丙之工廠（土地及建物）內有機器設備（動產）。
  • 執行法院將「全部」合併拍賣，並適用「不動產拍賣」程序（如須公告、鑑價）。
  • → 應拍賣之財產有動產及不動產者，執行法院得合併拍賣之。合併拍賣之動產，適用關於不動產拍賣之規定
一句話總結
  • 不動產執行可用查封、拍賣、強制管理。
  • 建物與基地同屬債務人可合併拍賣。
  • 動產與不動產可合併拍賣，並適用不動產拍賣規定。

不動產查封之方法與查封登記

查封不動產，由執行法官「命書記官督同執達員」，以「揭示」、「封閉」、「追繳契據」方法行之。以上方法「得併用之」
  • 法官命書記官督同執達員：執行主體與動產查封相同：法官下令、書記官監督、執達員執行。
  • 揭示：張貼「查封公告」於不動產之「門口、牆壁」或「土地界標處」。使「不特定第三人」知悉查封事實。
  • 封閉：將建物「上鎖」、「貼封條」或「圍籬」，禁止出入。適用於「房屋」或「有圍牆之土地」。
  • 追繳契據：命債務人交付「所有權狀」、「他項權利證明書」、「租約」等文件。若債務人「拒絕交付」，執行法院得「強制取交」。
  • 得併用之：得「同時」使用多種方法（如揭示＋封閉＋追繳契據）。
通知查封登記之效力
已登記之不動產，執行法院應「先通知登記機關」為「查封登記」
  • 已登記：已於地政機關辦理「土地總登記」或「建物所有權第一次登記」。
  • 先通知登記機關：強調實施查封應「立即通知」登記機關。先通知再查封也是合法的，但時間點相距不宜過久。
  • 查封登記：登記機關應於「土地登記簿」上為「查封登記」註記。
其通知於「查封實施前」到達登記機關時，「亦發生查封之效力」
  • 若法院「先」發函通知地政機關，且該通知「早於」現場查封行為（如揭示、封閉）到達登記機關，則查封之效力「自通知到達時」即已發生。
  • 此為「避免時差」之規定——若現場查封與登記有「時間差」，以「先發生者」為準。
例1.
  • 執行法院查封債務人甲之房屋。
  • 書記官督同執達員於房屋大門張貼「查封公告」（揭示），並於門上貼封條及加鎖（封閉）。並命甲交出「土地所有權狀」及「他項權利證明書」。
  • → 「揭示」、「封閉」、「追繳契據」執行方法「得併用之」
例2.
  • 執行法院於7月10日上午9時發函通知地政機關辦理查封登記； 該通知於7月10日上午11時到達地政機關。
  • 執行人員於7月10日下午2時始現場揭示查封。查封效力自「上午11時」即發生。
  • → 通知於「查封實施前」到達登記機關時，「亦發生查封之效力」
一句話總結
  • 查封可用揭示、封閉、追繳契據三種方法，必要時可併用。
  • 已登記不動產須通知地政機關辦查封登記，通知先到則效力先發生。

不動產查封筆錄之作成與應載事項

查封時，書記官應作成「查封筆錄」。查封人員及「保管人」、「見證人」應於查封筆錄「簽名」
  • 應作成「查封筆錄」：書記官須於「查封現場」或「查封後立即」製作。
  • 查封人員：書記官、執達員（及執行法官，若有到場）。
  • 保管人：受託保管不動產之人。
  • 見證人：查封時債務人不在場者，到場見證之「家屬」或「鄰居」。
查封筆錄應載明下列事項：
  • 已登記：已於地政機關辦理「土地總登記」或「建物所有權第一次登記」。
  • 先通知登記機關：強調實施查封應「立即通知」登記機關。先通知再查封也是合法的，但時間點相距不宜過久。
  • 查封登記：登記機關應於「土地登記簿」上為「查封登記」註記。
其通知於「查封實施前」到達登記機關時，「亦發生查封之效力」
  1. 為查封原因之權利
    • 即「執行名義」（如確定判決、拍賣抵押物裁定）。
  2. 不動產之所在地、種類、實際狀況、使用情形
    • 「所在地」：土地地號、建物門牌號碼。
    • 「種類」：土地（旱地、建地）、建物（透天、公寓、大樓）。
    • 「實際狀況」：幾層樓、面積、結構（RC、磚造）、屋齡。
    • 「使用情形」：自住、出租、營業、空置、有無增建。
  3. 「現場調查所得」之海砂屋、輻射屋、地震受創、嚴重漏水、火災受損、建物內有非自然死亡或其他「足以影響交易之特殊情事」及其應記明之事項
    • 「現場調查所得」：限於「查封時」以「目視」、「訪談」或「文件查閱」所得之資訊。
      • 執行人員有「現況調查權」。被調查人有配合義務。
    • 重大瑕疵： 海砂屋、輻射屋、地震受創（結構受損）、嚴重漏水（長期滲漏）、火災受損（燒毀或煙燻） 、建物內有非自然死亡（兇宅——如自殺、他殺）
    • 「足以影響交易之特殊情事」：如「占用鄰地」、「鄰近高壓電塔」、「土壤污染」等。
  4. 債權人及債務人
  5. 查封方法及其實施之年、月、日、時
    • 查封方法：揭示、封閉、追繳契據
  6. 查封之不動產有保管人者，其保管人
    • 保管人通常為「債務人本人」或「第三人」（如管理員）。
例1.
  • 書記官查封債務人甲之房屋，訪談鄰居得知該屋曾發生「凶殺案」， 即於查封筆錄記載「建物內有非自然死亡（凶殺）」。
  • → 查封筆錄應載明「現場調查所得」之「重大瑕疵」、「足以影響交易之特殊情事」
例2.
  • 書記官查封乙之房屋，現場發現壁癌及滲水痕跡，但查封筆錄未予記載。
  • 拍定人丙拍定後發現「嚴重漏水」，主張法院未揭露瑕疵。
  • → 書記官應記載而未記載，筆錄有瑕疵
一句話總結
  • 查封時須製作筆錄，詳細記載不動產現況及特殊瑕疵（如海砂屋、兇宅等），並由在場人員簽名確認。

不動產現況與權利關係之調查權限及違反效果

不動產現況調查權限
執行法官或書記官，為「調查不動產現況」或「其他權利關係」得依下列方式行之：
  • 調查不動產現況：海砂屋、輻射屋、地震受創、嚴重漏水、火災受損、非自然死亡等重大瑕疵，或其他「足以影響交易之特殊情事」。
  • 其他權利關係：如「租賃關係」、「占用情形」、「共有關係」、「抵押權設定」等。
  1. 「開啟門鎖進入」不動產或「訊問」債務人或「占有之第三人」，並得「命其提出有關文書」
    • 開啟門鎖進入：得「強制開鎖」進入建物（如有鎖門），無須債務人同意。
    • 訊問：法院得「傳喚」債務人或「占有之第三人」到場說明。
    • 有關文書：如「租約」、「買賣契約」、「使用執照」、「檢測報告」等。
  2. 向警察、其他有關機關/團體調查，受調查者「不得拒絕」
    • 有關機關：地政機關（查登記資料）、戶政機關（查設籍）、建管機關（查使用執照）。
    • 有關團體：如公寓大廈管理委員會、農會、公會。
    • 不得拒絕：受調查之機關/團體負有「協力義務」。
不配合調查之法律效果
債務人不配合調查：得管收（需符合法定要件 + 法院裁量權）
  • 適用情況：「債務人」無正當理由「不陳述/虛偽陳述」或「不提出文書/提出虛偽文書」者
    • 無正當理由：如無「保密義務」、「不自證己罪」等正當事由。
  • 發動方式：依債權人聲請或依職權
    • 法院得「依職權」主動為之，也可以「依債權人聲請」為之。
  • 程序要件：1.應先訊問債務人 2.認定「非予管收，顯難查明不動產狀況」
    • 訊問債務人：管收前須「開庭訊問」，給予陳述機會。
    • 非予管收，顯難查明：須認定「管收為最後手段」——若尚有其他調查方法，即不得管收。
第三人不配合調查：得處1萬5千元以下罰鍰（法院裁量權）
  • 適用情況：1.無正當理由「不陳述/虛偽陳述」或「不提出文書/提出虛偽文書」者 2.拒絕到場
    • 拒絕到場：經合法通知無正當理由不到場。
  • 發動方式：法院裁定，得處1萬5千元以下罰鍰。
例1.
  • 債務人甲拒絕開門，執行法官依本條強制「開鎖」進入屋內，調查有無漏水及海砂屋情形。
  • → 執行法官或書記官，為「調查不動產現況」或「其他權利關係」，得「開啟門鎖進入」不動產
例2.
  • 書記官向管區警察調查該建物是否曾發生「非自然死亡」事件，警察不得拒絕提供資訊。
  • → 執行法官或書記官，為「調查不動產現況」，得向警察調查，受調查者「不得拒絕」
例3.
  • 債務人乙經訊問後，謊稱房屋「無漏水」，但現場明顯有壁癌及滲水痕跡。
  • 法院認非管收無法查明，裁定管收乙。
  • → 「債務人」受調查時「不陳述/虛偽陳述」，經法院訊問後認定「非予管收，顯難查明不動產狀況」者，得依職權管收
例4.
  • 承租人丙經合法通知拒絕到場陳述租約內容，法院裁定處丙「罰鍰1萬元」。
  • → 第三人不配合調查：得處1萬5千元以下罰鍰（法院裁量權）
一句話總結
  • 法院為「調查不動產現況」可強制開鎖、訊問當事人、向機關調資料。
  • 債務人拒絕陳述或說謊可管收（須經訊問及最後手段）。
  • 第三人拒絕可罰1萬5千元以下。

查封不動產之保管與使用

已查封之不動產，以「債務人為保管人者」，債務人「仍得為從來之管理或使用」
  • 以債務人為保管人：「揭示」或「封閉」後，將不動產「交由債務人保管」（因其仍居住或使用該不動產，此為最常見之方式）。
  • 仍得為從來之管理或使用：指查封前「慣常」之管理使用方式。包括自住、出租、營業、耕作等。
由債務人以外之人保管者，法院「得許」債務人於「必要範圍內」管理或使用之
  • 得許：法院有裁量權，得「許可」或「拒絕」。
  • 必要範圍內：限於「為維護不動產價值」或「債務人基本生活所需」之範圍。
    • 例如：允許債務人「進入取回重要物品」、允許「修繕漏水」、允許「繼續耕種已播種之土地」。
    • 若債務人之使用將「損及查封物價值」，法院得「不准許」或「附加條件」。
例1.
  • 執行法院查封債務人甲之房屋，由甲保管（甲仍居住於內）。
  • 甲得繼續居住，但不得出售或設定抵押。
  • → 查封之不動產，以「債務人為保管人者」，債務人「仍得為從來之管理或使用」
例2.
  • 乙之出租公寓被查封，由乙保管。
  • 乙得繼續向房客收取租金，但租金應交付法院（法定孳息）。
  • → 「出租」也屬於「從來之管理或使用」
例3.
  • 查封丙之空屋，由管理公司保管。
  • 丙向法院請求「進入取回個人重要文件」，法院許可丙於「必要範圍內」進入。
  • → 由債務人以外之人保管者，法院「得許」債務人於「必要範圍內」管理或使用之
一句話總結
    已查封之不動產：
  • 由債務人保管時，仍可照常使用。
  • 由他人保管時，法院可許債務人於必要範圍內使用。

查封不動產之委託保管或管理

查封不動產之「保管或管理」，法院得「委託機關/團體」為之
  • 保管：維持查封物「現狀」——防止他人侵入、毀損或擅自處分。
  • 管理：除保管外，尚含「積極利用」——如「收取租金」、「修繕維護」、「種植作物」等（以收益清償債務）。
  • 得委託：法院有裁量權，得「委託」或「自行保管」。
  • 機關/團體：有關機關、自治團體、商業團體、工業團體或其他團體（須為「團體」或「法人」）。
例1.
  • 查封債務人甲之大片土地，執行法院委託「地政機關」管理，定期巡查有無占用或濫墾。
例2.
  • 查封乙之果園，法院委託「當地農會」管理，負責修枝、施肥、採收等農作管理，收益納入執行所得。
例3.
  • 查封丙之公寓房屋，法院委託該大廈之「管理委員會」保管（例如巡視有無遭侵入）。
一句話總結
  • 執行法院可將查封的不動產委託給有關機關或團體（如農會、公會）來保管或管理，以減輕法院負擔並善用專業能力。

不動產拍賣之鑑價與底價核定

拍賣不動產，執行法院「應命鑑定人估價」，經「核定」後，做為拍賣「底價」
  • 應命：強制義務，法院不得省略鑑定程序。
  • 鑑定人：須具備「不動產估價」專業資格。
  • 估價：應以「專業估價方法」為之，並出具「書面估價報告」。
  • 核定：法院應「審查」估價報告之合理性，必要時得「依職權」調整。
  • 底價：即「拍賣最低價額」。應買人出價須「達到或超過」此價格，始得拍定。
例1.
  • 執行法院拍賣債務人甲之土地，委請「不動產估價師」乙出具估價報告， 估定市價800萬元。
  • 法院參酌「當事人意見」及「近期實價登錄」後，認該報告「過高」，核定底價為750萬元。
  • → 法院有「核定」權，得調整底價
一句話總結
  • 拍賣不動產前，法院必須請專業估價師估價，經核定後作為拍賣底價，確保價格客觀合理。

無拍賣實益之通知與債權人聲明續拍權利

抵押權、優先受償權人聲請拍賣者，不適用「無拍賣實益」規定
  • 「無拍賣實益」指不足清償「優先債權」及「執行費用」者。
  • 抵押權、優先受償權人就是「優先債權」，沒有「無拍賣實益」問題，因此不適用以下規定之程序。
無拍賣實益：不動產拍賣底價，不足清償「優先債權」及「執行費用」者
  • 優先債權：如「抵押權」、「稅捐優先權」。
  • 執行費用：鑑價費、公告費等。
  • 通知債權人：法院須「主動」通知，讓債權人知道「底價不足清償」的情況。
前置通知義務：法院應將「無拍賣實益」事由「通知債權人」
  • 法院應主動告知債權人「無拍賣實益」（底價不足清償），給債權人選擇機會。
後續處理方式一、依債權人聲請，繼續拍賣
  • 要件（須全部具備）：
    1. 債權人於受通知後「七日內提出聲請」
    2. 債權人「舉證」該不動產價值「高於」底價，拍賣後仍有餘額; 或主動「提高底價」至「超過」優先債權＋費用之金額
    3. 債權人「承諾」若拍賣不成功，願「負擔」全部費用
後續處理方式二、撤銷查封，將不動產返還債務人（「強制管理」除外）
  • 適用情況：債權人逾期未聲請繼續拍賣。即不符合「處理方式一」要件時。
  • 原則：撤銷查封，將不動產返還債務人。
  • 例外：若不動產已付「強制管理」（收取租金等收益），則「不撤銷查封」。
例1.
  • 拍賣債務人甲之房屋，底價300萬元。
  • 但第一順位抵押權人乙之債權額350萬元，執行費用20萬元，底價不足清償。 → 無拍賣實益：不動產拍賣底價，不足清償「優先債權」及「執行費用」者
  • 法院通知普通債權人丙，丙於7日內未聲請續拍，法院即「撤銷查封」，返還房屋予甲。
  • → 債權人受通知後七日內「未提出聲請」，撤銷查封，將不動產返還債務人
例2.
  • 延續例1，丙於7日內「證明」該屋「有賸餘可能」並「願負擔費用」，法院續行拍賣。
一句話總結
  • 底價不夠還優先債權和費用時，法院通知債權人。
  • 債權人可在7天內聲請續拍並願負擔費用，否則撤封還債務人。

無拍賣實益續拍不成之處理

抵押權、優先受償權人聲請拍賣者，不適用「無拍賣實益」規定
  • 「無拍賣實益」指不足清償「優先債權」及「執行費用」者。
  • 抵押權、優先受償權人就是「優先債權」，沒有「無拍賣實益」問題，因此不適用以下規定之程序。
適用情況：不動產「無拍賣實益」，依債權人聲請「繼續拍賣而未拍定」者
  • 繼續拍賣而未拍定：續行拍賣「無人應買」或「低於底價」。
1.債權人是否願意承受
  • 由債權人承受為「優先選項」。如債權人不願承受，繼續下一步驟處理。
2.法院公告3個月，以「原定拍賣條件」徵求應買人
  • 原定拍賣條件：按原底價及付款條件。
  • 徵求應買人：不特定第三人得「申請應買」。
  • 公告期間「有人申請應買」者：法院應「徵詢」雙方意見，再決定是否「許可」。 （由債權人承受為「優先選項」）
  • 債權人復願承受者亦同：債權人於公告期間「改變心意」願承受者，亦得為之。
3.公告期間無人應買或承受者，撤銷查封（「強制管理」除外）
  • 原則：3個月期滿仍無人問津，即撤銷查封，將不動產返還債務人。
  • 例外：若不動產已付「強制管理」（收取租金等收益），則「不撤銷查封」。
抵押權、優先受償權人聲請拍賣者，不適用「無拍賣實益」此規定
例1.
  • 拍賣債務人甲之房屋，底價300萬元。
  • 但第一順位抵押權人乙之債權額350萬元，執行費用20萬元，底價不足清償。
  • 法院通知普通債權人丙，丙於7日內「證明」該屋「有賸餘可能」並「願負擔費用」，法院續行拍賣。
  • 拍賣仍無人應買，丙亦不承受。
  • 法院即「公告」3個月許他人應買，期滿無人應買，法院「撤封還甲」。
  • → 公告期間無人應買或承受者，撤銷查封
一句話總結
  • 再拍賣賣不掉則公告3個月應買，否則撤封。

不動產拍賣之公告與應載事項

拍賣不動產，應由執行法院「先期公告」。並載明下列事項：
  1. 不動產之所在地、種類、實際狀況、占有使用情形、調查所得之海砂屋、輻射屋、地震受創、嚴重漏水、火災受損、建物內有非自然死亡或其他足以影響交易之特殊情事及其應記明之事項
    • 占有使用情形：自住、出租、空置、有無占用。
    • 調查所得之重大瑕疵、其他足以影響交易之特殊情事：須以「查封時調查所得」為準。
      • 若「未記載」此等瑕疵，拍定人得主張「詐欺」或請求「撤銷拍賣」（實務上極難，但仍有可能性）。
  2. 拍賣之原因、日期及場所。如以投標方法拍賣者，其開標之日時及場所，定有保證金額者，其金額
  3. 拍賣最低價額
  4. 交付價金之期限
  5. 閱覽查封筆錄之處所及日、時
    • 應買人得於拍賣前「閱覽」查封筆錄，以了解不動產詳細狀況。
  6. 定有應買資格或條件者，其資格或條件
  7. 拍賣後不點交者，其原因
    • 若「不點交」，須載明原因——如「現由第三人承租中（租期未滿）」、「第三人占用中」等。
  8. 定有應買人察看拍賣物之日、時者，其日、時
    • 法院應「指定時間」供應買人「實地查看」不動產。
拍賣期日距公告之日，不得少於十四日
  • 例如：公告日為7月1日，則拍賣期日最早為7月15日。
  • 若公告日與拍賣期日「間隔不足14日」，拍賣程序違法。
拍賣公告之揭示
1.「應揭示」於執行法院、「不動產所在地」或當地「鄉鎮市（區）公所」
  • 執行法院：執行法院之「公告處」為「法定」揭示場所。
  • 不動產所在地：須於「不動產本身」之「明顯處」張貼公告（如大門、圍牆、土地界標）。
  • 當地「鄉鎮市（區）公所」：若不動產所在地「不易張貼」或「無適當處所」，得於「當地區公所」公告欄揭示。
2.應公告於「法院網站」
  • 強制義務，法院須「上網公告」。
  • 法院網站：司法院「法拍屋公告系統」為現行實務主要管道。
3.法院認為「必要時」，得命登載於「公報或新聞紙」
  • 通常用於「高價值不動產」或「偏遠地區」以擴大傳播。
例1.
  • 拍賣公告於7月1日張貼，執行法院指定拍賣期日為7月15日（公告日＋14日）。
  • → 拍賣期日距公告之日，不得少於14日
例2.
  • 執行法院拍賣債務人甲位於臺北市之房屋，公告「揭示於臺北地方法院公告處」及「臺北市大安區公所公告欄」。
    → 拍賣公告「應揭示」於執行法院、「不動產所在地」或當地「鄉鎮市（區）公所」
  • 執行法院將拍賣公告「上傳」至司法院「法拍屋公告系統」。 → 應公告於「法院網站」
一句話總結
  • 拍賣前須先公告，公告上須載明不動產詳細資訊（含海砂屋、兇宅等瑕疵）、 拍賣時地、底價、付款期限、閱覽筆錄、應買資格、不點交原因及看貨時日。
  • 公告後須至少等待14天才能拍賣，確保應買人有充分時間準備。
  • 公告須揭示於執行法院及區公所，並須公告於法院網站；必要時得登報或刊公報。

不動產拍賣之執行主體與場所

拍賣不動產，由「執行法官命書記官督同執達員」於執行法院「或其他場所」為之
  • 執行法官命：執行法官負責「核發拍賣命令」及「訂定拍賣條件」（如底價、保證金）。
  • 書記官督同執達員：書記官應「到場監督」並「製作拍賣筆錄」。執達員負責「實際執行」拍賣程序（如主持投標、開啟標封、宣布結果）。
  • 於執行法院為之：通常於法院內之「投標室」或「拍賣室」舉行（絕大多數情況）。
  • 於其他場所為之：如「不動產所在地」、「債務人住所」、「區公所」等（實務上極少使用）。
例1.
  • 執行法院拍賣債務人甲之房屋，於法院內之「投標室」進行開標，由書記官督同執達員主持。
例2.
  • 拍賣位於「澎湖」之土地，因地處偏遠，執行法院指定於「當地鄉公所」進行拍賣（實務上極少）。
例3.
  • 執達員「自行」決定拍賣日期及場所，未經執行法官命令。
  • → 拍賣程序欠缺「法官命令」之要件。程序違法
一句話總結
  • 拍賣由法官下令、書記官監督、執達員執行；地點可在執行法院或其他場所。

不動產拍賣之投標方法

拍賣不動產，法院得「因聲請或依職權」，以「投標」之方法行之
  • 因聲請：債權人或債務人得以「書面」請求採投標方式拍賣。
  • 依職權：法院得「主動」決定採投標方式拍賣。
  • 投標：應買人應於「指定期限內」將「投標書」及「保證金」密封送達法院。
不動產投標之保證金
以「投標」方法拍賣不動產時，執行法院得「酌定保證金額」，命投標人於「開標前繳納之」
  • 得：法院有裁量權，得「定」或「不定」保證金。
  • 酌定保證金額：法院應「合理」決定金額，通常為「底價之一定比例」（如20%）
    • 保證金之數額，應於拍賣公告中載明。
  • 開標前繳納：投標人須於「投標時」或「開標前」繳納保證金（通常「隨標單繳納」）。
    • 若「未繳納」，其投標「無效」
投標應繳納保證金而「未照納」者，其「投標無效」
  • 未照納：包括完全「未繳納」或繳納之金額「不足」所定數額。
  • 投標無效：該投標書「自始不生投標之效力」。
例1.
  • 執行法院拍賣債務人甲之房屋，法院為避免現場圍標，逕「依職權」公告以「投標方式」拍賣。
  • 法院並酌定保證金，於拍賣公告載明：「拍賣底價1000萬元，保證金200萬元（底價20%），投標人應於開標前繳納保證金。」
例2.
  • 延續例1，投標人丙「未於開標前繳納」保證金200萬元，法院宣布其投標「無效」。
一句話總結
  • 不動產拍賣得採密封投標方式，法院可依聲請或依職權決定。
  • 不動產投標時，法院可訂保證金，投標人須在開標前繳納。

投標之方式與投標書件之應載事項

投標人應以書件「密封」，投入執行法院所設之標匭
  • 投標人：參與投標之「應買人」（自然人、法人）。
  • 書件密封：投標書及相關文件（如保證金票據）應「封緘完整」，不得有「開口」或「破損」。
  • 投入標匭：於「投標截止時間前」投入法院設置之「投標箱」（標匭）。
  • 若「未密封」或「未投入標匭」，投標「無效」。
投標書件，應載明下列事項：
  1. 投標人之姓名、年齡及住址
  2. 願買之不動產
    • 須「明確」特定標的——如「臺北市○○區○○段○○地號土地」。
  3. 願出之價額
例1.
  • 甲於投標截止前，將密封之投標書（載明「甲、40歲、台北市○○路」、 願買「○○地號土地」、願出「1000萬元」）投入標匭。
  • → 合法投標
例2.
  • 乙之投標書「未密封」，僅以「對折」投入標匭。
  • → 未密封，投標無效
例3.
  • 丙之投標書載明姓名及住址，但「未載年齡」。
  • → 漏載年齡，投標無效
一句話總結
  • 投標書須密封投入標匭。
  • 投標書須載明投標人資訊、標的物及出價，缺漏或未密封者無效。

開標程序

開標應由執行法官「當眾開示」，並「朗讀」之
  • 執行法官：該執行事件之承辦法官。實務上執行法官在場，書記官協助操作亦可。
  • 當眾開示：應使「在場之人」得「親眼目睹」開標過程。
  • 朗讀：將投標書內容「大聲宣讀」，朗讀之目的在於使「在場之人」得「即時知悉」各投標人之出價。
一句話總結
  • 開標須由執行法官當眾拆封並朗讀投標內容，確保公開透明。

最高價相同之處理與得標人未繳足價金之再行拍賣

投標人願出之「最高價相同」時，以「當場加價最高者」得標；若「無人加價」，以「抽籤」定之
  • 最高價相同：指「有效投標」中，「最高價」有「二名以上」投標人出價相同。
  • 以「當場加價最高者」得標：於開標現場，讓最高價相同之投標人「當場增加金額」，以「加價後最高者」為得標人。
  • 若無人加價，以「抽籤」定之：若無人願意加價，則以「抽籤」決定得標人。
棄標處理
得標人「未於期限內繳足價金」者，依下列程序處理：
  1. 未中籤之投標人是否願意「按原定投標條件」承買?
    • 若無人願意，則「再行拍賣」。
  2. 再行拍賣
    • 重新進行拍賣程序。
例1.
  • 甲、乙均出價1000萬元（同為最高價）。 願買「○○地號土地」、願出「1000萬元」）投入標匭。
  • 執行法官命甲、乙「當場加價」，甲加至1010萬元，乙不加，甲為得標人。
  • → 投標人願出之「最高價相同」時，以「當場加價最高者」得標
例2.
  • 甲、乙均出價1000萬元，兩人均「不加價」，執行法官「公開抽籤」，甲中籤，甲為得標人。
  • → 若「無人加價」，以「抽籤」定之
例3.
  • 甲抽籤得標後，未於期限內繳足價金。
  • 乙（未中籤）仍願按原條件（1000萬元）承買，法院准許乙承買，無庸再拍賣。
  • → 得標人「未於期限內繳足價金」者，未中籤之投標人得「按原定投標條件」承買
一句話總結
  • 投標最高價相同時，現場加價決定，無人加價則抽籤。
  • 得標人未繳足價金時，未中籤者得按原條件承買。
    • 若無人承買，則「再行拍賣」。

不動產第一次拍賣無人應買或未達底價之承受與再行拍賣

流標處理
「無人應買」或「最高價低於底價」時，依下列程序處理：
1.交債權人承受
  • 要件：債權人於「拍賣期日終結前」聲明願依該次拍賣所定「底價」承受。
  • 程序：法院發給「權利移轉證書」（不動產所有權移轉之法定憑證）。
2.法院定期「再行拍賣」
  • 要件：無人承受或依法不得承受者。
  • 程序：重新訂定拍賣期日，再次拍賣。
再行拍賣規範
再行拍賣時，法院「應酌減底價」。酌減數額「不得逾百分之二十」
  • 應酌減：法院「必須」降低底價。
  • 酌減數額不得逾百分之二十：例如：原底價1000萬元，再拍賣底價「不得低於800萬元」。
    • 若仍流標，下次再拍賣得「再減20%」（以新底價為準，每次減20%為上限）。
再行拍賣「又流標」時，「比照初次流標處理程序」辦理
  • 比照初次流標處理程序：即「1.交債權人承受」「2.法院定期再行拍賣」
  • 再行拍賣底價酌減數額不得逾百分之二十：例如：
    • 第一次底價1000萬元，第二次減至800萬元（減20%）。
    • 第三次拍賣時，若流標，最多再減「800萬元之20%」＝160萬元，新底價不得低於640萬元。
再行拍賣之期日，距公告之日，「不得少於10日多於30日」
  • 不得少於10日：確保應買人有「最低限度」之準備時間（閱覽筆錄、察看標的、籌措資金）。
  • 不得多於30日：避免因公告期間過長而「拖延執行」，影響債權人權益。
  • 例如：公告日為7月1日，拍賣期日最早為7月11日; 最遲為7月31日。
例1.
  • 第一次拍賣房屋，底價1000萬元，無人應買。
  • 到場之債權人甲於拍賣期日終結前「聲明承受」，法院即依1000萬元將房屋交甲承受，發給權利移轉證書。
  • → 債權人於「拍賣期日終結前」聲明願依該次拍賣所定「底價」承受者，法院應交其承受，並發給「權利移轉證書」
例2.
  • 延續例1，債權人甲「未聲明承受」，法院「指定7月25日再行拍賣」，並將底價「酌減」至800萬元。
    → 再行拍賣時，法院「應酌減底價」。酌減數額「不得逾百分之二十」
  • 法院於7月1日公告再行拍賣（距再行拍賣之期日25日）。 → 再行拍賣之期日，距公告之日「不得少於10日多於30日」
例3.
  • 延續例2，再行拍賣時「又流標」，債權人甲「未聲明承受」，法院「定期再行拍賣」，並將底價再次「酌減」至640萬元。
  • → 再行拍賣「又流標」時，「比照初次流標處理程序」辦理。
一句話總結
  • 無人應買或未達底價時，到場債權人得按底價承受。
  • 無人承受則再拍賣，再拍賣底價最多減20%
  • 再拍賣公告日期距離拍賣期日「不得少於10日多於30日」。

多數債權人承受之抽籤、差額補繳與再行拍賣

債權人有二人以上願承受者，以「抽籤」定之
  • 願承受：願按「底價」承受該不動產。
  • 以抽籤定之：以抽籤決定誰來承受該不動產。
承受不動產之債權人，其應繳之價金「超過其應受分配額」者，法院應命其「限期補繳差額」後，發給權利移轉證書
  • 應繳之價金：即「拍賣最低價額」（底價）。
  • 應受分配額：該債權人依「分配表」應受清償之金額（含本金、利息、費用）。
  • 價金超過其應受分配額：底價 > 債權額，承受人須「補繳差額」。
    • 若底價 ≤ 債權額，無庸補繳（甚至可能獲分配餘額）
  • 限期補繳差額：法院應定「相當期限」（通常7至14日）命承受人繳底價與債權額之差額。
  • 補繳差額後，發給權利移轉證書：繳足差額後，法院始發給權利移轉證書。
逾期不繳者，再行拍賣。但有未中籤之債權人仍「願按原定拍賣條件」依法承受者，不在此限
  • 承受人未於期限內補繳差額，法院應「再行拍賣」。
    • 再行拍賣時，原承受人「不得應買」。
    • 若再拍賣價金「低於」原拍賣價金及費用，原承受人應負擔「差額」。
  • 但有抽籤落敗之其他債權人願依「原底價」及「原付款條件」承受者，准其承受，無庸再行拍賣。
例1.
  • 第一次拍賣流標，債權人甲、乙均願按底價1000萬元承受。
  • 執行法院「公開抽籤」，甲中籤，由甲承受。
  • → 債權人有二人以上願承受者，以「抽籤」定之
例2.
  • 甲承受底價1000萬元之房屋，甲之債權額為800萬元。
  • 甲應「補繳差額」200萬元。法院限期14日，甲補繳後發給權利移轉證書。
  • → 承受不動產之債權人，其應繳之價金「超過其應受分配額」者，法院應命其「限期補繳差額」後，發給權利移轉證書
例3.
  • 延續例2，甲逾期未補繳。
  • 乙（未中籤）仍願按1000萬元承受，法院准許乙承受，無庸再拍賣。
  • → 承受人逾期不補繳差額者，其他未中籤之債權人得「按原定拍賣條件」承受
例4.
  • 延續例2，甲逾期未補繳，且乙亦不願承受。
  • 法院「再行拍賣」，甲「不得應買」，且若再拍賣價格低於1000萬元，甲應負擔差額。
  • → 再行拍賣時，原承受人「不得應買」。若再拍賣價金低於原拍賣價金及費用，原承受人應負擔「差額」
一句話總結
  • 多人承受時抽籤決定。
  • 承受人須補繳差額，逾期不繳則「未中籤者得按原條件承受」；無人承受則「再拍賣」。
    • 再拍賣時，原承受人「不得應買」。
    • 若再拍賣價金低於原拍賣價金及費用，原承受人應負擔「差額」。

數宗不動產拍賣之停止與債務人指定權

有「數宗不動產供拍賣」者，當「其中一宗或數宗之賣得價金，已足清償」時，其他部分「應停止拍賣」
  • 數宗不動產供拍賣：指「同一執行事件」中，有「數筆」不動產被查封並預備拍賣（如A地、B屋、C地）。
  • 其中一宗或數宗之賣得價金：指已拍定之一宗或數宗不動產「累計價金」。
  • 已足清償：已足夠清償強制執行之「債權額」及債務人應負擔之「費用」時。
    • 累計價金 ≥ 全部債權額＋費用（含尚未拍賣部分之預估費用）。
  • 其他部分「應停止拍賣」：法院須「立即」停止後續拍賣。未拍賣之不動產，應「撤銷查封」返還債務人。
前項情形，「債務人得指定」其應拍賣不動產之部分
  • 債務人得「優先」指定「價值較高」或「較易變現」之不動產先行拍賣， 以避免「賤賣」其他財產。
但建築物及其基地，「不得指定單獨拍賣」
  • 債務人不得要求「只賣房屋不賣土地」或「只賣土地不賣房屋」——二者須「合併拍賣」。
  • 理由：避免「所有權」與「使用權」分離，影響拍賣價值及後續產權利用。
例1.
  • 債務人甲有A、B兩筆土地被查封，拍賣A地得款1000萬元，已足清償甲之全部債務（800萬元）及費用（100萬元）。
  • 法院即「停止」拍賣B地，撤封返還甲。
  • → 有「數宗不動產供拍賣」者，當「其中一宗或數宗之賣得價金，已足清償」時，其他部分「應停止拍賣」
例2.
  • 甲有A地（價值高）及B屋（價值低）被查封。
  • 甲「指定」優先拍賣A地，法院依其指定先行拍賣A地。
  • → 有「數宗不動產供拍賣」者，「債務人得指定」其應拍賣不動產之部分
例3.
  • 甲有房屋及基地被查封，甲指定「僅拍賣房屋，不拍賣基地」，法院駁回。
  • → 建物與基地不得單獨指定拍賣，應合併拍賣
一句話總結
  • 部分不動產賣價已足清償時，其餘應停止拍賣。
  • 債務人得指定拍賣標的，但建物與基地不得單獨指定拍賣。

權利移轉證書之發給

拍賣之不動產，買受人「繳足價金」後，執行法院應「發給權利移轉證書」及其他書據
  • 繳足價金：全部拍定價金已「全額繳清」。
  • 應發給：強制義務，法院須「即時」發給。
  • 權利移轉證書：法院核發之「所有權移轉證明書」，為「公文書」。證書載明：執行案號及拍賣日期、買受人姓名、住址、不動產標示（地號、門牌、面積）、拍定價額、發給日期。
  • 其他書據：土地增值稅申報書（供買受人申報土增稅）、契稅申報書、執行法院之「證明書」（證明已繳足價金）等必要文件。
例1.
  • 甲拍定房屋，於期限內繳清全部價金1000萬元。
  • 執行法院即發給甲「權利移轉證書」，載明甲已取得該房屋所有權。
一句話總結
  • 買受人繳足價金後，法院應發給權利移轉證書，作為取得所有權的正式憑證。

拍賣不動產所有權之取得時點與原有負擔之處理

拍賣之不動產，買受人自「領得權利移轉證書之日」起，取得所有權，「債權人承受者亦同」
  • 領得權利移轉證書之日：買受人「繳足價金」後，法院即發給權利移轉證書。
  • 債權人承受者亦同：債權人承受債務人之不動產者，「補繳差額」後，法院發給權利移轉證書
抵押權及其他優先受償權，因拍賣而消滅
原則消滅：存於不動產上之「抵押權」及其他「優先受償權」，因拍賣而「消滅」
  • 拍賣價金將「優先清償」抵押權人。
  • 消滅：抵押權及優先權「塗銷」，買受人取得「無負擔」之所有權。
例外承受：尚未到期、拍定人聲明清償、經抵押權人同意
  • 要件1.抵押權所擔保之債權尚未到期
  • 要件2.拍定人「聲明」願在「拍定價格範圍內」清償該債務
  • 要件3.經「抵押權人同意」
租賃關係、地上權、永佃權、地役權、典權「隨同移轉」
  • 隨同移轉：買受人須「承受」該等權利（即該等權利對買受人繼續存在）。
  • 此為「買賣不破租賃」等原則之具體化。
例外：「發生於設定抵押權之後」，並對抵押權有影響，「經法院除去後拍賣」者，不在此限
  • 設定抵押權之後：該權利係「抵押權設定後」始發生。
  • 對抵押權有影響：如「長期租賃」會降低拍賣價格。
  • 經執行法院除去：法院依職權或聲請「裁定除去」該權利。
  • 不在此限：該權利「不隨同移轉」，買受人無庸承受。
例1.
  • 甲拍定房屋，於7月10日領得權利移轉證書。
  • 甲自7月10日起取得該房屋所有權（無庸登記即生效）。
  • → 買受人自「領得權利移轉證書之日」起，取得所有權
例2.
  • 拍賣土地原本設有抵押權，拍賣後該抵押權「消滅」，買受人取得無抵押負擔之所有權。
  • → 存於不動產上之「抵押權」及其他「優先受償權」，因拍賣而「消滅」
例3.
  • 拍賣之房屋原有「10年租約」（租期尚未屆滿），拍定人乙須「承受」該租約，不得驅逐承租人。
  • → 租賃關係、地上權、永佃權、地役權、典權「隨同移轉」
一句話總結
  • 買受人自領得權利移轉證書日起取得所有權。
  • 抵押權及其他優先權因拍賣而消滅（但經抵押權人同意且拍定人願清償者除外）。
  • 地上權、租賃等原則上隨同移轉（影響抵押權且經除去者除外）。

不動產之點交與占有排除

債務人應交出之不動產，現「有人占有」，而屬以下情形之一者，法院「應解除其占有」，點交於買受人或承受人
  1. 現為債務人占有
    • 債務人「本人」或其家屬、受僱人占有。
  2. 於「查封後」為第三人占有
    • 例如債務人於「查封後出租」予第三人（租約在查封後始訂立）。
  3. 第三人於查封前「無權占有」且「不爭執」無權占有之事實
    • 第三人承認其「無權占有」。
  4. 第三人占有權力「經執行法院除去」
    • 發生於設定抵押權之後，並對抵押權有影響，經執行法院除去後拍賣
點交後，原占有人「再次」占有該不動產者：法院得「依聲請」再解除其占有後點交之，並「應徵執行費」
  • 原占有人「再次」占有：如債務人又搬回。
  • 依聲請：須經買受人/承受人聲請「再解除占有」並「點交」。
  • 應徵執行費：再點交程序應「徵收執行費」。
點交/解除占有時如有「拒絕交出」或其他情事，得請警察協助
  • 法院得請求警察協助維持秩序、強制搬離、排除抗拒。
例1.
  • 拍定人甲拍得房屋，該屋仍由債務人乙自住。
  • 法院發函命乙搬離，乙拒絕，法院「強制點交」並請警察協助。
  • → 點交/解除占有時如有「拒絕交出」或其他情事，得請警察協助
例2.
  • 查封後，債務人丙將房屋出租予丁（查封後租約）。
  • 法院點交時，丁須「搬離」。
  • → 於「查封後」為第三人占有，法院「應解除其占有」，點交於買受人或承受人
例3.
  • 點交後，債務人「再度搬回」該屋。
  • 買受人庚聲請法院「再點交」，法院再行驅離，並徵收執行費。
  • → 點交後，原占有人「再次」占有該不動產者：法院得「依聲請」再解除其占有後點交之，並「應徵執行費」
一句話總結
  • 法院應解除債務人或查封後第三人之占有，點交予買受人。
    • 查封前無權占有且不爭執者亦同。
  • 點交後再占有者可再點交；再點交應徵執行費。

點交時房屋內動產之處理

房屋內或土地上之動產，應「取出並點交債務人」
  • 房屋內或土地上之動產：例如家具、電器、衣物等。
  • 點交債務人：將動產自不動產取出，移交給債務人。
    • 債務人得委由家屬、受僱人、代理人代為受領。
「無法點交債務人」時，應將動產「暫付保管」，並通知債務人「限期領取」
  • 「無法點交債務人」：債務人及其代理人、家屬、受僱人「均不在場」或「拒絕受領」。
  • 暫付保管：法院須先「保管」動產（不得逕行棄置或變賣）。 法院得指定「保管人」（如倉庫業者、債務人指定之人）保管。
  • 通知債務人「限期領取」：法院應「書面通知」債務人，定「相當期限」命其領取（通常為7至14日）。
「逾期不領取」者，得「拍賣」並「提存其價金」，或為其他適當之處置
  • 提存其價金：賣得價金「提存」於法院（清償提存）。
  • 其他適當之處置：如「捐贈」、「銷毀」（限於無價值之物）。
動產「為第三人所有」者，適用之
  • 為第三人所有：如無權占有人、承租人所有之物品。
  • 適用之：與前述債務人所有物品同樣處理程序（取出並點交）。
與不動產「同時執行」之動產，不在此限
  • 指該動產「亦為查封標的」（如與不動產一併拍賣），則「不」取出，隨不動產一併移轉。
例1.
  • 法院點交房屋時，屋內有債務人甲之家具。
  • 法院將家具「取出」，「點交」予甲之代理人（其配偶）。
  • → 房屋內或土地上之動產，應「取出並點交債務人」
例2.
  • 點交時，債務人乙「不在場」且「無代理人」。
  • 法院將動產「暫付保管」，並「發函通知」乙於14日內領取。
  • → 「無法點交債務人」時，應將動產「暫付保管」，並通知債務人「限期領取」
例3.
  • 延續例2，乙逾期未領。
  • 法院將該批動產「拍賣」，賣得價金「提存」於法院。
  • → 「逾期不領取」者，得「拍賣」並「提存其價金」，或為其他適當之處置
一句話總結
  • 非查封標的之動產應取出交還債務人。
  • 無人接收則保管並通知限期領取，逾期不領得拍賣提存或適當處置。
