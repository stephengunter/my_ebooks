關於金錢請求權之執行 - 對於其他財產權之執行- 總覽

對於第三人金錢債權之執行

適用情況：就債務人對於第三人之「金錢債權」為執行時
  • 「存款債權」（第三人為銀行）
  • 「薪資債權」（第三人為雇主）
  • 「租金債權」（第三人為房客）
  • 「應收帳款」（第三人為客戶）
處理原則：應發「扣押命令」，並「禁止」第三人「向債務人清償」
  • 應發扣押命令：強制義務，法院須「立即」核發。
  • 扣押命令之內容：
    • 禁止債務人「收取」該債權。
    • 禁止債務人「處分」該債權（如轉讓、設定質權）。
    • 禁止第三人「向債務人清償」。
  • 禁止第三人向債務人清償：若第三人「違反」而向債務人清償，該清償「對債權人不生效力」（第三人仍須再向執行法院或債權人給付）。
執行方式：得詢問債權人意見決定
  1. 「收取命令」 ：以命令許債權人收取。債權人得「直接」向第三人收取該債權（如直接向銀行提領存款）。
  2. 「移轉命令」 ：將該債權「移轉」予債權人。債權人「取得」該債權（成為新債權人）， 得「以自己的名義」向第三人請求。
  3. 「支付轉給命令」 ：第三人應將款項「支付」予「執行法院」， 法院再「轉交」予債權人（由法院介入，避免爭議）。
例外處理：依聲請，拍賣或變賣
適用情況：金錢債權因「附條件、期限、對待給付」或其他事由，致「難依前項規定辦理」者
  • 附條件：如「債務人交付貨物後，始得請求貨款」。
  • 期限：如「債權尚未到期」。
  • 對待給付：如「債務人須先為給付，始得請求」。
  • 其他事由：如「債權金額不確定」。
法院得「依聲請」，準用動產執行之規定「拍賣或變賣」之
  • 依聲請：須由「債權人」聲請（法院不得依職權）。
  • 準用動產執行：即「公開拍賣」或「變賣」該債權（由應買人競標，以價金清償債務）。
擔保物權登記
金錢債權附有已登記之「擔保物權」者，執行法院依前三項為強制執行時，「應即通知」登記機關「登記其事由」
  • 已登記之擔保物權：如「抵押權」（登記於地政機關）、「質權」、動產擔保交易之「抵押」。
  • 應即通知：強制義務，使「擔保物權」之狀態「公示」於登記簿，以保護交易安全。
例1.
  • 甲對乙有債權，執行法院扣押乙對A銀行之「存款債權」——禁止A銀行向乙付款。
  • → 「金錢債權」處理原則：應發「扣押命令」，並「禁止」第三人「向債務人清償」
例2.
  • 法院發「收取命令」，許債權人甲「直接」向A銀行收取乙之存款。
  • → 「收取命令」：以命令許債權人收取。債權人得「直接」向第三人收取該債權
例3.
  • 法院將乙對A銀行之存款債權「移轉」予甲，甲成為A銀行之債權人。
  • → 「移轉命令」：將該債權「移轉」予債權人。債權人「取得」該債權（成為新債權人），得「以自己的名義」向第三人請求。
例4.
  • 法院命A銀行將乙之存款「支付予法院」，法院再「轉交」予甲。
  • → 「支付轉給命令」：第三人應將款項「支付」予「執行法院」， 法院再「轉交」予債權人（由法院介入，避免爭議）。
例5.
  • 乙對丙之貨款債權「尚未到期」，法院依聲請「拍賣」該債權，由應買人競標。
  • → 金錢債權因「附條件、期限、對待給付」或其他事由，致「難依前項規定辦理」者，法院得「依聲請」，準用動產執行之規定「拍賣或變賣」之
例6.
  • 乙對丙之債權附有「抵押權」，執行法院通知「地政機關」登記此事由。
  • → 金錢債權附有已登記之「擔保物權」者，執行法院為強制執行時，「應即通知」登記機關「登記其事由」
一句話總結
  • 法院應發扣押命令；後續可發收取、移轉或支付轉給命令。
  • 無法處理時可拍賣或變賣債權。
  • 債權有擔保物權者應通知登記機關登記。

薪資及繼續性給付債權之執行與扣押範圍限制

對於「薪資」或其他「繼續性給付」之債權所為強制執行
  • 其他「繼續性給付」債權：例如退休金、年金、租金等。
於「債權及執行費用」之範圍內，其「效力及於扣押後應受及增加之給付」
  • 效力及於：扣押命令之效力「自動」延伸至「後續各期」給付。下次給付「無須」重新核發扣押命令。
  • 應受及增加之給付：如「每月薪資」、「年終獎金」、「調薪增加部分」。
債務人於「扣押後」應受及增加之給付，執行法院得以命令「移轉於債權人」
  • 即「移轉命令」——將「未來各期」給付「移轉」予債權人。
但債務人「喪失其權利」或「第三人喪失支付能力」時，債權人債權未受清償部分，「移轉命令失其效力」，得聲請繼續執行，並免徵執行費
  • 債務人「喪失其權利」：如「離職」、「退休金停止發給」。
  • 第三人喪失支付能力：如「雇主倒閉」。
  • 移轉命令失其效力：移轉命令自動失效。
  • 得聲請繼續執行：債權人得「再聲請」對債務人「其他財產」執行。
  • 並免徵執行費：繼續執行「免徵」執行費（因已繳過一次）。
三分之一上限
對於下列債權發扣押命令之範圍，不得逾各期給付數額三分之一
  1. 自然人因「提供勞務」而獲得之「繼續性報酬」債權
    • 例如「薪資」、「工資」、「銷售獎金」等。
  2. 以維持債務人或其共同生活親屬「生活所必需」為目的之「繼續性給付」債權
    • 例如「退休金」、「年金」、「社會救助金」、「贍養費」。
例外情況：法院認「有失公平」者，得不受比例限制。但應預留債務人生活費用
  • 有失公平：法院應斟酌債務人與債權人生活狀況及其他情事。
  • 得不受比例限制：得「提高」或「降低」扣押比例。
  • 但應預留債務人生活費用：強制義務，須「保留」債務人及其家屬「基本生活費」（參第52條之精神）。
例1.
  • 法院扣押甲之薪資，甲之雇主A公司每月應支付甲薪資。
  • 扣押命令效力「自動」及於「每月」薪資，無庸逐月聲請。
  • → 於「債權及執行費用」之範圍內，其「效力及於扣押後應受及增加之給付」
例2.
  • 甲之月薪9萬元，法院扣押「不得超過3萬元」（三分之一）。
  • → 自然人因「提供勞務」而獲得之「繼續性報酬」債權：扣押範圍不得逾「各期給付數額三分之一」
例3.
  • 甲之「退休金」為維持其生活所必需，法院扣押「不得超過三分之一」。
  • → 以維持債務人或其共同生活親屬「生活所必需」為目的之「繼續性給付」債權：扣押範圍不得逾「各期給付數額三分之一」
例4.
  • 法院發「移轉命令」將甲之薪資移轉予乙。
  • 嗣後甲「離職」，移轉命令「失效」，乙未受償部分得「聲請繼續執行」且「免徵執行費」。
  • → 債務人「喪失其權利」或「第三人喪失支付能力」時，債權人債權未受清償部分，「移轉命令失其效力」，得聲請繼續執行，並免徵執行費
一句話總結
  • 扣押效力及於後續各期給付。
  • 薪資等債權扣押上限為三分之一；法院得依公平原則調整（但須預留生活費）。
  • 移轉命令後若債務人或第三人喪失權利能力，命令失效，得繼續執行且免徵執行費。

第三人提存、扣押競合與陳明義務

白話文
  • 在法院發「收取命令」或「移轉命令」之前：
    • 第三人可以把「欠債務人的錢」的「全部或扣押部分」「提存」到法院提存所（先把錢交給法院，免得之後麻煩）。
  • 如果第三人已經要依照法院命令（例如收取命令或支付轉給命令）來辦了，
    • 但在辦理「之前」又收到「另一個扣押命令」，
    • 而且「新扣押的金額」超過了「債務人這筆錢還沒被扣押的部分」，
    • 那麼第三人就「必須」把這筆錢的「全部金額」都「支付」給「最先扣押」的那個法院。
  • 第三人如果已經「提存」或「支付」了，必須向執行法院「陳明」這件事。
  • 簡單說：
    • 第三人在收取命令前得提存避險。
    • 若在辦理前又收受扣押命令且超額，應將全額支付給先扣押法院。
    • 提存或支付後應向法院陳明。
例1.
  • 甲銀行（第三人）收到法院對債務人乙之扣押命令。
  • 但在法院發「收取命令」前，甲銀行將乙之存款100萬元「提存」於「臺灣臺北地方法院提存所」。
  • → 在法院發「收取命令」或「移轉命令」之前：第三人可以把「欠債務人的錢」的「全部或扣押部分」「提存」到法院提存所
例2.
  • 乙對甲銀行有存款債權100萬元。A法院先扣押60萬元，B法院後扣押50萬元（超過未扣押部分40萬元）。
  • 甲銀行應將「全額100萬元」支付給「A法院」（先扣押法院）。
  • → 「新扣押的金額」超過了「債務人這筆錢還沒被扣押的部分」，第三人「必須」把這筆錢的「全部金額」都「支付」給「最先扣押」的那個法院。
例3.
  • 甲銀行已「提存」或「支付」款項，應向「執行法院」以「書面」陳明：「已於某年某月某日提存/支付若干元」。
  • → 第三人如果已經「提存」或「支付」了，必須向執行法院「陳明」這件事
一句話總結
  • 第三人在收取命令前得提存避險。
  • 若在辦理前又收受扣押命令且超額，應將全額支付給先扣押法院。
  • 提存或支付後應向法院陳明。

對於物之交付或移轉請求權之執行

白話文
  • 如果債務人對第三人有一個權利， 可以請求第三人「交付或移轉」動產或不動產（例如債務人買了房子，有權要求賣方過戶）， 法院要執行這個權利時：
    • 除了要「禁止」債務人處分這個權利，也「禁止」第三人交付或移轉給債務人之外，
    • 如果法院覺得「適當」，可以直接「命令」第三人把這個動產或不動產「交給執行法院」， 然後法院再依照「動產」或「不動產」的執行規定來拍賣。
  • 另外，如果因為「確定判決」或「法院和解、調解」，第三人有義務要把不動產「移轉」給債務人：
    • 執行法院可以因為「債權人」的請求，用「債務人」的費用，
    • 直接「通知」地政機關把這筆不動產「登記為債務人所有」之後，再來拍賣。
  • 簡單說：
    • 法院可命令第三人將動產或不動產交付法院後，依動產或不動產執行規定執行。
    • 若基於判決等第三人應移轉不動產予債務人，法院得通知登記機關登記為債務人所有後執行。
例1.
  • 甲對乙有債權，乙對丙有「汽車交付請求權」（基於買賣契約）。
  • 執行法院命丙將該汽車「交與執行法院」，法院再依「動產執行」規定「查封拍賣」。
  • → 如果法院覺得「適當」，可以直接「命令」第三人把這個動產或不動產「交給執行法院」， 然後法院再依照「動產」或「不動產」的執行規定來拍賣
例2.
  • 乙對丙有「土地所有權移轉登記請求權」。
  • 執行法院命丙將該土地「交與執行法院」——惟不動產「不能交付」， 實務上係命丙「交付權狀」並配合「查封登記」。
  • → 法院可命令第三人將動產或不動產交付法院後依動產或不動產執行規定執行
例3.
  • 法院確定判決命丙應將A地「移轉登記」予乙。
  • 債權人甲聲請執行，法院即「通知地政機關」將A地「登記為乙所有」，再「拍賣」該土地。
  • → 若基於判決等第三人應移轉不動產予債務人，法院得通知登記機關登記為債務人所有後執行
一句話總結
  • 法院可命令第三人將動產或不動產交付法院後，依動產或不動產執行規定執行。
  • 若基於判決等第三人應移轉不動產予債務人，法院得通知登記機關登記為債務人所有後執行。

對於船舶或航空器交付或移轉請求權之執行

白話文
  • 如果債務人對第三人有權利可以請求「交付」或「移轉」「船舶」或「航空器」，
    • 法院要執行時，就「比照」前一條（第116條）的規定來辦理—— 也就是可以命令第三人把船或飛機「交給法院」，
    • 然後再依照「船舶」或「航空器」的「特別執行規定」來查封、拍賣。
  • 簡單說：對於船舶或航空器交付或移轉請求權的執行，準用第116條規定，並依船舶或航空器執行之特別規定執行。

其他財產權執行之概括準用與特別處分

白話文
  • 對於「前三節」（動產、不動產、船舶、航空器）和「第115條到第116條之1」（金錢債權、物之請求權） 「以外」的
    • 其他財產權（例如專利權、商標權、股權、礦業權等）要執行時，
    • 就「比照」第115條到第116條之1的規定來辦理（扣押、收取、移轉等）。
    而且，執行法院可以「視情況」，
    • 命令把這個財產權「賣掉」（讓與），或「派人管理」它（例如收取權利金），
    • 然後用賣掉的錢或管理的收益來還債。
  • 簡單說：
    • 對於其他財產權（如專利權、股權等）的執行，準用扣押、收取、移轉等。
    • 法院並得命讓與或管理，以價金或收益清償債務。
例1.
  • 甲對乙有債權，乙擁有一項「專利權」。
  • 執行法院「準用」第115條規定，發「扣押命令」禁止乙處分該專利權， 並得「命令讓與」該專利權（拍賣），以價金清償甲之債權。
  • → 對於其他財產權（如專利權、股權等）的執行，準用扣押、收取、移轉等
例2.
  • 乙對丙之「有限公司出資額」有權利。
  • 執行法院得「準用」第115條之「移轉命令」，將乙之出資額「移轉」予甲（債權人），甲成為該公司之股東。
  • → 對於其他財產權（如專利權、股權等）的執行，準用扣押、收取、移轉等
例3.
  • 乙擁有一項「商標權」，不易「讓與」（無合適買家）。
  • 執行法院「命令管理」該商標權，由「管理人」收取「授權金」，以「收益」清償債務。
  • → 法院並得命讓與或管理，以價金或收益清償債務。
一句話總結
  • 對於其他財產權（如專利權、股權等）的執行，準用扣押、收取、移轉等。
  • 法院並得命讓與或管理，以價金或收益清償債務。

命令之送達、生效時點與通知義務

白話文
  • 第115條到第117條所發的各種命令（扣押、收取、移轉等），
    • 都必須「送達」給「債務人」和「第三人」。
    • 送達之後，還要「通知」債權人。
  • 這些命令，原則上是在「送達給第三人」的時候才「生效」；
    • 如果「沒有第三人」（例如執行標的是債務人自己持有的東西），則在「送達給債務人」時生效。
    • 但是，如果在「送達之前」已經辦了「扣押登記」（例如在智慧財產局辦了登記），那麼效力就從「登記時」就生效。
  • 簡單說：
    • 命令應送達債務人及第三人，送達後應通知債權人。
    • 命令原則上送達第三人時生效（無第三人則送達債務人時生效）；但送達前已為扣押登記者，於登記時生效。
例1.
  • 執行法院核發扣押命令（第115條），於7月10日「送達」予A銀行（第三人）。
  • 該命令「於7月10日」發生效力，A銀行不得向債務人乙付款。
  • → 命令送達第三人時生效
例2.
  • 執行標的為債務人甲「自行持有」之無記名公司債（無第三人）。
  • 執行法院發扣押命令，於7月10日「送達」予甲。命令「於7月10日」生效。
  • → 無第三人，命令送達債務人時生效
例3.
  • 執行法院扣押乙之「專利權」，於7月10日「通知」經濟部智慧財產局辦理「扣押登記」（完成登記）。
  • 雖扣押命令於7月15日始「送達」予乙，但效力「自7月10日」即發生。
  • → 送達前已為扣押登記者，於登記時生效
一句話總結
  • 扣押、收取、移轉等命令應送達債務人及第三人，送達後應通知債權人。
  • 命令原則上送達第三人時生效（無第三人則送達債務人時生效）；但送達前已為扣押登記者，於登記時生效。

第三人之聲明異議與逕行執行

白話文
  • 第三人（例如銀行、雇主）如果「不承認」債務人對他有債權，或者對「金額有意見」， 或者有其他「可以對抗債務人」的理由（例如已經還錢了）：
    • 必須在「收到法院命令後10天內」，用「書面」向執行法院「聲明異議」。
  • 如果第三人「沒有在10天內異議」，也沒有依照法院命令把錢付給債權人或交給法院：
    • 執行法院可以因為「債權人」的請求，「直接」對該第三人「強制執行」。
  • 對於這種「直接執行」，第三人可以用「第一項的異議事由」來「提起異議之訴」救濟。
    • 提起異議之訴時，可以「聲請停止執行」（須提供擔保）。
  • 簡單說：
    • 第三人對債權有爭議，應於10日內書面異議。
    • 逾期未異議且未依命令履行，法院得因債權人聲請逕對第三人強制執行。
    • 第三人得提起異議之訴救濟，並準用停止執行之規定。
例1.
  • A銀行（第三人）收到法院扣押命令，認債務人乙對其「無存款債權」。
  • A銀行於「送達後第5日」以「書狀」向執行法院「聲明異議」。
  • → 第三人對債權有爭議，應於10日內書面異議
例2.
  • A銀行收到命令後，「未於10日內異議」，「亦未」將乙之存款支付予法院。
  • 債權人甲「聲請」執行法院對A銀行「逕行執行」，法院扣押A銀行之財產。
  • → 逾期未異議且未依命令履行，法院得因債權人聲請逕對第三人強制執行
例3.
  • A銀行遭「逕行執行」後，以「乙對其無存款債權」為由，對債權人甲「提起異議之訴」。
  • → 對於這種「直接執行」，第三人可以用「第一項的異議事由」來「提起異議之訴」救濟
一句話總結
  • 第三人對債權有爭議，應於10日內書面異議。
  • 逾期未異議且未依命令履行，法院得因債權人聲請逕對第三人強制執行。
  • 第三人得提起異議之訴救濟，並準用停止執行之規定。

第三人異議後債權人之訴訟與撤銷命令

白話文
  • 如果第三人「聲明異議」，執行法院必須「通知」債權人。
  • 債權人如果「認為」第三人的異議「不實在」：
    • 可以在「收到通知後10天內」，向法院「提起訴訟」，
    • 並且必須向「執行法院」提出「已經起訴的證明」，同時也要「告知」債務人。
  • 如果債權人「沒有在10天內提出起訴的證明」：
    • 執行法院就可以「依第三人的請求」，把之前發的「執行命令」「撤銷」。
  • 簡單說：
    • 第三人異議時，法院應通知債權人。
    • 債權人認異議不實，應於10日內起訴並證明。
    • 逾期未證明，法院得依第三人聲請撤銷命令。
例1.
  • A銀行（第三人）對扣押命令「聲明異議」（主張乙無存款）。
  • 執行法院「通知」債權人甲。甲「認為」異議不實，於「通知送達後第5日」向法院提起「確認債權存在之訴」， 並向執行法院提出「起訴證明」，同時「告知」債務人乙。
  • → 第三人異議時，法院應通知債權人。債權人認異議不實，應於10日內起訴並證明
例2.
  • 甲收到通知後，未於「10日內」提出「起訴證明」。
  • A銀行聲請「撤銷扣押命令」，執行法院即「撤銷」該命令。
  • → 如果債權人收到異議通知「沒有在10天內提出起訴的證明」：執行法院就可以「依第三人的請求」，把之前發的「執行命令」「撤銷」
一句話總結
  • 第三人異議時，法院應通知債權人。
  • 債權人認異議不實，應於10日內起訴並證明。
  • 逾期未證明，法院得依第三人聲請撤銷命令。

債務人持有債權書據之處理

白話文
  • 如果債務人對第三人有債權，並「持有」相關的書據（例如借據、股票）， 法院「命令」債務人交出來，但債務人「拒絕」時：
    • 法院可以「強行取出」這份書據。
    • 如果沒辦法取出（例如被藏起來了），法院可以「公告」說「這份書據無效」， 然後另外「製作證明書」給債權人。
  • 簡單說：
    • 法院可強制取出書據；若無法取出，可公告宣示書據無效，另發證明書予債權人。
例1.
  • 甲對乙有債權，乙對丙有「借據」（書據）。 執行法院命乙交出借據，乙拒絕。
  • 法院依第48條「搜索」乙之處所，於保險箱內發現借據，「強制取出」後交予甲。
  • → 法院可強制取出書據
例2.
  • 乙拒絕交出借據，且借據「已遺失」無法取出。
  • 執行法院「公告」宣示該借據「無效」，並另作「證明書」發給甲。甲持證明書向丙請求清償。
  • → 若無法取出，可公告宣示書據無效，另發證明書予債權人
一句話總結
  • 法院可強制取出書據；若無法取出，可公告宣示書據無效，另發證明書予債權人。

社會福利、救助津貼及維持生活所必需之債權禁止執行

白話文
  • 債務人「依法領取」的「社會福利津貼、社會救助或補助」（例如低收入戶補助、老人津貼），「不得」強制執行。
  • 另外，債務人「依法領取」的「社會保險給付」（例如勞保、國民年金）或「對第三人的債權」（例如薪資），
    • 如果這些錢是「維持債務人及其家人生活所必需」的，也「不得」強制執行。
  • 什麼是「生活所必需」？
    • 原則上以「最近一年衛生福利部或直轄市政府公告的當地每人每月最低生活費的1.2倍」來計算。
    • 而且要「考量債務人的其他財產」。
  • 如果債務人還要扶養「共同生活的親屬」，也「比照」同樣的計算基準，
    • 並按債務人「應負擔的扶養比例」來計算。
  • 不過，如果法院覺得「完全禁止執行」會「顯失公平」，就可以「不受」前三項規定的限制，
    • 但「仍然必須預留」債務人及其扶養親屬的「生活費用」。
  • 簡單說：
    • 社會福利津貼、救助補助不得執行。
    • 社會保險給付及維持生活所必需之債權不得執行。
    • 生活必需數額以最低生活費1.2倍計算；扶養親屬部分準用之。
    • 法院認顯失公平者得調整，但須預留生活費。
例1.
  • 甲領有「低收入戶生活扶助」每月1萬元，債權人乙聲請扣押該筆補助。執行法院「不得」扣押。
  • → 社會福利津貼不得執行
例2.
  • 甲領有「勞保老年年金」每月2萬元，該年金係甲維持生活所必需（無其他收入），法院「不得」扣押。
  • → 社會保險給付不得執行
例3.
  • 甲居住於台北市，最低生活費為19,000元，1.2倍為22,800元。
  • 甲月薪5萬元，扣除22,800元（生活必需）後，僅得就「27,200元」範圍內扣押。
  • → 生活必需數額以最低生活費1.2倍計算
例4.
  • 甲扶養「配偶」及「未成年子女」2人，扶養比例為1/3。
  • 最低生活費1.2倍為22,800元，甲應負擔「22,800 × 1/3 × 2人」= 15,200元（生活必需）。
  • → 扶養「共同生活的親屬」，按債務人「應負擔的扶養比例」來計算
例5.
  • 甲月薪10萬元，生活必需僅需3萬元，若僅扣押「少額」對債權人「顯失公平」，法院得「提高」扣押比例。
  • 但仍須「預留」3萬元生活費。
  • → 法院認顯失公平者得調整，但須預留生活費
一句話總結
  • 社會福利津貼、救助補助不得執行。
  • 社會保險給付及維持生活所必需之債權不得執行。
  • 生活必需數額以最低生活費1.2倍計算；扶養親屬部分準用之。
  • 法院認顯失公平者得調整，但須預留生活費。
