3 關於物之交付請求權之執行

第123條 動產交付請求權之執行
  1. 「執行名義係命債務人交付一定之動產而不交付者，執行法院得將該動產取交債權人。」
  2. 「債務人應交付之物為書據、印章或其他相類之憑證而依前項規定執行無效果者，得準用第一百二十一條、第一百二十八條第一項之規定強制執行之。」
這一條是關於？
  • 如果執行名義是「命令債務人交付『一定的動產』」給債權人（例如交付一輛車、一批貨物）， 但債務人「不交付」時：
    • 執行法院可以「直接把該動產取走」，交給債權人。
  • 如果債務人應該交付的東西是「書據、印章」或其他類似的「憑證」（例如所有權狀、存摺、公司大小章），
    • 而依照前項規定（直接取交）「無法執行」時（例如書據被藏起來找不到），
    • 法院可以「準用」第121條（債務人持有債權書據之處理） 及第128條第1項（行為不行為請求權之執行，處以怠金）的規定來強制執行。
  • 簡單說：第123條是「動產交付請求權之執行」——
    • 法院得直接取交動產交付債權人。
    • 若為書據、印章等憑證且直接取交無效果，得準用第121條及第128條第1項強制執行。
這一條的核心
  • 本條係強制執行法關於「動產交付請求權執行」之核心規定，
    • 其立法目的在於「確保債權人得取得特定動產之占有」及「提供書據、印章等憑證之特別執行方法」。
  • 執行名義若為「命債務人交付特定動產」（如「返還汽車」、「交付貨物」）：
    • 其執行方式與「金錢請求權」不同——並非「查封拍賣變價」，而是「直接取交」該特定物予債權人。
  • 第1項（一般動產）：
    • 法院得「直接」將該動產「取交」債權人（無需「拍賣」）。
    • 若債務人「拒不交付」，法院得「強制取交」（如搜索、查封）。
  • 第2項（書據、印章等憑證）：
    • 若應交付之物為「書據、印章或其他相類之憑證」（如所有權狀、公司章、存摺）。
    • 若「直接取交」無效（如無法尋獲），得「準用」：
      • 第121條：債務人持有書據之處理（命交出、強制取出、公告無效、另發證明書）。
      • 第128條第1項：行為不行為請求權之執行（處以「怠金」）。
條文拆解
第1項
  • 「執行名義係命債務人交付一定之動產而不交付者」
    • 「一定之動產」：須「特定」之動產（如「特定車號之汽車」、「特定型號之機器」）。
    • 「不交付」：債務人「拒絕」或「遲延」交付。
  • 「執行法院得將該動產取交債權人」
    • 「得」：法院有裁量權（得「強制取交」）。
    • 「取交」：執行人員「搜尋」該動產，「取走」並「交付」予債權人。
第2項
  • 「債務人應交付之物為書據、印章或其他相類之憑證而依前項規定執行無效果者」
    • 「書據」：如「借據」、「所有權狀」。
    • 「印章」：如「公司大小章」、「個人印鑑」。
    • 「其他相類之憑證」：如「存摺」、「提款卡」、「股票」。
    • 「執行無效果」：如「該物已滅失」或「無法尋獲」。
  • 「得準用第一百二十一條、第一百二十八條第一項之規定強制執行之」
    • 第121條：
      • 命債務人「交出」書據。
      • 若拒絕，得「強制取出」。
      • 若無法取出，得「公告無效」，另發「證明書」。
    • 第128條第1項：
      • 對「行為不行為請求權」之執行——處以「怠金」（間接強制）。
      • 本條「準用」怠金制度：命債務人「交出」憑證，若「不從」，得「處以怠金」。
為什麼要有這條規定？
  • 確保債權人取得特定動產之占有：直接「取交」予債權人，滿足其「物之交付請求權」。
  • 提供書據、印章等憑證之特別執行方法：此類憑證之「交付」具有「證明」或「法律行為」之功能（如公司大小章），其執行方式應有「彈性」。
  • 以「怠金」間接強制：若債務人「拒不交出」憑證，得「處以怠金」，迫使債務人「自行」交付。
  • 與第121條（書據處理）銜接：若憑證「無法尋獲」，得以「公告無效」及「另發證明書」解決。
白話文
  • 如果執行名義是「命令債務人交付『特定的動產』」（例如汽車、貨物），但債務人「不交」時：
    • 執行法院可以「直接把該動產拿走」，交給債權人。
  • 如果債務人應該交付的是「書據、印章」或其他類似的「憑證」（例如所有權狀、公司章）， 而且「直接取交」沒有辦法執行時（例如被藏起來找不到），
    • 法院可以「比照」第121條（書據處理）及第128條第1項（行為不行為執行，處以怠金）的規定來強制執行。
  • 簡單說：
    • 法院得直接取交動產交付債權人。
    • 若為書據、印章等憑證且直接取交無效果，得準用第121條及第128條第1項強制執行。
舉個例子
例1：直接取交動產
  • 甲對乙有「返還汽車」之確定判決，乙拒不返還。
  • 執行法院依第123條第1項，至乙之住處「取走」該汽車，「交付」予甲。
  • → 符合第123條第1項。
例2：書據執行
  • 甲對乙有「返還所有權狀」之執行名義，乙拒不交出。
  • 執行法院依第123條第2項「準用」第121條，命乙「交出」權狀，乙拒絕，法院「強制取出」； 若無法取出，得「公告無效」並「另發證明書」予甲。
  • → 符合第123條第2項。
例3：怠金強制
  • 乙應交付「公司大小章」予甲，但乙拒不交付，且該印章「無法尋獲」。
  • 執行法院「準用」第128條第1項，對乙「處以怠金」（如3萬元），迫使乙「自行」交付印章。
  • → 符合第123條第2項。
實務運作
  • 「一定之動產」之認定：
    • 須「特定」——如「車牌號碼XXX之汽車」、「編號XXX之機器」。
    • 若為「種類物」（如「100公斤米」），仍得執行（但須「指定」）。
  • 「取交」之方式：
    • 法院應「搜尋」該動產（得「搜索」債務人處所，第48條）。
    • 若該動產「在第三人處」，得「命第三人交付」（第116條）。
  • 書據、印章執行之優先順序：
    • 先「命交出」（第121條）。
    • 若「拒絕」，得「強制取出」或「處以怠金」（第128條）。
    • 若「無法取出」，得「公告無效」並「另發證明書」。
  • 「怠金」之數額：
    • 由法院「酌定」（通常為「新臺幣3萬元至30萬元」），得「連續處罰」。
一句話總結
    第123條是「動產交付請求權之執行」——
  • 法院得直接取交動產交付債權人。
  • 若為書據、印章等憑證且直接取交無效果，得準用第121條及第128條第1項強制執行。
第124條 不動產、船舶及航空器交付請求權之執行
  1. 「執行名義係命債務人交出不動產而不交出者，執行法院得解除債務人之占有，使歸債權人占有。如債務人於解除占有後，復即占有該不動產者，執行法院得依聲請再為執行。」
  2. 「前項再為執行，應徵執行費。」
  3. 「執行名義係命債務人交出船舶、航空器或在建造中之船舶而不交出者，準用前二項規定。」
這一條是關於？
  • 如果執行名義是「命令債務人交出不動產」（例如返還房屋、土地），但債務人「不交出」時：
    • 執行法院可以「解除」債務人的「占有」，把不動產「交給」債權人占有。
  • 如果債務人在被解除占有「之後」，又「再度」占有該不動產：
    • 法院可以「依聲請」再次執行（再解除占有並交付）。
    • 而且，這種「再執行」要「徵收執行費」。
  • 另外，如果執行名義是「命令債務人交出船舶、航空器或建造中的船舶」但債務人「不交出」：
    • 也「準用」前面兩項的規定（即解除占有交付，再占有可再執行，再執行徵收執行費）。
  • 簡單說：第124條是「不動產、船舶及航空器交付請求權之執行」——
    • 法院得解除債務人占有，將不動產交付債權人。
    • 債務人復占有者，得再執行（應徵執行費）。
    • 船舶、航空器等亦同。
這一條的核心
  • 本條係強制執行法關於「不動產交付請求權執行」之規定，
    • 其立法目的在於「確保債權人取得不動產之現實占有」。
  • 與動產交付（第123條「取交」）不同，不動產「無法移動」，
    • 其執行方式為「解除債務人之占有，使歸債權人占有」（即「點交」）。
  • 本條三項要旨：
    • 第1項（不動產交付）：法院得「解除占有」→「交付」予債權人。
    • 第2項（再執行）：若債務人「復占有」，得「再執行」——但須「徵收執行費」。
    • 第3項（船舶、航空器）：交付船舶、航空器、建造中船舶者，準用前二項。
條文拆解
第1項
  • 「執行名義係命債務人交出不動產而不交出者」
    • 「交出不動產」：如「返還房屋」、「遷讓土地」。
    • 「不交出」：債務人「拒絕」或「遲延」交付。
  • 「執行法院得解除債務人之占有，使歸債權人占有」
    • 「解除占有」：將債務人（及其家屬、物品）「驅離」該不動產。
    • 「使歸債權人占有」：將不動產之「現實占有」移轉予債權人。
  • 「如債務人於解除占有後，復即占有該不動產者，執行法院得依聲請再為執行」
    • 「復即占有」：債務人「再度」進入或占用該不動產。
    • 「執行法院得依聲請再為執行」：須由「債權人」聲請，法院再行「解除占有」並「交付」。
第2項
  • 「前項再為執行，應徵執行費」
    • 「再為執行」係「另一執行程序」，應「另徵執行費」（第28條之2）。
第3項
  • 「執行名義係命債務人交出船舶、航空器或在建造中之船舶而不交出者，準用前二項規定」
    • 「船舶」：海商法所定之船舶（第114條）。
    • 「航空器」：民用航空法所定之航空器（第114條之4）。
    • 「建造中之船舶」：仍得為執行標的（第114條第1項）。
    • 「準用」：亦得「解除占有」並「交付」，且「再執行」應「徵執行費」。
為什麼要有這條規定？
  • 確保債權人取得不動產之現實占有：所有權之行使須以「占有」為基礎，交付執行使債權人得「實際使用」不動產。
  • 防止債務人反覆占用：賦予「再執行」之機制，避免債務人「點交後又搬回」。
  • 明確再執行之費用：再執行屬「新執行程序」，應「另徵執行費」。
  • 適用於船舶、航空器等：此類高價值交通運輸工具，其「交付」亦應有「強制力」。
白話文
  • 如果執行名義是「命令債務人交出不動產」（例如房屋、土地），但債務人「不交」時：
    • 執行法院可以「解除」債務人的「占有」，把不動產「交給」債權人占有。
  • 如果債務人在被解除占有「之後」，又「跑回來」占用：
    • 法院可以「依聲請」再次執行（再驅離並交付）。
    • 這種「再執行」要「徵收執行費」。
  • 另外，如果執行名義是「命令債務人交出船舶、航空器或建造中的船舶」，也「比照」前面兩項的規定。
  • 簡單說：
    • 法院得解除債務人占有，將不動產交付債權人。
    • 債務人復占有者，得再執行（應徵執行費）。
    • 船舶、航空器等亦同。
舉個例子
例1：不動產交付
  • 甲對乙有「返還房屋」之確定判決，乙拒不搬遷。
  • 執行法院至現場「解除」乙之占有（強制搬離物品），將房屋「交付」予甲。
  • → 符合第124條第1項。
例2：復占有，再執行
  • 甲取得房屋後，乙「再度」搬入該屋。
  • 甲「聲請」法院「再執行」，法院再行「解除」乙之占有，並「徵收」執行費。
  • → 符合第124條第1項後段、第2項。
例3：船舶交付
  • 甲對乙有「返還船舶」之執行名義，乙拒不交付。
  • 法院「準用」第124條第1項，解除乙對船舶之占有，將船舶「交付」予甲。
  • → 符合第124條第3項。
實務運作
  • 「解除占有」之方式：
    • 法院應「事先」命債務人「限期搬離」。
    • 若逾期，法院「強制執行」——由執達員至現場「驅離」債務人及物品。
    • 得請求「警察」協助（第3條之1）。
  • 「再執行」之程序：
    • 須由「債權人」聲請（法院不得依職權）。
    • 應「另行徵收」執行費（按執行標的價額計算）。
  • 船舶、航空器交付：
    • 船舶：應將船舶「駛離」或「交付」予債權人。
    • 航空器：應將航空器「飛離」或「交付」予債權人（惟實務上多以「交付證書」及「解除占有」方式為之）。
  • 與第99條（點交）之區別：
    • 第99條：拍賣後之「點交」（買受人）。
    • 本條：基於「執行名義」之「交付」請求權（債權人）。
一句話總結
    第124條是「不動產、船舶及航空器交付請求權之執行」——
  • 法院得解除債務人占有，將不動產交付債權人。
  • 債務人復占有者，得再執行（應徵執行費）。
  • 船舶、航空器等亦同。
第125條 動產、不動產交付執行程序之準用
  • 「關於動產、不動產執行之規定，於前二條情形準用之。」
這一條是關於？
  • 在執行「動產交付」（第123條）或「不動產交付」（第124條）時，
  • 如果有程序上的需要，可以「準用」前面「關於動產、不動產執行之規定」。
  • 簡單說：第125條是「動產、不動產交付執行程序之準用」——
  • 關於動產、不動產執行的規定，於第123條、第124條之情形準用之。
這一條的核心
  • 本條係強制執行法關於「動產、不動產交付執行之補充程序」之規定，
    • 其立法目的在於「確保動產及不動產交付執行程序之完整性」。
  • 第123條（動產交付）及第124條（不動產交付）雖已規定「取交」及「解除占有」之主要執行方式，
    • 惟其「具體執行程序」（如查封、搜索、保管、點交等）仍有不足，
    • 故本條以「準用」方式，引入「動產執行」（第45條至第74條）及「不動產執行」（第75條至第113條）之相關程序規定。
  • 本條之「準用」範圍，包括：
    • 動產交付（第123條）：準用「動產執行」之「查封」、「搜索」、「保管」等規定。
    • 不動產交付（第124條）：準用「不動產執行」之「查封」、「點交」等規定。
條文拆解
  • 「關於動產、不動產執行之規定」
    • 「動產執行之規定」：第45條至第74條（查封、拍賣、變賣、鑑定、公告、筆錄等）。
    • 「不動產執行之規定」：第75條至第113條（查封、拍賣、強制管理、鑑價、公告、點交等）。
  • 「於前二條情形準用之」
    • 「前二條」：第123條（動產交付）及第124條（不動產交付）。
    • 「準用」：即「性質相容」之程序規定，得「比照適用」。
為什麼要有這條規定？
  • 確保執行程序之完整性：動產、不動產交付之執行，除「取交」或「解除占有」外，尚須「搜索」、「查封」、「點交」等程序，本條提供「準用」依據。
  • 節省立法資源：無庸重複規定動產、不動產執行之「全部」程序。
  • 維持程序之一致性：使動產、不動產交付執行之程序，與「查封拍賣」之程序儘可能一致。
白話文
  • 在執行「動產交付」（第123條）或「不動產交付」（第124條）時：
    • 如果有程序上的需要，可以「比照」前面「關於動產、不動產執行」的規定來辦理。
  • 簡單說：關於動產、不動產執行的規定，於第123條、第124條之情形準用之。
舉個例子
例1：準用動產查封
  • 甲對乙有「返還汽車」之執行名義，乙拒不交付。
  • 執行法院依第123條「取交」前，得「準用」動產查封之規定（第46條、第48條），「搜索」乙之處所並「查封」該汽車。
  • → 符合第125條。
例2：準用不動產點交
  • 甲對乙有「返還房屋」之執行名義，乙拒不搬遷。
  • 執行法院依第124條「解除占有」時，得「準用」不動產點交之規定（第99條），「強制搬離」乙之物品並「換鎖」。
  • → 符合第125條。
一句話總結
    第125條是「動產、不動產交付執行程序之準用」——
  • 關於動產、不動產執行的規定，於第123條、第124條之情形準用之。
第126條 第三人占有之交付請求權移轉
  • 「第一百二十三條及第一百二十四條應交付之動產、不動產或船舶及航空器為第三人占有者，執行法院應以命令將債務人對於第三人得請求交付之權利移轉於債權人。」
這一條是關於？
  • 第123條（動產交付）和第124條（不動產、船舶、航空器交付）所規定的 「應交付的動產、不動產或船舶、航空器」，
    • 如果是「第三人」占有著（例如債務人把東西借給朋友、租給房客），
    • 執行法院就必須用「命令」把「債務人對第三人請求交付的權利」移轉給債權人。
  • 簡單說：第126條是「第三人占有之交付請求權移轉」——
    • 應交付之動產、不動產等若為第三人占有，法院應將債務人對第三人之交付請求權移轉予債權人。
這一條的核心
  • 本條係強制執行法關於「第三人占有之物之交付執行」之規定，
    • 其立法目的在於「確保債權人得就第三人占有之標的物為執行」。
  • 動產交付（第123條）或不動產交付（第124條）之執行：
    • 若標的物「非債務人占有」而係「第三人占有」（如借用人、承租人、受託人）， 法院「無法」直接對債務人「取交」或「解除占有」。
    • 此時，執行法院應以「命令」將「債務人對第三人之交付請求權」移轉予債權人， 使債權人得「以自己名義」向第三人請求交付該物。
  • 本條之法律效果：
    • 移轉命令：將債務人對第三人之「交付請求權」移轉予債權人。
    • 債權人「取得」該請求權後，得「直接」向第三人「請求」交付該物。
    • 若第三人「拒絕交付」，債權人得「另行訴訟」請求（如「所有物返還請求權」或「基於移轉命令之請求權」）。
條文拆解
  • 「第一百二十三條及第一百二十四條應交付之動產、不動產或船舶及航空器」
    • 第123條：動產。
    • 第124條：不動產、船舶、航空器、建造中船舶。
  • 「為第三人占有者」
    • 「第三人」：非債務人（如「承租人」、「借用人」、「保管人」）。
    • 「占有」：該第三人「現實」占有該標的物。
  • 「執行法院應以命令將債務人對於第三人得請求交付之權利移轉於債權人」
    • 「應」：強制義務，法院「必須」發移轉命令。
    • 「移轉」：將債務人對第三人之「交付請求權」（基於「租賃」、「使用借貸」、「寄託」等）移轉予債權人。
    • 債權人「取得」該請求權後，得「以自己名義」向第三人請求交付。
為什麼要有這條規定？
  • 確保債權人得就第三人占有之標的物為執行：若標的物為第三人占有，法院無法「直接」對債務人執行，須透過「移轉請求權」之方式。
  • 簡化執行程序：以「命令」移轉請求權，無庸「另行訴訟」或「查封」第三人占有之物。
  • 賦予債權人直接請求權：債權人取得請求權後，得「直接」向第三人請求交付。
白話文
  • 第123條（動產交付）和第124條（不動產、船舶、航空器交付）所規定的「應交付的動產、不動產等」， 如果是「第三人」（例如房客、借用人）占著：
    • 執行法院就必須用「命令」把「債務人對第三人請求交付的權利」移轉給債權人，讓債權人自己去向第三人要回來。
  • 簡單說：應交付之動產、不動產等若為第三人占有，法院應將債務人對第三人之交付請求權移轉予債權人。
舉個例子
例1：動產為第三人占有
  • 甲對乙有「返還汽車」之執行名義，但該汽車現由「丙」（乙之友人）占有。
  • 執行法院發「移轉命令」，將乙對丙之「汽車交付請求權」移轉予甲。甲得「直接」向丙請求返還汽車。
  • → 符合第126條。
例2：不動產為第三人占有
  • 甲對乙有「返還房屋」之執行名義，但該房屋現由「丙」（承租人）占有。
  • 執行法院發「移轉命令」，將乙對丙之「房屋交付請求權」移轉予甲。甲得「直接」向丙請求返還房屋。
  • → 符合第126條。
例3：船舶為第三人占有
  • 甲對乙有「返還船舶」之執行名義，該船舶現由「丙」（保管人）占有。
  • 法院發「移轉命令」，將乙對丙之「船舶交付請求權」移轉予甲。
  • → 符合第126條。
實務運作
  • 「移轉命令」之內容：應載明：
    • 債務人對第三人之「交付請求權」之內容。
    • 該請求權「移轉」予債權人。
    • 第三人應「向債權人」交付該標的物。
  • 移轉後之法律效果：
    • 債權人「取得」該請求權（與第115條之「移轉命令」類似）。
    • 第三人「不得」再向債務人交付（否則對債權人不生效力）。
    • 若第三人「拒絕交付」，債權人得「提起訴訟」請求。
  • 與第115條（金錢債權移轉）之區別：
    • 第115條：移轉「金錢債權」。
    • 本條：移轉「物之交付請求權」。
  • 與第116條（命第三人交付）之區別：
    • 第116條：法院「直接」命第三人「交付」予執行法院。
    • 本條：法院「移轉請求權」予債權人，由債權人「自行」請求第三人交付。
一句話總結
    第126條是「第三人占有之交付請求權移轉」——
  • 應交付之動產、不動產等若為第三人占有，法院應將債務人對第三人之交付請求權移轉予債權人。
