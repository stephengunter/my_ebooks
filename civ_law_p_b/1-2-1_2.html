民事訴訟法 選定當事人

選定當事人

  • 「選定當事人」制度，就是讓一群利害關係相同的人，不必全體出庭，只要派代表就可以了。
  • 例如：一棟大樓的數十位住戶，都因為樓下工廠的噪音而受害。他們不需要全體都去當原告，可以選出幾個「班長」代表大家去告。
多數有「共同利益」之人，「不具非法人團體資格」者：得由其中「選定一人或數人」，代表全體起訴或被訴
  • 共同利益：指對於訴訟標的（例如請求損害賠償、請求給付會費），大家的利害關係是「相同」的、可以「合一確定」的。例如：
    • 同一棟大樓的住戶，都因為建商偷工減料而房屋受損。每個住戶的請求雖然金額不同，但都是基於同一個事實（建商偷工減料），有共同利益。
    • 同一個社區的居民，都受到附近工廠的噪音污染。
  • 「不具非法人團體資格」者：指不具有「非法人之團體，設有代表人或管理人者，有當事人能力」之當事人資格。
    • 如果他們已經組成非法人團體（例如有立案的社區發展協會），就直接用團體名義當事人即可，不需要再適用選定當事人制度。
  • 「選定一人或數人」：可以只選一個代表，也可以選好幾個代表。
  • 代表全體起訴或被訴：代表人可以當原告（告別人），也可以當被告（被人告）。
訴訟繫屬後，經「選定當事人」者，其他當事人「脫離訴訟」
  • 訴訟繫屬後：案件已經起訴，在法院審理中。
  • 脫離訴訟：其他當事人從訴訟中「退出」，不再是原告或被告。
    • 訴訟只剩下被選定人（班長）在進行（因為他們已經把訴訟實施權交給了班長）。
    • 而判決的效力仍然及於那些「脫離」的人。
例1.
  • 某社區50戶住戶，都因為建商「誠信建設公司」偷工減料，導致房屋牆壁龜裂、漏水。50戶住戶沒有成立管委會（或管委會不願出面）
  • 他們可以召開住戶大會，選出住戶代表「老王」一人，由老王代表50戶住戶向法院起訴，請求建商賠償每戶的修繕費用
  • 老王就是「被選定人」，其他49戶就是「選定人」
例2.
  • 承上例，老王和另外2個住戶（共3人）先向法院起訴。開庭一次後，其他47戶覺得應該一起加入，於是他們選定老王為代表人
  • 老王向法院陳報選定事實，法院准許後，其他47戶「脫離訴訟」，只剩下老王一個人繼續打官司
「得限制」選定當事人「捨棄、認諾、撤回或和解」
被選定人有為選定人為「一切訴訟行為」之權。但選定人「得限制」其為「捨棄、認諾、撤回或和解」
  • 被選定人：被選出來的代表人（班長）。
  • 一切訴訟行為之權：原則上，代表人可以進行訴訟上「所有」的行為，不需要每次都要得到選定人的同意。例如：
    • 提出起訴狀、答辯狀、準備書狀
    • 到法院開庭、陳述意見
    • 聲請調查證據、提出證據、對證據表示意見
  • 得限制其為「捨棄、認諾、撤回或和解」：這四種行為會直接「處分」當事人的實體權利（例如認諾就等於直接認輸，和解就等於放棄一部分權利），不像開庭陳述、提出證據只是「程序」行為。為了保護選定人的權益，法律允許選定人事先限制代表人的這四項權限。
限制選定當事人「捨棄、認諾、撤回或和解」者，應以文書證之，並提出於法院
  • 這些限制可以在「選定書」裡面寫清楚。也可以在選定之後另外用一份書狀（例如「限制權限聲明書」）向法院提出。
選定人中之一人所為限制，其效力不及於其他選定人
  • 選定人中之一人：某一個被代表的人（例如50個住戶中的某一個人）。
  • 所為限制：他個人說「我限制班長不能和解」。
  • 其效力不及於其他選定人：這個限制只對他自己有效，對其他選定人（其他49人）沒有效力。
    • 換句話說，必須「全體」選定人共同決定的限制，才有效力。
例1.
  • 某社區50戶住戶選定「老王」為代表人，告建商偷工減料。選定書上沒有寫任何限制。老王可以：
    • 向法院提出起訴狀、開庭時陳述事實、
    • 聲請法院鑑定房屋受損程度、對一審判決提起上訴
  • → 被選定人有為選定人為「一切訴訟行為」之權。
例2.
  • 承上例，50戶住戶在選定書上明確寫道：「老王不得與建商進行和解。」
  • 老王違反這個限制，私下與建商和解。
  • 這個和解原則上對住戶無效（因為代表人違反授權範圍）。建商如果知道老王有限制，和解可能被法院撤銷。
  • → 選定人「得限制」選定當事人為「捨棄、認諾、撤回或和解」
例3.
  • 承例1，住戶「老張」一個人寫了一封信給法院，說：「我限制老王不得撤回起訴。」其他49位住戶沒有表示意見。
  • 法院認為這個限制無效（因為不是全體選定人的共同決定）。
  • 老王仍然可以撤回起訴（但撤回後，老張可能告老王違反委任關係）。
  • → 選定人中之一人所為限制，其效力不及於其他選定人
例4.
  • 承例1，50戶住戶召開住戶大會，決議：「老王不得為捨棄、認諾、撤回或和解。」並將這個決議寫成書狀，送交法院。
  • 老王受到限制，不能擅自做這些行為 。
  • → 選定人「得限制」選定當事人為「捨棄、認諾、撤回或和解」
  • → 限制選定當事人「捨棄、認諾、撤回或和解」者，應以文書證之，並提出於法院
當事人之選定、更換、增減，應以文書證之。並通知他造
訴訟當事人之選定及其更換、增減，應以文書證之。
  • 當事人之選定：多數有共同利益的人，選出其中一人或數人，作為代表全體起訴或被訴的行為。
  • 更換、增減：改選另一個代表人，或增加/減少代表人數 。
  • 以文書證之：必須有「白紙黑字」的書面證據（例如選定書、會議記錄）。
選定當事人之「更換、增減」，非「通知他造」，不生效力
  • 通知他造：必須讓對方當事人（被告或原告）知道這個變更。
  • 不生效力：如果沒有通知對方，對方仍然可以跟原來的代表人開庭、和解，原來的代表人做的行為仍然有效。直到通知到達對方時，新的代表人才正式取代舊的。
例1.
  • 某社區50戶住戶要告建商，他們召開住戶大會，決議選出「老王」為代表人，並製作了一份「選定書」，上面有50戶住戶的簽名（或蓋章），寫明：「就ＯＯ建案房屋瑕疵損害賠償事件，全體住戶選定老王為代表人，代表全體起訴。」
  • 老王拿著這份選定書向法院起訴。法院認為選定合法有效。
  • → 訴訟當事人之選定，應以文書證之。
例2.
  • 承上例，老王後來搬家出國，無法繼續擔任代表人。住戶們重新選定「老李」為新的代表人。
  • 老李必須將「更換」的事實通知建商（他造）。通知到達建商後，老李才能取代老王 。
  • → 選定當事人之「更換、增減」，非「通知他造」，不生效力。
被選定人死亡者，不影響其他被選定人之代表權
被選定人中，有因死亡或其他事由喪失其資格者，他被選定人得為全體為訴訟行為
  • 如果一群人選了兩個以上的代表人（班長），其中一人因死亡或其他原因不能繼續擔任時，剩下的代表人可以自己繼續代表全體進行訴訟，不需要立刻重新選舉。
選定公益社團法人為當事人
  • 同一公益社團法人（如工會、農會）的多數社員，在章程目的範圍內有共同利益時，可以選定該法人代表全體起訴。
  • 如果是請求金錢賠償，且全體社員以書面同意只判總額並協議好分配方法，法院就可以只判被告應給付的總金額，不必分別認定各社員的數額。
多數有共同利益之人，為「同一公益社團法人之社員」者，於「章程所定目的範圍內」，得選定該法人為選定人起訴
  • 多數有共同利益之人：指一群人對於訴訟標的有共同的利害關係（例如同一家公司被欠薪的員工）。
  • 同一公益社團法人：指以公益為目的的社團法人，例如：工會（如中華電信企業工會）、農會、其他依法設立之公益社團。
  • 社員：這些人必須是該法人的「會員」。例如：工會的會員、農會的會員。
  • 於章程所定目的範圍內：訴訟的內容必須與法人的章程目的相關。
    • 例如：工會為會員爭取加班費（與保障勞動權益有關），在章程目的範圍內。
    • 如果工會為會員處理買賣房屋的糾紛（與勞動權益無關），就不在章程目的範圍內，不能適用本條。
  • 得選定該法人為選定人起訴：由該法人以自己的名義，為全體選定人（社員）提起訴訟。
選定法人為社員提起「金錢賠償」損害之訴時，得就「應給付總額及分配方法」達成協議並提出於法院。由法院「就應給付總額為裁判」
  • 適用要件：
    1. 「選定法人」：多數有共同利益之人，為「同一公益社團法人之社員」者，於「章程所定目的範圍內」，選定該法人為選定人起訴。
    2. 「金錢賠償」損害之訴：例如請求給付加班費、請求損害賠償。
    3. 就「應給付總額及分配方法」達成協議：必須「全體」社員同意應給付總額及分配方法。
      • 例如應給付總額500萬，按損害程度比例分配。
    4. 提出於法院：協議應以書面為證，並具狀向法院提出，表明：「願由法院判定被告應給付選定人全體之總額」。
  • 法律效果：法院可以只判應給付總額，不必分別認定各選定人應受給付金額。簡化審理過程。
例1.
  • 某公司有100名員工，都是該公司「企業工會」的會員。公司長期積欠員工「平日加班費」，每人欠的金額不同（有的5萬、有的10萬）。
  • 工會章程明定「保障會員勞動權益」。
  • 工會召開會員大會，100名會員決議「選定工會為代表人」，由工會向法院起訴，請求公司給付積欠的加班費。
  • 法院審理後，准許工會為被選定人。
  • → 多數有共同利益之人，為「同一公益社團法人之社員」者，於「章程所定目的範圍內」，得選定該法人為選定人起訴。
例2.
  • 承上例，100名會員覺得如果要法院一個一個算每個人的加班費，官司會打很久。於是他們「全體」簽了一份「協議書」，內容：
    1. 請求法院只判「公司應給付全體會員加班費之總額」
    2. 內部協議分配方法：按「每個人被積欠的加班費數額（依出勤紀錄計算）」比例分配
    他們將這份協議書連同起訴狀一併提交法院。
  • 法院審查後，認為符合第44-1條第2項，決定只判「公司應給付全體會員加班費總額新台幣500萬元」（假設數字），而不逐一認定每個人各得多少 。
  • → 選定法人為社員提起「金錢賠償」損害之訴時，得就「應給付總額及分配方法」達成協議並提出於法院。由法院「就應給付總額為裁判」

公告曉示制度

  • 在公害、交通事故、商品瑕疵等大規模受害事件中，當有人先提起訴訟後：
    • 法院可以透過公告（在法院網站、佈告欄、甚至報紙），通知其他有相同受害事實的人在一定期間內登記併案。
  • 登記的人自動視為選定原來的代表人，大家一起在同一訴訟中解決紛爭。
  • 就算原來的代表人不同意，法院也可以主動公告
適用事件類型：「公害、交通事故、商品瑕疵」或其他「本於同一原因事實」而有「共同利益」之多數人
  • 公害：例如工廠排放廢水、廢氣，污染附近農田或住宅。
  • 交通事故：例如火車出軌、空難、遊覽車翻覆，造成多人傷亡。
  • 商品瑕疵：例如問題奶粉、問題汽車（安全氣囊瑕疵）、問題食品（塑化劑）。
  • 其他本於同一原因事實而有共同利益之多數人：概括條款，例如：金融詐欺（同一投資案）、大樓倒塌（同一建商偷工減料）。
前提要件：「已經選定當事人」且「已經起訴」
  • 必須已經有人先依選定當事人之規定（書面提出於法院），選出了「代表人」（原被選定人），並且已經向法院起訴。這是「先鋒部隊」。
發動方式：「依聲請」或「依職權」
  • 法院「徵求被選定人之同意」：法院主動問先鋒班長：「我可以幫你公告找其他人嗎？」班長說好。
    • 被選定人不同意，法院仍得「依職權」公告曉示。
  • 「被選定人向法院聲請獲准」：班長自己跟法院說：「請幫我公告找其他人。」法院覺得OK。
  • 「其他有共同利益之人，亦得聲請」：尚未起訴、也不是原被選定人的其他受害者也可以「主動」向法院聲請，要求法院發布公告。
公告曉示：「其他共同利益人」，得於一定期間內「提出併案請求」
  • 公告曉示：公告於法院公告欄、法院網站，必要時得登載公報、新聞紙或以其他傳播工具公告之，其費用由國庫墊付。
  • 其他共同利益人：還沒有加入訴訟的其他受害者。
  • 一定期間內：法院會訂一個期限（至少20天）。
  • 「提出併案請求」：以書狀表明其原因事實、證據及應受判決事項之聲明，向法院提出併案請求。
    • 併案請求：法院會把這些人的請求，跟原來的案子合併在一起審理。
併案請求之人，視為「已依法為選定」
  • 這些來登記的人，不用再重新簽一份選定書，法律自動「當作」他們已經選定了原來的班長（原被選定人）作為他們的代表人。
併案請求之書狀，應送達繕本於兩造
  • 要把這份書狀的影本，寄給「原告方」（原被選定人）和「被告方」（對造）。讓雙方都知道「又有人加入訴訟了」。
例1.
  • 台鐵某列車出軌，造成100人受傷。其中10名傷者先選出「老王」為代表人，向台鐵提起損害賠償訴訟。
  • 法院認為這是「交通事故」，且有「共同利益」，於是徵求老王同意後，在法院網站及公告處發布公告：「因本件火車出軌事故受傷之其他乘客，得於公告日起30日內，以書狀向本院併案請求。」
  • 公告期間，另有50名傷者（不知道老王在告）看到公告，向法院提出書狀（載明原因事實、證據、請求金額）
  • 法院將這50人併入原訴訟。這50人視為已選定老王為代表人。
  • → 其他有共同利益之人，亦得聲請公告曉示
例2.
  • 承上例，老王沒有聲請公告曉示，法院也沒有主動徵求同意。
  • 另外一個受害者「老李」（不在原來的10人中）看到新聞，知道老王在告，但老王不願意公告。老李可以自己寫信給法院：「請法院依第44-2條第2項公告曉示。」
  • 法院審查後認為適當，發布公告。
  • → 法院得「徵求被選定人之同意」後，公告曉示
