民事訴訟法 訴訟費用之擔保

訴訟費用之擔保

原告在中華民國無住所等時之訴訟費用擔保
  • 外國原告在台灣沒據點時，被告可要求他提供訴訟費用擔保（押金）。
  • 若原告有資產或被告已承認部分請求，則不在此限。
「原告」於我國無住所/事務所/營業所者
  • 重點：原告在國內「無任何財產上之聯絡點」，致被告將來無法對其強制執行。
法院應「依被告聲請」，以「裁定」命原告供訴訟費用之「擔保」
  • 依被告聲請：法院不得依職權為之，須由被告主動聲請（被告可放棄此權利）。
  • 以裁定命原告供擔保：法院應以裁定指定擔保金額及方式（如現金提存、有價證券）。
訴訟中發生擔保「不足額」或「不確實」之情事時，亦同
  • 擔保不足額：擔保金數額不足以支付可能之訴訟費用（如訴訟規模擴大、費用增加）。
  • 擔保不確實：擔保品價值下跌（如股票跌價）或銀行保證失效等。
  • 法院得依聲請命原告補足或更換擔保。
例外無須擔保：1.被告對請求「不爭執」部分 2.原告在我國有「足額資產」
  • 被告對請求不爭執：若原告之請求中，有一部分被告「不爭執」（例如被告承認積欠5萬元，但爭執其餘金額），則該無爭執部分無須擔保。
  • 原告在我國有「足額資產」：若原告在台灣境內有「足夠資產」（如不動產、存款），足以支付可能之訴訟費用，則被告將來已可對該資產執行，無須命供擔保。
例1.
  • 甲（美國人，在台無住所）起訴乙請求給付貨款。乙向法院聲請命甲供訴訟費用擔保。
  • 法院審查後，裁定甲應提供50萬元擔保金（預估訴訟費用）。
  • → 在台無住所，被告聲請擔保
例2.
  • 甲已提供50萬元擔保，但訴訟中因追加請求，預估訴訟費用增加為80萬元。
  • 乙聲請法院命甲補足擔保30萬元。法院裁定准許。
  • → 訴訟中擔保不足
例3.
  • 甲起訴請求乙給付100萬元，乙對其中30萬元不爭執（承認欠款），僅爭執70萬元。
  • 法院認該30萬元不爭執部分無擔保必要，僅命甲就70萬元部分提供擔保。
  • → 被告對請求「不爭執」部分無須擔保
例4.
  • 甲（香港公司）在台擁有一棟價值1,000萬元之不動產，足以支付訴訟費用。
  • 乙聲請命甲供擔保。法院審查後認甲之資產足以賠償費用，裁定駁回乙之聲請。
  • → 原告在台有資產，得免擔保
被告聲請供擔保之失權時點
  • 被告若已對案情實質開庭辯論，原則上就不能再要求原告提供擔保金。
    • 除非是開庭後才知道對方該提供擔保的事由。
被告已為本案之「言詞辯論」者，「不得聲請」命原告供擔保
  • 本案之言詞辯論：指被告於言詞辯論期日，就「訴訟標的之實體爭點」為陳述或答辯（如爭執事實、提出抗辯）。
  • 不得聲請命原告供擔保：被告喪失依第96條聲請命原告供訴訟費用擔保之權利。法院應駁回其聲請。
例外：應供擔保之「事由知悉在後」者，不在此限
  • 應供擔保之事由：指原告於中華民國無住所、事務所及營業所，或擔保不足等事由。
  • 知悉在後：被告於本案言詞辯論終結後，始「知悉」該事由（如原告將財產移往國外）。
  • 不在此限：此時，被告仍得聲請供擔保（不受前段限制）。
例1.
  • 甲（外國人）起訴乙，乙於第一次言詞辯論期日已就甲之請求為實質答辯（爭執金額）。
  • 乙於第二次開庭時，才聲請命甲供訴訟費用擔保。法院認乙已為本案言詞辯論，駁回其聲請。
  • → 已為本案言詞辯論，不得聲請
例2.
  • 甲（外國人）起訴乙，乙已為本案言詞辯論。辯論終結後，乙始知悉甲已將其國內唯一資產移轉至國外（致將來無法求償費用）。
  • 乙立即聲請命甲供擔保。法院認符合「知悉在後」之例外，裁定命甲供擔保。
  • → 知悉在後，例外准許
被告聲請供擔保後之拒絕辯論權
  • 被告在聲請命原告提供擔保金之後、法院駁回聲請或原告拿出擔保金之前，可以暫時拒絕針對案件實質內容進行辯論。
被告「聲請命原告供擔保」者，於其聲請被「駁回」或原告「供擔保前」，「得拒絕本案辯論」
  • 被告聲請命原告供擔保者：被告已依第96條向法院提出聲請，請求命原告提供訴訟費用擔保。
  • 聲請被駁回：指法院已裁定駁回被告之擔保聲請。
  • 拒絕本案辯論：被告對原告之「實體主張」（如給付請求權之原因事實）不為實質答辯（如不爭執、不抗辯），僅主張「先處理擔保問題」。
例1.
  • 甲（外國人）起訴乙，乙聲請命甲供擔保。第一次開庭時，乙主張「在甲未提供擔保前，拒絕本案辯論」。
  • 法院即先就擔保聲請為調查，暫不審理甲之請求有無理由。
  • → 聲請被「駁回」或原告「供擔保前」，被告「得拒絕本案辯論」
例2.
  • 乙行使拒絕辯論權，但法院就「管轄權」或「擔保金額」詢問乙意見時，乙仍應陳述（非屬本案辯論）。
  • → 拒絕辯論僅限於本案實體，程序事項仍應配合
供擔保之金額與期間
  • 命原告供擔保的裁定要寫明金額和期限；金額要算到可能上訴到三審的全部費用總額。
法院命原告供擔保者，應於「裁定」中定「擔保金額」及「供擔保期間」
  • 擔保金額：如「新臺幣50萬元」
  • 供擔保期間：原告應於「幾日內」提供擔保（如「應於收受裁定後10日內」）。
定擔保額，以「被告」於「各審」應支出之「費用總額」為準
  • 各審：指「第一審」及可能之「第二審」、「第三審」訴訟程序。
  • 費用總額：法院應「預估」各審級可能發生之費用總額，並以此為擔保額。
例1.
  • 甲起訴請求乙給付1,000萬元，預估第一審裁判費約10萬元、鑑定費20萬元；第二審裁判費約15萬元、律師酬金10萬元；第三審裁判費約10萬元、律師酬金10萬元。
  • 法院裁定：「甲應於收受本裁定送達後10日內，提供訴訟費用擔保金新臺幣75萬元。」
  • → 裁定載明金額與期間，擔保額以被告於各審應支出之費用總額為準
命供擔保裁定之抗告
  • 對於法院「命原告提供擔保」或「駁回被告聲請」的裁定，當事人不服可以在10天內提起抗告。
關於聲請命供擔保之裁定，得為抗告
  • 聲請命供擔保之裁定：包括：
    • 准許被告聲請，命原告供擔保之裁定。
    • 駁回被告聲請，認原告毋庸供擔保之裁定。
    • 核定擔保額及期間之裁定。
    • 命補足擔保之裁定。
  • 得為抗告：對法院之「裁定」，向上級法院聲明不服。
    • 抗告期間：10日。
    • 抗告法院：原則上為原裁定法院之直接上級法院。
例1.
  • 法院裁定甲（原告）應供擔保50萬元。甲認為擔保額過高，於送達後10日內提起抗告。
  • 抗告法院審查後，認原裁定之擔保額計算有誤，廢棄原裁定，發回原法院更為裁定。
  • → 聲請命供擔保之裁定，得為抗告
