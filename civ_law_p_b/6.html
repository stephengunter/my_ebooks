民事訴訟法 督促程序

督促程序

督促程序之聲請要件與科技化辦理
  • 如果你的請求是「給付一定數量的錢、米、股票」，你可以不告一般訴訟，而是向法院聲請支付命令——
    • 快、便宜、不用開庭；債務人20天內不抗議，就可以直接強制執行。
債權人之請求，以「給付金錢」或其他代替物或有價證券之「一定數量」為標的者
  • 債權人：主張自己有權利請求對造給付的人（即聲請人）。不以「已有確定判決」為前提，只要有實體法上的請求權即可。
  • 請求：民事上的權利主張，包括契約、侵權、不當得利、無因管理等各種請求權。
  • 一定數量：必須具體特定，例如「新臺幣100萬元」、「50噸白米」、「台積電股票1000股」。若請求「返還土地」（特定物）或「為一定行為」（如道歉），不得聲請支付命令。
得「聲請」法院依督促程序發「支付命令」
  • 得：債權人之選擇權，可選督促程序，也可選一般訴訟程序。
  • 聲請法院：原則上向「債務人住所地」或「約定履行地」的地方法院聲請（第510條）。
  • 支付命令：法院核發的書面命令，命債務人於20日內向債權人清償，或提出異議。
支付命令之聲請與處理，得以電子傳輸為之。其辦法，由司法院定之
  • 例如：債權人透過司法院「電子訴訟文書（含書狀傳送）平台」上傳聲請狀及證據；法院以電子方式核發支付命令；債務人以電子方式提出異議。
例1.
  • 甲借給乙100萬元，約定還款日屆至乙未還。
  • 甲向法院聲請支付命令，請求乙給付100萬元及利息。
  • → 請求標的為「金錢」一定數量，得聲請支付命令
例2.
  • 甲向乙買一幅特定名畫，乙未交付。
  • 甲向法院聲請支付命令，請求乙交付該名畫。
  • → 請求標的為「特定物」（非代替物），不得聲請支付命令，應提起一般訴訟
督促程序之限制（不得聲請支付命令之情形）
  • 如果你自己還沒履行應盡的義務、或債務人住在外國、或債務人住址不明要用登報公告送達—— 這三種情況都不能聲請支付命令，只能去打一般官司。
聲請人「應為對待給付」尚未履行：不得聲請
  • 對待給付：指雙務契約中，債權人自己也有應先為或同時履行的義務。例如：買賣契約中，買受人（債權人）請求交付買賣標的物，但買受人自己還沒付錢（對待給付未履行）。
  • 尚未履行：債權人還沒做他該做的事，或還沒提出給付。
支付命令應「送達於外國」：不得聲請
  • 應送達於外國：債務人的住居所、事務所或營業所在外國（依戶籍、公司登記等判斷），支付命令必須透過外交部送達或囑託外國管轄機關送達。
  • 立法理由：外國送達耗時長且不確定性高，將嚴重延滯督促程序；且外國債務人可能不了解我國支付命令的異議制度，容易喪失權益。應由債權人提起一般訴訟（由法院審理實體爭議，且送達依司法互助協定辦理）。
支付命令應「公示送達」者：不得聲請
  • 公示送達：指債務人「住居所不明」或「應為送達之處所不明」，法院依聲請或職權將文書公告於法院牌示處或網站（民事訴訟法第149條以下）。
  • 立法理由：公示送達是對「真正不知去向」的人為最後手段，債務人實際上極有可能未收到支付命令。若允許以公示送達核發支付命令，債務人可能在不知情下被確定，嚴重侵害其防禦權（過去曾被詐騙集團濫用）。因此，一律禁止。
例1.
  • 甲向乙訂購100台電腦，約定「先付款後交貨」。
  • 甲尚未付款，卻向法院聲請支付命令，請求乙交付100台電腦。
  • 甲應為對待給付（付款）尚未履行，不得聲請支付命令。法院應駁回。
  • → 聲請人「應為對待給付」尚未履行：不得聲請
例2.
  • 同上例，甲已付清貨款，但乙未交貨。
  • 甲聲請支付命令請求乙交付100台電腦。
  • 甲已履行對待給付，得聲請支付命令。
支付命令之專屬管轄
  • 支付命令只能去向「債務人住所地、公司地、營業所地」的法院聲請，這是專屬管轄，跑錯法院直接駁回，不能轉、不能換。
支付命令之聲請，專屬……法院管轄
  • 專屬：強制性管轄規定，當事人不得以合意變更管轄法院（不能約定「即使債務人住高雄，雙方合意向台北地院聲請」）。法院若發現無管轄權，應依職權裁定駁回。
債務人為被告時，普通審判籍、法人審判籍管轄權法院
  • 普通審判籍：自然人被告，由「住所地」法院管轄。無住所者，由「居所地」管轄；在國內無住所或居所者，由「最後住所地」管轄。
  • 法人審判籍：法人或其他團體（如公司、工會、社區管委會），由「主事務所或主營業所」所在地法院管轄。
  • 業務或營業所：債務是因該業務而發生，得由「業務或營業所所在地」法院管轄。
例1.
  • 甲住在新北市板橋區，乙住在台北市大安區。
  • 乙向甲借款100萬元未還。甲要聲請支付命令，應向債務人住所地法院聲請。
例2.
  • 戊公司總公司在台北，但在高雄設有營業所。
  • 己與高雄營業所簽約，產生債務。
  • 己要聲請支付命令，可選擇「臺灣高雄地方法院」（第6條）， 亦可選擇「臺灣臺北地方法院」（第2條，總公司所在地）。
  • 二者均屬有管轄權，己可擇一聲請（專屬管轄僅限制「不能選其他不相關法院」， 但仍有數個有管轄權法院時，債權人可選擇其一）。
支付命令聲請之程式
  • 聲請支付命令要寫明雙方身分、請求內容、原因事實（有對待給付要寫已履行）、請法院發命令、 向哪個法院聲請，而且必須附上證據（釋明請求是真的）。
支付命令之聲請，應表明下列事項：
  1. 當事人及法定代理人
  2. 請求之標的及其數量
  3. 請求之原因事實。其有對待給付者，已履行之情形
    • 如「債務人於110年1月1日向債權人借款100萬元，約定110年12月31日還款，屆期未還」
    • 如：「債權人已於110年1月1日交付貨物，債務人迄今未付貨款。」
  4. 應發支付命令之陳述
    • 例如：「為此，依民事訴訟法第508條規定，聲請對債務人發支付命令。」此為格式上的例行記載。
  5. 法院
支付命令聲請之書面審查原則
  • 法院審查支付命令聲請時，只能看書面資料，不能開庭問債務人意見，以維持督促程序的快速。
法院應「不訊問債務人」，就支付命令之聲請為裁定
  • 不訊問債務人：包括不開庭、不行言詞辯論、不發函命債務人表示意見。法院僅能書面審查。
  • 例外：若法院認為有必要（例如聲請狀明顯矛盾），可依職權「訊問債權人」以釐清事實（但實務上極少為之），但絕對不能訊問債務人。
  • 法院審查後，應以「裁定」形式（而非判決）決定准駁。
例1.
  • 甲聲請對乙支付命令，並檢附借據、匯款單。
  • 法院未通知乙到庭，逕依書面審查後，認為聲請合法，即核發支付命令。
  • → 法院不訊問債務人
例2.
  • 甲聲請支付命令，檢附之證據模糊不清（如手寫借據難以辨識）。
  • 法院為釐清事實，通知甲到庭說明（訊問債權人）。
  • → 法院僅「不得訊問債務人」，訊問債權人並不禁止
支付命令聲請之駁回
  • 支付命令聲請若不符合法定要件（或一看就知道沒理由），法院必須裁定駁回，且債權人不能抗告。
  • 若只有一部分不合，就只駁回那部分。
支付命令之聲請，「不合規定」者，法院應以「裁定駁回」之
  • 不合規定：指違反程序要件，包括：有對待給付未履行、須外國送達、須公示送達。
  • 只要不符合要件，法院「必須」駁回，無裁量空間。
支付命令之聲請，認債權人之「請求無理由」者，法院應以「裁定駁回」之
  • 請求為無理由：指縱使聲請狀所載事實為真，該請求在法律上亦顯然不能成立。例如：請求權已罹於時效、請求權所依據之法律關係不存在（如票據已因清償而消滅，但聲請狀已載明）。
就「請求之一部」不得發支付命令者，應「僅就該部分」之聲請駁回之
  • 請求之一部：若聲請包含數項獨立請求（例如本金100萬元＋違約金10萬元），僅其中一部分不合法（例如違約金金額不明確），則僅駁回該部分（違約金部分），其餘合法部分仍應核發支付命令。
  • 若請求為「不可分」者（例如單一金額），則全部駁回。
駁回裁定，不得抗告
  • 債權人對駁回裁定「不得抗告」。
  • 立法理由：督促程序講求快速，若允許抗告，將使程序延宕，失去簡速意義。
  • 債權人的救濟途徑：可重新提出「合法的聲請」（補正程式或管轄），或改提「一般訴訟」（起訴）。
例1.
  • 甲聲請支付命令，主張乙欠款100萬元，但未附任何借據或匯款單，法院以裁定駁回。
  • → 未釋明請求，駁回全部
例2.
  • 甲聲請支付命令，請求乙給付本金100萬元及違約金「若干元」（未具體載明違約金數額）。
  • 法院就本金部分准予核發，違約金部分以「未特定」為由駁回。
  • → 一部不合法，一部核發
支付命令之應記載事項
  • 支付命令必須寫明雙方身分、請求內容與原因、法院。並清楚告知債務人：20天內不還錢就異議，否則會被強制執行。
支付命令，應記載下列事項：
  1. 當事人及法定代理人
  2. 請求之標的及其數量
  3. 請求之原因事實
  4. 法院
  5. 債務人應向債權人清償其請求並賠償程序費用
  6. 如不清償，應於支付命令送達後「20日不變期間內」，向發命令之法院「提出異議」
    • 債務人若不付款，必須在20日內異議。異議應向核發支付命令的法院提出（非債權人）。
  7. 不異議後果：債權人「得聲請強制執行」
    • 明確告知債務人「不異議的後果」：支付命令確定，債權人可強制執行。
    • 確定證明書：支付命令確定後，法院會核發「支付命令確定證明書」給債權人。
    • 債權人持「支付命令正本」+「確定證明書」，即可向執行法院聲請強制執行。
例1.
  • 法院核發支付命令，本文記載：
    • 債權人：甲（住台北市），債務人：乙（住台中市）。
    • 債務人應給付債權人新臺幣100萬元，及自民國113年1月1日起至清償日止按年息5%計算之利息，並賠償程序費用新臺幣500元。
    • 如不服本命令，應於送達後20日內向本院提出異議。
    • 如逾期未異議，債權人得聲請強制執行。
    • 原因事實詳如附件（附甲之聲請狀影本）。
支付命令送達失效與失權效之補救
  • 支付命令三個月無法送達就失效。
  • 若法院誤發確定證明書，債權人收到撤銷通知後20天內起訴，起訴時間可回溯至聲請時，之前繳的費用也可轉為訴訟費。
發支付命令後，「三個月內不能送達」於債務人者，其「命令失其效力」
  • 不能送達：指法院依職權為送達（郵務送達、寄存送達、留置送達）均無法合法送達債務人（如債務人遷移不明、查無此人）。送達不合法之情形，包括：
    • 債務人住居所不明，無法投遞、應受送達處所查無此人。
  • 命令失其效力：支付命令「當然失效」，自始無效。債權人不得以此失效之支付命令聲請強制執行。
前項情形，法院誤發確定證明書者
  • 誤發確定證明書：法院在支付命令已失效之情況下，仍誤核發「支付命令確定證明書」予債權人（通常因行政疏失，未察覺送達不合法）。
補救：法院撤銷確定證明書 → 通知債權人 → 債權人20日內起訴 → 視為自支付命令聲請時，已經起訴
  • 債權人收到通知後「20天內」趕快去提告，法律上會把這個提告的時間「回溯」 到當初聲請支付命令的時候（這樣可以中斷時效，不怕超過時間）。
例1.
  • 法院於113年1月1日核發支付命令，經多次郵務送達均無法送達乙（乙已搬遷）。
  • 至113年4月1日（滿三個月），支付命令自動失效。甲不得持該支付命令聲請強制執行。
  • → 三個月未送達，支付命令失效
例2.
  • 同上例，法院因行政疏失，於113年4月15日誤發支付命令確定證明書（記載確定日期為113年2月1日）
  • 嗣後法院發現錯誤，於113年6月1日撤銷該確定證明書，並通知甲。
  • 甲於113年6月5日收到通知，於113年6月20日（20日內）對乙提起訴訟。
  • 甲之起訴視為自113年1月1日（聲請支付命令時）已經起訴，時效中斷回溯。
  • → 誤發確定證明書，法院通知債權人
債務人對支付命令之異議與撤回
  • 債務人收到支付命令後20天內，可以不用寫理由就向法院異議。
  • 異議後若改變主意，可在調解成立或一審辯論終結前撤回，但要負擔已產生的費用。
債務人對於支付命令之全部或一部，得於送達後「20日」不變期間內，「免附理由」向發命令之法院「提出異議」
  • 全部異議：對支付命令所載全部請求（含本金、利息、程序費用）均不服。
  • 一部異議：僅對部分請求不服（例如本金部分承認，但利息計算有誤）。可僅對該部分異議。
  • 「20日」不變期間內：不得延長。逾期異議，法院應以「異議不合法」裁定駁回（但實務上若債務人能證明非可歸責，可聲請回復原狀）。
  • 免附理由：債務人無須說明「為什麼異議」，只要表明「異議」即可（例如書狀僅寫「聲明異議」）。
  • 提出異議：提出「異議狀」（書面），載明案號、債務人姓名、聲明異議之意旨。
撤回異議：債務人得在「調解成立前」或第一審「言詞辯論終結前」，撤回異議。但應負擔調解程序費用或訴訟費用
  • 撤回後，異議視為自始未提出。
  • 債務人撤回異議後，須負擔已發生之調解費用或訴訟費用（例如調解程序費、裁判費等）。這是因為該程序是因債務人異議而啟動的，撤回後應由債務人承擔該費用。
例1.
  • 乙收到支付命令（請求100萬元），乙認為實際上只欠50萬元。
  • 乙於送達後第15天，向法院提出異議狀，僅載明「聲明異議」（未附理由）。
  • → 合法異議
例2.
  • 乙於送達後第25天才提出異議，且未聲請回復原狀。
  • 法院審查後，以「異議已逾20日不變期間」為由，裁定駁回異議。
  • → 逾期異議，駁回
例3.
  • 乙對支付命令異議後，案件進入調解程序。
  • 乙與甲在調解中達成協議，乙同意支付部分款項。
  • 乙於調解成立前，向法院撤回異議。撤回後，乙須負擔已發生之調解程序費用（例如調解聲請費）
  • → 撤回異議，負擔費用
支付命令逾期異議之駁回
  • 支付命令送達後超過20天才異議，法院會用裁定駁回（不接受），支付命令就會確定，債權人可以強制執行。
債務人逾二十日不變期間始提出異議者，法院應以裁定駁回之
  • 異議不合法，不生異議效力。支付命令已確定（若期間內無其他異議），債權人可聲請核發確定證明書並強制執行。
異議之效力（支付命令失效與視為起訴或調解）
  • 債務人20天內合法異議，支付命令失效，案件視為已起訴或聲請調解，之前繳的督促費用可轉為訴訟或調解費用。
債務人對於支付命令於法定期間合法提出異議者，支付命令「於異議範圍內失其效力」
  • 異議範圍內：若債務人對「全部」異議，支付命令「全部」失效。若僅對「一部」異議（例如僅對利息部分），則僅「利息部分」失效，本金部分仍確定。
  • 失其效力：支付命令不再具有執行名義之效力。債權人不得再以該支付命令聲請強制執行。
債權人支付命令之聲請，「視為起訴或聲請調解」
  • 視為：法律上之擬制，無須債權人另行起訴或聲請調解。
  • 起訴：若案件應行訴訟程序（如一般民事案件），則視為債權人已提起「本案訴訟」（起訴）。法院會將案件移由民事庭審理。
  • 聲請調解：若案件依法應先經調解（如家事事件、相鄰關係等），則視為債權人已聲請調解，法院會先進行調解程序。
前項情形，督促程序費用，作為訴訟費用或調解程序費用之一部
  • 督促程序費用：債權人聲請支付命令時繳納之裁判費（新臺幣500元）及送達費用。
  • 應作為訴訟費用或調解程序費用之一部：該筆費用併入本案訴訟或調解程序之費用中，由法院於終局判決或調解成立時，一併裁定由敗訴方負擔或由雙方分擔。債權人無須重複繳納（若訴訟費用高於500元，僅需補繳差額）。
例1.
  • 乙對支付命令（100萬元）全部不服，於20天內異議。
  • 支付命令全部失效，案件視為甲已起訴，進入訴訟程序。甲無須重新繳納裁判費（僅補繳差額）
  • → 全部異議，支付命令全部失效，進入訴訟程序
例2.
  • 支付命令命乙給付本金100萬元及利息10萬元。
  • 乙對「利息10萬元」部分異議（本金部分未異議）
  • 支付命令僅「利息部分」失效， 本金部分確定（乙未異議）。案件視為甲就「利息部分」起訴（或聲請調解）。
  • → 一部異議，支付命令一部失效
支付命令之確定效力與救濟
  • 債務人20天內未異議，支付命令確定，債權人可持支付命令及確定證明書強制執行。
  • 債務人事後可提起確認之訴並供擔保聲請停止執行。
債務人對於支付命令未於法定期間合法提出異議者
  • 未於法定期間：20日不變期間內未異議。
  • 合法提出異議：若債務人提出異議，但異議不合法（如逾期、非債務人提出），法院會駁回異議，支付命令仍確定（視同未異議）。
支付命令得為執行名義
  • 債權人可持支付命令，依強制執行法第4條第1項第6款，向執行法院聲請強制執行（如查封、扣押、拍賣債務人財產）。
  • 注意：支付命令確定後「僅有執行力」，無「既判力」（確定判決之既判力）。債務人仍可另訴爭執債權是否存在。
前項情形，為裁定之法院應付與裁定「確定證明書」
  • 為裁定之法院：原核發支付命令之法院。
  • 應付與：強制規定，法院應依職權或依聲請核發「支付命令確定證明書」。
  • 確定證明書：證明支付命令已確定（無合法異議）之公文書。債權人持支付命令正本＋確定證明書，始得聲請強制執行。
債務人主張支付命令上所載債權不存在，得「提起確認之訴」。起訴後得「聲請停止強制執行」
  • 債務人雖未異議，但認為債權不存在（例如已清償、契約無效、時效消滅等），可對債權人提起「確認債權不存在之訴」。
法院依債務人聲請，得許其提供相當並確實之「擔保」，停止強制執行
  • 得：法院裁量權。法院審酌債務人是否具有勝訴望、停止執行是否造成債權人難以彌補之損害等。
  • 相當並確實之擔保：債務人須提供擔保金（通常為請求金額之一定比例），以擔保債權人因停止執行所受之損害。
  • 停止強制執行：法院裁定停止執行後，執行程序暫停，待確認之訴確定後再決定是否繼續執行。
例1.
  • 乙未於20天內異議，支付命令確定。
  • 甲持支付命令正本及確定證明書，向執行法院聲請扣押乙之存款。
  • 乙主張該借款已清償，提起「確認債權不存在之訴」，並聲請停止執行。
  • 法院審查後，認乙有相當勝訴望，裁定乙供擔保50萬元後，停止執行。
  • → 債務人提起確認之訴並聲請停止執行
