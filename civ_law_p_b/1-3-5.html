民事訴訟法 訴訟救助

訴訟救助

訴訟救助之要件
  • 沒錢繳訴訟費用的人，可聲請訴訟救助（暫時免繳）；但若官司顯然會輸，就不會准許。
  • 法院判斷有無資力時，要考慮當事人和家人的基本生活開銷。
當事人「無資力」支出訴訟費用者，法院應依「聲請」，以「裁定」准予訴訟救助。但「顯無勝訴之望」者，不在此限
  • 無資力：指當事人之經濟狀況，在扣除「自己及共同生活親屬之基本生活費」後，仍不足以支付訴訟費用（裁判費、鑑定費、證人費等）。
  • 訴訟費用：不限於裁判費，尚包括證人日旅費、鑑定費、登報費等。
  • 依聲請：須由當事人主動聲請（法院不得依職權為之）。
  • 以裁定：法院應以「裁定」形式准駁。
  • 訴訟救助：准許後，當事人得「暫免」繳納訴訟費用（非「免除」），待訴訟終結後，若敗訴仍應補繳。
法院認定前項資力時，應斟酌當事人及其「共同生活親屬」基本生活之需要
  • 共同生活親屬：與當事人同住且共同生活之配偶、子女、父母等。
  • 基本生活之需要：指維持最低生活水準所必要之開銷（如房租、水電、伙食、醫療、交通等）。
  • 法院應綜合考量其「收入」、「財產」及「必要支出」，不得僅因當事人有「存款」即認非無資力。
例1.
  • 甲（月薪2萬元，須養2名子女，房租1萬元）起訴請求損害賠償，無力支付裁判費3萬元。
  • 甲聲請訴訟救助，提出收入證明及支出明細。法院審酌後認其無資力，裁定准許。
  • → 無資力，依「聲請」，以「裁定」准予救助
例2.
  • 甲對乙請求損害賠償，但甲之請求權已罹於15年時效，且無中斷事由。
  • 法院認顯無勝訴之望，駁回訴訟救助聲請。
  • → 「顯無勝訴之望」者，不在此限
外國人訴訟救助之互惠原則
  • 外國人要在台灣聲請訴訟救助，必須他的國家也對台灣人有相同的訴訟救助待遇（互惠）才行。
對於外國人准予訴訟救助
  • 外國人（非中華民國國民或未具有中華民國國籍者）在台灣提起民事訴訟，聲請訴訟救助。
以依條約、協定或其本國法令或慣例，中華民國人在其國得受訴訟救助者為限
  • 條約、協定：台灣與該國簽訂之司法互助條約或協定（如台美司法互助協定）。
  • 其本國法令或慣例：該外國人本國之「法律」或「實務慣例」，有明定或實質上准許中華民國人民在其國內獲得訴訟救助。
  • 中華民國人在其國得受訴訟救助者：須我國人民在該國亦能獲得訴訟救助（互惠）。
  • 為限：若無互惠，則不得准許（強制限制）。
例1.
  • 甲為A國人，在台提起訴訟並聲請訴訟救助。
  • 我國與A國簽有「司法互助協定」，明定雙方國民在對方國家得受訴訟救助。法院審查後認有互惠，裁定准許。
  • → 有互惠，准許
例2.
  • 甲為B國人，B國法律並未規定准許中華民國人民在其國內聲請訴訟救助，亦無相關條約或慣例。
  • 法院認無互惠，駁回甲之訴訟救助聲請。
  • → 無互惠，駁回
訴訟救助之聲請程序與釋明
  • 聲請訴訟救助要向本案法院提出，並釋明無資力；若無法釋明，可由有資力的第三人出具保證書代替。
聲請訴訟救助，應向受訴法院為之
  • 受訴法院：指「本案訴訟」已繫屬或將繫屬之法院（如第一審法院）。
    • 若已起訴：向該案之法院聲請。
    • 若尚未起訴：向將來起訴之法院聲請。
於訴訟「繫屬前」聲請者，並應「陳明」關於本案訴訟之聲明及其原因事實
  • 須於聲請狀中記載：
    • 訴訟標的：請求之法律關係。
    • 訴之聲明：具體請求內容（如「被告應給付原告新臺幣100萬元」）。
    • 原因事實：請求權發生之事實。
無資力支出訴訟費用之事由，應釋明之
  • 聲請人應提出「能即時調查之證據」，使法院「大致相信」其確無資力。
  • 釋明方法：低收入戶證明、綜合所得稅資料、存摺影本、財產清冊、房租契約等。
保證書代釋明：無資力之釋明，得由受訴法院管轄區域內「有資力」之人，出具「保證書」代之。保證書應載明「願為待繳」
  • 若聲請人無法提出直接證據，得由「第三人」出具保證書。
  • 該第三人須「在受訴法院管轄區域內有資力」（如不動產、存款）。
  • 保證書應載明「願為待繳」：保證書須明確載明：保證人願於聲請人敗訴確定應負擔訴訟費用時，代為繳納「暫免」之費用。
例1.
  • 甲已對乙起訴，案件由臺北地院審理。甲向臺北地院聲請訴訟救助，並提出低收入戶證明及存摺影本。
  • → 已起訴，向受訴法院聲請
例2.
  • 甲尚未起訴，但欲對乙提起訴訟。甲向臺北地院聲請訴訟救助，並於聲請狀中載明：「本案請求乙給付100萬元，因甲對乙有借款債權，乙屆期未還。」
  • → 起訴前，「陳明」訴訟之聲明及原因事實，向受訴法院聲請
例3.
  • 甲無法提出收入證明，但請丙（在台北市有房產）出具保證書，載明「丙願於甲應負擔訴訟費用時，代繳暫免之費用」。
  • 法院審查丙之資力後，准許訴訟救助。
  • → 「有資力」之人，出具「保證書」代無資力之釋明
訴訟救助聲請駁回確定前不得駁回起訴
  • 訴訟救助聲請，在駁回裁定確定前，法院不能因為原告還沒繳裁判費就駁回他的起訴。
「駁回」訴訟救助聲請之裁定「確定前」
  • 指法院已為「駁回訴訟救助」之裁定，但該裁定尚未「確定」（即仍在抗告期間內，或已提起抗告尚未終結）。
  • 若法院「准許」訴訟救助，則當然無本條適用（因原告已獲救助）。
第一審法院「不得」以原告未繳納裁判費為由駁回其訴
  • 第一審法院：指本案訴訟之第一審法院。
  • 不得：強制禁止規定
  • 以原告未繳納裁判費為由駁回其訴：法院不得以原告未繳納裁判費（起訴不合法）駁回起訴。
例1.
  • 甲起訴乙，同時聲請訴訟救助。法院裁定駁回訴訟救助（認甲有資力）。
  • 甲於10日抗告期間內提起抗告。在抗告程序終結前，法院不得以甲未繳裁判費為由駁回起訴。
  • → 訴訟救助駁回裁定尚未確定，不得以未繳裁判費為由駁回起訴
例2.
  • 甲之訴訟救助聲請經駁回，甲未於10日內抗告，駁回裁定確定。
  • 法院得定期命甲補繳裁判費；若逾期未繳，法院得裁定駁回起訴。
准予訴訟救助之效力
  • 准予訴訟救助後，可暫免繳裁判費等費用、免供擔保、暫免付律師費；暫免的費用由國庫先墊付。
准予訴訟救助，於訴訟終結前，有下列效力：
  1. 暫免裁判費及其他應預納之訴訟費用。由國庫墊付
    • 暫免：暫時免除繳納義務，非永久免除。
    • 其他應預納之訴訟費用：證人日旅費、鑑定費、通譯費、登報費、送達費等。
    • 由國庫墊付：墊付後，待訴訟終結，若受救助人敗訴，應「補繳」該費用。
  2. 免供訴訟費用之擔保
    • 免依第96條（原告在台無住所）提供擔保金。
  3. 審判長依法為受救助人選任律師代理訴訟時，暫行免付酬金
    • 例如：家事事件法或民事訴訟法第68條（強制律師代理）之情形。
    • 律師酬金由國庫暫墊，或由法院指定之律師暫不收取。
訴訟救助效力之擴張
  • 訴訟救助的效力，不僅在起訴時有用，在上訴、抗告、假扣押、假處分時也一樣適用，不用再重新聲請。
准予訴訟救助，於假扣押、假處分、上訴及抗告，亦有效力
  • 假扣押：保全金錢請求之程序。
  • 假處分：保全金錢以外請求之程序。
  • 上訴：對第一審或第二審判決不服，提起上訴（第二審或第三審）。
  • 抗告：對法院之裁定不服，提起抗告。
  • 亦有效力：受救助人於上開程序中，無須再聲請訴訟救助，即享有救助效力（暫免費用、免供擔保等）。
例1.
  • 甲獲准第一審訴訟救助，第一審判決甲敗訴。
  • 甲提起第二審上訴，無須重新聲請訴訟救助，即暫免繳納第二審裁判費
  • → 准予訴訟救助，於上訴亦有效力
例2.
  • 甲獲准訴訟救助，訴訟中甲為保全債權，聲請對乙假扣押。
  • 假扣押程序之裁判費亦暫免繳納，且免供擔保。
  • → 准予訴訟救助，於假扣押亦有效力
訴訟救助之消滅事由
  • 獲得訴訟救助的人如果死亡，訴訟救助的效力就消滅了，繼承人若想繼續享有，須重新聲請。
准予訴訟救助之效力，因受救助人死亡而消滅
  • 准予訴訟救助之效力：暫免裁判費、免供擔保、暫免律師酬金等效力。
  • 受救助人：獲得訴訟救助裁定之當事人。
  • 死亡：不論是訴訟中或訴訟終結前死亡。
  • 消滅：訴訟救助之效力自受救助人死亡時起，向後失效。其繼承人不得繼續享有該救助之利益。
例1.
  • 甲獲准訴訟救助，訴訟進行中甲死亡。
  • 訴訟救助之效力自甲死亡時消滅，甲之繼承人承受訴訟後，須重新聲請訴訟救助，否則應繳納後續訴訟費用。
  • → 受救助人死亡，救助效力消滅
例2.
  • 甲死亡後，其繼承人乙承受訴訟。乙向法院重新聲請訴訟救助，並釋明自己亦無資力。
  • 法院重新審查後，裁定准許乙之訴訟救助。
  • → 繼承人重新聲請救助
訴訟救助之撤銷與費用補交
  • 如果受救助人其實有錢或後來有錢了，法院應撤銷救助並命其補繳暫免的費用；裁定由案件現在所在的法院為之。
撤銷事由：有資力支付訴訟費用
  • 包括兩種情況：
    1. 聲請時即非無資力（如隱瞞財產）
    2. 聲請時無資力，但訴訟中資力改善（如繼承遺產、獲得薪資）
撤銷方式：由訴訟卷宗所在法院以「裁定」撤銷救助
  • 訴訟卷宗所在之法院：指該案「目前」繫屬之法院。
    • 若案件在第一審，由第一審法院裁定。若已上訴至第二審，由第二審法院裁定。
  • 撤銷救助：使訴訟救助之效力自始或自事由發生時失效。
撤銷效果：補交費用
  • 補繳「先前暫免」之全部費用（裁判費、鑑定費等）。
  • 補繳期限由法院於裁定中定之。
例1.
  • 甲聲請訴訟救助時隱瞞名下存款100萬元，獲准救助。
  • 事後法院發現，裁定撤銷救助，並命甲補繳已暫免之裁判費5萬元。
  • → 聲請時即有資力，訴訟卷宗所在法院以「裁定」撤銷救助
例2.
  • 甲獲准訴訟救助（無資力），訴訟中甲繼承遺產1,000萬元，資力顯著改善。
  • 法院依職權裁定撤銷救助，並命甲補繳鑑定費3萬元。
  • → 訴訟中資力改善（有資力），訴訟卷宗所在法院以「裁定」撤銷救助
訴訟救助後訴訟費用之徵收與律師酬金之國庫墊付
  • 訴訟結束後，法院會主動計算全部費用並向應負擔者徵收；若受救助人應負擔卻無力支付，可向保證人執行。
    • 受救助而應負擔之人，如果是「兒童或少年」，且這筆錢會對他的生活造成「重大影響」，他可以聲請法院裁定「減輕」或「免除」這筆費用。
  • 法院選任的律師酬金若徵收不到，由國庫墊付。
訴訟終結後，第一審法院應主動計算全部費用，並向應負擔者徵收
  • 訴訟終結：包括判決確定、撤回起訴、和解成立等。
  • 第一審法院須主動（依職權，無待聲請）以裁定確定費用額。
  • 向應負擔者徵收：若敗訴方為「受救助人」，則向其徵收暫免之費用。
    • 若敗訴方為「他造」（非受救助人），則向他造徵收。
若受救助人應負擔卻無力支付，可向保證人執行
  • 保證人：出具保證書之第三人。若受救助人無力支付，法院得對保證人強制執行（保證書具執行名義）。
受救助人而應負擔之人，若為「兒童或少年」而「負擔致影響生計」者，得「聲請減輕或免除」
  • 受救助人而應負擔之人：法院依職權確定訴訟費用額，向應負擔費用之當事人徵收之情形。
  • 兒童：未滿12歲之人。
  • 少年：12歲以上未滿18歲之人。
  • 負擔致影響生計：該費用之徵收，將使兒童或少年之「基本生活」受到嚴重影響（如無法負擔教育、醫療、生活開銷）。
  • 聲請減輕或免除：「3個月內」向「確定訴訟費用額裁定之法院」提出聲請。法院可「酌減」或「全額免除」應負擔之費用。
    • 若聲請顯無理由，法院得駁回。
法院選任律師之酬金若徵收不到，由國庫墊付
  • 法院選任律師：法院依法為受救助人選任律師。
  • 徵收不到：對受救助人強制執行無結果（如無財產）。
  • 由國庫墊付：該律師酬金由國家支付（非由受救助人負擔）。
例1.
  • 甲獲准訴訟救助，但終局判決甲敗訴（應負擔訴訟費用）。
  • 法院依職權確定費用額（共10萬元），命甲補繳暫免之費用。
  • → 受救助人敗訴，徵收暫免費用
例2.
  • 甲無力支付，法院對保證人丙強制執行10萬元（依保證書）。
  • → 向保證書人執行
例3.
  • 法院為甲選任律師，酬金5萬元。徵收無效果（甲無財產），該酬金由國庫墊付。
  • → 法院選任律師之酬金若徵收不到，由國庫墊付
例4.
  • 甲（15歲，學生）獲准訴訟救助，但敗訴確定，應負擔訴訟費用10萬元。甲無收入，該費用將使其無法繼續就學及維持基本生活。
  • 甲於費用額裁定確定後2個月內，聲請法院減免費用。法院審查後，認負擔確有重大影響，裁定「免除」該費用。
  • → 受救助人而應負擔之人，為「兒童或少年」而「負擔致影響生計」者，得「聲請減輕或免除」
訴訟救助相關裁定得抗告
  • 訴訟救助程序中的所有裁定（例如准駁、撤銷、確定費用額等），當事人不服都可以在10天內提起抗告。
訴訟救助相關裁定，得抗告
  • 訴訟救助相關裁定，包括：
    1. 准予或駁回訴訟救助之裁定。
    2. 撤銷訴訟救助之裁定。
    3. 確定訴訟費用額之裁定。
    4. 減輕或免除訴訟費用之裁定。
  • 得抗告：10日（自裁定送達翌日起算）內向上級法院聲明不服。
例1.
  • 甲聲請訴訟救助遭法院駁回，甲於送達後10日內提起抗告。
例2.
  • 甲獲准訴訟救助（無資力），訴訟中甲繼承遺產1,000萬元，資力顯著改善。
  • 法院認甲已資力改善，裁定撤銷訴訟救助並命補繳費用。甲不服，提起抗告。
