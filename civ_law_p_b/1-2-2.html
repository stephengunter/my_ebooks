民事訴訟法 共同訴訟

共同訴訟

共同訴訟之要件
  • 二人以上可以在下列情況下一起告人或一起被告：
    • 他們的權利義務是共同的（例如共同繼承人）。
    • 他們的權利義務來自於同一件事（例如同一場車禍）。
    • 他們的權利義務是同一種類且來自於同種類的原因（例如同一建案的住戶），但這種情況必須被告住在同一法院轄區或有共同管轄法院。
二人以上於下列各款情形，得為共同訴訟人，一同起訴或一同被訴
  • 一同起訴：一起當原告 。
  • 一同被訴：一起當被告 。
1.「權利義務」共同
  • 訴訟標的的權利或義務，是「多數人共同享有或共同負擔」的。例如：公同共有（遺產）、連帶債權、連帶債務。
  • 典型例子：
    • 遺產分割：全體繼承人（公同共有人）必須一同起訴或一同被訴。
    • 合夥財產：合夥人對合夥財產有公同共有權。
    • 連帶債務：債權人對數個連帶債務人可以共同起訴。
2.同一「事實上」、「法律上」原因
  • 同一事實上原因：例如「同一場車禍」、「同一件商品瑕疵」、「同一棟大樓倒塌」、「同一次股東會決議」。
  • 同一法律上原因：例如都是基於「侵權行為」、都是基於「債務不履行」、都是基於「同一份契約」。
  • 典型例子：
    • 同一車禍：甲、乙、丙三人都被丁開車撞傷，三人各自對丁有損害賠償請求權（不是共同債權），但都是基於「同一場車禍」（同一事實）及「侵權行為」（同一法律原因）。三人可以共同起訴丁。
    • 同一商品瑕疵：數十位消費者購買了同一批有瑕疵的電器（同一事實），基於買賣契約（同一法律原因）請求退貨還款。
3.「同種類」權利義務、「同種類」事實上法律上原因。但以「共同管轄法院」為限
  • 典型例子：
    • 同一個建商的不同建案：建商在A地蓋了10戶，在B地蓋了20戶，都偷工減料。A地的10戶住戶可以共同起訴（因為同種類原因：都是買A地房子），但A地住戶不能與B地住戶共同起訴。
    • 同一個銀行的不同分行：數十位存款人分別在不同分行與銀行簽訂定存契約，銀行倒閉，存款人可以共同起訴（因為都是「存款契約」，同種類原因）。
例1.
  • 甲、乙、丙三人共同繼承父親留下的一筆土地（公同共有）。丁無權占用該土地。
  • 甲、乙、丙三人可以「共同起訴」丁，請求返還土地。
  • → 「權利義務」共同，得為共同訴訟人
例2.
  • 甲、乙、丙三人騎機車，被丁開車撞傷。
  • 三人各自對丁有損害賠償請求權，但都是基於「同一場車禍」及「侵權行為」。三人可以共同起訴丁。
  • → 同一「事實上」、「法律上」原因，得為共同訴訟人
例3.
  • 甲、乙、丙三人分別在台北、台中、高雄向「ＯＯ電信公司」申辦手機門號（分別簽約），後來電信公司擅自調漲費率。三人想要共同起訴電信公司 。
  • 被告是同一個（電信公司），被告的住所在台北（公司所在地）。依但書，被告住所（台北）在同一法院轄區內，所以三人可以共同向台北地院起訴。
  • → 同種類原因，有共同管轄法院，得為共同訴訟人
主參加訴訟
  • 當別人之間正在打官司，如果你（第三人）認為他們爭執的權利是你的，或他們的官司結果會侵害你的權利：
    • 你可以在第一審或第二審的時候，以他們兩人為共同被告，向同一個法院提起一個新的訴訟（主參加訴訟），一次解決三方的紛爭。
就「他人」間之訴訟，有下列情形之一者：
  1. 對其「訴訟標的」全部或一部，為自己「有所請求」者
    • 他們在爭的那個權利（全部或一部分）是你的。
    • 例如甲和乙在爭一塊地，你跳出來說：「那塊地是我的！」
  2. 其訴訟之結果，自己「權利將被侵害」者
    • 例如甲告乙拆屋還地，你是承租戶，房子被拆你的租賃權就沒了。
得於第一審或第二審「本訴訟繫屬中」，以其當事人「兩造為共同被告」，向本訴訟繫屬之法院起訴
  • 第一審或第二審：不包括第三審（因為第三審是法律審，原則上不允許新的訴訟加入）。
  • 本訴訟繫屬中：從起訴後到判決確定前（包括上訴審）。如果本訴訟已經判決確定，就不能再提起主參加訴訟（必須另行起訴）。
  • 以其當事人「兩造為共同被告」：把本訴訟的原告和被告（例如甲和乙）一起列為共同被告。第三人自己當原告。
  • 向本訴訟繫屬之法院起訴：向原訴訟的那個法院起訴（不能去別的法院）。這是「牽連管轄」的表現。
例1.
  • 甲向法院起訴乙，主張乙無權占用甲的土地，請求乙拆屋還地（本訴訟）。丙突然跳出來說：「這塊地是我的！甲根本沒有所有權！」
  • 丙可以在同一個法院，以「甲和乙」為共同被告，提起主參加訴訟，請求確認土地為丙所有，並請求甲、乙返還土地。
  • → 對「他人」間之「訴訟標的」全部或一部，為自己「有所請求」者，得以其「兩造為共同被告」，向本訴訟繫屬之法院起訴
例2.
  • 甲向法院起訴乙，請求拆屋還地（本訴訟）。丙是乙房屋的「承租人」（租約還有5年）。如果乙敗訴拆屋，丙的租賃權就會消滅。
  • 丙可以在同一個法院，以甲、乙為共同被告，提起主參加訴訟，主張：「我的租賃權存在，甲不得請求拆屋，或甲應賠償我的損失。」。
  • → 對「他人」間之訴訟結果，自己「權利將被侵害」者，得以其「兩造為共同被告」，向本訴訟繫屬之法院起訴
共同訴訟各自獨立原則
    在共同訴訟中（尤其是普通共同訴訟）：
  • 其中一個共同訴訟人做的事（例如上訴、撤回、和解），或對方對他做的事，或他個人發生的事（例如死亡）：
    • 原則上「只對他自己有效」，不會影響到其他共同訴訟人。
共同訴訟中，「一人之行為」或他造對於其中一人之行為或「一人所生之事項」，除別有規定外，其「利害不及於其他」共同訴訟人
  • 共同訴訟中：指普通共同訴訟。「必要共同訴訟」屬於「別有規定」之例外。
  • 「一人之行為」：其中一位共同訴訟人（例如共同原告中的甲，或共同被告中的乙）所做的「訴訟行為」。
  • 他造對於其中一人之行為：例如原告只對共同被告中的甲為「認諾」（承認甲的請求），或原告只對甲「撤回起訴」，或原告只對甲為「訴訟上和解」。
  • 「一人所生之事項」：共同訴訟人中一人死亡或受破產宣告。
  • 「除別有規定外」：例如必要共同訴訟：一人行為，效力及於全體。
  • 「利害不及於其他」共同訴訟人：該行為或事項所產生的法律效果（例如勝訴、敗訴、訴訟停止、訴訟終結）不會影響到其他共同訴訟人。
例1.
  • 甲、乙、丙三人被丁開車撞傷，共同起訴丁請求賠償。一審判決：丁應賠償甲10萬、乙5萬、丙3萬。
  • 甲覺得賠太少，提起上訴；乙覺得合理，不上訴；丙也覺得合理，不上訴。
  • 甲的上訴行為「不及於」乙、丙。乙、丙部分判決確定，甲的部分繼續上訴。
  • → 一人上訴，效力不及於其他人
例2.
  • 甲、乙、丙共同被告（連帶保證人），甲對原告「認諾」（承認原告的請求）
  • 甲的認諾效力不及於乙、丙。法院不能因為甲認諾，就直接判乙、丙敗訴。
  • → 一人認諾，效力不及於其他人
例3.
  • 甲、乙、丙共同原告，訴訟中甲死亡。
  • 甲的部分訴訟當然停止（等待繼承人承受），但乙、丙的部分繼續進行，不受影響 。
  • → 一人死亡，訴訟停止只及於該人
必要共同訴訟之特別規定
  • 在必要共同訴訟（例如共同繼承人告人）中，大家都是「生命共同體」：
    • 一個人做「有利」的行為（如上訴），全體一起受惠。
    • 做「不利」的行為（如撤回），無效。
    • 對方做任何行為，全體一起受影響。
    • 一個人發生停止原因（如死亡），全體一起停。
「必要共同訴訟」：訴訟標的對於共同訴訟人必須「合一確定」
  • 也就是法院的判決必須對全體共同訴訟人「一致」（不能對甲勝訴、對乙敗訴）。
  • 典型的必要共同訴訟包括：
    • 公同共有物訴訟（如遺產、合夥財產）。
    • 分割共有物訴訟（全體共有人必須一同起訴或被訴）。
    • 撤銷股東會決議之訴（股東會決議對全體股東有效，必須合一確定）。
「必要共同訴訟」適用下列規定：
  1. 一人之行為「有利於全體」者，其「效力及於全體」；「不利益者」，對於全體「不生效力」
    • 「有利於全體」者，其「效力及於全體」：例如提起上訴，可能讓全體獲得更好結果 → 一人上訴，視同全體一起上訴。
    • 「不利益者」，對於全體「不生效力」：例如撤回起訴 → 一人撤回起訴，不生撤回效力，訴訟繼續進行（該行為無效，等於沒做）。
  2. 他造「對其中一人」之行為，其效力「及於全體」
    • 例如被告只對共同原告中的一人為「認諾」（承認其請求）→ 視同對全體原告認諾。
  3. 一人有「停止原因」者，停止效力「及於全體」
    • 只要共同訴訟人中「一人」發生停止原因，全體共同訴訟人的訴訟程序都「當然停止」或「裁定停止」。
    • 例如共同訴訟人中一人死亡，停止效力「及於全體」。
例1.
  • 甲、乙、丙三人共同繼承一筆土地（公同共有），被丁無權占用。三人共同起訴丁請求返還土地。
  • 一審判決甲、乙、丙敗訴。甲一人提起上訴（對全體有利，因為有機會翻盤）。
  • 甲的上訴「效力及於全體」，視同乙、丙也一起上訴。
  • → 有利行為「效力及於全體」
例2.
  • 承上例，訴訟中，甲覺得證據不足，想要「撤回起訴」。
  • 撤回起訴對全體「不利益」（會讓全體敗訴），所以甲的撤回「對全體不生效力」（無效）。訴訟繼續進行。
  • → 一人行為「不利益者」，對於全體「不生效力」
例3.
  • 甲、乙、丙三人為必要共同訴訟人（共同繼承）。
  • 一審敗訴，甲提起上訴。乙是受輔助宣告人（需要輔助人同意）。
  • 乙「無須」經輔助人同意，就視同上訴。不會因為輔助人不同意而卡住。
  • → 上訴（有利行為）效力及於乙，乙（受輔助宣告人）不需要輔助人的同意，就可以視同上訴
必要共同訴訟強制追加原告
在「必要共同訴訟」（訴訟標的必須合一確定）中：
  • 如果依法應該「共同起訴」的人（例如全體繼承人），有其中一個人或幾個人「拒絕」一起當原告，而且「沒有正當理由」時：
    • 原告可以請求法院強制把那個「不願意告的人」也拉進來當原告。
    • 如果他還是不願意，法律上就「視為」他已經同意一起告了。
案件類型：「必要共同訴訟」案件，而應「共同起訴」
  • 「必要共同訴訟」： 訴訟標的對於數人「必須合一確定」，依法「應共同起訴」（固有必要共同訴訟）。
    • 例如：公同共有物（遺產）的權利行使、分割共有物、撤銷股東會決議等。
適用情況：其中一人或數人「拒絕同為原告」，而無正當理由者
  • 應該一起告的人，不願意在起訴狀上簽名、不願意被列為原告。
  • 無正當理由：例如：怕麻煩、與被告關係好、覺得訴訟無益、故意阻撓等。
發動方式：依原告聲請，以「裁定」命「限期追加」為原告。裁定前，應給予「陳述意見」之機會
  • 法院會訂一個期限（例如7天、10天、14天），讓該未起訴之人追加為原告。
  • 應給予「陳述意見」之機會：法院要通知該未起訴之人，讓他有機會說明「為什麼拒絕當原告」。例如：寄一份通知給他，問他「你有沒有正當理由？」
「逾期未追加」者，「視為已一同起訴」
  • 逾期未追加：該未起訴之人在期限內沒有表示要追加（也沒有提出正當理由）。
  • 視為已一同起訴：法律擬制「他已經同意當原告了」。從此時起，他就是共同原告，不需要他簽名。法院可以將他列為原告進行審理。
未起訴之人「所在不明」者，得依聲請，以「裁定」列為原告。但該原告於第一次言詞辯論期日前陳明拒絕為原告之理由，經法院認為正當者，得撤銷原裁定
  • 所在不明：例如失蹤、惡意躲藏
  • 得依聲請，以「裁定」列為原告：原告向法院聲請追加該人為原告，法院認為聲請為正當，可以直接裁定「把這個人列為原告」，不需要先命其追加（因為找不到人，無法命其追加）
  • 但是，如果他後來在第一次開庭之前出現，向法院說明「我有正當理由拒絕當原告」，法院認為理由正當的話，可以撤銷原來的裁定。
追加裁定「得抗告」
  • 命追加原告的裁定（或駁回聲請的裁定），當事人（包括原起訴的原告、被追加的人）可以對這些裁定提起抗告（10日內）。
訴訟費用應由原告負擔者，法院得酌量情形，命僅由原起訴之原告負擔
  • 如本案判決原告敗訴，訴訟費用由原告負擔，法院可以裁定「只由原本願意起訴的那個原告」負擔訴訟費用，被強制追加進來的原告「不用負擔」。
例1.
  • 父親去世，留下土地一塊，由甲、乙、丙三人共同繼承（公同共有）
  • 丁無權占用該土地。甲、乙想要告丁返還土地，但丙認為「丁是好人，不要告他」，拒絕共同起訴
  • 甲、乙向法院起訴（僅列甲、乙為原告），並聲請追加丙為原告
  • 法院通知丙陳述意見，丙說：「我就是不想告。」法院認為「不想告」不是正當理由，裁定命丙於10日內追加為原告
  • 丙逾期未追加，法院「視為丙已一同起訴」。法院將丙列為原告，繼續審理
  • → 依原告聲請，以「裁定」命「限期追加」為原告
  • → 「逾期未追加」者，「視為已一同起訴」
例2.
  • 承例1，丙在父親去世後就離家出走，所在不明。甲、乙向法院起訴，並聲請追加丙為原告
  • 法院審查後認為丙應該共同起訴，直接裁定「將丙列為原告」。法院公示送達等方式通知丙
  • 丙在第一次開庭前出現，向法院陳明：「我不想起訴，因為我跟丁有約定。」法院認為理由正當，撤銷原裁定
  • → 未共同起訴之人「所在不明」，經原告聲請命為追加，法院認其聲請為正當者，得以裁定將該未起訴之人列為原告
  • → 該原告於第一次言詞辯論期日前陳明拒絕為原告之理由，經法院認為正當者，得撤銷原裁定
共同訴訟人各有續行訴訟之權
  • 在共同訴訟中，每個人都是「獨立」的訴訟主體，都可以自己推動訴訟進度。
  • 法院也不能只通知其中一個人，必須通知所有人。
共同訴訟人，各有續行訴訟之權
  • 共同訴訟人：包括共同原告、共同被告。不論是普通共同訴訟還是必要共同訴訟，都適用。
  • 各有：每一位、各自獨立的。不需要共同行使，也不需要得到其他人的同意。
  • 續行訴訟之權：指「繼續進行訴訟程序」的權限。包括：聲請調查證據、提出書狀、抗告。
法院指定期日，應通知各共同訴訟人到場
  • 法院指定期日：例如開庭期日（言詞辯論期日）、調解期日、準備程序期日、證據調查期日。
  • 應通知：法院的「義務」，不是裁量。不能只通知其中一人。
  • 各共同訴訟人：每一位共同訴訟人。包括共同原告、共同被告、以及（如果有的話）訴訟參加人。
例1.
  • 甲、乙、丙三人共同起訴丁，請求損害賠償。
  • 乙、丙消極不出庭、不寫狀子。甲自己向法院聲請傳喚證人。
  • 甲「有續行訴訟之權」，可以自己聲請，不需要乙、丙的同意或簽名。
  • → 共同訴訟人，各有續行訴訟之權
例2.
  • 甲、乙、丙三人共同起訴丁。法院指定言詞辯論期日，只寄通知給甲，沒有寄給乙、丙。乙、丙未收到通知，沒有出庭。
  • 法院在乙、丙缺席的情況下進行辯論並判決。法院「應通知各共同訴訟人」，只通知甲是違法的。
  • 乙、丙可以主張判決違背法令，提起上訴。
  • → 法院指定期日，應通知各共同訴訟人到場
