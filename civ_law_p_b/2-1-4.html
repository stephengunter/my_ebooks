民事訴訟法 和解

和解

試行和解與第三人參加
  • 法院在訴訟任何階段都可以試行和解；受命法官也可以；第三人經許可或法院通知也可參加和解。
法院不問訴訟程度如何，得隨時試行和解。受命法官或受託法官亦得為之
第三人經「法院許可」，得「參加和解」
  • 第三人：如連帶債務人、保證人。
  • 經法院許可：法院得准許其參加。
法院認為必要時，亦得「通知第三人參加和解」
例1.
  • 受命法官於準備程序中試行和解。
  • → 受命法官試行和解。
例2.
  • 法院認有必要，通知連帶債務人參加和解。
  • → 法院通知第三人參加和解。
定和解方案之聲請與效力
  • 雙方和解意思接近時，可共同聲請法院於一定範圍內定和解方案。
  • 法院依衡平原則定方案，告知或送達雙方時，視為和解成立。
當事人和解意思「已甚接近」者
  • 雙方已快要達成和解。
兩造得「聲請」法院、受命法官或受託法官「於當事人表明之範圍內，定和解方案」
  • 兩造得聲請：兩造共同聲請。
  • 於當事人表明之範圍內：當事人自行劃定範圍（如金額上下限）。
前項聲請，應「以書狀表明」法院得定和解方案之「範圍」及「願遵守」所定之和解方案
  • 應：強制規定。
  • 表明範圍：如「100萬元至150萬元之間」。
  • 願遵守：表明願意接受法院所定方案。 %，被告勝訴50%，法院命各自負擔。
法院、受命法官或受託法官依第一項定和解方案時，應斟酌一切情形，依衡平法理為之
  • 斟酌一切情形：考量雙方利益、紛爭解決等。
  • 依衡平法理：不嚴格依法，而依公平合理原則。
並應將所定「和解方案」，於期日「告知當事人，記明筆錄」，或將和解方案送達之
  • 告知：於期日當面告知，記明筆錄。
  • 送達：將方案送達當事人。
當事人已受前項告知或送達者，「不得撤回」定和解方案之聲請
  • 一旦收到告知或送達，即不得撤回聲請。
兩造當事人於受和解方案之告知或送達時，「視為和解成立」
  • 視為和解成立：法律擬制和解成立（無須再簽名）。
參加和解之第三人，亦得與兩造為定和解方案之聲請，並適用前四項之規定
  • 第三人亦得參與聲請，並適用本條規定。
例1.
  • 甲、乙和解意思已接近，共同聲請法院於「100萬至150萬」範圍內定方案。
  • 法院定方案為120萬元，告知雙方，雙方視為和解成立。
  • → 兩造當事人於受和解方案之告知或送達時，「視為和解成立」
例2.
  • 保證人丙參加和解，並與兩造共同聲請定方案。
  • → 參加和解之第三人，亦得與兩造為定和解方案之聲請
一造到場有困難之和解方案
  • 一方到場有困難時，法院可依一造聲請或依職權提出和解方案；雙方限期內接受即視為和解成立，且接受不得撤回。
當事人「有和解之望」，而一造到場有困難時
  • 如一方在國外、重病、行動不便。
法院、受命法官或受託法官得依當事人「一造之聲請或依職權」提出和解方案
  • 依一造聲請：一方當事人得聲請。
  • 依職權：法院亦得主動為之。
前項聲請，「宜表明」法院得提出和解方案之「範圍」
  • 宜：訓示規定（非強制）。
依第一項提出之和解方案，「應送達於兩造」，並「限期」命為「是否接受之表示」
  • 法院應定相當期限，命雙方表示是否接受。
如兩造於期限內「表示接受」時，「視為」已依該方案「成立和解」
  • 視為和解成立：法律擬制。
前項接受之表示，不得撤回
  • 一旦表示接受，不得撤回。
例1.
  • 甲在國外，無法到場，法院依乙之聲請提出和解方案。
  • 法院送達方案，甲、乙均於期限內表示接受，視為和解成立。
  • 甲表示接受後反悔，不得撤回。
  • → 期限內「表示接受」時，「視為」已依該方案「成立和解」。接受之表示，不得撤回
命當事人本人到場
  • 法院為了試行和解或定和解方案，可以命令當事人本人或法定代理人親自到場。
因試行和解或定和解方案，得命當事人或法定代理人本人到場
  • 法院為了「試行和解」或「定和解方案」，可以命令當事人本人或法定代理人親自到場。
和解筆錄之製作與送達
  • 試行和解成立應作成筆錄，10日內送達正本；依第377條之1、之2視為和解成立者，以書面通知代替筆錄，該通知視為和解筆錄。
試行和解而成立者，應作成和解筆錄
  • 和解筆錄：記載和解內容之正式文書。
和解筆錄，應於和解成立之日起「十日內」，以正本「送達」於當事人及參加和解之第三人
  • 應於十日內：自和解成立之日起算。
  • 送達：送達當事人及第三人。
法院定和解方案而「視為和解成立者」，應於十日內將「和解內容及成立日期」以書面通知當事人及參加和解之第三人
  • 應於十日內：自視為和解成立之日起算。
  • 書面通知：載明和解內容及成立日期。
該通知視為和解筆錄
  • 該書面通知「視為」和解筆錄（與筆錄有同一效力）。
例1.
  • 甲、乙和解成立，法院作成和解筆錄。
  • 法院於和解成立後10日內將筆錄正本送達甲、乙。
  • → 和解筆錄，應於和解成立之日起「十日內」，以正本「送達」於當事人及參加和解之第三人
例2.
  • 法院定和解方案，雙方接受視為和解成立，法院於10日內以書面通知雙方，該通知視為和解筆錄。
  • → 法院定和解方案而「視為和解成立者」，應於十日內將「和解內容及成立日期」以書面通知當事人及參加和解之第三人
和解之效力與繼續審判
  • 和解成立與確定判決有同一效力。
  • 若有無效或得撤銷原因，可請求繼續審判（並繳回退還之裁判費），並準用再審及第三人撤銷訴訟之規定。
和解成立者，與確定判決有同一之效力
  • 包括「既判力」（不得再起訴）及「執行力」（得強制執行）。
和解有「無效或得撤銷之原因」者，當事人得「請求繼續審判」
  • 無效：如違反強制規定。
  • 得撤銷：如詐欺、脅迫、錯誤。
  • 得請求繼續審判：回復原訴訟程序。
請求「繼續審判」者，應「補繳裁判費」
  • 第84條第2項：和解成立時退還三分之二裁判費。
  • 補繳裁判費：請求繼續審判時，應繳回退還之裁判費。
請求繼續審判，準用再審及第三人撤銷訴訟之規定
例1.
  • 甲、乙和解成立，甲不得再就同一事件起訴。
  • → 和解成立者，與確定判決有同一之效力
例2.
  • 甲被乙脅迫而和解，甲得請求繼續審判。
  • → 和解有「無效或得撤銷之原因」者，當事人得「請求繼續審判」
例3.
  • 甲請求繼續審判，應繳回先前退還之裁判費。
  • → 請求「繼續審判」者，應「補繳裁判費」
未聲明事項或第三人參加和解之執行力
  • 和解若涉及未聲明之事項或第三人參加，該和解筆錄也可以作為執行名義。
當事人就未聲明之事項
  • 指訴訟中「未起訴」或「未聲明」之事項（如另一筆借款）。
或第三人參加和解成立者
  • 第三人（如保證人）參加和解並成立。
得為執行名義
  • 該和解筆錄得作為「執行名義」，聲請強制執行。
例1.
  • 甲訴乙給付貨款，和解時另就「另一筆借款」達成協議，該和解筆錄得為執行名義。
  • → 當事人就未聲明之事項和解成立者，得為執行名義
例2.
  • 保證人丙參加和解，與甲、乙成立和解，該筆錄得為執行名義。
  • → 第三人參加和解成立者，得為執行名義。
