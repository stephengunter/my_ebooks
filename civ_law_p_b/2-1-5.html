民事訴訟法 通常訴訟程序-判決

判決

終局判決之要件與合併辯論之判決
  • 訴訟達可裁判程度時，法院應為終局判決；合併辯論中已可裁判者應先判，但若必須合一確定則不得先判。
訴訟達於可為裁判之程度者，法院應為終局判決
  • 可為裁判之程度：事實已調查清楚、雙方已充分辯論。
  • 終局判決：對本案之最終判決。
命「合併辯論」之數宗訴訟，「其一」達於可為裁判之程度者，應「先為終局判決」
  • 若其中一宗已可裁判，應先判決。
但訴訟標的必須「合一確定」者，應合併裁判
  • 合併辯論之數宗訴訟，其訴訟標的必須合一確定者，應合併裁判。
例1.
  • 甲訴乙、甲訴丙合併辯論，甲訴乙部分已可裁判，法院先為終局判決。
  • → 合併辯論，先判
例2.
  • 甲、乙、丙為必要共同訴訟，法院不得先判其中一人。
  • → 合一確定，不得先判
一部終局判決
  • 訴訟標的之一部、數項標的之一部，或本訴/反訴之一部已可裁判時，法院得先為一部終局判決。
訴訟標的之一部達於可為裁判之程度者，法院「得為一部之終局判決」
  • 如原告請求100萬元，其中50萬元已明確。
  • 一部終局判決：就該部分先為終局判決。
以一訴主張數項標的，其一達於可為裁判之程度者，法院「得為一部之終局判決」
  • 主張數項標的：如原告同時請求給付貨款及返還借款，其中貨款部分已可裁判。
本訴或反訴達於可為裁判之程度者，法院「得為一部之終局判決」
  • 若本訴或反訴其中一個已可裁判，得先判該部分。
例1.
  • 甲請求乙給付100萬元，其中50萬元已明確，法院先為一部終局判決。
  • → 訴訟標的一部，先為一部終局判決
例2.
  • 甲同時請求貨款及借款，貨款部分已可裁判，法院先判貨款部分。
  • → 一訴主張數項標的，先為一部終局判決
例3.
  • 本訴已可裁判，反訴尚待調查，法院先判本訴。
  • → 本訴達於可為裁判之程度，先為本訴一部終局判決
中間判決與中間裁定
  • 訴訟中獨立的攻擊防禦方法或請求原因已可判斷時，法院得為中間判決；程序爭點得先為中間裁定。
各種「獨立之攻擊防禦方法」，達於可為裁判之程度者，法院「得為中間判決」
  • 獨立之攻擊或防禦方法：如時效抗辯、抵銷抗辯、同時履行抗辯。
  • 得為中間判決：法院得先判該爭點。
請求之「原因及數額俱有爭執」時，法院以其「原因為正當」者，「得為中間判決」
  • 原因：請求權基礎（如契約有效）。
  • 原因為正當：法院認請求權存在，得先為中間判決。
訴訟「程序上之中間爭點」，達於可為裁判之程度者，法院「得先為裁定」
  • 程序上之中間爭點：如管轄權、當事人適格、訴之利益。
  • 得先為裁定：法院得先以「裁定」判斷該程序爭點。
例1.
  • 甲訴乙給付貨款，乙抗辯時效消滅，法院認時效抗辯無理由，先為中間判決。
  • → 獨立之攻擊或防禦方法，達於可為裁判之程度者，法院得為中間判決
例2.
  • 甲訴乙侵權行為，法院認侵權行為存在（原因正當），先為中間判決，再審數額。
  • → 請求之「原因及數額俱有爭執」時，法院以其「原因為正當」者，「得為中間判決」
例3.
  • 法院先裁定「管轄權有無」。
  • → 「程序上之中間爭點」，法院「得先為裁定」
捨棄與認諾之判決
  • 當事人於言詞辯論時捨棄或認諾，法院應直接判該當事人敗訴，無須再審理。
當事人「於言詞辯論時」
  • 須於「言詞辯論期日」為之（不得於準備程序或書狀中為之？實務上書狀亦可，但以言詞辯論為準）。
為訴訟標的之「捨棄或認諾」者
  • 捨棄：原告放棄其請求（如「我不要了」）。
  • 認諾：被告承認原告之請求（如「我確實欠錢」）。
「應本於其捨棄或認諾」為該當事人「敗訴之判決」
  • 應：強制規定。
  • 本於其捨棄或認諾：法院應受拘束，無須調查證據。
  • 為該當事人敗訴之判決：
    • 原告捨棄 → 判原告敗訴（駁回其訴）。
    • 原告被告認諾 → 判被告敗訴（准許原告之訴）。
例1.
  • 甲起訴乙給付貨款，甲於言詞辯論時表示「捨棄請求」，法院判甲敗訴。
  • → 「捨棄或認諾」者，「應本於其捨棄或認諾」為該當事人「敗訴之判決」
例2.
  • 乙於書狀中表示認諾，但未於言詞辯論時為之，法院仍應審理。
  • → 未於言詞辯論為之
中間判決、捨棄及認諾判決之簡化記載
  • 中間判決、捨棄及認諾判決，得簡化判決書記載，或以言詞辯論筆錄代替判決書，筆錄送達與判決書送達有同一效力。
中間判決或捨棄、認諾判決之判決書，其事實及理由得合併記載其要領
  • 中間判決或捨棄、認諾判決的判決書，可以把「事實」和「理由」合併寫成「要領」就好。
法院亦得於宣示捨棄或認諾判決時，命將判決主文所裁判之事項及理由要領，記載於言詞辯論筆錄，不另作判決書。其筆錄正本或節本之送達，與判決正本之送達，有同一之效力
  • 法院也可以在宣示捨棄或認諾判決時，直接命令把「主文」和「理由要領」記在「言詞辯論筆錄」裡，不用另外作判決書。
  • 這個筆錄送達後，與判決書送達有同一效力。
例1.
  • 法院宣示認諾判決，命將主文及理由要領記載於筆錄，不另作判決書。
  • 筆錄正本送達當事人，與判決正本送達有同一效力。
一造辯論判決
  • 一造不到場時，法院得依聲請或依職權由一造辯論判決；必要共同訴訟中一人到場亦適用；判決時應斟酌未到場人之書狀及證據。
言詞辯論期日，當事人之一造不到場者，得「依到場當事人之聲請」，由其一造辯論而為判決
  • 開庭時如果有一方沒到，法院可以依到場那一方的聲請，讓到場的一方單獨辯論並判決。
不到場之當事人，經「再次通知而仍不到場」者，並「得依職權」由一造辯論而為判決
  • 如果沒到的一方已經被再次通知還是不來，法院也可以主動這樣做。
訴訟標的對於共同訴訟之各人必須合一確定者，共同訴訟人中一人到場時，亦適用之
  • 如果是「必須一起判」的共同訴訟，其中一人到場就可以一造辯論。
未到場人之前「有聲明證據」者，必要時「仍應調查」
  • 若未到場人之前有聲明證據，且有必要，法院應調查。
未到場人之前的辯論內容、證據調查、書狀陳述，判決時仍應斟酌
  • 法院應斟酌以前之辯論、證據調查及未到場人之書狀陳述。
例1.
  • 甲起訴乙，乙未到場，甲聲請一造辯論判決。
  • → 到場當事人得聲請一造辯論
例2.
  • 乙經再次通知仍不到，法院依職權一造辯論判決。
  • → 再次通知不到，法院得「依職權」由一造辯論而為判決
例3.
  • 甲、乙、丙為必要共同訴訟，甲到場，乙、丙未到，法院得為一造辯論判決。
  • → 必要共同訴訟，共同訴訟人中一人到場時，得聲請一造辯論
一造辯論判決之限制
  • 若不到場者未受合法通知、有正當理由，或到場者未證明職權事項、未通知他造，法院應駁回一造辯論聲請並改期。
有下列情形之一者，法院應以裁定「駁回」一造辯論之聲請，並「延展辯論期日」
  1. 不到場之當事人未受合法通知
    • 未受合法通知：送達不合法或「未於相當期間前」通知。
  2. 因天災或其他正當理由無法到場
    • 如重病、車禍。
  3. 到場之當事人於法院「應依職權調查之事項，不能為必要之證明」者
    • 法院應依職權調查之事項：如當事人能力、管轄權。
  4. 到場之當事人所提出之聲明、事實或證據，未於相當時期通知他造者
    • 使他造無從準備。
    5. 例1.
    • 乙未受合法通知而未到場，法院駁回一造辯論聲請。
    • → 未受合法通知
    例2.
    • 甲提出新證據但未通知乙，法院駁回一造辯論聲請。
    • → 證據未通知他造，駁回一造辯論聲請
到場不為辯論之效果
  • 當事人雖到庭但不為辯論，視同不到場，法院得依第385條為一造辯論判決。
當事人於辯論期日到場不為辯論者，視同不到場
  • 如果當事人雖然到了法庭，但卻「不進行辯論」（例如不說話、拒絕陳述），法律上就把他「當作沒到場」。
    • 法院可以依第385條讓另一方單獨辯論並判決。
例1.
  • 乙到庭但拒絕陳述，法院視同不到場，依甲之聲請為一造辯論判決。
  • → 到場不為辯論者，視同不到場
不得就未聲明事項判決（處分權主義）
  • 法院原則上只能就當事人聲明的事項判決，不能主動判當事人沒請求的東西。
除別有規定外，法院不得就當事人「未聲明之事項」為判決
  • 未聲明之事項：當事人未起訴或未請求之事項。
例1.
  • 甲請求乙給付100萬元，法院不得判命乙給付200萬元。
  • → 不得逾越聲明
例2.
  • 甲請求給付貨款，法院不得主動判命乙返還借款。
  • → 不得就當事人未聲明之事項為判決
依職權宣告假執行之判決
  • 被告認諾、簡易程序被告敗訴、或給付未逾50萬元之判決，法院應依職權宣告假執行。
本於被告「認諾」所為之判決，法院應依職權宣告假執行
  • 被告認諾（第384條），法院判被告敗訴，應依職權宣告假執行。
訴訟行「簡易程序」，被告敗訴之判決，法院應依職權宣告假執行
  • 第427條第1項至第4項之簡易訴訟，被告敗訴判決。
命給付金額「50萬元以下」之判決
  • 給付金額或價額未逾50萬元。
例1.
  • 乙認諾，法院判乙敗訴，應依職權宣告假執行。
  • → 被告認諾，應依職權宣告假執行
例2.
  • 簡易程序被告敗訴，法院應依職權宣告假執行。
  • → 被告認諾，應依職權宣告假執行
例3.
  • 判命給付30萬元，法院應依職權宣告假執行。
  • → 命給付金額「50萬元以下」之判決，應依職權宣告假執行
依聲請宣告假執行
  • 財產權訴訟中，原告釋明有難於抵償之損害，或陳明願供擔保，法院應依聲請宣告假執行。
關於財產權之訴訟
  • 適用於財產權訴訟（非財產權訴訟不適用）。
原告聲請假執行：方式1.「釋明」有「難於抵償/難於計算」損害之虞
  • 原告「釋明」在判決確定前不為執行，恐受「難於抵償/難於計算」之「損害」者，法院「應依其聲請，宣告假執行」
  • 釋明：提出證據使法院大致相信。
  • 難於抵償：如被告脫產。
  • 難於計算：如商譽損失。
原告聲請假執行：方式2.提供擔保
  • 原告陳明在執行前可供擔保而聲請宣告假執行者，雖無前項釋明，法院「應定相當之擔保額」，宣告供擔保後，得為假執行。
  • 定相當擔保額：法院酌定。
  • 供擔保後得為假執行：原告供擔保後，得假執行。
例1.
  • 甲釋明乙正在脫產，若不先執行將難以抵償，法院依聲請宣告假執行。
  • → 原告聲請假執行：方式1.「釋明」有「難於抵償/難於計算」損害之虞
例2.
  • 甲陳明願供擔保，聲請假執行，法院定擔保額後准許。
  • → 原告聲請假執行：方式2.提供擔保
被告因假執行恐受不能回復損害之救濟
  • 被告釋明假執行將致不能回復之損害時，法院應不准假執行（第389條情形）或駁回原告假執行聲請（第390條情形）。
「被告釋明」因假執行恐受「不能回復之損害」者
  • 釋明：提出證據使法院大致相信。
  • 不能回復之損害：如工廠被拆除、獨特藝術品被拍賣、商譽受重大損害。
法院應依其聲請宣告「不准假執行」
  • 在依職權宣告假執行之情形，法院應宣告不准假執行。
或「駁回」原告假執行之聲請
  • 在原告聲請假執行之情形，法院應「駁回」原告假執行之聲請。
例1.
  • 法院依職權宣告假執行，被告釋明工廠將被拆除（不能回復），法院依聲請宣告不准假執行。
  • → 「被告釋明」因假執行恐受「不能回復之損害」，法院應依其聲請宣告「不准假執行」
例2.
  • 原告聲請假執行，被告釋明將受不能回復損害，法院駁回原告聲請。
  • → 法院「駁回」原告假執行之聲請
命提出文書原本與繕本影本之證據力
  • 法院可要求提出原本核對；若不提出或不能提出，法院依自由心證決定影本有多少證明力。
法院得命提出文書之原本
  • 當法院對影本的真實性有疑義，或他造爭執影本與原本不符時，可命當事人提出原本以供核對。
不從前項之命提出原本或不能提出者
  • 「不從前項之命」：當事人有能力提出原本，但無正當理由拒絕（如故意隱匿）。
  • 「不能提出」：客觀上無法提出原本，如原本已滅失、遺失且無法找回、在國外且無法即時取得、或原本由第三人持有且無法取回。
法院依「自由心證」斷定該文書繕本或影本之「證據力」
  • 法院不得僅因「未提出原本」就逕行排除影本之證據能力。
  • 法院應綜合全辯論意旨，依自由心證（第222條）判斷該繕本或影本的證明力高低。
  • 例如：
    • 若當事人惡意不提出原本，法院可認定影本證明力極低
    • 若當事人已釋明原本滅失且無過失，且有其他旁證，法院可認定影本有相當證明力。
例1.
  • 原告甲提出借據影本，被告乙爭執影本內容與原本不符。
  • 法院命甲於7日內提出借據原本。
  • → 法院命提出原本
例2.
  • 甲無正當理由拒不提出原本（如承認原本在家但不願拿出）。
  • 法院審酌後，認甲惡意隱匿，依自由心證認定該影本證明力極低（不足以證明借款）
  • → 不從命，降低影本證明力
受命法官或受託法官調查文書證據之囑託事項
  • 受訴法院囑託其他法官調查文書時，可事先指定筆錄要寫什麼、要附哪些文件。
使受命法官或受託法官就文書調查證據者
  • 適用前提：受訴法院（受理本案之法院）不自行調查文書證據，而是：
    • 委由「受命法官」調查（在合議審判中，指定一名法官行準備程序並調查證據，第270條）。
    • 或囑託「受託法官」調查（委託其他法院之法官代為調查，第290條、第293條）。
受訴法院得定其筆錄應記載事項及應添附之文書
  • 筆錄應記載事項：受訴法院可事先指示，在受命法官或受託法官製作的調查證據筆錄中，應特別記載哪些內容。例如：
    • 文書之形式（原本、影本、繕本）。
    • 有無塗改、增刪、破損。
    • 核對影本與原本之結果（若原本已提出）。
  • 應添附之文書：受訴法院可指定受命法官或受託法官應將哪些文書「附在筆錄後面」作為附件。例如：
    • 文書之原本（若已提出）。
    • 相關之說明書、對照表、翻譯本。
例1.
  • 台北地院囑託高雄地院法官訊問證人並調查一份契約書原本。
  • 台北地院在囑託函中指定：筆錄應記載（1）契約書之簽約日期及當事人；（2）有無增刪塗改；（3）證人對契約書真正性之意見。
  • 高雄地院受託法官依指示製作筆錄。
  • → 指定筆錄應記載事項
例2.
  • 受訴法院命受命法官調查一份財務報表，並指定「應將報表之原本附於筆錄後，並檢附影本三份」
  • → 指定應添附文書
公文書之推定真正與真偽調查
  • 看起來像公文書的文件，推定為真；有疑問時法院可請製作機關說明。
文書，依其程式及意旨「得認作」公文書者，推定為真正
  • 公文書之定義：不以形式上必須由「公務員」名義為限，而係從文書的「程式」（格式、用印、機關銜、公文字號）及「意旨」（內容涉及公權力行使或公共事務）綜合判斷。
    • 例如：地政機關核發之謄本、法院判決書、警察局舉發通知單。
  • 推定為真正：推定文書之形式真正（即文書為該機關或公務員所製作，未經偽造變造）。
    • 主張偽造之一方應提出反證（如證明印章為偽造、文書係盜用）。若未能提出反證，法院應認定該文書為真正。
公文書之「真偽可疑」者，法院得請「作成名義」之「機關或公務員」陳述其真偽
  • 法院可主動調查公文書真偽：
    • 「有可疑」指法院對文書之形式真正產生合理懷疑（如筆跡與該機關之標準不符、文書編號與年代矛盾）。
    • 法院得發函或傳喚該機關或公務員到場說明，以釐清真偽。
例1.
  • 甲提出戶政事務所核發之戶籍謄本，證明其與乙之親子關係。
  • 乙主張該謄本係偽造，但未提出任何證據。
  • 法院認謄本符合公文書程式，推定為真正。
  • → 文書依其程式及意旨「得認作」公文書者，推定為真正
例2.
  • 法院對一份地政機關核發之土地登記謄本有疑慮（格式與一般謄本不同），乃發函請該地政機關說明該謄本是否為其所製發。
  • 機關回函確認係偽造。
  • → 公文書之「真偽可疑」者，法院得請「作成名義」之「機關或公務員」陳述其真偽
外國公文書之真偽判斷
  • 外國公文書由法院個案判斷真偽；但若經我國駐外機構認證，則推定為真正。
外國之公文書，其真偽由法院審酌情形斷定之
  • 外國之公文書：例如：美國法院判決、日本戶籍謄本、德國政府核發之出生證明、新加坡商業登記證。
  • 其真偽由法院審酌情形斷定之：原則：本國法院不自動推定外國公文書為真正。
    • 法院應綜合一切情狀（文書之形式、內容、來源、有無其他證據佐證、該國公務制度之可信度等），依自由心證（第222條）判斷其真偽。
    • 若無法形成確信，則由提出該文書之當事人負舉證責任。
但經「駐在該國」之中華民國大使、公使、領事或其他「機構證明」者，推定為真正
  • 例外：若該外國公文書經我國駐在該國的大使館、總領事館、領事館、或代表處（如台北經濟文化辦事處）證明（如認證文書上之簽章、核驗簽名）：
    • 視同經過本國公務員之證明，法律上「推定為真正」。
    • 此項推定可由他造提出反證推翻。
例1.
  • 甲提出一份美國加州法院的判決書，未經我國駐外單位認證。乙爭執其真正。
  • 法院審酌該判決書之格式、內容、印章，並參酌其他證據（如專家意見），依自由心證認定其為真正。
  • → 未經認證，由法院審酌
例2.
  • 甲提出經我國駐日本代表處驗證之日本戶籍謄本。
  • 法院依本條但書，推定該謄本為真正。乙欲推翻，應提出反證（如證明代表處之認證係偽造）
  • → 經認證，推定真正
私文書之真正舉證
  • 私人文件，誰拿出來誰就要證明是真的；但對方如果不爭執，就不用證明。
私文書應「由舉證人」證其真正
  • 私文書：指非公文書之文書，即由私人（自然人或法人）製作之文書。
    • 如契約書、借據、收據、日記、私人信件、公司內部備忘錄等。
  • 應由舉證人證其真正：舉證人必須證明該文書為真正。「舉證人」指提出該私文書作為證據之當事人。
    • 「證其真正」指證明該文書之形式真正——即文書確由名義人所製作（簽名、蓋章為真正），且未經事後竄改。
    • 若舉證人無法證明，且他造爭執，則該文書不得採為證據。
但他造於其真正「無爭執」者，不在此限
  • 例外：若他造當事人明示或默示不爭執文書之真正（例如在書狀或開庭時表示「對文書真正不爭執」，或依第280條視同自認），則舉證人無須舉證。
例1.
  • 甲提出一份借據，主張乙向其借款50萬元。乙爭執借據上簽名非其所簽。
  • 甲須證明該簽名為真正（如聲請筆跡鑑定、傳喚證人）
  • → 私文書應「由舉證人」證其真正
例2.
  • 甲提出借據，乙在書狀中明確表示「對借據之真正不爭執」。
  • 甲無須證明真正。
  • → 他造不爭執，無庸舉證
例3.
  • 甲無法證明借據上乙之簽名為真正，乙始終爭執。
  • 法院認甲未盡舉證責任，該借據不得作為證據。
  • → 無法證明真正，不採信
故意爭執文書真正之制裁
  • 明知文件是真的，卻故意說它是假的，法院可罰3萬元；若及時承認可撤銷罰款。
當事人或代理人就真正之文書，「故意爭執」其真正者
  • 客觀要件：該文書在事實上為真正（非偽造或變造）。
  • 主觀要件：行為人明知其為真正，卻故意為相反之爭執（如主張「簽名是偽造的」、「印章是盜蓋的」）。
    • 若行為人主觀上確信文書為偽造（即使事後證明為真），不構成本條之故意。
法院得以裁定處三萬元以下罰鍰。得為抗告，抗告中應停止執行
  • 法院有裁量權，得視情節輕重處以罰鍰（1元至3萬元）。此為行政罰性質，由民事法院於訴訟中一併裁定。
  • 為避免罰鍰執行後難以回復，抗告期間「應停止執行」（強制規定）。
於「第二審言詞辯論終結前」，承認該文書為真正者，法院得審酌情形撤銷罰鍰裁定
  • 行為人若在「第二審言詞辯論終結前」承認文書為真正（即不再爭執），受訴法院得撤銷原罰鍰裁定。
例1.
  • 甲提出乙親簽之借據，乙於另案已自認該簽名為真正，卻於本案中故意爭執簽名係偽造。
  • 法院審理後認文書為真正，且乙係故意爭執。法院裁定處乙罰鍰2萬元。
  • 乙提起抗告。抗告期間，法院不得強制執行該罰鍰。
  • → 故意爭執，裁定處罰鍰。抗告期間罰鍰停止執行
例2.
  • 乙被處罰鍰後，在第二審言詞辯論終結前，具狀承認該借據為真正。
  • 法院審酌乙已改正，裁定撤銷原罰鍰裁定。
  • → 承認真正，撤銷罰鍰裁定
經簽章或認證之私文書推定真正
  • 有本人簽章、蓋章、指印或經法院、公證人認證的私文書，推定為真；對自己簽章說不知或不記得，由法院決定是否仍推定。
私文書經「本人或其代理人簽名」、蓋章或按指印
  • 文書上有本人（名義人）或其有權代理人之簽名、蓋章或按指印。
  • 此等行為在法律上通常代表本人承認文書內容。
或有法院或公證人之認證者
  • 文書經法院（如公證處）或公證人（包括民間公證人）依公證法規定為認證，證明文書上之簽章為本人所為或文書形式上真正。
  • 認證與簽章同具推定效力。
推定為真正
  • 法律效果。推定文書之形式真正（非偽造、非變造，且簽名、蓋章、指印為真正）。
  • 爭執其真正之一方應提出反證；若未能提出反證，法院應認定該文書為真正。
當事人就其本人之簽名、蓋章或按指印為「不知或不記憶」之陳述者
  • 當事人對自己之簽名、蓋章或指印，不積極否認，亦不承認，而陳述「不知道」、「不記得」、「沒印象」。
應否推定為真正，由法院審酌情形斷定之
  • 由法院裁量。法院應綜合考量：該簽名出現之場合與當事人之關聯性、當事人有無記憶之合理可能、當事人是否故意推諉、周圍證據等。
  • 若法院認當事人應知而諉為不知，仍可推定真正；若認確有可能不復記憶，則不逕予推定，此時舉證人仍須依第357條舉證。
例1.
  • 甲提出借據，上有乙之簽名。乙爭執借據真正。
  • 法院依第358條第1項推定借據為真正，乙應提出反證（如鑑定借據上簽名非乙所簽）
  • → 本人簽名，推定真正
例2.
  • 乙對借據上之簽名陳述「不記得是否我簽的」。
  • 法院審酌：該借據為乙借款時當場簽名，乙不可能不記得，且乙曾於他案承認該筆借款。
  • 法院認定仍應推定真正。
  • → 不知或不記憶，法院審酌
筆跡或印跡之核對
  • 筆跡、印跡比對可以證明文書真偽；法院有權命當事人或第三人提供比對文件；比對程序比照勘驗。
文書之真偽，得依「核對筆跡或印跡證之」
  • 證據方法：
    • 「核對筆跡」：將爭執之簽名與無爭議之簽名（比對樣本）進行比較。
    • 「核對印跡」：將爭執之印文與無爭議之印文進行比較。
  • 法院得自行核對，或命專家（如鑑定人）輔助核對。
法院得命當事人或第三人「提出可供核對之文書」
  • 取得比對樣本之強制命令。法院得依職權或聲請為之。違反提出命令者，依第345條（當事人）或第349條（第三人）處理。
  • 「可供核對之文書」：指可作為比對標準的文書，例如：當事人過去親簽之契約、書信、申請書、支票、日記。
  • 「當事人」：包括兩造。
  • 「第三人」：非訴訟當事人但持有該名義人筆跡或印跡之人。
核對筆跡或印跡，「適用勘驗」之規定
  • 程序準用。勘驗之規定見第364條至第367條，主要內容包括：
    • 勘驗時得命當事人到場。
    • 勘驗時得命鑑定人輔助。
    • 製作勘驗筆錄。
例1.
  • 原告甲提出借據，主張被告乙簽名。乙否認。
  • 法院命乙提出過去親簽之駕駛執照申請書、信用卡簽單，作為比對樣本。
  • 法院自行核對借據與樣本上之筆跡，認定高度相似，輔以鑑定人之意見，認借據上簽名為乙所簽。
  • → 文書之真偽，得依「核對筆跡或印跡證之」
例2.
  • 乙否認簽名，法院得命乙之雇主丙公司提出乙之「請假單」（上有乙親簽），作為比對樣本。
  • 丙應配合提出。
  • → 命第三人提出比對文書
命當事人當庭書寫文字以供核對
  • 沒有筆跡樣本可對照時，法院可命當事人當庭寫字作為比對樣本。
  • 拒絕寫字者，當事人受擬制真實制裁，第三人受罰鍰或強制處分。
無適當之筆跡可供核對者，法院得指定文字，命該文書之作成名義人書寫，以供核對
  • 「指定文字」：法院應選定一段與爭議文書內容相關或中性之文字（如爭議文書中的部分詞句、法院設計之文字），避免引導或偏頗。
  • 「作成名義人」：被指為簽名或製作該文書之人（可能是原告、被告或第三人）。
無正當理由不從前項之命者，得「擬制真實」
  • 「擬制真實」：若作成名義人為「當事人」：依第345條，法院得審酌情形認他造關於該文書之主張或應證之事實為真實。
  • 若作成名義人為「第三人」：依第349條，法院得處以罰鍰（三萬元以下）或為強制處分。
核對筆跡「所寫文字，應附於筆錄」；其他供核對之文件不須發還者亦同
  • 證據保全。當庭書寫之文字應附於言詞辯論筆錄或勘驗筆錄中。
  • 其他已提出供核對之文件（如第359條之既存文書），若無須發還（如當事人不請求返還），亦應附卷，以備上級審查。
例1.
  • 原告甲提出借據，主張被告乙簽名。乙否認。
  • 法院調閱乙之過往書寫文件，均無法取得或雙方爭執真正。
  • 法院指定「本人於民國113年1月10日向甲借款新臺幣50萬元」一段文字，命乙當庭書寫三次，以與借據上簽名核對。
  • 乙無正當理由拒絕書寫（如稱「我不想寫」）。
  • 法院依第360條第2項準用第345條，認甲關於「借據上簽名為乙所簽」之主張為真實。
  • → 命當庭書寫，無正當理由拒絕，擬制真實
文書原本之發還與保管
  • 須發還的正本要留影本在卷；有偽造嫌疑的正本，法院要保管到官司結束；需移送其他機關者例外。
提出之文書原本須發還者，應將其繕本、影本或節本附卷
  • 發還原本前，法院應製作（或命當事人提供）該文書之繕本（手抄複製本）、影本（影印或掃描複本）或節本（摘錄要旨之版本），附於訴訟卷宗，以取代原本作為證據資料。
提出之文書原本，如疑為「偽造/變造」者，於「訴訟終結前」，應「由法院保管」之
  • 強制保管。自提出至訴訟終結（判決確定、和解、撤回等），法院應將原本附於卷宗保管，不得發還。
  • 目的是避免證據遭滅失或竄改，並供鑑定或上級審查閱。
但應交付其他機關者，不在此限
  • 例外：若該文書依法必須交付其他機關（如刑事偵查機關、行政機關），法院應依規定交付，而非自行保管。
例1.
  • 甲提出借據，乙強烈爭執簽名為偽造。
  • 法院認有偽造嫌疑，將借據原本留存於卷宗保管，未發還甲。訴訟確定後，始發還。
  • → 疑為偽造，保管原本
準文書及科技文書之證據方法
  • 非文書但有記錄功能的物件，適用書證規定。
  • 數位檔案或大型原件可提書面替代，但要證明相符。
  • 法院必要時可命說明。
文書外之物件，有與文書相同之效用者，準用文書規定
  • 「有與文書相同之效用」：該物件以文字、符號、圖像、記號等方式記錄或表達思想、事實，可供人閱讀或理解。
    • 例如：照片、雕刻之石碑、光碟片、磁帶、X光片。
  • 準用之規定包括：提出（第341條）、聲請命他造提出（第342條）、義務範圍（第344條）、原本與影本（第352條）、真正推定（第358條）、核對筆跡（第359條）等。
文書或前項物件，須以科技設備始能呈現其內容
  • 如存在電腦硬碟、手機、雲端之數位檔案，須以電腦、讀取機、播放器始能顯示。
或提出原件有事實上之困難者
  • 如大型看板、壁畫、機器上之銘板，無法或不宜搬運到法院。
得僅提出呈現其內容之書面並證明其內容與原件相符
  • 替代方式：當事人可提出「呈現其內容之書面」（如列印出文件內容、翻拍照片、抄錄文字），並須「證明其內容與原件相符」（如提出原件來源證明、留存數位簽章、具結書、或經公證人認證）。
法院於必要時得命說明之
  • 法院對該文書、準文書或替代書面之內容有疑義時，得命當事人到場說明（如解釋如何證明相符、如何取得書面、或提出原始檔案以核對）。
例1.
  • 甲提出一片光碟，內有車禍現場監視器錄影，用以證明乙有過失。
  • 法院依第363條第1項準用書證規定，命甲提出光碟並說明其內容。
  • → 準文書——光碟
例2.
  • 甲主張乙於LINE對話中承認借款，但無法攜帶手機到庭（需作為日常通訊工具）。
  • 甲將LINE對話紀錄截圖列印成紙本，並提出切結書證明截圖與手機原始對話內容相符。法院准許。
  • → 數位檔案，提出列印書面
例3.
  • 法院對甲提出之LINE截圖是否真實有疑，命甲到庭說明如何取得截圖、如何證明與原始對話一致，並當庭操作手機比對。
