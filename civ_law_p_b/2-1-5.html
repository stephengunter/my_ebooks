民事訴訟法 通常訴訟程序-判決

判決

終局判決之要件與合併辯論之判決
  • 訴訟達可裁判程度時，法院應為終局判決；合併辯論中已可裁判者應先判，但若必須合一確定則不得先判。
訴訟達於可為裁判之程度者，法院應為終局判決
  • 可為裁判之程度：事實已調查清楚、雙方已充分辯論。
  • 終局判決：對本案之最終判決。
命「合併辯論」之數宗訴訟，「其一」達於可為裁判之程度者，應「先為終局判決」
  • 若其中一宗已可裁判，應先判決。
但訴訟標的必須「合一確定」者，應合併裁判
  • 合併辯論之數宗訴訟，其訴訟標的必須合一確定者，應合併裁判。
例1.
  • 甲訴乙、甲訴丙合併辯論，甲訴乙部分已可裁判，法院先為終局判決。
  • → 合併辯論，先判
例2.
  • 甲、乙、丙為必要共同訴訟，法院不得先判其中一人。
  • → 合一確定，不得先判
一部終局判決
  • 訴訟標的之一部、數項標的之一部，或本訴/反訴之一部已可裁判時，法院得先為一部終局判決。
訴訟標的之一部達於可為裁判之程度者，法院「得為一部之終局判決」
  • 如原告請求100萬元，其中50萬元已明確。
  • 一部終局判決：就該部分先為終局判決。
以一訴主張數項標的，其一達於可為裁判之程度者，法院「得為一部之終局判決」
  • 主張數項標的：如原告同時請求給付貨款及返還借款，其中貨款部分已可裁判。
本訴或反訴達於可為裁判之程度者，法院「得為一部之終局判決」
  • 若本訴或反訴其中一個已可裁判，得先判該部分。
例1.
  • 甲請求乙給付100萬元，其中50萬元已明確，法院先為一部終局判決。
  • → 訴訟標的一部，先為一部終局判決
例2.
  • 甲同時請求貨款及借款，貨款部分已可裁判，法院先判貨款部分。
  • → 一訴主張數項標的，先為一部終局判決
例3.
  • 本訴已可裁判，反訴尚待調查，法院先判本訴。
  • → 本訴達於可為裁判之程度，先為本訴一部終局判決
中間判決與中間裁定
  • 訴訟中獨立的攻擊防禦方法或請求原因已可判斷時，法院得為中間判決；程序爭點得先為中間裁定。
各種「獨立之攻擊防禦方法」，達於可為裁判之程度者，法院「得為中間判決」
  • 獨立之攻擊或防禦方法：如時效抗辯、抵銷抗辯、同時履行抗辯。
  • 得為中間判決：法院得先判該爭點。
請求之「原因及數額俱有爭執」時，法院以其「原因為正當」者，「得為中間判決」
  • 原因：請求權基礎（如契約有效）。
  • 原因為正當：法院認請求權存在，得先為中間判決。
訴訟「程序上之中間爭點」，達於可為裁判之程度者，法院「得先為裁定」
  • 程序上之中間爭點：如管轄權、當事人適格、訴之利益。
  • 得先為裁定：法院得先以「裁定」判斷該程序爭點。
例1.
  • 甲訴乙給付貨款，乙抗辯時效消滅，法院認時效抗辯無理由，先為中間判決。
  • → 獨立之攻擊或防禦方法，達於可為裁判之程度者，法院得為中間判決
例2.
  • 甲訴乙侵權行為，法院認侵權行為存在（原因正當），先為中間判決，再審數額。
  • → 請求之「原因及數額俱有爭執」時，法院以其「原因為正當」者，「得為中間判決」
例3.
  • 法院先裁定「管轄權有無」。
  • → 「程序上之中間爭點」，法院「得先為裁定」
捨棄與認諾之判決
  • 當事人於言詞辯論時捨棄或認諾，法院應直接判該當事人敗訴，無須再審理。
當事人「於言詞辯論時」
  • 須於「言詞辯論期日」為之（不得於準備程序或書狀中為之？實務上書狀亦可，但以言詞辯論為準）。
為訴訟標的之「捨棄或認諾」者
  • 捨棄：原告放棄其請求（如「我不要了」）。
  • 認諾：被告承認原告之請求（如「我確實欠錢」）。
「應本於其捨棄或認諾」為該當事人「敗訴之判決」
  • 應：強制規定。
  • 本於其捨棄或認諾：法院應受拘束，無須調查證據。
  • 為該當事人敗訴之判決：
    • 原告捨棄 → 判原告敗訴（駁回其訴）。
    • 原告被告認諾 → 判被告敗訴（准許原告之訴）。
例1.
  • 甲起訴乙給付貨款，甲於言詞辯論時表示「捨棄請求」，法院判甲敗訴。
  • → 「捨棄或認諾」者，「應本於其捨棄或認諾」為該當事人「敗訴之判決」
例2.
  • 乙於書狀中表示認諾，但未於言詞辯論時為之，法院仍應審理。
  • → 未於言詞辯論為之
中間判決、捨棄及認諾判決之簡化記載
  • 中間判決、捨棄及認諾判決，得簡化判決書記載，或以言詞辯論筆錄代替判決書，筆錄送達與判決書送達有同一效力。
中間判決或捨棄、認諾判決之判決書，其事實及理由得合併記載其要領
  • 中間判決或捨棄、認諾判決的判決書，可以把「事實」和「理由」合併寫成「要領」就好。
法院亦得於宣示捨棄或認諾判決時，命將判決主文所裁判之事項及理由要領，記載於言詞辯論筆錄，不另作判決書。其筆錄正本或節本之送達，與判決正本之送達，有同一之效力
  • 法院也可以在宣示捨棄或認諾判決時，直接命令把「主文」和「理由要領」記在「言詞辯論筆錄」裡，不用另外作判決書。
  • 這個筆錄送達後，與判決書送達有同一效力。
例1.
  • 法院宣示認諾判決，命將主文及理由要領記載於筆錄，不另作判決書。
  • 筆錄正本送達當事人，與判決正本送達有同一效力。
一造辯論判決
  • 一造不到場時，法院得依聲請或依職權由一造辯論判決；必要共同訴訟中一人到場亦適用；判決時應斟酌未到場人之書狀及證據。
言詞辯論期日，當事人之一造不到場者，得「依到場當事人之聲請」，由其一造辯論而為判決
  • 開庭時如果有一方沒到，法院可以依到場那一方的聲請，讓到場的一方單獨辯論並判決。
不到場之當事人，經「再次通知而仍不到場」者，並「得依職權」由一造辯論而為判決
  • 如果沒到的一方已經被再次通知還是不來，法院也可以主動這樣做。
訴訟標的對於共同訴訟之各人必須合一確定者，共同訴訟人中一人到場時，亦適用之
  • 如果是「必須一起判」的共同訴訟，其中一人到場就可以一造辯論。
未到場人之前「有聲明證據」者，必要時「仍應調查」
  • 若未到場人之前有聲明證據，且有必要，法院應調查。
未到場人之前的辯論內容、證據調查、書狀陳述，判決時仍應斟酌
  • 法院應斟酌以前之辯論、證據調查及未到場人之書狀陳述。
例1.
  • 甲起訴乙，乙未到場，甲聲請一造辯論判決。
  • → 到場當事人得聲請一造辯論
例2.
  • 乙經再次通知仍不到，法院依職權一造辯論判決。
  • → 再次通知不到，法院得「依職權」由一造辯論而為判決
例3.
  • 甲、乙、丙為必要共同訴訟，甲到場，乙、丙未到，法院得為一造辯論判決。
  • → 必要共同訴訟，共同訴訟人中一人到場時，得聲請一造辯論
一造辯論判決之限制
  • 若不到場者未受合法通知、有正當理由，或到場者未證明職權事項、未通知他造，法院應駁回一造辯論聲請並改期。
有下列情形之一者，法院應以裁定「駁回」一造辯論之聲請，並「延展辯論期日」
  1. 不到場之當事人未受合法通知
    • 未受合法通知：送達不合法或「未於相當期間前」通知。
  2. 因天災或其他正當理由無法到場
    • 如重病、車禍。
  3. 到場之當事人於法院「應依職權調查之事項，不能為必要之證明」者
    • 法院應依職權調查之事項：如當事人能力、管轄權。
  4. 到場之當事人所提出之聲明、事實或證據，未於相當時期通知他造者
    • 使他造無從準備。
    5. 例1.
    • 乙未受合法通知而未到場，法院駁回一造辯論聲請。
    • → 未受合法通知
    例2.
    • 甲提出新證據但未通知乙，法院駁回一造辯論聲請。
    • → 證據未通知他造，駁回一造辯論聲請
到場不為辯論之效果
  • 當事人雖到庭但不為辯論，視同不到場，法院得依第385條為一造辯論判決。
當事人於辯論期日到場不為辯論者，視同不到場
  • 如果當事人雖然到了法庭，但卻「不進行辯論」（例如不說話、拒絕陳述），法律上就把他「當作沒到場」。
    • 法院可以依第385條讓另一方單獨辯論並判決。
例1.
  • 乙到庭但拒絕陳述，法院視同不到場，依甲之聲請為一造辯論判決。
  • → 到場不為辯論者，視同不到場
不得就未聲明事項判決（處分權主義）
  • 法院原則上只能就當事人聲明的事項判決，不能主動判當事人沒請求的東西。
除別有規定外，法院不得就當事人「未聲明之事項」為判決
  • 未聲明之事項：當事人未起訴或未請求之事項。
例1.
  • 甲請求乙給付100萬元，法院不得判命乙給付200萬元。
  • → 不得逾越聲明
例2.
  • 甲請求給付貨款，法院不得主動判命乙返還借款。
  • → 不得就當事人未聲明之事項為判決
依職權宣告假執行之判決
  • 被告認諾、簡易程序被告敗訴、或給付未逾50萬元之判決，法院應依職權宣告假執行。
本於被告「認諾」所為之判決，法院應依職權宣告假執行
  • 被告認諾（第384條），法院判被告敗訴，應依職權宣告假執行。
訴訟行「簡易程序」，被告敗訴之判決，法院應依職權宣告假執行
  • 第427條第1項至第4項之簡易訴訟，被告敗訴判決。
命給付金額「50萬元以下」之判決
  • 給付金額或價額未逾50萬元。
例1.
  • 乙認諾，法院判乙敗訴，應依職權宣告假執行。
  • → 被告認諾，應依職權宣告假執行
例2.
  • 簡易程序被告敗訴，法院應依職權宣告假執行。
  • → 被告認諾，應依職權宣告假執行
例3.
  • 判命給付30萬元，法院應依職權宣告假執行。
  • → 命給付金額「50萬元以下」之判決，應依職權宣告假執行
依聲請宣告假執行
  • 財產權訴訟中，原告釋明有難於抵償之損害，或陳明願供擔保，法院應依聲請宣告假執行。
關於財產權之訴訟
  • 適用於財產權訴訟（非財產權訴訟不適用）。
原告聲請假執行：方式1.「釋明」有「難於抵償/難於計算」損害之虞
  • 原告「釋明」在判決確定前不為執行，恐受「難於抵償/難於計算」之「損害」者，法院「應依其聲請，宣告假執行」
  • 釋明：提出證據使法院大致相信。
  • 難於抵償：如被告脫產。
  • 難於計算：如商譽損失。
原告聲請假執行：方式2.提供擔保
  • 原告陳明在執行前可供擔保而聲請宣告假執行者，雖無前項釋明，法院「應定相當之擔保額」，宣告供擔保後，得為假執行。
  • 定相當擔保額：法院酌定。
  • 供擔保後得為假執行：原告供擔保後，得假執行。
例1.
  • 甲釋明乙正在脫產，若不先執行將難以抵償，法院依聲請宣告假執行。
  • → 原告聲請假執行：方式1.「釋明」有「難於抵償/難於計算」損害之虞
例2.
  • 甲陳明願供擔保，聲請假執行，法院定擔保額後准許。
  • → 原告聲請假執行：方式2.提供擔保
被告因假執行恐受不能回復損害之救濟
  • 被告釋明假執行將致不能回復之損害時，法院應不准假執行（第389條情形）或駁回原告假執行聲請（第390條情形）。
「被告釋明」因假執行恐受「不能回復之損害」者
  • 釋明：提出證據使法院大致相信。
  • 不能回復之損害：如工廠被拆除、獨特藝術品被拍賣、商譽受重大損害。
法院應依其聲請宣告「不准假執行」
  • 在依職權宣告假執行之情形，法院應宣告不准假執行。
或「駁回」原告假執行之聲請
  • 在原告聲請假執行之情形，法院應「駁回」原告假執行之聲請。
例1.
  • 法院依職權宣告假執行，被告釋明工廠將被拆除（不能回復），法院依聲請宣告不准假執行。
  • → 「被告釋明」因假執行恐受「不能回復之損害」，法院應依其聲請宣告「不准假執行」
例2.
  • 原告聲請假執行，被告釋明將受不能回復損害，法院駁回原告聲請。
  • → 法院「駁回」原告假執行之聲請
假執行之擔保與免為假執行
  • 法院得宣告原告供擔保後假執行，或被告供擔保/提存後免為假執行。
  • 免為假執行須在執行標的物拍定、變賣或交付前為之。
原告預供擔保後假執行：法院得宣告非經原告「預供擔保」，不得為假執行
  • 法院可以宣告「原告必須先提供擔保，才能假執行」。
被告供「擔保或提存」免假執行：法院得「依聲請或依職權」，宣告被告預供擔保，或將請求標的物提存而免為假執行
  • 法院可以依聲請或依職權，宣告「被告如果提供擔保或把請求標的物提存，就可以免為假執行」。
被告供「擔保或提存」免假執行：應於執行標的物拍定、變賣或交付前為之
  • 被告要提供擔保或提存來免為假執行，必須在「執行標的物拍定、變賣或物之交付前」為之。
假執行聲請之時期與裁判之記載
  • 假執行之聲請須在言詞辯論終結前提出；假執行之准駁應記載於判決主文。
假執行之聲請，應於「言詞辯論終結前」為之
  • 言詞辯論終結前：須在法院宣示辯論終結前提出。
  • 聲請：包括原告聲請假執行、被告聲請不准假執行或免為假執行。
記載於主文：假執行之裁判，應記載於裁判主文
  • 如「本判決得假執行」、「原告供擔保後得假執行」。
例1.
  • 原告於言詞辯論終結前聲請假執行，法院准許。
  • → 言詞辯論終結前聲請假執行
例2.
  • 判決主文記載「本判決得假執行」。
  • → 假執行之裁判，應記載於裁判主文
假執行漏未裁判之補充
  • 法院漏未宣告假執行或忽略假執行/免假執行之聲請時，準用補充判決之規定救濟。
法院應依職權宣告假執行而未為宣告
  • 應依職權宣告假執行：認諾、簡易程序、50萬元以下案件。
  • 未為宣告：法院漏未宣告。
或忽視假執行或免為假執行之聲請者
  • 法院忽略原告假執行之聲請（第390條）或被告免為假執行之聲請（第392條）。
準用「補充判決」規定
  • 第233條：補充判決。法院應依聲請或依職權，以判決補充之。
例1.
  • 法院應依第389條宣告假執行，但漏未宣告，當事人聲請補充判決。
例2.
  • 原告聲請假執行，法院忽略，原告聲請補充判決。
假執行宣告之失效與損害賠償
  • 假執行宣告因本案判決或該宣告被廢棄/變更而失效。
  • 法院廢棄/變更本案判決時，應依被告聲明命原告返還給付及賠償損害，未聲明者應闡明。
假執行失效原因：判決或假執行宣告被廢棄或變更
  • 上級法院廢棄或變更「本案判決」或「假執行宣告」。
假執行失效時點：該判決宣示時起
  • 自宣示時起：假執行宣告失其效力。
法院「廢棄/變更」宣告假執行判決，應「依被告聲明」，「命賠償損害」。被告未聲明者，應告以得為聲明
  • 如果法院廢棄或變更了「宣告假執行的本案判決」，應依「被告的聲明」，把被告因假執行或免假執行所為的給付及所受損害，在判決中命原告「返還及賠償」。
  • 被告沒聲明的話，法院要告訴他可以聲明。
例1.
  • 上級法院廢棄本案判決，假執行宣告自宣示時失效。
例2.
  • 被告因假執行已給付100萬元，法院廢棄本案判決，依被告聲明命原告返還100萬元及賠償損害。
  • → 「廢棄/變更」宣告假執行判決，應「依被告聲明」，「命賠償損害」
判決履行期間與分期給付
  • 法院得斟酌情形定履行期間或命分期給付；分期給付遲誤一次即喪失期限利益。
  • 履行期間自判決確定或假執行判決送達被告時起算；裁判前應令當事人辯論。
判決所命之給付，其性質非長期間不能履行
  • 如拆除違建、修繕房屋需較長時間。
或斟酌被告之境況，兼顧原告之利益
  • 考量被告經濟狀況及原告權益。
或經原告同意者
  • 若原告同意，法院亦得為之。
法院得於判決內定相當之「履行期間」或命「分期給付」
  • 定履行期間：如「六個月內履行」。
  • 命分期給付：如「分三期給付」。
判決定「履行期間」或命「分期給付」應，應令當事人有辯論之機會
  • 法院在裁判前，要讓當事人有辯論的機會。
分次履行「遲誤一次，其後全部到期」
  • 如果法院定「分期給付」，被告只要遲誤一次，後面的期間就「視為全部到期」。
例1.
  • 法院判命被告拆除違建，定「六個月」履行期間。
  • → 定履行期間
例2.
  • 法院命被告分三期給付，被告遲誤一期，其後視為到期。
  • → 分期給付
例3.
  • 法院定履行期間前，令當事人辯論。
  • → 辯論機會
情事變更後之變更判決之訴
  • 確定判決內容尚未實現，因言詞辯論終結後情事變更致顯失公平時，當事人得更行起訴請求變更原判決；和解、調解亦準用。
要件1.確定判決內容尚未實現
  • 判決尚未執行完畢（如尚未給付完畢）。
要件2.言詞辯論終結後，「情事變更」而「顯失公平」
  • 如通貨膨脹、經濟危機、戰爭。
要件3.不得依其他法定程序救濟
  • 如不能上訴、再審。
效果：當事人得「更行起訴」，請求「變更原判決之給付」
  • 更行起訴：提起新訴訟。
  • 變更原判決之給付：如減少給付金額或變更履行方式。
和解/調解或其他「與確定判決有同一效力」者準用之
  • 這項規定也適用於和解、調解等。
例1.
  • 法院判命被告給付100萬元，言詞辯論終結後發生嚴重通貨膨脹，被告請求變更給付金額。
  • → 言詞辯論終結後，「情事變更」而「顯失公平」
例2.
  • 和解成立後發生情事變更，當事人請求變更和解內容。
  • → 和解準用
判決確定之時期
  • 判決於上訴期間屆滿時確定；合法上訴阻其確定；不得上訴之判決於宣示或公告時確定。
判決，於上訴期間屆滿時確定
  • 上訴期間（如20日）屆滿，無人上訴，判決確定。
但於上訴期間內有合法之上訴者，阻其確定
  • 合法上訴：符合上訴要件。
  • 阻其確定：判決暫不確定。
「不得上訴」之判決，於「宣示時確定」
  • 如第三審判決、簡易程序之第二審判決（不得上訴第三審）。
當事人就其本人之簽名、蓋章或按指印為「不知或不記憶」之陳述者
  • 當事人對自己之簽名、蓋章或指印，不積極否認，亦不承認，而陳述「不知道」、「不記得」、「沒印象」。
不宣示者，於公告時確定
  • 若未宣示，則於公告時確定。
判決確定證明書之付與
  • 當事人得聲請判決確定證明書；原則上由第一審法院付與，卷宗在上級法院者由上級法院付與。
  • 判決確定證明書應於7日內付與；裁定亦準用。
當事人得聲請法院，付與判決確定證明書
  • 判決確定證明書：證明判決已確定之公文書。
判決確定證明書，由第一審法院付與之。但卷宗在上級法院者，由上級法院付與之
  • 原則上由「第一審法院」付與。
  • 若卷宗已送交上級法院（如第二審、第三審），則由上級法院付與。
判決確定證明書，應於聲請後七日內付與之
  • 七日內：自聲請之日起算。
前三項之規定，於裁定確定證明書準用之
  • 裁定確定證明書亦適用本條規定。
例1.
  • 第一審判決確定後，當事人向第一審法院聲請確定證明書。
  • 法院於聲請後7日內付與確定證明書。
既判力之範圍
  • 確定終局判決就經裁判之訴訟標的有既判力。
  • 主張抵銷之請求經裁判者，以主張抵銷之額為限，有既判力。
除別有規定外，確定之終局判決就「經裁判之訴訟標的」，有既判力
  • 經裁判之訴訟標的：判決所裁判之法律關係。
  • 既判力：當事人不得再起訴，法院不得為相反裁判。
主張抵銷之請求，其成立與否經裁判者
  • 被告主張抵銷，法院就抵銷之請求「成立與否」已為裁判。
以「主張抵銷之額為限」，有既判力
  • 在「主張抵銷之金額」範圍內，有既判力。
例1.
  • 甲訴乙給付貨款，判決確定後，甲不得再就同一貨款起訴。
例2.
  • 甲訴乙給付100萬元，乙主張以50萬元債權抵銷，法院認抵銷成立，就該50萬元有既判力。
既判力之主觀範圍
  • 確定判決除當事人外，及於訴訟繫屬後之繼受人、為當事人占有標的物者，及為他人而為訴訟之該他人；假執行亦準用。
確定判決，除當事人外，
  • 原則上及於當事人。
擴張對象1.「訴訟繫屬後」為當事人之「繼受人」者
  • 繼受人：如繼承人、受讓人（債權讓與、物權讓與）。
擴張對象2.為當事人或其繼受人占有請求之標的物者
  • 占有標的物者：如保管人、受託人。
擴張效果：既判力及於該等人
為他人而為原告或被告者之確定判決，對於該他人亦有效力
  • 如遺產管理人、破產管理人、選定當事人。
  • 既判力及於被代表之「他人」。
前二項之規定，於假執行之宣告準用之
例1.
  • 甲訴乙給付貨款，判決確定後，乙死亡，其繼承人丙受既判力拘束。
  • → 繼受人
例2.
  • 遺產管理人甲起訴，判決確定後，對繼承人乙亦有效力。
  • → 為他人訴訟
外國法院確定判決之承認要件
  • 外國法院確定判決，若有無管轄權、未應訴、違反公序良俗或無相互承認等情形之一，台灣法院不承認其效力；外國裁定亦準用。
外國法院之確定判決，有下列情形之一者，不認其效力：
  1. 依中華民國之法律，外國法院「無管轄權」
  2. 敗訴之「被告未應訴」（若已合法送達，則不在此限）
  3. 判決之內容或訴訟程序，「有背公共秩序或善良風俗」
  4. 與我國無相互之承認
