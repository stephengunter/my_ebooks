民事訴訟法 通常訴訟程序-言詞辯論之準備

言詞辯論之準備

言詞辯論準備書狀之提出與通知
  • 開庭前要用書狀把主張寫清楚，自己直接寄給對方；對方若說沒收到，你就要提出送達證明。
當事人因準備言詞辯論之必要
  • 適用主體：兩造當事人（不限原告或被告）
  • 「必要」是指為了使言詞辯論能聚焦、有效率地進行，例如案件事實複雜、爭點眾多、證據繁雜時。若案件極簡單（如小額訴訟），法院得不要求書狀先行。
應以書狀記載攻擊防禦方法
  • 攻擊方法：原告用以支持自己請求的事實、法律觀點及證據（如「被告於某日借款50萬元未還，有借據為證」。
  • 防禦方法：被告用以反駁或消滅原告請求的事實、法律觀點及證據（如「我已清償」、「時效消滅」）。必須具體記載，不能空泛（例如僅寫「被告否認」）。
及對於他造之聲明、攻擊防禦方法之陳述
  • 除了提出自己的主張，還必須針對對方已經提出的聲明（例如原告的訴之聲明）及對方的主張進行回應。
  • 例如：原告提出準備書狀後，被告的答辯狀必須針對原告的主張逐點回應。這樣可以讓法院在開庭前就掌握雙方的爭執所在。
「提出於法院」，並以繕本或影本直接「通知他造」
  • 雙重送達義務：一是將書狀正本提交給法院（給法官及卷宗）。二是將書狀的副本（繕本）或影本「直接」通知他造，不經過法院轉送。
他造「否認收到」書狀繕本/影本時，由「提出書狀」之當事人「釋明」之
  • 舉證責任分配：若他造否認收到書狀（例如主張「你寄的信我沒收到」），提出書狀的一方必須「釋明」已經完成通知。
例1.
  • 甲起訴乙請求返還借款100萬元。甲於起訴狀僅簡要記載借款事實。
  • 法院定言詞辯論期日後，甲認為有必要補充詳細事證，於是提出「準備書狀」， 載明借款日期、金額、交付方式、約定還款日及借據影本，並將繕本掛號郵寄給乙。
  • → 提出準備書狀
例2.
  • 甲主張已將準備書狀繕本寄給乙（平信），乙否認收到。
  • 甲無法提出掛號回執或其他證明。法院要求甲釋明，甲提不出證據。
  • 法院可能認定該書狀未合法送達乙， 不將該書狀內容作為審理依據，或命甲重新送達。
  • → 他造爭議未收到與釋明
準備書狀與答辯狀之應記載事項
  • 原告要寫清楚告人的事實、理由、所有證據及對被告主張的回應；被告比照辦理，且要附證據影本、直接寄給對方。
原告準備言詞辯論之書狀，應記載下列事項：
  1. 請求所依據之事實及理由
    • 事實：具體時、地、人、物、行為。例如「民國113年3月15日，被告向原告借款新臺幣50萬元，約定113年6月15日返還，原告當日交付現金，被告簽發借據乙紙（如附件1）」
    • 理由：法律依據（如「依消費借貸法律關係請求返還」）或法理依據。
  2. 證明應證事實所用之證據。如有多數證據者，應全部記載之
    • 應證事實：指第一款的待證事實。
    • 證據：包括人證（證人姓名、地址）、書證（文件編號、名稱）、物證、鑑定等。
    • 全部記載：不能隱藏部分證據留待開庭時突襲。此為「證據揭示義務」。
  3. 對他造主張之事實及證據為承認與否之陳述；如有爭執，其理由
    • 針對被告已經提出的主張（若被告已提出答辯狀）或針對被告可能的主張（預先回應），原告須表明承認或爭執。
    • 若爭執，須附理由。例如：「被告主張已清償50萬元，原告否認之，理由：被告未提出任何還款證明，原告帳戶亦無該筆入款紀錄。」
被告之答辯狀，應記載下列事項：
  1. 答辯之事實及理由
    • 被告用以反駁原告請求的事實及法律理由。
    • 例如「原告主張之50萬元實為贈與，並非借貸」、「該筆借款已於113年7月10日以現金清償完畢，有收據為證」。
  2. 證明應證事實所用之證據。如有多數證據者，應全部記載之
  3. 對他造主張之事實及證據為承認與否之陳述；如有爭執，其理由
書狀應添具所用書證之影本，提出於法院，並以影本直接通知他造
  • 若書狀中引用書證（如借據、契約、收據、診斷證明），必須將該書證的影本附在書狀後面（作為附件），一併提交法院。
  • 同時，要把這些書證影本的副本（或另行影印）直接寄給對造。這確保他造能實際看到證據內容，而非僅知證據名稱。
準備書狀與答辯狀之提出期間
  • 被告收受起訴狀後10日內要提答辯狀，最晚不能開庭前5日。
  • 補充書狀最晚開庭前5日。
  • 再回應書狀最晚開庭前3日。
  • 逾期可能被法院拒收。
被告答辯狀，應於十日內提出。並以繕本/影本徑送原告。最遲應在言詞辯論期日五日前提出
  • 十日內提出：從被告「收受訴狀」之翌日起算10日。
  • 若法院已經定了言詞辯論期日，被告提出答辯狀的最晚期限是「開庭日5天前」。
應通知他造使為準備之事項，有未記載於訴狀或答辯狀者
  • 指當事人（原告或被告）在最初的訴狀或答辯狀中，漏掉了某些應該讓對方知道的重要事項（例如新的事實、新的法律主張、新的證據）。
當事人應於他造得就該事項進行準備所必要之期間內，提出記載該事項之準備書狀於法院
  • 提出時間必須是「他造可以進行實質準備的合理期間內」，由法院依個案判斷（例如事項複雜需要2週，簡單事項可能3天即可）。
如已指定言詞辯論期日者，至遲應於該期日五日前為之
  • 無論如何，不能超過開庭前5日才提出補充書狀。這是「絕對底線」。
對於前二項書狀所記載事項再為主張或答辯之準備書狀
  • 當事人收到對方的第一層或第二層書狀後，想要針對其中的內容再提出補充主張或再答辯（例如原告對被告的答辯狀提出「再準備書狀」反駁）。
當事人應於收受前二項書狀後五日內提出於法院
  • 從收到對方書狀的翌日起算5日內要提出。
並以繕本或影本直接通知他造；如已指定言詞辯論期日者，至遲應於該期日三日前為之
  • 同樣要自行通知對造。若有指定開庭日，最晚必須在開庭前3日提出。
例1.
  • 甲於4月1日起訴乙，起訴狀於4月3日送達乙。法院定6月10日為言詞辯論期日。
  • 乙於4月12日提出答辯狀（收受後9日），並將繕本寄給甲。
  • → 被告答辯狀，應於十日內提出。並以繕本/影本徑送原告。最遲應在言詞辯論期日五日前提出
例2.
  • 法院定5月10日開庭。被告於5月6日才提出答辯狀（距開庭僅4日）。
  • 違反第267條第1項後段「至遲應於該期日五日前為之」（5月10日開庭，最晚應為5月5日）。
  • 法院得依第268條之2，不審酌該答辯狀內容，或命被告負擔費用。
  • → 答辯狀最遲應在言詞辯論期日五日前提出
例3.
  • 甲於4月1日提出準備書狀，乙於4月6日收受。
  • 乙於4月10日提出再答辯狀（收受後4日，符合5日內）。
  • 法院定5月20日開庭，乙於5月18日才提出「再再答辯狀」（距開庭僅2日）。
  • 違反第267條第3項後段「至遲應於該期日三日前為之」（最晚5月17日）。法院得不審酌該書狀。
  • → 第三層書狀3日底線
審判長命提出書狀之權限
  • 法官如果覺得書狀沒寫好、準備不夠，可以訂期限強制當事人補齊、寫清楚、列證據——不遵守的話，後續可能不准再提出。
審判長如認言詞辯論之「準備未足」
  • 審判長的裁量權。判斷標準包括：
    • 當事人提出的書狀是否欠缺具體事實、理由或證據（違反第266條）。
    • 當事人間的爭點是否仍不明確。
    • 是否有必要調查特定證據等。
得定期間命當事人提出記載完全之準備書狀或答辯狀
  • 記載完全：具體記載事實、理由、證據及對對造主張之回應。不得再有明顯缺漏或空泛陳述。
並得命其就特定事項詳為表明或聲明所用之證據
  • 更進一步的具體指示。審判長可以針對案件中某個關鍵爭點，要求當事人詳細說明其主張（詳為表明），或具體列出要用的證據。
  • 例如「被告是否已清償借款？」「原告是否與有過失？」
例1.
  • 甲起訴乙返還借款，準備書狀僅寫「乙向甲借款50萬元未還」，未載明借款日期、交付方式，也未附任何證據。
  • 審判長認為準備尚未充足，裁定命甲於15日內提出「記載完全之準備書狀」，應具體載明借款日期、地點、交付方式、還款約定，並聲明證據（如借據、匯款單、證人）。
  • → 審判長命補正準備書狀
例2.
  • 甲起訴乙侵權行為，主張乙駕車撞傷甲。乙提出答辯狀稱「甲與有過失」。
  • 審判長認為「與有過失」的具體態樣不明，命乙於10日內「詳為表明」甲與有過失的事實（例如甲闖紅燈、未注意車前狀況），並提出證據（如行車紀錄器畫面、現場圖）。
  • → 審判長命就特定事項詳為表明
書狀先行後之期日與爭點整理
  • 書狀換完後，法官要趕快開庭，帶著雙方整理爭點並簡化；必要時要交一份簡明、分項、不抄襲原書狀的爭點摘要。
「書狀先行後」，審判長或受命法官應「速定」言詞辯論期日或準備程序期日
  • 「言詞辯論期日」是直接進行辯論的庭期。
  • 「準備程序期日」是先由受命法官整理爭點、調查證據，再交由言詞辯論。複雜案件多先定準備程序。
法院於前項期日，應使當事人整理並協議簡化爭點
  • 簡化的方式：排除無爭議事項、限縮證據調查範圍、協議自認或不爭執事項。
  • 經雙方協議簡化後的爭點，對當事人有拘束力（第270條之1第3項），不得事後任意翻異。
審判長於必要時，得「定期間命」當事人就「整理爭點」之結果提出「摘要書狀」
  • 若爭點繁雜或當事人記憶不清，審判長可命當事人將整理後的爭點寫成摘要書狀。
  • 「必要時」由審判長裁量，通常在案件複雜、爭點超過5個以上時使用。
爭點摘要書狀，應以簡明文字，「逐項分段」記載，不得「概括引用」原有書狀或言詞之陳述
  • 對摘要書狀的形式要求。這是為了強迫當事人親手濃縮爭點，並讓法院不需翻閱厚厚卷宗就能掌握核心。
  • 不得概括引用：不能只寫「如原告準備書狀所載」或「如被告言詞所述」，必須自己重新整理。
例1.
  • 甲起訴乙請求給付工程款200萬元。經過書狀先行程序後，受命法官訂定準備程序期日。
  • 當日，法官引導雙方列出爭點：1. 工程是否已驗收完成？2. 乙主張的瑕疵是否存在？3. 瑕疵是否可歸責於甲？4. 乙是否有權扣款50萬元？
  • 雙方協議將爭點1（驗收）簡化為「雙方確認工程於113年1月15日完工，但就驗收程序是否符合契約約定，仍有爭議」。
  • → 準備程序整理爭點
例2.
  • 爭點繁雜多達12項，審判長命兩造於10日內各自提出爭點摘要書狀。
  • 甲提出書狀，分12段逐項記載，每項以2至3行說明，未引用原起訴狀。
  • 乙提出書狀，內容寫「詳如被告答辯狀第3頁至第10頁」。
  • 乙違反「不得概括引用」規定，法院得命乙重提。
  • → 審判長於必要時，得「定期間命」當事人就「整理爭點」之結果提出「摘要書狀」
未依規定提出書狀或聲明證據之處理
  • 沒按時交書狀，法院會先要你說明理由；不說明的話，可能不准你再提（失權），或判決時對你做不利認定。
當事人未依規定提出書狀或聲明證據者，法院得依聲請或依職權命該當事人以書狀說明其理由
  • 未依規定提出書狀：
    • 未於期限內提出答辯狀、補充書狀或再回應書狀。
    • 未依審判長所定期間提出記載完全的準備書狀或答辯狀，或未就特定事項詳為表明或聲明證據。
    • 未依審判長所定期間提出爭點摘要書狀。
  • 命以書狀說明理由：當事人應解釋為何未按時提出書狀或證據（如不可歸責事由、證據尚在蒐集中等）。
當事人未依前項規定說明者，法院得準用「失權效」規定或於判決時依全辯論意旨斟酌之
  • 未依前項規定說明：指法院已命說明，但當事人逾期未提出說明書狀，或提出的說明內容空泛、顯無理由（例如僅寫「我不想提」）。
  • 第276條的失權效內容：當事人不得再主張該未提出之事項（包括事實、證據方法）。法院亦不得依職權調查該事項。
    • 準用後的效果：違反書狀提出義務的當事人，將失去在後續程序（包括言詞辯論）中提出該攻擊防禦方法的權利。這是一個非常嚴厲的制裁。
    • 例外：該事項為法院應依職權調查者、該事項不甚延滯訴訟、或因不可歸責於當事人之事由不能提出。
  • 全辯論意旨：指法院在判決時可以綜合考量訴訟過程中所有情況，包括當事人是否積極提出書狀、是否拖延訴訟、是否妨礙他造防禦等。
    • 法院可以將「當事人未提出書狀」這件事，作為對該當事人不利認定的一個因素。
    • 例如：原告未依期限提出借據，法院在判決時可因此認定原告舉證不足，判其敗訴。這個效果雖比失權效輕，但仍有實質殺傷力。
例1.
  • 法院依第268條命甲於15日內提出記載完全的準備書狀，甲逾期5日仍未提出。
  • 乙聲請法院命甲說明理由。法院裁定命甲於7日內以書狀說明為何逾期。
  • 甲提出說明書狀，主張因車禍住院10日，無法如期提出書狀，並附上診斷證明。
  • 法院認為理由正當，准予延長期間，未予制裁。
  • → 命說明理由。正當理由，不制裁
例2.
  • 法院命甲說明逾期理由，甲置之不理，未提出任何說明書狀。
  • 法院依第268-2條第2項準用第276條，裁定甲不得再提出原應於期限內提出之準備書狀及證據。
  • 甲於後續言詞辯論期日欲提出該書狀，法院拒絕審酌。
  • → 未說明，準用失權效
例3.
  • 甲未依期限提出爭點摘要書狀（違反第268-1條第3項），法院命說明理由，甲僅回覆「沒空寫」。
  • 法院未動用失權效，但在終局判決理由中載明：「原告甲無正當理由未依期限提出爭點摘要書狀，致爭點整理困難，本院依全辯論意旨，認其主張之某項事實舉證不足，不予採信。」
  • → 未說明，依全辯論意旨斟酌
言詞辯論前之準備處置
  • 為了讓開庭辯論更順利，法官可以在開庭前就要求當事人、證人、鑑定人到場，交出文件，到現場勘驗，或派其他法官先查證據。
法院因使辯論易於終結，認為必要時，得於言詞辯論前，為下列處置：
  1. 命當事人或法定代理人本人到場
    • 法院可以命令當事人（原告、被告）或其法定代理人（如未成年人的父母）親自到法院。若無正當理由不到場，法院可能依第360條處以罰鍰，或依第367條之1作為全辯論意旨的參考。
  2. 命當事人提出文書、物件
    • 法院可以命令當事人交出持有的文件（如契約、診斷證明、會計帳簿）或物品（如產品、照片、錄音檔）。
    • 若當事人無正當理由拒不提出，法院得依第345條認定他造主張之事實為真實（舉證責任倒置）。
  3. 通知證人或鑑定人及調取或命第三人提出文書、物件
    • 法院可以傳喚證人、鑑定人到場（準備訊問），也可以向「第三人」（非當事人）調取或命令其提出文書、物件（例如銀行帳戶明細、警察局的車禍現場圖）。
    • 第三人也受強制力拘束，無正當理由不提出，法院得依第349條處以罰鍰。
  4. 行勘驗、鑑定或囑託機關、團體為調查
    • 「勘驗」：法官親自到現場查看（如查看房屋漏水、土地界址、車輛毀損狀況）。
    • 「鑑定」：委請專家（如建築師、醫師、會計師）就特定事項提出專業意見。
    • 法院也可以「囑託」政府機關（如地政事務所、車輛行車事故鑑定委員會）或民間團體進行調查。
  5. 使受命法官或受託法官調查證據
    • 「受命法官」：同一法院內，由審判長指定其中一位法官（通常是陪席法官）專門負責調查證據。
    • 「受託法官」：如果證據在遙遠的法院轄區（如證人住高雄，案件在台北地院），台北地院可以囑託高雄地院的法官代為訊問證人。這可以節省證人長途跋涉的時間與費用。
例1.
  • 甲起訴乙返還借款，乙抗辯「甲交付的款項是賭債，法律上不得請求返還」。
  • 法院認為需要直接訊問甲、乙本人以了解交付過程，於言詞辯論前命令甲、乙本人到場接受訊問。
  • → 命當事人本人到場
例2.
  • 甲起訴乙請求給付工程款，主張乙曾出具驗收合格證明。乙否認。
  • 法院向擔任監造的丙工程顧問公司（第三人）調取該工程的驗收報告。
  • → 命第三人提出文書
例3.
  • 甲主張乙搭建的違建占用甲的土地。
  • 法院在言詞辯論前，會同地政機關人員及兩造，到現場測量、拍照，製作勘驗筆錄及現場圖。
  • → 行勘驗
受命法官與準備程序
  • 合議案件可指定一位受命法官負責準備程序，把爭點整理清楚。
  • 準備程序原則上不查證據，但四種例外（在外地、法院外、證據恐滅失、兩造同意）可以查。
行「合議審判」之訴訟事件，法院「於必要時」以庭員一人為「受命法官」，使行「準備程序」
  • 適用前提：案件屬於「合議審判」（通常訴訟程序中，標的金額超過50萬元或案情複雜，由地方法院民事庭以3位法官合議）。
  • 「必要時」：指案情繁雜、爭點眾多、有行準備程序以整理爭點之必要，由法院裁量。
  • 必要時，法院（合議庭）從3位庭員中指定其中1人為「受命法官」，授權他進行準備程序。
原則：準備程序，以「闡明訴訟關係」為止
  • 原則上，準備程序進行到訴訟關係已經明確、可以進行言詞辯論時，就應終結。
  • 「闡明訴訟關係」：指釐清原告的訴訟標的及訴之聲明、被告的抗辯內容、整理兩造不爭執事項與爭執事項、確認證據調查的必要性與順序。
例外：法院命於準備程序調查證據者，不在此限
  • 若合議庭認為有必要，可以「命」受命法官在準備程序就調查證據。
命受命法官調查證據，以下列情形為限
  1. 有在證據所在地調查之必要者
    • 證據（如待勘驗的土地、建物、機器）位於遠方，若要等到言詞辯論期日由合議庭全體前往，耗費過鉅。由受命法官一人前往勘驗，較有效率。
  2. 依法應在法院以外之場所調查者
    • 必須在法院外進行的證據調查。例如現場履勘、現場模擬。
  3. 於言詞辯論期日調查，有致證據毀損、滅失或礙難使用之虞，或顯有其他困難者
    • 例如證物即將腐敗、證人重病恐無法到庭、保存期限將屆等急迫情形。
  4. 兩造合意由受命法官調查者
    • 雙方當事人同意由受命法官調查證據，法院應尊重。
書狀就審期間規定，於行準備程序準用之
  • 準備程序的期日通知書應與相關書狀一併送達他造，且距準備程序期日至少應有10日就審期間（若有急迫情形不在此限）。
例1.
  • 原告甲主張有一紙關鍵借據原本，但該借據因潮濕有霉爛之虞（可能滅失）。
  • 合議庭命受命法官於準備程序即行調查該借據，王法官於準備程序期日命甲提出借據原本，當場勘驗並記明筆錄。
  • → 受命法官調查證據（有致證據毀損滅失之虞）
例2.
  • 甲起訴乙請求拆屋還地，爭執點在於乙的房屋是否占用甲的土地。
  • 受命法官至現場履勘、測量，並製作勘驗筆錄及現場圖。
  • → 受命法官至現場勘驗（依法應在法院以外之場所調查）
受命法官整理爭點與協議簡化之權限
  • 受命法官可以在非公開場合，引導雙方整理、簡化、協議爭點。
  • 協議後雙方受拘束不能反悔，除非雙方同意或有不可歸責的新事由。
受命法官為「闡明」訴訟關係，得為下列各款事項，並得「不用公開」法庭之形式行之
  1. 命當事人就準備書狀記載之事項為說明
    • 受命法官可要求當事人針對已經提出的書狀內容，進行口頭補充說明，讓模糊的地方變清楚。
  2. 命當事人就事實或文書、物件為陳述
    • 可要求當事人當場陳述與案件相關的事實，或提出文書、物件並說明其內容。
  3. 整理並協議簡化爭點
    • 「整理」：受命法官協助雙方釐清哪些事項有爭執、哪些無爭執。
    • 「協議簡化」：引導雙方合意將爭點數量減少、範圍縮小、或以某項事實替代某項爭點。例如雙方同意「被告於某日有收到原告交付之款項」此一事實，不再爭執金額。
  4. 其他必要事項
    • 概括條款，例如試行和解、確認證據調查方式等，只要是為闡明訴訟關係所必要。
受命法官於行前項程序認為「適當時」，「得暫行退席」或命當事人暫行退庭
  • 法官可以暫時離開（退席），或請當事人暫時離開法庭（退庭）。
    • 讓雙方在沒有法官在場壓力下，進行較為自由、坦誠的協商。這在複雜案件中非常有用。
或指定「七日以下」之期間，命當事人就爭點，或其他有利於訴訟終結之事項，「為簡化之協議」，並共同「向法院陳明」
  • 受命法官可指定一個「7天以內」的期間（例如3天、5天），要求雙方當事人（通常是透過律師）自行私下協商：
    • 針對爭點或有利訴訟終結的事項（如證據調查方式、可否部分和解）達成簡化協議。
    • 然後「共同」向法院陳報協議結果。若無法達成協議，也應陳明。
指定期間「命當事人為協議」者，以「二次為限」
  • 若第一次7天內無法達成協議，法官可再指定第二次（仍為7天內）。
    • 但不得超過兩次。這避免程序無限拖延。
當事人就其主張之「爭點」，經「達成協議」後，應「受其拘束」
  • 雙方一旦達成爭點簡化協議（不論是在法官面前協議，或是依第二項私下協議後陳報），就產生「拘束力」。
    • 雙方不得在後續程序中再推翻該協議，主張新的爭點或否認已協議的事項。這是「爭點效」的明文依據。
例外不受拘束：1.經兩造「同意變更」2.因「不可歸責」於當事人之事由 3.顯失公平
  • 例外一：雙方可以合意變更協議內容（事後共同同意修改）。
  • 例外二：發生不可歸責於雙方的事由，導致原協議基礎動搖，當事人可不受拘束。例如關鍵證人突然死亡、新證據於協議後才發現。
  • 例外三：若協議內容明顯不公平，法院可依職權或聲請，宣告不受拘束。例如一方被詐欺、脅迫，或協議結果嚴重違反正義。
例1.
  • 受命法官為避免當事人在公開法庭對立過深，將雙方律師及當事人請到法官辦公室（非公開法庭），進行爭點整理及協議。
  • → 非公開法庭形式，進行爭點整理及協議
例2.
  • 受命法官認為爭點繁雜，當庭協商不易，依本條指定雙方於7日內自行協議簡化爭點，並共同向法院陳明。
  • 雙方於第5日共同陳報達成協議。
  • → 指定期間私下協議
例3.
  • 雙方曾協議「不爭執被告於事故當日有駕車經過現場」此一事實。
  • 訴訟後期，原告突然取得行車紀錄器，證明被告根本不在現場，原告欲推翻原協議。
  • 符合第270-1條第3項但書「因不可歸責於當事人之事由」（新證據於協議後始發現），原告不受該協議拘束
  • → 協議之拘束力與例外
準備程序筆錄之應記載事項
  • 準備程序必須製作筆錄，記載雙方的主張、回應、以及最重要的「整理爭點結果」——哪些不吵、哪些是關鍵爭點，都要寫清楚。
準備程序筆錄應記載下列各款事項
  1. 當事人之聲明及所用之攻擊防禦方法
    • 「聲明」：指原告的訴之聲明（例如「被告應給付原告新臺幣100萬元」）及被告的聲明（例如「原告之訴駁回」）。
    • 「攻擊或防禦方法」：指當事人所主張的事實、法律觀點、證據方法等。例如原告陳述「被告於某日向我借款50萬元，有借據為證」；被告陳述「該借款已於某日清償」等。
  2. 對於他造之聲明及攻擊防禦方法之陳述
    • 必須記錄他造針對對造的主張所做的回應。這有助於釐清兩造間的爭執與不爭執事項。
  3. 整理爭點之結果、其他必要事項
    • 整理爭點之結果，以及命當事人說明書狀、陳述事實或文書物件、整理並協議簡化爭點、其他必要事項。
例1.
  • 準備程序中，雙方已清楚協議將爭點簡化為2項，但書記官漏未記載，筆錄僅記載雙方聲明及攻防方法。
  • 後續言詞辯論時，乙突然就「已協議簡化捨棄」的第3項爭點再為主張。甲異議，但筆錄無記載，難以證明曾協議。
  • → 筆錄漏未記載爭點整理結果，導致協議效力不明確，增加訴訟爭議
例2.
  • 準備程序筆錄記載：受命法官詢問雙方有無其他證據聲請，甲稱「目前沒有」。
  • 言詞辯論期日，甲突然提出一份新證據（證人丙）。
  • 法院審酌準備程序筆錄，認定甲於準備程序未主張該證據，且無正當理由，依第276條不予審酌。
  • → 準備程序筆錄作為失權效依據
獨任審判準用準備程序筆錄與整理爭點之規定
  • 獨任法官（一人審理）也可以比照合議庭的準備程序，進行爭點整理、協議簡化、非公開協商，並製作詳細筆錄。
受命法官行準備程序時準用之法院或審判長權限
  • 受命法官在準備程序中，可以準用一大串原本屬於法院或審判長的權限（除了命供擔保和命補正起訴要件須經兩造同意），讓他能有效主導程序。
準備程序期日一造不到場之處理
  • 準備程序一方沒來，法官繼續對來的那方開庭，再把筆錄寄給沒來的。
  • 除非有必要，否則法官可以直接終結準備程序，不再另開庭。
當事人之「一造」，於「準備程序場」之期日「不到場」者，「應」對於到場之一造，「行準備程序」，「將筆錄送達」於未到場人
  • 適用前提：準備程序期日（非言詞辯論期日），原告或被告其中一方未到場。不到場原因不限於無正當理由（即使有正當理由，如生病、天災，本條同樣適用——因為準備程序仍應進行）。
    • 若兩造均不到場，則不適用本條（受命法官應另定期日或報請審判長處理）。
  • 應對於到場之一造，行準備程序：受命法官不能因為一方缺席就「撤銷期日」或「停止程序」。必須繼續開庭，對有來的一方進行準備程序的所有必要事項：例如訊問其聲明、攻擊防禦方法、整理其主張、確認其證據等。
  • 將筆錄送達於未到場人：關鍵的程序保障。準備程序結束後，書記官應將該次期日的筆錄（記載了到場方的陳述、受命法官的整理結果等）製作繕本，送達給未到場的當事人。
    • 讓他能夠知悉準備程序的進行內容，並有機會在言詞辯論時表示意見或提出反駁。
前項情形，除有另定新期日之必要者外，受命法官「得終結準備程序」
  • 受命法官的裁量權：得終結準備程序。
  • 原則上，在一造不到場且已對到場方進行準備程序、筆錄送達後，受命法官可以「終結準備程序」，不再另行開庭。
  • 但若受命法官認為「有必要繼續準備程序」，則另定新期日繼續準備程序。例如：缺席方有正當理由且已事先請假；或爭點仍不明確，需要缺席方親自到場陳述；或法律規定必須兩造同時在場才能進行某事項。
例1.
  • 準備程序期日，原告甲依約到場，被告乙無正當理由未到場。
  • 受命法官對甲進行準備程序，訊問其請求依據、證據，並整理爭點。
  • 筆錄製作完成後，法院將筆錄繕本送達乙。
  • 受命法官認為乙不到場，爭點已經因甲的陳述而明確，無另定期日之必要，當庭諭知「準備程序終結」。
  • → 一造不到場，繼續行準備程序並終結
例2.
  • 原告甲到場，被告乙未到場，但乙前一天已傳真請假單，表明因重病住院，並附診斷證明。
  • 受命法官對甲行準備程序後，認為乙本人對於「契約是否成立」此一爭點有親自說明的必要，因此另定一個月後的新準備程序期日，並通知乙到場。
  • → 一造不到場，但另定新期日
準備程序之終結與再開
  • 準備程序結束時要當場告訴雙方並記在筆錄裡。
  • 之後若有需要，法官或法院可以決定「再開」準備程序。
準備程序至「終結」時，「應告知」當事人，並「記載於筆錄」
  • 終結的認定時點：當受命法官認為訴訟關係已經闡明、爭點已整理明確、無進一步準備之必要時，即達到終結狀態。
    • 此時，受命法官必須在準備程序期日當場，以言詞告知到場的當事人（或透過代理人）「準備程序終結」。
    • 若當事人未到場（如一造不到場情形），則應將終結的意旨連同筆錄送達。
  • 並記載於筆錄：告知後，書記官應將「受命法官告知準備程序終結」一事及當事人有無異議等，明確記載於準備程序筆錄中。此記載是日後判斷「失權效」起算點的重要證據。
受命法官或法院「得命再開」已終結之準備程序
  • 再開的主體：受命法官（若案件仍在其手中）或法院（合議庭，若案件已移由合議庭進行言詞辯論）。
  • 再開的原因：例如發現新證據、發現先前整理之事實有重大錯誤或遺漏、有必要再調查某證據、當事人提出正當理由請求再開等。
  • 再開後，準備程序重新進行，先前已整理的爭點原則上仍有效，但當事人可補充新主張。
例1.
  • 受命法官經過三次準備程序，已將雙方爭點整理為三項，並確認證據都已提出。
  • 法官當庭告知兩造：「本件準備程序終結，將移由合議庭行言詞辯論。」書記官將此告知記明於筆錄，兩造及法官簽名。
  • → 告知終結準備程序並記明筆錄
例2.
  • 準備程序終結後第五天，原告甲發現一份關鍵的借據原本（先前以為遺失，現在找到了），可能影響判決結果。
  • 甲緊急向受命法官聲請再開準備程序，以提出該借據。
  • 受命法官審酌後認為該證據確有重大影響，且非可歸責於甲，裁定再開準備程序。
  • → 終結後再開準備程序
言詞辯論時準備程序要領之陳述
  • 準備程序後開庭，雙方要口頭摘要準備程序的結果。審判長可以直接請書記官朗讀筆錄來代替，更省事。
於「準備程序後」，行「言詞辯論時」，當事人「應陳述」準備程序之「要領」
  • 適用時點：準備程序已經終結（依第274條），案件進入合議庭言詞辯論的第一次期日（或後續期日，但通常指第一次言詞辯論期日）。
  • 原則：由當事人（通常是原告先、被告後）以口頭方式，簡要說明準備程序中發生的重要事項。所謂「要領」，指準備程序的核心結果，包括：
    • 雙方不爭執的事項（如「雙方同意被告於某日收到款項」）。
    • 整理的爭點。
    • 已提出的證據與證據調查聲請。
但審判長得令書記官「朗讀」準備程序「筆錄」代之
  • 審判長可以裁量，不讓當事人口頭陳述，而直接由書記官朗讀準備程序筆錄的全部或摘要。朗讀後，視同當事人已盡陳述義務。此方式更為客觀、完整、省時。
例1.
  • 準備程序終結後，合議庭行言詞辯論。審判長請原告先陳述準備程序要領。
  • 原告律師站起來說：「在準備程序中，兩造不爭執被告於113年1月10日收受原告匯款100萬元； 爭點僅有二：第一，該款項性質為借款或投資？第二，借據是否為被告簽署。雙方已提出借據、匯款單及證人甲。」
  • 被告律師接著為相同要領之陳述。
  • → 當事人陳述準備程序要領
例2.
  • 審判長為節省時間，直接指示書記官：「請朗讀準備程序筆錄中關於整理爭點之部分。」
  • 書記官朗讀筆錄所載之「兩造不爭執事項」及「爭執事項」。
  • 朗讀完畢，審判長確認兩造無補充。
  • → 朗讀筆錄替代
準備程序之失權效
  • 準備程序沒講的事，之後開庭原則上不准再講。
  • 除非法院該主動查、不會拖太久、不是你的錯、或不准會很不公平。
原則：「準備程序未主張」之事項，行「言詞辯論時，不得主張」之
  • 未於準備程序主張之事項：當事人在準備程序期間（從受命法官開始行準備程序，到依第274條宣告準備程序終結為止） 沒有提出的攻擊或防禦方法。包括：
    • 完全未提出的新事實。
    • 未提出的新證據（如證人、書證）。
    • 未提出的法律上抗辯（如時效抗辯、同時履行抗辯）。
  • 言詞辯論時，不得主張：法律效果：失權。當事人不能在言詞辯論期日再提出這些事項。如果硬要提出，法院應依職權不予審酌（他造亦可異議）。
例外：有下列情形之一者，仍得主張
  1. 法院應依職權調查之事項
    • 不管當事人有沒有提出，法院都有義務主動調查的事項。例如：訴訟成立要件（當事人能力、訴訟能力、審判權、管轄權）等。
  2. 該事項「不甚延滯」訴訟者
    • 法院應判斷：若准許當事人提出該事項，是否會造成訴訟明顯拖延？若法院認為「影響不大」，可准許提出。
    • 判斷標準包括：事項的複雜程度、所需證據調查時間、提出時點（如言詞辯論初期或後期）、他造是否須另為準備等。
  3. 因「不可歸責」於當事人之事由不能於準備程序提出者
    • 不可歸責事由包括：天災、重病住院、證據在國外且來不及調取、關鍵證人突發重病無法到庭、對造惡意隱匿證據等。
    • 主張此款者，應「釋明」不可歸責事由（提出即時可調查的證據）。
  4. 依其他情形「顯失公平」者
    • 顯失公平：概括衡平條款。法院有裁量權。
    • 例如：若准許提出，雖有輕微延滯，但不准許提出將導致當事人實體權利嚴重受損，明顯違反正義。
例1.
  • 準備程序中，受命法官數次詢問被告有無證據聲請，被告均稱無。
  • 準備程序終結後，言詞辯論期日，被告突然提出一份證人丙的證詞（丙從未在準備程序被提及），且無正當理由。
  • 原告異議。法院審酌被告無釋明不可歸責事由，且該證詞涉及新事實，將延滯訴訟。依第276條本文，不准被告提出該證詞。
  • → 可歸責逾期提出
例2.
  • 準備程序終結後，原告在言詞辯論期日提出一項補強證據（原本已提出的書證的另一頁）。
  • 該證據僅一頁，且他造早已看過相關內容，無須額外調查。
  • 法院認為該事項「不甚延滯訴訟」，准許提出。
  • → 不甚延滯訴訟
例3.
  • 準備程序終結後，原告立即聲請提出一份關鍵錄音檔，並釋明：該錄音檔原儲存於損壞的手機中，準備程序時無法讀取，近日才修復完成取出。
  • 法院審酌確非可歸責於原告，准許提出。
  • → 例外——不可歸責
例4.
  • 準備程序終結後，被告突然發現原告提出的主要證物（契約書）係偽造，但該偽造事實極難提前發現。
  • 若不准被告提出偽造抗辯，被告將遭受極大不利益。法院認為顯失公平，准許提出。
  • → 例外——顯失公平
