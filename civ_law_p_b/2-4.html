民事訴訟法 第一審程序-小額訴訟程序

小額訴訟程序

小額程序之適用範圍
  • 10萬元以下之金錢、代替物或有價證券訴訟，適用小額程序；法院認不適當得改用簡易程序；50萬元以下得合意適用小額程序。
請求給付金錢/有價證券/其他代替物之訴訟，標的金額「10萬元以下」者，適用小額程序
  • 請求給付金錢、代替物或有價證券的訴訟，標的金額在「10萬元以下」，適用「小額程序」。
法院認適用小額程序為不適當者，「得依職權」以「裁定改用簡易程序」，並由「原法官繼續審理」。此一裁定，「不得抗告」
  • 如果法院認為適用小額程序「不適當」，可以依職權裁定改用「簡易程序」，由原法官繼續審理。
  • 對改用簡易程序之裁定，不得抗告。
第一項之訴訟，其標的金額50萬元以下者，得以當事人之「合意適用」小額程序，其合意應以文書證之
  • 請求給付金錢/有價證券/其他代替物之訴訟，標的金額在「50萬元以下」，雙方可以「合意」適用小額程序，但合意要用「文書」證明。
例1.
  • 甲請求乙給付8萬元，適用小額程序。
  • → 請求給付金錢，標的金額「10萬元以下」者，適用小額程序
例2.
  • 法院認小額程序不適當，裁定改用簡易程序。
  • → 法院認適用小額程序為不適當者，「得依職權」以「裁定改用簡易程序」
例3.
  • 甲、乙合意就30萬元之訴訟適用小額程序，並以文書證明。
  • → 合意適用
小額事件之管轄（排除合意管轄及債務履行地管轄）
  • 小額事件中，法人或商人以定型化契約條款約定債務履行地或合意管轄者，約定無效；但兩造均為法人或商人者不在此限。
小額事件當事人之「一造為法人或商人」者
  • 一方為法人（公司）或商人（獨資、合夥）。
於其預定用於同類契約之條款
  • 即「定型化契約條款」。
約定債務履行地或以合意定第一審管轄法院時
  • 約定「債務履行地」或「合意定第一審管轄法院」
該等約定不生管轄之效力
  • 約定無效。
但兩造均為法人或商人者，不在此限
  • 若雙方均為法人或商人，則仍可適用。
例1.
  • 甲公司以定型化契約與消費者乙約定合意管轄，該約定不適用。
  • → 一造為法人，約定無效
例2.
  • 甲公司以定型化契約與乙公司約定合意管轄，兩造均為法人，仍可適用。
  • → 兩造均為法人，仍可適用
小額程序之表格化訴狀
  • 依小額程序起訴時，當事人可以使用「表格化訴狀」（預先印好的表格），不一定要自己寫正式的起訴狀。表格的格式由司法院訂定。
小額程序之開庭時間
  • 小額程序可以在「夜間」或「星期日或其他休息日」開庭。但如果當事人提出「異議」，就不可以在這些時間開庭。
  • 夜間或休息日開庭的規則，由司法院訂定。
小額事件調解期日不到場之效果
  • 小額事件應調解者，一造於期日5日前受合法通知無故不到，法院得依聲請即為辯論，並依職權一造辯論判決；通知書應記載不到場效果。
適用情形：小額事件 → 依法應行調解程序 → 當事人一造於調解期日不到場
  • 依法應行調解程序：強制調解事件。例如交通事故、親屬財產權爭執。
要件：當事人5日前經合法通知、通知載明不到場效果、無正當理由不到場
  • 合法通知：須於調解期日5日前通知。
  • 不到場效果：法院得一造辯論判決。
  • 無正當理由：無不可歸責事由。
效果：依聲請 → 即為辯論 → 一造辯論判決
  • 依聲請：依到場當事人之聲請即為辯論。
例1.
  • 甲、乙小額事件應調解，乙於5日前受合法通知無故不到，法院依甲聲請命即為辯論，並一造辯論判決。
  • → 一造調解不到場，依聲請即為辯論，並一造辯論判決
小額程序之簡化證據調查
  • 小額程序中，經兩造同意或調查證據成本與請求顯不相當者，法院得不調查證據，逕審酌一切情況為公平裁判。
例1.
  • 甲、乙均同意不調查證據，法院逕為公平裁判。
  • → 兩造同意不調查證據
例2.
  • 甲請求1萬元，但鑑定費需10萬元，法院認顯不相當，不調查證據。
  • → 鑑定費用與請求顯不相當，不調查證據
小額程序之訴之變更、追加及反訴
  • 小額程序中，訴之變更、追加或反訴原則上僅得於10萬元以下範圍內為之；但當事人合意且法院認為適當者，不在此限。
例1.
  • 甲小額程序請求8萬元，追加至20萬元，未經合意，法院不允許。
  • → 追加超出10萬元以下範圍，未經合意，不得追加
例2.
  • 甲、乙合意就追加至15萬元繼續適用小額程序，法院認為適當。
  • → 合意繼續適用小額程序，法院認為適當
禁止為適用小額程序而為一部請求
  • 當事人不得為適用小額程序而為一部請求；但已陳明就其餘額不另起訴者，不在此限。
例1.
  • 甲原本請求乙給付30萬元，但為適用小額程序，僅就10萬元起訴。
  • → 禁止一部請求
例2.
  • 甲僅就10萬元起訴，並向法院陳明「其餘20萬元不另起訴」。
  • → 陳明不另起訴
小額程序判決書之簡化
  • 小額程序判決書得僅記載主文，必要時加記理由要領；得記載於訴狀或筆錄，並得表格化，格式由司法院定之。
例1.
  • 小額程序判決書僅記載「被告應給付原告5萬元」
  • → 得僅記載主文
例2.
  • 當事人對金額有爭執，法院加記理由要領。
  • → 必要時加記理由要領
小額程序訴訟費用額之確定
  • 小額程序中，法院裁判訴訟費用時應一併確定其費用額，並得命當事人提出費用計算書及證明文件。
例1.
  • 小額程序判決中，法院確定訴訟費用為3,000元。
  • → 為訴訟費用之裁判時，應確定其費用額
例2.
  • 小額程序，法院命原告提出費用計算書及收據。
  • → 法院得命當事人提出費用計算書
例3.
  • 法院僅諭知「訴訟費用由被告負擔」，未確定金額。
  • → 未確定費用額，違法
小額程序之依職權宣告假執行
  • 小額程序中，法院判決被告敗訴時，應依職權宣告假執行。
法院為被告敗訴之判決時，應依職權宣告假執行
  • 應：強制規定。
  • 依職權：法院主動為之，無待聲請。
  • 宣告假執行：於判決中宣告得假執行。
例1.
  • 小額程序判決被告應給付原告5萬元，法院依職權宣告假執行。
  • → 為被告敗訴之判決時，應依職權宣告假執行
例2.
  • 法院漏未宣告假執行，得依第394條補充判決。
小額程序之附條件給付判決
  • 小額程序中，經原告同意，法院得判決被告於期限內自動清償者，免除部分給付。
適用情況：命被告為給付
  • 法院判命被告給付（如金錢）。
要件：原告同意
  • 須經原告同意。
效果：得判決「限期清償，免除部分給付」
  • 即被告若於期限內自動清償，則可免除部分給付（如原本判10萬元，自動清償則只需付8萬元）。
  • 此為「附條件之給付判決」，其條件為「被告於一定期限內自動清償」。
例1.
  • 經原告同意，法院判被告應給付10萬元，但若被告於1個月內自動清償，則只需付8萬元。
  • → 經原告同意，得判決「限期清償，免除部分給付」
例2.
  • 經原告同意，法院判被告應給付10萬元，但若被告於1個月內自動清償，則只需付8萬元。
  • 被告未於期限內自動清償，應付全額10萬元。
  • → 條件未成就，應付全額
小額程序分期給付或緩期清償之違約金
  • 小額程序中，法院依被告意願為分期給付或緩期清償時，得定逾期不履行之違約金，但不得逾原給付金額三分之一。
法院得依被告之意願，為「分期給付」或「緩期清償」之判決
並得於判決內，定被告「逾期不履行」時應加給之「違約金額」。違約金額「不得逾三分之一」
  • 得於判決內明定如被告「逾期不履行」，就必須「加給原告」一筆金額。
  • 違約金額不得逾判決所命原給付金額或價額之三分之一。
例1.
  • 法院判被告分三期給付30萬元，並定「逾期不履行應加給10萬元」（三分之一）。
  • → 違約金額「不得逾三分之一」
小額程序準用簡易程序之規定
  • 小額程序準用簡易程序之相關規定（如起訴、筆錄、送達、證據調查、判決書簡化、上訴等）。
小額程序第一審裁判之上訴或抗告
  • 小額程序第一審裁判，得上訴或抗告於地方法院合議庭，且須以違背法令為理由。
對於小額程序之第一審裁判，得上訴或抗告於管轄之地方法院，其審判以合議行之
  • 對於小額程序的第一審裁判，可以向「地方法院」提起上訴或抗告，由「合議庭」審判。
對於前項第一審裁判之上訴或抗告，非以其「違背法令」為理由，不得為之
  • 非以其違背法令為理由：須以「違背法令」為理由。
  • 不得為之：不得僅以「事實認定錯誤」為理由。
小額程序上訴狀之應記載事項
  • 小額程序上訴狀須具體表明原判決違背之法令及其內容，以及違背法令之具體事實。
小額程序上訴狀內「應記載上訴理由」，表明下列各款事項︰
  1. 原判決所違背之法令及其具體內容
    • 指出原判決違反的法律條文（如民法第184條）及其具體內容。
  2. 原判決違背法令之具體事實
    • 依據訴訟資料，具體指摘原判決如何違背法令。
應適用通常或簡易程序而誤用小額程序之處理
  • 應適用通常或簡易程序而誤用小額程序者，第二審得廢棄發回；但當事人無異議者不在此限；兩造同意由第二審繼續者，第二審自為裁判。
適用情況：第一審法院誤行小額程序
  • 該案件依法應適用通常或簡易程序，第一審法院誤行小額程序。
效果：「第二審法院」得不經言詞辯論，「以判決」廢棄原判決，將該事件「發回原法院」
  • 得：第二審法院裁量權。
  • 廢棄原判決：撤銷第一審判決。
  • 發回原法院：發回更審。
例外：50萬元以下案件經當事人合意適用小額程序，當事人已表示無異議
  • 當事人已表示無異議或知悉而無異議為本案辯論者，則不得發回。
判決發回前，應予當事人陳述意見之機會，如「兩造同意」由第二審法院繼續適用小額程序者，應「自為裁判」
  • 第二審法院為發回前，應予當事人陳述意見之機會；若兩造同意由第二審法院繼續適用小額程序，則應自為裁判。
小額程序第二審禁止訴之變更、追加及反訴
  • 小額程序第二審程序中，當事人不得為訴之變更、追加或提起反訴。
小額程序第二審禁止提出新攻擊防禦方法
  • 小額程序第二審中，當事人不得提出新攻擊或防禦方法；但若因原法院違背法令致未能提出者，不在此限。
小額程序第二審判決得不經言詞辯論
  • 在小額程序的「第二審」判決，如果有以下兩種情形之一，法院可以「不開庭」就直接判決：
    1. 雙方當事人都同意不開庭。
    2. 從上訴理由一看就知道「上訴沒有理由」。
小額程序之第二審判決，有下列情形之一者，得不經言詞辯論為之︰
  1. 經兩造同意者
  2. 依上訴意旨足認上訴為無理由者
小額程序第二審裁判不得上訴或抗告
  • 小額程序之第二審裁判為終審裁判，不得再上訴或抗告。
對於小額程序之第二審裁判，不得上訴或抗告
  • 對於小額程序的「第二審裁判」，「不能」再上訴或抗告。也就是說，第二審裁判就是「終審」，一經作出就確定。
小額程序上訴或抗告無理由駁回後禁止再審
  • 小額程序第一審裁判，上訴或抗告經以無理由駁回者，不得再以同一理由提起再審之訴或聲請再審。
對於小額程序之第一審裁判，提起上訴或抗告，經以上訴或抗告無理由為駁回之裁判者，不得更以同一理由提起再審之訴或聲請再審
  • 對於小額程序的第一審裁判，如果提起上訴或抗告，被法院以「無理由」駁回，就不能再以「同一個理由」提起再審之訴或聲請再審。
