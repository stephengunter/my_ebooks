民事訴訟法 訴訟參加

訴訟參加

訴訟參加（輔助參加）
  • 如果一個第三人（不是原本的原告或被告），對於別人正在進行的訴訟結果，有「法律上的利害關係」：
    • 他可以「主動」加入這個訴訟，協助其中一方（原告或被告）打官司，幫助他贏。
    • 誰能參加：就兩造之訴訟有「法律上利害關係」之「第三人」
    • 例如：甲告乙，請求返還某物品。丙已經向乙買了這個物品，如果乙敗訴，丙就拿不到貨。丙雖然不是訴訟的當事人，但訴訟的結果會影響到丙的權益。
    參加者的地位：「輔助」，不是當事人地位
    • 第三人是「幫助」原告或被告，不是當事人。
    得聲請參加時間：該訴訟繫屬中。得與上訴、抗告或其他訴訟行為，合併為之
    • 訴訟繫屬中：從起訴後到判決確定前（包括第一審、第二審、第三審）。判決確定後就不能參加了。
    • 得聲請參加：第三人有「權利」參加，但不是義務。他可以選擇參加，也可以不參加。
    • 第三人可以在「提起上訴」的同時，一併聲請參加（例如在第二審才想要參加）。也可以與其他訴訟行為（如聲請再審）合併為之。
    就兩造之確定判決有法律上利害關係之第三人，於前訴訟程序中「已為參加」者，亦得輔助一造「提起再審」之訴
    • 已為參加：這個第三人「在之前的一審、二審程序中，已經參加過了」。
    • 輔助一造提起再審之訴：即使判決已經確定，他仍然可以「輔助」原訴訟中的一方（原告或被告），提起「再審之訴」，試圖推翻原判決。
    • 立法目的：如果第三人已經參加了訴訟，但仍然敗訴（他所輔助的一方敗訴），他應該有權協助該方提起再審，而不是只能眼睜睜看著判決確定。
例1.
  • 甲向乙購買A車，但A車實際上是丙的（丙是所有人）。丙起訴乙，請求返還A車（本訴訟）
  • 甲是A車的買受人，如果丙勝訴，甲就拿不到車（甲的「交付請求權」會受影響）
  • 甲有「法律上利害關係」，可以參加訴訟，輔助乙（被告）打官司，幫助乙贏
  • → 就兩造之訴訟有「法律上利害關係」之「第三人」，得聲請參加
例2.
  • 第一審判決乙敗訴。乙還沒有決定是否上訴
  • 甲（第三人）想要參加訴訟輔助乙。甲可以在乙提起上訴的時候，同時聲請參加（在第二審參加）
  • → 聲請參加，得與上訴、抗告或其他訴訟行為，合併為之
參加人之權限
  • 參加人可以幫助他所輔助的那一方當事人做各種訴訟行為（例如提出證據、開庭辯論、上訴）。
  • 但不能做出與該當事人自己行為「互相衝突」的事（例如當事人自認，參加人卻否認），否則參加人的行為無效。
參加人得輔助當事人為一切訴訟行為。但其行為與該當事人之行為「牴觸」者，「不生效力」
  • 一切訴訟行為：包括：提出攻擊防禦方法（例如提出書狀、陳述事實、主張法律見解）
  • 牴觸：與參加人所輔助的那一方當事人「自己」做的行為「互相矛盾」或「衝突」。
    • 例如：當事人已經「自認」某事實，參加人卻「否認」該事實。
  • 不生效力：參加人的行為「無效」，法律上當作沒有發生。
例1.
  • 甲告乙返還借款。丙參加訴訟輔助乙
  • 乙自己沒有提出任何證據。丙可以自己提出證據（例如乙的還款收據），證明乙已經還錢
  • 丙的行為與乙的行為沒有牴觸（乙只是消極，沒有反對）
  • → 參加人得輔助當事人為一切訴訟行為
例2.
  • 甲告乙返還借款。乙在法庭上「自認」：「我確實有向甲借100萬沒還。」
  • 丙參加訴訟輔助乙，卻說：「乙沒有借錢，借據是偽造的。」
  • 丙的行為與乙的行為「牴觸」（乙承認、丙否認）。丙的否認行為「不生效力」。法院仍然可以根據乙的自認，判乙敗訴
  • → 參加人輔助行為與該當事人之行為「牴觸」者，「不生效力」
參加效力
  • 參加人（來幫忙打官司的人）事後不能對他輔助的當事人說「那個判決是錯的」，他必須接受該訴訟的結果。
  • 同樣的，被參加人也不能事後否認參加人在訴訟中所做的行為。這就是「參加效力」。
    • 但如果參加人因為太晚參加、或被參加人阻撓而無法提出攻擊防禦方法，或被參加人自己故意不用參加人不知道的有利方法，則參加人不受拘束。
原則：參加人「不得主張」本訴訟之「裁判不當」
  • 參加人與被參加人之間，就該裁判所判斷的法律關係，參加人不能否認。
  • 例如：參加人參加了甲告乙的訴訟（輔助甲），法院判決甲敗訴。事後，參加人自己告乙（或乙告參加人），參加人不能說「那個判決是錯的，其實甲應該勝訴」
但書：1.因參加時訴訟之程度、因該當事人之行為，不能用攻擊或防禦方法。 2.該當事人故意或重大過失不用參加人所不知之攻擊或防禦方法
  • 參加時訴訟之程度：參加人參加訴訟時，訴訟已經進行到某個程度（例如已經調查完證據、已經辯論終結）。他來不及提出自己的攻擊或防禦方法。
    • 例如：一審已經辯論終結，參加人才參加。他無法提出新證據。
  • 因該當事人之行為：被參加人（他所輔助的當事人）的行為，導致他無法使用攻擊或防禦方法。
    • 例如：被參加人故意不讓他閱卷、不讓他出庭、不讓他提出書狀。
  • 該當事人故意或重大過失不用參加人所不知之攻擊或防禦方法：被參加人明知有某個有利的攻擊或防禦方法（例如某個關鍵證人、某份關鍵文件），但故意不用（例如想隱瞞）或重大過失不用（例如忘記了）。
    • 參加人所不知：參加人不知道有這個方法（所以無法主動提出）。
  • 有以上但書情況，參加人可以主張不受裁判的拘束。
例1.
  • 甲告乙，請求返還借款。丙是甲的友人，擔心甲敗訴，參加訴訟輔助甲
  • 法院判決甲敗訴（認定借款不存在）。事後，乙告丙（參加人），主張丙是甲的連帶保證人，應負連帶責任
  • 丙在乙丙的訴訟中，主張：「甲告乙的那個判決是錯的，其實借款存在，所以我不應該負責。」
  • 丙「不得主張」該裁判不當。法院應基於甲敗訴的判決（借款不存在），認定丙也不必負責
  • → 參加人不得主張裁判不當
例2.
  • 承上例，丙在甲、乙訴訟的「言詞辯論終結後」才參加。丙來不及提出任何證據或主張。法院判決甲敗訴
  • 事後，乙告丙。丙可以主張：「我參加的時候已經太晚了，來不及提出攻擊防禦方法。」依但書，丙不受裁判拘束
  • → 參加時訴訟程度已晚，得主張不受裁判拘束
參加人承當訴訟
  • 如果原告和被告都同意，原本只是來「幫忙」的參加人，可以「升格」為正式的當事人，取代原本被幫忙的人（例如原告）。
  • 而原本的當事人則可以「退出」訴訟。但是判決結果對他仍有效力。
參加人經「兩造同意」時，得代其所輔助之當事人「承當訴訟」
  • 參加人：從參加人，原本是輔助一方當事人。
  • 經兩造同意：必須得到「原告」與「被告」雙方的同意。
  • 承當訴訟：承接訴訟，成為訴訟當事人（取代其所輔助之當事人）
參加人「承當訴訟後」，其所輔助之當事人「脫離訴訟」。但本案之判決，對於脫離之當事人，「仍有效力」
  • 脫離訴訟：被參加人不再是訴訟當事人，退出訴訟程序。
  • 仍有效力：判決結果仍然拘束被參加人（既判力或參加效力）。
例1.
  • 甲告乙，請求返還借款。丙是甲的債權人，擔心甲敗訴會影響丙對甲的債權，於是參加訴訟輔助甲
  • 訴訟中，甲因為出國長期無法到庭，甲、乙、丙三方協商，甲和乙都同意由丙「承當訴訟」，取代甲成為原告
  • 法院准許後，甲脫離訴訟，丙成為原告（以自己的名義告乙）
  • 判決確定後，如果丙勝訴，乙要還錢給丙；如果丙敗訴，判決對甲仍然有效（甲不能再告乙）
例2.
  • 承例1，甲脫離訴訟後，丙敗訴（法院認定借款不存在）
  • 事後，甲另行起訴乙，請求返還同一筆借款
  • 乙可以主張：「甲在之前的訴訟已經脫離，但判決對甲仍然有效，甲不得再行起訴。」法院應駁回甲的起訴（違反既判力）
  • → 本案之判決，對於脫離之當事人，「仍有效力」
訴訟告知第三人
  • 當事人（原告或被告）可以在官司進行中，主動通知一個「如果我敗訴，會影響到他法律上權益」的第三人（例如保證人、連帶債務人）。
    • 被通知的第三人，也可以再通知另一個有利害關係的人。這樣可以讓所有相關的人都有機會參加訴訟，避免將來產生更多紛爭。
  • 告知訴訟必須寫一份書狀，說明「為什麼要告知」以及「官司現在進行到什麼程度」，然後交給法院。
    • 法院會將書狀送達給第三人，同時也送一份給對方當事人。
當事人得於訴訟繫屬中，將訴訟「告知」於因自己「敗訴」而有「法律上利害關係」之「第三人」
  • 因自己「敗訴」而有「法律上利害關係」之「第三人」：例如保證人、連帶債務人。
受訴訟之告知者，得遞行告知
  • 被通知的第三人可以再「轉告」另一個有利害關係的第三人。例如：B如果敗訴，會影響到C，B就可以告知C。
告知訴訟，應以「書狀聲請」並「表明理由」及訴訟程度提出於法院，「由法院送達於第三人」。聲請書狀「並應送達於他造」
  • 表明理由：例如：「第三人丙為被告甲之連帶保證人，如被告甲敗訴，原告乙將向丙求償，故丙有法律上利害關係。」
  • 表明訴訟程度：例如：「本訴訟已於民國OO年OO月OO日進行言詞辯論，目前尚未終結。」
  • 由法院送達於第三人：法院收到書狀後，會將繕本送達給第三人。
  • 並應送達於他造：讓對方當事人也知道「我方通知了誰」，避免對方當事人措手不及（例如突然多了一個參加人）。
例1.
  • 甲向乙借款100萬元，丙是連帶保證人。乙起訴甲，請求返還借款
  • 甲（被告）擔心自己敗訴後，乙會轉向丙求償
  • 甲向法院提出聲請：將本訴訟「告知」丙（保證人）。讓丙知道有這個官司，丙可以決定是否參加訴訟（輔助甲）
例2.
  • 承例1，丙收到告知後，想到：「如果甲敗訴，乙來告我，我會再向我的連帶保證人『庚』求償。」
  • 丙可以再「遞行告知」庚。庚也可以再告知下一個。
  • → 受訴訟之告知者，得遞行告知
告知效力：視為已參加
  • 如果當事人依法告知了第三人（例如保證人），第三人卻不參加訴訟，或太晚才要參加，法律上就「視為」他已經參加了。
    • 所以他也不能事後主張「那個判決是錯的」（與實際參加的人受到相同的拘束）。
受告知人「不為參加」或「參加逾時」者，「視為」於得行參加時「已參加」於訴訟。
  • 受告知人：受法院通知得參加的「法律上利害關係」之「第三人」。
  • 不為參加：第三人收到告知後，沒有聲請參加訴訟。
  • 參加逾時：想要參加，但太晚了。法院會以「逾時」為由，駁回參加的聲請。
  • 視為於得行參加時已參加於訴訟：法律上「視為」他已經參加了訴訟（成為從參加人）。
  • 法律效果：不能主張本訴訟的裁判不當。
例1.
  • 甲向乙借款100萬元，丙是連帶保證人。乙起訴甲請求返還借款。
  • 甲（被告）聲請告知丙（保證人）。丙收到告知後，認為甲一定會贏，所以不參加訴訟。
  • 後來法院判決甲敗訴（認定借款存在）。乙轉向丙求償。
  • 丙在乙丙的訴訟中，主張：「甲告乙的判決是錯的，其實甲已經還錢了。」法院駁回丙的主張。
  • → 受告知後不參加，視為已參加。不能主張本訴訟的裁判不當
例2.
  • 承上例，丙收到告知時，第一審已經言詞辯論終結，丙根本來不及提出任何攻擊防禦方法。
  • 而且，甲（被參加人）故意隱瞞了一份對丙有利的證據（證明甲已經還錢），丙完全不知道。
  • 依但書，丙可以主張裁判不當，不受裁判拘束（因為他參加時訴訟程度已晚，且甲故意不用攻擊方法）
法院依職權通知第三人
  • 如果官司的結果會影響到第三人（例如保證人），法院可以在第一審或第二審言詞辯論終結前，主動用書面通知該第三人，告訴他這個官司的存在。
  • 第三人收到通知後5天內可以聲請閱卷；如果第三人依法可以參加卻不參加，就會受到與「受告知不參加」相同的拘束（不能事後說判決不當）。
通知時間：第一審或第二審「言詞辯論終結前」相當時期
  • 必須在「還有時間讓第三人參加」的時候通知。通常指：至少還有足夠時間讓第三人聲請閱卷、提出書狀、參加訴訟（例如一至二週以上）
通知對象：對於訴訟結果，有法律上「利害關係」的「第三人」
  • 例如：保證人、連帶債務人、物上保證人、承租人、受讓人等。
通知內容：訴訟事件及進行程度
  • 例如：例如「台灣台北地方法院OO年度訴字第OO號，原告甲與被告乙間返還借款事件。已於OO年OO月OO日進行言詞辯論，預定於OO年OO月OO日續行辯論」）
受通知人得聲請閱卷。得「聲請參加」者，逾時不參加，視為已參加
  • 第三人原本沒有「當事人」身分，不能閱卷。本項特別賦予「受通知人」臨時的閱卷權。讓第三人了解訴訟的具體內容（例如兩造的主張、證據），以便決定是否參加訴訟。
  • 得「聲請參加」者：該第三人「有法律上利害關係」，依法可以參加訴訟者。
  • 逾時不參加，視為已參加：即告知效力。受通知人如果不參加，或參加逾時，視為已參加，不得主張裁判不當。
