民事訴訟法 再審程序

再審程序

再審事由
  • 判決確定後，只有發生法官貪污、證人說謊、發現新證物、判決理由矛盾等13種極重大瑕疵，且當事人無法在上訴時主張，才能在30天內提再審。
第一類：程序上重大瑕疵：法院組織不合法、法官應迴避、當事人未經合法代理
第二類：訴訟詐欺或犯罪行為：法官收賄、證人偽證、證物偽造
  • 以「刑事有罪判決確定」或「懲戒處分確定」為限。
第三類：判決基礎已動搖或新證據：原判決所依據的行政處分被撤銷、發現前未斟酌的關鍵證物
不得上訴第三審事件之再審事由（證物漏未斟酌與一造辯論判決）
  • 對不能上訴三審的二審確定判決，若法院漏掉關鍵證據、或把有正當理由請假的當事人直接判敗訴，也可以提再審。
適用案件：不得上訴於第三審法院之事件
  • 包括訴訟標的金額或價額未達法定門檻（現為150萬元），或依其他法律不得上訴第三審之事件。
以下情況可為再審事由：
情況1：第二審之確定判決，「漏未斟酌」足影響於判決之「重要證物」
  • 僅適用於「第二審法院作出的確定判決」，不適用於第一審確定判決。
  • 漏未斟酌：法院在判決中完全未審酌、未提及該證物，形同視而不見。若法院已審酌但認為不可採，則不屬「漏未斟酌」（屬證據評價問題）。
情況2：當事人有正當理由不到場，法院為一造辯論判決者
  • 例如因重病住院、天災交通中斷、重大事故等不可歸責於當事人之事由，致無法於言詞辯論期日到場。
  • 法院為一造辯論判決：他造聲請一造辯論（第385條），法院准許後，僅依到場一造之聲明及證據逕為判決，未審酌未到場當事人之主張。
例1.
  • 原告起訴請求被告給付貨款50萬元（未達150萬元上訴門檻）。
  • 原告提出「送貨單簽收聯」為證，但第二審判決書完全未提及該簽收聯，也未說明為何不採，逕以「原告舉證不足」判決原告敗訴。
  • 判決確定後，原告以「重要證物漏未斟酌」提再審。
  • → 該簽收聯為足影響判決之重要證物，法院漏未斟酌，得提起再審之訴
例2.
  • 被告因突發心肌梗塞住院，出具醫院診斷證明向法院請假，聲請改期。
  • 法院不准假，如期開庭，並依原告聲請為一造辯論判決，判決被告敗訴確定。
  • → 被告有正當理由不到場，法院仍為一造辯論判決，得提起再審之訴。
以「為判決基礎之裁判」有瑕疵為由提起再審
  • 如果你的判決是靠另一個裁判（如刑事判決、行政處分）才成立的，而那個裁判後來被發現有再審的重大瑕疵，你可以直接對這個判決提再審。
「為判決基礎之裁判」，如「有再審重大瑕疵」者，得據以對於該判決提起再審之訴
  • 為判決基礎之裁判：指在作成A判決的過程中，法院所依賴、引用或作為判斷前提的另一個「裁判」（以下稱B裁判）。B裁判必須是A判決的「必要前提」或「關鍵依據」，而非僅是附帶提及。
  • 有再審重大瑕疵：B裁判有「適用法規顯有錯誤」（第496條第1款）、「判決理由與主文矛盾」（第2款）、「證人偽證」（第10款）、「發現未經斟酌之證物」（第13款），或對不得上訴三審事件有「重要證物漏未斟酌」（第497條前段）等。
  • 對於該判決提起再審之訴：對於「以B裁判為基礎的A判決」提起再審之訴。
例1.
  • 甲起訴乙侵權行為損害賠償，法院以刑事庭認定乙「有罪」的確定判決為基礎，判決乙應賠償甲100萬元。
  • 事後，乙對該刑事判決提起再審，刑事再審法院廢棄原判決，改判乙無罪（因發現新證據）。
  • 甲對乙的民事賠償判決尚未清償。乙對該民事確定判決提起再審之訴。
  • → 為判決基礎之刑事裁判有再審事由，得據以對民事判決提起再審
再審事由之禁止重複主張（一事不再理）
  • 同一個再審理由，被法院以「無理由」判決駁回確定後，就永遠不能再拿來對原判決或駁回判決提再審，不能一魚兩吃。
再審之訴，法院認無再審理由，判決駁回後
  • 法院認無再審理由：法院經過實體審查（包括審查再審事由是否成立），最終認定當事人所主張的再審事由不成立（例如「你所說的證物並非『未經斟酌』，或該證物不足以影響判決」）。
  • 判決駁回：法院以「判決」（而非裁定）的形式，駁回再審之訴。此判決為終局判決，得上訴（但實務上再審駁回判決上訴成功機率極低）。
不得以同一事由更行提起再審之訴
  • 若違反本條規定提起，法院應以「再審之訴不合法」裁定駁回（無須進入實體審查），或依職權逕行駁回。
例1.
  • 甲以「發現未經斟酌之證物（A契約書）」為由，對確定判決提起再審。
  • 法院審理後，認定該契約書並非「未經斟酌」（甲在原始訴訟中已提出過），判決駁回再審確定。
  • 甲事後又持「同一份A契約書」，再次對原確定判決提起再審。
  • → 同一事由不得更行提起再審，法院應以不合法裁定駁回。
例2.
  • 甲第一次再審主張「發現新證物（A契約書）」（第13款），遭判決駁回確定。
  • 甲第二次再審主張「證人乙具結後為虛偽陳述，且已受有罪判決確定」（第10款）。
  • 第二次再審主張的是不同事由（第10款 vs 第13款），非「同一事由」，法院應實體審理（但仍須審查其他要件，如期間、補充性等）
  • → 不同事由，不禁止
再審之訴之管轄法院
  • 再審要去原判決法院告；若同時對好幾個審級的判決告，由最高那級的法院合併處理。
  • 但對最高法院判決告「事實型」再審事由（第9-13款），要回到二審法院告。
再審之訴，「專屬為判決之原法院管轄」
  • 專屬：強制性管轄規定，當事人不能以合意變更，法院也不能以「無管轄權」移送其他法院（若誤送，應依職權移送回原法院）。
  • 為判決之原法院：指作出「當事人想要再審的那個確定判決」的法院。
對於審級不同之法院就同一事件所為之判決，提起再審之訴者，專屬上級法院合併管轄
  • 審級不同之法院：例如一審法院（地方法院）與二審法院（高等法院）就同一事件分別作出判決（通常是一審判決後上訴，二審判決確定）。
  • 同一事件：指同一個訴訟案件（同一當事人、同一訴訟標的、同一訴之聲明）。
  • 提起再審之訴者：當事人對「一審判決」及「二審判決」同時提起再審（或先後提起，但合併處理）。
  • 合併管轄：由該上級法院將所有審級的判決一併審理、一次決定，避免裁判矛盾。
  • 對二審及一審判決同時再審 → 由二審法院合併管轄（因二審為上級）。
但對於第三審法院之判決，再審事關「事實重新認定」者，專屬原第二審法院管轄
  • 事實重新認定：第496條第1項第9款至第13款事由：
    • 為判決基礎之證物係偽造或變造。
    • 證人、鑑定人、通譯、當事人或法定代理人經具結後為虛偽陳述。
    • 為判決基礎之裁判或行政處分已變更。
    • 同一訴訟標的前已有確定判決或和解調解。
    • 發現未經斟酌之證物或得使用該證物。
  • 專屬原第二審法院管轄：不向最高法院提再審，而是向「作出第二審判決的高等法院」提起。
  • 立法理由：第9款至第13款事由涉及「事實認定」（如證物是否偽造、新證物是否確實存在），最高法院為法律審，原則上不調查事實，若由最高法院直接管轄再審，將無法有效審理。故將管轄權下放給事實審的最後一關——第二審法院，由其調查事實並為再審判決。
例1.
  • 甲、乙間訴訟，經高等法院判決甲敗訴確定（甲未上訴三審或上訴被駁回）。
  • 甲欲以「發現未經斟酌之證物」（第496條第1項第13款）提再審。
  • 再審專屬為判決之原法院（高等法院）管轄。甲應向高等法院提起再審之訴。
  • → 二審判決確定，向二審法院提再審
例2.
  • 最高法院判決甲敗訴確定。甲主張「發現未經斟酌之證物」（第13款，事實問題）。
  • 事關「事實重新認定」，甲應向原二審法院（高等法院）提起再審之訴，而非最高法院。
  • → 再審事關「事實重新認定」者，專屬原第二審法院管轄
再審之訴的不變期間
  • 再審要在判決確定（或知道再審理由）後30天內提起，最晚不能超過判決確定後5年。
  • 只有「未經合法代理」「謊報所在不明」「已有前案確定判決」這三種情形，超過5年仍可提起。
再審之訴，應於「30日不變期間」內提起
  • 30日：法定不變期間，不得延長或縮短。
  • 不變期間：逾期未提起，即生失權效果，法院應以「再審之訴不合法」裁定駁回。
前項期間，判決確定時起算
  • 判決確定時：判決因不得上訴、未上訴、上訴駁回等而確定之時點。這是30日原則上的起算點。
再審之理由發生或知悉在後者，「自知悉時起算」
  • 例如判決確定後，證人才為虛偽陳述，或判決所依據的行政處分之後才被撤銷。此時從「知悉理由」起算30日。
但自判決確定後「已逾五年者，不得提起」
  • 不論再審理由何時發生、何時知悉，只要判決確定超過5年，就「絕對不得」再提再審（除非第3項例外）。
  • 立法目的：維護法安定性，避免數十年前的判決被拿出來反覆爭執。
但以下事由不適用5年限制：
  1. 當事人於訴訟未經合法代理：例如被冒名起訴、無訴訟能力人未由法定代理人代理。這剝奪了當事人實質的訴訟防禦權，且此瑕疵通常難以發現。
  2. 當事人知他造之住居所，指為所在不明而與涉訟者：原告惡意謊報被告地址，導致被告從未收到開庭通知。此為嚴重訴訟詐欺，被告直到判決被強制執行時才可能發現。
  3. 當事人發現就同一訴訟標的在前已有確定判決或和解、調解者：存在既判力衝突，法院不應再受理。此涉及司法裁判的一致性，不因時間經過而合理化。
例1.
  • 甲於109年3月1日判決確定敗訴。
  • 甲於112年5月10日才在舊倉庫發現一份關鍵契約書（該契約書在判決前已存在，但甲當時不知），此為第13款事由。
  • 甲自知悉日（112年5月10日）起30日內（112年6月8日前）提起再審。
  • → 自知悉時起算30日內；且未逾判決確定後5年，合法。
例2.
  • 乙於100年1月1日被某自稱「丙之法定代理人」者起訴，法院判決乙敗訴確定。
  • 乙當時並不知丙實際上無訴訟能力（丙未經合法代理）。乙於108年1月1日（判決確定已8年）發現此事實，依第5款提起再審。
  • → 未經合法代理不適用5年限制，乙仍可提再審（但須自知悉日起30日內）
再審之訴的駁回
  • 再審之訴程序不對，法院用「裁定」駁回（不開庭）；再審之訴一看就知道沒理由，法院可以用「判決」駁回（也不開庭）。
再審之訴不合法者，法院應以裁定駁回之
  • 不合法：違反程序要件，包括但不限於：
    • 逾30日不變期間或逾5年、被告不適格、以同一事由再審
  • 以裁定駁回：用「裁定」的形式駁回，而非「判決」。當事人對裁定不服，可以「抗告」（而非上訴）。
再審之訴「顯無再審理由」者，得不經言詞辯論「以判決駁回」之
  • 顯無再審理由：指再審之訴在實體上「明顯、一望即知」不具備任何再審事由，無須進一步調查證據或開庭辯論。
  • 以判決駁回：用「判決」形式駁回（而非裁定），因為法院已對「再審理由是否存在」作出實體判斷。當事人對判決不服，可以「上訴」（而非抗告）。
例1.
  • 甲於判決確定後第40天才提起再審之訴（逾越30日），且未主張任何「知悉在後」的事由。
  • 法院審查後，認為逾不變期間，以裁定駁回再審之訴。
  • → 不合法：逾期，裁定駁回
例2.
  • 甲主張「原判決認定甲有過失是錯的，因為證人乙的證詞不可信」， 以此為由提起再審（未主張任何第496條事由，僅爭執事實認定）。
  • 事實認定錯誤非再審事由，顯無再審理由， 得不經言詞辯論，以判決駁回。
  • → 顯無理由：主張事實認定錯誤，判決駁回
再審之訴本案審理之範圍
  • 再審重新審理原案件時，法院只能審當事人說要翻盤的那個部分，當事人沒說要改的部分就確定不動。
再審本案之辯論及裁判，以聲明不服之部分為限
  • 本案：指「原來的訴訟案件」，而非「再審之訴本身」。也就是確定判決所處理的那個實體爭議（例如：甲對乙的損害賠償請求權是否存在）。
  • 聲明不服之部分：指當事人在再審訴狀中（第501條第1項第3款）所明示的「希望法院廢棄原判決的範圍」及「希望法院如何改判的請求」。
例1.
  • 原確定判決命被告給付原告500萬元（包含本金400萬元及利息100萬元）。
  • 被告提起再審，再審訴狀中聲明：「請求廢棄原判決關於『利息100萬元』部分，駁回原告該部分之請求。」（對本金400萬元未聲明不服）。
  • 法院審理後認定再審有理由。本案重新審理時，僅能就「利息100萬元」部分進行辯論及裁判，本金400萬元部分已確定，不得再審酌。
  • → 本案之辯論及裁判，以聲明不服之部分為限
例2.
  • 再審審理中，法院發現原判決除了當事人聲明不服的利息部分外，本金部分也可能有問題。
  • 法院可否主動將本金部分一併審理、廢棄？法院不得逾越聲明不服之部分。法院應僅就利息部分審理。
  • → 本案之辯論及裁判，以聲明不服之部分為限
再審有理由但原判決正當之駁回
  • 就算證明原判決程序有重大瑕疵，但如果重新審理後發現原判決的結果是對的，法院還是會駁回再審，維持原判。
再審之訴，雖有再審理由
  • 雖有再審理由：法院已認定當事人所主張的再審事由確實存在（例如，證物確係偽造、證人確為虛偽陳述、法官確應迴避而未迴避）。
  • 此為「第一階段」的結論。換言之，再審之訴在「程序瑕疵面」是站得住腳的。
法院如認原判決為正當者，應以判決駁回之
  • 認原判決為正當：法院在重新審理「本案」（即原訴訟的實體爭議）後，認為「原確定判決的結論是正確的」，即使沒有那個再審瑕疵，結果也不會改變。
  • 例如：原判決命被告給付100萬元，法院認為實體上被告確實欠100萬元。即使發現法官應迴避而未迴避，或證人偽證（但偽證內容不影響結論），仍屬「原判決正當」。
  • 以判決駁回：用「判決」形式駁回再審之訴（而非裁定），因為法院已對本案實體（原判決是否正當）作出判斷。
例1.
  • 甲訴請乙給付貨款100萬元，一審判決甲勝訴確定。
  • 甲懷疑法官收賄，經刑事判決確定法官確有收賄（第7款），甲提起再審。
  • 法院重新審理本案（貨款糾紛），仍認定乙確實積欠甲100萬元（證據確鑿，原判決正當）。
  • → 雖有再審理由（法官收賄），但法院認原判決正當，應以判決駁回再審之訴。
例2.
  • 甲主張「發現未經斟酌之證物」（第13款），該證物是一張估價單，可證明乙曾詢價。
  • 但法院重新審理後認為，乙是否詢價與本案核心爭點（乙是否已付款）無關，縱使該證物提出，原判決結果（乙勝訴）仍然正確。
  • → 雖有再審理由（新證物），但原判決正當，駁回再審
「賠償因假執行所受損害」，於再審之訴準用之
  • 再審打贏、翻掉舊判決，順便要求對方把之前靠假執行搶走的錢吐回來，不用再打新的官司。
賠償因假執行所受損害
  • 如果上訴審法院把「准許假執行的判決」廢掉或改判，而且被告（被執行的人）有請求，法院就必須在原判決（或再審判決）中，直接命原告（原本拿錢的人）把因為假執行而拿到的錢或受到的損害還回來、賠出來。
  • 如果被告沒主動要求，法院應該提醒他可以聲明。
例1.
  • 第一審法院判決甲應給付乙100萬元，並宣告假執行。
  • 乙拿著判決去法院，扣押了甲銀行帳戶裡的100萬元。
  • 甲不服，上訴到二審敗訴（判決確定），甲仍不服，提起再審。
  • 再審法院認定再審有理由，廢棄原判決，改判乙敗訴（乙一毛錢都拿不到）。
  • 甲在再審程序中，向法院聲明：「請依第505條之1準用第395條第2項，命乙返還已被執行的100萬元及利息。」
  • 法院應於再審判決中直接命乙返還100萬元。
  • → 再審成功，請求返還假執行金額
例2.
  • 第一審法院判決丙應給付丁500萬元，宣告假執行。
  • 丁聲請法院拍賣丙的房屋，拍定價格為400萬元（丙因此損失房屋，且仍有100萬債務追索）。
  • 丙提起再審，最終法院廢棄原判決，認定丁不得請求500萬元（丙勝訴）。
  • 丙在再審程序中，聲明請求丁賠償因房屋被低拍所受的損害（如拍賣價與市價之差額）。
  • 法院應於再審判決中審酌並命丁賠償。
  • → 假執行造成房屋被拍賣，請求賠償差價
再審判決對善意第三人權利之保障
  • 再審改判，只影響原來打官司的兩造；信賴法院程序而善意取得權利的第三人，其權利不受影響。
再審之訴之判決，於第三人以「善意取得」之權利「無影響」
  • 第三人：指原訴訟（確定判決）當事人以外的第三人。例如：在強制執行程序中買到拍賣物的買受人；因信賴支付命令而受讓債權的受讓人；因信賴判決而取得物權登記的轉得人。
  • 善意：指第三人於取得權利時，「不知道」原判決有再審事由（或不知道原判決可能被推翻），且無重大過失。
  • 取得之權利：包括物權（所有權、抵押權）、債權（受讓的債權）、其他財產權。
  • 取得方式：包括買賣、拍賣、受贈、設定擔保等。
  • 無影響：再審判決不影響該第三人已取得的權利。換言之，再審當事人（尤其是原勝訴方）不能因為再審改判，就主張善意第三人的權利無效、應返還或應塗銷登記。
例1.
  • 甲對乙有虛假債權，取得確定支付命令後，聲請拍賣乙的房屋。
  • 丙參加法院拍賣，善意買下該屋並完成登記。
  • 事後，乙提起再審成功，廢棄原支付命令（確認甲無債權）。
  • 法院再審判決認定甲敗訴。
  • 丙係善意第三人，其取得之房屋所有權不受再審判決影響，無須返還。乙只能向甲請求損害賠償
  • → 再審之訴之判決，於第三人以善意取得之權利無影響
例2.
  • 丁明知甲對乙的判決有偽造證據情事（丁曾參與偽造），仍向甲購買該判決所生的債權。
  • 事後乙再審成功，廢棄原判決。
  • 丁非善意取得之權利可能受再審判決影響，不得對抗乙。
確定裁定準用再審程序
  • 確定裁定如果也有判決再審的那些重大瑕疵（如法官應迴避、證物偽造），可以準用再審程序，聲請再審。
例1.
  • 法院以裁定對證人丙處罰鍰3萬元（因不到場）。丙未抗告，裁定確定後罰鍰被執行。
  • 事後，丙提出證據證明，法院據以為裁定的「合法通知書」係偽造（丙根本未收到通知，通知書是對方偽造的，第496條第1項第9款）。
  • 丙聲請再審，請求撤銷罰鍰裁定。
  • → 確定裁定準用再審程序
