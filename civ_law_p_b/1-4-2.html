民事訴訟法 送達

送達

送達之職權性
  • 訴訟文書的送達，原則上由法院書記官主動負責辦理，不需當事人自己動手。
送達，除別有規定外，由法院書記官依職權為之
  • 送達：法院依法定方式，將訴訟文書（如起訴狀繕本、判決書、開庭通知等）送交應受送達人之程序。
  • 書記官依職權為之：書記官應「主動」辦理送達，無待當事人聲請。
送達之執行機關
  • 送達由書記官交「執達員」或「郵局」執行；郵局送達時，郵差就是送達人。
送達，由法院書記官交「執達員」或「郵務機構」行之
  • 送達之實際執行者為「執達員」或「郵務機構」。
郵務機構行送達者，以郵務人員為送達人
  • 若由郵局送達，郵差（郵務人員）即為「送達人」。
  • 郵務人員之送達行為（如將文書交予本人或同居人簽收），具有「合法送達」之效力。
例1.
  • 書記官將開庭通知書交給執達員，執達員親赴被告住所，將通知書親手交給被告簽收。
  • → 執達員送達
例2.
  • 書記官將判決書以「掛號郵件」寄送至原告地址。
  • 郵差送達時，若應受送達人不在，郵差得將文書交予其同居人或受僱人簽收，該送達仍屬合法。
  • → 郵務人員為合法送達人
囑託送達
  • 法院可以委託（囑託）文書送達地的地方法院，代為送達訴訟文書。
法院得向送達地地方法院為送達之囑託
  • 「得」：裁量權。法院可選擇自行送達（郵務或執達員），亦可囑託他法院。
  • 送達地：指應受送達人「實際應受送達之處所」所在地。
  • 囑託：委託、請求。原法院以「囑託函」方式，請求送達地法院協助送達。受囑託法院應依職權為送達（如交執達員或郵務機構），並將送達結果回報原法院。
例1.
  • 臺北地院審理案件，被告住高雄市。臺北地院發函囑託「臺灣高雄地方法院」代為送達開庭通知書。
  • 高雄地院收函後，指派執達員至被告地址送達。並將送達證書寄回臺北地院。
  • → 囑託高雄地院送達
法院內交付送達
  • 法院書記官可以在法院內直接把文書交給當事人，這樣就算送達了。
法院書記官，得於法院內，將文書付與應受送達人，以為送達
  • 「法院書記官」：限於「書記官」本人，不包括執達員或郵務人員。
  • 「於法院內」：限於「法院建築物內」（如法庭、訴訟輔導科、閱卷室、收發室等）。
  • 「將文書付與應受送達人」：親手交付應受送達人本人（非同居人或受僱人，因本條限於本人）。
  • 「以為送達」：交付即完成送達。
例1.
  • 乙至法院閱卷時，書記官將開庭通知書直接交付乙。
  • → 當事人至法院領取文書
對無訴訟能力人之送達
  • 送達給無訴訟能力人（如未成年人），要送給他的全體法定代理人（如父母）。
  • 如果法定代理人有好幾位（例如父母兩人）：
    • 原則上要送給「所有」法定代理人；
    • 但如果其中一個法定代理人的地址不明（找不到人），法院可以「只送給其他法定代理人」就好了。
對於「無訴訟能力人」為送達者，應向其「全體法定代理人」為之
  • 無訴訟能力人：包括未滿18歲之未成年人、受監護宣告之人等。
  • 全體法定代理人：如未成年人父母（若均為法定代理人）、監護人。
    • 須向「全部」法定代理人送達，始生合法送達效力。
法定代理人有二人以上，如其中有「應為送達處所不明」者：得僅向其餘之法定代理人送達
  • 二人以上：如父母均為法定代理人。
  • 應為送達處所不明：指其中一法定代理人之住居所、事務所不明，無法送達。
  • 得僅向其餘之法定代理人送達：法院裁量權，可僅向「其餘」法定代理人（地址明確者）送達。
例1.
  • 甲（15歲）為被告，其法定代理人為父母乙、丙。法院應將開庭通知書分別送達予乙及丙。
  • → 送達予父母雙方
例2.
  • 甲（15歲）為被告，父母離婚，母為監護人（單獨監護），父住居所不明。
  • 法院僅須向母送達即可（因母為唯一法定代理人）。
  • → 父處所不明，僅送達母
對外國法人或團體之送達
  • 對在台有營業據點的外國公司或團體，要送達給它在台灣的代表人或管理人。
    • 若代表人有數人且其中一人地址不明，可只送給其他人。
外國法人或團體，在我國有「事務所或營業所」者：應向其在我國之「代表人或管理人」為送達
  • 外國法人：依外國法設立之公司、社團、財團等（如Google台灣分公司）。
  • 團體：非法人但具組織性之團體（如外國商會、工會）。
  • 事務所或營業所：在台灣設有固定辦公處所或營業據點。
  • 代表人：如分公司經理、台灣辦事處負責人。
  • 管理人：如團體之負責人、執行長。
法定代理人有二人以上，其中一人處所不明，得僅向其餘代理人送達
  • 若外國法人之代表人或管理人有「二人以上」，其中一人地址不明，得僅向「其餘」代表人或管理人送達。
例1.
  • 美國A公司在台北設有分公司，法院應將開庭通知書送達予該分公司之經理（代表人）。
  • → 外國法人在我國有「營業所」者：應向其在我國之「代表人或管理人」為送達
例2.
  • A公司台灣分公司設有「總經理」及「副總經理」二人為共同代表人。副總經理出國且地址不明，法院得僅向總經理送達。
  • → 法定代理人有二人以上，其中一人處所不明，得僅向其餘代理人送達
特殊身份送達
對服役軍人之送達
  • 應囑託該管軍事機關或長官送達
對在監所人之送達
  • 應囑託該監所首長送達
對駐外人員之送達
  • 應囑託外交部為之
對有治外法權人之送達
  • 得囑託外交部為之
對經理人之送達
  • 跟公司或商號有關的訴訟，可以將文書送達給該公司的經理人（例如總經理）。
關於商業之訴訟事件，送達得向經理人為之
  • 商業：指以營利為目的之事業，包括公司、商號、行號、工廠等。
  • 訴訟事件：不限於「商務案件」，凡涉及該商業主體之訴訟（如貨款糾紛、侵權行為等）均屬之。
  • 得：法院裁量權，可向經理人送達，亦可向負責人或其他人送達。
  • 經理人：包括總經理、分公司經理、廠長、店長等有管理權限之人。
例1.
  • 法院審理甲對乙公司之貨款訴訟，將開庭通知書送達予乙公司之「總經理」。
  • → 關於商業之訴訟事件，送達得向經理人為之
例2.
  • 乙公司設有台中分公司，法院將文書送達予該分公司經理。
對訴訟代理人之送達
  • 法院原則上將文書送達給訴訟代理人；但法官認為必要時，也可以命送達給當事人本人。
訴訟代理人受送達之權限「未受限制」者，送達「應」向該代理人為之
  • 訴訟代理人：依委任狀授權之律師或非律師代理人。
  • 受送達之權限：訴訟代理人「有受送達之權限」。
  • 未受限制：若當事人於委任狀中特別約定「代理人不得代收送達」，則限制之；否則即屬未受限制。
  • 送達「應」向該代理人為之：法院應優先向代理人送達。向代理人送達，即視為對當事人本人合法送達（送達效力及於本人）。
但審判長認為必要時，得命送達於當事人本人
  • 必要時：例如：代理人遲延轉交文書，可能影響當事人權益。
  • 得命送達於當事人本人：法院可「同時」送達代理人及本人，或「改」送達本人。
例1.
  • 甲委任律師乙為訴訟代理人（未限制受送達權限）。法院應將開庭通知書送達予乙（代理人事務所）。
  • → 訴訟代理人受送達之權限「未受限制」者，送達「應」向該代理人為之
例2.
  • 甲委任律師乙，但乙已出國且無法聯繫，審判長認有必要，命法院另將判決書送達予甲本人。
  • → 審判長認為必要時，得命送達於當事人本人
送達代收人
  • 當事人可指定送達代收人，法院會把文書送給代收人。
    • 如果在台灣沒有地址，就必須指定一個在台灣的代收人。
  • 指定的送達代收人，效力會自動涵蓋同一地區的各級法院；但如果當事人特別聲明只限於某法院，就只在那個法院有效。
當事人或代理人經「指定送達代收人」向受訴法院「陳明」者，應向該代收人為送達
  • 當事人或代理人：原告、被告、上訴人、抗告人或其訴訟代理人。
  • 指定送達代收人：指定第三人（如律師、事務所人員）代為收受送達。
  • 向受訴法院陳明：須以書狀或言詞向法院陳報該代收人之姓名、地址。
  • 應向該代收人為送達：法院應將文書送達予代收人。向代收人送達，即視為對當事人本人合法送達。
原告、聲請人、上訴人或抗告人於我國「無送達處所」者，「應指定」送達代收人
  • 無送達處所：在中華民國境內無「住居所」、「事務所」或「營業所」可收受送達。例如：外國人、外國公司在台無地址。
  • 「應指定」送達代收人：強制義務。若不指定，法院得命補正；逾期不補正，得駁回其起訴、聲請、上訴或抗告。
送達代收人「經指定陳明後」，其效力「及於同地之各級法院」。但該當事人或代理人別有陳明者，不在此限
  • 效力及於同地之各級法院：例如：向「臺灣臺北地方法院」陳明代收人，效力亦及於「臺灣高等法院」（同為臺北市）。
  • 別有陳明：當事人可於指定時特別聲明「本代收人僅限於○○法院」。
例1.
  • 甲委任律師乙，並向法院陳明「指定乙為送達代收人」。法院應將文書送達予乙。
例2.
  • 甲（美國人）在台無住所，提起訴訟。法院命甲指定在台之送達代收人（如律師）。
  • 甲指定後，法院向該代收人送達。
  • → 原告於我國「無送達處所」者，「應指定」送達代收人
例3.
  • 甲向臺北地院陳明指定乙律師為送達代收人（未限制）。
  • 案件上訴至臺灣高等法院（同地），法院應仍向乙律師送達。
  • → 送達代收人「經指定陳明後」，其效力「及於同地之各級法院」
補充送達（交付同居人或受僱人）
  • 送達時若沒碰到本人，可以把文書交給有辨別事理能力的同居人或受僱人（例如配偶、員工）。
    • 但如果代收人是對造當事人，就不能交給他。
送達於住居所、事務所或營業所不獲會晤應受送達人者
  • 已至法定送達處所，但應受送達人「本人」不在場。
得將文書付與「有辨別事理能力」之「同居人或受僱人」
  • 有辨別事理能力：非未成年人或精神障礙者（通常以「滿18歲」且「心智正常」為標準）。
  • 同居人：與應受送達人同住之人（如配偶、父母、成年子女、室友）。
  • 受僱人：受應受送達人僱用之人（如公司員工、大樓管理員、管家）。
例外：如同居人或受僱人為「他造當事人」者，不得代收
  • 他造當事人：即訴訟之「對造」（原告送達予被告時，被告之同居人為原告本人時）。
  • 若代收人係對造，則不得將文書交付予其代收（因可能故意不轉交）。
例1.
  • 法院至甲（被告）之住所送達，甲不在，其配偶乙（成年人）在場。法院將文書交付乙。
  • → 交付配偶代收
例2.
  • 法院至甲之事務所送達，甲不在，其受僱人丙（員工）在場。法院將文書交付丙。
  • → 交付受僱人代收
例3.
  • 甲（原告）對乙（被告）提起訴訟。法院至乙之住所送達，乙不在，其同居人甲（即原告本人）在場。法院不得將文書交付甲。
  • → 同居人為「他造當事人」，不得代收
寄存送達
  • 無法直接或補充送達時，可將文書寄存於派出所或村里辦公室，貼通知書在門首及信箱。
  • 寄存送達從寄存日起算10天後才生效，寄存機關要保存2個月。
適用情況：本人不在、無人可代收
  • 如應受送達人不在、無同居人或受僱人、代收人拒絕收受等。
寄存方式：將文書「寄存」送達地之「自治機關」或「警察機關」
  • 自治機關：村里長辦公室、鄉鎮市公所。
  • 警察機關：派出所、警察局。
並作「送達通知書兩份」，一份黏貼於送達處所門首，另一份置於該送達處所信箱或其他適當位置
  • 送達通知書：用以通知應受送達人「文書已寄存」之書面通知。
  • 黏貼門首：使應受送達人返家時能看到。
  • 置於信箱：確保通知送達。
生效時點：寄存送達，自寄存之日起，經「十日發生效力」
  • 自寄存之日起：自「文書寄存於自治或警察機關」之翌日起算。
  • 經十日：須經過「10日」始生送達效力（如寄存日為1月1日，則1月11日生效）。
  • 若應受送達人「提前」至寄存機關領取文書，則以「實際領取日」為送達日（實務見解）。
保存期限：寄存之文書自寄存之日起，寄存機關應「保存二個月」
  • 寄存機關須將文書保存「2個月」，以利應受送達人領取。
  • 逾期未領取，寄存機關得依規定退回。
例1.
  • 法院至甲之住所送達，甲不在，亦無同居人或受僱人可代收。法院將文書寄存於甲住所轄區之派出所，並將送達通知書貼於甲之門首及置於信箱。
  • 寄存日為1月1日，送達生效日為1月11日。
  • → 寄存送達，自寄存之日起，經「十日發生效力」
例2.
  • 甲於1月5日即至派出所領取寄存文書，則送達日為1月5日（實際領取日），而非1月11日。
  • → 提前領取，以領取日為送達日
留置送達
  • 如果應受送達人無正當理由拒絕簽收，送達人可以把文書留置在送達處所，即算送達；若無法留置，則改為寄存送達。
適用情況：應受送達人「無法律上理由」拒收
送達方式：將文書置於送達處所，以為送達。如有難以留置情事者，得改為寄存送達
  • 置於送達處所：將文書「留置」於送達處所（如住家門口、公司櫃台、辦公室桌上）。留置即完成送達（無須應受送達人簽收）。
  • 有難以留置情事：如應受送達人強力阻止、文書無法放置（如門鎖住、無法進入）。
  • 改為寄存送達：將文書寄存於自治或警察機關，並製作通知書黏貼門首及置於信箱，自寄存日起10日生效。
例1.
  • 法院執達員至甲之住所送達判決書，甲在場但明確表示「我不收」，且無正當理由。
  • 執達員將判決書放置於甲之桌上，並於送達證書註明「拒絕收受，留置送達」。
  • → 拒絕收受，留置送達
例2.
  • 同上例，甲將大門鎖住，拒絕執達員進入，亦不開門。
  • 執達員無法留置文書，改為寄存送達（將文書寄存於派出所，並貼通知書）。
  • → 難達留置，改寄存
送達證書
  • 送達完成後須製作送達證書，記載送達時間、地點、方式，由收領人簽名（或註明拒絕），並附卷存證。
送達人應作送達證書並簽名
  • 送達人：執達員、郵務人員（郵差）或其他法院指派人員。
  • 應作送達證書：強制規定，每次送達均須製作。
送達證書應記載下列事項
  1. 交送達之法院：法院名稱（如「臺灣臺北地方法院」）。
  2. 應受送達人：姓名（如「甲○○」）。
  3. 應送達之文書：文書名稱及件數（如「開庭通知書乙件」）。
  4. 送達處所及年、月、日、時：地址、日期、時間（如「臺北市○○路○號，113年1月1日上午10時」）。
  5. 送達方法：如「本人收受」、「交付同居人」、「寄存送達」、「留置送達」等。
送達證書應由收領人簽名、蓋章或按指印。如拒絕或不能簽名、蓋章或按指印者，送達人應記明其事由
  • 簽名、蓋章或按指印：三種方式均可。
  • 記明其事由：送達人應於證書上記載「拒絕簽名」或「不能簽名」之事由。
「非本人收領」者，送達人應記明「代收人姓名」
  • 若代收人（如同居人、受僱人）代收，應記載該代收人之姓名及與應受送達人之關係（如「配偶乙○○代收」）。
送達證書，應提出於法院附卷
  • 送達證書須交回法院，附於該案卷宗內，作為送達合法之證明。
例1.
  • 執達員將判決書送達予甲，甲本人簽名於送達證書。證書記載：「法院：臺北地院；受送達人：甲；文書：判決書；處所：臺北市○○路；時間：113/1/1 10:00；方法：本人收受。」
例2.
  • 甲不在，其配偶乙代收，送達證書記載：「收領人：乙（配偶）」。
  • → 「非本人收領」者，送達人應記明「代收人姓名」
不能送達之處理程序
  • 送達失敗時，送達人要寫報告說明原因並繳回文書；書記官要通知聲請送達的當事人，讓他採取後續措施。
適用情況：「不能為送達」者
  • 例如：「查無此人」、「已遷移」
處理方式：送達人應作報告書，記載不能送達事由。報告書交法院附卷，並繳回應送達之文書
  • 書面報告，載明「不能送達之具體原因」（如「該址查無此人」）。
  • 將報告書及原文書一併繳回法院，由法院附於卷宗。
書記官之通知義務：法院書記官應將不能送達之事由，通知使為送達之當事人
  • 通知使為送達之當事人：通常為「聲請送達」之當事人（如原告、上訴人）。
  • 通知方式：以「書面通知」或「電話告知」。
  • 目的：使當事人知悉送達失敗，以便採取後續措施（如聲請公示送達、陳報新址）。
例1.
  • 執達員至甲之地址送達，發現「查無此人」。執達員製作報告書記載「該址查無此人」，連同開庭通知書繳回法院。
  • 書記官通知原告：「被告甲送達失敗，請陳報新址或聲請公示送達。」
  • → 不能送達之事由，書記官通知當事人
受囑託送達機關之回報與通知義務
  • 受託機關回報送達結果後，書記官要將回報附卷；若回報無法送達，還要通知聲請送達的當事人。
受囑託之機關或公務員，經通知已為送達或不能為送達者，法院書記官應將通知書附卷
  • 受囑託送達之警察機關、村里長、外國法院、軍事機關、監所、外交部等。
  • 通知已為送達或不能為送達：受託機關將送達結果以「通知書」回報原法院。
  • 附卷：將該通知書附於法院卷宗，作為送達（或不能送達）之證明。
其不能為送達者，並應將其事由通知使為送達之當事人
  • 不能為送達者：如「查無此人」、「已遷移」、「拒絕收受」等。
  • 並應將其事由通知使為送達之當事人：書記官應將「不能送達之具體原因」以書面或電話通知聲請送達之當事人（如原告、上訴人）。
例1.
  • 法院囑託外國法院送達，外國法院回報「查無此人」。
  • 書記官將通知書附卷，並通知聲請送達之原告：「被告甲在外國查無此人，請陳報新址或聲請公示送達。」
  • → 不能送達之事由，書記官通知當事人
以電信傳真或其他科技設備傳送訴訟文書
  • 訴訟文書可用傳真或電子方式傳送；若對方確認收到或事先同意，就等同於合法送達。
訴訟文書，得以電信傳真或其他科技設備傳送之；其有下列情形之一者，傳送與送達有同一之效力：
  1. 應受送達人陳明已收領該文書者
    • 當事人已「明確表示」收到該文書（如回覆電子郵件、簽收傳真）。
  2. 訴訟關係人就特定訴訟文書聲請傳送者
    • 當事人或代理人「主動聲請」法院以科技設備傳送該文書（如同意電子送達）。
前項傳送辦法，由司法院定之
  • 授權司法院訂定「民事訴訟文書使用電信傳真或其他科技設備作業辦法」等相關規定。
例1.
  • 法院以電子郵件將開庭通知寄送予甲，甲回覆「已收到」。該傳送與送達有同一效力。
  • → 陳明收領
例2.
  • 甲事先聲請法院以傳真方式送達判決書，法院以傳真傳送。傳送與送達有同一效力。
  • → 聲請傳送

公示送達

公示送達之要件與聲請
  • 當事人地址不明、外交送達失敗或外國送達無效時，法院可依聲請或依職權以「公告」方式送達（公示送達）。
受訴法院得「依聲請」，「准為」公示送達
  • 依聲請：須由當事人主動聲請。
  • 「准為」公示送達：需經法院審查後核准，使得公示送達。
聲請事由
  1. 應為送達之「處所不明」
    • 如查無此人、已遷移、戶籍不明。
  2. 對有「治外法權」送達失敗
  3. 外國送達無法辦理或預知無效
駁回聲請公示送達之裁定，「得為抗告」
  • 對法院駁回公示送達聲請之裁定，當事人得提起抗告（10日內）。
「必要時」，法院得「依職權」命為公示送達
  • 要件：
    1. 有為公示送達之事由：如查無此人、已遷移、外國送達無法辦理。
    2. 無人為公示送達之聲請
    3. 為避免訴訟遲延認有必要
原告或曾受送達之被告「變更地址未陳明」，致為送達之處所不明者，受訴法院得「依職權」，命為公示送達
  • 若當事人搬家卻未通知法院，導致地址不明，法院得依職權公示送達。
原告、聲請人、上訴人或抗告人在「國內無地址」，卻「未指定送達代收人」，導致無法送達，法院得「依職權」公示送達
  • 原告、聲請人、上訴人或抗告人在「國內無地址」，依法應該指定國內送達代收人。未指定者，法院得「依職權」公示送達。
例1.
  • 甲起訴乙，但乙之戶籍地址查無此人。甲聲請公示送達，法院裁定准許。
  • → 應為送達之處所不明者，法院得依聲請，准為公示送達
例2.
  • 甲起訴乙，乙地址不明，甲未聲請公示送達。法院為避免訴訟遲延，依職權命為公示送達。
  • → 有為公示送達之事由、無人為公示送達之聲請，為避免訴訟遲延之必要，法院得依職權命為公示送達
例3.
  • 甲（原告）搬家後未通知法院，法院無法送達。法院依職權命為公示送達。
  • → 原告或曾受送達之被告「變更地址未陳明」，致為送達之處所不明者，受訴法院得「依職權」，命為公示送達
例4.
  • 甲聲請公示送達，法院認乙地址並非「不明」（如仍有聯絡可能），裁定駁回。甲提起抗告。
  • → 駁回聲請公示送達之裁定，「得為抗告」
公示送達之續行（依職權）
  • 對同一個當事人已經用過一次公示送達後，之後再要送達給他，法院可以直接主動再用公示送達，不用重新聲請。
依規定為公示送達後
  • 法院已依第149條（聲請或依職權）對某當事人為「公示送達」。
  • 公示送達已完成（如已公告，且生效）。
對於「同一當事人」仍應為公示送達者，「依職權」為之
  • 後續訴訟程序中，仍有文書須送達予「同一當事人」（如另一次開庭通知、判決書）。
  • 且該當事人之「處所不明」狀態仍未改變（仍無法以一般方式送達）。
  • 法院無須待當事人聲請，應主動再次為公示送達。
例1.
  • 甲起訴乙，法院首次對乙為公示送達（因乙地址不明）。
  • 後續法院需再送達「開庭通知書」予乙，法院即依職權再次為公示送達（無須甲再聲請）。
公示送達之方法
  • 公示送達須在法院公告處黏貼公告（通知書要直接貼），並在法院網站公告；必要時得登報。
公示送達，應由法院「書記官保管」應送達之文書
  • 文書（如判決書、開庭通知）由書記官「保管」，不寄送或交付他人。
  • 應受送達人得隨時向書記官「領取」。
並於法院公告處黏貼「公告」，「曉示」應受送達人隨時向其領取。應送達文書係「通知書」者，應將該通知書「黏貼於公告處」
  • 公告：於法院公告處張貼「公示送達公告」。
  • 曉示：公告載明「應受送達人應於期間內向書記官領取文書」。
  • 通知書：如開庭通知、補正通知等。
  • 黏貼於公告處：直接將「通知書」黏貼於公告處（使當事人能直接看到內容）。
除前項規定外，法院應將文書副本公告於「法院網站」。必要時，得登載於公報或新聞紙
  • 應：強制規定，須公告於法院網站（現代化方式）。
  • 文書副本：繕本、影本或節本。
  • 必要時，得登載於公報或新聞紙：法院有裁量權。認有必要時，才登報。
例1.
  • 法院對甲為公示送達，書記官保管判決書，並於法院公告處黏貼「公示送達公告」，載明甲應於期間內領取，另將文書影本公告於法院網站。
  • → 公示送達，應於法院公告處公告，並將文書影本公告於法院網站
公示送達之生效日期
  • 公示送達自公告或登報日起算，一般案件20天生效、外國案件60天生效；但第二次公示送達隔天就生效。
公示送達，自公告之日起，經「二十日」發生效力。但應受送達人「在外國」者，經「六十日」發生效力
  • 公告之日：若有登載於公報或報紙，以「最後登載日」為起算點。
  • 經二十日：自起算日之「翌日」起算，20日後發生送達效力。
  • 應受送達人「在外國」，期間延長為「60日」（以利其知悉）。
對「同一當事人」後續「再公示送達」：自黏貼公告處之翌日起，發生效力
  • 自黏貼公告處之翌日起：僅須「公告處黏貼」即可生效（無須經20日，因已曾公示送達）。
例1.
  • 法院於1月1日黏貼公告，並於1月1日公告於網站，經20日，於1月21日發生效力。
  • → 公示送達，自公告之日起，經「二十日」發生效力。
例2.
  • 應受送達人在美國，經60日發生效力。
  • → 應受送達人「在外國」者，經「六十日」發生效力
例3.
  • 續行公示送達，於1月2日（黏貼翌日）生效。
  • → 對「同一當事人」後續「再公示送達」：自黏貼公告處之翌日起，發生效力
公示送達之證書製作
  • 公示送達後，書記官須製作證書，載明事由及時間，並附卷存證。
為公示送達者，法院書記官應作「記載該事由」及年、月、日、時之「證書附卷」
  • 法院進行公示送達後，書記官必須製作一份「證書」，寫明「為什麼要公示送達」（事由）和「送達的年、月、日、時」，然後把這份證書附在卷宗裡。
例1.
  • 法院對甲為公示送達（因甲處所不明），書記官製作證書，記載「應受送達人甲應為送達之處所不明，中華民國113年1月1日上午10時黏貼公告」。
  • → 書記官製作證書，記載事由和「送達的年、月、日、時」並附卷
