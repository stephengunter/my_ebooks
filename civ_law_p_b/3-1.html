民事訴訟法 上訴審程序-第二審程序

第二審程序

第二審上訴之標的
  • 對第一審的最後判決不服，原則上可以向高等法院上訴，但法律特別規定不能上訴的例外。
對於第一審之終局判決，除別有規定外，得上訴於管轄第二審之法院
  • 別有規定：如小額事件、簡易事件上訴別有規定。
判決前裁判之併受審判
  • 對終局判決上訴時，相關的中間裁判會一併被二審審查。
  • 但法律規定不得抗告或應單獨抗告的裁判，不在此限。
一審判決前之裁判，牽涉該判決者，並受第二審法院之審判
  • 指在第一審終局判決作出之前，法院在訴訟過程中曾經作成的「裁判」。
  • 包括裁定（如駁回參加、准許證據調查、命補正）及中間判決。
但依本法不得聲明不服或得以抗告聲明不服者，不在此限
  • 不得聲明不服：法律明文禁止對該裁判提起任何救濟。
  • 得以抗告聲明不服：此類裁判應在抗告期間內單獨提起抗告，若未提起，即告確定，不得於上訴時再爭執。
例1.
  • 第一審法院在訴訟中裁定駁回原告甲聲請傳喚關鍵證人丙。甲未對該裁定抗告。
  • 後第一審判決甲敗訴，甲對終局判決上訴。
  • 二審法院審理時，甲爭執「一審駁回傳喚證人丙的裁定不當」。
  • 該裁定牽涉終局判決（影響勝敗），二審法院應一併審查該裁定是否合法。
  • → 牽涉判決，併受審判
例2.
  • 第一審法院駁回甲聲請之假扣押裁定。
  • 甲未於10日內抗告，卻等到終局判決敗訴後，對判決上訴時一併爭執假扣押駁回不當。
  • 甲未即時抗告，該裁定已確定，二審法院不得審查。
  • → 應抗告未抗告，裁定已確定，二審法院不得審查
上訴權之捨棄
  • 判決後當事人可以放棄上訴權。在宣判時口頭放棄，要記在筆錄並通知對方。
當事人於第一審判決宣示、公告或送達後，得捨棄上訴權
  • 時間要件：判決已對外發生效力之後（宣示、公告或送達），但尚未逾上訴期間。
  • 捨棄的主體：可為勝訴方或敗訴方（勝訴方捨棄，表示對勝訴結果滿意，不擔心對造上訴；敗訴方捨棄，表示接受敗訴結果）
  • 方式：以書狀或言詞向法院為之。
當事人於宣示判決時，以言詞捨棄上訴權者，應記載於言詞辯論筆錄。如他造不在場，應將筆錄送達
  • 如果是在宣判當天，當場用嘴巴說要放棄：法院要記在筆錄裡；如果對方當時不在場，法院要把筆錄寄給他。
例1.
  • 法院宣示判決時，原告甲當場捨棄上訴權，但被告乙未到場。
  • 法院將記載捨棄的筆錄送達乙。
  • 乙收到後，知悉甲已捨棄，決定也不上訴，判決確定。
  • → 他造不在場，送達筆錄
上訴期間
  • 上訴要在判決送達後20天內提出。
  • 宣判或公告後、送達前就上訴，也有效。
提起上訴，應於第一審判決送達後「二十日不變期間內」為之
  • 上訴期間的長度：20日。
  • 起算點：第一審判決「送達」於當事人之日（不論勝敗訴，各當事人各自起算）。
  • 不變期間：除法律另有規定（如回復原狀）外，不得延長或縮短。
宣示或公告後送達前之上訴，亦有效力
  • 如果法院已經先宣判或公告了，只是判決書還沒寄到，你在這段時間就提起上訴，仍然是有效的。
例1.
  • 甲於113年5月1日收受判決書，遲至113年5月22日始提起上訴（送達後第21日）。
  • 甲於113年5月1日收受判決書，遲至113年5月22日始提起上訴（送達後第21日）。
  • → 上訴不合法，法院應裁定駁回
例2.
  • 台北地院於113年5月1日宣示判決（當庭朗讀主文），但判決書於113年5月10日始送達甲。
  • 甲於113年5月5日即提起上訴。上訴有效。
  • → 宣示後送達前上訴
上訴狀之程式
  • 上訴狀要寫清楚：誰告誰、對哪個判決、不服多少、希望怎麼改，以及具體的理由和證據。
提起上訴，應以上訴狀表明下列事項，提出於原第一審法院為之：
  1. 當事人及法定代理人
  2. 第一審判決及對於該判決上訴之陳述
    • 應記載第一審法院名稱、案號、判決日期（特定欲上訴的判決）。
    • 表明「對該判決不服，提起上訴」的意思。
  3. 對於第一審判決不服之程度，及應如何廢棄或變更之聲明
    • 上訴聲明（又稱「上訴之聲明」）：此為第二審審判範圍的界線。
    • 「不服之程度」：如「原判決不利於上訴人部分全部不服」或「僅就其中新臺幣50萬元部分不服」。
    • 「應如何廢棄或變更之聲明」：具體請求第二審法院如何判決，例如「原判決廢棄，被上訴人應給付上訴人新臺幣100萬元」。
  4. 上訴理由
上訴理由應表明下列事項：
  1. 應廢棄或變更原判決之理由
    • 上訴的法律上及事實上論點。
    • 例如：「原判決認定事實違反論理法則」、「原判決適用民法第184條錯誤」、「被上訴人已自認之事實，原判決未予採納」。
  2. 關於前款理由之事實及證據
    • 支持上訴理由的具體事實（例如「證人丙之證詞與監視器畫面不符」）及證據（例如「聲請傳喚證人丁」、「提出新鑑定報告」）。
上訴不合法之處理
  • 逾上訴期間或不能上訴的，直接駁回。
  • 程式有問題可補正，不補就駁回；但沒寫上訴理由不能直接駁回。
提起上訴，如逾上訴期間者，原第一審法院應「以裁定駁回」之
  • 逾20日上訴期間，上訴不合法。直接駁回。
對「不得上訴之判決」提起上訴者，原第一審法院應「以裁定駁回」之
  • 不得上訴之判決：例如中間判決、小額訴訟第二審判決。
上訴不合法但可以補正者，原第一審法院應「定期間命其補正」，如不於期間內補正，應以裁定駁回之
  • 可補正的上訴瑕疵：命其補正。例如：上訴狀未表明當事人、未記載第一審判決案號、未簽名、未表明上訴聲明。
  • 原法院應訂一個期間（通常7-14日）命補正；上訴人逾期不補正，裁定駁回。
上訴狀未具上訴理由者，不適用前項之規定
  • 法院不能以上訴人未附理由為由駁回上訴。理由可在上訴後補提（第444條之1）。
上訴狀之送達與卷宗送交
  • 上訴合法後，第一審法院要先把上訴狀寄給對方。
  • 等到所有人上訴期間都過了（或全體上訴），再把卷宗送交二審。
上訴未經依前條規定駁回者，第一審法院應速將上訴狀送達被上訴人
  • 義務：第一審法院應將上訴狀的繕本（或影本）送達被上訴人（即對造）
  • 送達後，被上訴人始知悉上訴事實及上訴聲明、理由，以便其提出答辯狀。
各當事人均提起上訴，或上訴期間已滿後，第一審法院應速將訴訟卷宗連同上訴狀及其他有關文件送交第二審法院
  • 卷宗移轉：包括全部訴訟卷宗、上訴狀、答辯狀、證據資料等。
  • 若第一審法院因另有其他程序（例如同一卷宗內尚有未結的保全程序、他案相關）仍需使用原卷宗，應自行製作影本或節本留存，再將正本送交二審，以免耽誤一審業務。
第二審法院對上訴不合法之處理與惡意上訴制裁
  • 二審發現上訴不合法，原則先命補正再駁回。
  • 一審已命補正而未補，二審可直接駁回。
  • 惡意上訴另可罰鍰12萬元。
上訴不合法者，第二審法院應以裁定駁回之。但其情形可以補正者，審判長應定期間先命補正
  • 上訴不合法：例如逾上訴期間、對不得上訴判決上訴、上訴狀未表明上訴聲明（一審未發現）、上訴人無訴訟能力未經合法代理等。
  • 可以補正的瑕疵：二審審判長應先定期命補正，逾期未補正才駁回。例如未簽名、未附委任狀。
上訴不合法之情形，已經原第一審法院定期間命其補正而未補正者，得不行前項但書之程序
  • 若一審法院已依第442條第2項命補正，上訴人逾期未補正，一審本應駁回（但可能一審誤將案件送交二審）。
  • 此時二審無須再次命補正，可直接駁回。這是為了避免重複程序。
上訴基於惡意或不當目的者，第二審法院或原第一審法院得各處上訴人、法定代理人、訴訟代理人12萬元以下之罰鍰
  • 主觀要件：上訴係「基於惡意或不當目的」，例如：
    • 明知上訴期間已過仍提起，企圖拖延。
    • 明知判決不得上訴，仍惡意上訴。
上訴理由書與第二審書狀程序
  • 上訴狀沒寫理由，法官可限期叫上訴人補提理由書。
  • 對方可提答辯狀，再互換書面意見。
  • 不補理由書可能被限制提出新主張。
上訴狀內未表明上訴理由者，審判長得定相當期間命上訴人提出理由書
  • 審判長「得」定期間：表示裁量權。實務上通常會命補提，以明確上訴範圍。
上訴人提出理由書後，除應依前條規定駁回者外，第二審法院應速將上訴理由書送達被上訴人
  • 若上訴人提出理由書，且上訴不合法，則不須送達。
  • 若上訴合法，法院應「速」送達被上訴人，使其知悉上訴具體理由。
審判長得定相當期間命被上訴人提出答辯狀，及命上訴人就答辯狀提出書面意見
  • 審判長可命被上訴人提出答辯狀（針對上訴理由答辯），再命上訴人對答辯狀提出書面意見（類似再辯論）。
  • 這有助於二審法官在開庭前掌握爭點。
當事人逾所定期間提出書狀者，法院得命該當事人以書狀說明其理由
  • 當事人若超過審判長指定的期限才提出書狀（如遲交理由書、答辯狀），法院有權命其以書面解釋為什麼遲延。
  • 此為「遲延說明」義務。
當事人未依命提出上訴理由書或未依前項規定說明者，第二審法院得不許提出新攻擊防禦方法，或於判決時依全辯論意旨斟酌之
  • 制裁規定。若上訴人未依第1項提出理由書，或違反第4項的說明義務，二審法院可以：
    • 準用第447條：原則上第二審不許提出新攻擊防禦方法。換言之，上訴人若遲延提出上訴理由，可能被禁止再提出新的攻擊方法。
    • 於判決時依全辯論意旨斟酌：法院可將上訴人消極不配合的態度，作為全辯論意旨的一部分，對其為不利的判斷（例如認其未盡主張責任）。
例1.
  • 甲上訴狀僅寫「對原判決不服」，未附理由。
  • 二審審判長裁定命甲於15日內提出上訴理由書。
  • 甲如期提出，詳列原判決違法之處及證據。二審法院將上訴理由書繕本送達乙。
  • 乙收受後得提出答辯狀。
例2.
  • 審判長命乙於20日內提出答辯狀。
  • 乙提出後，再命甲於10日內就答辯狀提出書面意見。
  • → 命被上訴人答辯及上訴人書面意見
例3.
  • 審判長命甲於15日內提出上訴理由書，甲置之不理。
  • 二審法院準用第447條，認定甲不得在後續程序中提出新攻擊防禦方法，僅能就原審已提出之主張為辯論。
第二審言詞辯論之範圍與要領陳述
  • 二審只能在當事人上訴的範圍內審理。
  • 開庭時可請當事人說一審重點或直接朗讀筆錄。
言詞辯論，應於上訴聲明之範圍內為之
  • 「上訴聲明」指上訴狀內記載的「對於第一審判決不服之程度，及應如何廢棄或變更之聲明」
  • 逾此範圍，法院不得審判。例如：上訴聲明僅要求廢棄原判決關於違約金的部分，二審就不能審理本金部分。
當事人應陳述第一審言詞辯論之要領。但審判長得令書記官朗讀第一審判決、筆錄或其他卷內文書代之
  • 原則：當事人（通常先由上訴人、再由被上訴人）應以口頭簡要說明第一審言詞辯論的重要內容。
  • 審判長可以指揮書記官直接朗讀第一審的判決書、言詞辯論筆錄、準備程序筆錄、勘驗筆錄、鑑定報告等文書，來代替當事人的口頭陳述。
例1.
  • 第一審判決乙應給付甲本金100萬元及違約金20萬元。
  • 甲僅就「違約金20萬元」敗訴部分上訴（主張違約金應為50萬元），對本金100萬元勝訴部分未上訴。
  • 二審言詞辯論僅能審理違約金部分，不得變更本金100萬元之判決。
  • → 上訴聲明範圍內審理
例2.
  • 二審言詞辯論期日，審判長請上訴人甲陳述第一審要領。
  • 甲說：「第一審主要爭點有二：被告乙是否有過失？損害金額為何？法院曾勘驗現場並傳喚證人丙、丁。」被上訴人乙後為補充。
  • → 當事人陳述一審要領
例3.
  • 審判長為節省時間，命書記官朗讀第一審判決書及準備程序筆錄。
  • 書記官朗讀完畢後，審判長問兩造有無補充。
  • → 朗讀筆錄代替
第二審訴之變更、追加與反訴之限制
  • 第二審要變更、追加或提反訴，原則要對方同意。
  • 但同一事實、金額加減、情事變更、合一確定、中間確認及抵銷餘額等例外情況不用。
第二審訴之變更或追加，非經他造同意，不得為之
  • 第二審原則：對方同意。他造若不同意，法院應駁回變更或追加。
但以下情形，不在此限
  1. 請求之基礎事實同一
  2. 擴張或減縮應受判決事項之聲明
  3. 因情事變更而以他項聲明代最初之聲明
  4. 該訴訟標的對於數人必須合一確定時，追加原非當事人之人為當事人。
  5. 中間確認之訴
第二審提起反訴，非經他造同意，不得為之
  • 第二審提起反訴，原則上須被上訴人（原告）同意。
但以下情形，不在此限
  1. 於某法律關係之成立與否有爭執，而本訴裁判應以該法律關係為據，並請求確定其關係者
    • 類似本訴中的中間確認之訴。
    • 例如：本訴請求給付租金，被上訴人爭執租賃關係不存在，上訴人可提起反訴請求確認租賃關係存在。
  2. 就同一訴訟標的有提起反訴之利益者
    • 本訴與反訴的訴訟標的相同，但兩造角色互換。
    • 例如：本訴請求確認債權不存在，反訴請求給付該債權。此為有反訴利益。
  3. 就主張抵銷之請求尚有餘額部分，有提起反訴之利益者
    • 例如：本訴請求100萬元，被上訴人（被告）於第一審主張以其對上訴人之120萬元債權抵銷。
      • 法院認抵銷成立，本訴請求消滅，但抵銷後尚有餘額20萬元。被上訴人可在第二審提起反訴請求該20萬元。
例1.
  • 甲在第二審欲將請求權基礎從「侵權行為」變更為「不當得利」，二者基礎事實不同一。
  • 乙不同意。法院不准變更。
  • → 須他造同意之變更
例2.
  • 甲於第二審將請求金額從100萬元擴張為150萬元（同一借款事實）
  • 「擴張應受判決事項之聲明」屬例外無須他造同意事由，法院得准許。
  • → 無須同意之擴張聲明
例3.
  • 乙於一審主張以對甲之120萬元債權抵銷甲之100萬元請求，一審認抵銷成立。
  • 乙於二審提起反訴，請求甲給付抵銷後餘額20萬元。
  • → 就同一訴訟標的有提起反訴之利益者，屬例外無須他造同意事由，法院得准許
第二審新攻擊防禦方法之限制
  • 二審原則不能提新主張新證據，除非法院違法、事後新事實、補充原主張、顯著事實、不可歸責、或顯失公平 ——而且要釋明。
二審當事人不得提出新攻擊或防禦方法
  • 「新攻擊或防禦方法」包括：新事實主張、新證據、新法律上抗辯（如時效抗辯、同時履行抗辯）、對對造主張的新否認等。
  • 只要是第一審言詞辯論終結前已存在（或已可提出）而未提出者，均屬之。
但有下列情形之一者，不在此限：
  1. 因第一審法院違背法令致未能提出者
    • 例如：第一審法院違法駁回證據聲請、不當限制當事人陳述、未依法闡明導致當事人不知應提出某項主張。
  2. 事實發生於第一審法院言詞辯論終結後者
    • 一審辯論終結後才發生的新事實（例如判決前一日起火導致標的物滅失），當事人不可能於一審提出，自應准許。
  3. 對於在第一審已提出之攻擊或防禦方法為補充者
    • 並非全新方法，而是針對一審已提出的主張，補充細節、補強證據。
    • 例如一審已主張「被告有過失」，二審補充「被告闖紅燈」的具體證據。
  4. 事實於法院已顯著或為其職務上所已知或應依職權調查證據者
    • 第278條（顯著事實、職務已知）及第288條（法院職權調查）的延伸。
    • 法院可主動知悉，不受當事人提出限制。
  5. 其他非可歸責於當事人之事由，致未能於第一審提出者
    • 概括條款，例如：證人突發重病無法於一審到庭、證據因天災滅失後才找回、對造惡意隱匿證據等。須非可歸責於提出方。
  6. 如不許其提出顯失公平者
    • 衡平條款。例如：新證據極為重要，不採納將導致實體判決嚴重違反正義，且對造並無重大不利益。
前項但書各款事由，當事人應釋明之
  • 釋明義務：當事人主張符合例外時，須提出即時能調查的證據（釋明），使法院大概相信其事由存在。
  • 例如提出一審法院違法駁回證據聲請的裁定、證明事實發生在一審辯論終結後的文件、證人重病之診斷證明等。
違反前二項之規定者，第二審法院應駁回之
  • 若當事人提出新攻擊防禦方法，但不符合六款例外（或未釋明），第二審法院應以「裁定」或在判決中「駁回」該新方法之提出，不予審酌。
例1.
  • 甲於第一審未主張時效抗辯，第二審始提出。
  • 甲無法釋明任何例外，二審法院應駁回該時效抗辯。
  • → 原則禁止
例2.
  • 一審甲已主張「乙有過失」，並提出目擊證人丙。
  • 二審甲另提出行車紀錄器畫面，證明乙闖紅燈。
  • → 屬於對一審已提出之攻擊方法的補充
例3.
  • 甲於二審提出新證據（一份一審前即存在的契約書），但未釋明任何例外，且一審時甲完全有機會提出。
  • 二審法院裁定駁回該證據之提出。
  • → 違反效果，駁回
第一審訴訟行為於第二審之效力
  • 在第一審做過的訴訟行為（自認、證據聲明、書狀等），上訴到第二審後依然有效，不必重做。
在第一審所為之訴訟行為，於第二審亦有效力
  • 上述第一審訴訟行為的效力，不因案件上訴而消滅或中斷，應繼續拘束當事人及法院。
例1.
  • 第一審中，被告乙自認「有向原告甲借款50萬元」。甲勝訴後乙上訴。
  • 第二審中，乙欲否認借款。法院依第448條，認定乙的一審自認在二審仍有效力，乙不得再為相反主張。
  • → 自認效力延續
例2.
  • 原告甲在第一審已提出準備書狀及證據清單。
  • 上訴二審後，甲無須重新提出該書狀及證據清單，第二審法院可直接援用。
  • → 書狀效力延續
第二審上訴無理由之判決
  • 二審認為上訴沒理由就駁回。
  • 原判決理由即使寫錯，只要結論正確，還是駁回上訴。
第二審法院認上訴為無理由者，應為駁回之判決
  • 「上訴無理由」：指上訴人主張「原判決應廢棄或變更」的請求，經二審審理後認為不成立。
  • 二審法院應在判決主文中諭知「上訴駁回」，並維持第一審判決的效力。
原判決依其「理由雖屬不當」，而依其他理由認為正當者，應以上訴為「無理由」
  • 「原判決理由不當」：如適用法律錯誤、理由矛盾、證據評價有誤。
  • 「而依其他理由認為正當」：但從「其他正確的法律理由」來看，原判決的「結論」（主文）仍然正確。
  • 此時二審仍應駁回上訴（維持原判的結論），但可在判決理由中更正或補充原判決的論述。
  • 例如：第一審以A理由判原告勝訴，但A理由錯誤；二審發現以B理由可以得出相同勝訴結論，則維持勝訴判決，但將理由改為B。
例1.
  • 第一審判決甲敗訴。甲上訴主張「乙確實有借款，原判決認定錯誤」。
  • 二審審理後，認為原判決認定事實正確、適用法律亦無違誤。二審判決「上訴駁回」
  • → 上訴無理由，駁回
例2.
  • 第一審以「乙違反民法第184條第1項前段」判決乙應負侵權責任。
  • 二審法院認為乙之行為應適用「民法第184條第2項（違反保護他人之法律）」，原判決引法條不當。
  • 但二審認為，無論適用哪一條，乙都應負賠償責任，結論相同。
  • 二審判決「上訴駁回」，並在理由中更正為「應適用民法第184條第2項」。
  • → 理由不當，結論正當，駁回上訴
第二審惡意上訴之制裁
  • 惡意、顯無理由的上訴，二審法院可罰上訴人、法定代理人、律師最高12萬元，並令其負擔對方律師費。
上訴基於惡意、不當目的或有重大過失
  • 「惡意」：明知無理由，仍惡意上訴（如騷擾對造）。
  • 「不當目的」：為達訴訟外目的（如拖延強制執行、製造談判籌碼）。
  • 「重大過失」：違反一般人的注意義務，對顯無理由之上訴盲目提出（例如上訴人完全未閱讀第一審判決即提起上訴）。
且事實上或法律上之主張欠缺合理依據
  • 上訴人所主張的事實或法律觀點，客觀上欠缺合理基礎。
第二審法院得各處上訴人、法定代理人、訴訟代理人12萬元以下之罰鍰
  • 「各處」指可對不同對象分別處罰，非總額12萬元。例如上訴人罰鍰6萬、律師罰鍰4萬。
被上訴人因此支出的律師費、開庭日費、交通費，得列為訴訟費用由上訴人負擔
第二審認上訴有理由之判決
  • 二審認為上訴有理由，必須在上訴人請求的範圍內，判決廢棄或變更原判決。
第二審法院認上訴為有理由者
  • 二審法院經過實體審理，認定上訴人主張原判決違法或不當是有理由的。
  • 包括：原判決認定事實違反證據法則、適用法律錯誤、程序有重大瑕疵影響判決結果等。
應於上訴聲明之範圍內
  • 二審法院只能在「上訴人聲明不服的範圍內」作出裁判。
  • 上訴聲明是上訴人請求廢棄或變更原判決的具體範圍（例如「原判決關於違約金超過20萬元部分廢棄」）。
  • 超過此範圍的部分，二審不得審判。
為廢棄或變更原判決之判決
  • 「廢棄」：指將原判決的全部或一部取消（但不直接代替判決）。
  • 「變更」指二審直接對訴訟標的作出新的實體判決，取代原判決。
  • 通常二審會先廢棄原判決，然後自為變更判決（如廢棄原判決，改判被上訴人給付若干）。
  • 若案件尚未達可自為判決的程度（如事實未明），二審得僅廢棄原判決，並發回更審（第451條）。
第一審程序有重大瑕疵之發回更審
  • 第一審有重大程序瑕疵且為維持審級制度必要時，二審可發回更審。
  • 但如果兩造都同意二審直接判，就不能發回。
適用前提：第一審之訴訟程序有重大之瑕疵者
  • 指違反程序法上重要規定，足以影響判決結果，且通常屬於第469條所列各款「判決當然違背法令」的事由，例如：
    • 判決法院之組織不合法
    • 當事人於訴訟未經合法代理
    • 訴訟未經合法送達、應命停止訴訟而未停止等
第二審法院得不經言詞辯論，以判決廢棄原判決，將該事件發回原法院。但以因維持審級制度認為必要時為限
  • 「得」而非「應」，表示二審法院有裁量權；但一旦認為「為維持審級制度有必要」，就應發回。
  • 「維持審級制度必要為限」：指若不發回，當事人將實質喪失第一審的審級利益。因為二審是事實審兼法律審，但若直接判決，當事人對第一審判決的上訴權形同被剝奪。
前項情形，應予當事人陳述意見之機會，如兩造同意願由第二審法院就該事件為裁判者，應自為判決
  • 二審在決定是否發回前，應先聽取雙方當事人的意見。
  • 若兩造都同意由二審直接裁判（而非發回），則二審「應」自為判決，不得發回。
  • 這體現了當事人處分權優先於審級利益。
依第一項之規定廢棄原判決者，其第一審訴訟程序有瑕疵之部分，視為亦經廢棄
  • 原判決被廢棄外，第一審訴訟程序中「有瑕疵的部分」（例如未經合法代理所進行的全部程序）也視同已被廢棄。
  • 原法院應從瑕疵發生前的狀態重新進行審理（而非繼續原程序）。
誤行通常程序之簡易事件於第二審之處理
  • 第一審該用簡易程序卻用了通常程序，二審不能因此發回，要改用簡易二審程序繼續審。
應適用簡易訴訟程序之事件，第二審法院「不得」以第一審法院行通常訴訟程序而「廢棄」原判決
  • 應適用簡易訴訟程序之事件：指依民事訴訟法第427條第1項（標的金額50萬元以下）或第2項（特定類型，如房屋租賃、占有、侵權等，不問金額）應行簡易程序的事件。
  • 禁止發回：即使第一審法院誤用通常程序，第二審法院也不能依第451條（程序重大瑕疵）將原判決廢棄發回。
前項情形，應適用簡易訴訟事件第二審程序之規定
  • 矯正方式：第二審應將該事件視為「簡易事件」，適用簡易事件的第二審程序。
例1.
  • 甲起訴請求乙給付30萬元貨款（應行簡易程序）。第一審法院誤行通常程序，判決甲敗訴。
  • 甲上訴到台灣高等法院（通常程序第二審）。高等法院發現第一審程序錯誤，但依第451-1條第1項，不得以此廢棄原判決發回。
  • 高等法院應將事件移轉或改由「台北地方法院合議庭」依簡易第二審程序審理。
  • → 簡易事件誤行通常程序，二審不得發回
第一審無管轄權於第二審之處理
  • 二審不能因一審無管轄權就發回。
  • 除非違反專屬管轄，此時應以判決移送給有管轄權的法院。
第二審法院「不得」以第一審法院「無管轄權而廢棄」原判決
  • 原則：即使第一審法院對案件無管轄權（例如被告住所地、契約履行地均不在其轄區），第二審法院也不能將原判決廢棄發回。
  • 這是為了訴訟經濟，避免已審理完成的案件因管轄問題而重新來過。
但違背「專屬管轄」之規定者，「不在此限」
  • 例外：如果第一審法院違反的是「專屬管轄」（如不動產分割訴訟第10條、再審之訴第499條等），第二審法院仍得廢棄原判決。
  • 專屬管轄是強行規定，違反者嚴重影響裁判正當性，無法治癒。
因第一審違背「專屬管轄」而廢棄原判決者，應以判決將該事件移送於管轄法院，並得不經言詞辯論
  • 僅適用於違反專屬管轄而廢棄的情形。
  • 此時第二審法院不應發回原法院，應以「判決」移送至有管轄權的法院（例如將事件從台北地院移送至專屬管轄的台南地院）。
例1.
  • 法院傳買賣契約約定履行地在台中，被告住所在台北，原告卻向高雄地院起訴（高雄無管轄權）
  • 第一審判決原告敗訴。原告上訴，二審發現高雄地院無管轄權，但非專屬管轄違反。
  • 二審不得以管轄錯誤廢棄原判決，應繼續審理上訴。
  • → 非專屬管轄，不得廢棄
例2.
  • 甲起訴請求分割甲、乙共有之台南土地，卻向台北地院起訴（不動產分割訴訟專屬台南地院管轄）
  • 第一審台北地院判決分割方案。乙上訴。
  • 二審認違反專屬管轄，乃廢棄原判決，並以判決將事件移送台南地院。
  • → 違反專屬管轄，得廢棄移送
第二審判決書對第一審判決之引用
  • 二審判決書的事實及理由，可以引用一審判決；但有新攻防方法或見解不同時，要另外寫清楚。
判決書內應記載之事實，得引用第一審判決
  • 第二審判決書的「事實」欄（包括原告聲明、被告聲明、兩造主張等），可以直接寫「引用第一審判決事實欄所載」，不必重複抄錄。
當事人提出新攻擊或防禦方法者，應併記載之
  • 如果當事人在第二審依第447條提出新的攻擊或防禦方法（例如新事實、新證據），這些新方法不能僅靠引用第一審判決，必須在二審判決書中一併記載，以明確二審的審理範圍。
判決書內應記載之理由，如第二審關於攻擊或防禦方法之意見及法律上之意見與第一審判決相同者，得引用之
  • 若二審法院對攻擊防禦方法的取捨、證據評價、法律適用等，與第一審判決完全相同，則可以引用第一審判決的理由。
  • 例如：「關於兩造爭執之A事實，本院認第一審判決理由欄第○段之論述為可採，爰予引用」。
意見如有不同者，應另行記載
  • 若二審法院對某項爭點有不同看法（例如第一審認定被告無過失，二審認定有過失），則必須自行撰寫理由，不能引用。
關於當事人提出新攻擊或防禦方法之意見，應併記載之
  • 對於當事人在二審提出的新攻擊防禦方法，二審法院不論是否採納，都必須在判決理由中明確記載其意見。
  • 例如准許或駁回、採信或不採信的理由。
假執行上訴之先為辯論及裁判
  • 對假執行上訴時，只要當事人聲請，二審必須優先辯論、優先裁判。
第二審法院「應依聲請」，就關於「假執行」之上訴，「先為辯論及裁判」
  • 發動條件：須由當事人（通常是受假執行宣告不利的一方，即債務人）向第二審法院提出聲請。
  • 對象：僅限於上訴聲明中針對「第一審判決關於假執行之宣告」的部分。假執行上訴通常與本案上訴一併提起，但本條允許將其分離出來優先處理。
  • 效果：第二審法院應優先（早於本案請求部分）進行言詞辯論，並先作成裁判（例如裁定或判決，實務上多以判決為之）。
  • 裁判內容可能包括：駁回假執行之上訴（維持假執行）、廢棄假執行之宣告、或命提供擔保免為假執行等。
例1.
  • 第一審判決甲勝訴，宣告甲得假執行。
  • 乙對本案及假執行均上訴，並聲請二審先就假執行部分辯論裁判。
  • 二審法院即先就假執行部分開庭，辯論後判決「廢棄第一審關於假執行之宣告」
  • → 聲請先審假執行
例2.
  • 乙聲請先審假執行，二審辯論後認乙如供擔保新臺幣100萬元，得免為假執行。
  • 二審判決「乙於供擔保100萬元後，免為假執行」
  • → 先審假執行，先判決供擔保免假執行
第二審法院對假執行之補充宣告與制裁性假執行
  • 對已確定部分，可聲請二審補充宣告假執行。
  • 惡意上訴拖延，可聲請二審直接宣告假執行以制裁。
第一審判決未宣告假執行或宣告附條件之假執行者
  • 第一種情況：第一審判決沒有宣告假執行，或是宣告了「附條件」的假執行（例如要提供擔保才能執行）。
其未經聲明不服之部分，第二審法院應依當事人之聲請，以裁定宣告假執行
  • 對於判決中「沒有人上訴的部分」（已確定部分），當事人可以聲請第二審法院以「裁定」補充宣告假執行。
第二審法院認為上訴人係「意圖延滯訴訟」而提起上訴或逾時提出攻擊或防禦方法可認為係意圖延滯訴訟者者
  • 第二種情況：如果上訴人提起上訴是為了「拖延訴訟」，或是逾時提出攻擊防禦方法也是為了拖延訴訟。
應依被上訴人聲請，以裁定就第一審判決宣告假執行
  • 第二審法院應依被上訴人（即對造）的聲請，以裁定就第一審判決「宣告假執行」，讓被上訴人可以提前執行，以制裁惡意拖延的上訴人。
例1.
  • 第一審判決被告乙應給付甲100萬元，但漏未宣告假執行。
  • 乙僅就其中20萬元上訴，其餘80萬元已確定。甲向二審法院聲請就80萬元部分宣告假執行。
  • 二審法院以裁定准許。
  • → 補充宣告假執行
例2.
  • 甲起訴乙請求給付100萬元，第一審判決甲勝訴（未宣告假執行）
  • 乙明知無理由，仍提起上訴，企圖拖延甲取得執行名義。
  • 甲聲請二審法院宣告假執行。二審法院認定乙係意圖延滯訴訟，裁定就第一審判決（100萬元）宣告假執行。
  • → 制裁意圖延滯訴訟之上訴
第二審維持第一審判決時之假執行宣告
  • 二審維持一審勝訴判決時，應依聲請宣告假執行；必要時法院可主動宣告。
關於財產權之訴訟，第二審法院維持第一審判決者
  • 適用範圍：限於財產權訴訟（如金錢、物品、不動產、債權等），不包括身分訴訟（如離婚、親子關係）或非財產權訴訟。
  • 條件：第二審判決駁回上訴，第一審判決的結論未被變更。
應於其範圍內，依聲請宣告假執行
  • 效果：法院應依勝訴方聲請，在「維持第一審判決的範圍內」宣告假執行。
  • 例如第一審判決被告應給付100萬元，二審駁回上訴，維持該判決，二審應依勝訴方聲請宣告就100萬元假執行。
前項宣告假執行，如有必要，亦得以職權為之
  • 法院可主動宣告。即使勝訴方未聲請，法院若認有必要（如債務人即將脫產、訴訟已歷時甚久），可依職權宣告假執行。
例1.
  • 第一審判決乙應給付甲100萬元。乙上訴，二審駁回乙的上訴，維持原判決。
  • 甲向二審法院聲請宣告假執行。二審判決主文除「上訴駁回」外，另諭知「本判決（或第一審判決）於甲供擔保新臺幣30萬元後得假執行」
  • → 維持原判決，依聲請宣告假執行
例2.
  • 同上例，甲未聲請假執行，但二審法院認乙有脫產之虞，乃依職權宣告假執行。
  • → 法院依職權宣告假執行
對第二審假執行裁判之救濟限制
  • 對二審假執行裁判，原則上不能抗告上訴，但涉及假執行後損害賠償的裁判除外。
對第二審法院關於假執行之裁判，不得聲明不服
  • 適用範圍：包括第二審法院對於假執行的各種裁定或判決中關於假執行的部分。
    • 例如：准許假執行之裁判、駁回假執行之裁判、命供擔保後假執行或免為假執行之裁判、依第456條宣告假執行之裁定。
  • 法律效果：當事人不得對該裁判提起抗告（若為裁定）或上訴（若為判決）。該裁判即告確定，不得再爭執。
例外：賠償因假執行所受損害之裁判，不在此限
  • 第395條第2項、第3項規定：當第一審判決宣告假執行，而第二審判決廢棄或變更該第一審判決時，被告（被上訴人）得聲請就因假執行所受之損害為賠償或返還不當得利之判決。
  • 此種裁判涉及實體賠償責任，非純粹假執行程序事項，故仍允許當事人聲明不服（如抗告或上訴）。
例1.
  • 第二審法院裁定准許被上訴人甲假執行之聲請。
  • → 假執行裁定不得抗告
例2.
  • 第一審判決宣告假執行，第二審廢棄該判決，並依第395條第2項判決原勝訴方甲應賠償乙因假執行所受之損害。
  • 甲對該賠償判決不服，提起上訴。
  • → 例外：賠償因假執行所受損害之裁判，不在此限
上訴之撤回
  • 判決前上訴人可隨時撤回上訴，但被上訴人已提附帶上訴時須其同意。
  • 合一確定案件，一人撤回會通知其他人，逾期未回覆視同撤回。
上訴人於終局判決前，得將上訴撤回
  • 原則：上訴人（包括共同上訴人）可在第二審終局判決作出前（包括判決宣示前）隨時撤回上訴。
  • 撤回後，訴訟繫屬消滅（第一審判決確定）。
但被上訴人已為「附帶上訴」者，應「得其同意」
  • 例外：若被上訴人已依第460條提起附帶上訴（即附帶對上訴人聲明不服），此時上訴人撤回上訴須經被上訴人同意，否則附帶上訴可能失所附麗。
訴訟標的對於共同訴訟之各人必須合一確定者
  • 例如：公同共有債權、連帶債務、分割共有物等，判決效力須對全體一致。
其中一人或數人撤回上訴時，法院應即通知共同訴訟人，命其於十日內表示是否撤回，逾期未為表示者，視為亦撤回上訴
  • 依第56條第1項第1款，一人上訴視為全體上訴。
  • 若其中一人撤回，法院須主動通知其他共同訴訟人，詢問是否也撤回。
  • 10日內未表示，視為同意撤回（即亦撤回上訴）。這避免判決矛盾。
撤回上訴者，喪失其上訴權
  • 撤回上訴後，不得再對同一判決提起上訴。
例1.
  • 甲上訴後，乙提起附帶上訴。
  • 甲欲撤回上訴，須得乙同意；若乙不同意，甲不得撤回。
  • → 附帶上訴已提，須同意
例2.
  • 甲、乙、丙為連帶債務人，一審判決連帶給付。僅甲提起上訴（視為乙、丙亦上訴）
  • 嗣後甲欲撤回上訴。法院應通知乙、丙，於10日內表示是否撤回。10日內未表示，視為同意撤回。
  • → 合一確定共同訴訟，一人撤回上訴，法院應通知共同訴訟人
附帶上訴
  • 被上訴人在二審辯論終結前，可隨時提起附帶上訴，不受上訴期間限制。
  • 發回後不得提，且可以口頭為之。
被上訴人於言詞辯論終結前，得為附帶上訴
  • 附帶上訴的內容：針對第一審判決不利於己的部分，請求廢棄或變更。
但經第三審法院發回或發交後，不得為之
  • 例外：案件若已上訴至第三審，第三審法院將案件發回或發交第二審更審時，被上訴人不得在更審程序中提起附帶上訴。因程序已趨於終結。
附帶上訴，雖在被上訴人之上訴期間已滿，或曾捨棄上訴權或「撤回上訴後」，「亦得為之」
  • 附帶上訴不受原上訴權時效限制。被上訴人即使已不能再「獨立上訴」，仍可「附帶上訴」。
  • 其法律性質並非行使原上訴權，而是利用對造上訴所開啟的程序。
例1.
  • 第一審判決乙應給付甲本金100萬元，但駁回甲其餘50萬元請求。
  • 甲僅就敗訴50萬元上訴。
  • 乙雖未上訴（且上訴期間已過），但可在二審言詞辯論終結前，提起附帶上訴主張「本金100萬元中應扣除20萬元」
  • → 被上訴人於言詞辯論終結前，得為附帶上訴
例2.
  • 案件經第三審發回二審更審。
  • 被上訴人乙不得在更審程序中提起附帶上訴。
  • → 第三審法院發回更審，不得附帶上訴
附帶上訴之效力與獨立化
  • 本上訴消滅時，附帶上訴原則失效；但若附帶上訴本身可獨立上訴，則變成獨立上訴。
上訴經撤回或因不合法而被駁回者，附帶上訴失其效力
  • 前提條件：本上訴（原上訴人之上訴）因為以下原因消滅：
    • 上訴人撤回上訴（第459條）。
    • 第二審法院以上訴不合法（如逾上訴期間、對不得上訴之判決上訴、程式不備且未補正）裁定駁回上訴（第444條）。
  • 原則：附帶上訴依附於本上訴而生，本上訴消滅，附帶上訴當然失效。法院無須就附帶上訴為實體裁判。
但附帶上訴備上訴之要件者，視為獨立之上訴
  • 例外：獨立化。「備上訴之要件」，指附帶上訴本身符合獨立上訴的法定要件，應包括：
    • 上訴權：附帶上訴人（原被上訴人）係因第一審判決對其不利部分而得提起上訴。
    • 上訴期間：附帶上訴人提起附帶上訴時，其獨立上訴期間尚未屆滿。
    • 程式完備：附帶上訴狀已表明當事人、上訴聲明、上訴理由等。
  • 當符合上述要件時，附帶上訴視為獨立上訴，法院應繼續審理該獨立上訴（如同被上訴人自己合法提起了上訴）。
例1.
  • 甲提起上訴後，又撤回上訴。
  • 乙曾提起附帶上訴，但乙的獨立上訴期間早已屆滿（無法獨立上訴），附帶上訴失其效力。
  • → 無法獨立上訴，附帶上訴失效
例2.
  • 甲提起上訴，乙於收受判決後第10日提起附帶上訴（乙的獨立上訴期間為20日，尚未屆滿）。
  • 嗣後甲撤回上訴。乙之附帶上訴具備獨立上訴要件，視為獨立上訴。
  • 乙之附帶上訴視為獨立上訴後，乙成為上訴人，甲成為被上訴人。
  • 第二審法院應就乙之請求為實體裁判。
  • → 附帶上訴獨立化，繼續審理
第二審判決確定後卷宗之送交
  • 第二審判決確定後，書記官要儘快把判決書附卷，送回第一審法院；非判決終結的情形也一樣。
上訴因判決而終結者，第二審法院書記官應於判決確定後，速將判決正本附入卷宗，「送交第一審法院」
  • 將完整卷宗送回原第一審法院（通常是地方法院）。
