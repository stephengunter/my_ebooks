民事訴訟法 通常訴訟程序-證據-鑑定

證據-鑑定

鑑定準用證人之規定
  • 鑑定人在程序上（車馬費、到場義務、具結、拒絕權等）大致比照證人處理。
  • 但若鑑定章節自己已有特殊規則（如選任、拒卻、書面報告），就依照鑑定自己的規則。
鑑定，除本目別有規定外，準用關於人證之規定
  • 鑑定：指法院選任或當事人合意指定的「鑑定人」，基於其特別知識、經驗或技能，就特定事件或事實（通常是具有專業性的爭點）向法院提供「意見」或「判斷」的證據方法。
    • 鑑定人不是「看到事發經過」的人，而是「事後分析證據」的人。
    • 例如：車禍事故的「行車速度鑑定」、筆跡真偽鑑定、建築物漏水原因鑑定、會計帳目鑑定、醫療過失鑑定。
  • 除本目別有規定外：指鑑定這一目裡面，有針對鑑定人的特殊性而另外訂定的條文。這些條文優先於證人規定。
    • 鑑定人不是「看到事發經過」的人，而是「事後分析證據」的人。
    • 例如：第326條（選任鑑定人）、第327條（囑託鑑定）、第328條（拒卻鑑定人）、第331條（拒卻鑑定人之裁定程序）、第333條（多數鑑定人陳述方式）、第334條（鑑定報告之要件）等，都是鑑目特有規定，不準用證人相關條文。
  • 準用關於人證之規定：具體被準用的條文包括：到場義務（第302條）、期日通知（第299條）、拒絕證言（第307條，調整後適用）、具結義務（第312條至第314條，但有修正）、日費旅費（第323條）、隔別訊問與對質（第317條）、命當事人退庭（第321條）等。
例1.
  • 法院選任結構技師甲為鑑定人，就房屋傾斜原因出具鑑定意見。
  • 甲經合法通知，無正當理由不到庭，法院依第303條（人證規定）對甲處以罰鍰。
  • 鑑定準用人證關於罰鍰之規定，法院得對無故不到之鑑定人處罰鍰。
  • → 鑑定準用證到場義務與罰鍰
例2.
  • 當事人聲請法院傳喚證人丙，丙因生病無法到庭。證人不可替代，法院只能延期。
  • 但法院原選任鑑定人丁，丁也生病無法到庭，法院卻可依第326條第3項「更換鑑定人」
  • 因為鑑定人原則上可替代。鑑定人「可更換」不準用證人「不可替代」之性質，此為「除本目別有規定外」的展現。
  • → 不準用證人不可替代性
聲請鑑定之程式
  • 想請專家鑑定，不能只喊「我要鑑定」，必須說清楚「到底要鑑定什麼具體問題」。
聲請鑑定，應表明鑑定之事項
  • 聲請鑑定：指當事人（原告或被告）向法院提出書狀或言詞請求，要求法院選任鑑定人，就某一專業事項提出意見。
  • 應表明：強制性規定。未表明或表明不明確者，法院得命補正；逾期不補正，得駁回聲請。
  • 鑑定之事項：指「應由鑑定人提供專業意見的具體事實或問題」，而非法律適用問題（法律問題屬法院職權）。 常見鑑定事項類型：
    • 因果關係鑑定：例如「系爭醫療行為是否為病人死亡之原因」。
    • 損害數額鑑定：例如「系爭建物因漏水所致之減損價值」。
    • 專業標準鑑定：例如「系爭工程之施工是否符合建築技術規則」。
例1.
  • 原告主張被告積欠借款，被告否認借據上簽名為其所為。
  • 原告聲請鑑定：「請求鑑定系爭借據上『張三』之簽名筆跡，是否與被告當庭書寫之筆跡或其在銀行留存之簽名卡相符。」
  • → 聲請鑑定，應表明鑑定之事項
鑑定人之選任、人數、合意指定與撤換
  • 原則上法院挑專家，但若兩造都同意同一位專家，法院就得聽話——除非那專家實在太扯。
  • 法院隨時有權把不適任的專家換掉。
鑑定人「由法院選任」，並定其人數
  • 法院：指「現在正在審理這個案件的法院」（合議庭或獨任法官）。
  • 選任：法院有裁量權，可以從政府公告的鑑定人名冊、學術機構、專業公會或其他有特別知識經驗的個人中挑選。
  • 定其人數：法院決定要請1位、3位還是更多鑑定人。通常1位即足，但重大或複雜案件（如醫療糾紛、專利侵權、重大工程）可能選任3位組成鑑定小組。
法院於選任鑑定人前，得命當事人陳述意見
  • 得：裁量權，非強制。法官可問雙方「你們有沒有推薦的鑑定人或機構？」也可不問直接指定。
  • 命當事人陳述意見：法院可發函或當庭詢問。當事人可建議人選、機構，或表示對特定人選的反對意見（如該鑑定人曾與對造有長期合作關係）。
    • 實務上，法院多半會先函詢雙方有無合意人選，以促進訴訟和諧。
經當事人「合意指定」鑑定人者，應「從其合意」選任之
  • 當事人合意指定：原告與被告「雙方共同」以書面或言詞一致同意某一位（或幾位）特定鑑定人，或某個鑑定機構（如「中華民國建築師公會全國聯合會」）。
  • 應從其合意：強制規定。法院沒有拒絕的自由，必須依照雙方指定的人選來選任。這是對當事人程序主體權的尊重。
    • 立法理由：避免法院指定的一方偏好的鑑定人遭對造不斷質疑，拖延訴訟；雙方合意的人選，事後較少爭議。
但法院認其人選「顯不適當」時，不在此限
  • 顯不適當：例外條款，法院須有「明顯、重大」的理由才能推翻當事人合意。例如：
    • 該鑑定人無法定資格（如不具技師執照）。
    • 該鑑定人與本案有直接利害關係（如鑑定人是被告的父親）。
  • 不在此限：法院可以不受當事人合意的拘束，自行另選鑑定人。但法院必須在裁定中說明「顯不適當」的理由。
已選任之鑑定人，法院「得撤換」之
  • 得撤換：法院的固有權限，無須當事人同意。事由包括：鑑定人無正當理由拖延不出具報告、報告品質低劣、發現有偏頗之虞、喪失資格、生病無法繼續、或當事人合意要求撤換等。
  • 撤換後，法院可選任新鑑定人。
例1.
  • 在醫療過失訴訟中，原告聲請鑑定。
  • 法院未詢問當事人意見，直接自衛生福利部醫事審議委員會名單中， 選任一位未曾醫治過兩造的心臟科權威醫師為鑑定人，人數為1人。
  • 法院有權主動選任，且「得」命陳述意見而非「應」，故未詢問亦不違法。
  • → 鑑定人「由法院選任」，並定其人數
例2.
  • 在筆跡真偽訴訟中，原告和被告共同具狀表示：「雙方合意指定內政部警政署刑事警察局文書鑑識科為本案鑑定機關。」
  • 法院審查該局確有此專業能力，且無顯不適當情事。法院「應」從其合意選任，不得另選其他機關。
  • → 當事人「合意指定」鑑定人者，應「從其合意」選任之
例3.
  • 法院選任會計師甲為鑑定人，命其於2個月內提出公司帳目鑑定報告。
  • 甲藉故拖延6個月仍未提出，經多次催告無效。法院撤換甲，另選任會計師乙。
  • → 已選任之鑑定人，法院「得撤換」之
受命法官或受託法官選任鑑定人之準用
  • 受命法官或受託法官在需要鑑定時，可以自己選專家、尊重雙方合意、也可以換人，但如果原審法院已經指定了專家，就不能另請高明。
有調查證據權限之受命法官或受託法官
  • 受命法官：在合議庭中，經審判長指定負責準備程序或特定證據調查的法官
    • 此處限定為「有調查證據權限」的受命法官，因為並非所有受命法官都被授權調查證據（有些只負責調解或整理爭點）。
  • 受託法官：受訴法院囑託其他法院代為調查證據時，被囑託法院所指派的法官。同樣限於「有調查證據權限」者。
  • 常見情境：受命法官在準備程序中，發現需要筆跡鑑定；或受託法官在外縣市訊問證人時，發現證人提出的書面有偽造嫌疑，需要即時鑑定。
依鑑定調查證據者，準用前條之規定
  • 依鑑定調查證據者：指該法官正在進行的證據調查方法，是「鑑定」，而非訊問證人或勘驗等其他方法。
    • 只有當該法官是在進行鑑定相關的調查時，才準用前條；若他在做其他事情（如調解），則不適用。
  • 準用前條之規定：前條：即第326條（鑑定人之選任、人數、合意指定與撤換）。 具體準用的內容包括：
    • 受命法官或受託法官有權「選任鑑定人並定其人數」。
    • 選任前「得」命當事人陳述意見。
    • 若當事人合意指定鑑定人，原則上「應從其合意」，除非顯不適當。
    • 已選任之鑑定人，「得」撤換之（同第326條第3項）。
但經受訴法院選任鑑定人者，不在此限
  • 但書：例外規定。若受訴法院（原審法院合議庭或獨任法官）已經先依第326條選任了某位鑑定人，那麼受命法官或受託法官就不能再用本條前段的準用權限，去選任「另一個」鑑定人或推翻受訴法院的選任。
例1.
  • 台北地方法院合議庭指定李法官為受命法官進行準備程序。
  • 審理中，兩造就借據上的指紋是否為被告所有發生爭執，且受訴法院尚未選任鑑定人。
  • 李法官當庭詢問雙方有無合意人選，雙方無法合意，李法官遂依職權選任刑事警察局指紋鑑識科為鑑定人，並命原告預繳鑑定費用。
  • 受命法官有調查證據權限，且受訴法院尚未選任鑑定人，故準用第326條，有權自行選任。
  • → 受命法官選任鑑定人
例2.
  • 高雄地方法院審理A案，已依第326條選任陳土木技師為鑑定人就房屋傾斜原因進行鑑定。
  • 因證人住在台中，高雄地院囑託台中地方法院王法官為受託法官訊問證人。
  • 訊問中，證人提出一張房屋設計圖，當事人爭執該圖是否為原設計圖。
  • 王法官認為需要筆跡及圖面鑑定，但受訴法院已選任陳土木技師（雖其專長非筆跡，但該案鑑定統一由陳技師負責統籌，可再委外）。
  • 王法官決定不另選鑑定人，而是通知陳土木技師前來協助說明。
  • → 因受訴法院已選任鑑定人，受託法官不得再自行選任另一鑑定人
鑑定人之義務
  • 只要你的專業能力夠強，或是機關公派的鑑定人員，法院找你當鑑定人你就不能說不，這是法律賦予你的社會義務。
具有鑑定所需之特別「學識經驗」或經機關委任有「鑑定職務」者
  • 特別學識經驗：指超越一般常人的專業知識或實務經驗，且與本案待鑑定事項直接相關。例如：心臟科醫師之於醫療過失、土木技師之於房屋傾斜、書法鑑定專家之於筆跡真偽。
  • 經機關委任有鑑定職務：該機關在組織編制或職務說明中，明定該人員的工作內容包含「鑑定、檢驗、化驗、分析」等事項。例如：法務部調查局化學組調查員、縣市警察局鑑識中心巡官。
於他人之訴訟，有為鑑定人之義務
  • 他人之訴訟：指非鑑定人自己的訴訟。若鑑定人是訴訟當事人本人，當然不負此義務（且應迴避）。
  • 為鑑定人之義務：法律上的強制性要求，違反者可能有不利效果（但本法對鑑定人拒絕義務，並不像證人不到場有罰鍰或拘提的直接罰則，而是由法院審查其拒絕理由是否合法，若無正當理由拒絕，法院得處以罰鍰──此為第329條第2項之反面解釋）。
例1.
  • 某醫學中心心臟科主任陳醫師，是全台知名的冠狀動脈繞道手術權威。
  • 某醫療過失訴訟中，法院選任陳醫師為鑑定人，鑑定被告醫師的手術是否符合醫療常規。
  • 陳醫師回函：「我工作太忙，不想接。」
  • 陳醫師具有特別學識經驗，有為鑑定人之義務，不得以「忙碌」為由拒絕。
  • 法院可依第329條審查其拒絕是否正當，若無正當理由，得處罰鍰。
  • → 具有特別學識經驗之醫師，有為鑑定人之義務
例2.
  • 刑事警察局鑑識科王科員，主要負責文書鑑定。
  • 某民事訴訟中，法院選任王科員為筆跡鑑定人，鑑定遺囑真偽。
  • 王科員表示：「我現在刑事案件太多，不想接民事案件。」
  • 王科員經機關委任有鑑定職務，對民事訴訟亦有鑑定義務，不得選擇性拒絕。
  • → 經機關委任有鑑定職務者，有為鑑定人之義務
鑑定人不得拘提
  • 鑑定人不來，法院只能罰錢或換人，絕不能派警察把他抓來──因為專家可以換，不像目擊證人只有一個。
鑑定人不得拘提
  • 拘提：指司法警察或法院執達員以強制力（上手銬、押解）將鑑定人帶到法庭的強制處分。依第303條第2項，證人經合法通知無正當理由不到場，法院得以裁定拘提之。
  • 法律效果：若法院誤發拘票拘提鑑定人，該拘提行為違法，鑑定人可即時聲明異議，甚至請求國家賠償。
例1.
  • 法院選任某土木技師公會之技師甲為鑑定人，就房屋傾斜原因進行鑑定。
  • 甲經兩次合法通知，均以「工作太忙」為由未到場說明。
  • 鑑定人不得拘提。法院應對甲處以罰鍰，並撤換鑑定人，另選任乙技師。
  • → 鑑定人不到，法院不得拘提
鑑定人之迴避事由與拒絕鑑定之許可
  • 鑑定人跟案子有特殊關係原則上不能用，除非找不到別人或雙方都同意。
  • 鑑定人若有正當理由，即使法律沒明列，法院也可以准他不幹。
鑑定人與當事人有親屬、僱傭、代理等「當然迴避事由」者，不得為鑑定人
  • 簡言之，鑑定人不能與當事人有密切的身分、代理或利益關係。
例外1.無其他適當人可為選任
  • 例如在離島偏鄉，全縣只有一位具有該專業的技師；或某種極冷門的專業（如特定古物修復），全國僅有一人。此時勉強用該有迴避事由者，總比無法鑑定好。
例外2.經當事人合意指定
  • 若原告與被告「都知道」這位鑑定人是某造的表哥，但雙方都同意由他鑑定，法院應尊重當事人合意。此為處分權主義的展現。
經「兩造同意」者，證人亦得於法院外「以書狀為陳述」
  • 「書狀作證」之二。只要雙方都同意，可以不經過公證人，直接寫書狀陳述。
鑑定人無「得拒絕證言事由」而拒絕鑑定，如法院「認為正當」者，「亦得免除」其鑑定義務
  • 得拒絕證言事由：涉及自身或親屬受刑事追訴、職業秘密、營業秘密等。
  • 而拒絕鑑定：鑑定人提出的理由，不在以上的列舉範圍內。
  • 法院認為正當：由法院依個案裁量。常見的正當理由包括：健康因素、時間因素、技術或資源因素（如需要百萬級的電子顯微鏡）。
  • 亦得免除：法院「得」免除，而非「應」免除。法院若認為理由不充分，可命其鑑定，並於拒絕時處以罰鍰。
例1.
  • 法院選任甲建築師為鑑定人，鑑定房屋漏水原因。
  • 被告發現甲是原告的親哥哥（四親等內血親，屬第32條第1款）。被告聲請拒卻。
  • 法院審查後認定甲不得為鑑定人，撤銷選任。
  • → 絕對迴避，不得為鑑定人
例2.
  • 雙方都知道丙會計師是被告公司的簽證會計師（有僱傭關係，屬第32條第4款類似關係）
  • 但雙方認為丙最熟悉帳務，合意指定丙為鑑定人。法院從之。
  • → 當事人合意指定，迴避事由不予排除
例3.
  • 法院選任丁醫師為醫療過失鑑定人。
  • 丁醫師回覆：「本人下個月將赴美參加國際醫學年會並擔任主講人，為期三週，期間與鑑定時程完全重疊， 且年會已籌備兩年無法取消。」
  • 法院審查後認為出國學術交流屬正當理由，裁定免除丁醫師的鑑定義務。
  • → 正當理由，法院裁定免除鑑定義務
拒卻鑑定人
  • 你覺得鑑定人不公正，可以用法官迴避的理由趕走他，但不能嫌他當過證人。
  • 而且要在專家開口或交報告前就喊停，除非你事後才知道他不對勁。
當事人得依聲請「法官迴避」之原因「拒卻」鑑定人
  • 聲請法官迴避之原因：指民事訴訟法第32條（法官自行迴避事由，如親屬、僱傭等）及第33條（當事人聲請法官迴避事由，如法官有偏頗之虞）。這些原因均可作為拒卻鑑定人的依據。
  • 拒卻：法律用語，即「聲請排除、迴避」之意。當事人應向法院提出書狀或言詞聲請，釋明拒卻原因。
但「不得」以鑑定人於該訴訟事件「曾為證人/鑑定人」為拒卻之原因
  • 曾為證人：例如主治醫師在本案先以證人身分說明病患到院時的傷勢，之後被選任為醫療過失鑑定人。
    • 此為常見情形，因證人提供的是親身經歷事實，鑑定人提供的是專業意見，兩者角色不同但不衝突，不當然構成偏頗。
  • 曾為鑑定人：例如同一位會計師先被選任為A事實的鑑定人，之後又被選任為B事實的鑑定人。這也不構成拒卻理由，除非有其他具體偏頗事證。
鑑定人已就鑑定事項「有所陳述」或已「提出鑑定」書後，「不得聲明拒卻」
  • 有所陳述：包括口頭說明、回答問題、當庭解釋初步意見等。
  • 已提出鑑定書：鑑定人已繳交書面報告給法院。
  • 不得聲明拒卻：此時拒卻權「消滅」，法院應駁回聲請。立法目的是避免當事人「先看風向」，若鑑定意見對己不利才發動拒卻，浪費已進行之鑑定資源。
例外不在此限：1.有當然迴避事由 2.拒卻之原因發生在後或知悉在後
  • 當然迴避事由：如親屬、僱傭等。
  • 拒卻之原因發生在後或知悉在後：知悉在後：拒卻原因其實早已存在，但當事人是在鑑定人陳述或提出報告「之後」才「偶然得知」。例如鑑定人隱瞞其與對造的表兄弟關係，當事人事後翻閱戶籍謄本才發現。
  • 不在此限：即使是鑑定人已陳述或提出報告，當事人仍可聲請拒卻。
例1.
  • 主治醫師乙先在本案以證人身分說明病人到院時傷勢，之後法院選任乙為醫療過失鑑定人。
  • 被告主張「乙已當過證人，心證已成偏頗」而聲請拒卻。
  • 不得以「曾為證人」為拒卻原因，法院應駁回聲請。
  • → 不得以曾為證人拒卻鑑定人
例2.
  • 法院選任丙土木技師為鑑定人。
  • 丙已提出書面鑑定報告，內容對原告不利。原告此時才聲請拒卻，主張「丙曾為被告公司之合作顧問」
  • 鑑定人已提出鑑定書後，不得聲明拒卻，且無「知悉在後」之適用（原告早已知悉），法院駁回。
  • → 鑑定人已就鑑定事項「有所陳述」或已「提出鑑定」書後，「不得聲明拒卻」
拒卻鑑定人之程序與釋明義務
  • 要把鑑定人趕走，必須寫明具體理由並向選任他的法院提出，而且要拿出證據讓法院「大概相信」你的理由是真的，不能空口說白話。
聲明拒卻鑑定人，應舉其原因，向選任鑑定人之法院或法官為之
  • 聲明拒卻鑑定人：即「向法院提出聲請，要求排除該鑑定人」。應以書狀為原則（提出「聲明拒卻狀」），亦可在期日以言詞提出並記明筆錄。
  • 應舉其原因：不能僅空泛陳述「我覺得他不公正」、「他看起來偏袒對方」。必須具體說明拒卻所依據的法律上原因。例如：「鑑定人甲與被告為配偶關係，違反第32條第1款。」
  • 向選任鑑定人之法院或法官為之：這是管轄的特別規定，不得向其他法院或法官提出。
拒卻原因、知悉在後之事實，應釋明之
  • 常見釋明內容：提出戶籍謄本顯示鑑定人與對造於某日結婚（發生在後）；提出對話紀錄證明昨日才從第三人處得知親屬關係（知悉在後）。
例1.
  • 被告發現法院選任的鑑定人甲會計師，其配偶是原告的妹妹。
  • 被告向受訴法院提出「聲明拒卻鑑定人狀」，載明：「拒卻事由：甲與原告有三親等姻親關係 （甲之配偶為原告之妹，依第32條第1款）。釋明證據：甲之戶籍謄本（謄本顯示配偶為原告之妹）、原告之戶籍謄本。」
  • → 已具體舉出原因，並向選任法院提出，且以書證釋明。
拒卻鑑定人裁定之救濟
  • 你想趕走鑑定人卻被法院駁回，可以抗告；但法院准你趕走對方時，對方不能抗告，換人就換人了。
聲請拒卻鑑定人經裁定駁回者，得為抗告
  • 被駁回的聲請人（即主張鑑定人不公的那一方）有權在裁定送達後10日內（依第487條），向直接上級法院提起抗告，請求上級法院撤銷原裁定、准許拒卻。
聲請拒卻鑑定人經「裁定許可」者，「不得抗告」
  • 此裁定一經作出，立即確定。
例1.
  • 原告聲請拒卻鑑定人甲，主張甲與被告有僱傭關係，但原告僅提出「聽說」而無任何證據。
  • 法院裁定「聲明為不當」，駁回拒卻。原告不服。原告得對駁回裁定提起抗告。
  • → 聲請拒卻鑑定人經裁定駁回者，得為抗告
例2.
  • 被告聲請拒卻鑑定人乙，提出乙與原告的四親等戶籍謄本為證。
  • 法院裁定「聲明為正當」，准許拒卻，撤銷乙的選任。
  • 原告當庭表示：「我要抗告！乙明明很公正！」
  • 原告（對造）不得對准許拒卻之裁定聲明不服，書記官記明筆錄後，法院即可另行選任新鑑定人。
  • → 聲請拒卻鑑定人經「裁定許可」者，「不得抗告」
鑑定人之具結義務
  • 鑑定人必須在開工前簽署誓詞，保證公平誠實、不說假話，否則以偽證罪論處。
鑑定人應於「鑑定前具結」
  • 應：強制規定。未經具結所為之鑑定，原則上無證據能力，不得作為裁判基礎。
  • 於鑑定前：具結必須在鑑定人開始實質鑑定工作（如檢視證物、進行實驗、分析數據）「之前」完成。實務上法院會先寄送結文請鑑定人簽署後寄回，或於期日當庭朗讀簽署。
  • 具結：以書面（結文）或口頭（於法庭朗讀結文並簽名）方式，表示願意承擔法律責任之莊嚴宣示。
結文內記載必為公正、誠實之鑑定，如有虛偽鑑定，願受偽證之處罰等語
  • 虛偽鑑定：鑑定人故意做出與其專業確信相反之虛假意見，或明知不實而仍為陳述。例如：明知筆跡為真卻謊稱為偽；明知漏水原因是施工不良卻推給天災。
  • 偽證之處罰：指刑法第168條偽證罪：「於執行審判職務之公署審判時，……於案情有重要關係之事項，供前或供後具結，而為虛偽陳述者，處七年以下有期徒刑。」鑑定人虛偽鑑定，以偽證罪論處。
例1.
  • 法院選任李會計師為鑑定人，未要求李會計師具結，李會計師直接提出鑑定報告。
  • 被告主張該報告未經具結，不得作為證據。
  • 鑑定人應於鑑定前具結而未為，該鑑定報告無證據能力，法院不得採為裁判基礎。
  • → 未具結，鑑定報告無證據能力
鑑定書之提出與到場說明
  • 法院可以讓鑑定人寫書面報告（結文釘在後面），如果報告寫不清楚，再叫他來法庭當面說明。
法院得命鑑定人具鑑定書陳述意見
  • 得命：裁量權。法院可選擇命提出書面，也可選擇命到場口頭陳述（後者少見）。原則上先命提出書面。
  • 鑑定書：書面報告，內容應包括：委託機關、案號、鑑定事項、鑑定方法、檢驗過程、使用設備、數據分析、結論等。格式不拘，但須完整可讀。
  • 陳述意見：以書面方式為之。學理上稱為「書面陳述」，法律上視為鑑定人已履行「陳述義務」。
  • 立法理由：多數鑑定事項（如筆跡、DNA、會計帳目、工程結構）需耗費數天至數月，不可能讓鑑定人天天在法庭上進行。書面報告是較合理的替代方式。
具結之結文，得「附於鑑定書」提出
  • 得附於鑑定書提出：鑑定人不須親自到法院朗讀結文並簽名，而是直接在鑑定書後附上已簽署的結文（或於鑑定書首頁載明具結意旨並簽名），一併送交法院。
鑑定書須說明者，得命鑑定人到場說明
  • 鑑定書須說明：指書面報告有不明確、矛盾、遺漏或兩造對其內容有重大爭執時，法院認為有進一步釐清之必要。
  • 得命鑑定人到場說明：法院可發通知，命鑑定人於指定期日到庭，就鑑定書內容接受法院或當事人的詢問（通常由審判長或受命法官主導，當事人亦可依第320條發問）。
例1.
  • 台北地方法院選任甲會計師為鑑定人，函文載明： 「請台端就系爭公司五年內帳目進行鑑定，並於三個月內提出鑑定書，結文請附於鑑定書後一併送院。」
  • 甲會計師完成鑑定後，將30頁鑑定報告連同已簽署之結文裝訂成冊，寄給法院。
  • → 命提出鑑定書，結文附於報告
例2.
  • 乙土木技師提出房屋傾斜原因之鑑定書，但報告中對「建物原始設計是否有瑕疵」與「施工不當之貢獻比例」兩點敘述模糊。
  • 被告攻擊該報告說理不清。法院開庭通知乙技師： 「請於民國113年10月5日到庭，就鑑定書中爭議部分到場說明。」乙技師到庭以簡報輔助口頭說明， 並接受兩造律師發問。」
  • → 鑑定書須說明，法院得命到場說明
多數鑑定人之陳述方式
  • 專家有兩位以上時，法院可以讓他們一起出報告、一起講，也可以各做各的、分開講，視案情需要自由決定。
鑑定人有數人者，得命其共同或各別陳述意見
  • 得命：法院裁量權。可視情況選擇最適當的方式，也可中途變更（先各別後共同）。
  • 共同陳述意見：鑑定人共同出具一份聯名鑑定書（全體簽名），或一同到庭，由審判長統一詢問，鑑定人可互相補充、討論後共同回答。
  • 各別陳述意見：：每位鑑定人各自出具獨立鑑定書，或分別隔離訊問（參考第317條精神），一人講完換另一人，相互不見面、不討論。
例1.
  • 法院就車禍事故的行車速度鑑定，選任三位車輛工程技師。
  • 法院命三人共同出具一份聯名鑑定書，並於開庭時一同到場，由審判長統一詢問。
  • 三位技師討論後共同回答：「我們一致認為，事發當時車速為每小時85公里。」
  • → 命共同陳述
例2.
  • 法院就一幅名畫的真偽，選任三位藝術鑑定專家。
  • 法院命各別提出獨立鑑定書，並分別通知三人不同日期到庭，隔別訊問。
  • 結果：兩位認為為真跡，一位認為為贗品。法院在判決中詳細比較三人理由後，採信多數見解。
  • → 命各別陳述
鑑定所需資料之取得與調查權限
  • 法院要打開資料庫給鑑定人用，還可以強制當事人或證人交出更多資料。
  • 鑑定人覺得不夠，可以主動申請調證據、問人，甚至自己開口發問。
鑑定所需資料在法院者，應告知鑑定人准其利用
  • 鑑定所需資料：指進行鑑定所必要的原始證據，包括卷宗內之書狀、筆錄、證物、勘驗筆錄、光碟、照片等。
  • 應告知鑑定人：法院應主動發函或以電話、當庭告知鑑定人：「卷內有以下資料，請至法院閱覽或由法院影印提供。」
  • 准其利用：鑑定人有權查閱、複製、影印、拍照或以其他方式取得資料。
必要時，得依職權或依聲請命證人或當事人提供鑑定所需資料
  • 必要時：法院裁量。例如資料不在卷內（如當事人持有原始設計圖、證人擁有現場錄影）、或卷內資料不完整。
  • 得依職權：法院可不待當事人請求，主動命提供。
  • 或依聲請：當事人或鑑定人可向法院聲請，命對造或證人提出資料。
  • 命證人或當事人提供：法院以裁定或處分方式，強制持有資料之人交出。
    • 拒絕提供之效果：依第345條（當事人無正當理由不從提出文書之命）或第349條（證人無正當理由不提出文書），法院得處罰鍰或對他造為不利之認定。
鑑定人因行鑑定，得「聲請」「調取證物或訊問證人/當事人」
  • 得聲請：鑑定人認為有必要時（例如需要查看現場壓痕、聽取證人描述製程），可向法院提出書面或言詞聲請。
  • 調取證物：請求法院向第三人（如銀行、醫院、政府機關）調取文件或實物。
  • 訊問證人或當事人：請求法院傳喚特定證人或當事人到庭，由法院進行訊問（鑑定人可在場聽取）。
經許可後，鑑定人並得對於證人或當事人自行發問
  • 經許可：法院審查聲請後，若認為與鑑定事項有關且必要，以裁定許可之。
  • 自行發問：許可後，鑑定人可親自（或在法院指揮下）向證人或當事人提問，不必透過審判長轉達。問題性質通常聚焦於鑑定所需的技術細節、數據來源、操作步驟等。
當事人亦得提供意見
  • 當事人對鑑定人聲請調取證據或發問，可向法院表示意見（例如：「鑑定人擬訊問的證人與本案無關」或「該資料涉及營業秘密，應限制使用」）。
例1.
  • 法院選任某會計師為鑑定人，函文載明： 「卷內有被告公司103年至112年之財務報表及國稅局申報資料共八宗，台端可至法院閱卷室閱覽或聲請影印。」
  • → 法院應告知並准許鑑定人利用卷內資料。
例2.
  • 法院選任土木技師鑑定房屋傾斜原因，技師反映需要原始建築設計圖。
  • 該設計圖由原告持有且未附於卷內。 法院依聲請裁定：「原告應於10日內提出系爭房屋之原始設計圖，逾期不提出，本院得依民事訴訟法第345條為不利於原告之認定。」
  • → 法院得命當事人提供鑑定所需資料
例3.
  • 某筆跡鑑定人發現卷內筆跡樣本不足，向法院聲請傳喚被告公司前秘書（證人），詢問被告平日簽名習慣。
  • 法院許可後，證人到庭，鑑定人先由審判長同意，自行問證人： 「請問被告在簽署正式文件時，習慣先簽名再押日期，還是先押日期再簽名？」
  • → 鑑定人聲請訊問證人並自行發問
鑑定人之報酬與費用預付
  • 鑑定人除了車馬費，還可以領一筆專業酬勞（金額由法院核定）。
  • 需要花錢的材料或檢驗，可以先跟法院請款，不用自己墊。
鑑定人於法定之日費、旅費外，得請求相當之報酬
  • 相當之報酬：報酬應與鑑定事項的價值、難度、所需時間、鑑定人專業資歷相當。
鑑定所需費用，得依鑑定人之請求預行酌給之
  • 依鑑定人之請求：須由鑑定人主動提出（書面或言詞），法院不會主動給。
  • 預行酌給：在鑑定「開始前」或「進行中」，法院先預付部分或全部費用，而非等鑑定完成後才給。目的在於避免鑑定人因墊付不起而拒絕鑑定。
例1.
  • 法院選任甲建築師為鑑定人，鑑定房屋漏水原因。
  • 甲花費20小時現場勘查、撰寫報告，事後向法院請求報酬3萬元（依建築師公會收費標準）。
  • 法院審查後認為鑑定事項非極複雜，核定報酬2萬元，連同日費500元及旅費800元，共2萬1300元發給甲。
  • → 鑑定人於法定之日費、旅費外，得請求相當之報酬
例2.
  • 法院選任乙醫師為鑑定人，鑑定某藥物是否導致病患腎衰竭。
  • 乙醫師告知法院：「需委託檢驗所進行質譜分析，費用約5萬元，本人無力墊付。」
  • 法院裁定：「准予預行酌給5萬元，由聲請鑑定之原告先行預繳。」
  • → 鑑定所需費用，得依鑑定人之請求預行酌給之
鑑定證人
  • 如果一個人因為他的專業才能親眼看到某個過去的事實（比如醫師開刀所見）， 法院問他此事時，就把他當成普通證人來對待，讓他到庭、具結、被詰問，只領車馬費。
訊問依「特別知識」得知「已往事實」之人
  • 依特別知識：該人之所以能得知該事實，是因為他擁有超越一般人的專業技能、訓練、職位或經驗。例如：醫生、工程師、鑑識人員。
  • 得知已往事實：該人提供的是「過去曾經發生過的具體事件」，而非對某事項的「判斷意見」。例如：
    • 「我親眼看到病人的肝臟有3公分的腫瘤」（過去事實）。
  • 關鍵區分：如果這個人是「運用專業知識對某事項做判斷」，那就是「鑑定人」（適用第324條以下）；如果是「運用專業知識才得以親眼看到或經歷某事實」，那就是「鑑定證人」（適用本條）。
適用關於人證之規定
  • 具體適用的內容包括：到場義務、得拒絕證言、必須具結，結文內容為「據實陳述」，而非鑑定人的「公正、誠實」。
例1.
  • 醫療過失訴訟中，原告聲請傳喚為其動手術的主治醫師甲。
  • 法官要問甲：「你在手術中，有沒有看到病人體內有不正常的沾黏？」 甲回答：「有，我在切開腹腔後，親眼看到腸道與腹壁之間有大量的纖維化沾黏。」
  • 甲是依其醫師專業知識（特別知識）才得以在手術中親眼看到該事實（已往事實）， 適用證人規定。甲應到庭、具結、接受詰問，不得以書面報告代替，僅得請求日費旅費。
  • → 鑑定證人：主治醫師的手術所見
例2.
  • 車禍訴訟中，到場處理的交通警察丙（具交通事故處理專業）被傳喚。
  • 法官問丙：「你到現場時，看到兩車的相對位置如何？煞車痕多長？」 丙回答：「我拍攝的照片顯示，A車停在路口中央，B車在後方15公尺處，煞車痕為12公尺。」
  • 丙是以其專業身分至現場親眼所見之事實，適用證人規定。 當事人可對其交叉詰問，問他「當時光線是否充足」、「你有沒有漏看其他煞車痕」等。
  • → 鑑定證人：鑑識人員的現場所見
機關（團體）鑑定
  • 法院可以委託公會、醫院、大學等機關團體做鑑定（或審查鑑定報告），由該機關派人說明。
  • 除了「個人具結」和「鑑定證人」外，其他鑑定人規定都準用。
法院認為必要時，得囑託機關、團體或商請外國機關、團體為「鑑定或審查人」鑑定意見
  • 必要時：裁量權。法院判斷選任自然人鑑定人不適當或不可行時，即可啟動。常見必要情形：
    • 鑑定需多領域專業（如醫療+藥理+護理）
    • 鑑定需特殊設備（僅機關或學校擁有）
    • 鑑定需大量人力（如大規模帳目查核）
  • 機關、團體：包括政府機關（如工研院、警政署、衛生福利部）、公立或私立大學、醫院、同業公會（如建築師公會、會計師公會）、私人檢驗機構（如台灣檢驗科技SGS）。
  • 為鑑定：該機關團體就待鑑定事項，提出鑑定意見。
  • 審查鑑定意見：該機關團體不親自做第一線鑑定，而是就「已有的鑑定報告」進行審查、複核，提供批評或補充意見（類似同儕審查）。
其須說明者，由該機關或團體所指定之人為之
  • 須說明者：當鑑定報告有疑問、兩造爭執，或法院認為有必要時，機關團體須派人到庭說明。
  • 所指定之人：由該機關團體自行指派參與鑑定或熟悉鑑定過程的人員（通常為主要執行人）。法院不得強制指定特定人。
    • 此人到庭說明時，其身分為「機關的代理人」，而非「個人鑑定人」。
例1.
  • 在房屋傾斜損害賠償訴訟中，法院認為案情複雜，非單一技師所能勝任。法院乃依職權囑託「社團法人台灣省土木技師公會」為鑑定。
  • 公會指派三位技師組成小組，會勘後出具鑑定報告。
  • 開庭時，法院認有說明必要，公會指派其中一位技師甲到庭說明。
  • → 囑託國內公會鑑定
例2.
  • 在專利侵權訴訟中，涉及極先進半導體製程。我國無此類鑑定機構。原告提出一份美國某大學實驗室的鑑定報告。
  • 法院認為有疑義，乃「商請」德國Fraunhofer研究所審查該報告。
  • 該研究所審查後提出審查意見，指出報告中的若干方法論錯誤。
  • → 商請外國機關審查鑑定意見
