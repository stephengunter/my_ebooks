民事訴訟法 保全程序

假扣押

假扣押之要件
  • 怕對方脫產、將來拿不到錢，你可以先向法院聲請「假扣押」，查封他的財產；
  • 即使你的債權還沒到期或附有條件，也可以提前聲請。
債權人就金錢或「得易為金錢」之請求
  • 金錢請求：請求標的為「一定金額的錢」，例如借款、貨款、損害賠償、票款。
  • 得易為金錢請求之請求：原請求標的不是錢（例如請求交付特定物、返還土地、移轉專利權），但如果不履行時，可以轉換為金錢賠償。
欲保全強制執行者，得聲請假扣押
  • 保全強制執行：確保將來取得勝訴判決（或與確定判決同一效力之文書，如支付命令、調解筆錄）後，能夠實際執行到債務人的財產，不致因債務人脫產而落空。
  • 假扣押：一種「暫時性」的保全措施。
    • 法院裁定准許後，債權人須提供擔保金（通常為請求金額之1/3至1/10不等）
    • 再聲請執行法院（強制執行處）對債務人財產進行「查封」（不動產）或「扣押」（存款、股票、薪水） ，但不會立即變賣（僅暫時凍結）。
「附條件或期限」之請求，「亦得聲請」假扣押
  • 附條件之請求：例如「若乙今年考上律師，甲應給付乙10萬元」（停止條件）。條件尚未成就，請求權尚未發生，但仍可聲請假扣押（因條件可能成就）。
  • 附期限之請求：例如「明年1月1日到期之本票」。期限尚未屆至，仍可聲請假扣押。
  • 立法理由：避免債務人利用「請求權尚未屆至」的時間差脫產。 例如，債務人明知一個月後本票到期，在到期前就把財產全部過戶給他人。本項允許債權人提前聲請假扣押，防止脫產。
  • 實務上，法院會要求債權人釋明「條件或期限即將成就」或「債務人有脫產之虞」，才能准許。
例1.
  • 甲借乙100萬元，約定年底還錢。
  • 甲擔心乙會脫產，在年底前就向法院聲請假扣押乙的銀行存款。
  • → 有金錢請求權，得聲請假扣押。
例2.
  • 乙開立本票100萬元，發票日為113年10月1日，到期日為114年1月1日。
  • 甲於113年11月1日（尚未到期）向法院聲請假扣押乙的財產。
  • → 附期限之請求，亦得為假扣押聲請
假扣押之原因（保全必要性）
  • 怕他脫產還不夠，要拿出證據證明他真的會脫產；
  • 如果將來要跑到外國去執行，法律直接當作很難執行。
假扣押，非有日後「不能強制執行或甚難執行」之虞者，不得為之
  • 法院要核准假扣押，必須先確認：如果現在不扣押，未來很可能「完全拿不到錢」或「非常難拿到錢」。你不能隨便說「我怕他跑掉」就過關，要拿出證據。
應「在外國為強制執行」者，「視為」有日後「甚難執行」之虞
  • 應在外國為強制執行：指債權人將來取得勝訴判決後，必須到外國（中華民國以外國家或地區）去強制執行債務人的財產。例如：債務人是外國公司，在台灣無財產。
  • 視為有日後甚難執行之虞：法律上的「擬制」——只要符合「應在外國執行」之事實，就不需要債權人另外舉證「債務人有脫產行為」。
例1.
  • 甲對乙有100萬元債權。甲發現乙正在將名下房屋賤賣給他的兄弟，且乙的銀行存款近日被大量提領。
  • 甲提出異動謄本、銀行交易明細為證。
  • → 有日後不能強制執行之虞，法院得准許假扣押
例2.
  • 甲（台灣公司）對乙（美國加州公司）有貨款債權100萬美元。
  • 乙在台灣無任何財產，僅在美國有倉庫及存款。 重點：甲主張本案勝訴後須至美國執行。
  • 應在外國為強制執行，視為有日後甚難執行之虞，甲無須另舉證脫產行為，法院得准許假扣押（若乙有在台資產）。
  • → 應在外國執行，視為有虞
假扣押之管轄法院
  • 假扣押可以去「本案法院」（一審或二審）或「財產所在地法院」，看哪個方便。
  • 扣押債權或登記財產，法律有特別規定所在地。
假扣押之聲請，由「本案管轄法院」或假扣押「標的所在地」之地方法院管轄
  • 本案管轄法院：指未來或現在審理「本案實體爭議」的法院。
  • 假扣押標的所在地之地方法院：指「你想要扣押的那個具體財產」所在位置的地方法院。例如：扣押債務人在台北市的不動產 → 臺灣臺北地方法院。
  • 債權人可選擇其中一個法院聲請，不必兩個都去。此為「選擇合併」之管轄。
本案管轄法院，為訴訟已繫屬或應繫屬之第一審法院
  • 例如：債務人住所在台中，債權人還未起訴，將來應向臺中地院起訴。此時債權人可向臺中地院聲請假扣押（即使尚未起訴）。
但訴訟現繫屬於第二審者，得以第二審法院為本案管轄法院
  • 若債權人已經起訴，且第一審判決後，案件上訴到第二審（高等法院），此時債權人可選擇向「第二審法院」聲請假扣押，不必回到第一審法院。
假扣押之標的如係債權或須經登記之財產權，以債務人住所或擔保之標的所在地或登記地，為假扣押標的所在地
  • 如果你想扣押的是「債權」（例如別人欠債務人的錢）或「需要登記的財產」（例如土地、專利），那麼：
    • 債權所在地 = 欠債務人錢的那個人的住址所在地。
    • 登記財產權所在地 = 這筆財產的登記地（例如土地所在地）。
例1.
  • 甲（住台北）要告乙（住台中）借款100萬元，尚未起訴。
  • 甲向「臺灣臺中地方法院」（本案應繫屬之第一審法院，因乙住台中）聲請假扣押。
  • → 向本案管轄法院聲請
例2.
  • 同上例，甲不向台中地院聲請，而是發現乙在台北市有房屋一棟。
  • 甲向「臺灣臺北地方法院」（房屋所在地法院）聲請假扣押該房屋。
  • → 向假扣押標的所在地法院聲請
假扣押之聲請
  • 假扣押聲請狀要寫明：雙方身分、請求內容及原因、脫產原因、管轄法院。
  • 請求不是錢要估價；因財產所在地選法院要寫明哪個財產、在哪裡。
假扣押之聲請，應表明下列事項：
  1. 當事人及法定代理人
  2. 請求及其原因事實
  3. 假扣押之原因
    • 簡述債務人如何浪費財產、逃匿、隱匿財產等情事，例如「債務人已將名下不動產設定高額抵押權予第三人，顯有脫產之虞」。
    • 實務上通常會附上相關證據（如土地謄本、銀行交易明細）作為釋明。
  4. 法院
請求非關於一定金額者，應記載其價額
  • 適用於「得易為金錢請求之請求」，例如請求返還特定物、股票、不動產。
  • 債權人應估算該標的之客觀價額（例如市價、公告現值、鑑價），並記載於聲請狀中，以利法院核定擔保金額（通常為請求價額之一定比例）。
依假扣押之標的所在地定法院管轄者，應記載假扣押之標的及其所在地
  • 若債權人是依第524條第1項後段，選擇向「假扣押標的所在地法院」聲請，則必須在聲請狀中具體指明：
    • 假扣押之標的：例如「債務人所有之臺北市大安區仁愛路三段某地號土地」、「債務人於臺灣銀行台北分行之存款帳戶」。
    • 其所在地：例如「土地坐落臺北市大安區」、「銀行分行地址在台北市中正區」。
  • 若未記載或記載不明，法院無法審查管轄權，將命補正。
假扣押之釋明與擔保
  • 你要提出證據讓法院相信你說的（釋明）
  • 證據不夠但願意提供擔保，還是可能准。
  • 據夠了法院也可以要你擔保。
  • 夫妻討剩餘財產，擔保金最高只要1/10。
請求及假扣押之原因，應釋明之
  • 請求：債權人對債務人的實體請求權（如借款、貨款）及原因事實（第525條第1項第2款）。
  • 釋明：低於「證明」的舉證程度。債權人須提出「能即時調查的證據」，使法院達到「大致相信」、「有點可能」的心證程度（通常認為超過50%）。
  • 若完全未釋明（僅空言主張），法院應駁回聲請。
前項釋明如有不足
  • 債權人有提出證據，但法院認為尚未達到「釋明」的程度（例如只有片面陳述、證據薄弱）。
而債權人「陳明願供擔保」或「法院認為適當」者
  • 債權人陳明願供擔保：最常見。債權人在聲請狀中主動表示「若釋明不足，願供擔保以補足」。
  • 法院認為適當：法院依職權認有必要，即使債權人未主動陳明，亦可命其供擔保（實務較少）。
法院得「定相當之擔保」，「命供擔保」後為假扣押
  • 得：法院裁量權。若釋明不足，法院可駁回，也可命供擔保。
  • 相當之擔保：通常為請求金額的「一定比例」，實務常見為1/3、1/5、1/10，視釋明不足程度及案件類型而定。
  • 擔保金由債權人向法院提存所繳納後，始得聲請執行假扣押。
請求及假扣押之原因「雖經釋明」，法院「亦得命」債權人供「擔保」後為假扣押
  • 即使債權人已「完全釋明」（已達到法院相信的程度），法院仍可「額外」要求提供擔保，作為對債務人權益的雙重保障。
  • 此為法院的裁量權。實務上，多數案件即使釋明充足，法院仍會命供擔保（比例通常較低，如1/10）。
  • 立法理由：假扣押對債務人影響甚大，供擔保可確保債務人將來若勝訴，有財產可供賠償。
夫妻基於剩餘財產差額分配請求權聲請假扣押者，法院命供擔保之金額不得高於請求金額之十分之一
  • 剩餘財產差額分配請求權：民法第1030條之1，夫妻法定財產制關係消滅時（如離婚、死亡、改約），婚後財產較少的一方，得請求財產較多的一方給付「差額的一半」。
  • 此類案件的聲請人通常是經濟弱勢的配偶（如全職家庭主婦/主夫）。
  • 不得高於請求金額之十分之一：例如請求剩餘財產差額1000萬元，法院命供擔保最高不超過100萬元。
例1.
  • 甲聲請對乙假扣押100萬元，主張乙有脫產之虞，僅提出乙「曾向他人提及移民計畫」的Line對話截圖（釋明薄弱）。
  • 法院認釋明不足，但甲陳明願供擔保，法院裁定：「甲供擔保20萬元後，准許假扣押。」
  • → 釋明不足，命供擔保補正
例2.
  • 甲聲請假扣押，聲請狀僅寫「乙欠我100萬元，我怕他跑掉」，未附任何證據。
  • 法院認「未釋明」，且甲未提出願供擔保（或即使提出，因完全未釋明，不得以擔保取代），駁回。
  • → 完全未釋明，駁回
例3.
  • 甲（妻）對乙（夫）請求剩餘財產差額分配1000萬元，聲請假扣押。
  • 法院認甲已釋明請求及假扣押原因，但依第3項命供擔保。法院原擬定擔保金200萬元（1/5），但查甲為家管、無收入，最終裁定擔保金為100萬元（1/10）。
  • → 剩餘財產分配，擔保金上限1/10
假扣押裁定之反面記載（債務人之免為或撤銷假扣押）
  • 假扣押裁定書一定要告訴債務人：你可以用提供擔保金或提存請求金額的方式，免於被假扣押或把已查封的財產解套。
假扣押裁定內，應記載債務人「供所定金額擔保」或「將請求金額提存」，得「免為或撤銷假扣押」
  • 供所定金額之擔保：法院在裁定中會「指定一個金額」，債務人只要將這筆錢提存到法院（通常為假扣押請求金額的全部或一部分），即可免除假扣押。
  • 將請求之金額提存：債務人也可以直接把「債權人請求的那筆錢」全額提存到法院（例如債權人主張100萬元，債務人就提存100萬元）。這是最徹底的擔保方式。
  • 免為假扣押：若假扣押「尚未執行」（債權人還沒去查封債務人的財產），債務人供擔保後，可聲請法院禁止債權人進行假扣押執行。
  • 撤銷假扣押：若假扣押「已經執行」（財產已被查封），債務人供擔保後，可聲請法院撤銷假扣押裁定及執行命令，使查封效力消滅，財產恢復自由。
例1.
  • 法院准許甲對乙假扣押100萬元，裁定中記載「乙供擔保20萬元得免為假扣押」。
  • 乙在甲尚未聲請查封前，將20萬元提存法院。乙持提存證明向法院聲請「免為假扣押」，法院即禁止甲進行執行。
  • → 債務人供擔保，免為假扣押
例2.
  • 甲假扣押乙之房屋獲准，甲已聲請法院查封該屋。
  • 乙將100萬元（即甲請求之金額）全額提存法院。
  • 乙聲請撤銷假扣押裁定及查封。法院裁定准許，並囑託地政機關塗銷查封登記。
  • → 債務人提存請求金額，撤銷已執行之假扣押
假扣押裁定之抗告
  • 准許或駁回假扣押都可以抗告。抗告法院要給雙方講話機會。
  • 債務人抗告期間，已經查封的財產繼續封住，不自動解封。
  • 抗告有理由者，法院自己直接改判。
關於假扣押聲請之裁定，得為抗告
  • 包括「准許假扣押」的裁定（債權人勝）及「駁回假扣押聲請」的裁定（債務人勝）。
  • 得為抗告：當事人（債權人或債務人）不服時，可在裁定送達後10日內，向上級法院提起抗告。
  • 本項不區分准許或駁回，一律賦予抗告權。
抗告法院為裁定前，應使債權人及債務人有陳述意見之機會
  • 陳述意見之機會：可透過「開庭」（行訊問或辯論）或「發函命提出書狀」的方式為之。
  • 立法目的：原審法院核發假扣押裁定時，通常未通知債務人（避免債務人脫產）。抗告程序是債務人第一次有機會完整陳述，必須保障其聽審權。
抗告法院認「抗告有理由」者，「應自為裁定」
  • 應自為裁定：抗告法院不能將案件「發回原法院」要求重新審理，必須自己直接作出終局裁定（例如：廢棄原准許假扣押裁定，改駁回聲請；或廢棄原駁回裁定，改准許假扣押）。
  • 自為裁定的優點：節省時間，避免因發回而延誤保全程序；且抗告法院（通常是高等法院或最高法院）法律見解較為統一。
准許假扣押之裁定，如經抗告者，在駁回假扣押聲請「裁定確定前」，「已實施之假扣押執行程序，不受影響」
  • 准許假扣押之裁定，如經抗告者：債務人對「准許假扣押」的裁定提起抗告。
  • 在駁回假扣押聲請裁定確定前：在抗告法院最終裁定「駁回假扣押聲請」並確定之前。
  • 已實施之假扣押執行程序，不受影響：債權人已經聲請法院查封、扣押的財產，不會因為債務人提起抗告就自動停止或解除。查封繼續有效。
  • 立法理由：避免債務人利用抗告期間（通常數週至數月）迅速脫產。即使債務人抗告，債權人仍可繼續執行，確保保全實效。若最終抗告成功（駁回假扣押），債務人可請求賠償，但不能提前要求撤銷執行。
例1.
  • 法院駁回甲之假扣押聲請。甲抗告。
  • 抗告法院審理後，認為甲已充分釋明請求及假扣押原因，廢棄原裁定，並「自為裁定」准許假扣押。
  • → 假扣押裁定，認抗告有理由者，抗告法院應自為裁定
例2.
  • 法院准許甲假扣押乙之房屋，甲已查封完畢。
  • 乙抗告成功，抗告法院最終裁定「駁回甲假扣押之聲請」確定。
  • 但在該裁定確定前，查封仍然有效，乙不能要求立即解封。乙需待裁定確定後，再聲請撤銷假扣押執行。
  • → 抗告裁定確定前，已執行之查封不受影響
命債權人限期起訴
  • 假扣押後，如果債權人遲遲不提告，債務人可以請求法院限期起訴。
  • 逾期不起訴，假扣押就會被撤銷。
本案尚未繫屬者，命假扣押之法院應「依債務人聲請」，命債權人於「一定期間內起訴」
  • 本案：指假扣押所保全的實體請求權（如借款、貨款）的本案訴訟。
  • 尚未繫屬：債權人還沒有提起本案訴訟（或聲請支付命令、調解、仲裁等替代程序）。
  • 應依債務人聲請：債務人得主動向法院聲請，法院「原則上必須准許」，沒有裁量空間（除非本案已繫屬）。
  • 一定期間：法院通常會定7日至30日不等（常見為2週或20日）。
下列事項與前項起訴有同一效力：
  1. 聲請發支付命令
  2. 聲請調解
  3. 在訴訟中為第395條第2項的聲明
    • 第395條第2項為聲明：即上訴審中，被告請求返還因假執行所為之給付。此項較為特殊，係針對特定訴訟狀態。
  4. 開始仲裁
    • 若雙方有仲裁協議。
  5. 其他起訴前必須走的程序
    • 例如勞資爭議調解、消費爭議申訴等，屬概括條款。
  6. 夫妻剩餘財產分配，已聲請宣告改用分別財產制
    • 基於剩餘財產分配請求權，已請求宣告改用分別財產制。
夫妻改用分別財產制者，債權人應於十日內起訴請求夫妻剩餘財產差額分配
  • 適用對象：夫妻之一方基於民法第1030條之1（剩餘財產差額分配請求權）聲請假扣押。
  • 流程：債權人必須先依民法第1010條，聲請法院宣告夫妻「改用分別財產制」（因法定財產制消滅，始得請求分配）。
  • 十日內起訴：宣告改用分別財產制裁定確定之日起十日內，債權人應提起本案訴訟（請求剩餘財產差額分配）。
債權人「不於第一項期間內起訴」或未遵守前項規定者，債務人得「聲請撤銷假扣押裁定」
  • 若債權人未於法院所定期間內起訴（或未進行第2項之替代程序），或未遵守第3項之10日起訴期限。
  • 債務人可向「命假扣押之法院」聲請「撤銷假扣押裁定」。
  • 法院審查後，應將原假扣押裁定撤銷，已實施之執行程序亦應一併撤銷（查封登記塗銷、存款解凍等）。
例1.
  • 法院准許甲對乙假扣押100萬元，甲尚未起訴本案（未告乙還錢）。
  • 乙向法院聲請命甲限期起訴。法院裁定：「甲應於收受裁定後20日內，就本案提起訴訟。」
  • 甲未起訴，但於20日內向法院聲請對乙核發支付命令（督促程序）。
  • 乙事後再向法院主張「甲未起訴，應撤銷假扣押」。法院審查後認為，聲請支付命令依第2項第1款，與起訴有同一效力，故不撤銷假扣押。
  • → 債權人聲請支付命令，視為已起訴
例2.
  • 甲對乙假扣押獲准，法院命甲於20日內起訴。
  • 甲逾期未起訴，亦未為任何第2項之行為。
  • 乙聲請撤銷假扣押。法院裁定撤銷原假扣押裁定，並通知執行法院塗銷查封。
  • → 逾期未起訴，聲請撤銷假扣押
假扣押裁定之撤銷
  • 假扣押原因消失、債權人敗訴確定、或情況改變，債務人可聲請撤銷。
  • 債權人自己也可以隨時撤銷。
  • 撤銷要向原法院或本案法院聲請。
債務人聲請撤銷事由1.假扣押之原因消滅
  • 假扣押之原因：第523條的「日後不能強制執行或甚難執行之虞」（脫產之虞）。
  • 消滅：例如債務人已提供足額擔保（依第527條）、債務人已清償全部或部分債務、債務人不再有脫產行為（如停止出售財產）、債務人已將財產交付信託或公證。
  • 債務人須舉證原因已消滅。
債務人聲請撤銷事由2.債權人受本案敗訴判決確定
  • 若上訴人提出理由書，且上訴不合法，則不須送達。
  • 若上訴合法，法院應「速」送達被上訴人，使其知悉上訴具體理由。
債務人聲請撤銷事由3.其他「命假扣押之情事變更」者
  • 概括條款，例如：假扣押所保全的請求權已因清償、抵銷、免除而消滅。
假扣押之裁定，「債權人得聲請撤銷」之
  • 債權人可隨時主動聲請撤銷假扣押，無須附理由。
  • 常見情況：雙方已達成和解，債權人同意撤回假扣押；或債權人發現自己確實無理由，主動撤銷以免賠償。
撤銷假扣押，應向命假扣押之法院聲請；如本案已繫屬者，向本案法院聲請
  • 命假扣押之法院：原核發假扣押裁定的法院（可能是地方法院或高等法院）。
  • 本案已繫屬者：若債權人已提起本案訴訟（或聲請支付命令、調解、仲裁等），則撤銷假扣押的聲請應向「本案法院」（即正在審理本案的法院）提出，以便該法院綜合考量本案情況。
例1.
  • 甲假扣押乙之房屋獲准。乙依第527條供擔保20萬元，聲請撤銷假扣押。
  • 法院審查後認假扣押原因已消滅（乙已供擔保，無脫產之虞），裁定撤銷假扣押。
  • → 債務人供擔保，聲請撤銷假扣押（假扣押原因消滅）
例2.
  • 甲假扣押乙之財產，其後甲起訴請求乙給付100萬元，但法院判決甲敗訴確定（甲無請求權）。
  • 乙聲請撤銷假扣押。法院裁定撤銷。
  • → 債權人本案敗訴確定，聲請撤銷假扣押
假扣押之損害賠償責任
  • 假扣押因自始不當、債權人逾期未起訴或主動撤銷而被撤銷，債權人要賠償債務人因查封或提供擔保所受的損失。
  • 本案訴訟中，債務人可直接請求法院在本案判決內一併判賠。
假扣押撤銷有下列賠償事由，債權人應賠償債務人因假扣押或供擔保所受之損害
  • 因假扣押所受之損害：債務人因財產被查封、扣押所生的直接損失。例如：查封期間無法處分財產所生的利息損失或交易損失（如股價下跌、錯失賣房時機）。
  • 因供擔保所受之損害：債務人為免為或撤銷假扣押，依第527條提供擔保金所生的損失。例如：提存擔保金期間，無法運用該筆資金所生的利息損失（通常按法定利率計算）。
賠償事由1.假扣押裁定「自始不當」
  • 自始不當：指從假扣押聲請時起，客觀上就不具備法定要件（欠缺請求權或假扣押原因），法院原本就不應准許。
  • 常見情形：
    • 債權人明知無請求權（如偽造債權）仍聲請假扣押。
    • 債權人完全未釋明假扣押原因（如無脫產之虞），法院誤認而准許。
  • 注意：若假扣押裁定是「因事後原因消滅」而被撤銷（例如債務人清償債務），而非「自始不當」，則不適用本款。
賠償事由2.債權人未於限期內起訴
  • 假扣押裁定准許後，債權人未於法院限期內起訴（或未遵守剩餘財產分配之10日期限），經債務人聲請而撤銷假扣押。
  • 此時債權人雖有請求權，但因消極不行使權利，導致假扣押被撤銷，亦應負賠償責任。
賠償事由3.債權人「主動聲請」撤銷假扣押
  • 債權人主動撤銷，通常代表其已認為無保全必要（例如自知請求無理由、已達成和解）。為保護債務人，亦應負賠償責任。
假扣押所保全之請求已起訴者，法院於「第一審言詞辯論終結前」，應「依債務人之聲明」，於「本案判決內命債權人賠償」
  • 應依債務人之聲明：債務人須向法院「聲明」請求賠償（可以於起訴狀、答辯狀或言詞辯論期日提出）。
  • 於本案判決內命債權人賠償：法院在審理本案請求（例如借款返還）時，若認定假扣押已因上述事由被撤銷，應一併在本案判決的主文中，命債權人賠償債務人所受的損害。
債務人未聲明者，應「告以得為聲明」
  • 法院的「闡明義務」：若債務人未主動請求賠償，法院應主動告知債務人「你可以請求賠償」。
  • 此為保障不懂法律的債務人（尤其是自然人），避免其喪失權利。
  • 若法院未告知，判決可能有瑕疵（但非當然無效）。
例1.
  • 甲明知乙不欠錢，卻捏造債權聲請假扣押乙之房屋獲准。
  • 乙的房屋被查封6個月，無法出售。
  • 其後法院撤銷假扣押（自始不當）。乙向甲請求賠償：查封期間房屋市價下跌100萬元損失、及乙為此事請假出庭的損失。
  • → 自始不當：債權人明知無債權。請求賠償假扣押損失
例2.
  • 甲起訴乙請求給付貨款100萬元（本案），之前甲曾聲請假扣押乙之財產，後因甲逾期未起訴，假扣押被撤銷。
  • 乙在本案第一審言詞辯論終結前，向法院聲明：「請求甲賠償因假扣押所受損害10萬元。」
  • 法院審理後，判決「甲之訴駁回（甲無貨款請求權），甲應賠償乙10萬元」
  • → 本案審理中，債務人聲明請求賠償假扣押損失。法院於本案判決內一併處理

假處分

假處分之要件
  • 金錢以外的請求（如交還名畫、移轉土地、不得使用商標），為防止對方變更現狀導致將來拿不到，可以聲請「假處分」。
適用範圍：債權人就「金錢以外」之請求
  • 金錢請求以外之請求：指請求的標的不是一定金額的金錢，也無法（或不適合）直接轉換為金錢。包括：
    • 請求交付特定物：例如A名畫、B古董、特定型號之汽車、特定不動產。
    • 請求移轉或登記權利：例如移轉土地所有權、設定抵押權、移轉專利權。
    • 請求作為或不作為：例如拆除越界建築、容忍通行、不得使用商標、不得洩漏營業秘密、不得召開股東會。
  • 若請求同時包含金錢與非金錢，可分別適用假扣押及假處分（或選擇其一）。
欲保全強制執行者，得聲請假處分
  • 保全強制執行：假處分的目的，是為了確保將來取得勝訴判決（或其他執行名義）後，能夠實際執行到該請求標的，不致因債務人任意變更現狀而落空。
  • 假處分：法院以裁定命債務人維持現狀、禁止變更、或命其為一定行為或不行為的保全處分。
聲請要件：因「請求標的之現狀變更」，有日後不能強制執行，或「甚難執行之虞」
  • 請求標的之現狀變更：指債務人對該標的物（例如土地、股票、商標權）可能為處分（出售、贈與、設定抵押）、移轉、隱匿、毀損、變更性質等行為。
  • 有日後不能強制執行或甚難執行之虞：類似假扣押的「脫產之虞」，但此處強調的是「標的物本身的狀態變化」而非債務人整體財產狀況。例如：
    • 債務人已與第三人簽訂買賣契約，準備將系爭土地過戶。
    • 系爭古董即將被運往國外拍賣。
    • 債務人公司即將召開股東會改選董監事，可能影響股權結構。
  • 若無現狀變更之虞，法院應駁回假處分聲請（例如標的物已由法院查封中，或債務人已書面承諾不處分）。
例1.
  • 甲向乙購買一幅特定名畫，乙收款後拒不交畫，且乙已與丙談好要將該畫高價轉售。
  • 甲向法院聲請假處分，請求禁止乙將該畫移轉或交付給第三人。
  • → 請求標的現狀將變更（出售），有甚難執行之虞，得聲請假處分
例2.
  • 甲對乙有袋地通行權，乙卻準備在該通路上設置圍籬。
  • 甲聲請假處分，命乙不得設置圍籬（或應維持道路暢通）。
  • → 請求標的（通行狀態）現狀將變更，得准許假處分
假處分準用假扣押之規定
  • 假處分的大部分程序（聲請、擔保、管轄、抗告、撤銷、賠償）都比照假扣押。
    • 但執行方法和債務人用擔保金撤銷這兩件事，要依假處分自己的特別規定。
關於假扣押之規定，於假處分準用之
  • 關於假扣押之規定：指第522條至第531條（假扣押聲請要件、管轄、釋明、擔保、抗告、撤銷、賠償等），以及第524條（管轄）、第525條（聲請程式）、第526條（釋明與擔保）、第527條（債務人供擔保免為或撤銷） 、第528條（抗告）、第529條（限期起訴）、第530條（撤銷）、第531條（損害賠償）。
  • 準用之：假處分的聲請、審理、裁定、執行、救濟、撤銷、賠償等程序，原則上比照假扣押程序辦理。
規定而不同者，不在此限
  • 第535條（假處分之執行方法）：規定假處分的具體執行方式（如禁止債務人處分、交付保管、選任管理人），與假扣押的「查封、扣押」不同。 因此，假處分的執行不準用假扣押執行方法，應依第535條。
  • 第536條（債務人供擔保撤銷假處分之限制）：規定債務人欲提供擔保撤銷假處分， 必須符合「無因假處分而受不可回復之損害」等要件，較假扣押嚴格（假扣押債務人原則上可任意供擔保撤銷）。 因此，此部分不準用第527條（假扣押之債務人撤銷）。
例1.
  • 甲聲請假處分，請求禁止乙移轉某土地所有權。
  • 法院依第533條準用第526條，要求甲釋明「請求標的現狀將變更之虞」，並命甲提供擔保金20萬元後始准許假處分。
  • → 準用假扣押之釋明及擔保規定
例2.
  • 法院准許假處分後，依第535條規定，發函地政機關禁止乙移轉該土地（此為「禁止處分」命令）。
  • 此種執行方法與假扣押的「查封」不同，故不準用假扣押執行規定。
  • → 執行方法不同，不準用假扣押之執行方法
假處分之必要方法
  • 法院可以針對不同案件，靈活裁定假處分的方法，例如禁止債務人賣土地、命令他讓我通行、或派一個管理人來管爭議財產。
假處分「所必要之方法」，由「法院以裁定酌定之」
  • 假處分所必要之方法：指為了達到保全目的（避免請求標的現狀變更，確保將來能執行）所採取的手段。
    • 必要：強調必須符合「比例原則」——法院應選擇對債務人侵害最小、又能有效達成保全目的的方法。不得濫用或過度。
  • 以裁定：必須以書面裁定形式為之，具體載明假處分的方法（如「禁止債務人將如附表所示之不動產為移轉、設定抵押或其他處分行為」）。
  • 酌定：法院有裁量權，可自由選擇最適當的方法，不受當事人聲請方法之拘束（但通常會參考債權人之建議）。
列舉方法1.選任管理人
  • 由法院選任的第三人（可以是自然人、法人、甚至政府機關），負責管理假處分標的物，以維持其價值或避免爭議惡化。
  • 常見情形：
    • 爭議中的公司或工廠：選任臨時管理人維持營運，避免停業損失。
    • 爭議中的共有物（如土地、建物）：選任管理人負責收益、保管、修繕。
列舉方法2.命令或禁止債務人為一定行為
  • 命令債務人為一定行為：要求債務人「積極去做」某事。例如：
    • 命令債務人容忍債權人進入其土地進行測量或修繕管線。
    • 命令債務人將特定物品交由法院或管理人保管。
    • 命令債務人不得阻撓債權人通行。
  • 禁止債務人為一定行為：要求債務人「不得去做」某事。例如：
    • 禁止債務人將特定不動產出售、贈與、設定抵押。
    • 禁止債務人將特定動產搬離某處或銷毀。
    • 禁止債務人召開股東會或為特定決議。
    • 禁止債務人使用特定商標、專利或營業秘密。
例1.
  • 甲聲請假處分，禁止乙將A土地過戶給第三人。
  • 法院裁定：「債務人乙就附表所示之A土地，不得為移轉、設定抵押權、信託或其他任何處分行為。」
  • → 禁止債務人為一定行為
例2.
  • 甲乙共有某工廠，但雙方經營理念不合，無法共同管理。
  • 甲聲請假處分，保全其股權及經營權。
  • 法院裁定：「選任丙會計師為該工廠之臨時管理人，於本案判決確定前，由丙代行工廠之經營管理權，原股東不得干擾。」
  • → 選任管理人
債務人供擔保撤銷假處分之限制
  • 假處分不是有錢就能解決；債務人想用擔保金撤銷假處分，必須證明債權人的請求可以用錢打發、或不撤銷自己會受無法彌補的重大損害。
以下情形，得供擔保撤銷假處分
  1. 所保全之請求，「得以金錢給付」達其目的
    • 債權人的請求，其實「用錢就可以搞定」，不一定要維持特定物的現狀或禁止特定行為。例如：
      • 請求交付「台積電1000股股票」：股票為代替物，可以市價賠償。
      • 請求「不得使用商標」：若債權人主要目的是索賠過去侵權的損害，而非禁止未來使用，則可能被認定可金錢賠償。
  2. 債務人將因假處分而受「難以補償之重大損害」
    • 指損害極大，且事後即使債權人賠錢也無法回復原狀或填補。
      • 例如：假處分禁止工廠運作，導致工廠倒閉、員工解僱、商譽全毀（即使事後賠錢，也無法讓工廠復活）。
  3. 其他特別情事
    • 概括條款，例如：
      • 假處分的原因已消滅（如債務人已提供其他足額擔保）。
      • 假處分所保全的債權明顯不存在或數額過高。
有以上情形，法院始得於假處分裁定內，記載債務人供所定金額之擔保後免為或撤銷假處分
  • 始得：只有在上述三種例外之一成立時，法院「可以」（裁量）在裁定中記載，但「並非必須」記載。
  • 此記載通常稱為「反擔保條款」。
假處分裁定未依前項規定為記載者，債務人「亦得聲請」法院許其供擔保後撤銷假處分
  • 若假處分裁定中，法院未依第一項記載「供擔保得撤銷」的條款，債務人仍可事後向法院「聲請」許其供擔保後撤銷。
  • 法院審查時，仍須符合第一項的三種例外之一，且須裁定准許。
法院為撤銷假處分裁定前，應使債權人有陳述意見之機會
  • 應：強制規定。法院在決定是否允許債務人供擔保撤銷假處分前，必須讓債權人表示意見（例如發函命於5日內提出書狀，或開庭訊問）。
  • 立法理由：保障債權人的程序權，避免法院單方面採信債務人主張而犧牲債權人權益。
例1.
  • 甲聲請假處分，禁止乙將1000包水泥運走（水泥為代替物）
  • 乙主張「水泥可以用市價賠償」，聲請提供擔保撤銷假處分。
  • 法院審查後認為，水泥為市售常見物，甲可用賠償金另行購買，裁定准許乙供擔保後撤銷假處分。
  • → 所保全之請求，「得以金錢給付」達其目的，聲請撤銷假處分
例2.
  • 甲聲請假處分，禁止乙經營之唯一工廠運作（因專利侵權爭議）
  • 乙主張，若停工半年將導致倒閉、上千員工失業，且甲之損害可用金錢賠償。
  • 法院審查後，裁定准許乙供擔保後撤銷假處分。
  • → 債務人將因假處分而受「難以補償之重大損害」，聲請撤銷假處分
自助行為後之即時聲請假扣押或假處分
  • 自己動手扣債務人財產或攔人後，必須馬上向「動手地點」的法院聲請假扣押或假處分，讓法院接手。
    • 否則自助行為失效，還可能賠錢。
債權人依民法第151條規定押收債務人之財產或拘束其自由者
  • 民法第151條（自助行為）：「為保護自己權利，對於他人之自由或財產施以拘束、押收或毀損者，不負損害賠償之責。 但以不及受法院或其他有關機關援助，且非於其時為之，則請求權不得實行或其實行顯有困難者為限。」
  • 押收債務人之財產：例如拿走債務人手上的現金、皮包、手機，或扣押其車輛鑰匙。
  • 拘束其自由：例如拉住債務人不讓他離開、暫時關在房間內等候警察。
  • 自助行為的要件：
    1. 為保護自己的權利。
    2. 不及時請求法院援助。
    3. 非及時為之，請求權將無法實現或顯有困難。
應「即時聲請」法院為「假扣押或假處分」之裁定
  • 應即時聲請：須在自助行為完成後「毫無遲延」地（通常數小時內，最晚翌日）向法院聲請，不得拖延。
  • 聲請法院為假扣押或假處分之裁定：債權人應依自助行為的性質聲請：
    • 若為金錢請求 → 聲請假扣押。
    • 若為金錢以外請求（如押收特定物）→ 聲請假處分。
  • 若未即時聲請或聲請被駁回，自助行為視為自始不當，債權人應負損害賠償責任（民法第151條第2項）。
前項聲請，「專屬」押收債務人財產或拘束其自由之「行為地地方法院管轄」
  • 專屬：強制性管轄，當事人不能合意變更，法院亦不得移送。
  • 行為地地方法院：以債權人實際執行自助行為的地點為準。例如：
    • 在台北市信義區攔下債務人 → 臺灣臺北地方法院。
    • 在高雄市前鎮區扣押債務人貨物 → 臺灣高雄地方法院。
  • 立法理由：行為地法院距離事發現場最近，便於法院即時審查、迅速保全證據，符合「即時聲請」的要求。
例1.
  • 甲在夜市巧遇欠債不還的乙，乙看到甲轉身就跑。甲追上前攔住乙（拘束自由），並拿走乙的錢包（內有現金2萬元）
  • 甲隨即打電話報警，並在1小時內向該夜市所在地的臺北地方法院聲請假扣押（針對乙之存款）
  • 法院審查後，認甲符合自助行為要件，准許假扣押。
  • → 合法自助 + 即時聲請，「專屬」行為地法院管轄
例2.
  • 甲在超商遇到乙，乙並無逃跑跡象，甲卻逕行扣押乙的手機（乙只是正常購物）。
  • 甲隨即向行為地法院聲請假處分。
  • 法院審查後認為，甲當時並無「不及受法院援助」或「請求權將無法實現」之急迫情形，自助行為不合法，駁回假處分聲請。
  • → 自助行為不合法，法院駁回
自助行為後聲請之調查程序與言詞陳述要求
  • 法院對自助行為後的聲請要馬上審、馬上判；不合法的立刻駁回。
  • 如果涉及限制人身自由，法院一定要開庭讓雙方當面講清楚，才能核准。
「自助行為」後之聲請，法院「應即調查裁定」之
  • 「自助行為」後之聲請：債權人於自助行為後，向法院聲請假扣押或假處分。
  • 將請求之金額提存：債務人也可以直接把「債權人請求的那筆錢」全額提存到法院（例如債權人主張100萬元，債務人就提存100萬元）。這是最徹底的擔保方式。
  • 應即調查：法院必須「毫無遲延」地（通常在收件後數小時內，最遲當日或翌日）開始審查，不得排入一般案件之順序拖延。
  • 裁定之：應以「裁定」形式（而非判決）決定准駁。
不合於民法第151條之規定，或有其他「不應准許之情形」者，法院「應即以裁定駁回」之
  • 不合於民法第151條：例如：
    • 當時其實有時間報警或聲請法院，卻未為之（不符「不及受法院援助」）。
    • 即使不及時為自助行為，請求權仍可實現（例如債務人只是單純遲延，無逃跑跡象）。
    • 自助行為逾越必要程度（如債務人只欠1萬元，卻扣留他價值100萬元的汽車）。
  • 或有其他不應准許之情形：例如：
    • 債權人根本無請求權（債權不存在）。
    • 自助行為已結束過久，債權人未即時聲請。
  • 應即以裁定駁回之：強制規定，只要不符要件，法院「必須」駁回，無裁量空間。
自助行為「拘束債務人自由」者，「非經言詞陳述，不得為准許之裁定」
  • 拘束債務人自由：如攔下、拉住關住、限制行動，而非僅「押收財產」。
  • 非經言詞陳述：法院必須讓雙方言詞陳述意見。比如立即開庭（或臨時庭訊），由法官訊問債權人及債務人。
  • 不得為准許之裁定：如未經言詞陳述，准許假扣押/假處分裁定違法。
例1.
  • 甲在機場攔阻即將搭機離境的乙（乙欠甲100萬，且乙已辦妥移民），並立即向機場所在地法院聲請假扣押。
  • 法院收到聲請後，於4小時內開庭，審查甲提出之借據、乙之機票、移民文件，認定符合民法第151條（不及受法院援助），裁定准許假扣押。
  • → 合法自助，准許假扣押
例2.
  • 甲攔住乙後聲請假扣押。法院未開庭、未通知雙方到場，僅書面審查甲提出之借據及陳述，即裁定准許假扣押。
  • 乙抗告，抗告法院以「未命言詞陳述」為由，廢棄原裁定。
  • → 因拘束自由之聲請，非經言詞陳述不得准許
自助行為後財產與債務人之送交法院及處置
  • 自助扣押的財產或逮住的人，要馬上送法院。
  • 法院24小時內要決定准駁；駁回的話，債權人要還財產、放人。
債權人「自助行為」後聲請假扣押/假處分時，應將所押收之財產或被拘束自由之債務人「送交法院處理」。但有正當理由不能送交者，不在此限。
  • 債權人「自助行為」後向法院聲請假扣押或假處分時，必須「同時」將押收的財產（如扣留的現金、包包、手機）或被拘束自由的債務人（如攔下的人）帶到法院，交由法院處理。
  • 除非有正當理由（例如東西太大搬不動、人受傷不能移動）。
法院為裁定及開始執行前，就前項財產或債務人「應為適當處置」
  • 適當處置：例如：
    • 對財產：指定保管人、封存、移置保管場所。
    • 對債務人：安置於法院等候室、請法警看管。
但拘束債務人之自由，自送交法院時起，不得逾24小時
  • 從「送交法院」那一刻起算，24小時內法院必須做出裁定（准許或駁回），並釋放債務人或將其轉為合法的假處分執行（如限制住居、責付）。
  • 此為憲法第8條第2項之具體化（因犯罪嫌疑被逮捕拘禁者，24小時內應移送法院）。若超過24小時，債務人可聲請提審（提審法）或直接請求釋放。
裁定「駁回」者，應「將該財產發還債務人」或回復其自由
  • 若法院最終裁定「駁回」假扣押或假處分之聲請（不論因自助行為不合法、或請求不存在等理由），債權人必須：
    • 返還押收的財產給債務人。
    • 立即釋放被拘束自由的債務人。
例1.
  • 甲在機場攔下乙，扣押乙的行李箱（內有現金）。
  • 甲立即向機場所在地法院聲請假扣押，並同時將行李箱帶到法院。
  • 法院收下行李箱，暫時保管於贓物庫。
  • → 押收財產，送交法院，法院適當處置押收之財產
例2.
  • 同上例，法院審查後認自助行為不合法，於乙送交後第6小時裁定駁回假扣押聲請。
  • 法院立即釋放乙，並返還乙遭扣押之財物。
  • → 駁回聲請，立即釋放
拘束自由之假扣押/假處分後之特別起訴期限
  • 法院若准許限制債務人的人身自由（例如禁止出境），債權人必須在收到裁定後5天內提起本案訴訟。
  • 超過5天沒告，法院可以直接或依聲請把裁定撤銷、把人放掉。
因拘束債務人自由而為假扣押或假處分裁定
  • 法院裁定准許債權人聲請假扣押或假處分，其內容涉及「限制債務人的人身自由」者。 例如：
    • 法院裁定「限制債務人出境」（實務上屬假處分之一種，亦拘束自由）。
    • 法院裁定「責付」債權人看管債務人。
其本案「尚未繫屬」者
  • 債權人還沒有提起本案訴訟（或聲請支付命令、調解、仲裁等替代程序）。
「債權人應」於裁定送達後「五日內起訴」
  • 應：強制規定。
  • 五日內起訴：包括提起本案訴訟、聲請支付命令、聲請調解、開始仲裁等（依第529條第2項）。5日為法定不變期間，不能延長。
「逾期未起訴」時，命假扣押或假處分之法院得「依聲請或依職權」，「撤銷」假扣押或假處分裁定
  • 逾期未起訴：債權人未於5日內為任何起訴或與起訴同一效力之行為。
  • 依聲請：債務人可主動向法院聲請撤銷假扣押或假處分。
  • 依職權：法院可不待債務人聲請，主動撤銷。
  • 撤銷假扣押或假處分裁定：撤銷後，已實施的執行程序（如限制出境、拘束自由）應一併解除。
例1.
  • 法院裁定准許甲假處分，禁止乙出境（拘束自由）
  • 裁定於5月1日送達甲。甲於5月5日向法院提起本案訴訟（請求乙返還借款）
  • → 合法，5日內起訴
例2.
  • 同上例，甲逾期未起訴。法院於5月10日主動發函撤銷原假處分裁定，並通知入出境管理機關解除乙之出境限制。
  • → 逾期未起訴，法院得依職權撤銷

定暫時狀態

定暫時狀態之處分
  • 如果爭執的法律關係不趕快處理會發生重大損害或急迫危險，法院可以先裁定一個暫時狀態，甚至命令一方先付錢或先做事，不必等官司打完。
於爭執之法律關係
  • 雙方當事人間，有一個「正在爭執」的法律關係（實體法上的權利義務）。 例如：僱傭關係是否存在、專利權是否被侵害、公司董事資格是否有效、袋地通行權是否存在。
為防止發生重大之損害
  • 重大之損害：損害程度顯著，例如：公司將倒閉、工廠將停工、唯一收入來源被切斷。
或避免急迫之危險
  • 急迫之危險：危險即將發生，例如：債務人即將搭機出境，從此失聯；病患若不立即手術將死亡。
或有其他相類之情形
  • 概括條款，例如：避免訴訟程序嚴重延宕、避免判決無法執行。
而有必要時
  • 有必要：必須符合比例原則，且無其他更溫和的手段可達成相同目的。
得聲請為定暫時狀態之處分
  • 當事人（通常是債權人）可向法院聲請。
  • 定暫時狀態之處分：法院以裁定，暫時創設或維持一個法律狀態，直到本案判決確定為止。
請求之關聯性：定暫時狀態之裁定，以其本案訴訟「能確定該爭執之法律關係」者為限
  • 法院必須確認：當事人將來提起的「本案訴訟」，能夠「最終確定」這個爭執的法律關係。
    • 換句話說，不能是虛假爭議、或依法不得訴訟的事項（如政治問題）。
  • 例如：專利侵權爭議，可以透過本案訴訟確認專利權是否受侵害；但若爭執的是「颱風是否會來」，則無法訴訟確定，不能聲請。
定暫時狀態之處分，得命「先為一定之給付」
  • 突破傳統假處分僅能「禁止」的框架，授權法院「命令」債務人「積極給付」。例如：
    • 命令僱主先給付工資（即使本案訴訟尚未確定）。
    • 命令醫院先給付必要醫療費用。
    • 命令公司先交付產品或提供服務。
定暫時狀態之處分「裁定前」，「應使兩造」當事人「有陳述之機會」。但法院認為不適當者，不在此限
  • 這是正當法律程序的要求，尤其是此種處分對債務人影響重大。
  • 應：強制規定。法院必須通知雙方（例如開庭、發函命提出書狀），讓雙方有機會表達意見。
  • 不適當：例如：若事先通知債務人，債務人會立即脫產、銷毀證據、或造成急迫危險（如即將搭機出境）。此時法院可不經陳述意見，先為裁定（即「緊急處分」）。但事後應補正程序（如讓債務人抗告或聲請撤銷）。
例1.
  • 甲遭乙公司違法解僱，甲提起確認僱傭關係存在之訴。
  • 甲同時聲請定暫時狀態處分，請求法院命乙公司「暫時恢復僱傭關係並繼續給付薪資」，以免甲在訴訟期間失去生計、家庭陷入困境。
  • 法院審查後認有重大損害，裁定准許。
  • → 勞工遭解僱，定暫時狀態命復職(防止發生重大之損害)
例2.
  • 某公司董事會鬧雙胞，公司業務停擺，瀕臨破產。股東甲聲請定暫時狀態處分，請求法院選任臨時管理人代行董事會職權。
  • 法院審查後認有重大損害，裁定選任第三方會計師為臨時管理人。
  • → 公司經營權爭議，選任臨時管理人
定暫時狀態處分之緊急處置
  • 情況緊急到連等幾天的定暫時狀態處分都來不及時，法院可以先給一個最長10天的「緊急處置」（如禁止出境），而且這個緊急處置不能抗告。
發動條件：依聲請
  • 須由債權人聲請（不能依職權）。
法院審查：認有必要時
  • 情況極度急迫，若等到正式裁定核發，損害將已發生或無法挽回。例如：
    • 債務人已買好2小時後飛往國外的機票。
    • 病患幾小時內可能死亡或產生永久性傷害。
效果：以裁定先為一定之緊急處置
  • 法院以裁定命為緊急措施，例如：
    • 禁止債務人出境（立即通知入出境管理機關）。
    • 命醫院先提供緊急藥物或手術。
時效限制：緊急處置有效期間不得逾七日。期滿前得聲請延長之，但延長期間不得逾三日
  • 立法理由：這是「急救」措施，不能長期取代正式處分。債權人應在此期間內說服法院核發正式定暫時狀態處分。
前項「期間屆滿前」，法院以「裁定駁回」定暫時狀態處分之聲請者，其先為之處置「當然失其效力」
  • 若法院在緊急處置有效期間內，正式裁定「駁回」定暫時狀態處分的聲請（即不淮許）， 則緊急處置「自動失效」，無須另為裁定撤銷。
  • 法院應通知相關機關（如入出境管理機關、地政機關）解除處置。
其經裁定許為定暫時狀態，而其內容與先為之處置相異時，其相異之處置失其效力
  • 若法院最終「准許」定暫時狀態處分（第538條），但處分內容與先前的緊急處置不完全相同。 則「相異的部分」失效，改適用正式處分的內容。
  • 例如：緊急處置禁止債務人出境；正式處分則僅禁止債務人處分不動產（未禁止出境）。則禁止出境的部分失效。
「定暫時狀態」處分之裁定，「不得聲明不服」
  • 對於法院「准許緊急處置」或「駁回緊急處置聲請」的裁定，雙方當事人「均不得抗告」。
  • 立法理由：緊急處置極具時效性，若允許抗告，將失去實益。且此為暫時之暫時，期間極短，若對債務人造成損害，可於後續程序求償。
例1.
  • 甲對乙有債權，乙已買好3小時後飛往美國的單程機票。
  • 甲緊急向法院聲請定暫時狀態處分（禁止乙出境），並同時聲請緊急處置。
  • 法院審查後，立即核發緊急處置裁定：「禁止乙出境，有效期間7天。」並即刻通知移民署執行。
  • 7天期滿前，甲向法院聲請延長（因甲已提起本案訴訟，但正式定暫時狀態處分尚未裁定）。
  • 法院認仍有必要，裁定延長3天（總第10天）
  • → 禁止出境之緊急處置，7天期滿前聲請延長3天
例2.
  • 法院於緊急處置第5天，正式裁定駁回甲之定暫時狀態處分聲請（認甲本案無理由）。
  • 該緊急處置於駁回裁定生效時「當然失效」，移民署自動解除乙之出境管制（或由法院通知解除）
  • → 正式裁定駁回，緊急處置失效
定暫時狀態處分廢棄或變更後之給付返還
  • 上級法院把「先為給付」的假處分裁定廢掉時，必須在廢掉的同時，命令拿到錢或東西的人，連本帶利還回來。
  • 對這個命返還的裁定不能單獨抗告。
抗告法院「廢棄或變更」定暫時狀態處分之裁定時
  • 廢棄或變更：上級法院認定原審法院的定暫時狀態處分裁定（尤其是其中「命先為一定給付」的部分）不當，而予以撤銷或修改。
應依抗告人之聲請，在廢棄或變更範圍內，同時「命聲請人返還」其所受領之給付
  • 依抗告人之聲請：債務人必須「主動請求」返還。若未聲請，法院不會主動命返還（但法院應闡明）。
  • 在廢棄或變更範圍內：僅限於被上級法院推翻的那部分給付。例如原裁定命給付100萬元，抗告法院認為僅其中60萬元不當，則僅就60萬元部分命返還。
  • 聲請人：指原審的「聲請人」（即債權人，受領給付的一方）。
  • 返還其所受領之給付：債務人已經給付出去的東西（金錢、貨物、服務），要還回來。
其給付為金錢者，並應依聲請附加自受領時起之利息
  • 例如：債權人於1月1日收到100萬元，抗告法院於6月1日裁定返還，則利息自1月1日計算至返還日。
前項命返還給付之裁定，非對於抗告法院廢棄或變更定暫時狀態之裁定再為抗告時，不得聲明不服；抗告中應停止執行
  • 債務人不能「單獨」對「命返還給付」的部分提抗告。必須是對「廢棄或變更定暫時狀態處分」 的主裁定提起「再抗告」（到上級法院）時，才可一併爭執返還部分。
  • 若抗告人（通常是原審債權人）對「廢棄或變更定暫時狀態處分」的主裁定提起再抗告，則在再抗告程序進行中， 「命返還給付」的執行應暫停，以免債權人先還了錢，結果再抗告成功（原裁定復活），又要再給付一次。
例1.
  • 地方法院依第538條第3項裁定，命雇主甲「先給付勞工乙薪資30萬元」。
  • 甲已支付。甲抗告，並聲請命乙返還30萬元及利息。
  • 高等法院認定原裁定不當（乙無權請求），廢棄原裁定。
  • 高等法院在廢棄原裁定的同時，裁定：「乙應返還甲30萬元，及自受領之日（例如1月1日）起至清償日止，按年息5%計算之利息。」
  • → 雇傭案件，命雇主先付薪資棄。抗告廢棄原裁定時命返還
例2.
  • 法院核發緊急處置，命債務人甲先給付乙10萬元。
  • 後因法院駁回定暫時狀態處分，緊急處置失效。
  • 甲聲請法院命乙返還10萬元及利息。
  • → 緊急處置失效，準用返還
定暫時狀態處分撤銷後之損害賠償責任減免
  • 定暫時狀態處分被撤銷後，若債權人能證明自己沒有過失，法院可以視情況少賠或不賠，不必負全額無過失責任。
定暫時狀態之裁定，因第531條之事由被撤銷，而應負損害賠償責任者
  • 第531條之事由：自始不當、逾期未起訴、債權人主動聲請撤銷。
  • 只要因這三種事由之一被撤銷，原本第531條就會課予債權人損害賠償責任。
如聲請人「證明其無過失」時，法院得視情形「減輕或免除其賠償責任」
  • 聲請人：原聲請定暫時狀態處分的債權人。
  • 證明其無過失：債權人必須自行舉證，證明自己對「裁定被撤銷」這件事「沒有過失」。
    • 例如：聲請時已提出所有可得之證據、已充分釋明請求及假處分原因、已遵守所有程序要求（如即時起訴）、無法預見法院會作出不同判斷。
  • 減輕或免除其賠償責任：可全免，也可部分減輕（如賠償50%）。
例1.
  • 甲因公司即將倒閉，緊急聲請定暫時狀態處分，禁止乙（大股東）移轉公司資產。
  • 甲提出財務報表、證人證詞，盡力釋明。法院審查後准許。
  • 事後本案判決認定乙之行為合法，原定暫時狀態處分「自始不當」被撤銷。乙向甲求償100萬元。
  • 甲主張「我已盡全力調查，無過失」，法院審酌甲已善盡義務，且當時確有急迫性，裁定減輕賠償至20萬元。
  • → 證明無過失，法院減輕賠償
定暫時狀態處分準用假處分之規定
  • 定暫時狀態處分，除了自己那套特別規則外，其他程序（管轄、擔保、抗告、執行、撤銷限制等）都比照一般假處分辦理。
例1.
  • 甲聲請定暫時狀態處分，法院審查後認釋明不足，依第538條之4準用第526條第2項，命甲供擔保後准許。
  • → 準用一般假處分之擔保
