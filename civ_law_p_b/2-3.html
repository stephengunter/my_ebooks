民事訴訟法 簡易訴訟程序

簡易訴訟程序

簡易訴訟程序之適用範圍
  • 50萬元以下、或12種特定類型（租賃、票據、車禍等）的案件，用簡易程序；雙方也可合意轉為簡易程序。
關於財產權之訴訟，其標的金額「50萬元以下」者，適用簡易程序
  • 現行標準：標的金額在50萬元以下的財產權訴訟。
  • 非財產權訴訟（如名譽、身分）不適用。
下列各款訴訟，不問標的金額「一律適用」簡易程序
  1. 建築物/工作物，「定期租賃/定期借貸」關係
    • 建築物或工作物（如廠房、機械）的「定期」租賃或借貸（不定期租賃不屬之）。
  2. 「僱傭契約」涉訟，其僱傭期間在「一年以下」者
    • 僱傭期間在一年以下者（勞動事件法優先適用，但本條仍屬基礎）。
  3. 「旅館/餐廳/運送人」，因食宿、運送費或因寄存行李、財物涉訟者
    • 旅客與旅館、餐廳、運送人間的食宿費、運費、寄存爭議。
  4. 因請求保護占有涉訟者
    • 「保護占有」訴訟（占有物返還、除去妨害等，時效短）。
  5. 「不動產界線/界標」涉訟
    • 不動產界線或界標爭議（通常與相鄰關係有關）。
  6. 「票據請求」涉訟
    • 票據請求（本票、支票、匯票），不論金額。
  7. 本於「合會」有所請求而涉訟
    • 合會（民間互助會）請求。
  8. 請求「利息/紅利/租金/退職金」或其他「定期給付」
    • 定期給付（利息、紅利、租金、退職金等），不論金額。
  9. 「動產租賃或使用」借貸關係所生之爭執涉訟
    • 動產租賃或使用借貸（如汽車出租、借用）。
  10. 因票據/僱傭租賃之「保證關係」涉訟
    • 第1-3、6-9款之保證關係。
  11. 本於道路「交通事故」有所請求而涉訟
    • 道路交通事故（車禍）請求。
  12. 「刑事簡易訴訟」程序案件之附帶民事訴訟
    • 刑事簡易判決之附帶民事訴訟移送民事庭。
當事人得「合意」適用簡易程序，其合意「應以文書證之」
  • 當事人可將通常程序事件合意改為簡易程序。
  • 必須以「文書」（書面）證明合意。
法院「誤行」簡易程序，「當事人不抗辯」而為本案之言詞辯論者，「視為」已有行簡易程序之「合意」
  • 擬制合意。法院誤行簡易程序，當事人未異議而進行本案辯論，即視為同意。
應行簡易程序事件，其案情繁雜或訴訟標的金額逾第一項所定金額「十倍以上」者，法院得「依當事人聲請」，以「裁定」改用通常訴訟程序，並由原法官繼續審理
  • 若案情太複雜或金額超過50萬元的十倍（即500萬元），得依聲請轉為通常程序。
前項裁定，不得聲明不服
  • 轉換程序裁定不得抗告。
應行簡易程序金額，司法院得因情勢需要，以命令「減至25萬元，或增至75萬元」
  • 授權司法院調整金額門檻，可調低至25萬或調高至75萬。
例1.
  • 甲起訴乙請求返還借款30萬元。
  • → 50萬元以下，適用簡易程序
例2.
  • 甲因車禍向乙求償100萬元。
  • → 車禍事件，適用簡易程序
例3.
  • 甲持有乙簽發之面額200萬元本票，起訴請求乙給付。
  • → 票據事件，不問金額，適用簡易程序
例4.
  • 甲起訴乙返還借款100萬元（非前兩項事件），雙方簽署書面同意改用簡易程序。
  • → 合意適用簡易程序
例5.
  • 甲起訴乙返還借款100萬元，法院誤行簡易程序，甲、乙未抗辯而為本案辯論。
  • → 院誤行簡易程序，未抗辯而為本案，辯論擬制合意
例6.
  • 甲起訴乙請求票款500萬元（第2項第6款），案情繁雜，甲聲請改用通常程序。
  • → 案情繁雜，當事人得聲請轉換通常程序
簡易程序起訴之便利性
  • 在簡易程序，原告只需口頭或書面講清事實經過，不用寫出法律依據；開庭以外的聲明陳述，全部可以口頭進行。
簡易程序，原告於起訴時得僅表明請求之原因事實
  • 第244條第1項第2款規定：起訴狀應記載「訴訟標的及其原因事實」。
  • 本條放寬為：在簡易程序，原告可以省略「訴訟標的」的記載，只寫「原因事實」。
  • 法院會根據原告描述的事實，依職權判斷可能的訴訟標的（如借貸、不當得利）。
  • 例如：原告寫「被告跟我借了3萬元沒還」，法院即知原告是依消費借貸關係請求。
起訴及其他期日外之聲明或陳述，概得以言詞為之
  • 「起訴」：原告可以口頭向法院起訴，由書記官記明筆錄（第244條第2項）。
  • 「其他期日外之聲明或陳述」：指在法庭開庭以外的時間（例如非開庭日、或開庭前後、或到法院服務中心）。
  • 當事人的各種聲明（如聲請調查證據、聲請停止訴訟、撤回起訴）或陳述（如補充事實），都可以用「口頭」方式為之。
例1.
  • 甲向法院起訴，起訴狀寫：「乙於113年1月10日向我借款10萬元，說好3個月還，但到現在都沒還，請判乙還我10萬元。」
  • 甲未寫依「消費借貸」法律關係。法院依其記述，認屬消費借貸請求。
  • → 簡易程序，起訴時得僅表明請求之原因事實
例2.
  • 甲到法院訴訟輔導科，向書記官口頭說明乙欠款10萬元之事實，書記官依其陳述製作筆錄，作為起訴狀。
  • → 簡易程序，起訴及其他期日外之聲明或陳述，概得以言詞為之
言詞起訴之送達與就審期間
  • 口頭起訴，法院要把筆錄連同開庭通知寄給被告，並給至少5天準備。
以言詞起訴者，應將筆錄與言詞辯論期日之通知書，「一併送達於被告」
  • 合併送達義務：筆錄（記載原告口頭陳述之事實及請求）與開庭通知書須同時送達被告，不可分開。
就審期間，至少應有五日。但有急迫情形者，不在此限
  • 就審期間為5日（自送達翌日起算至開庭前一日，至少5日）。
例1.
  • 甲到法院口頭起訴，書記官製作筆錄。
  • 法院將該筆錄影本及開庭通知一併送達乙。
  • → 以言詞起訴者，應將筆錄與言詞辯論期日之通知書，「一併送達於被告」
例2.
  • 乙於6月1日收到通知，開庭日最早可訂6月7日（6月1日送達，6月2日起算，6月6日為第5日，故7日開庭）
  • → 就審期間，至少應有五日
簡易程序言詞辯論期日通知書之應記載事項
  • 簡易程序開庭通知要寫明「這是簡易案件」，並提醒當事人開庭時要自帶證據、自帶證人。
言詞辯論期日之通知書，應表明適用簡易訴訟程序
  • 強制記載事項。使當事人知悉本案適用簡易程序（而非通常程序），進而理解程序較為緊湊、證據應及早提出。
並記載當事人務於期日「攜帶證物」及「偕同證人」到場
  • 通知書上必須明確要求當事人：
    1. 將所有「物證」（書證、照片、錄音檔等實體證據）隨身帶到法庭。
    2. 將「人證」（證人）一併帶到法庭，法院可當庭直接訊問，無須另行寄發證人傳票。
例1.
  • 法院寄給甲的通知書記載：「本案適用簡易訴訟程序。請務必於期日攜帶所引用之借據原本、匯款單等證物，並偕同你所舉之證人丙到場。」
  • → 言詞辯論通知書，應表明適用簡易訴訟程序。並記載務於期日「攜帶證物」及「偕同證人」到場
簡易程序之書狀交換與言詞陳述筆錄送達
  • 在簡易程序中，若你的主張太複雜，對方需要時間準備，你就得提前交書狀並寄給對方。
  • 口頭講的，法院會記筆錄寄給對方。
當事人於其聲明或主張之事實或證據，以認為他造非有準備不能陳述者為限
  • 適用標準：他造是否需要準備才能回應。
  • 若該主張或證據較為複雜、涉及專業、或需要查閱文件，他造若當庭聽聞將無法立即回答，則應事前提出書狀。
  • 若極簡單（如「有無收到10萬元」），他造可當庭陳述，則不強制。
應於期日前提出準備書狀或答辯狀，並以繕本或影本直接通知他造
  • 應在言詞辯論期日前，向法院提出書狀，並自行將副本寄給他造。
  • 違反者，他造得聲請變更期日或請求法院命補正。
其以言詞為陳述者，由法院書記官作成筆錄，送達於他造
  • 言詞陳述之處理：若當事人未提書狀，而是以口頭向法院陳述（例如在開庭前到法院訴訟輔導科陳述），書記官應將其陳述記明筆錄，並將筆錄送達他造。
例1.
  • 甲主張乙借款10萬元，但甲提出之證據為本票、匯款單及證人丙、丁，事實較複雜，乙顯然無法當庭立即回應。
  • 甲應於開庭前提出準備書狀，載明事實及證據，並將繕本寄乙。
  • → 他造非有準備不能陳述者，應於期日前提出準備書狀或答辯狀，並以繕本或影本直接通知他造
例2.
  • 甲主張乙借款3萬元，僅有一張借據，事實單純。
  • 乙可當庭答辯。甲無須事前提出書狀。
簡易程序之任意到場與擬合意
  • 雙方可以不經通知，自行到法院開庭辯論，法院記明筆錄當作起訴，並視為雙方同意用簡易程序。
例1.
  • 甲、乙因借款糾紛，知道每週三下午法院有簡易庭開庭。
  • 兩人約定某週三下午一起到法院，向法官表示要進行辯論。
  • 法官當場開庭，書記官將甲請求乙返還10萬元記載於筆錄，進行辯論。
  • → 雙方自行到場辯論，法院記明筆錄當作起訴，並視為雙方同意用簡易程序
簡易程序通知證人或鑑定人之便宜方法
  • 簡易程序中，法院可用電話等便宜方式通知證人；但證人若未到，想處罰仍須先寄正式通知書。
例1.
  • 法院書記官打電話通知證人丙於5月10日到庭，丙於該日到場作證。
  • → 便宜方法通知，證人到場
例2.
  • 法院以電話通知丁於5月10日到庭，丁未到。
  • 法院改對丁寄送正式通知書，命於6月1日到庭。
  • → 便宜方法通知，證人未到，補送通知書
例3.
  • 法院僅以電話通知證人戊，戊未到庭，法院逕依第303條第1項裁處罰鍰。
  • → 便宜通知後，直接罰鍰，不合法
簡易程序以一次期日辯論終結為原則
  • 簡易程序原則上只開一次庭就結案，不能拖拖拉拉。
簡易訴訟程序事件，法院應以一次期日辯論終結為原則
  • 「應」表示原則上強制，法院應盡力達成一次辯論終結。
  • 「一次期日」指第一次言詞辯論期日。
  • 「辯論終結」指法官宣布言詞辯論終結，準備定期宣判。
  • 例外情形得再開辯論或另定期日，但須正當理由。
例1.
  • 甲起訴乙返還借款10萬元，雙方到庭，各自提出借據、匯款單，法官整理爭點（借款是否已清償）， 當庭訊問證人丙，行言詞辯論後，法官諭知「辯論終結，定5月30日宣判」。
  • → 一次辯論終結
例2.
  • 第一次期日，乙聲請傳喚重要證人丁，但丁未到庭（有正當理由住院）。
  • 法官另定第二次期日訊問丁。
  • → 例外再開辯論
簡易程序言詞辯論筆錄之省略
  • 簡易程序筆錄經法院許可且當事人無異議，可省略部分記載；但捨棄、認諾、和解、自認等不得省略。
簡易程序言詞辯論筆錄，經法院之許可，得省略應記載之事項
  • 例如：省略當事人詳細陳述、省略證人訊問之逐字記載（改摘要）。
但當事人有異議者，不在此限
  • 若任一方當事人不同意省略（例如擔心上級審無法審查），法院不得許可省略。保障當事人程序權。
言詞辯論程式之遵守、捨棄、認諾、撤回、和解、自認及裁判之宣示，筆錄不得省略
  • 「言詞辯論程式之遵守」：當事人是否到場、是否一造辯論、是否變更期日等。
  • 「捨棄、認諾、撤回、和解、自認」：涉及當事人對訴訟標的之處分，須明確記載。
  • 「裁判之宣示」：宣示判決主文應記明筆錄。
例1.
  • 法官許可書記官省略筆錄中當事人陳述的逐字紀錄，改為「原告陳述如起訴狀所載；被告陳述如答辯狀所載」。
  • 當事人均無異議。
  • → 許可省略
例2.
  • 被告乙擔心上訴審無法審查，表示「不同意省略筆錄」。
  • 法院應命書記官詳實記載。
  • → 當事人異議
例3.
  • 兩造當庭和解，書記官不得省略和解內容，應明確記載和解條款。
  • → 不得省略和解
簡易程序依職權一造辯論判決
  • 簡易程序一方不到場，法院可主動直接判決，不用等對方請求。
簡易程序言詞辯論期日，當事人之「一造不到場」者
  • 事實要件：原告或被告其中一人未到場（含未委任代理人到場）。
  • 不到場之理由是否正當，不影響法院發動職權（但法院裁量時會考量）。
法院得「依職權」由「一造辯論」而為判決
  • 「依職權」：法院不待到場當事人聲請，自行決定。
  • 「得」：法院有裁量權，若認應另定期日（如不到場者有正當理由），可不行之。
  • 「由一造辯論」：僅聽取到場一造之辯論，未到場一造視為放棄防禦。
  • 「而為判決」：基於辯論及卷證資料作出判決。
例1.
  • 簡易程序開庭，被告乙無正當理由未到場。
  • 法官未待原告甲聲請，即主動諭知「被告未到場，本院依職權由原告一造辯論判決」。
  • → 法院依職權一造辯論
例2.
  • 通常程序開庭，被告乙未到，原告甲未聲請一造辯論。
  • 法院不能主動一造辯論，應另定期日。
  • → 通常程序須聲請
簡易程序判決書之簡化
  • 簡易程序判決書可寫重點或引用書狀，甚至可不另作判決書，直接把主文及要領記在開庭筆錄裡當作判決書。
簡易程序判決書內之事實及理由，得合併記載其要領
  • 「合併記載其要領」：事實與理由不分段，綜合敘述重點。
  • 「必要」指若不處置，調解可能無法進行或結果將落空。
或引用當事人書狀、筆錄或其他文書，必要時得以之作為附件
  • 「引用」：例如「事實及理由如原告起訴狀所載」。
  • 「作為附件」：將起訴狀、答辯狀等附在判決書後，視為判決書之一部。
法院亦得於宣示判決時，命將判決主文及其事實、理由之要領，記載於言詞辯論筆錄，「不另作判決書」
  • 要件：法院於「宣示判決」時（即宣布判決結果時），命書記官將主文及要領記入「言詞辯論筆錄」（而非另外打字）。
  • 當事人拿到的是筆錄正本或節本。
其「筆錄正本或節本」之送達，「與判決正本」之送達，「有同一之效力」
  • 把記載判決主文及要領的筆錄正本或節本送達給當事人，效力等同於送達判決正本。
例1.
  • 法官在判決書中寫：「事實及理由要領：被告乙於113年1月10日向原告甲借款10萬元，約定3個月還款， 屆期未還，原告請求返還為有理由，被告抗辯已清償不足採。」
  • → 判決書合併記載要領
例2.
  • 判決書寫：「事實及理由如原告起訴狀及被告答辯狀所載。」
  • → 引用書狀
例3.
  • 法官當庭宣判：「主文：被告應給付原告10萬元。理由要領：依借據及匯款單，借貸關係存在，被告未能證明清償。」
  • 書記官將此內容記入言詞辯論筆錄。法院將筆錄節本寄送兩造。
  • → 不另作判決書，記明筆錄
簡易程序判決書之簡化記載（僅記載主文）
  • 簡易程序中，當事人捨棄、認諾、宣判時放棄上訴或當場履行，判決書可只寫主文。
有下列各款情形之一者，判決書得僅記載主文︰
  1. 本於當事人對於訴訟標的之「捨棄或認諾」者
    • 「捨棄」：指原告放棄自己對被告的請求
    • 「認諾」：指被告承認原告的請求
    • 這兩種情況下，法院必須「本於其捨棄或認諾」為該當事人敗訴之判決，無須調查事實。因為結果已無爭議，判決書只要讓大家知道「誰輸誰贏」就好。
  2. 受不利判決之當事人於宣示判決時，「捨棄上訴權」者
    • 獲得勝訴判決的當事人，其權利狀態尚待判決確定才能穩固。
    • 反之，敗訴方若當場放棄上訴權，則判決立即確定。
    • 此時，勝訴方即獲得一確定的執行名義，判決理由已非重點。
  3. 受不利判決之當事人於宣示判決時，「履行判決所命之給付」者
    • 敗訴方在宣判時立即付錢或還地，原告的實體權利已立即獲得滿足。這是最徹底的根本解決。
    • 此時判決確定與否對勝訴方已無意義，判決書僅是記錄此一程序結果。
例1.
  • 甲告乙請求給付10萬元貨款。在法院開庭時，乙向法官說：「我承認這筆債務，願意全數給付。」
  • 法官當場判決乙必須給付。此時，判決書可以只寫「乙應給付甲新臺幣10萬元。訴訟費用由乙負擔。」
  • → 認諾判決，判決書得僅記載主文
例2.
  • 法官宣判甲敗訴後，詢問當事人意見。
  • 甲當場表示：「我對這個判決結果沒意見，放棄上訴。」法官告知書記官後，判決書便可只記載主文。
  • → 宣示判決時捨棄上訴，判決書得僅記載主文
例3.
  • 法官宣判乙應賠償甲5萬元。閉庭後，乙立即當庭交付5萬元現金給甲，由書記官記明筆錄。
  • 法官此時可諭知判決書依本條僅記載主文。
  • → 宣示判決時履行給付，判決書得僅記載主文
簡易程序因訴之變更、追加或反訴而改用通常程序
  • 簡易程序中因變更追加或反訴而超出範圍，原則改用通常程序。
  • 雙方合意或被告不抗辯而辯論者，可續用簡易程序。
因訴之變更、追加或提起反訴，致其訴之全部或一部，不屬簡易程序範圍者
  • 適用前提：
    • 原本案件屬於簡易程序（例如標的金額40萬元）。
    • 但因為原告變更或追加（如追加至150萬元），或被告提起反訴（如反訴請求200萬元）
    • 導致「全部」訴訟（本訴+反訴）或「一部」（如追加之部分）已超出簡易程序的範圍（超過50萬元且非屬第427條第2項之事件）。
原則：法院應「以裁定改用通常訴訟程序」，並由「原法官」繼續審理
  • 原則：改用通常程序。法院須以「裁定」為程序轉換。
例外1.當事人合意繼續用簡易程序
  • 雙方合意繼續用簡易程序（應記明筆錄）。
例外2.被告「不抗辯而為本案之言詞辯論」者，視為已有適用簡易程序之合意
  • 擬制合意：繼續用簡易程序。
  • 若原告變更追加或被告提起反訴後，被告沒有抗辯「不應再用簡易程序」
  • 反而針對本案實體內容進行辯論（如陳述事實、提出證據）
  • 則法律上視為被告已「默示同意」繼續用簡易程序，法院毋庸轉換。
例1.
  • 甲對乙提起簡易程序請求返還40萬元。訴訟中，甲追加請求150萬元（合計190萬元），超出簡易程序範圍。
  • 乙不同意續用簡易程序。法院裁定改用通常程序，由原法官續審。
  • → 追加而超出簡易程序適用範圍，法院裁定改用通常程序
例2.
  • 同上例，甲追加至190萬元，但兩造均同意繼續用簡易程序，記明筆錄。
  • 法院毋庸轉換。
  • → 雙方合意續用簡易程序
例3.
  • 甲提起反訴請求200萬元（超出簡易程序範圍）。
  • 乙未抗辯程序問題，直接針對反訴內容答辯「該筆款項已清償」。
  • 法院認乙已為本案言詞辯論，視為同意續用簡易程序。
  • → 「不抗辯而為本案之言詞辯論」者，視為已有適用簡易程序之合意
簡易程序之組織與普通規定之適用
  • 簡易程序由獨任法官審理。本章未規定的，仍適用通常程序的規定。
簡易訴訟程序在「獨任法官」前行之
  • 由「一位法官」獨任審理，不組成合議庭。
  • 此與通常程序（原則上合議，但小額亦獨任）不同，旨在追求程序簡速。
簡易訴訟程序，除本章別有規定外，仍適用第一章通常訴訟程序之規定
  • 簡易程序專章（第427條至第436條之34）有特別規定者，優先適用該特別規定。 例如第433條之1：得命行書狀先行程序；第434條：判決書得僅記載要領..等。
  • 若簡易程序專章「未規定」之事項，則仍適用第一章之通常訴訟程序規定。 如當事人能力、訴訟能力、共同訴訟、訴訟參加、訴訟費用、送達、期日期間、訴訟停止、證據通則、判決確定等。
例1.
  • 甲向法院起訴請求乙返還30萬元（簡易程序）。
  • 分案後，由一位法官獨任審理，不組成三人合議庭。
  • → 獨任審理
例2.
  • 簡易程序中，甲聲請傳喚證人。
  • 簡易程序章未規定證據調查程序，法院即適用第一章第277條以下 （舉證責任、人證、鑑定等）之規定。
簡易程序第一審裁判之上訴抗告程序
  • 簡易程序第一審判決，上訴到地方法院合議庭。
  • 上訴審中不得變更追加導致轉通常程序。
  • 若已改用通常程序者，則上訴高等法院。
簡易程序之第一審裁判，得上訴或抗告於管轄之地方法院，其審判以合議行之
  • 上訴/抗告之管轄法院：地方法院（不是高等法院）。
  • 上訴/審判組織：該地方法院的「合議庭」（三名法官）。
  • 適用對象：簡易程序第一審的「判決」（上訴）或「裁定」（抗告）。
簡易程序第一審裁判之上訴，為訴之變更、追加或提起反訴，致應適用通常訴訟程序者，不得為之
  • 上訴審中限制變更追加反訴：若變更、追加或反訴，會導致案件不再屬於簡易程序範圍（如追加後金額逾50萬元），則「不得為之」。
  • 此規定是為了避免簡易程序上訴審反而變成通常程序，違背簡速本旨。
依法院裁定改用通常訴訟程序所為之裁判，得上訴或抗告於管轄之高等法院
  • 第427條第5項：簡易程序事件，因案情繁雜或訴訟標的價額逾50萬元而當事人合意，法院改用通常程序。
  • 此類案件已非純粹簡易程序，其上訴/抗告應向「高等法院」為之，回歸通常程序之審級。
例1.
  • 甲依簡易程序起訴乙返還30萬元，第一審判決甲敗訴。
  • 甲向原法院（地方法院）提起上訴，由該院民事合議庭（三位法官）審理。
  • → 上訴至地院合議庭
例2.
  • 甲上訴後，欲追加請求另外20萬元（合計50萬元，仍屬簡易範圍邊界）。
  • 如追加至60萬元，已逾簡易程序範圍，法院不准追加。
  • → 上訴審禁止變更追加逾簡易程序範圍
簡易程序第二審裁判之第三審上訴或抗告
  • 簡易程序第二審裁判，上訴利益逾150萬元且適用法規顯有錯誤，可飛躍上訴最高法院。
簡易訴訟程序之第二審裁判，其上訴利益逾第三審所定之利益數額者
  • 上訴或抗告之對象：地方法院合議庭所為之第二審「判決」或「裁定」。
  • 金額門檻：第466條第1項、第3項授權司法院以命令調整上訴第三審之利益數額。 目前為新臺幣150萬元。
  • 若上訴利益未逾150萬元，不得上訴第三審（但得依第436條之3許可上訴）。
當事人「僅得」以其「適用法規顯有錯誤」為理由，逕向最高法院提起上訴或抗告
  • 上訴理由限制。僅限於「適用法規顯有錯誤」。其他理由一律不行。
  • 「適用法規顯有錯誤」：指判決所適用之法規顯然不合於法律規定，或與司法院解釋、大法庭裁定、最高法院判例（變更後之實務見解）顯然違反。
例1.
  • 甲起訴乙返還200萬元，依第427條第2項行簡易程序。
  • 第二審判決甲敗訴，上訴利益200萬元>150萬元。甲以第二審「適用法規顯有錯誤」為由，向最高法院提起上訴。
  • → 上訴利益200萬元>150萬元。得以「適用法規顯有錯誤」為由，上訴第三審
例2.
  • 簡易程序第二審判決，上訴利益為120萬元（未逾150萬元）。
  • 當事人不得上訴第三審，判決即告確定。
  • → 金額未達門檻
例3.
  • 上訴利益逾150萬元，但甲僅主張「第二審認定事實錯誤」（例如證人證詞取捨不當），未主張適用法規錯誤。
  • 最高法院裁定駁回上訴。
  • → 僅得以適用法規顯有錯誤為由，上訴第三審
簡易程序第二審裁判之許可上訴
  • 簡易程序第二審裁判，上訴利益未達150萬元但法律見解具原則上重要性，須經原法院許可始得上訴最高法院。
簡易訴訟程序之第二審裁判，其上訴利益「低於」第三審所定之利益數額者
  • 簡易程序第二審裁判，且上訴利益「未逾」第466條所定金額門檻（否則應依第436-2條逕行上訴）。
提起第三審上訴或抗告，須經「原裁判法院之許可」
  • 許可機關：「原裁判法院」（即作成第二審裁判之地方法院合議庭），而非最高法院。
前項許可，以訴訟事件所涉及之「法律見解」具有「原則上之重要性者」為限
  • 許可要件：法律見解具有「原則上之重要性」，指對於法律適用具有普遍性、根本性影響。
原裁判法院認為應行許可者，應「添具意見書」，敘明合於前項規定之理由，逕將卷宗送最高法院
  • 原法院若認應許可，須製作「意見書」，詳細說明為什麼該事件的法律見解具有原則上重要性。
認為不應許可者，應以裁定駁回其上訴或抗告
  • 不許可程序：原法院若認不應許可，以「裁定」駁回上訴或抗告。
前項裁定，得逕向最高法院抗告
  • 對駁回上訴或抗告的裁定，當事人得「逕向最高法院」提起抗告（不經高等法院）。
  • 最高法院若認抗告有理由，可撤銷原裁定，命原法院許可並送卷，或由最高法院自為許可。
例1.
  • 甲、乙間簡易程序租賃糾紛，第二審判決甲敗訴，上訴利益為80萬元（未達150萬元）。
  • 但本案涉及「住宅租賃押金返還請求權時效」之法律問題，最高法院未曾表示見解，且影響全國租屋市場。
  • 原法院認具有原則上重要性，裁定許可上訴，附意見書送最高法院。
  • → 許可上訴，附意見書送最高法院
例2.
  • 同上例，但本案僅為一般事實認定爭議（如證人證詞取捨），不涉及新穎法律問題。
  • 原法院認不具原則上重要性，裁定駁回上訴許可。
  • → 不許可上訴，裁定駁回
例3.
  • 甲對原法院駁回許可之裁定不服，向最高法院提起抗告。
  • 最高法院審查後認原法院判斷有誤，廢棄原裁定，命原法院許可並送卷。
  • → 對駁回裁定抗告
簡易程序第三審上訴或抗告理由之表明與補正
  • 簡易程序上訴第三審，須同時附上理由；未附者直接駁回，不給補正機會（除宣示後送達前上訴者，可於送達後10日內補正）。
簡易程序上訴第三審，應同時表明上訴或抗告理由
  • 不得先提上訴、事後再補理由（但宣示後送達前提起者除外）。
其於裁判宣示後送達前提起上訴或抗告者，應於裁判送達後十日內補具之
  • 例外：當事人在判決宣示後、收到判決書前就提起上訴（此時上訴人尚未收到判決書，無法具體表明理由）。
  • 允許其在「判決送達後10日內」補提理由書。此10日為不變期間。
未依前項規定表明上訴或抗告理由者，毋庸命其補正，由原法院裁定駁回之
  • 若當事人未同時表明理由，或未在送達後10日內補正：原法院「不必」先命補正，直接以裁定駁回上訴或抗告。
例1.
  • 甲收到簡易程序第二審判決（敗訴），上訴利益200萬元。
  • 甲向原法院提出上訴狀，同時在狀內敘明「原判決適用民法第125條關於時效之規定顯有錯誤， 該請求權應適用第126條之5年時效」。
  • 丙將方案記明筆錄並簽名，送法官核定。法官核定後，調解成立。
  • → 簡易程序上訴第三審同時表明理由，合法
例2.
  • 法院宣示判決時，甲當庭表示上訴（未附理由）。
  • 判決書於6月1日送達甲，甲於6月10日補提上訴理由書（10日內）
  • → 宣示後送達前上訴，後補理由
例3.
  • 甲提起上訴，但上訴狀完全未記載任何理由，亦未於10日內補正。
  • 原法院不命補正，直接裁定駁回上訴。
  • → 簡易程序上訴第三審未附理由，逕行駁回
最高法院對簡易程序許可上訴之駁回裁定與再審禁止
  • 最高法院認簡易程序上訴不符法定許可要件，應裁定駁回，且不得對該裁定聲請再審。
最高法院認上訴或抗告，不合要件規定而不應許可者，應以裁定駁回之
  • 第436-2條第1項：上訴利益逾150萬元，且上訴理由為「適用法規顯有錯誤」。
  • 第436-3條第2項：上訴利益未逾150萬元，但「法律見解具有原則上之重要性」（且經原法院許可或最高法院自為許可）。
  • 若不符合以上要件規定，最高法院應以「裁定」駁回，而非判決。
前項裁定，不得聲請再審
  • 對於最高法院駁回上訴或抗告的裁定，當事人不得依民事訴訟法第496條至第502條（再審程序）聲請再審。
例1.
  • 甲依第436-2條提起上訴，主張簡易程序第二審判決適用法規顯有錯誤。
  • 最高法院審查後認為，甲所主張之錯誤實際上是事實認定問題，不構成「適用法規顯有錯誤」。
  • 最高法院裁定駁回上訴。甲不得對該裁定聲請再審。
簡易程序第三審駁回後不得以同一理由聲請再審
  • 簡易程序上訴第三審經最高法院實體駁回後，不得以同一理由聲請再審。
對於簡易訴訟程序之裁判，逕向最高法院提起上訴或抗告
  • 適用前提：指依第436-2條（金額上訴）或第436-3條（許可上訴）之程序，跳過高等法院，直接上訴或抗告至最高法院。
經以上訴或抗告無理由為駁回之裁判者
  • 最高法院的實體審查結果。
  • 最高法院已審查上訴理由（通常是「適用法規顯有錯誤」），認定該理由不成立， 因此判決或裁定「駁回上訴」（或抗告）。
  • 此為「實體駁回」，而非「程序駁回（不合許可要件）」。
不得更以同一理由提起再審之訴或聲請再審
  • 禁止再審。當事人不得再以「同一理由」向法院提起再審之訴（對判決）或聲請再審（對裁定）。
  • 「同一理由」指與上訴時相同之「適用法規顯有錯誤」之具體指摘。
例1.
  • 甲依第436-2條向最高法院提起上訴，主張「原判決適用民法第125條（15年時效）顯有錯誤，應適用第126條（5年時效）」。
  • 最高法院審理後認原判決適用第125條並無錯誤，判決駁回上訴。
  • 甲不得再以「原判決應適用第126條而非第125條」為同一理由，提起再審之訴。
  • → 最高法院駁回上訴，不得以同一理由再審
簡易程序第二審確定裁判之漏未斟酌證物再審
  • 簡易程序第二審確定裁判，如漏未斟酌足以影響判決之重要證物，得提起再審。
對於簡易訴訟程序之第二審確定終局裁判
  • 適用對象：限於簡易程序「第二審」（地方法院合議庭）已「確定」（不得再以通常上訴程序救濟）之裁判。
如就足影響於裁判之重要證物，「漏未斟酌」者
  • 「重要證物」：指足以影響判決結果之證據（如書證、人證、鑑定報告、勘驗筆錄等）。
  • 「漏未斟酌」：法院在判決理由中完全未提及該證物，或雖提及但未實質審酌其證明力。
  • 「足影響於裁判」：若法院曾斟酌該證物，可能導致不同的裁判結果（有因果關係）。
亦得提起再審之訴或聲請再審
  • 對「判決」提起再審之訴（第496條以下）。
  • 對「裁定」聲請再審（第507條）。
例1.
  • 甲、乙因車禍損害賠償簡易程序訴訟，第二審判決甲敗訴確定。
  • 判決理由中完全未提及甲所提出之「行車紀錄器畫面」（該畫面可證明乙闖紅燈）。
  • 甲以「漏未斟酌重要證物」為由提起再審之訴。法院審認該證物如經斟酌， 可能影響判決結果，裁定開始再審。
  • → 漏未斟酌重要證物，再審成立
