民事訴訟法 調解程序

調解程序

強制調解事件之範圍
  • 鄰居、親屬、車禍、醫療、僱傭、合夥、不動產及50萬元以下財產爭議，起訴前要先強制調解。
下列事件，於起訴前，應經法院調解
  1. 相鄰關係
  2. 土地界線
  3. 共有物處分/分割
  4. 公寓大廈管理
  5. 不動產租賃
  6. 地上權
  7. 交通事故（車禍）
  8. 醫療糾紛
  9. 僱傭契約
  10. 合夥糾紛
  11. 親屬財產
  12. 50萬元以下財產權事件
任意調解與合意調解
  • 非強制調解事件也可聲請調解。
  • 雙方合意先調解後訴訟者，若一方直接起訴，他方可抗辯轉為調解，但已實質辯論者不得抗辯。
當事人得於起訴前，聲請調解
  • 當事人主動聲請，法院應受理（依第405條）。
「有合意」起訴前應先經法院調解，而當事人逕行起訴者
  • 當事人間訂有契約或協議，約定「於起訴前應先聲請法院調解」。
  • 當事人逕行起訴：一方未經調解即直接起訴。
經他造抗辯後，視其起訴為調解之聲請
  • 他方得於訴訟中提出「抗辯」，法院審認合意存在後，應將該起訴視為調解之聲請，並移送調解程序。
但已為本案之言詞辯論者，不得再為抗辯
  • 若已進入實質審理階段，他方不得再主張「應先調解」之抗辯，以避免程序反覆及拖延。
例1.
  • 甲對乙有新臺幣100萬元的貨款爭議（非屬第403條強制調解事件）。
  • 甲認為調解可能快速解決，於起訴前向法院聲請調解。法院應受理。
  • → 當事人得於起訴前，聲請調解
例2.
  • 甲乙於契約中約定「如有爭議，應先向法院聲請調解，調解不成立始得起訴」。
  • 甲違約直接起訴。乙於第一次言詞辯論期日前提出抗辯。
  • 法院審查後，將甲的起訴視為調解之聲請，移送調解。
  • → 有合意起訴前應先經法院調解，經他造抗辯後，視其起訴為調解之聲請
例3.
  • 同上例，甲直接起訴後，法院已進行兩次言詞辯論，且已調查證人。
  • 乙此時始提出「應先調解」之抗辯。法院認已為本案言詞辯論，駁回乙之抗辯。
  • → 已為本案言詞辯論，不得抗辯
調解之聲請、程式與管轄
  • 調解要由當事人寫狀紙向法院聲請，載明爭議標的及事實，附上證據。
  • 調解管轄法院比照一般訴訟。
調解，依當事人之聲請行之
  • 調解之啟動方式。須由當事人（一方或雙方共同）向法院提出聲請。
  • 法院不得依職權主動開啟調解程序（除非法律另有規定，如家事事件法）。
聲請調解，應表明為調解標的之法律關係及爭議之情形
  • 「調解標的之法律關係」：如買賣、借貸、侵權行為、僱傭、合夥、相鄰關係等。
  • 「爭議之情形」：具體事實（如乙於某日向甲借款50萬元未還；某車禍發生經過及損害）。
有文書為證據者，並應提出其原本或影本
  • 證據之提出。當事人得附上相關文書（如借據、契約書、車禍現場圖、估價單）之原本或影本，以協助調解委員及法院了解案情。
  • 未提出者不影響聲請之合法性。
聲請調解之管轄法院，準用訴訟管轄法院之規定
  • 例如：動產界線爭執：專屬不動產所在地法院管轄。
例1.
  • 甲向法院提出調解聲請狀，狀內記載： 「聲請人甲與相對人乙間因買賣契約紛爭，相對人乙於113年1月10日向甲購買貨物一批， 價金新臺幣30萬元，乙僅支付10萬元，尚欠20萬元未付。 聲請調解標的：買賣價金請求權。」
  • 並附上買賣契約影本。
  • → 聲請調解，應表明為調解標的之法律關係及爭議之情形
例2.
  • 甲、乙均住台北，因車禍（發生於台中）糾紛，甲向台中地院聲請調解。
  • 依第15條（侵權行為地）及第405條第3項，台中地院有管轄權。
  • → 聲請調解之管轄法院，準用訴訟管轄法院之規定
法院駁回調解聲請之事由
  • 調解聲請有六種情況（不可能成立、已調過、票據、反訴、送達不到、銀行催債），法院可直接裁定駁回，且不得抗告。
法院認調解之聲請有下列情形之一者，得「逕以裁定駁回」之
  1. 無成立之望
    • 不能調解、沒必要調解、或調解顯然不可能成功（如兩造已水火不容）。
  2. 已在他機關調解不成立
    • 如鄉鎮市調解委員會調解不成立，無需再重複。
  3. 票據請求
    • 票據（支票、本票、匯票）法律關係明確，票據法賦予執票人迅速追索之權利，調解不易成立且可能拖延。
  4. 提起反訴
    • 反訴係在本訴訴訟程序中提出，不宜單獨移付調解。
  5. 公示送達
    • 被告所在不明或域外送達（被告住外國），耗時且他造參與意願低。
  6. 金融機構消費借貸契約或信用卡契約請求
    • 金融機構通常無調解意願，且事件單純。
前項駁回調解裁定，不得聲明不服
  • 為避免當事人就「是否應調解」反覆爭執，延宕程序，本條明定此裁定一出即告確定。
例1.
  • 甲對乙聲請調解，但雙方於另案訴訟中已激烈對峙，乙明確表示絕不接受調解。
  • 法院認調解顯無成立之望，裁定駁回調解聲請。
  • → 無成立之望
例2.
  • 甲持有乙簽發之本票，聲請調解請求乙給付票款。
  • 法院依第406條第1項第3款裁定駁回調解，並通知甲得逕行起訴或聲請本票裁定。
  • → 票據爭執
例3.
  • 某銀行聲請調解，請求債務人乙返還信用卡消費款。
  • 法院認屬第406條第1項第6款，裁定駁回調解聲請。
  • → 金融機構信用卡請求
調解程序之進行方式與調解委員
  • 調解由簡易庭法官主導，通常先由調解委員談，快成時再請法官來。
  • 當事人可對調解委員人選異議或合意選任。
調解程序，由簡易庭法官行之
  • 原則：調解事件由地方法院「簡易庭」法官負責（通常為第427條簡易事件專股）。
  • 簡易庭法官熟悉小額及簡易案件，且有調解專業訓練。
訴訟中經法官移付調解事件，得由原法院、受命法官或受託法官行之
  • 例外：訴訟中經法官依第420條之1移付調解者，可由原承辦法官（通常為普通庭法官）、受命法官（合議案之受命法官）、受託法官（他法院受託之法官）進行，無須移給簡易庭。
調解「由法官選任調解委員」一人至三人「先行調解」
  • 委員先行原則：法官不直接上場，先從法院調解委員名冊中選任1至3名委員，由委員進行初步溝通、協調。
先行調解至相當程度「有成立之望」或其他必要情形時，再「報請法官」到場
  • 待委員先行調解認案件有成立之望，或發生其他必要情形（如雙方已達成共識），再報請法官到場主持。
但兩造當事人合意或法官認為適當時，亦得逕由法官行之
  • 例外：若雙方當事人均同意由法官直接調解，或法官認案件特別簡單（如數額極小、爭點明確）或委員無作用，得由法官親自調解，不經委員。
當事人對於前項調解委員人選有異議或兩造合意選任其他適當之人者，法官得「另行選任或依其合意選任」之
  • 當事人對委員之異議權及選任權。當事人可對法官原選任之委員表示異議（如認為委員偏頗、不專業），法官應另選其他委員。
  • 若雙方共同推舉特定第三人為委員，法官應尊重其合意。
例1.
  • 甲因車禍糾紛向法院聲請調解（強制調解事件）。
  • 法院分案給簡易庭法官A，由A選任調解委員。
  • → 簡易庭法官
例2.
  • 乙訴請丙給付貨款案件，在言詞辯論中，承辦法官B認有和解之望，依第420條之1移付調解。
  • 法官B自行主持調解，未移給簡易庭。
  • → 訴訟中移付調解
例3.
  • 法官選任調解委員丁、戊，由丁、戊先與雙方溝通，歷時一小時後，雙方已有初步共識，委員報請法官到場。
  • 法官到場後製作調解筆錄，調解成立。
  • → 委員先行調解
例4.
  • 兩造均希望由某資深律師己擔任調解委員。
  • 法官尊重其合意，選任己為委員。
  • → 當事人合意選任委員
地方法院調解委員名冊之設置與彈性選任
  • 法院要有調解委員名單供平時選用，但法官為了案子好，也可以找名單外的人來幫忙調解。
例1.
  • 法官B處理一件涉及晶片製程的商業機密糾紛。調解委員名冊中缺乏熟悉半導體產業的人士。
  • 法官B依職權選任了一位國內知名且雙方均為信服的半導體專家（未列冊）擔任調解委員。
  • → 選任名冊外專業人士
調解期日之指定與通知
  • 法官指定第一次調解期日，後續可授權委員指定。
  • 法院要同時把調解聲請書和通知書寄給對方，並寫明不到場的後果。
例1.
  • 甲向法院聲請調解，法官收案後，指定113年6月15日上午10時為調解期日，並命書記官製作通知書。
  • → 法官指定第一次期日
例2.
  • 第一次調解期日雙方未達共識，法官授權主任調解委員指定續行期日。
  • 主任調解委員指定7日後同一時間。
  • → 授權委員指定續行期日
調解委員之程序指揮權
  • 調解委員主持調解時有權指揮程序；若有多位委員，由法官指定的主任委員統一指揮。
例1.
  • 法官選任調解委員甲一人。
  • 甲在調解期日，指揮兩造先各自陳述，再進行溝通。
  • → 單一委員指揮
例2.
  • 法官選任調解委員乙、丙、丁三人，並指定乙為主任調解委員。
  • 調解過程中，由乙決定發言順序及休息時間。
  • → 複數委員，指定主任委員
命當事人本人到場
  • 法官於必要時，得命當事人或法定代理人本人於調解期日到場。
  • 調解委員認有必要時，亦得報請法官行之。
例1.
  • 法官審閱卷宗發現，A公司積欠B款項，但雙方對於還款金額與方式有極大歧見，而A公司僅派無決定權的員工到場。
  • 法官認為負責人本人不到場無法解決，裁定「命A公司法定代理人林先生本人於下週五調解期日到場」。
  • → 法官命本人到場
例2.
  • 在一件遺產分割調解中，四兄弟委任律師到場，但律師對各房私下恩怨與特殊情感需求完全不了解，使調解陷入僵局。
  • 調解委員向法官報告，法官隨即命令四位當事人本人下次必須親自到場。
  • → 委員報請法官命本人到場
無正當理由不到場之制裁
  • 調解不到場且無正當理由，法院可罰3,000元；已被命令本人到場卻不來，同樣可罰。
  • 被罰者可抗告，抗告期間停止執行。
例1.
  • 甲聲請對乙調解，法院通知乙於5月10日到場。
  • 乙當日無故未到，亦未委任代理人。法院依第409條第1項前段，裁定處乙罰鍰2,000元。
  • → 無正當理由不到場
例2.
  • 法官曾依第408條命丙本人必須到場。
  • 丙委任律師到場，本人未到，且無正當理由（如無生病證明）。
  • 法院依第409條第1項後段，裁定處丙罰鍰1,500元。
  • → 違反命本人到場命令
調解程序中之暫時處置與保全
  • 調解中為避免脫產或破壞，法院可依聲請作暫時處置（不得抗告），違反者可罰3萬元。
  • 但處置不能強制執行，且調解終結即失效。
要件：1.為達成調解目的之必要 2.依當事人之聲請
  • 須由當事人聲請，法院不得依職權發動。
  • 「必要」指若不處置，調解可能無法進行或結果將落空。
措施：禁止他造「變更現狀」、「處分標的物」，或命為其他一定行為或不行為
  • 「禁止變更現狀」例如禁止拆除房屋、禁止搬離特定物品。
  • 「禁止處分標的物」例如禁止出售、移轉、設定抵押。
  • 「命為一定行為或不行為」例如限期修復漏水、暫停施工、交付鑰匙。
擔保：必要時，得命聲請人供擔保後行之
  • 為避免聲請人濫用聲請，法院得命其提供擔保（如現金、銀行保證書），以賠償他造可能因不當處置所受之損害。
不得抗告：聲請暫時處置之裁定，不得抗告
  • 對於准許或駁回暫時處置的裁定，當事人均不得抗告。
例1.
  • 甲聲請對乙調解，法院通知乙於5月10日到場。
  • 乙當日無故未到，亦未委任代理人。法院依第409條第1項前段，裁定處乙罰鍰2,000元。
  • → 無正當理由不到場
例2.
  • 法官曾依第408條命丙本人必須到場。
  • 丙委任律師到場，本人未到，且無正當理由（如無生病證明）。
  • 法院依第409條第1項後段，裁定處丙罰鍰1,500元。
  • → 違反命本人到場命令
調解之處所與公開原則
  • 調解可在法院外進行（委員須經法官許可），且可以不公開，方便當事人暢所欲言。
調解程序於法院行之，於必要時，亦得於其他適當處所行之
  • 原則：法院內 。
  • 例外：其他適當處所。
  • 「必要時」例如：當事人臥病在床、勘驗現場後立即調解、大型機具須現場檢視、群體紛爭於社區調解。
調解委員於「其他處所行調解」者，應「經法官許可」
  • 委員在法院外進行調解，須事先報請法官許可（書面或口頭），以確保程序監督。
前項調解，「得不公開」
  • 調解程序不適用公開原則。法院得依職權或當事人聲請，禁止第三人旁聽。
例1.
  • 甲車禍重傷住院，無法到法院。
  • 法官獲悉後，決定於甲所在醫院的會議室進行調解。
  • → 其他適當處所行調解者，應經法官之許可
例2.
  • 調解委員至土地現場勘驗界址，現場即進行調解，並事先報請法官許可。
  • → 其他適當處所行調解者，應經法官之許可
調解委員報請法官處理之情形
  • 調解委員若發現案件有駁回調解事由（顯無成立之望、票據、金融機構等），不能自己決定，要報請法官處理。
調解委員認調解有第406條第1項「駁回調解事由」者
  • 調解委員依其調解經驗及對案情的了解，認為有第406條第1項「駁回調解事由」，例如：
    • 調解顯無成立之望（如雙方水火不容、一方已明確拒絕）。
    • 已經其他法定調解機關調解不成立。
    • 票據爭執。
    • 金融機構請求事件。
    • 係反訴事件。
    • 應為公示送達或於外國送達。
報請法官處理之
  • 委員應製作書面或口頭報告，將案件及具體理由呈報給承辦法官，由法官決定是否駁回調解聲請或續行調解。
例1.
  • 調解委員在進行調解時，發現相對人住址不明，法院通知書必須公示送達。
  • 委員認屬第406條第1項第5款，報請法官處理。法官收報後，依同條裁定駁回調解聲請。
  • → 有第406條第1項「駁回調解事由」，委員報請法官處理
調解委員之日費、旅費及報酬
  • 調解委員幫忙調解，可以領取出席費、車馬費和報酬，全部由國庫買單，當事人免付費。
例1.
  • 王律師擔任某地方法院的調解委員，接到一件車禍賠償的調解案。他於調解期日到場，為此請了半天假，並開車前往法院。
  • 調解結束後，王委員可以依規定向法院申請500元的日費、依里程計算的交通費（旅費），法官還可能視其貢獻，額外核准一筆報酬。
  • → 調解委員行調解，得支領日費、旅費，並得酌支報酬
例2.
  • 民眾甲與乙因漏水問題聲請調解，法院指派了調解委員進行調解。
  • 甲與乙事後並未收到法院要求他們繳納「調解委員出席費」或「報酬」的帳單。→ 因第411條第2項明定此費用由國庫負擔。
  • → 調解費用由國庫負擔
第三人之參加調解
  • 與調解結果有利害關係的第三人，可以主動申請參加，法院也可以命他參加。
就調解事件有「利害關係」之第三人
  • 與訴訟參加相同，此處的利害關係指「法律上之利害關係」，即調解的結果（尤其是調解成立後的效力）將直接影響第三人的權利義務。
  • 例如：調解事件是分割共有物，未參與調解的其他共有人；或調解事件是確認債權，該債權的保證人。
「經法官許可」，得參加調解程序
  • 第三人的主動參加權。第三人須向法院提出聲請，並釋明其有利害關係。
  • 法官審查後，若認確有利害關係且無礙調解程序之進行，應予許可。許可後，第三人即成為調解程序的當事人。
法官並得將事件通知第三人，「命其參加」
  • 法院的職權通知與強制參加。法院若知悉有該第三人存在（例如從卷證資料發現），為避免將來另生爭議，得主動通知該第三人，並「命令」其參加調解。
例1.
  • 甲、乙因一筆連帶債務如何分擔聲請調解。丙為該債務的連帶保證人，調解結果將直接影響丙的代位求償權。
  • 丙向法官聲請參加調解，法官許可。
  • → 有「利害關係」之第三人，經法官許可，得參加調解程序
例2.
  • 甲、乙調解分割A地，法院從土地登記資料中發現A地尚有共有人丙未參與調解。
  • 為求一次解決，法院通知丙並命其參加調解。
  • → 法官得將事件通知第三人，「命其參加」
調解程序中對事件關係之審究
  • 調解時可以聽專家說、去現場看，但如果要正式調查證據，還是得交給法官來做。
行調解時，為審究事件關係及兩造爭議之所在
  • 此為本條各項作為的目的。強調所有動作都是為了服務「調解」，而非為了審判，核心是找出能讓雙方接受的「共識點」。
得聽取當事人、具有專門知識經驗或知悉事件始末之人或其他關係人之陳述
  • 這是一個比訴訟程序更為靈活的資訊蒐集方法。不需要像證人般具結，也不必經過嚴格的交互詰問，其目的在於獲得資訊，而非取得證據。
察看現場或調解標的物之狀況
  • 類似訴訟中的勘驗，但程序更為簡便。可以由調解委員在法官授權下為之。
於必要時，得由法官調查證據
  • 為權限歸屬的關鍵規定。當案情複雜或事實爭議過大，例如雙方對於某份文件的真偽有爭執，或須對損害數額進行專業鑑定。
  • 此時必須回歸法官職權，由法官依正式的證據調查程序（如鑑定、文書提出命令）來處理，調解委員應報請法官進行。
例1.
  • 在一件房屋瑕疵的調解案中，雙方對漏水原因各執一詞。
  • 調解委員邀請一位水電技師（具有專門知識經驗者）到場，說明管線配置與漏水的可能原因。→ 符合本條「聽取具有專門知識經驗之人」的規定。
  • → 聽取專家意見
例2.
  • 一件車禍賠償案，雙方對肇事責任歸屬的鑑定報告有根本性爭執，調解委員認為無法僅靠陳述釐清，遂報請法官。
  • 法官決定函請車輛行車事故鑑定委員會重新鑑定。
  • → 法官調查證據
調解委員之態度與職責
  • 調解委員要態度親切、從旁勸導、提出公平方案，全力促成雙方和諧解決問題。
例1.
  • 王委員在調解一場兄弟鬩牆的遺產分割案。
  • 他沒有責備任何一方，而是先耐心聽完兩人發洩多年怨氣，然後用溫和的語氣說：「我能理解你們的感受，但為了這塊地打官司，至少要兩三年還要花幾十萬律師費，對誰都沒有好處。」
  • → 「和平懇切之態度」與「適當之勸導」。
例2.
  • 在一件鄰居因狗吠噪音引起的糾紛中，雙方僵持不下。調解委員見狀，擬了一個方案：「是不是可以這樣，張先生在晚上10點後將狗帶入室內，而李先生也不再向環保局檢舉，大家各退一步。」
  • → 「就調解事件酌擬平允方案」
調解委員及法官酌定調解條款
  • 財產爭議調解，經雙方同意，可由調解委員或法官代為擬定解決方案，經核定或記明筆錄即生效。
關於財產權爭議之調解
  • 適用範圍：限財產權爭議（非身分或親屬事件）。
要件：經兩造同意
  • 雙方必須明確表示同意由委員酌定方案，不得強迫。委員酌定後，方案即成為調解條款。
得「由調解委員酌定」解決事件之調解條款
  • 委員酌定後，方案即成為調解條款。
酌定之調解條款，應作成書面或記明於調解程序筆錄。由調解委員簽名後，送請法官審核；其「經法官核定者，視為調解成立」
  • 委員酌定 → 作成書面或記明筆錄 → 委員簽名 → 送法官審核。
  • 法官審核後若核定（認可），即發生與調解成立相同之效力。若法官不核定，則不成立。
前項調解條款之酌定，除兩造另有約定外，以「調解委員過半數定之」
  • 若有多位委員，以過半數決。
調解委員「不能酌定」調解條款時，法官得於徵詢兩造同意後，酌定調解條款。或另定調解期日，或視為調解不成立
  • 調解委員「不能酌定」調解條款：如過半數無法形成、委員意見分歧。
  • 法官有三種選擇：
    1. 徵得兩造同意後，由法官酌定方案。
    2. 另定調解期日（再給雙方機會）
    3. 視為調解不成立（調解程序終結）。
法官酌定之調解條款，於書記官「記明筆錄」時，視為調解成立
  • 法官酌定方案，無須再送核定（因法官本身就是核定者），直接記明筆錄即生效。
例1.
  • 甲、乙因買賣價金50萬元爭議調解，雙方同意由調解委員丙酌定方案。
  • 丙提出「乙應於30日內給付甲35萬元，雙方其餘請求拋棄」，甲、乙當場未表示反對。
  • 丙將方案記明筆錄並簽名，送法官核定。法官核定後，調解成立。
  • → 委員酌定 → 作成書面或記明筆錄 → 委員簽名 → 送法官審核 → 調解成立
例2.
  • 甲、乙同意授權調解委員酌定，但兩位委員意見不同（一人支持40萬元、一人支持30萬元），無法達過半數。
  • 法官徵得兩造同意後，自行酌定「乙應給付甲38萬元」，記明筆錄。調解成立。
  • → 委員不能酌定 → 徵得兩造同意 → 法官酌定 → 記明筆錄 → 調解成立
調解不成立之處理
  • 調解不成立者，法院應付與當事人證明書。
例1.
  • 甲、乙調解不成，法院發給「調解不成立證明書」。
  • 甲持該證明書向法院起訴，證明已踐行強制調解前置程序。
調解之效力、救濟
  • 調解成立，效力等同確定判決。
  • 有瑕疵可提宣告無效或撤銷之訴（30天內）。
調解經當事人合意而成立
  • 「合意」：雙方意思表示一致，不以書面為必要（但實務上會作成筆錄）。
調解成立者，與訴訟上和解有同一之效力
  • 效力：與訴訟上和解相同（第380條第1項），亦即與確定判決有同一效力。
    • 有既判力（當事人不得就同一事件再行起訴）
    • 有執行力（給付內容可直接聲請強制執行）
調解成立後撤銷：提起宣告調解無效或撤銷調解之訴
  • 無效原因：調解內容違反強制規定或公序良俗（如調解殺人賠償約定）、當事人無行為能力、調解違反專屬管轄等。
  • 撤銷原因：當事人被詐欺、脅迫、或基於重要錯誤而成立調解。
  • 宣告調解無效或撤銷調解之訴：形成之訴。
宣告調解無效或撤銷調解之訴，得就「原調解事件」合併起訴或提起反訴。並視為自聲請調解時，已經起訴
  • 就「原調解事件」合併起訴：在同一訴訟中，合併請求對原爭議為裁判（例如：請求宣告調解無效，同時請求被告給付原爭議款項）。
  • 視為自聲請調解時已經起訴：時效中斷、附帶請求利息等效果，回溯至聲請調解時，避免因調解程序耗費時間而受不利益。
例1.
  • 甲、乙因車禍損害賠償調解成立，乙同意賠甲10萬元。
  • 甲持調解筆錄向法院聲請強制執行乙的財產。乙不得就同一車禍事件再行起訴。
  • → 調解成立，效力等同確定判決
例2.
  • 甲以不實之估價單詐騙乙，乙陷於錯誤而同意賠償甲50萬元。
  • 乙事後發現遭騙，於30日內向原法院提起撤銷調解之訴。
  • → 有調解撤銷原因——遭詐欺，30日內向原法院提起撤銷調解之訴
例3.
  • 甲聲請調解時（6月1日），借款請求權時效將於6月30日屆滿。調解於7月15日不成立。甲於7月20日起訴。
  • 因本條第3項「視為自聲請調解時起訴」，時效視為6月1日中斷，未消滅。
  • → 視為自聲請調解時起訴
法官依職權提出調解方案
  • 雙方在財產爭議中已很接近但差一步時，法官可主動提出公平方案，送達後10天內無人異議就成立。
要件1.關於財產權爭議之調解。 要件2.當事人不能合意但「已甚接近」
  • 例如：甲請求50萬元，乙願意給付48萬元，僅差2萬元；或雙方對給付方式有共識，僅對履行期限差幾天。
效果：法官「以職權提出方案」
  • 法官應斟酌一切情形，其有調解委員者，並應徵詢調解委員之意見，求兩造利益之平衡。
  • 法官方案應在不違反兩造當事人之「主要意思範圍」內。例如：雙方均同意「給付金錢」，法官不得改為「給付實物」。雙方均同意「分期」，法官不得改為「一次付清」。
  • 以職權提出：法官主動提出具體方案，不待當事人聲請。方案應明確、可執行（如「乙應於113年7月31日前給付甲新臺幣49萬元」）。
前項方案，應送達於當事人及參加調解之利害關係人
  • 方案作成後，應送達雙方當事人及已參加調解之第三人。
  • 送達後，依第418條，當事人於10日內若未異議，視為調解成立。
當事人或「參加調解」之利害關係人對於「法官職權提出方案」，得於送達後「十日不變期間」內，提出「異議」
  • 異議主體：原當事人及參加調解之利害關係人（第三人）。
  • 異議對象：法官「依職權」提出之方案。
  • 提起期間：送達後10日內。
  • 「不變期間」意即不能延長，逾期即失權。
前項期間內提出異議者，視為調解不成立；其未於前項期間內提出異議者，視為已依該方案成立調解
  • 「提出異議」→ 調解不成立（回復到未調解前狀態，當事人可起訴）。
  • 「未提出異議」→ 擬制成立（無須雙方另簽同意書，該方案自動成為調解內容，與確定判決同效力）。
例1.
  • 法官依職權提出「乙應給付甲49萬元」之方案，於6月1日送達甲、乙。
  • 甲、乙均未於6月11日前提出異議。6月12日起，視為調解成立，該方案具有與確定判決同一效力。
  • → 法官依職權提出方案 → 10日內無人異議 → 調解成立
例2.
  • 同上例，甲於6月5日向法院提出異議。
  • 院收受後，通知乙。視為調解不成立，甲得逕行起訴。
  • → 法官依職權提出方案 → 10日內異議 → 調解不成立
例3.
  • 甲聲請調解時（6月1日），借款請求權時效將於6月30日屆滿。調解於7月15日不成立。甲於7月20日起訴。
  • 因本條第3項「視為自聲請調解時起訴」，時效視為6月1日中斷，未消滅。
  • → 視為自聲請調解時起訴
調解不成立與訴訟之銜接
  • 調解不成立可直接轉訴訟辯論，起訴時點回溯到聲請調解時，保障時效利益。
情況1.兩造到場調解不成立：得「立即辯論」
  • 要件：一造聲請，他造無異議。
    • 他造聲請延展期日者，應許可之。
  • 效果：視為自聲請調解時，已經起訴。保障聲請人的時效利益及附帶利息起算點。
情況2.於調解不成立證明書「送達後十日內起訴」
  • 效果：視為自聲請調解時，已經起訴。
情況3.強制調解事件當事人直接起訴，法院視為調解聲請而調解不成立：除當事人聲請延期外，法院應命「立即辯論」
  • 效果：訴訟繫屬時點回溯至「原起訴時」
情況4.債務人對支付命令提出異議，法院視為調解聲請而調解不成立：除當事人聲請延期外，法院應命「立即辯論」
  • 效果：訴訟繫屬時點回溯至「支付命令聲請時」
例1.
  • 甲、乙因車禍糾紛聲請調解，雙方到場但無法達成協議。甲聲請法院直接進行訴訟辯論。
  • 法官准許，並諭知「本件調解不成立，改依通常訴訟程序進行辯論」。甲無須另具起訴狀。
  • → 到場調解不成立，轉訴訟辯論
例2.
  • 同上例，乙表示需要時間準備答辯，請求延展期日。法官應許可，改定一個月後再開庭。
  • → 他造聲請延展期日
例3.
  • 甲於3月1日聲請調解，調解於6月1日不成立。甲於6月5日收到不成立證明書，6月10日起訴。
  • 甲對乙之請求權時效將於6月30日屆滿。因本條第3項「視為自聲請調解時起訴」，時效視為3月1日中斷，有效。
  • → 視為自聲請調解時起訴，時效中斷
例4.
  • 甲因相鄰關係爭執直接起訴（依第403條應先調解）。法院將起訴視為調解聲請。
  • 調解不成立後，法院依第419條第4項，直接命為訴訟辯論，並以甲原起訴日為訴訟繫屬日。
  • → 強制調解事件，直接起訴
當事人不到場時調解程序之處理
  • 調解有人缺席時，法官可視情況直接宣告不成立，或再訂一次調解期日。
當事人兩造或一造於期日不到場者
  • 適用前提。包括兩種情形：
    • 兩造不到場：雙方均未出席。
    • 一造不到場：僅一方出席，他方缺席。
法官酌量情形，得視為調解不成立或另定調解期日
  • 酌量情形：應綜合考量缺席者有無正當理由（需否罰鍰）、過去缺席次數、案件類型、調解成立之可能性、他造意願、訴訟經濟等。
  • 視為調解不成立：選擇一。直接終結調解程序，法律上擬制為調解不成立。當事人可依第419條起訴或聲請轉為訴訟辯論。
  • 另定調解期日：選擇二。再給機會，指定新的調解期日，續行調解程序。通常會同時告知缺席者如再不到場可能受罰（第409條）或視為不成立。
例1.
  • 甲到場，乙未到場。乙事前已傳真請假單（因住院），表示願意擇期再調。
  • 法官認乙有正當理由，另定下個月10日為調解期日。
  • → 一造缺席，另定期日
例2.
  • 甲、乙均無正當理由未到場，且前次已缺席過一次。
  • 法官認調解顯無成立之望，當庭諭知「視為調解不成立」。
  • → 兩造缺席，得視為不成立
例3.
  • 甲到場，乙無正當理由缺席（乙曾表示「絕不妥協」）。
  • 法官認無續行實益，逕行視為調解不成立。
  • → 一造缺席，得視為不成立
訴訟中移付調解
  • 官司進行中，雙方合意可轉調解；調解成立，原告可退三分之二裁判費，訴訟終結；調解不成，訴訟繼續。
「第一審」訴訟繫屬中，得「經兩造合意」將事件「移付調解」。訴訟程序停止進行
  • 適用時機：第一審判決前（起訴後、辯論終結前）。
  • 要件：兩造均同意（應以書面或記明筆錄）。法院僅被動受理，不得依職權移付。
  • 訴訟停止：法院暫不進行開庭、裁判等訴訟行為。
調解成立時，訴訟終結。原告得聲請退還裁判費三分之二
  • 調解成立：雙方達成合意，作成調解筆錄（與確定判決同一效力），訴訟因而終結。
  • 原告在調解成立後3個月內向法院聲請，可退還「已繳裁判費」的三分之二（例如繳了3萬元，可退2萬元）。
調解不成立，訴訟程序繼續進行
  • 調解不成立：訴訟自停止處「接續」進行，不重來。
調解成立後，「有無效或得撤銷之原因」者，得「請求繼續審判」
  • 若調解事後被宣告無效或撤銷（如被詐欺、脅迫）。準用第380條第2項：當事人得請求繼續審判（而非另訴）。
  • 退費之請求人，必須將已退還的裁判費「繳回」法院。
例1.
  • 甲到甲起訴乙給付貨款100萬元，已繳裁判費1萬元。
  • 訴訟中，兩造合意移付調解。調解成立，乙同意給付70萬元。
  • 甲於調解成立後2個月，向法院聲請退還裁判費三分之二（6,666元）
  • → 移付調解成立時，訴訟終結。原告得聲請退還裁判費三分之二
例2.
  • 甲、乙合意移付調解，但調解不成立。
  • 法院接續進行原訴訟程序（無須重新起訴或開庭）
  • → 移付調解不成立，續行訴訟
例3.
  • 甲、乙調解成立後，甲聲請退費6,666元。
  • 嗣後乙提起撤銷調解之訴勝訴（甲有詐欺行為）。法院命甲將6,666元繳回。
  • → 調解撤銷，「請求繼續審判」，繳回退費
調解程序筆錄之製作與送達
  • 調解程序須製作筆錄，記載調解成立與否；調解成立後須在10天內將筆錄正本送達當事人。
法院書記官應作調解程序筆錄
  • 應：強制規定，原則上應由書記官製作。
  • 調解程序筆錄：記錄調解程序進行情形之文書。
調解程序筆錄應記載：調解成立或不成立、期日之延展、訴訟之辯論
  • 調解成立或不成立：調解是否成功。
  • 期日之延展：調解期日是否延期。
  • 訴訟之辯論：若調解不成立，是否進入訴訟辯論（即言詞辯論）。
但調解委員行調解時，得僅由「調解委員自行記錄」調解不成立或延展期日情形
  • 但書：若由「調解委員」調解（非法官），且調解「不成立」或「延期」，委員可「自行記錄」即可（節省程序）。
法院提出之調解方案，「經法官當場宣示」者，應一併記載於筆錄
  • 法院提出之調解方案：法官依職權提出之「解決事件之方案」（第417條）
  • 經法官當場宣示：法官於調解期日當場宣布該方案。應將該方案內容一併記載於筆錄。
「調解成立」者，應於「十日內將筆錄正本送達」於當事人及參加調解之利害關係人
  • 十日內：自調解成立之日起算「10日內」。
  • 送達當事人及利害關係人：送達予當事人及參加調解之第三人。
例1.
  • 法院書記官製作調解程序筆錄，記載「調解不成立，雙方未能達成協議，定於○月○日續行訴訟辯論」
  • → 書記官製作調解筆錄
例2.
  • 調解委員進行調解，調解不成立，委員自行在筆錄上記載「調解不成立，延期至○月○日」
  • → 調解委員自行記錄
例3.
  • 調解成立，法院於10日內將調解筆錄正本送達甲、乙兩造。
  • → 調解成立後10日內送達筆錄
例4.
  • 法官依第417條提出解決方案並宣示，書記官將該方案內容記載於筆錄。
  • → 法院提出之調解方案，「經法官當場宣示」者，應一併記載於筆錄
調解程序中陳述或讓步之保密與證據排除
  • 調解時說的任何話、提出的任何讓步，只要調解沒成功，在後續的官司裡都不能拿來當作判決的依據。
調解程序中，調解委員或法官所為之勸導、當事人所為之陳述或讓步
  • 調解委員或法官為促進和解所為之「勸導」、「建議」、「分析」等言詞。
  • 當事人就事實或法律所為之陳述、當事人為促成和解所提出之「讓步條件」（如「我願意賠償50萬元」）。
於調解「不成立後」之本案訴訟，「不得採為裁判之基礎」
  • 調解「不成立後」（即未達成和解），案件進入「本案訴訟」（即一般訴訟程序）。
  • 不得採為裁判之基礎：法院「不得」將該等陳述、讓步或勸導作為「認定事實」或「適用法律」之依據。亦不得於判決理由中引用該等內容。
例1.
  • 甲、乙調解時，甲說「我承認有欠錢，但希望少還一點」。調解不成立，乙在後續訴訟中主張「甲已承認欠錢」。
  • 法院不得以甲之陳述為判決基礎。
  • → 調解不成立，調解陳述不得引用於後續訴訟
例2.
  • 甲在調解中表示「願意賠償30萬元」。調解不成立，乙於訴訟中主張「甲已同意賠償30萬元」。
  • 法院不得以此為判決基礎。
  • → 調解不成立，調解讓步不得引用於後續訴訟
例3.
  • 法官於調解中勸導甲「本案你可能敗訴」。調解不成立，甲於訴訟中主張「法官已認同我方主張」。
  • → 調解不成立，調解中法官勸導不得引用於後續訴訟
調解費用之負擔與準用和解退費
  • 調解不成立後起訴，調解費用可納入訴訟費用；調解成立，可比照和解聲請退還三分之二裁判費。
調解不成立後起訴者，其調解程序之費用，應作為訴訟費用之一部
  • 調解程序之費用：包括調解聲請費、調解委員之日費旅費、報酬等。
  • 應作為訴訟費用之一部：該筆費用計入訴訟費用總額，由「敗訴之當事人」負擔。
調解不成立後「不起訴者」，由調解「聲請人負擔」調解程序之費用
  • 調解不成立後，當事人「未起訴」（放棄訴訟）。 該筆費用由「聲請調解之人」（如原告）自行負擔。
調解成立，可比照和解聲請退還三分之二裁判費
  • 第84條：訴訟上和解之費用負擔與裁判費退還（當事人得於和解成立後3個月內聲請退還裁判費三分之二）。
  • 準用之：調調解成立時，當事人亦得聲請退還該審級「裁判費三分之二」（限於已繳納之裁判費）。
例1.
  • 甲聲請調解，調解不成立，甲起訴乙，最終甲勝訴。
  • 調解程序費用（如聲請費1,000元）計入訴訟費用，由乙（敗訴方）負擔。
  • → 調解不成立後起訴者，其調解程序之費用，應作為訴訟費用之一部
例2.
  • 甲聲請調解，調解不成立，甲未起訴。調解費用由甲（聲請人）自行負擔。
  • → 調解不成立後「不起訴者」，由調解「聲請人負擔」調解程序之費用
例3.
  • 甲、乙調解成立，甲已繳納裁判費10萬元。甲得於調解成立後3個月內聲請退還三分之二（即66,666元）
  • → 調解成立，準用退費
應強制調解事件逕行起訴之效果
  • 強制調解案件若直接起訴且無例外事由，會被視為調解聲請；若僅部分請求屬強制調解，則不適用此規定。
「強制調解事件」，逕向法院起訴者，視為調解之聲請
  • 「強制調解事件」（如鄰居間爭議、合夥糾紛、消費訴訟等）。
  • 逕向法院起訴：當事人未先聲請調解，直接向法院提起訴訟。
  • 視為調解之聲請：法院應將案件移付「調解程序」，不直接進入訴訟審理。
例外1：起訴時釋明「調解例外事由」
  • 調解例外事由：406條第1項所列之「例外事由」（如聲請人住居所不明、對造在國外等）。
例外2：以一訴「主張數項標的」，其一部「非屬強制調解事件」
  • 若原告同時主張「數項標的」（如請求給付貨款及返還借款），其中「僅一部」屬強制調解事件，另一部非屬強制調解。
  • 則「不適用」前項「視為調解聲請」之規定（即案件仍可起訴，無須先調解）。
例1.
  • 甲、乙為鄰居，因漏水爭議（屬第403條第1項第4款「鄰居間爭議」）甲逕行起訴。
  • 甲無第406條例外事由。法院將甲之起訴「視為調解之聲請」，先移付調解。
  • → 應強制調解事件，無例外事由，直接起訴：「視為調解之聲請」
例2.
  • 甲起訴乙（乙住國外，屬第406條第1項第1款），甲於訴狀中表明「乙住美國」並附出入境證明。
  • 法院認有例外事由，不視為調解聲請，直接進入訴訟程序。
  • → 應強制調解事件，起訴時釋明「例外事由」，直接進入訴訟程序
例3.
  • 甲起訴請求乙給付貨款（非強制調解）及排除漏水侵害（強制調解）。
  • 法院認僅一部屬強制調解，不適用視為調解聲請之規定，案件仍可訴訟。
  • → 一部強制調解，一部非屬，得直接進入訴訟程序
撤回調解聲請之效果與準用撤回起訴之退費
  • 撤回調解聲請，視為從未聲請；且可比照撤回起訴，在程序終結前撤回可聲請退還部分費用。
調解之聲請經撤回者，視為未聲請調解
  • 視為未聲請調解：法律上「擬制」該調解聲請自始不存在。
  • 效果：法院無須續行調解程序、不發生「中斷時效」之效力。
「調解程序終結前」撤回，可聲請退還部分費用
  • 第83條第1項：撤回起訴者，訴訟費用由原告負擔；但於第一審言詞辯論終結前撤回者，得於撤回後三個月內聲請退還裁判費三分之二。
  • 準用之：撤回調解聲請者，得類推適用該退費規定。
  • 即：若於「調解程序終結前」（即尚未為實質調解）撤回，得聲請退還「調解聲請費」或其他費用之三分之二。
例1.
  • 甲聲請調解，後因乙拒絕調解，甲撤回聲請。該調解聲請視為自始不存在，時效不中斷。
  • → 撤回調解，視為未聲請
例2.
  • 甲聲請調解，已繳納聲請費1,000元。甲於調解期日前撤回聲請，得準用第83條第1項，聲請退還三分之二（約666元）
  • → 準用退費
調解事件之保密義務
  • 法官、書記官和調解委員因調解而知悉的業務機密或個人隱私，都必須保密，不得洩漏。
法官、書記官及調解委員
  • 參與調解程序之法院人員（法官、書記官）及調解委員。
  • 不包括「當事人」或「第三人」（其保密義務另依法律規定）。
因經辦調解事件，知悉他人職務上、業務上之秘密或其他涉及個人隱私之事項，應保守秘密
  • 秘密不得「洩漏」或「交付」予第三人（包括訴訟外之人）。
例1.
  • 甲、乙調解時，甲透露其公司配方。調解委員知悉後，不得將該配方洩漏予第三人。
  • → 調解委員應保守秘密
例2.
  • 調解事件涉及政府機關，法官知悉公務機密，不得洩漏。
  • → 法官應保守秘密
