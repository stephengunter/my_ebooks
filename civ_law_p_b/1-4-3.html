民事訴訟法 期日及期間

期日及期間

送達之職權性
  • 訴訟期日（開庭日期）原則上由審判長主動決定。
期日，除別有規定外，由審判長依職權定之
  • 開庭日期或其他訴訟期日，原則上由審判長「主動」決定，不需要等當事人來請求。
期日之通知
  • 開庭日期原則上要寄通知書；但若當場告知或當事人已表明會到場，就不用再寄。
審判長定期日後，法院書記官「應作通知書」「送達」於訴訟關係人
  • 審判長指定開庭日期後，書記官原則上要寄「通知書」給當事人。
但經審判長「當面告知」所定之期日「命其到場」，或訴訟關係人「曾以書狀陳明」屆期到場者，與送達有同一之效力
  • 審判長「當面告知」所定之期日「命其到場」：審判長已經當面告訴你開庭日期並叫你來。
  • 訴訟關係人「曾以書狀陳明」屆期到場：之前已經寫狀紙說「會如期到場」。
  • 與送達有同一之效力：跟收到通知書有一樣的效力。可以不用再寄通知書。
例1.
  • 審判長於開庭時當面告知甲「下次期日為1月15日」，甲在場聽聞。無須再送達通知書。
  • → 審判長「當面告知」所定之期日「命其到場」
期日之開始
  • 期日，以朗讀案由為始。
  • 每次開庭的開始，都要先由法院人員「朗讀案由」（例如「臺灣臺北地方法院113年度訴字第123號，給付貨款事件」），作為開庭的正式開場。
期日之變更或延展
  • 如有重大理由（如生病、天災），法院可以變更或延後開庭日期，由審判長裁定。
例1.
  • 甲因重病住院，聲請變更期日。法院認有重大理由，裁定變更期日。
  • → 審判長裁定變更期日
期間之酌定與起算
  • 除了法律規定的「法定不變期間」（例如上訴20天）之外，其他的期間（例如法院命補正的期間）由法院或審判長視情況決定。
  • 法院指定的期間，從「送達文件」那天開始算；如果不用送達（例如當庭宣布），就從「宣布」那天開始算。
    • 但如果法院有特別指定起算方式，就依照法院的指定。
期間，除法定者外，由法院或審判長酌量情形定之
  • 法定期間：法律明定之不變期間（如抗告10日、上訴20日）
  • 非法定者：由法院或審判長指定之期間（如命補正書狀之期間、命提出證據之期間）。
法院或審判長所定期間，自定期間之文書「送達」時起算
  • 自「送達」指定期間之「裁定」或「通知」時起算（如收受補正裁定之翌日起算）。
無庸送達者，自宣示定期間之裁判時起算
  • 若當庭「宣示」裁判（如口頭命補正），自「宣示時」起算。
但別定起算方法者，不在此限
  • 若法院「特別指定」起算方式（如「自民國113年1月1日起算」），則從其指定。
例1.
  • 法院裁定「命原告於收受裁定後10日內補正書狀」，該10日自「送達裁定」之翌日起算。
  • → 法院指定補正期間
例2.
  • 審判長當庭宣示「命被告於5日內提出證據」，該5日自「宣示日」起算。
  • → 當庭宣示期間
期間計算依民法規定
  • 訴訟期間的計算方式（例如起算日、假日順延），都依照民法規定。
期間之計算，依民法之規定。
  • 民法第120條：以日、星期、月或年定期間者，其始日不算入
  • 民法第121條：期間末日之計算。
  • 民法第122條：期間末日為休息日時，以次日代之。
例1.
  • 上訴期間20日，自判決送達之「翌日」起算（民法第120條）。
  • → 始日不算入
例2.
  • 期間末日為「星期日」，順延至「星期一」（民法第122條）。
  • → 期間末日為休息日時，以次日代之
例3.
  • 法院指定「一個月」期間，自某日起算，至「下月同日」為止（民法第121條）
  • → 以月定期間，該月同日
在途期間之扣除
  • 不住在法院所在地的當事人，計算上訴等法定期間時可扣除郵遞往返的「在途期間」；但有律師在法院所在地代理的話，就不扣。
當事人不在法院所在地住居者，計算法定期間，應「扣除」其「在途期間」
  • 法定期間：如第440條上訴期間20日、第487條抗告期間10日。
  • 在途期間：郵遞或交通所需之時間（由司法院訂定）。
但「有訴訟代理人」住居法院所在地，得為期間內應為之訴訟行為者，不在此限
  • 若代理人住居法院所在地，且可代為訴訟行為，則「不扣除」在途期間（因無郵遞延誤問題）。
前項應扣除之在途期間，由司法院定之
  • 司法院訂定「法院訴訟當事人在途期間標準」或類似規定。
例1.
  • 甲住高雄，對台北地院判決上訴，法定期間20日，應扣除在途期間（如4日），實際上訴期間為「24日」（20+4）。
  • → 住高雄，上訴台北地院，計算法定期間，應「扣除」其「在途期間」
例2.
  • 甲委任台北律師乙為訴訟代理人，乙得住居台北，則不扣除在途期間，上訴期間仍為20日。
  • → 「有訴訟代理人」住居法院所在地，無在途期間
期間之伸長或縮短
  • 法院指定的期間如有重大理由可延長或縮短，但法定的「不變期間」（如上訴20天）不能改。
期間，如有「重大理由」，得「伸長或縮短」之。但不變期間，不得改變
  • 重大理由：如當事人重病、天災、需更多時間準備等。
  • 得「伸長或縮短」：法院有裁量權。
  • 不變期間：法律明定之期間（如上訴期間20日、抗告期間10日、再審期間30日）。 不得伸長或縮短。
伸長或縮短期間，由法院裁定。但期間係審判長所定者，由審判長裁定
  • 若原期間係「法院」所定（如合議庭裁定），由「法院」裁定伸縮。
  • 若原期間係「審判長」所定（如指定補正期間），由「審判長」裁定伸縮。
例1.
  • 法院命原告於10日內補正書狀，原告因重病聲請延長。法院認有重大理由，裁定延長為15日。
  • → 有重大理由（重病），法院得裁定延長
例2.
  • 上訴期間20日為不變期間，不得伸長。
  • → 法定不變期間，不得改變
受命法官或受託法官定期日及期間之權限
  • 受命法官或受託法官在自己負責的事務範圍內，有權指定期日和期間，並適用期日及期間的相關規定。
受命法官或受託法官關於其所為之行為，得定期日及期間
  • 受命法官（準備程序的法官）或受託法官（受委託調查證據的法官），在自己負責的事務範圍內，可以指定開庭日期和期限。
  • 關於期日和期間的相關規定（例如如何指定、通知、變更、計算等），也同樣適用於他們。
例1.
  • 受命法官指定「準備程序」於113年1月15日進行。
  • → 受命法官定期日行準備程序
例2.
  • 受託法官命證人於10日內提出文書。
  • → 受託法官定期間命提出文書

回復原狀

聲請回復原狀
  • 因天災等不可歸責事由遲誤不變期間，可在原因消滅後10天內聲請回復原狀；但遲誤超過1年就不能再聲請了。
當事人或代理人，因天災或其他「不應歸責於己」之事由，「遲誤不變期間」者
  • 當事人或代理人：包括本人及訴訟代理人。
  • 天災：如地震、颱風、洪水。
  • 其他不應歸責於己之事由：如重病、車禍、突然被拘禁。
  • 遲誤不變期間：如未於20日內上訴、未於10日內抗告。
得於「原因消滅」後「十日不變期間內」，「聲請」回復原狀
  • 原因消滅後十日不變期間內：自障礙事由結束之翌日起算10日。不變期間，不得伸縮。
  • 聲請回復原狀：向法院聲請「回復原狀」（即回復遲誤前之狀態）。
遲誤不變期間「已逾一年」者，「不得聲請」回復原狀
  • 自「不變期間屆滿日」起算，若已逾「1年」，不得再聲請回復原狀。
例1.
  • 甲因颱風停班，無法於上訴期間20日內上訴。颱風結束後，甲於10日內聲請回復原狀。
  • → 天災遲誤不變期間，得聲請回復原狀
例2.
  • 甲於遲誤上訴期間後第1年2個月始聲請回復原狀，法院駁回。
  • → 遲誤不變期間「已逾一年」者，「不得聲請」回復原狀
回復原狀之聲請程式與補行行為
  • 聲請回復原狀，須向原法院或管轄法院提出書狀，載明原因並釋明，同時補行遲誤的訴訟行為。
因遲誤「上訴」或「抗告」期間而聲請「回復原狀」者，應以書狀向為裁判之「原法院」為之
  • 為裁判之「原法院」：如對第一審判決遲誤上訴，向「第一審法院」聲請；對抗告遲誤，向「為裁定之法院」聲請。
遲誤其他期間者，向管轄該期間內應為之訴訟行為之法院為之
  • 其他期間：如命補正書狀之期間、提出證據之期間。
  • 向「應為該訴訟行為之法院」聲請（通常為本案繫屬法院）。
遲誤期間之「原因」及其「消滅時期」，應於書狀內「表明並釋明」之
  • 表明：具體記載原因（如「因重病住院」）及消滅時期（如「民國113年1月10日出院」）。
  • 釋明：提出證據（如診斷證明、天災證明）。
聲請回復原狀，應「同時補行」期間內應為之「訴訟行為」
  • 例如：遲誤上訴期間，聲請時應「同時」補提「上訴狀」。
  • 若未補行，法院可能駁回聲請。
例1.
  • 甲遲誤上訴期間，向第一審法院提出回復原狀聲請，並補提上訴狀。
  • → 遲誤上訴，以書狀向為裁判之「原法院」聲請回復原狀。並補提上訴狀
例2.
  • 甲遲誤命補正書狀之期間，向本案繫屬法院聲請回復原狀。並補正書狀。
  • → 遲誤補正期間，以書狀向繫屬法院聲請回復原狀。並補正書狀
回復原狀聲請之裁判方式
  • 回復原狀聲請，原則上由原法院與補行行為合併裁判；若原法院准許且送交上級法院，則由上級法院合併裁判。
回復原狀之聲請，由受聲請之法院與補行之訴訟行為「合併裁判」之
  • 受聲請之法院：受理回復原狀聲請之法院。
  • 補行之訴訟行為：如補提上訴狀、抗告狀。
  • 合併裁判：在同一裁定或判決中一併決定（如「准許回復原狀，並受理上訴」）。
但原法院認其聲請「應許可」，而將該上訴或抗告事件「送交」上級法院者，由「上級法院合併裁判」
  • 認其聲請應行許可：原法院認為回復原狀之聲請「有理由」。
  • 將該上訴或抗告事件送交上級法院：若上訴或抗告事件依法應送交上級法院（如上訴期間內補提上訴狀）。
  • 由「上級法院合併裁判」：原法院應將回復原狀聲請及上訴事件「一併送交」上級法院，由其合併裁判。
例1.
  • 原法院認回復原狀聲請有理由，且將上訴事件送交第二審法院，應將回復原狀聲請一併送交第二審法院合併裁判。
  • → 回復原狀聲請有理由，將上訴「送交」上級法院，由「上級法院合併裁判」
