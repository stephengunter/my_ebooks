民事訴訟法 訴訟程序之停止

訴訟程序之停止

當事人死亡之當然停止
  • 官司進行中當事人死亡，訴訟自動停止，必須等到繼承人或遺產管理人承接訴訟後才能繼續。
當事人死亡者，訴訟程序當然停止
  • 當然停止：自動停止，無須法院裁定或當事人聲請。
  • 停止時點：自「當事人死亡時」起，訴訟程序即停止。
直至「繼承人」、「遺產管理人」或其他依法令應續行訴訟之人「承受訴訟」
  • 繼承人：民法上之法定繼承人（配偶、子女、父母等）。
  • 遺產管理人：若繼承人有無不明，法院選任之遺產管理人（民法第1177條）。
  • 其他依法令應續行訴訟之人：如破產管理人（破產法）、清算人（公司法）。
  • 承受其訴訟：繼承人或管理人應向法院「聲明承受訴訟」（第175條），或由法院依職權命其承受（第178條）。
例1.
  • 甲起訴乙，訴訟中甲死亡。訴訟程序當然停止。
  • 甲之繼承人丙（配偶）應聲明承受訴訟，始能續行。
  • → 當事人死亡者，訴訟程序當然停止。直至「繼承人」「承受訴訟」
例2.
  • 乙死亡且無繼承人，法院選任遺產管理人戊，戊承受訴訟後續行。
  • → 當事人死亡者，訴訟程序當然停止。直至「遺產管理人」「承受訴訟」
法人合併之當然停止
  • 公司合併消滅，訴訟會自動停止，由合併後存續或新設的公司承接。
    • 但若合併不能對抗對造，則不停止。
法人因「合併」而「消滅」者
  • 法人：公司、財團法人、社團法人等。
  • 合併而消滅：法人因合併（吸收合併或新設合併）而消滅（如A公司被B公司吸收）。
訴訟程序在因合併而「設立」或合併後「存續」之法人「承受訴訟」前當然停止
  • 因合併而設立：新設合併（A+B=C）。
  • 合併後存續：吸收合併（A+B=A，A存續）。
  • 承受訴訟：存續或新設法人應向法院聲明承受訴訟。
  • 當然停止：自動停止，無須法院裁定。
前項規定，於其合併「不得對抗他造」者，不適用之
  • 不得對抗他造：例如：
    • 合併係在訴訟「提起後」始發生，且他造「不知」或「未同意」。
    • 合併係為「規避訴訟」而為之（如將債務移轉予無資力之法人）。
  • 此時，他造仍可對「原法人」繼續訴訟（或對合併後之法人直接訴訟），不適用當然停止。
例1.
  • 甲起訴乙公司，訴訟中乙公司被丙公司吸收合併（乙消滅）。訴訟程序當然停止，須由丙公司承受訴訟。
  • → 吸收合併，合併後「存續」之法人「承受訴訟」前當然停止
例2.
  • 甲起訴乙公司，乙公司於訴訟中與丙公司合併（合併係為將資產移轉予丙，以規避賠償）。
  • 甲主張合併不得對抗甲，法院認甲之主張有理，不適用停止規定，訴訟仍可繼續對乙（或丙）進行。
  • → 合併「不得對抗他造」者，不當然停止
當事人喪失訴訟能力或法定代理人變更之當然停止
  • 當事人喪失訴訟能力或法定代理人變更，訴訟會自動停止，直到新的法定代理人或本人承接訴訟。
當事人喪失訴訟能力，訴訟程序當然停止。直至「法定代理人」或取得訴訟能力之本人「承受訴訟」
  • 喪失訴訟能力：例如因精神障礙受「監護宣告」（民法第14條），無法獨立為訴訟行為。
  • 法定代理人：例如新選任之監護人、新董事長等。
  • 取得訴訟能力之本人：若原喪失訴訟能力之當事人「回復訴訟能力」（如撤銷監護宣告），則本人可承受訴訟。
當事人之「法定代理人死亡」或其「代理權消滅」者，訴訟程序當然停止。直至「新法定代理人」「承受訴訟」
  • 法定代理人死亡：如未成年人父母死亡、公司代表人死亡。
  • 代理權消滅：如法定代理人被解任、公司負責人更換、監護人任期屆滿。
例1.
  • 甲訴訟中因精神障礙受監護宣告，喪失訴訟能力。
  • 訴訟程序當然停止，須由新監護人承受訴訟。
  • → 當事人喪失訴訟能力，訴訟程序當然停止。直至「法定代理人」或取得訴訟能力之本人「承受訴訟」
例2.
  • 甲（未成年人）之法定代理人父死亡，訴訟程序停止，須由母（新法定代理人）承受訴訟。
  • → 當事人之「法定代理人死亡」，訴訟程序當然停止。直至「新法定代理人」「承受訴訟」
例3.
  • 乙公司之法定代理人董事長A解任，訴訟程序停止，須由新任董事長B承受訴訟。
  • → 當事人之法定代理人「代理權消滅」者，訴訟程序當然停止。直至「新法定代理人」「承受訴訟」
受託人信託任務終了之當然停止
  • 受託人因辭職、解任或死亡而任務終了，訴訟會自動停止，直到新受託人或相關人承接訴訟。
受託人之「信託任務終了」者，訴訟程序當然停止。直至「新受託人」或其他依法令應續行訴訟之人「承受訴訟」
  • 受託人：依信託契約或遺囑指定之信託財產管理人。
  • 信託任務終了：如受託人辭任（信託法第36條）、解任（信託法第36條、第38條）、死亡、破產、受監護宣告等。
  • 新受託人：依信託法第45條選任或指定之新受託人。
  • 其他依法令應續行訴訟之人：如信託監察人（信託法第52條）、法院選任之臨時受託人。
例1.
  • 甲為信託受託人，因訴訟中辭任。訴訟程序當然停止，須由新受託人乙承受訴訟。
  • → 受託人之「信託任務終了」者，訴訟程序當然停止。直至「新受託人」「承受訴訟」
例2.
  • 甲為信託受託人，因訴訟中辭任。訴訟程序當然停止。
  • 無新受託人，由法院選任信託監察人丙承受訴訟。
基於一定資格為他人為訴訟當事人資格喪失或死亡之當然停止
  • 基於特定資格代理他人訴訟的人喪失資格或死亡，或選定代表全體喪失資格，訴訟會自動停止，直到新資格人或相關人承接。
本於一定資格「以自己名義為他人」任訴訟「當事人」之人
  • 一定資格：如遺產管理人（民法第1177條）、破產管理人（破產法）、共有人選定之管理人。
  • 以自己名義為他人：名義上為當事人，但實質上為他人（如遺產）進行訴訟。
「喪失其資格」或死亡者，訴訟程序當然停止。直至「有同一資格之人」「承受訴訟」
  • 喪失資格：如解任、任期屆滿、破產管理人職務終了。
  • 有同一資格之人：如新任遺產管理人、新任破產管理人。
依法被「選定」為訴訟「當事人」之人「全體」喪失其資格者，訴訟程序當然停止。直至「新被選定當事人」或「共同利益人全體」「承受訴訟」
  • 被「選定」為訴訟「當事人」之人：依第41條選定之當事人（如多數共有人選定一人為原告）。
  • 全體喪失資格：所有被選定人均喪失資格（如解任、死亡）。
  • 新被選定當事人：重新選定之代表人。
  • 共同利益人全體：原選定人（即全體利害關係人）可承受訴訟。
例1.
  • 甲為乙之遺產管理人，訴訟中甲死亡。訴訟程序當然停止，須由新任遺產管理人承受訴訟。
  • → 遺產管理人：本於一定資格「以自己名義為他人」任訴訟「當事人」之人
例2.
  • 甲、乙、丙選定丁為訴訟當事人，丁死亡。訴訟停止，須由甲、乙、丙全體或新選定之人承受。
  • → 被「選定」為訴訟「當事人」之人「全體」喪失其資格者，訴訟程序當然停止。
有訴訟代理人時停止規定之例外
  • 有訴訟代理人時，當事人死亡或喪失能力等事由不會讓訴訟自動停止；但法院認為必要時仍可裁定停止。
有訴訟代理人時，原則上不停止
  • 當事人死亡、喪失訴訟能力、法人合併、法法定代理人變更等停止事由，如有訴訟代理人時，原則上不停止。
但法院得酌量情形，「裁定停止」訴訟程序
  • 酌量情形：如代理人無法獨立判斷、對造權益受影響、需等待繼承人或新法定代理人參與等。
  • 裁定停止：法院得依職權或依聲請，以「裁定」停止訴訟程序。
例1.
  • 甲委任律師乙為訴訟代理人，訴訟中甲死亡。因有訴訟代理人，訴訟程序不當然停止，乙仍可繼續進行訴訟。
  • → 有訴訟代理人時，原則上不停止
例2.
  • 甲委任律師乙，訴訟中甲死亡，法院認繼承人丙之權益可能受影響，裁定停止訴訟，待丙承受訴訟。
  • → 法院得酌量情形，「裁定停止」訴訟程序
當事人受破產或清算宣告之當然停止
  • 當事人受破產或清算宣告，與其財產有關的訴訟會自動停止，直到管理人承接或破產/清算結束。
當事人受「破產」之宣告者，關於「破產財團」之訴訟程序「當然停止」。直至「有承受訴訟人」或「破產程序終結」
  • 破產宣告：法院依破產法宣告當事人（自然人、法人）破產。
  • 破產財團：破產人所有之財產，由破產管理人管理（破產法第82條）。
  • 關於破產財團之訴訟：如破產人為被告，請求給付金錢之訴訟。
  • 承受訴訟人：如破產管理人（破產法第64條）或破產債權人會議。
  • 破產程序終結：如破產分配完畢。
當事人依「消債條例」經法院裁定「開始清算程序」者，關於「清算財團」之訴訟程序「當然停止」。直至「管理人承受訴訟」或「清算程序終止/終結」
  • 依消費者債務清理條例開始清算程序（與破產類似，但適用於消費者）。
  • 清算財團：清算人之財產。
  • 管理人：清算管理人。
  • 清算程序終止/終結：清算程序結束。
例1.
  • 甲訴訟中受破產宣告，其為被告之訴訟（請求給付貨款）當然停止，須由破產管理人承受訴訟。
  • → 當事人受「破產」之宣告者，關於「破產財團」之訴訟程序「當然停止」。直至「有承受訴訟人」或「破產程序終結」
例2.
  • 甲依消費者債務清理條例開始清算程序，其為原告之訴訟（請求返還借款）當然停止，須由清算管理人承受。
  • → 當事人依「消債條例」經法院裁定「開始清算程序」者，關於「清算財團」之訴訟程序「當然停止」。直至「管理人承受訴訟」或「清算程序終止/終結」
承受訴訟之聲明
  • 承受訴訟人應於可以承接時立即向法院聲明；若未聲明，對造也可以聲明承接。
承受訴訟人，於「得為承受」時，「應即聲明」承受
  • 承受訴訟人：繼承人、遺產管理人、新法定代理人、合併後存續或新設法人。
  • 得為承受時：承受人具備資格（如已取得繼承人地位、已就任管理人）時。
  • 「應即聲明」承受：應儘速向法院提出「承受訴訟狀」，表明承接訴訟。
「他造」當事人，「亦得聲明」承受訴訟
  • 若承受訴訟人未主動聲明，他造得主動向法院聲明承受訴訟（以促其承接）。
例1.
  • 甲死亡，其子乙為繼承人。乙應於知悉甲死亡後，立即向法院提出「承受訴訟狀」，聲明承受訴訟。
  • → 承受訴訟人，於「得為承受」時，「應即聲明」承受
例2.
  • 甲死亡，其繼承人乙未聲明承受。原告（他造）得向法院聲明承受訴訟，促乙承接。
  • → 「他造」當事人，「亦得聲明」承受訴訟
聲明承受訴訟與依職權命續行訴訟
  • 聲明承受訴訟，應提出書狀於受訴法院，由法院送達於他造。
  • 如果該承接訴訟的人沒有主動聲明，法院可以主動用裁定命令他承接，讓訴訟繼續。
「聲明承受」訴訟，應「提出書狀」於受訴法院，由法院「送達於他造」
當事人「不聲明承受」訴訟時，法院亦得「依職權」，以「裁定」命其續行訴訟。裁定「得抗告」
  • 當事人「不聲明承受」：指有當然停止事由（如當事人死亡），但承受訴訟人（如繼承人）未主動聲明承受。
  • 得依職權：法院得主動為之，無待當事人聲請。
  • 以「裁定」命其續行訴訟：裁定命承受人「承受訴訟」並「繼續進行訴訟程序」。該裁定具有強制力，承受人應遵從。
  • 裁定「得抗告」：對於法院「命續行訴訟」的裁定，當事人不服的話，可以提出「抗告」。
例1.
  • 甲死亡，其繼承人乙欲承受訴訟。乙應向法院提出「承受訴訟狀」，載明「乙為甲之繼承人，聲明承受訴訟」，並檢附繼承系統表、戶籍謄本。
  • 法院收受後，將繕本送達予原告（他造）。
  • → 「聲明承受」訴訟，應「提出書狀」於受訴法院，由法院「送達於他造」
例2.
  • 甲死亡，其繼承人乙未聲明承受訴訟。
  • 法院查知乙為繼承人，依職權裁定「命乙續行訴訟」，即強制乙承受訴訟。
  • → 當事人「不聲明承受」訴訟時，法院亦得「依職權」，以「裁定」命其續行訴訟
例3.
  • 甲聲明承受訴訟，法院裁定駁回（認甲非繼承人）。甲不服，於送達後10日內提起抗告。
  • → 駁回聲明承受訴訟裁定，得為抗告
承受訴訟聲明之審查與駁回
  • 法院要主動審查承受訴訟聲明是否合法；不合法就裁定駁回。
  • 裁判送達後才停止者，由原法院裁定承受。
承受訴訟之聲明「有無理由」，法院應「依職權調查」之
  • 有無理由：聲明人是否為合法之承受訴訟人（如是否為真正繼承人、是否為合併後存續法人）。
  • 應依職權調查：法院應「主動」調查，無待當事人主張。得調閱戶籍謄本、公司登記資料、遺產清冊等。
法院認其聲明為「無理由」者，應「以裁定駁回」之。裁定「得抗告」
  • 無理由：如聲明人非合法繼承人、非新法定代理人、非合併後存續法人等。
  • 以裁定駁回：法院應以「裁定」形式駁回聲明（不得以判決）。
  • 裁定「得抗告」：對於法院「駁回承受訴訟聲明」的裁定，當事人不服的話，可以提出「抗告」。
訴訟程序於「裁判送達後」當然停止者，其承受訴訟之聲明，由「為裁判之原法院」裁定之
  • 裁判送達後當然停止：如判決書送達予當事人後，該當事人死亡。
  • 為裁判之原法院：作出該裁判之法院（如第一審法院作出判決，當事人於送達後死亡，則由第一審法院裁定承受）。
  • 理由：原法院最清楚該案之裁判內容及停止事由。
例1.
  • 甲死亡，乙聲明承受訴訟。法院應主動調查乙是否為甲之合法繼承人（如調閱戶籍謄本）。
  • → 承受訴訟之聲明「有無理由」，法院應「依職權調查」之
例2.
  • 法院調查後認乙非甲之繼承人（如甲另有配偶），裁定駁回乙之承受聲明。
  • → 承受訴訟之聲明「無理由」者，應「以裁定駁回」之
例3.
  • 第一審法院判決後，將判決書送達甲，甲於送達後死亡。乙聲明承受訴訟，應由「第一審法院」裁定，而非第二審法院。
  • → 訴訟程序於「裁判送達後」當然停止者，其承受訴訟之聲明，由「為裁判之原法院」裁定之
例4.
  • 法院依職權裁定命乙續行訴訟。乙不服（認其非合法承受人），提起抗告。
  • → 對「命續行訴訟」裁定，得為抗告
訴訟裁判以他訴訟或行政爭訟為據之停止
  • 訴訟裁判須以他訴訟或行政爭訟為前提時，法院可裁定停止訴訟，避免裁判矛盾。
訴訟全部或一部之裁判，以「他訴訟」之法律關係是否成立為據者，法院得在「他訴訟終結前」以「裁定停止」訴訟程序
  • 訴訟全部或一部之裁判：本案之判決（全部或部分）須取決於另一法律關係。
  • 以他訴訟之法律關係是否成立為據：本案之先決問題（如所有權歸屬、契約是否有效）繫屬於「他訴訟」中。
  • 得：法院裁量權（可停止，亦可續行）。
  • 他訴訟終結前：至他訴訟判決確定（或和解、撤回）為止。
  • 以裁定停止：應以「裁定」為之。
前項規定，於應依「行政爭訟」程序確定法律關係是否成立者「準用」之。但法律別有規定者，依其規定
  • 行政爭訟程序：如訴願、行政訴訟（行政法院）。
  • 準用之：若本案裁判須先經行政爭訟確定先決問題，法院得裁定停止。
  • 若其他法律有特別規定（如某事件須先經行政程序），則優先適用該特別規定。
例1.
  • 甲訴乙返還土地，但乙主張其為所有權人（乙已另訴確認所有權）。法院認本案裁判以所有權歸屬為據，裁定停止本案，待所有權訴訟確定。
  • → 以他訴訟為據，法院得在「他訴訟終結前」以「裁定停止」訴訟程序
例2.
  • 甲訴請確認土地為其所有，但該土地是否為國有地須先經行政訴訟確定。法院得裁定停止，待行政訴訟確定。
  • → 以行政爭訟為據，法院得在「他訴訟終結前」以「裁定停止」訴訟程序
例3.
  • 雖有他訴訟，但法院認該先決問題可由本案自行判斷，認無停止必要，駁回停止聲請。
  • → 法院認無停止必要，得續行訴訟
普通法院就行政法院移送訴訟認無審判權之處理
  • 普通法院若認為行政法院移來的案子自己沒審判權，應停止訴訟並請求最高法院指定。
    • 例外是最高行政法院已確定或當事人合意由普通法院審。
普通法院就「行政法院移送」之訴訟「認無審判權」者，應以「裁定停止」訴訟程序，並「請求最高法院指定」有審判權之管轄法院
  • 「行政法院移送」之訴訟：行政法院依職權或聲請，將訴訟移送至普通法院（行政訴訟法第12條之2）。
  • 「認無審判權」者：普通法院審查後，認該訴訟「不屬於普通法院審判權」（如應屬行政法院）。
  • 應以「裁定停止」訴訟：暫停審理。
  • 請求最高法院指定：由「最高法院」統一決定審判權歸屬（非普通法院自行決定）。
但有下列情形之一者，不在此限
  1. 移送經「最高行政法院」裁判確定
    • 審判權爭議已由最高行政法院終局確定（如最高行政法院認應由普通法院審理）。
  2. 「當事人合意」願由普通法院裁判
    • 雙方均同意由普通法院審理（尊重當事人程序選擇權）。
    • 合意須「明確」記載於「筆錄」或「書面文件」（如協議書），以杜爭議。
最高法院就第一項請求為裁定前，應使當事人有陳述意見之機會
  • 最高法院須通知雙方當事人表示意見（不得逕行裁定）。
普通法院就「行政法院移送」之訴訟為裁判者，上級審法院「不得以其無審判權而廢棄」之
  • 若普通法院已為「本案裁判」（如判決），則上級審（如高等法院、最高法院）不得以「普通法院無審判權」為由廢棄該裁判（以維護程序安定及當事人信賴）。
例1.
  • 行政法院將一宗土地徵收補償費訴訟移送普通法院。
  • 普通法院認無審判權（應屬行政法院），裁定停止訴訟，並請求最高法院指定有審判權之法院。
  • → 普通法院就「行政法院移送」之訴訟「認無審判權」者，應以「裁定停止」訴訟程序，並「請求最高法院指定」有審判權之管轄法院
例2.
  • 雙方當事人合意願由普通法院裁判，並記明筆錄。普通法院應續行審理，不得停止。
  • → 「當事人合意」願由普通法院裁判，不在此限
外國法院訴訟繫屬中更行起訴之停止
  • 外國法院已繫屬同一事件，若外國判決將來可能被承認且被告應訴無不便，法院可裁定停止台灣訴訟；但當事人合意由台灣法院裁判者除外。
要件：當事人就「已繫屬於外國法院」之事件「更行起訴」
  • 已繫屬於外國法院：同一事件已在外國法院起訴，且訴訟仍在進行中（尚未判決確定）。
  • 更行起訴：當事人就同一事件向我國法院提起訴訟（重複起訴）。
停止要件1：外國法院之判決有被「我國承認」之可能
  • 須有具體事實（如該國與我國有司法互助、該國判決具備承認要件）。
  • 有承認其效力之可能：該外國判決可能符合民事訴訟法第402條之承認要件（如依條約、無違反公序良俗等）。
停止要件2：被告在「外國應訴無重大不便」
  • 無重大不便：被告在外國應訴無重大困難（如語言、距離、費用）。
效果：法院得在「外國法院判決確定」前，以「裁定停止」訴訟程序
  • 得：法院裁量權。
  • 外國法院判決確定前：停止至外國判決確定為止。
但書：但「兩造合意」願由我國法院裁判者，不在此限
  • 雙方均同意由台灣法院審理。
  • 若合意，法院應續行訴訟。
例1.
  • 甲、乙在美國法院就同一契約爭議訴訟中，甲又在台灣起訴。
  • 法院認美國判決可能被台灣承認（如互惠），且乙在美國應訴無不便，裁定停止台灣訴訟，待美國判決確定。
  • → 外國法院之判決有被「我國承認」之可能，被告在「外國應訴無重大不便」，得以「裁定停止」訴訟程序
例2.
  • 甲、乙合意願由台灣法院裁判，法院不得停止，應續行審理。
  • → 以行政爭訟為據，法院得在「他訴訟終結前」以「裁定停止」訴訟程序
例3.
  • 雖有他訴訟，但法院認該先決問題可由本案自行判斷，認無停止必要，駁回停止聲請。
  • → 「兩造合意」願由我國法院裁判，應續行審理
訴訟中有犯罪嫌疑牽涉裁判之停止
  • 民事訴訟中若有犯罪嫌疑影響裁判，法院可在刑事判決確定前裁定停止民事訴訟。
訴訟中有犯罪嫌疑牽涉其裁判者，法院得在「刑事訴訟終結前」，以「裁定停止」訴訟程序
例1.
  • 甲訴乙侵權行為損害賠償（乙涉嫌偽造文書），偽造文書罪之有無影響契約是否有效。
  • 法院得裁定停止民事訴訟，待刑事判決確定。
  • → 犯罪嫌疑牽涉裁判，得在「刑事訴訟終結前」，以「裁定停止」訴訟程序
例2.
  • 甲訴乙返還借款，乙抗辯該借款係賭債（可能涉犯賭博罪），但法院認賭博罪之有無不影響借款返還之判斷，得認無停止必要，續行訴訟。
  • → 法院認無須停止
主參加訴訟提起後本訴訟之停止
  • 第三人提起主參加訴訟時，法院得裁定停止本訴訟，避免裁判矛盾。
第三人提起「主參加訴訟」者，法院得在「該訴訟終結」前，以「裁定停止」本訴訟之程序
  • 第三人提起「主參加訴訟」：第三人同時對原告和被告主張權利。
  • 法院可以在主參加訴訟結束前，裁定「停止」原本的訴訟。
例1.
  • 甲訴乙返還土地，丙主張土地為其所有，而對甲、乙提起主參加訴訟。
  • 法院認本訴訟與主參加訴訟之判決可能矛盾，裁定停止本訴訟，待主參加訴訟確定。
  • → 第三人提起「主參加訴訟」，法院得在「該訴訟終結」前，以「裁定停止」本訴訟之程序
例2.
  • 甲訴乙返還土地，丙提起主參加訴訟，但法院認本訴訟之事實明確，無須等待主參加訴訟，得續行本訴訟。
告知訴訟後於受告知人參加前之停止
  • 告知訴訟後，若法院認受告知人能參加，可在其參加前裁定停止訴訟，讓其考慮是否參加。
當事人依規定「告知訴訟」，法院如認受告知人「能參加」者，得在其參加前以「裁定停止」訴訟程序
  • 依規定「告知訴訟」：通知有利害關係的第三人參加訴訟。
  • 認受告知人「能參加」者：法院認為這個人是可以參加訴訟的，法院可以在他實際參加之前，裁定「停止」訴訟。
例1.
  • 甲訴乙，甲告知丙（有利害關係）。法院認丙有參加資格，裁定停止訴訟，待丙決定是否參加。
  • → 「告知訴訟」，法院如認受告知人「能參加」者，得在其參加前以「裁定停止」訴訟程序
例2.
  • 甲告知丙，但法院認丙無法律上利害關係（不能參加），則不停止，續行訴訟。
停止訴訟程序裁定之撤銷
  • 停止訴訟的裁定，法院可以依聲請或依職權撤銷，讓訴訟恢復進行。
停止訴訟程序之裁定，法院得「依聲請或依職權」撤銷之
  • 法院之前「裁定停止」訴訟後，如果停止的原因已經消失（例如刑事判決已經確定了）， 法院可以「依當事人聲請」或「自己主動」，把停止的裁定「撤銷」，讓訴訟繼續進行。
例1.
  • 法院因他訴訟停止本案，他訴訟判決確定後，當事人聲請撤銷停止裁定，法院准許，訴訟續行。
  • → 停止訴訟程序之裁定，法院得「依聲請」撤銷之
例2.
  • 法院因天災停止訴訟，天災結束後，法院依職權撤銷停止裁定，續行訴訟。
  • → 停止訴訟程序之裁定，法院得「依職權」撤銷之
停止及撤銷停止裁定之抗告
  • 法院停止或撤銷停止的裁定，當事人不服都可以在10天內提起抗告。
關於停止訴訟程序之裁定，及關於撤銷停止之裁定，得為抗告
  • 法院「裁定停止訴訟」或「裁定撤銷停止」的決定，當事人不服都可以提出「抗告」。
例1.
  • 法院裁定停止訴訟（認有犯罪嫌疑），原告不服，於送達後10日內提起抗告。
  • → 停止訴訟程序之裁定，得為抗告
例2.
  • 法院撤銷停止裁定（續行訴訟），被告不服（認停止原因尚未消滅），提起抗告。
  • → 撤銷停止之裁定，得為抗告
訴訟停止期間之效力
  • 訴訟停止期間，不能進行訴訟行為；法定期間也暫停計算，停止結束後重新起算。
訴訟程序當然或裁定「停止期間」，法院及當事人「不得為」關於本案之「訴訟行為」
  • 例如不能開庭、不能遞狀、不能判決。
但於「言詞辯論終結後當然停止」者，本於其辯論之「裁判得宣示」之
  • 言詞辯論終結後當然停止：如法官已宣示「言詞辯論終結」，嗣後當事人死亡。
  • 本於其辯論之裁判得宣示之：法院仍得「宣示判決」（因裁判已可基於辯論內容作成）。
訴訟程序當然或裁定停止者，「期間停止進行」
  • 停止期間不計入期間之計算。包括「不變期間」（如上訴期間、抗告期間）及「法院所定期間」（如命補正期間）。
自停止事由消滅起，其期間更始進行
  • 停止事由消滅：如繼承人承受訴訟、天災結束。
  • 更始進行：期間「重新起算」（例如上訴期間剩餘10日，停止後重新起算10日）。
例1.
  • 言詞辯論終結後，當事人死亡，法院仍得宣示判決。
  • → 於「言詞辯論終結後當然停止」者，本於其辯論之「裁判得宣示」之
例2.
  • 上訴期間進行中，因天災停止訴訟。停止期間不計入上訴期間。
  • 停止終竣後，上訴期間「重新起算」（如原剩餘5日，重新起算為20日？應依上訴期間規定，但更始進行係重新起算全部期間）。
  • → 自停止事由消滅起，其期間更始進行

合意停止訴訟程序

合意停止訴訟程序
  • 雙方當事人可合意停止訴訟，但法定不變期間繼續計算；合意向法院陳明後生效。
當事人得以合意停止訴訟程序。但不變期間之進行，不受影響
  • 合意停止：雙方當事人「一致同意」暫停訴訟。
  • 不變期間：法定不變期間（如上訴期間、抗告期間、再審期間）。
  • 不受影響：不變期間「繼續進行」，不因合意停止而停止。
前項合意，應由兩造向受訴法院或受命法官「陳明」
  • 陳明：以「書面」或於「期日」以「言詞」向法院表明合意停止。
合意停止期間，不得為本案訴訟行為。停止終竣後，法院所定期間「更始進行」
  • 「法院所定期間」，不包括「不變期間」。
合意停止之期間限制與逾期效果
  • 合意停止後4個月內未續行，視為撤回。
  • 續行後可再合意停止一次；第三次不生效力，法院可續行，兩造無故不到則視為撤回。
「合意停止」訴訟程序之當事人，自陳明合意停止時起，如於「四個月內不續行」訴訟者，「視為撤回」其訴或上訴
  • 四個月內：自「陳明合意停止」之日起算「4個月」。
  • 不續行訴訟：當事人未於期限內「聲請續行」訴訟。
  • 視為撤回其訴或上訴：逾期未續行，訴訟「擬制撤回」（原告撤回起訴，上訴人撤回上訴）。
續行訴訟而「再合意停止」訴訟程序者，以「一次為限」
  • 再以合意停止：續行後，雙方再次合意停止。
  • 以一次為限：合意停止「總共只能兩次」（第一次+第二次）。
如「再次陳明合意停止」訴訟程序，其合意停止「不生效力」，法院得「依職權續行訴訟」
  • 再次陳明：第三次陳明合意停止。
  • 不生效力：該合意停止無效，法院不受拘束。
  • 得依職權續行：法院得主動排定開庭。
如「兩造時」無正當理由「遲誤言詞辯論」期日者，「視為撤回」其訴或上訴
  • 若法院排定開庭，兩造「無正當理由」均未到庭，則「視為撤回其訴或上訴」。
例1.
  • 甲、乙合意停止，4個月內未續行，視為撤回起訴或上訴。
  • → 合意停止，4個月內未續行，視為撤回起訴或上訴
例2.
  • 甲、乙續行後，再以合意停止（第二次），合法。
例3.
  • 甲、乙第三次陳明合意停止，不生效力，法院得續行。
兩造遲誤言詞辯論期日之擬制合意停止與撤回
  • 兩造無故不到庭，視為合意停止；4個月內未續行，視為撤回；法院可主動續行，若再不到則逕行視為撤回。
當事人「兩造」無正當理由「遲誤言詞辯論」期日者
  • 兩造：原告及被告（或上訴人及被上訴人）均未到庭。
  • 無正當理由：如無生病、天災等不可抗力事由。
  • 遲誤言詞辯論期日：未於指定期日到場。
除別有規定外，「視為合意停止」訴訟程序
  • 視為合意停止：法律「擬制」雙方合意停止（無須實際合意）。
如於「四個月內不續行」訴訟者，「視為撤回」其訴或上訴
  • 停止後4個月內未聲請續行，訴訟「視為撤回」。
法院依職權續行：前項訴訟程序停止間，法院於「認為必要」時，得「依職權續行」訴訟
  • 法院得「主動」排定開庭，續行訴訟。
如無正當理由兩造「仍遲誤不到」者，「視為撤回」其訴或上訴
  • 若續行後兩造再次無故不到，直接「視為撤回」（無須再等4個月）。
例1.
  • 甲、乙均無正當理由未到庭，法院視為合意停止。4個月內未續行，視為撤回起訴。
例2.
  • 法院認有必要，主動排定新期日續行。
例3.
  • 法院續行後，甲、乙又無故不到，視為撤回。
