民事訴訟法 抗告程序

抗告程序

抗告之一般容許性
  • 對於法院的裁定，原則上都可以抗告；但法律特別規定不能抗告的除外。
對於裁定，得為抗告
  • 裁定：法院就「程序事項」所為之決定（如駁回起訴、命供擔保、停止訴訟、確定訴訟費用額等）。
  • 得為抗告：當事人對裁定不服者，得向上級法院聲明不服（即「抗告」）。
但別有不許抗告之規定者，不在此限
  • 別有不許抗告之規定：其他條文明文規定「不得抗告」者。例如：
    • 支付命令之駁回裁定，不得抗告。
    • 緊急處置之裁定，不得抗告。
訴訟程序進行中所為裁定不得抗告之原則
  • 訴訟進行中的程序裁定，原則上不能抗告；除非法律特別規定可以。
訴訟程序進行中所為之裁定
  • 指法院為「指揮訴訟」或「處理程序事項」所為之裁定，如：
    • 指定言詞辯論期日、命當事人補正書狀、駁回證據調查聲請。
除別有規定外，不得抗告
  • 例如：駁回訴訟救助聲請、駁回參加訴訟聲請、關於訴訟費用之裁定。
不得上訴第三審事件之第二審裁定不得抗告之原則與例外
  • 不得上訴三審的案件，二審裁定原則上不能抗告；但罰鍰、強制提出文書等四種裁定可向原法院異議，異議裁定不得再爭執。
「不得上訴於第三審」法院之事件，其第二審法院所為裁定，「不得抗告」
  • 不得上訴第三審：如訴訟標的金額低於上訴三審門檻（現行為新臺幣150萬元以下）。
  • 第二審法院所為裁定：第二審（高等法院）於審理中所為之裁定。
  • 不得抗告：不得向最高法院提起抗告。
但下列裁定，得向原法院提出異議：
  • 異議：向「原法院」（即為裁定之第二審法院）聲明不服，而非向上級法院抗告。
  1. 命特定人員負擔費用
  2. 罰鍰裁定
  3. 駁回拒絕證言、拒絕鑑定、拒絕通譯之裁定
  4. 強制提出文書、勘驗物之裁定
前項異議，準用對於法院同種裁定抗告之規定。受訴法院就異議所為之裁定，不得聲明不服
  • 異議之「程式」、「期間」、「效力」等，準用抗告之規定（如第487條抗告期間10日）。
  • 法院對異議所為之裁定，雙方「不得」再抗告或異議（救濟程序終結）。
例1.
  • 甲對乙請求100萬元（未達150萬元），第二審法院裁定駁回甲之證據調查聲請。此裁定不得抗告。
  • → 不得上訴第三審，第二審法院裁定，不得抗告
例2.
  • 第二審法院對證人丙處以罰鍰（得異議事由），丙得向原法院提出異議。
  • 法院就異議為裁定後，當事人不得再抗告。
  • → 罰鍰裁定得異議，異議裁定不得再爭執
受命法官或受託法官裁定之救濟
  • 受命法官或受託法官的裁定不能直接抗告，應向合議庭異議；合議庭的異議裁定則可抗告。
受命法官或受託法官之裁定，不得抗告
  • 受命法官：合議庭指定負責準備程序之法官。
  • 受託法官：受他法院囑託調查證據之法官。
  • 不得抗告：不得向上級法院提起抗告。
但其裁定如係受訴法院所為而依法得為抗告者，得向受訴法院提出異議
  • 受訴法院：原合議庭。
  • 得向受訴法院提出異議：向合議庭聲明不服。
受訴法院就異議所為之裁定，得依規定抗告
  • 合議庭對異議之裁定（如駁回異議），當事人得「抗告」至上級法院。
訴訟繫屬於第三審法院者，其受命法官或受託法官所為之裁定，得向第三審法院提出異議
  • 案件在最高法院時，異議向最高法院提出。
不得上訴於第三審法院之事件，第二審法院受命法官或受託法官所為之裁定，得向受訴法院提出異議
  • 不得上訴三審之案件，異議向第二審受訴法院（合議庭）提出。
例1.
  • 受命法官於準備程序裁定駁回證據調查聲請。當事人不得抗告，但得向合議庭提出異議。
  • → 受命法官裁定，向合議庭提出異議
例2.
  • 合議庭駁回異議，當事人得抗告至上級法院。
  • → 異議裁定得抗告
例3.
  • 案件在最高法院，受命法官裁定，當事人向最高法院提出異議。
  • → 第三審法院受命法官之裁定，得向第三審法院提出異議
抗告之審級與再抗告之限制
  • 抗告由直接上級法院裁定；不合法駁回僅得異議；再抗告僅限於適用法規顯有錯誤。
抗告，除別有規定外，由直接上級法院裁定
  • 抗告法院為「原裁定法院之直接上級法院」（如高等法院對地方法院裁定）。
抗告法院之裁定，以「抗告不合法而駁回」者，「不得再為抗告」。但得向所屬法院提出異議
  • 不合法：如逾期（逾10日）、未繳納裁判費、程式不備。
  • 不得再為抗告：不得再向上級法院抗告。
  • 得向「原抗告法院」（即為該裁定之法院）提出「異議」。
除前二項之情形外，對於抗告法院之裁定「再抗告」，僅得以「適用法規顯有錯誤」為理由
  • 再抗告：對抗告法院之「實體裁定」不服，再向上級法院抗告。
  • 僅得以適用法規顯有錯誤為理由：不得以「事實認定錯誤」為由再抗告。
因抗告未繳納裁判費而駁回者，亦不得再抗告，僅得異議
  • 若抗告因未繳費被駁回，亦不得再抗告，僅得異議。
例1.
  • 抗告逾期，高院裁定駁回，不得再抗告，僅得異議。
  • → 抗告不合法而駁回，不得再抗告，僅得異議
例2.
  • 對高院實體裁定再抗告至最高法院，僅得以適用法規顯有錯誤為理由。
  • → 對於抗告法院之裁定「再抗告」，僅得以「適用法規顯有錯誤」為理由
抗告期間
  • 抗告須在裁定送達後10天內提起；送達前提起也有效。
提起抗告，應於裁定送達後「十日不變期間內」為之
  • 裁定送達後：自「裁定正本合法送達」之翌日起算。
  • 十日不變期間：法定不變期間，不得延長。逾期未抗告，即失權。
送達前之抗告，亦有效力
  • 若當事人於「裁定送達前」即向法院提出抗告（如已知悉裁定內容），該抗告仍屬「有效」。
抗告之程式與方式
  • 抗告原則上用書面向原法院提出；簡易、小額等特定事件可用口頭（言詞）提出；都要寫明或講明抗告理由。
提起抗告，除別有規定外，應向為裁定之原法院或原審判長所屬法院提出抗告狀為之
  • 提起抗告，原則上要用「抗告狀」（書面）向原法院提出。
提起抗告，應表明抗告理由
  • 抗告理由：具體指摘原裁定有何不當（如事實認定錯誤、法律適用錯誤）。
簡易程序、小額訴訟程序，抗告得以言詞為之
  • 為簡化程序，得以言詞為之。
關於訴訟救助裁定，抗告得以言詞為之
  • 訴訟救助之抗告，得以言詞為之。
證人、鑑定人、通譯或執有證物之第三人提起抗告，得以言詞為之
  • 第三人抗告，得以言詞為之。
例1.
  • 甲對地院裁定不服，以「抗告狀」向地院提出。
  • → 向為裁定原法院提出抗告狀
例2.
  • 證人甲對罰鍰裁定不服，於開庭時以言詞提起抗告（記明筆錄）
  • → 證人提起抗告，得以言詞為之
原法院對抗告之處理方式
  • 原法院若認抗告有理由，可自行撤銷或變更裁定；否則應速將抗告送交上級法院，必要時送卷宗及意見書。
原法院認抗告不合法者，應駁回抗告
  • 不合法「逾期」、「程式不備」等理由駁回抗告。
原法院或審判長認抗告為有理由者，應撤銷或變更原裁定
  • 認抗告為有理由：原法院審查後，認為原裁定「有錯誤」。
  • 應撤銷或變更原裁定：自己撤銷或變更原裁定（自我糾正）。
否則應速將抗告送交抗告法院
  • 送交抗告法院：將抗告狀及相關資料送交「直接上級法院」。
如認為必要時，應送交訴訟卷宗，並得添具意見書
  • 應送交訴訟卷宗：必要時應將全卷送交。
  • 得添具意見書：原法院得附上「意見書」（說明原裁定之理由及對抗告之看法）。
抗告之效力與停止執行
  • 抗告原則上不停止原裁定執行；但法院得裁定停止；該停止裁定不得抗告。
抗告，除別有規定外，無停止執行之效力
  • 無停止執行之效力：提起抗告，不影響原裁定之執行（原裁定仍可執行）。
  • 除別有規定外：如法律明定抗告有停止執行效力者（如第104條第2項「返還擔保之抗告，應停止執行」）。
原法院或審判長或抗告法院得在抗告事件「裁定前」，「停止原裁定之執行」或為其他必要處分
  • 裁定前：在抗告事件終結前。
  • 停止原裁定之執行：暫緩執行。
  • 其他必要處分：如命供擔保、暫時保全等。
前項裁定，不得抗告
  • 對於「停止執行」或「必要處分」之裁定，當事人不得抗告（以維護裁定之安定性）。
例1.
  • 甲對法院「命供擔保」之裁定提起抗告，但原裁定仍可執行（甲仍須供擔保）
  • → 抗告，除別有規定外，無停止執行之效力
例2.
  • 抗告法院認原裁定執行將造成難以回復之損害，裁定停止執行。
  • 對停止執行之裁定，不得抗告。
  • → 原法院或審判長或抗告法院得在抗告事件「裁定前」，「停止原裁定之執行」或為其他必要處分
抗告法院認抗告有理由之處理方式
  • 抗告法院認為抗告有理由時，應自為裁定廢棄或變更原裁定；除非有必要，不得發回原法院。
抗告法院認抗告為「有理由」者，「應廢棄或變更原裁定」
  • 認抗告為有理由：認定原裁定「不當」（如事實認定錯誤、法律適用錯誤）。
  • 應：強制規定，抗告法院應自為裁定。
  • 廢棄或變更：將原裁定撤銷（廢棄），並自為正確之裁定（變更）。
非有必要，不得命原法院或審判長更為裁定
  • 非有必要：如有「必要」（如事實不明、須調查證據），始得發回。
  • 不得命原法院或審判長更為裁定：不得發回原法院重行裁定（應自為裁定）。
抗告與異議之誤用轉換
  • 如果該抗告卻寫成異議，或該異議卻寫成抗告，法院會「視為」已經用了正確的程序，不會因為名稱寫錯而駁回。
應為抗告而誤為異議者，視為已提起抗告；應提出異議而誤為抗告者，視為已提出異議
  • 如果應該「抗告」卻錯誤地寫成「異議」，法律上會「當作」已經提了抗告。
  • 如果應該「異議」卻錯誤地寫成「抗告」，也會「當作」已經提了異議。法院會依照正確的程序處理。
抗告程序準用上訴程序之規定
  • 抗告程序原則上準用上訴程序；逕向最高法院抗告及再抗告，則準用上訴審（第三審）的規定。
