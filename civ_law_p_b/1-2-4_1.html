民事訴訟法 訴訟代理人

訴訟代理人

訴訟代理人資格限制
  • 訴訟代理人，原則上必須請「律師」。
    • 只有經過審判長特別許可，才能請非律師（如親屬、法律系畢業生）
    • 如果法官發現這個「非律師」不適任，可以隨時取消許可。
    • 至於非律師在什麼條件下可以獲得許可，則授權司法院另外訂定《許可準則》來規範 。
原則：訴訟代理人應委任律師為之
  • 訴訟代理人：指受當事人委任，以當事人名義在訴訟中為訴訟行為（如開庭、提出書狀）的人。
  • 應委任律師：這是法律上的「義務」與「原則」。當事人如果要委任代理人，原則上必須找具有律師資格的人。
例外：委任非律師，需審判長「許可」。如不適任，審判長得「裁定撤銷」許可
  • 經審判長許可：必須得到承辦案件的審判長（獨任審判時即為法官本人）的「許可」。許可的標準，由司法院另定之。
  • 審判長得「裁定撤銷」許可：審判長有權力在任何時間點撤銷許可，撤銷許可的裁定，必須送達給委任人（即當事人）。
例1.
  • 丙的父親丁車禍受傷，丙想幫父親打官司，但父親不想花錢請律師。
  • 丙本身是「大學法律系畢業生」（符合許可準則）。丙向法院提出委任狀，並說明自己具有法律專業。
  • 審判長審查後，認為丙可以勝任，許可丙為其父親的訴訟代理人。
  • → 委任非律師，需審判長「許可」
例2.
  • 承例1，丙雖然是法律系畢業，但在訴訟中對法官的詢問一問三不知，書狀內容雜亂無章，甚至有損父親權益之虞。
  • 審判長認為丙已不適任，裁定撤銷對丙的許可。法院將裁定送達給丙的父親丁。
  • → 如不適任，審判長得「裁定撤銷」許可
委任訴訟代理人，應提出委任書
  • 當事人委任訴訟代理人，原則上要在代理人第一次開庭或寫狀子時，提出書面的「委任書」。
    • 但如果是在法庭上口頭委任（記明筆錄）或由法院直接選任，則不用書面。
原則：訴訟代理人，應於「最初」為訴訟行為時，「提出委任書」
  • 最初為訴訟行為時：訴訟代理人第一次代表當事人向法院做某個動作（例如提出書狀、出庭陳述）的時候，就必須提出委任書。
  • 提出委任書：將委任書正本或繕本提交給法院，證明代理權的存在。
例外：1.言詞委任，並記明於筆錄 2.由法院依法選任者
  • 言詞委任，並記明於筆錄：當事人直接在法庭上，用口頭說「我委任某某人為我的訴訟代理人」。法院的書記官將這個口頭委任的內容，記載在開庭筆錄中。
  • 由法院依法選任者：例如為無訴訟能力人選任「特別代理人」。這種由法院選任的情況，不需要提出委任書（因為法院就是選任者，當然知道代理權存在）
委任單一審級有效原則
  • 原則上，訴訟代理人的委任只在單一審級範圍有效。每個審級（一審、二審、三審）都要重新委任一次。
    • 但如果當事人在委任書上寫明「所有審級都有效」，並經過公證，就可以一次委任用到底。
原則：單一審級有效
  • 原則上，訴訟代理人的委任只在單一審級範圍有效。
  • 也就是說，一審的代理人，到了二審並不能直接代理，要再寫一次委任書。
例外：當事人就特定訴訟於委任書「表明」其委任「不受審級限制」，並經「公證」者，不在此限
  • 就特定訴訟：針對一個案件。
  • 於委任書表明其委任不受審級限制：在委任書上明確寫出「本委任之效力及於一、二、三審，不受審級限制」。
  • 並經公證者：這份委任書必須經過「公證人」公證（證明是當事人本人的簽名或蓋章）。
  • 不在此限：這種情況下，一個委任書就可以用於所有審級，不需要每審級重新委任。
例1.
  • 甲在一審委任「陳律師」，一審判決後，甲不服上訴二審。
  • 陳律師要繼續在二審代理甲，必須在二審「重新」提出委任書（或再次言詞委任）
  • 如果陳律師沒有提出新的委任書，他在二審就沒有代理權。
  • → 原則：委任於單一審級有效。每個審級都要重新委任一次
例2.
  • 甲非常信賴「陳律師」，希望他從一審、二審到三審都幫他打官司。
  • 甲在委任書上寫明：「本委任之效力及於第一、二、三審，不受審級限制。」甲將這份委任書拿去公證人那裡公證。
  • 之後，陳律師在二審、三審都可以直接代理，不需要再重新提出委任書。
  • → 例外：當事人就特定訴訟於委任書「表明」其委任「不受審級限制」，並經「公證」者，不在此限
訴訟代理人之權限
  • 訴訟代理人原則上可以獨立做任何訴訟行為（開庭、寫狀子、聲請證據）。
    • 但是，對於「捨棄、認諾、撤回、和解、反訴、上訴、再審、選任代理人、強制執行、領取物品」這幾種會直接處分當事人權利的重大行為，必須在委任書上「特別寫明授權」，代理人才能做。
原則：訴訟代理人就其受委任之事件有為「一切訴訟行為」之權
  • 包括：提出書狀、出庭陳述、聲請調查證據、對證據表示意見、聲請法官迴避、聲請訴訟救助、聲請停止訴訟、聲請回復原狀、提起抗告、受送達、聲請假扣押、假處分等。
例外：「捨棄、認諾、撤回、和解、反訴、上訴、再審、選任代理人、強制執行、領取物品」，非受「特別委任」不得為之
  • 這幾種會直接處分當事人權利的重大行為，必須在委任書上「特別寫明授權」，代理人才能做。
例1.
  • 甲委任陳律師為訴訟代理人，委任書上只寫「委任陳律師為訴訟代理人」。
  • 陳律師可以：提出起訴狀、答辯狀、準備書狀、出庭陳述、聲請法院調查證據、對對方的證據表示意見、受送達。
  • → 原則：訴訟代理人就其受委任之事件有為「一切訴訟行為」之權
例2.
  • 承上例，開庭時，對方提出和解方案 。
  • 陳律師沒有得到甲的特別授權，就擅自同意和解。
  • 法院問：「你有和解的權限嗎？」陳律師說：「委任書上沒有寫，但我覺得和解對甲有利。」
  • 法院認為陳律師沒有特別委任，拒絕製作和解筆錄。
  • → 例外：和解須特別委任
法院選任律師之權限
  • 法院指派的律師，原則上也可以做一切訴訟行為。
    • 但「不能」幫當事人做捨棄、認諾、撤回或和解這四種重大決定。
    • 而且，如果當事人後來自己找了律師，法院指派的律師就要「退場」。
法院或審判長「依法為當事人選任」之訴訟代理人，得代理當事人為一切訴訟行為。但「不得」為捨棄、認諾、撤回或和解
  • 法院或審判長「依法為當事人選任」之訴訟代理人：例如無訴訟能力人沒有法定代理人，法院為他選任特別代理人。
  • 一切訴訟行為：包括提出書狀、出庭陳述、聲請調查證據、受送達、提起抗告等。
  • 「不得」為捨棄、認諾、撤回或和解：即使當事人同意，也不能做。這四種行為會直接處分當事人的實體權利（如認諾等於認輸），必須由當事人「親自」決定，或由當事人「自行委任」且有特別委任的律師為之
當事人「自行委任」訴訟代理人或表示「自為訴訟行為」者，前項訴訟代理人之「代理權消滅」
  • 當事人自行委任訴訟代理人：當事人自己另外花錢請了律師。
  • 當事人表示自為訴訟行為：當事人向法院表示「我不要法院派的律師了，我要自己打官司」。
  • 代理權消滅：自動失效，不需要法院再另外做一個裁定。從當事人自行委任律師或表示自為訴訟行為的那一刻起，法院選任的律師就沒有代理權了。
例1.
  • 甲因失智受監護宣告，沒有法定代理人，需要告乙返還借款。
  • 法院依法選任「陳律師」為甲的特別代理人。陳律師可以：幫甲寫起訴狀、出庭、聲請調查證據（一切訴訟行為）
  • 但是，陳律師「不能」幫甲做「捨棄、認諾、撤回或和解」（即使甲同意也不行）
  • → 法院「依法為當事人選任」之訴訟代理人，「不得」為捨棄、認諾、撤回或和解
例2.
  • 承上例，甲的兒子丙覺得陳律師不夠好，自己花錢請了「王律師」為甲的訴訟代理人。
  • 丙向法院提出委任書。此時，陳律師的代理權「自動消滅」。
  • 法院應通知陳律師及對造乙。
  • → 當事人自行委任訴訟代理人者，選任訴訟代理人之「代理權消滅」
共同訴訟代理人之單獨代理權
  • 如果當事人同時請了兩位以上的訴訟代理人：
    • 每個人都可以「單獨」代理（自己開庭、自己寫狀子），不需要等其他人同意。
    • 即使當事人在委任書上規定「他們必須一起行動」，這個規定對「對方當事人」也沒有拘束力
訴訟代理人有二人以上者，「均得單獨代理」當事人
  • 每一位都可以單獨出庭、單獨提出書狀、單獨聲請調查證據、單獨受送達，不需要等其他人同意。
違反前項之規定而為委任者，對於他造「不生效力」
  • 這個「共同代理」的約定，對對方當事人沒有拘束力。對方當事人仍然可以只對「其中一位」代理人為訴訟行為（例如只對陳律師送達、只對林律師認諾）。
    • 對內效力：這個共同代理的約定，在「當事人與代理人之間」仍然有效（例如當事人可以依內部關係向違約的代理人求償），但不能對抗善意第三人（他造）。
當事人本人對訴訟代理人事實上陳述之撤銷
  • 在法庭上，如果律師講錯了（或講了對當事人不利的話），當事人當場糾正，就以當事人說的為準。
訴訟代理人「事實上之陳述」，經「到場之當事人本人」即時「撤銷或更正」者，「不生效力」
  • 事實上之陳述：指對於「過去發生的具體事實」的描述。例如：「這份契約上的簽名是我的當事人親簽的。」
  • 到場之當事人本人：當事人本人必須「親自」在法庭現場（或準備程序、調解現場）。如果當事人本人沒有到場，就不能適用本條（因為他無法「即時」撤銷）
  • 即時撤銷或更正：例如代理人說「甲承認有收到錢」，甲馬上舉手說「我沒有承認！我沒有收到錢！」
  • 不生效力：代理人的該項事實上陳述，法律上視為「無效」，法院不能採為裁判的基礎。法院應以「當事人本人更正後的陳述」為準。
例1.
  • 甲告乙返還借款，甲的律師陳律師在法庭上說：「我的當事人甲承認，乙已經還了50萬元。」
  • 甲本人也在庭上，馬上舉手說：「不對！我沒有承認！乙根本沒還錢！」
  • 法官問甲：「你的意思是，你不同意律師講的？」甲說：「對，我沒收到任何還款。」
  • 陳律師的陳述「不生效力」，法院不能認定甲有承認乙還款的事實。
  • → 當事人即時撤銷，律師的事實上陳述「不生效力」
例2.
  • 承例1，陳律師說：「甲承認乙已經還了50萬元。」甲在庭上沒有說話（默不作聲） 。
  • 開完庭後，甲才跟法官說：「我不同意律師講的。」法官認為甲沒有「即時」撤銷，陳律師的陳述仍然有效。
訴訟代理權之獨立性
  • 訴訟代理人（律師）的代理權，不會因為當事人過世、破產、變成植物人（喪失訴訟能力），或當事人的法定代理人換人，就自動消滅。
    • 這樣官司才能繼續打，不會因為當事人的變故而中斷。
訴訟代理權，不因本人死亡、破產或訴訟能力喪失而消滅；法定代理有變更者亦同
  • 死亡：當事人死亡，訴訟程序當然停止，但訴訟代理人的代理權「不消滅」。在繼承人承受訴訟之前，訴訟代理人仍然可以繼續為訴訟行為（例如提出書狀、聲請證據），以保障繼承人的權益。
  • 破產：當事人受破產宣告。訴訟程序當然停止，但訴訟代理人的代理權「不消滅」。在破產管理人承受訴訟之前，訴訟代理人仍可繼續代理為訴訟行為。
  • 訴訟能力喪失：當事人成為無訴訟能力人（例如受監護宣告），訴訟程序當然停止（第170條），但訴訟代理人的代理權「不消滅」。 在法定代理人（監護人）承受訴訟之前，訴訟代理人仍可繼續代理為訴訟行為。
  • 法定代理有變更：當事人原本有法定代理人（例如未成年人由父親監護），後來法定代理人變更（例如父親死亡，改由母親監護）。訴訟代理權也不消滅，不需要重新委任，原訴訟代理人可以繼續代理為訴訟行為。
例1.
  • 甲告乙，甲委任陳律師為訴訟代理人。訴訟中，甲突然死亡 。
  • 依第168條，當事人死亡，訴訟程序當然停止（等待甲的繼承人承受訴訟）。但陳律師的代理權「不消滅」。
  • 在繼承人承受訴訟前，陳律師仍然可以代理甲（的繼承人）為訴訟行為（例如聲請調查證據、提出書狀）
例2.
  • 甲告乙，甲委任陳律師。訴訟中，甲因車禍變成植物人，受監護宣告（喪失訴訟能力）。
  • 依第170條，訴訟程序當然停止（等待監護人承受訴訟）。但依第73條，陳律師的代理權不消滅。
  • 監護人承受訴訟前，陳律師仍可代理。
訴訟委任之終止
  • 當事人想換律師，或律師不想幹了，不能私下講講就算，必須透過法院「通知」對方當事人，才會生效。
  • 如果是律師主動辭職，從辭職那天起15天內，律師還是要繼續做「保護當事人權益」的必要行為（例如出庭、提上訴），不能馬上擺爛。
訴訟委任之終止，非「通知他造」，不生效力
  • 訴訟委任終止：包括當事人主動「終止委任」（解僱律師）或訴訟代理人主動「終止委任」（律師辭職）
  • 通知他造：必須讓「對方當事人」（對造）知道這個終止。
  • 不生效力：在他造收到通知「之前」，原訴訟代理人「仍然」有代理權。
    • 他造向原代理人送達書狀仍然有效。原代理人所為的行為，對當事人仍然有效。
委任終止通知，應以書狀或言詞「提出於法院」，「由法院送達」或告知於他造
  • 應提出於法院：不能自己寄信給對造，必須透過法院。
  • 由法院送達：法院收到書狀後，會將繕本「送達」給對造。
由訴訟代理人終止委任者，自為終止之意思表示之日起「十五日內」，「仍應為」防衛本人權利所「必要之行為」
  • 由訴訟代理人終止委任：律師自己不想幹了，主動辭職（不是當事人解僱律師）。
  • 為終止之意思表示之日起「十五日內」：律師向當事人表示「我不幹了」的那一天起算15天。
  • 必要之行為：指為了避免當事人權益受損，所必須做的訴訟行為。例如：已經排定的開庭，律師仍然要出庭。
  • 「仍應為」：律師「有義務」繼續做，不能馬上擺爛
例1.
  • 甲委任陳律師為訴訟代理人，告乙。訴訟中，甲對陳律師不滿，決定終止委任（解僱陳律師）。
  • 甲寫了一份「終止委任狀」給法院，法院將繕本送達給乙（他造）。
  • 在乙收到送達「之前」，陳律師仍然有代理權（乙如果在這期間把書狀寄給陳律師，仍然有效）
  • 乙收到送達後，陳律師的代理權才對外消滅。
  • → 訴訟委任之終止，非「通知他造」，不生效力
例2.
  • 陳律師因個人因素決定辭去甲的訴訟代理人。陳律師向法院提出「終止委任狀」，並通知甲。
  • 從陳律師提出終止的那一天起算15天內，陳律師仍然必須：
    • 出席已經排定的開庭
    • 在甲找到新律師前，提出必要的書狀（例如對造提出新證據，陳律師要表示意見）
  • 15天過後，陳律師才完全解除義務。
  • → 由訴訟代理人終止委任者，自為終止之意思表示之日起「十五日內」，「仍應為」防衛本人權利所「必要之行為」
訴訟代理權欠缺之補正
  • 如果訴訟代理人的代理權有問題（例如忘了交委任書），但這個問題是可以事後補救的：
    • 法院不能直接說他無效，而是要訂一個期限讓他補正。
    • 如果情況緊急，法院也可以暫時允許他繼續做訴訟行為。
    • 如果當事人事後「承認」代理人的行為，那麼這個行為就溯及到當初做的時候就有效。
訴訟代理權有欠缺而「可以補正」者，審判長應定期間「命其補正」。但得許其「暫為訴訟行為」
  • 訴訟代理權有欠缺而可以補正者：例如缺少委任書。
  • 定期間「命其補正」：法院要訂一個期限（例如7天、10天、14天），讓當事人補正。法院會以「裁定」或「通知」的方式，告知當事人：「你的訴訟代理人有欠缺（例如沒有委任書），請於某年某月某日前補正（例如提出委任書）。」
  • 得許其「暫為訴訟行為」：如果法院認為，等到補正期限屆滿會來不及（例如證人即將出國、被告即將脫產），可以暫時允許該代理人繼續做訴訟行為（例如出庭、提書狀、聲請證據）
補正後，訴訟代理人暫為之訴訟行為，溯及於行為時發生效力
  • 溯及於行為時發生效力：視同一開始就有代理權而有效。
例1.
  • 甲委任陳律師為訴訟代理人，但陳律師第一次開庭時忘了附上委任書。
  • 法院發現後，審判長裁定：「陳律師應於7日內補正委任書，逾期未補正，將認定無代理權。」
  • 陳律師於3日內補提委任書。代理權溯及於第一次開庭時生效。
  • → 訴訟代理權有欠缺而「可以補正」者，審判長應定期間「命其補正」
例2.
  • 承上例，法院給陳律師7天補正委任書。但在第2天，甲發現乙（他造）正在脫產。
  • 陳律師還沒有委任書（代理權有欠缺），陳律師向法院聲請「假扣押」乙的財產。
  • 法院認為情況急迫，「暫時」允許陳律師聲請假扣押。
  • 法院先裁定准許假扣押，查封乙的財產。陳律師於期限內補正委任書。假扣押有效。
  • → 訴訟代理權有欠缺而「可以補正」者，審判長應定期間「命其補正」。但得許其「暫為訴訟行為」
  • → 補正後，訴訟代理人暫為之訴訟行為，溯及於行為時發生效力
