證據-證據保全

證據保全之要件
  • 證據有滅失風險、他造同意，或為確定現狀而有必要時，可聲請證據保全（如訊問證人、鑑定、勘驗）。
證據有滅失或礙難使用之虞
  • 滅失：如證物即將銷毀、證人病危。
  • 礙難使用：如文書將被攜至國外、證人將出國。
或經他造同意者
  • 若他造同意保全證據，則無須證明有滅失之虞。
得向法院「聲請保全」
  • 保全：預先調查並保存證據（如訊問證人、鑑定、勘驗）。
就確定事、物之「現狀」有「法律上利益」並有必要時
  • 確定事、物之現狀：如為確認房屋漏水狀況、土地界址。
  • 有法律上利益：如為避免將來訴訟舉證困難。
  • 並有必要：須有具體必要性。
亦得聲請為鑑定、勘驗或保全書證
  • 鑑定：如聲請鑑定工程瑕疵。
  • 勘驗：如聲請勘驗現場。
  • 保全書證：如聲請保全契約書。
前項證據保全，應適用調查證據方法之規定
  • 保全證據之「程序」應依各該調查證據方法之規定（如鑑定依第324條以下、勘驗依第364條以下）。
例1.
  • 甲、乙均同意保全書證，法院准許。
  • → 他造同意
例2.
  • 甲為確認房屋漏水現狀，聲請勘驗及鑑定。
  • → 確定現狀
證據保全之管轄法院
  • 證據保全在起訴後向本案法院聲請，起訴前向證人住居地或證物所在地法院聲請；緊急時即使起訴後也可向該地法院聲請。
保全證據之聲請，在起訴後，向受訴法院為之
  • 起訴後：本案已繫屬於法院。
  • 受訴法院：本案之繫屬法院（如第一審法院、第二審法院）。
在「起訴前」，向受訊問人住居地或「證物所在地」之地方法院為之
  • 起訴前：尚未提起本案訴訟。
  • 受訊問人住居地：證人（受訊問人）之住居所。
  • 證物所在地：證據標的物之所在地（如文書、物件）。
遇有「急迫情形」時，於起訴後，亦得向「證物所在地」地方法院聲請保全證據
  • 急迫情形：如證人即將出境、證物即將銷毀。
  • 於起訴後：即使已起訴，仍得向「受訊問人住居地」或「證物所在地」之地方法院聲請（而非限於受訴法院）。
例1.
  • 甲尚未起訴，為保全證人乙之證言（乙住高雄），向「臺灣高雄地方法院」聲請。
  • → 起訴前，向受訊問人住居地之地方法院為之
例2.
  • 甲已起訴，但證人乙即將出國，甲向乙住居地之高雄地院聲請保全。
  • → 「急迫情形」時，於起訴後，亦得向「證物所在地」地方法院聲請保全證據
證據保全聲請之程式
  • 保全證據由法院裁定准駁；准許裁定要載明證據和待證事實；駁回可抗告，准許不得抗告。
保全證據之「聲請」，由受聲請之法院「裁定」之
  • 受聲請之法院：受理保全聲請之法院（第369條）。
  • 裁定之：法院應以「裁定」形式准駁。
准許保全證據之裁定，應表明該證據及應證之事實
  • 該證據：具體指明證據（如「證人甲」、「系爭契約書」）。
  • 應證之事實：該證據所欲證明之事實（如「甲曾向乙借款100萬元」）。
駁回保全證據聲請之裁定，得為抗告
  • 若法院駁回聲請（對聲請人不利），聲請人得提起「抗告」。
准許保全證據之裁定，不得聲明不服
  • 若法院准許保全（對聲請人有利），聲請人不得抗告（他造亦不得抗告）。
例1.
  • 法院裁定「准許保全證人甲之證言，以證明乙曾向甲借款100萬元」
  • 此准許保全裁定，當事人不得抗告。
  • → 准許保全證據之裁定，應表明該證據及應證之事實。
例2.
  • 法院駁回保全聲請，甲提起抗告。
  • → 駁回保全證據聲請之裁定，得為抗告
法院依職權為證據保全
  • 訴訟中法院認為必要時，可以主動裁定保全證據，不需要當事人聲請。
法院「認為必要時」，得於「訴訟繫屬中」，「依職權為保全」證據之裁定
  • 認為必要：如發現證物將滅失、證人將出國、當事人未及時聲請。
  • 訴訟繫屬中：本案已起訴，訴訟程序進行中（不限於起訴前）。
  • 依職權：法院主動為之，無待當事人聲請。
  • 保全證據之裁定：以裁定命保全證據（如訊問證人、鑑定、勘驗）。
例1.
  • 法院發現證人甲即將出國，依職權裁定保全甲之證言。
  • → 法院「認為必要時」，得於「訴訟繫屬中」，「依職權為保全」證據之裁定
證據保全期日之通知與當事人陳述意見
  • 證據保全調查期日要通知聲請人；非緊急時也要事先通知他造；當事人在場可命其陳述意見。
調查證據期日，應通知聲請人
  • 聲請人：聲請保全證據之當事人。
除有急迫或有礙證據保全情形外
  • 急迫：如證人將出境。
  • 有礙證據保全：如事先通知他造可能導致證物被銷毀。
並應於期日前「送達聲請書狀」或筆錄及裁定於「他造當事人」而通知之
  • 應於期日「前」送達「聲請書狀或筆錄」及「裁定」予他造。
  • 使他有機會準備及陳述意見。
當事人於前項期日在場者，得命其陳述意見
  • 若當事人到場，法院得命其陳述意見（但非強制）。
證據保全中特別代理人之選任
  • 證據保全時若對造不明或來不及通知，法院可為對造選任特別代理人，以保障其權利。
他造當事人不明，或調查證據期日不及通知他造者
  • 他造當事人不明：如起訴前不知侵權行為人為何人。
  • 調查證據期日不及通知他造：因「急迫」致無法於期日前通知他造（如證人即將出境）。
法院因保護該當事人關於調查證據之權利，得為選任特別代理人
  • 為保障他造之「程序參與權」及「防禦權」，法院得依職權為他造選任「特別代理人」。
第五十一條第三項至第五項之規定，於前項特別代理人準用之
  • 第51條第3項：特別代理人應由法院「裁定」選任。
  • 第51條第4項：特別代理人得請求「報酬」。
  • 第51條第5項：對選任裁定得「抗告」。
例1.
  • 甲遭不明車輛撞傷，聲請保全監視器畫面，法院選任特別代理人代為行使權利。
  • → 對造不明，法院選任特別代理人
例2.
  • 證人即將出境，法院不及通知他造，選任特別代理人。
  • → 調查證據期日不及通知他造，法院選任特別代理人
證據保全筆錄之保管與送交
  • 證據保全筆錄由保全法院保管；若本案移給其他法院審理，應將筆錄送交該法院。
調查證據筆錄，由命保全證據之法院保管
  • 證據保全時製作的「調查筆錄」（例如證人筆錄），由「准許保全的法院」保管。
但訴訟繫屬他法院者，應送交該法院
  • 但如果後來本案訴訟是在「其他法院」審理，就要把筆錄送交給那個法院。
例1.
  • 甲向高雄地院聲請保全證據，筆錄由高雄地院保管。
  • → 調查證據筆錄，由命保全證據之法院保管
例2.
  • 甲於保全後向臺北地院起訴，高雄地院應將筆錄送交臺北地院。
  • → 但訴訟繫屬他法院者，應送交該法院
證據保全證人於本案之言詞辯論再為訊問
  • 證據保全時已問過的證人，當事人可在開庭時聲請再問一次，法院原則上應准；除非認為沒必要。
當事人就已於保全證據程序訊問之證人
  • 證人已於「證據保全程序」中經法院訊問。
「於言詞辯論」程序中「聲請再為訊問」時
  • 於本案「言詞辯論程序」中，當事人聲請再訊問該證人。
「於言詞辯論」程序中「聲請再為訊問」時，法院應為訊問
  • 於本案「言詞辯論程序」中，當事人聲請再訊問該證人。法院原則上應准許。
但法院認為不必要者，不在此限
  • 不必要：如證人證詞已明確、無爭議、證人已死亡或無法到場、或當事人未具體表明再訊問之理由。
例1.
  • 甲於保全程序訊問證人乙，本案言詞辯論中甲聲請再訊問乙，法院准許。
  • → 「於言詞辯論」程序中「聲請再為訊問」時，法院應為訊問
證據保全費用之負擔
  • 證據保全費用要算進訴訟費用，最後依訴訟費用負擔的原則（例如敗訴者負擔）來決定由誰付。
「保全證據程序之費用」，除別有規定外，應作為「訴訟費用之一部」定其負擔
  • 證據保全程序產生的費用（例如證人費、鑑定費），要算進「訴訟費用」裡面，最後依照誰輸誰贏來決定由誰負擔。
例1.
  • 甲聲請保全證據，費用共2萬元。本案判決甲勝訴，該2萬元納入訴訟費用，由敗訴之乙負擔。
保全證據程序中之協議與其效力
  • 保全程序中雙方達成協議，記明筆錄；若協議涉及給付，該筆錄可作為執行名義，直接強制執行。
本案尚未繫屬者，於保全證據程序期日到場之兩造，就訴訟標的、事實、證據或其他事項成立協議時，法院應將其協議記明筆錄
  • 在「還沒起訴」的證據保全程序中，如果雙方當事人到場並達成協議（類似和解。例如同意賠多少錢），法院要記在筆錄裡。
前項協議係就訴訟標的成立者，法院並應將協議之法律關係及爭議情形記明筆錄。依其協議之內容，當事人應為一定之給付者，得為執行名義
  • 如果協議是針對「訴訟標的」本身，法院還要把「法律關係」和「爭議情形」記明筆錄。
  • 如果協議內容是「一方應給付一定金錢或物品」，這份筆錄可以作為「執行名義」（直接聲請強制執行）。
協議成立者，應於十日內以筆錄正本送達於當事人
  • 協議成立後，法院應在「10天內」將筆錄正本送達給當事人。
例1.
  • 甲、乙於保全程序期日達成協議，乙同意給付甲100萬元，法院記明筆錄，筆錄得為執行名義。
  • 協議成立後，法院於10日內送達筆錄正本。
保全證據程序終結後本案未繫屬之處理
  • 保全證據後30天內未起訴，法院可依聲請解除留置或命聲請人負擔費用；對此裁定可抗告。
保全證據程序終結後「逾三十日」，本案「尚未繫屬」者
  • 保全證據程序終結：如證人訊問完畢、鑑定完成。
  • 逾三十日：自程序終結之日起算30日。
  • 本案尚未繫屬者：聲請人尚未提起本案訴訟。
法院得依「利害關係人」之聲請，以「裁定解除」因保全證據所為文書、物件之留置或為其他適當之處置
  • 利害關係人：如證據被留置之對造。
  • 解除留置：返還留置之文書、物件。
  • 其他適當之處置：如銷毀、發還等。
前項期間內本案尚未繫屬者，法院得依利害關係人之聲請，命保全證據之聲請人「負擔程序費用」
  • 若30日內未起訴，法院得命「保全證據之聲請人」「負擔程序費用」。
例1.
  • 甲保全契約書後，30日內未起訴，乙聲請解除留置，法院裁定返還契約書。
  • 法院命甲負擔保全程序費用。
