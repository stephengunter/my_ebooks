問題：
  1. 甲不服考績列乙等之事 ，依我國現行法制及實務，甲應如何提起救濟？
答案
結論
  • 甲應先向公務人員保障暨培訓委員會（保訓會）提起復審；若不服復審決定，得向行政法院提起撤銷訴訟。
理由
  • 實務見解：考績乙等應定性為「行政處分」
    • 過去實務長期認為，年終考績列乙等未改變公務人員身分，不屬行政處分，僅得提起申訴、再申訴。
    • 然而，司法院釋字第785號解釋揭示：基於「有權利即有救濟」原則：
      • 公務人員因其身分與服務機關發生公法上爭議，認其權利遭受違法侵害時，得按相關措施與爭議之性質，依法提起相應之行政訴訟，不因其公務人員身分而異其救濟途徑之保障。
    • 保訓會據此函示：保障法第25條所稱「行政處分」，應與行政程序法第92條為相同認定，不再以「權利侵害是否重大」為門檻。
      • 考績評定各等次（不論甲、乙、丙或丁等），均已觸及公務人員服公職權等法律地位，對外直接發生法律效果，核屬行政處分，應循復審程序救濟。
    • 因此，甲之考績乙等，在現行實務下不再是只能申訴的管理措施，而是得提起復審的「行政處分」。
    甲應如何提起救濟？
    • 第一步：向保訓會提起「復審」
      • 依公務人員保障法第25條，公務人員對於服務機關所為之行政處分，認為違法或顯然不當，致損害其權利或利益者，得提起復審。
      • 管轄機關：復審事件統一由保訓會審議決定。甲應繕具復審書，經由原處分機關（臺北市榮服處） 向保訓會提起，或直接向保訓會提起。
      • 期間：應自考績通知書達到之次日起30日內為之。
    • 第二步：不服復審決定，向行政法院提起撤銷訴訟
      • 復審決定後，甲如仍不服，得向管轄之高等行政法院提起撤銷訴訟，請求撤銷考績處分及復審決定。
      • 實務上已有諸多考績乙等案件，經復審駁回後進入行政訴訟審理。

  • 行政執行法規定直接強制與即時強制之意義、執行方法及執行要件各為何？並各舉例說明之。
答案
結論
  • 直接強制：義務人「已有義務」卻不履行時，經間接強制無效或急迫時所採取的「最後手段」
  • 即時強制：沒有事先的義務存在，行政機關為「防止危害」發生，直接介入處置的「緊急措施」。
法律依據
  • 行政執行法第27條：
    1. 「依法令或本於法令之行政處分，負有行為或不行為義務，經於處分書或另以書面限定相當期間履行，逾期仍不履行者，由執行機關依間接強制或直接強制方法執行之。」
    2. 「前項文書，應載明不依限履行時將予強制執行之意旨。」
  • 行政執行法第28條：
    1. 「前條所稱之間接強制方法如下：1.代履行。 2.怠金」
    2. 「前條所稱之直接強制方法如下：」
      1. 扣留、收取交付、解除占有、處置、使用或限制使用動產、不動產。
      2. 進入、封閉、拆除住宅、建築物或其他處所。
      3. 收繳、註銷證照。
      4. 斷絕營業所必須之自來水、電力或其他能源。
      5. 其他以實力直接實現與履行義務同一內容狀態之方法。
  • 行政執行法第32條：「經間接強制不能達成執行目的，或因情況急迫，如不及時執行，顯難達成執行目的時，執行機關得依直接強制方法執行之。」
  • 行政執行法第36條：
    1. 「行政機關為阻止犯罪、危害之發生或避免急迫危險，而有即時處置之必要時，得為即時強制。」
    2. 「即時強制方法如下：」
      1. 對於人之管束。
      2. 對於物之扣留、使用、處置或限制其使用。
      3. 對於住宅、建築物或其他處所之進入。
      4. 其他依法定職權所為之必要處置。
  • 行政執行法第37條：
    1. 「對於人之管束，以合於下列情形之一者為限：」
      1. 瘋狂或酗酒泥醉，非管束不能救護其生命、身體之危險，及預防他人生命、身體之危險者。
      2. 意圖自殺，非管束不能救護其生命者。
      3. 暴行或鬥毆，非管束不能預防其傷害者。
      4. 其他認為必須救護或有害公共安全之虞，非管束不能救護或不能預防危害者。
    2. 「前項管束，不得逾二十四小時。」
理由
一、直接強制
  • 意義
    • 直接強制，是指行政機關以「實力」，直接實現與義務人履行義務相同內容狀態的強制方法。
    • 它是「間接強制（代履行、怠金）不能達成目的」或「情況急迫，不及時執行顯難達成目的」時，始得採用的最後手段。
  • 執行要件
    • 義務存在：人民依法令或行政處分，負有行為或不行為義務。
    • 已踐行告戒程序：須以處分書或書面限定相當期間履行，並載明不履行將予強制執行之意旨。
    • 逾期不履行：義務人於期限屆滿後仍未履行。
    • 補充性要件（二者之一）：①經間接強制不能達成執行目的；或②情況急迫，如不及時執行，顯難達成執行目的。
  • 執行方法
    • 扣留、收取交付、解除占有、處置、使用或限制使用動產、不動產
    • 進入、封閉、拆除住宅、建築物或其他處所
    • 收繳、註銷證照
    • 斷絕營業所必需之自來水、電力或其他能源
    • 其他以實力直接實現與履行義務同一內容狀態之方法
  • 實例
    • 違章建築拆除：
      • 主管機關作成「限期拆除」之行政處分，義務人逾期不拆。
      • 經間接強制（如科處怠金）仍不履行，或情況急迫時，執行機關即得依第28條第2項第2款直接進入並拆除該違章建築，以實力實現「拆除」此一義務內容。
二、即時強制
  • 意義
    • 即時強制，是指行政機關為阻止犯罪、危害之發生或「避免急迫危險」，在有「即時處置」必要時，直接以實力介入的強制措施。
    • 其最關鍵的特徵在於：不以人民已違反行政法上義務為前提——它是針對「當下存在的危險狀態」所為的立即排除，而非對「過去不履行義務」的追究。
  • 執行要件
    • 目的要件：為阻止犯罪、危害之發生或避免急迫危險。
    • 急迫性要件：有即時處置之必要，無法等待作成行政處分再循一般程序執行。
    • 不以義務違反為前提：人民縱無違反任何行政法上義務，仍得對之實施即時強制。
    • 最後手段性：即時強制是對人民權利干預最為強烈的措施，必須是最後手段。
  • 執行方法
    • 對於人之管束：（瘋狂或酗酒泥醉等情形，不得逾24小時）
    • 對於物之扣留、使用、處置或限制其使用（軍器、凶器等危險物之扣留）
    • 對於住宅、建築物或其他處所之進入（以人民生命、身體、財產有迫切危害，非進入不能救護者為限）
    • 其他依法定職權所為之必要處置
  • 實例
    • 對泥醉駕車者之管束：
      • 警察發現某人酗酒泥醉，已無法安全駕駛，且有危害他人生命、身體之虞。
      • 此時該人未必已違反某項「義務」，但危險狀態當下存在且急迫，警察得依第36條第2項第1款對其管束，至危險結束為止，但不得逾24小時。
三、兩者關鍵區別整理
直接強制 即時強制
前提 人民已負有義務且不履行 無須先有義務存在
程序 須經書面限期履行、告戒 無須事先告戒或限期
時機 間接強制無效或情況急迫 為阻止犯罪、危害或急迫危險
本質 「義務之強制執行」的一種方法 獨立的緊急處置制度
法律效果 實現已存在的義務內容 直接排除當下的危險

問題：
  1. 請依行政程序法之規定，說明本細則之法律性質、意涵及效力。
答案
法律依據
  • 行政程序法第150條：
    1. 「本法所稱法規命令，係指行政機關基於法律授權，對多數不特定人民就一般事項所作抽象之對外發生法律效果之規定。」
    2. 「法規命令之內容應明列其法律授權之依據，並不得逾越法律授權之範圍與立法精神。」
  • 行政程序法第159條：
    1. 「本法所稱行政規則，係指上級機關對下級機關，或長官對屬官，依其權限或職權為規範機關內部秩序及運作，所為非直接對外發生法規範效力之一般、抽象之規定。」
    2. 「行政規則包括下列各款之規定︰」
      1. 關於機關內部之組織、事務之分配、業務處理方式、人事管理等一般性規定。
      2. 為協助下級機關或屬官統一解釋法令、認定事實、及行使裁量權，而訂頒之解釋性規定及裁量基準。
  • 行政程序法第161條：「有效下達之行政規則，具有拘束訂定機關、其下級機關及屬官之效力。」
結論
  • 該「辦事細則」之法律性質為「行政規則」，非「法規命令」。
  • 其意涵在於規範機關內部秩序及運作，效力上僅生「對內拘束力」，不直接對外發生法規範效力。
理由
  • 一、法律性質：行政規則
    • 依行政程序法第159條第1項規定，行政規則係指上級機關對下級機關，或長官對屬官，依其權限或職權為規範機關內部秩序及運作，所為非直接對外發生法規範效力之一般、抽象之規定。
    • 同條第2項第1款進一步規定，行政規則包括「關於機關內部之組織、事務之分配、業務處理方式、人事管理等一般性規定」。
    • 本細則之內容，係就臺北關內部各組、室、分關之設置、職掌劃分、分層負責等事項所為之規範，核屬行政程序法第159條第2項第1款所定之組織性／事務性行政規則。
    • 與法規命令之區別：法規命令須有法律授權，且對多數不特定人民直接發生法律效果（第150條第1項）；本細則係依機關權限或職權訂定，規範對象為機關內部單位及所屬人員，非直接對外發生法規範效力，故非屬法規命令。
  • 二、意涵：規範機關內部秩序及運作
    • 本細則之意涵，在於建立臺北關內部之組織架構與權責分工，具體包括：
      • 組織編制：明定臺北關設各組、室、分關及其下設課、股。
      • 權責劃分：明定關務長綜理關務，副關務長輔佐關務長處理關務；各組、室、分關之職掌。
      • 業務處理方式：實施分層負責制度，依分層負責明細表逐級授權決定。
    • 此類規範之目的在於維持機關內部秩序、提升行政效能，屬於行政機關之內部管理事項。
  • 三、效力：對內拘束力，不直接對外發生效力
    • 對內效力
      • 依行政程序法第161條規定：「有效下達之行政規則，具有拘束訂定機關、其下級機關及屬官之效力。」
      • 本細則經財政部發布下達後，即對臺北關及其所屬單位與公務人員產生內部拘束力。
    • 不直接對外發生法律效果
      • 行政規則原則上僅生對內效力，不直接對人民發生法律效果。人民不會因本細則之規定而直接取得權利或負擔義務。
    • 間接對外效力之問題
      • 若行政規則具有解釋性規定或裁量基準之性質（第159條第2項第2款），因公務員反覆適用形成行政慣例，基於行政自我拘束原則及平等原則，可能間接對外發生效力。
      • 惟本細則係純粹之組織性／事務性規則，不具解釋性規定或裁量基準之性質，故無間接對外效力之問題。
    • 對法院之效力
      • 行政規則對於法院無拘束力。法官依據法律獨立審判，不受行政機關訂定之行政規則所拘束。

問題：
  1. 請依現行法制及實務，說明本號函之法律性質、意涵及效力。
答案
法律依據
  • 行政程序法第150條：
    1. 「本法所稱法規命令，係指行政機關基於法律授權，對多數不特定人民就一般事項所作抽象之對外發生法律效果之規定。」
    2. 「法規命令之內容應明列其法律授權之依據，並不得逾越法律授權之範圍與立法精神。」
  • 行政程序法第159條：
    1. 「本法所稱行政規則，係指上級機關對下級機關，或長官對屬官，依其權限或職權為規範機關內部秩序及運作，所為非直接對外發生法規範效力之一般、抽象之規定。」
    2. 「行政規則包括下列各款之規定︰」
      1. 關於機關內部之組織、事務之分配、業務處理方式、人事管理等一般性規定。
      2. 為協助下級機關或屬官統一解釋法令、認定事實、及行使裁量權，而訂頒之解釋性規定及裁量基準。
  • 行政程序法第161條：「有效下達之行政規則，具有拘束訂定機關、其下級機關及屬官之效力。」
結論
  • 本號函之法律性質為「解釋性行政規則」，其意涵在於闡明菸害防制法第15條第1項第8款、第9款所定禁菸場所之適用範圍。
  • 效力上原則僅拘束下級機關及屬官，不直接對外發生法規範效力，但因反覆適用而產生「行政自我拘束」之間接對外效力。
理由
  • 一、法律性質：解釋性行政規則
    • 依行政程序法第159條第1項規定，行政規則係指上級機關對下級機關，或長官對屬官，依其權限或職權為規範機關內部秩序及運作，所為非直接對外發生法規範效力之一般、抽象之規定。
    • 同條第2項第1款進一步規定，行政規則包括「關於機關內部之組織、事務之分配、業務處理方式、人事管理等一般性規定」。
    • 本號函係衛生福利部國民健康署基於菸害防制法中央主管機關之職權，就該法第15條第1項第8款、第9款所定禁菸場所之適用範圍所為之釋示。
      • 目的在於統一解釋法令，供下級機關及屬官行使職權時之依據。
      • 其性質為解釋性「行政規則」，而非組織性／事務性規則，亦非法規命令。
    • 與法規命令之區別：法規命令須有法律授權，且對多數不特定人民直接發生法律效果（第150條第1項）；
      • 本號函係依機關職權所為之釋示，未經法律授權，且規範目的在於協助下級機關適用法令，非直接對外發生法規範效力，故非屬法規命令。
  • 二、意涵：闡明禁菸場所之適用範圍
    • 本號函之意涵，在於釐清菸害防制法第15條第1項第8款、第9款所定禁菸場所之範圍，其核心論述為：
      • 場所獨立設置或附設均同受規範：上開場所除獨立設置外，亦常見附設於其他公、私立場所中，菸害防制法並未區分其所屬場所之性質而有不同規範。
      • 單獨列款之意義：因該等場所單獨列為菸害防制法第15條之一款，故無論係設於營業場所、公共場所，抑或是公寓大廈內，均為全面禁菸場所。
    • 此號函之目的，在於協助下級機關及屬官統一認定禁菸場所之範圍，避免因場所附設於不同性質之建築物內而產生適用上之疑義，供各級衛生主管機關於執行取締時有所依循。
  • 三、效力：對內拘束力與間接對外效力
    • 對內效力
      • 依行政程序法第161條規定：「有效下達之行政規則，具有拘束訂定機關、其下級機關及屬官之效力。」
      • 本號函經下達後，即對衛生福利部國民健康署及其下級機關、所屬公務人員產生內部拘束力。
        • 相關機關於認定禁菸場所範圍時，應依該函之解釋意旨執行職務。
    • 不直接對外發生法律效果
      • 行政規則原則上僅生對內效力，不直接對人民發生法律效果。
      • 本號函作為解釋性行政規則，其本身並非法律或法規命令，人民不會因該函之規定而直接取得權利或負擔義務。
    • 間接對外效力：行政自我拘束原則
      • 惟解釋性行政規則因公務員在具體個案「反覆適用」而作成解釋或裁量結果，已形成行政慣例。
        • 基於行政自我拘束原則及平等原則，行政機關非有正當理由，對於相同之事件，不得為不同之處理。
      • 最高法院113年度台上字第2583號判決明確指出，此類行政規則因公務員反覆適用而形成行政慣例，「行政規則乃因此間接對外發生法律效力」，人民對於違反行政慣例之行政行為，得以其違反平等原則而主張權利救濟。
    • 對法院之效力
      • 解釋性行政規則對於無隸屬關係或無業務監督之機關或法院，並無拘束力。
      • 法官依據法律獨立審判，於審判時應就具體案情，依其獨立確信之判斷，認定事實，適用法律，不受行政機關函釋之拘束。
    • 溯及效力
      • 解釋性行政規則之效力，依司法院釋字第287號解釋意旨，溯及自法規生效之日起有其適用，與一般行政規則或法規命令向後生效之概念不同。
總結
  • 法律性質：解釋性行政規則（行政程序法第159條第2項第2款）
  • 意涵：闡明菸害防制法第15條第1項第8款、第9款禁菸場所之適用範圍
  • 對內效力：有效下達後拘束訂定機關、下級機關及屬官（第161條）
  • 對外效力：不直接發生法規範效力；因行政自我拘束原則而間接對外發生效力
  • 對法院之效力：無拘束力，法院得本於確信獨立解釋法律
  • 溯及效力：溯及自法規生效之日起有其適用（釋字第287號）
提示
評分要點
  • 能否正確將該函定性為「解釋性行政規則」，說明其意涵在於闡明禁菸場所之適用範圍
  • 並正確交代其效力——對內有拘束力、不直接對外發生法規範效力、因行政自我拘束原則而間接對外、對法院無拘束力。

二、法律性質：解釋性行政規則（核心得分區）
要點 說明 配分權重
引出行政程序法第159條第1項 行政規則之定義：規範機關內部秩序及運作，非直接對外發生法規範效力之一般、抽象規定 高
引出第159條第2項第2款 為協助下級機關或屬官統一解釋法令、認定事實、行使裁量權而訂頒之解釋性規定及裁量基準 高

要點 說明 配分權重
