行政法 3-7 行政作用法 - 行政執行

總覽

  • 本節處理的核心問題是：
    • 行政機關作成行政處分後，義務人不履行時，行政機關如何強制實現處分內容？
    • 執行的手段有哪些？執行期間有何限制？義務人不服執行行為時如何救濟？
  • 管束24小時、執行期間（五年）、代履行與怠金、聲明異議，都是本節的高頻爭點。

總結
  • 行政執行是實現行政處分內容的強制手段，分為行為或不行為義務之執行（間接強制：代履行、怠金；直接強制）與即時強制（管束、扣留、進入處所等）。
  • 代履行針對能由他人代為履行之行為義務；怠金針對不能由他人代為履行之行為義務及不行為義務。
  • 管束不得逾24小時（憲法第8條精神）。
  • 執行期間為5年，屬法定期間，非消滅時效，無中斷問題。
  • 對執行命令不服，經聲明異議後，相當於已經訴願程序，可直接提起撤銷訴訟。

行政執行之概念

本法所稱行政執行，指：
  • 公法上「金錢給付」義務
    • 基於行政權作用而生的金錢給付義務，例如稅款、罰鍰、代履行費用等。
  • 「行為或不行為」義務
    • 指人民負有做出特定行為（如拆除違建）或不做出特定行為（如不得夜間施工）的公法上義務。
    • 意義：此類義務無法直接用金錢執行完畢，須透過代履行、怠金或直接強制等手段實現。
執行方式
  • 強制執行
    • 指行政機關以強制力迫使義務人履行，或實現與履行相同狀態的手段。
  • 即時強制
    • 指行政機關為排除急迫危害，無須先經告戒或書面處分，直接對人民身體、財產或場所採取的必要措施。
    • 要件：須有急迫性，且屬防止危害所必要。
執行機關
行政執行，由「原處分機關」或該管行政機關為之
  • 行為或不行為義務之執行、即時強制，原則上由做成原行政處分之機關，或主管該法令之行政機關自行執行。
但公法上「金錢」給付義務「逾期不履行」者，「移送」行政執行署執行之
  • 須具備兩個要件：義務屬公法上金錢給付，且已逾期不履行。
  • 符合上述要件者，原處分機關應將案件移送專責機關執行，不得自行強制扣薪或查封。
  • 法律效果：採「集中執行」模式；現行機關名稱為「行政執行分署」。
例1.
  • 老李的違章建築經工務局命令限期拆除，逾期不拆。
  • 工務局自行雇工代為拆除，並向老李追討費用。
  • → 行為義務，由原處分機關自行執行
例2.
  • 阿華欠綜合所得稅三十萬元，國稅局通知後逾期不繳。
  • 國稅局將案件移送法務部行政執行署臺北分署執行，分署對阿華的公司發扣押薪資命令。
  • → 金錢給付義務，逾期不履行，移送行政執行署

執行期間

五年啟動期
起算點1.處分/裁定「確定」之日
  • 行政處分確定是指相對人已不能再以通常救濟途徑（訴願、行政訴訟）變更或撤銷，即產生形式存續力之日。
  • 意義：執行期間的起算點，不是處分作成日，而是確定日。
起算點2.書面通知「限期履行」，所定「期間屆滿之日」起
  • 適用於直接依法令負義務、未經個別處分的情形。
  • 意義：以限期履行通知的期間屆滿日為起算點。
行政執行，五年內「未經執行」者，「不再執行」
  • 五年內完全沒有執行動作，執行權限消滅。
十年絕對終結期限
五年期間屆滿前「已開始」執行者，仍「得繼續」執行
  • 五年內有合法開始執行，即可跨越五年門檻。
但自五年期間屆滿之日起已逾五年「尚未執行終結」者，「不得再執行」
  • 從原始起算日算起滿十年仍未終結，執行權限徹底消滅。
  • 法律效果：十年為絕對上限。
法律有特別規定者，不適用之
  • 其他法律對執行期間有不同規定時，優先適用該特別法。
  • 典型：稅捐稽徵法第23條的徵收期間規定。
已開始執行的定義（移送執行機關的情形）
  1. 通知義務人到場
    • 通知義務人到場或自動清繳應納金額、報告其財產狀況或為其他必要之陳述。
  2. 已開始調查程序
    • 執行機關已著手調查義務人的財產或相關事實。
例1.
  • 阿明於2015年1月1日收到罰鍰處分確定，機關直到2021年才想起來要移送執行，中間完全沒有通知、沒有調查。
  • → 處分確定五年內「未經執行」者，「不再執行」
例2.
  • 阿華的處分於2015年1月1日確定，機關在2018年通知阿華到場報告財產狀況（已開始執行），但直到2026年仍未終結。
  • → 自五年期間屆滿之日起已逾五年「尚未執行終結」者，「不得再執行」

行政執行之比例原則

行政執行，應依公平合理之原則
  • 行政執行不得偏頗、不得恣意，須考量個案具體情境。
兼顧公共利益與人民權益之維護
  • 不得以「公共利益」為由，無限上綱犧牲人民權益。
以「適當方法」為之
  • 手段須與目的具有合理關聯，且屬有效達成目的之方法。
不得逾「達成執行目的」之「必要限度」
  • 對應「必要性原則」（選損害最小者）與「狹義比例原則」（損害與利益不得顯失均衡）。
國家賠償
行政執行，有國家賠償法所定國家應負賠償責任之情事者
  • 國賠法第2條第2項：公務員於執行職務行使公權力時，因故意或過失不法侵害人民自由或權利。
  • 要件：須有公務員行為、執行職務行使公權力、故意或過失、不法、侵害權益、因果關係。
受損害人得依國家賠償法請求損害賠償
  • 請求權基礎是《國家賠償法》，而非本條。本條不創設新的賠償事由，只是確認國賠法適用。
  • 法律效果：須循國賠法程序（先以書面向賠償義務機關請求，協議不成再提起國賠訴訟）。
例1.
  • 義務人欠地價稅，執行處考量拍賣不動產需負擔鑑價費、登報費，且拍賣價金尚須優先扣繳土地增值稅，能否拍定亦不確定。
  • 扣押銀行存款的執行成本遠低於拍賣土地，乃選擇先扣押存款。
  • → 先扣存款再拍不動產，選擇對義務人損害最少之方法
例2.
  • 行政執行分署人員查封動產時，未依規定清點造冊，粗暴搬運導致義務人非執行標的的高價音響摔落毀損。
  • 義務人得依國賠法請求賠償。
  • → 有國賠法所定情事，得依國家賠償法請求損害賠償

終止執行

終止事由
  1. 已履行
    • 義務已全部履行或執行完畢。
    • 義務人已自行履行完畢，或執行機關已透過強制手段實現義務內容。
  2. 處分撤銷
    • 行政處分或裁定經撤銷或變更確定。
    • 作為執行名義的行政處分或裁定，經訴願、行政訴訟等程序撤銷或變更而確定。
    • 執行名義一部被撤銷或變更時，僅該部分終止，其餘部分繼續執行。
  3. 不可能履行
    • 義務之履行經證明為不可能。
    • 如一身專屬義務因義務人死亡、執行標的已滅失（如應拆除之違建已焚毀）
發動：「應依職權」或依申請
  • 如執行機關未主動停止，義務人、利害關係人得申請終止執行。
聲明異議
得異議事由：執行命令、執行方法、應遵守之程序或其他侵害利益之情事
  • 須針對執行行為，而非執行名義的實體內容。例如：查封方式不當、未依法先期公告拍賣、扣押禁止執行之財產等。
得異議人：義務人或利害關係人
  • 義務人指執行名義所載負有義務之人；利害關係人指法律上權益因執行行為受侵害之人，須非僅有事實上關聯。
得異議期限：執行程序「終結前」，向執行機關聲明異議
  • 異議須在程序尚未完結時提出。程序終結後，聲明異議即不合法，僅能循其他途徑救濟。
執行機關之異議處理
認異議有理由者，應即停止執行，並「撤銷或更正」已為之執行行為
  • 執行機關自行審查認為有理時，主動糾正。
認異議無理由者，應於「十日內加具意見」，「送直接上級主管機關」於三十日內決定之
  • 執行機關認為異議無理由時，不能自己駁回就算了，須在十日內附意見送上級機關，上級須在三十日內做成決定。
不停止執行原則
除法律另有規定外，不因聲明異議而停止執行
  • 聲明異議原則上不具停止執行之效力。
但執行機關因「必要情形」，得「依職權或申請停止」之
  • 要件：須有「必要情形」，由執行機關就個案具體認定。
例1.
  • 老李的違建拆除處分經行政法院判決撤銷確定。行政執行分署應終止拆除執行程序。
  • → 處分被撤銷確定，應終止執行程序
例2.
  • 阿明欠稅五十萬，行政執行分署卻查封了他價值五百萬的房子。
  • 阿明認為違反比例原則，在拍賣終結前向分署聲明異議。
  • → 執行程序「終結前」，向執行機關聲明異議

公法上金錢給付義務之執行

主管機關 行政執行署
執行名義：依法令、行政處分、法院裁定
  • 執行名義的發生來源有三：直接依法令、行政處分、法院裁定。
義務性質：公法上「金錢給付」
  • 例如：罰鍰、補稅。
主管機關執行方式
第一步：書面通知限期履行
  1. 處分文書或裁定書定有履行期間，或有法定履行期間。
  2. 另以書面通知限期履行。
第二步：移送行政執行署
  • 逾期不履行，移送行政執行署就義務人之財產執行之。
遺產得強制執行
義務人死亡遺有財產者，行政執行處得逕對其遺產強制執行
  • 義務人死亡留有遺產，國家可以直接追那筆遺產討公法債——追的是「物」不是「人」，繼承人的固有財產不受牽連。
通知義務人到場，自行繳清或報告財產
  • 執行機關可以發通知叫義務人來、繳錢、報財產或說明。
  • 這是柔性手段，也是後續限制出境、拘提、管收的正當程序前提；給你機會你不理，後面就別怪手段變硬。
間接強制：擔保、限期履行、限制住居
  • 有錢不還、想跑、藏財產、叫不動——先命擔保 + 限制住居。
  • 滯欠金額合計未達十萬元，不得限制住居。但義務人已出境達二次者，不在此限。
拘提
  • 前提：經命提供擔保，限期履行，屆期不履行亦未提供擔保。
  • 事由：限於「顯有逃匿之虞」或「經合法通知無正當理由不到場」
  • 程序：行政執行處聲請法院裁定，法院5日內裁定，急迫時即時裁定。
管收：最後手段
  • 前提：經到場訊問。
  • 事由：有錢不還、想跑、藏財產。有聲請管收必要。
  • 程序：向法院聲請管收。法院應即訊問義務人並裁定。
例1.
  • 阿華收到綜合所得稅單，上面載明繳納期限至2026年5月31日。
  • 阿華逾期未繳，國稅局將案件移送行政執行分署執行。
  • → 處分文書定有履行期間，逾期未繳，移送行政執行分署執行
例2.
  • 老王欠稅200萬，名下有不動產卻不繳，且近期頻繁查詢機票、有意移民。
  • 行政執行分署限制其出境。
  • → 有錢不還+想跑→限制出境

行為或不行為義務之執行

執行名義：依法令、行政處分
  • 義務的來源有兩種——法律直接課予，或行政機關依法作成的處分。
義務性質：行為或不行為
  • 行為義務如拆除違建、清除廢棄物；不行為義務如不得營業、不得夜間施工。
主管機關執行方式
第一步：書面通知限期履行
  1. 期限須寫在處分書本身，或另外以書面通知。
  2. 應書面載明不依限履行時將予強制執行之意旨。
第二步：間接強制或直接強制
  • 間接強制優先於直接強制，除非「經間接強制不能達成目的」或「情況急迫」。
例外：情況急迫，如不及時執行，顯難達成執行目的時，得依直接強制方法執行
  • 比如危險建物隨時可能倒塌傷人。
間接強制：代履行、怠金
代履行
  • 義務人負有行為義務而不為，且該行為能由他人代為履行者。
  • 執行機關委託第三人或指定人員代為履行，再向義務人收取費用。
  • 典型：拆除違建、清除廢棄物、拖吊違規車輛。
怠金
  • 義務人負有行為或不行為義務而不履行，以金錢壓力迫使履行。
  • 怠金是「執行罰」，不是行政罰；可連續處以怠金。
  • 典型：命停止營業仍繼續營業、命限期改善仍不改善。
直接強制方法
  • 扣留、收取交付、解除占有、處置、使用或限制使用動產、不動產
    • 對物的直接實力支配。例如扣留營業設備、限制使用特定機具。
    • 「限制使用動產」適用於義務人負有「容忍處置或使用」或「不得使用」義務而不履行的情形。
  • 進入、封閉、拆除住宅、建築物或其他處所
    • 涉及居住自由與財產權的強制手段。例如強制拆除違建、封閉危險建物。
  • 收繳、註銷證照
    • 使義務人喪失從事特定活動的資格。例如吊銷營業許可、收繳牌照。
  • 斷絕營業所必須之自來水、電力或其他能源
    • 作用對象限於營業所，本質為勒令停工、歇業的執行手段。
    • 限制：若義務內容不包含停業，不得使用此款。
  • 其他「以實力直接實現」與履行義務同一內容狀態之方法
    • 概括條款，保留彈性。
代履行之實施
前提：負有行為義務而不為，其行為能由他人代為履行
  • 依法令或本於法令之行政處分，負有行為義務而不為。
  • 要件：須經限期履行與告戒程序，逾期仍不履行。
方式：執行機關得委託第三人或指定人員代履行之
  • 可委託民間廠商（第三人），或依其他法律指定人員。
費用：由執行機關估計其數額，命義務人繳納。多退少補
  • 性質：命繳納代履行費用的處分，是確認及下命處分，具行政處分效力。
  • 多退少補：預繳只是「暫付」，最終以實際支出為準。
怠金
前提：負有行為義務而不為，其行為「不能」由他人代為履行
  • 依法令或本於法令之行政處分，負有行為義務而不為。
  • 要件：須經限期履行與告戒程序，逾期仍不履行。
  • 「不能」由他人代為履行：例如：親自出席、親自報告、具有高度屬人性的行為。
負有不行為義務而為之者，亦同
  • 義務內容是「不要做某事」，義務人卻做了。例如：命停止營業仍繼續營業、命不得夜間施工仍施工。
  • 意義：不行為義務本質上無法「代履行」（不可能找人「代替他不做」），因此怠金是主要的間接強制手段。
裁處：依其情節輕重處5千元以上30萬元以下怠金
  • 金額在此區間內裁量，須符合比例原則。
仍不履行義務者，得連續處以怠金
  • 怠金處分後，義務人仍未履行，執行機關得連續處以怠金。
連續處以怠金前，仍應按規定程序，以「書面限期履行」
  • 每一次連續開罰之前，都要重新走一次「書面限期履行」的程序——書面限定相當期間、載明不履行將強制執行的意旨。

即時強制

即時強制要件
  1. 阻止犯罪、危害之發生
    • 犯罪預防（如有人正持械攻擊）、危害防止（如瓦斯外洩隨時可能爆炸）
    • 即時強制保護的是公共安全與個人重大法益，不是一般的行政秩序。
  2. 避免急迫危險
    • 如精神病患自傷。
  3. 有即時處置之必要
    • 時間上的急迫性，客觀上無法等待正常的行政程序（下命、限期、告戒、執行）。
即時強制方法
  1. 「管束」：對於人之管束
    • 比如把爛醉的人帶走。
  2. 「扣留」：對於物之、使用、處置或限制其使用
    • 扣留（如扣下刀械）、使用（如徵用民車救災）、處置（如銷毀腐壞食品）、限制使用（如封鎖危險設備）。
  3. 「進入住宅」：對於住宅、建築物或其他處所之進入
    • 時間上的急迫性，客觀上無法等待正常的行政程序（下命、限期、告戒、執行）。
  4. 其他依「法定職權」所為之「必要處置」
    • 概括條款，但須有其他法律授權的職權為基礎，不是空白授權。
損失補償
補償請求權之成立：因即時強制，受「特別損失」
人民因執行機關依法實施「即時強制」
  • 前提是國家的行為合法。若執行機關有故意或過失不法侵害，屬於國家賠償問題，不適用本條。
致其生命、身體或財產遭受「特別損失」
  • 「特別損失」是關鍵概念——須超過一般人社會生活應忍受的程度。法務部函釋及學說稱之為「特別犧牲」。
但因「可歸責於該人民」之事由者，「不在此限」
  • 若損失是因人民自己的過錯所導致，排除補償請求。
補償方式與範圍
損失補償，應以金錢為之
  • 不能以「幫你修好」或「換一個新的」代替，原則上給錢。
並以補償「實際損失」為限
  • 實際損失：實際所受之特別損失，不是全額賠償（須扣掉人民本來就該忍受的部分）。
補償救濟
不服補償決定 → 訴願 → 行政訴訟
  • 對執行機關核定的補償金額不服，走行政爭訟救濟。
請求期間
知有損失後二年內
  • 主觀起算點，從人民知道有損失時起算2年。
自損失發生後，經過五年者，不得為之
  • 客觀上限，從損失發生時起算5年，不論知不知道，超過就不能請求。
管束事由
  1. 瘋狂或酗酒泥醉
    • 典型：爛醉倒臥馬路、精神失常持械自傷或傷人。
    • 注意：若屬罹患精神疾病之人，其緊急處置、送醫、強制鑑定等應優先適用精神衛生法相關規定。
  2. 意圖自殺
    • 有自殺意念且「非管束不能救護其生命」。
  3. 暴行或鬥毆
    • 典型：街頭鬥毆、持械攻擊他人。
  4. 其他認為必須救護或「有害公共安全」之虞
    • 概括條款，須達到「非管束不能救護或不能預防危害」的程度。
管束不得逾24小時
  • 法律效果：超時管束即屬違法剝奪人身自由，可能構成國家賠償責任。
扣留之標的與目的
軍器、凶器及其他危險物
  • 軍器如槍砲彈藥，凶器如刀械，其他危險物如爆裂物、腐蝕性化學品。
為「預防危害」之必要，得扣留之
  • 扣留的目的在於事前預防，不是處罰、不是證據保全、不是催繳工具。
扣留期間：不得逾30日
  • 例外1.除依法應沒收、沒入、毀棄或應變價發還者
    • 若有其他法律規定應沒收、沒入等，依各該規定處理，不受本項期間限制。
  • 例外2.扣留之原因未消失時，得延長之，延長期間不得逾兩個月
    • 延長以「原因未消失」為要件，且延長期間上限2個月。
發還與歸屬國庫
無繼續扣留必要者，應即發還
  • 原因消失（如危害已排除）即應發還，不待期滿。
於一年內無人領取或無法發還者，其所有權歸屬國庫
  • 發還不能時，經1年期間，所有權歸國庫。
其應變價發還者，亦同
  • 應變價發還的情形，1年內無人領取或無法發還，變價所得歸國庫。
對物之強制使用
情況1.遇有天災、事變
  • 例如颱風來了，橋斷了，政府需要卡車載救難物資。
情況2.交通、衛生或公共安全有危害情形
  • 例如爆發大規模傳染病。
非使用或限制使用不能達防護之目的時
  • 這是最後手段性的要件：別無他法，只能動用。
得使用、處置或限制其使用其土地、住宅、建築物、物品
  • 「使用」：如徵用卡車、借用場地。
  • 「處置」：如銷毀腐壞食品、拆除危險構造物。
  • 「限制其使用」：如禁止進入某區域、限制特定設備運轉。
強制進入建築物
對於住宅、建築物或其他處所之進入
  • 進入的客體不限於住宅，還包括建築物（如廠房、倉庫）及其他處所（如車輛、帳篷）。但住宅受到最嚴格的保護。
要件1.人民之生命、身體、財產「有迫切之危害」
  • 三種法益：生命（如有人受困火場）、身體（如傷病患需急救）、財產（如瓦斯外洩即將爆炸毀屋）。三者並列，不限於人身危險。
要件2.非進入不能救護
  • 最後手段性。如果有替代方案（如等待屋主回來開門、從其他入口進入），就不符合本要件。
