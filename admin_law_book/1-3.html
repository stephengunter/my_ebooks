行政法 1-3 基本概念及原則-依法行政與裁量

總覽

  • 依法行政與裁量，核心在於兩個層次：
    1. 行政機關的行為是否須有法律依據（依法行政、法律保留）
    2. 行政機關在有多數合法選擇時，如何行使裁量權而不致違法（裁量瑕疵、裁量收縮、判斷餘地）

依法行政原則

法律優位
  • 行政行為不得牴觸現行有效之法律，此為消極依法行政。
法律保留
  • 行政機關為特定行為須有法律依據，此為積極依法行政。
  • 保留密度依釋字第443號層級化判斷：
干預類型 保留密度 說明
剝奪人民生命或限制身體自由 絕對法律保留 須以法律定之，不得授權
限制人民其他自由權利 相對法律保留 須有法律或法律授權之命令
給付行政（非重大公益事項） 寬鬆保留 得有行政機關自由形成空間
執行法律之細節性、技術性事項 無須法律保留 得由行政機關依職權訂定
範例
  • 年終工作獎金發給注意事項 → 給付行政，不涉重大公益，不違反法律保留。

羈束處分 v.s 裁量處分

羈束處分
  • 法規對構成要件及法律效果均有明確規定，行政機關無選擇空間，符合要件即應作成特定處分。
範例
  • 社會救助法第9條「應停止」救助 → 羈束義務，機關無裁量空間。
裁量處分
  • 法規賦予行政機關在構成要件該當時，得於多數法律效果中選擇其一。
裁量權的兩個層面
  1. 決定裁量：是否採取行動。
  2. 選擇裁量：採取何種手段。
範例
  • 集會遊行法第25條「得」命令解散 → 裁量處分。
  • 空氣污染防制法第67條第2項「得」令停工、停業 → 裁量處分。

裁量瑕疵

  • 裁量並非自由無限制，行政機關行使裁量權仍受法律拘束。
三種類型裁量瑕疵
內涵 示例
裁量逾越 行政機關所選之法律效果，超出法律授權範圍 法定罰鍰上限10萬元，機關裁罰15萬元
裁量濫用 裁量之行使違反法律授權目的，或摻入與事件無關之考量 因個人好惡而重罰；以「殺雞儆猴」為由裁罰
裁量怠惰 行政機關消極不行使裁量權，或未經裁量即作成決定 一律按法定最高額裁罰，未審酌個案情節
範例
  • 行政法院對裁量處分之審查，限於合法性，不及於妥當性；但裁量逾越、濫用、怠惰均屬違法，法院得撤銷。
  • 裁量收縮（下述）→ 裁量萎縮至零，機關「必須」採取特定措施，若不作為即構成裁量怠惰。

裁量收縮（裁量縮減至零）

概念
  • 行政機關原享有裁量權，但在特定事實關係下，裁量範圍縮小至僅剩一種合法選擇。
    • 此時機關「必須」採取該措施，否則即構成裁量瑕疵而違法。
    • 又稱「裁量萎縮」或「裁量縮減至零」。
要件
  • 重大法益受迫切危險：
    • 人民之生命、身體、健康或財產等重大法益，遭受迫切而具體之危險。
  • 機關可預見危險：
    • 行政機關對危險之發生有預見可能性。
  • 機關有職權與義務：
    • 機關依法擁有採取措施之職權，且該職權係為保護人民權益。
  • 機關有迴避可能性：
    • 機關事實上能夠採取有效措施迴避危險。
  • 補充要件：
    • 私人無從自行迴避危險。
範例
  • 集會遊行法第25條：集會遊行已發生嚴重脫序行為，對在場群眾生命、身體造成迫切危險時，主管機關命令解散之裁量可能收縮至零。
  • 廢棄物清理法第8條：廢棄物緊急清理之方法、設施、處所及期限，若危害迫切，機關裁量可能收縮至零。

判斷餘地與不確定法律概念

不確定法律概念
  • 法律條文不可能把所有情況寫得鉅細靡遺，所以立法者常使用一些內涵不是百分之百精確的用語，讓行政機關在適用時有判斷空間。這種用語就叫「不確定法律概念」。
  • 常見例子：「公共利益」、「情節重大」、「顯無理由」、「有偏頗之虞」、「教學不力」、「危害公安之虞」
  • 這些概念的特點是：法律沒有明確定義它的边界，必須由行政機關在具體個案中，依當時的社會通念、專業知識來判斷「這個個案符不符合這個概念」。
關鍵區分
  • 確定法律概念：
    • 內涵明確，判斷不易有爭議。例如「年滿18歲」、「設籍滿6個月」。
  • 不確定法律概念：
    • 內涵不明確，須在個案中具體化。例如「情節重大」、「教學不力」。
行政機關適用法規的「三段論法」
  • 行政機關適用法律，基本上遵循三段論法：
    1. 大前提：法律規定（含不確定法律概念）
    2. 小前提：具體個案的事實。
    3. 結論：該個案是否該當法律要件 → 產生何種法律效果。
  • 舉例（教師法第16條第1項「教學不力」）：
    1. 大前提：教師「教學不力」者，得予解聘。
    2. 小前提：甲師上課經常遲到、教材多年未更新、學生評量成績低落。
    3. 結論：甲師是否該當「教學不力」？ → 這就是不確定法律概念的具體化
  • 關鍵問題來了：甲師的行為到底算不算「教學不力」？行政機關說「算」，甲師說「不算」，誰說了算？法院可以推翻行政機關的判斷嗎？
    • 這就是「判斷餘地」要處理的問題。
判斷餘地
基本概念
  • 當行政機關在具體化不確定法律概念時，如果該判斷涉及高度專業性、高度屬人性或高度技術性：
    • 法院原則上尊重行政機關的判斷，不輕易以自己的判斷取代行政機關的判斷。
    • 這種法院尊重行政機關判斷的空間，就叫「判斷餘地」。
  • 簡單說：判斷餘地 = 法院對行政機關「不確定法律概念具體化」的審查退讓。
為什麼要有判斷餘地？
  1. 專業能力：
    • 某些事項需要高度專業知識，法院不見得比行政機關更懂。
    • 例如：環境影響評估、藥品安全審查、學術論文審查。
  2. 屬人性判斷：
    • 某些事項涉及對人的整體評價，只有實際接觸、長期觀察的人才能作最適判斷。
    • 例如：教師教學評量、公務員考績、學生品行考核。
  3. 機關功能：
    • 某些事項涉及政策形成或資源分配，屬於行政機關的政治責任範圍，法院不宜過度介入。
    • 例如：科技產業補助、國土規劃。
判斷餘地的典型領域
領域 示例
考試評分 國家考試閱卷評分、論文口試評分
學術評量 教師升等著作審查、研究計畫審查
人事考評 公務員年終考績、陞遷圈定、教師教學不力認定
專業判斷 環境影響評估、藥品許可、建築結構安全審查
政策裁量 國土規劃、產業補助、預算分配
範例
  • 人事陞遷圈定：機關首長就前三名中圈定，屬高度屬人性判斷 → 有判斷餘地，法院低密度審查。
  • 年終考績乙等：考績評定屬人事考評 → 有判斷餘地，法院尊重。
  • 教師「教學不力」解聘：涉及教學專業評價 → 有判斷餘地。
判斷餘地不等於「法院完全不能審查」
  • 這是最容易誤解的地方。判斷餘地 ≠ 行政機關說了算。
  • 法院雖然尊重行政機關的判斷，但仍得審查以下事項（稱為「判斷瑕疵」）：
判斷瑕疵類型 內容 說明
錯誤的事實認定 行政機關基於錯誤或不完整的事實作成判斷 機關搞錯事實，判斷當然有問題
未遵守法定程序 未經法定委員會審議、未給予陳述意見機會 程序不合法，判斷結果也不可信
基於與事件無關的考量 摻入與事件無關的因素（如個人好惡、政治壓力） 不是基於專業，而是基於無關因素
違反一般公認的價值判斷標準 違反平等原則、比例原則、公益原則等 判斷結果明顯不合理
逾越判斷權限 超出法律授權的判斷範圍 法律沒給你這個權限，你卻作了判斷
違反經驗法則或論理法則 判斷明顯違背邏輯或一般經驗 判斷過程明顯有問題
範例
  • 法院不會說「我覺得甲師教學很好，所以機關的判斷錯了」；但法院會說「機關認定甲師教學不力，但所依據的事實有錯誤」或「機關沒有經過教評會審議」
    • 這些都是判斷瑕疵，法院得撤銷。
判斷餘地 vs. 裁量
裁量 判斷餘地
發生在哪個階段 法律效果的選擇階段 構成要件的認定階段
問題形式 「符合要件後，機關可以選擇甲、乙、丙三種效果，選哪個？」 「這個個案符不符合法律規定的要件？」
例子 空污法第67條：「情節重大者，得令停工、停業」→ 機關選擇停工或停業 教師法「教學不力」→ 甲師的行為算不算教學不力？
法院審查 審查裁量瑕疵（逾越、濫用、怠惰） 審查判斷瑕疵（錯誤事實、違反程序、無關考量等）
法院審查密度 原則審查合法性，不及於妥當性 原則尊重，僅審查判斷瑕疵
救濟用語 「裁量收縮」「裁量濫用」 「判斷餘地」「判斷瑕疵」
範例
  • 教師法第16條第1項：「教師教學不力（構成要件/不確定法律概念），得予解聘（法律效果/裁量）。」
    • 第一層（構成要件） ：甲師的行為算不算「教學不力」？ → 這是不確定法律概念的具體化，涉及判斷餘地。法院原則尊重，但審查有無判斷瑕疵。
    • 第二層（法律效果） ：就算甲師確實教學不力，機關「得」解聘，也可以選擇「不解聘而輔導」→ 這是裁量。法院審查有無裁量瑕疵。
法院審查密度的決定因素（釋字第553號）
  • 法院對行政機關判斷的尊重程度，不是一刀切，而是依下列因素綜合決定：
說明 對審查密度的影響
事件之性質 涉及高度專業或屬人性 越專業/屬人 → 越尊重（低密度）
基本權干預程度 對人民權利限制多大 干預越大 → 越嚴格審查（高密度）
組織之性質 是否經合議制、專業委員會 合議制/專業委員會 → 越尊重
法律規範之目的 公益維護 vs. 權利保障 權利保障目的越強 → 越嚴格審查
行政機關之專業能力 機關是否具備專業人員 專業越強 → 越尊重
行政機關之功能 政策形成 vs. 個案執行 政策形成 → 越尊重
簡單說
  • 不是所有判斷餘地都一樣大。
    • 越專業、越屬人、干預越小的事項，法院越尊重。
    • 越涉及基本權、越不專業、程序越有問題的事項，法院審查越嚴格。
考古題
  • 題目一：人事陞遷圈定
  • 事實：機關首長就陞遷名冊前三名中圈定第三名乙，第一名丙不服。
  • 分析：
    • 圈定屬高度屬人性判斷（首長對部屬的整體評價）→ 有判斷餘地。
    • 法院採低密度審查，僅審查：圈定是否基於錯誤事實？有無無關考量（如報復）？程序是否合法？有無違反一般價值判斷標準？
    • 丙若僅主張「我積分最高，應該圈我」→ 法院不會介入，因為積分高低不等於首長綜合判斷。
    • 丙若主張「首長是因為我檢舉他才不圈我」→ 涉及無關考量，法院得審查。
  • 題目二：年終考績乙等
  • 事實：甲因勤餘酒駕肇事，年終考績列乙等。
  • 分析：
    • 考績評定屬人事考評 → 有判斷餘地。
    • 法院尊重機關判斷，但審查：考評程序是否合法？事實認定有無錯誤？有無無關考量？
    • 甲若主張「考評委員未經合法組成」→ 程序瑕疵，法院得撤銷。
    • 甲若主張「我工作表現很好，應該甲等」→ 法院不會介入，因為這是機關的判斷餘地。
  • 題目三：教師「教學不力」解聘
  • 事實：乙校認定甲師教學不力，依教師法第16條第1項解聘。
  • 分析：
    • 「教學不力」是不確定法律概念 → 涉及判斷餘地。
    • 法院尊重學校的教學專業判斷，但審查：認定事實有無錯誤？教評會程序是否合法？有無無關考量？
    • 甲師若主張「學校未經教評會審議」→ 程序瑕疵，法院得撤銷。
    • 甲師若主張「我教學很好」→ 法院不會以自己的教學評價取代學校的判斷。
易錯陷阱
認為「判斷餘地 = 法院完全不能審查」 錯。法院仍審查判斷瑕疵（錯誤事實、違反程序、無關考量等）
認為「不確定法律概念 = 裁量」 錯。不確定法律概念是構成要件的認定，裁量是法律效果的選擇
認為「所有不確定法律概念都有判斷餘地」 錯。
  • 只有涉及高度專業、屬人性、技術性者，才有判斷餘地
  • 一般的不確定法律概念（如「公共利益」），法院仍可全面審查
認為「判斷餘地 = 行政機關說了算」 錯。判斷瑕疵仍可撤銷，只是法院不取代機關的專業判斷
認為「裁量瑕疵與判斷瑕疵是同一回事」 錯。
  • 裁量瑕疵發生在法律效果階段
  • 判斷瑕疵發生在構成要件階段
總結
  • 不確定法律概念是法律用語的模糊地帶；判斷餘地是法院對行政機關具體化這些概念時的尊重退讓。
    • 但尊重不等於放任，法院仍審查判斷瑕疵。
  • 裁量是法律效果階段的選擇問題，與判斷餘地分屬不同層次。
