行政法 3-4 行政作用法 - 行政契約

總覽

  • 本節處理的核心問題是：
    • 行政機關除了以單方的高權行為（行政處分）規制人民權利義務外，能否以「契約」這種雙方合意的方式來達成行政任務？
    • 行政契約與私法契約如何區別？行政契約的無效事由、調整機制與強制執行有何特殊規定？

總結
  • 行政契約是雙方合意設定、變更或消滅公法上法律關係的行為。其類型包括和解契約與雙務契約。
  • 情事變更時得請求調整或終止；行政機關為防止公益重大危害得補償後終止。
  • 強制執行須有自願接受執行之約定。
  • 爭議救濟走一般給付訴訟或確認訴訟，而非撤銷訴訟。

行政契約之容許性（契約自由原則與限制）

公法上法律關係，得以契約設定、變更或消滅之
  • 公法上法律關係：指受公法（憲法、行政法、稅法、環境法等）規範的法律關係。
    • 特徵：至少有一方當事人為行政機關，且涉及公共利益的實現。
    • 例子：補助關係（機關補助民間團體）、土地開發協議（都市更新、區段徵收）
但依其性質或法規規定不得締約者，不在此限
  • 有些事（如宣戰、徵稅）不適合用簽約的，或者法律說不能用簽約的，那就不能簽。
  • 依其性質不得締約：涉及「高權核心領域」的事項（如國家安全、軍事指揮、刑罰權行使、稅額核定）
  • 法規規定不得締約：法律明文禁止以契約方式為之。例如：某些法規規定特定事項「應以行政處分為之」，即排除契約。
例1：得締結行政契約——補助契約
  • 文化部為推廣藝術活動，與某藝文團體簽訂「補助契約」，約定文化部補助100萬元，藝文團體須舉辦10場公開演出，並於活動結束後提交成果報告。
  • → 公法上之補助關係，得以契約設定、變更或消滅
例2：法規規定不得締約——兵役徵集
  • 兵役法規定，役男應依徵集令入營服役。 主管機關不得與役男簽訂「自願入營契約」來代替徵集令。
  • 兵役徵集涉及國家高權，應以行政處分為之。
  • → 「法規規定不得締約」（或性質不得締約）

行政和解契約（代替行政處分）

  • 簡單記：政府查不清楚事實或法律爭議時，可以跟人民和解、簽契約，代替行政處分。
行政機關對於行政處分所依據之「事實或法律關係」
  • 行政處分所依據之事實：例如：裁罰處分所需認定的違規行為是否發生、發生在何時何地、行為人是誰。
  • 法律關係：例如：雙方之間是否存在公法上債權債務關係、是否適用特定法規、是否有管轄權等。
經依職權調查「仍不能確定」者
  • 依職權調查：行政機關應主動調查事實及證據，不受當事人主張拘束。
  • 仍不能確定：
    • 事實真偽不明（如證據不足、證人記憶不清、關鍵文件遺失）
    • 法律關係有重大爭議（如法規解釋有分歧、最高法院見解尚未統一）
  • 注意：機關不能「故意不調查」；必須已盡合理調查義務（如調閱資料、詢問證人、鑑定）
為有效「達成行政目的」，並「解決爭執」
  • 簽約是為了「把事情解決掉」，同時要符合政府的政策目標。
得與人民「和解」，「締結行政契約」，以代替行政處分
  • 政府可以跟你「談條件」，簽一份契約，代替原本要發給你的那張「處分書」。
  • 得：裁量權。機關可以選擇和解，也可以選擇不作成處分、或作成就爭議的處分（讓人民去訴願、訴訟）。
  • 和解：雙方互相讓步。人民可能放棄部分權利、負擔部分義務；機關也可能減免處罰或給付。
  • 締結行政契約：須以書面為之，內容不得違反強制規定或公序良俗。
  • 以代替行政處分：一旦締約，機關即不得再就同一事件作成行政處分（除非契約另有保留）。
例1：事實不明——和解契約
  • 環保局稽查某工廠，發現河川有污染物，懷疑是該工廠排放， 但監視器未拍到、科學鑑定也無法100%確定污染源。
  • 雙方為避免訴訟，達成和解：工廠自願繳納60萬元（法定最高可能為100萬元） 作為環境改善基金，環保局則不再追究。
  • → 事實經調查仍不能確定，為達成行政目的（環境保護）並解決爭執，締結行政和解契約，代替裁罰處分
例2：不得和解——事實已明確
  • 警察取締酒駕，酒測值明確超標（0.55mg/L），事實已確定。警察不得與駕駛人「和解」說「你繳一半罰款，我們就不移送」。
  • → 事實已確定，無「不能確定」。仍應依法作成行政處分（罰單）

雙務行政契約之要件（互負給付義務）

  • 簡單記：雙方都要付錢/東西的行政契約，要有限制——
    • 用途特定、有助公務、對等關聯；
    • 羈束處分替代契約不能亂要東西。
行政機關與人民締結行政契約，「互負給付義務」者
  • 互負給付義務：雙方各自負有給付義務（如政府給補助款，人民提供勞務或服務）。
應符合下列規定︰
  1. 契約中應約定人民給付之「特定用途」
    • 要寫清楚「你給的錢或東西，只能用在某個特定目的上」。
    • 特定用途：必須具體明確，例如「供環境保護基金使用」、「作為偏鄉教育推廣經費」。
  2. 人民之給付有助於行政機關執行其職務
    • 人民的給付須與機關的法定職務有關，且對職務之執行有積極幫助。
    • 不得是「無關的捐贈」或「單純的利益輸送」。
  3. 人民之給付與行政機關之「給付應相當」，並具有「正當合理之關聯」
    • 相當：比例原則——給付與對待給付之間不能顯失公平。例如：政府給1,000萬元補助，要求人民提供價值僅1萬元的服務 → 可能不相當。
    • 正當合理之關聯：不當連結禁止原則—— 人民的給付必須與行政機關給付的「目的」有合理關聯。
      • 例如：政府發建照（目的：合法建築）， 要求人民捐贈公園用地（有合理關聯，因涉及都市計畫）→ 正當關聯。
      • 要求人民捐獻給某政黨 → 不當關聯，違反本款。
契約「應載明」人民給付之「特定用途」及僅供該特定用途使用之意旨
  • 合約上要白紙黑字寫清楚「你給的錢只能用在○○○，不能挪作他用」。
羈束處分替代契約之限制
行政處分之作成，行政機關「無裁量權」時
  • 無裁量權：即「羈束處分」——法律規定機關只能為特定處分，別無選擇。
代替「羈束處分」之行政契約，所約定之人民給付，以「確保法定要件之履行」為限
  • 無裁量權時，僅於「法律有明文規定」或「為確保行政處分法定要件之履行」時，始得附款。
  • 此限制延伸至行政契約：契約要求人民的給付，不得超過「如果作行政處分時可以附加的附款」的範圍。
例1：合法雙務契約——符合三款
  • 市政府與某民間停車場管理公司簽訂契約，約定： 市政府將公有停車場委託公司經營（政府的給付）， 公司每年繳納權利金100萬元（人民的給付），該權利金「專用於停車場周邊環境改善」（特定用途）。
  • 公司之給付有助於市府執行停車場管理職務，且100萬元與停車場經營權價值相當，具有正當關聯。
  • → 雙務契約，給付有正當關聯
例2：羈束處分替代契約超限
  • 依法律規定，符合特定條件者，機關「應」發給某種許可（羈束處分）。
  • 機關與申請人簽約，要求申請人額外「提供100萬元回饋金」作為締約條件，而該條件並非「確保法定要件履行」之合法附款。
  • → 羈束處分，約定之人民給付非「確保法定要件履行」之合法附款，該契約無效

行政契約之無效

行政契約準用民法規定之結果為無效者，無效
  • 如果按照民法的標準，這個契約是無效的，那行政契約也跟著無效。
  • 無效：行政契約「自始、當然、確定」不生效力。
代替行政處分之行政契約，有下列情形之一者，無效︰
  • 代替行政處分之行政契約：指行政機關以契約「取代」原本應作成之行政處分（例如以和解契約取代裁罰處分、以雙務契約取代許可處分）。
  1. 與其內容相同之行政處分為無效者
    • 如果處分本身就是廢紙一張（無效），那用來代替它的契約也是廢紙。
    • 例子：處分因「不能由書面得知處分機關」而無效，代替該處分之契約亦無效。
  2. 與其內容相同之行政處分，「有得撤銷之違法原因」，並「為締約雙方所明知」者
    • 雙方都知道這個處分是違法的，還故意簽約來代替它，契約無效。
    • 有得撤銷之違法原因：處分違法，但尚未達到無效程度（例如違反程序規定、事實認定錯誤）。
    • 例子：機關明知某裁罰處分已逾時效（不得裁罰），仍與人民簽約約定「繳納一定金額代替裁罰」。
  3. 不符合法定要件的和解契約
    • 和解契約法定要件：
      1. 經依職權調查，事實或法律關係「未能確定」
      2. 為「有效達成行政目的」或「解決爭執」
    • 例子：事實已明確（如酒測值超標），機關卻與人民和解「繳一半罰款了事」。
  4. 違反規定的雙務契約
    • 雙務契約規定：
      1. 人民之給付應約定特定用途
      2. 人民之給付有助於行政機關執行其職務
      3. 人民之給付與行政機關之給付應相當，並具有正當合理之關聯。
      4. 羈束處分替代契約，人民給付超出附款範圍
    • 例子：機關發許可（羈束處分），要求人民「捐贈100萬元給機關員工旅遊基金」（不當關聯）。
一部無效之效力
原則：一部無效，「全部無效」
行政契約之一部無效者，全部無效
  • 一部無效：契約中的某個條款或某部分，為無效。
  • 全部無效：整個行政契約自始、當然、確定不生效力。
  • 理由：行政契約通常具有整體性，各條款間互有關聯；一部分無效可能破壞整體的公平性或功能。
例外：如可認為「欠缺該部分」，締約雙方「亦將締結契約」者，其他部分仍為有效
  • 可認為：客觀判斷，以締約時之情況為準（而非事後當事人的主觀意願）。
  • 欠缺該部分：將無效的條款刪除後，剩餘的契約內容。
  • 締約雙方亦將締結契約：雙方在締約時，如果知道該部分會無效，是否「仍然願意」簽訂「沒有該部分的契約」？
    • 判斷因素：該部分是否為契約的核心要素？刪除後是否嚴重影響契約目的？雙方是否有其他替代安排？
  • 其他部分仍為有效：僅無效之條款失效，其餘條款繼續有效。
例1：一部無效，全部無效
  • 甲市政府與乙公司簽訂BOT契約，其中第10條約定「乙公司每年捐贈100萬元給市長私人帳戶」（違反公序良俗，無效）。
  • 該條款為契約之核心對價之一，刪除後雙方顯然不會簽約（因為市府可能因此不給BOT案）。
  • → 一部無效，全部無效
例2：例外——其他部分仍為有效
  • 丙機關與丁團體簽訂補助契約，其中第5條約定「丁團體應於活動結束後15日內提交成果報告」，但該條款因違反某程序規定而無效。
  • 若刪除該條款，剩餘契約仍完整（補助金額、活動內容等均不受影響），且可認為雙方即使沒有該條款，仍會簽訂補助契約。
  • → 其他部分仍為有效（僅第5條無效）

行政契約履約費用增加之損失補償

補償請求權之發生
行政契約當事人之一方為人民者，其締約後
  • 政府與民間簽約之後。
因締約機關所屬公法人之「其他機關」於契約關係外「行使公權力」
  • 同一個政府（國家或地方自治團體）裡，不是簽約的那個單位，在契約以外行使公權力。
致相對人履行契約義務時，「顯增費用」或受其他「不可預期之損失」者
  • 害你履約成本大增，或受到其他沒想到的損失。
效果：相對人得向締約機關「請求補償」其損失
  • 可以跟「簽約的那個單位」請求「補償」。
請求時效：1年
補償之請求，應自相對人「知有損失」時起「一年內」為之
  • 從你知道有損失的那天起，1年內要提出請求。
締約機關書面決定
締約機關就補償請求，應以書面決定並敘明理由
  • 簽約的機關收到請求後，必須用書面回覆，寫清楚理由。
給付訴訟救濟
相對人「不服補償金額」，或其他補償爭議，得向行政法院提起「給付訴訟」，免先訴願
  • 包括機關拒絕補償、補償金額不合理、補償範圍爭議。免除訴願程序，直接提起一般給付訴訟。
例1.
  • 甲市政府環保局與某廢棄物處理廠商簽訂「廢棄物處理行政契約」
  • 契約履行期間，甲市都市發展局將該廠商所在區域劃設為「環境敏感地區」，要求所有工廠增設汙染防制設備。廠商因此增加設備支出500萬元。
  • 都市發展局為締約機關（環保局）所屬公法人（甲市）之其他機關，行使公權力（劃設環境敏感地區）
  • 致廠商顯增費用，且與契約履行有直接關聯（處理廢棄物須符合環保標準）
  • → 其他機關行使公權力，致廠商顯增費用，且與契約履行有直接關聯，廠商得向環保局請求補償

行政機關調整契約與終止契約

機關之調整或終止權
行政契約當事人之一方為人民者
  • 契約一方為行政機關，他方為人民。
行政機關為防止或除去「對公益之重大危害」
  • 為了阻止或消除會嚴重傷害公共利益的事。
效果：得「於必要範圍內」調整契約內容或終止契約
  • 政府可以在必要的範圍內，把合約內容改掉，或直接解約。
人民之終止權（對調整之反應）
相對人對機關之調整「難為履行」者，得以書面敘明理由「終止契約」
  • 政府把合約改得太硬，人民做不下去的話，可以自己提解約。
  • 注意：此項終止不影響人民依第2項請求補償的權利（因機關的調整已造成損失）。
補償義務
機關調整或終止契約，非「補償相對人」因此所受之「財產上損失」，不得為之
  • 政府要改約或解約，必須賠償人民的財產損失，否則不能改、不能解約。
書面與理由
機關調整或終止契約及補償之決定，應以書面敘明理由為之
  • 政府的決定要寫成書面文件，寫清楚為什麼要改、為什麼賠這個數字。
補償之救濟：給付訴訟
相對人對補償金額不同意時，得向行政法院提起「給付訴訟」，免先訴願
  • 對賠償金額不滿，可以直接告法院，不用先訴願。
例1.
  • 甲市政府與某化學廠商簽訂「廢棄物處理契約」。
  • 締約後，科學研究發現該化學物質有劇毒，若繼續處理將對周邊居民健康造成重大危害。
  • 市政府依第146條第1項終止契約，並補償廠商已投入的設備成本500萬元。
  • → 為防止公益重大危害，終止契約並補償
例2.
  • 乙機關與某停車場經營廠商簽訂BOT契約。
  • 締約後，因應環保法規提高，機關調整契約要求廠商增設電動車充電設備。
  • 機關承諾補償該200萬元。
  • 廠商對機關之補償金額，向行政法院提起給付訴訟，請求判命機關給付300萬元。
  • → 機關調整契約，補償損失。廠商不服補償金額，向行政法院提起給付訴訟

行政契約因情事變更調整

情事變更之調整與終止
行政契約締結後，有「情事重大變更」，非當時所得預料
  • 情事重大變更：簽約後，外在環境發生重大變化。（如法律、經濟、自然環境、技術發生重大改變）
  • 非當時所得預料：締約時，依一般理性人之標準，無法合理預見該變更。
而依原約定「顯失公平」者
  • 顯失公平：給付與對待給付嚴重失衡，或一方履行成本暴增，或契約目的無法達成。
當事人之一方得「請求他方適當調整」契約內容
  • 當事人之一方：人民或行政機關均得請求。
  • 適當調整：按變更後之情事，合理修改契約內容（如調整給付金額、期限、方式）。
如不能調整，得終止契約
  • 如果不能改，就可以解約。
行政機關為公益強制繼續履行
前項情形，行政契約當事人之一方為人民時
  • 當事人一方為行政機關，他方為人民。
行政機關為維護公益
  • 為維護公益：若人民終止契約或調整內容，將影響公共利益（如公共服務中斷、安全風險）。
得於「補償相對人之損失」後，「命其繼續履行」原約定之義務
  • 於補償相對人之損失後：必須先補償人民因情事變更所受的損失（實際損失，非預期利益）。
  • 命其繼續履行原約定之義務：機關以「行政處分」命人民依「原契約內容」繼續履行（不得調整）。
書面與理由
請求調整或終止與補償之決定，應以書面敘明理由為之
  • 機關對於人民請求調整之回應，或機關主動為強制繼續履行，均應以書面為之，附理由。
補償之救濟：給付訴訟
相對人對補償金額不同意時，得向行政法院提起「給付訴訟」，免先訴願
  • 對補償金額不滿，可以直接告法院，不用先訴願。
例1.
  • 甲與市政府簽訂BOT契約興建停車場。
  • 締約後，政府突然將該區域劃為「徒步區」，禁止車輛進入（情事重大變更，非可預料）。
  • 甲經營停車場已無意義，依原約定顯失公平。甲請求市政府調整契約內容（如變更為商場），或終止契約。
  • → 情事重大變更，原約定顯失公平，人民請求調整契約
例2.
  • 同上例1，但該停車場為該區域唯一大型停車場，若終止將導致周邊交通癱瘓（重大公益）
  • 市政府補償甲之損失後，命甲繼續經營停車場（原約定）。
  • 機關承諾補償該200萬元。
  • → 機關得為維護公益，補償後命繼續履行

自願接受執行條款

自願接受執行之約定與效果
行政契約「約定自願接受執行」時
  • 雙方在契約條款中明確約定「債務人不履行時，他方得逕行強制執行」。
債務人不為給付時
  • 債務人：依契約負有給付義務之一方（可能是人民，也可能是機關）。
  • 不為給付：屆期未履行、拒絕履行、不完全履行等。
債權人得以該契約為「強制執行之執行名義」
  • 不用告，債權人直接拿契約書正本（及認可文件）聲請強制執行。
強制執行之程序
強制執行，準用行政訴訟法有關強制執行之規定
  • 執行的程序，比照行政訴訟判決的強制執行來辦理。
認可程序
「自願接受執行」之約定，締約之一方為中央行政機關時，應經主管院、部或同等級機關之認可
  • 中央政府簽約要自願接受執行，要報上級（院或部）批准。
締約之一方為地方自治團體之行政機關時，應經該地方自治團體行政首長之認可
  • 地方政府簽約要自願接受執行，要報市長、縣長批准。
契約內容涉及委辦事項者，並應經委辦機關之認可，始生效力
  • 如果是上級委託辦的事，還要經過委託的機關批准。
例1.
  • 經濟部（中央機關）與某廠商簽訂BOT契約，契約第20條約定「雙方自願接受強制執行」。
  • 該條款經經濟部報請行政院認可。
  • 約定有效，不履約時得逕行強制執行。
  • → 有效之自願接受執行約定
例2.
  • 內政部委託臺北市政府辦理某項業務，臺北市政府與廠商簽約，約定自願接受執行。
  • 除須經市長認可外，尚須經內政部（委辦機關）認可。
  • → 須經委辦機關認可，始生效力
