行政法 1-5 基本概念及原則-行政法上之法律關係

總覽

  • 行政法上之法律關係處理三個層次的問題：
    1. 行政法上法律關係如何發生、變更、消滅。
    2. 公務人員與國家之間的法律關係（特別權力關係的演變）
    3. 人民與國家之間的公法上請求權與公法上債之關係。

總結
  • 人民與國家之法律關係，核心在於保護規範理論——判斷人民究竟有公法上權利（得提行政爭訟）還是僅有反射利益（不得救濟）。
    • 反射利益是法律執行時「順便」帶給人民的好處，不是法律「特意」賦予的權利。
    • 公法上請求權之類型包括法律明文、行政處分、行政契約、一般法律原則（特別犧牲補償）、公法上不當得利等。
  • 公法上不當得利之5年時效，自撤銷處分生效時起算。

行政法上法律關係之概念

定義
  • 行政法上法律關係，係指人民與國家（或行政機關）之間，或行政機關相互之間，基於行政法規所發生的權利義務關係。
特徵
  • 當事人：一方為國家或行政機關，他方為人民或另一行政機關。
  • 發生原因：法律規定、行政處分、行政契約、事實行為、公法上不當得利等。
  • 內容：權利、義務、負擔、限制。

人民之公法上權利

公法上權利之意義
  • 人民基於公法法規，得向國家請求為一定給付（作為、不作為或容忍）之法律上地位。
  • 公法上權利須有法律依據，並非所有人民因行政行為所受之利益均屬之。
核心要素
  • 請求權人：人民（自然人、法人）
  • 義務人：國家或行政機關。
  • 請求內容：一定作為、不作為或容忍。

保護規範理論

概念
  • 保護規範理論係判斷人民是否具有公法上權利（進而具備訴訟權能）之核心標準。
  • 其問題意識為：法律規定之目的，除維護公共利益外，是否兼有保護特定個人之個別利益？
判斷步驟
  1. 探求系爭法規之立法目的
  2. 判斷該法規是否兼有保護特定個人之目的
  3. 若兼有保護個人目的 → 該個人有公法上權利，得提起行政爭訟
  4. 若僅以維護公益為目的 → 個人僅有反射利益，不得提起行政爭訟
判斷方法
  1. 文義解釋：法規用語是否指向特定個人或可得確定之人群。
  2. 體系解釋：法規在整體法秩序中之地位與功能。
  3. 目的解釋：立法理由、立法過程中所揭示之保護目的。
  4. 歷史解釋：法規制定時之社會背景與立法者意圖。
保護規範理論與裁量權
情形 人民之請求權
法規構成要件明確，裁量收縮至零 得請求機關作成特定處分
法規賦予機關裁量空間 僅得請求機關無瑕疵裁量，不得請求特定內容

政府資訊公開法 保障人民知的權利 有（人民得請求提供資訊）

反射利益

定義
  • 反射利益係指法律規範之目的僅在於維護公共利益，人民因行政機關執行法律而偶然享受到之事實上好處。
  • 此種好處並非法律特意賦予個人之權利，因此當其受侵害時，人民原則上不得提起行政爭訟。
性質
  • 反射利益是事實上的利益，是法的反射性效果，而非法律對特定個人予以保護的權利。
  • 與公法上權利之區別，在於法律目的是否兼有保護特定個人。
與公法上權利之區別
公法上權利 反射利益
法律目的 兼有保護特定個人 僅維護公益
利益性質 法律特別賦予之權利 事實上的好處、附帶效果
救濟可能性 得提起行政爭訟 原則上不得
釋字第469號解釋
  • 若法律雖係為公共利益而設，但就法律之整體結構、適用對象、所欲產生之規範效果等綜合判斷：
    • 可得知亦有保障特定人之意旨，且機關對可得特定之人負有作為義務已無裁量空間時：該受保護之人即有公法上請求權。
    • 反之，若法規僅以公共利益為目標，人民所受利益即屬反射利益。
範例
利益性質 結論
公園旁住戶A不服兒童遊樂設施禁止使用 反射利益 欠缺訴訟權能，撤銷訴訟不合法
餐廳油煙之鄰居請求開罰 公法上權利 空污法兼保護鄰居健康，有訴訟權能
實務趨勢：反射利益之限縮
  • 現代行政法學說與實務逐漸認識到，若過度擴大反射利益之範圍，將導致人民權利保障出現漏洞。
  • 尤其當行政不作為涉及人民生命、身體等核心法益時，更應審慎認定，不宜輕易以反射利益為由否定人民之救濟權利。

特別犧牲補償請求權

概念
  • 特別犧牲（Sonderopfer）係指國家基於公益目的，對人民之自由權利所為之限制或干預，已逾越人民社會責任所應忍受之範圍，形成對特定個人之個別損害。
    • 此時國家應給予合理補償，方符憲法保障人民權利之意旨。
  • 其核心在於區別「社會義務」與「特別犧牲」：
    • 社會義務：人民享受財產權等權利時，本應承受之一般性限制（如遵守建築法規、交通規則），無須補償。
    • 特別犧牲：限制程度已逾越社會義務範圍，對特定人造成不平等之負擔，應予補償。
憲法基礎與釋字發展
  • 釋字第336號：公共設施保留地長期未取得，對土地所有權人形成個別損害，應予補償；但「如何檢討修正有關法律，係立法問題」
  • 釋字第400號：財產權應受保障，惟因社會責任而受限制，若形成個人利益之特別犧牲，社會公眾因而受益者，應享有相當補償之權利。
  • 釋字第400號：財產權應受保障，惟因社會責任而受限制，若形成個人利益之特別犧牲，社會公眾因而受益者，應享有相當補償之權利。
  • 釋字第440號：機關埋設地下設施物既不徵購又未設補償規定，與憲法保障財產權意旨不符。
  • 釋字第747號：需用土地人因興辦事業穿越私有土地上空或地下，致逾越社會責任忍受範圍，形成特別犧牲者，土地所有權人得請求需用土地人向主管機關申請徵收地上權。
成立要件
  • 依釋字第564號解釋意旨，並非一切對財產權之限制均構成特別犧牲，須符合：
    • 公益目的：國家基於公共利益所為之限制或干預。
    • 逾越忍受範圍：限制程度已超過人民社會責任所應忍受之範圍。
    • 比例原則檢驗：若手段適當且限制輕微，屬合理社會義務，不構成特別犧牲；若違反比例原則，則構成特別犧牲。
    • 個別損害：對特定人造成不平等之負擔，而非一般性限制。
請求權之性質與實務困境
  • 請求權內容：人民得請求國家給予合理補償。釋字第747號進一步承認，於特定情形下，土地所有權人得主動請求徵收以獲得補償。
  • 實務困境：
    • 釋字第336號雖認公共設施保留地長期未取得可能構成特別犧牲，但明言「係立法問題」，未賦予人民直接請求權。
    • 釋字第747號則突破此限制，於土地遭實際穿越之情形，明確賦予土地所有權人請求徵收地上權之權利。
    • 學理上認為，特別犧牲補償請求權雖具憲法層次依據，但補償法定原則（須俟法規修正完成，人民始得請求補償給付）仍為實務運作之限制。
範例
公共設施保留地歷經20年未徵收
  • 依釋字第336號解釋意旨，可能構成特別犧牲。
  • 但該號解釋未賦予人民直接請求權，實務多認為屬立法形成空間。
  • 結論：乙難以直接透過課予義務訴訟請求徵收補償。
土地遭公路穿越地下（釋字第747號）
  • 土地所有權人得請求需用土地人向主管機關申請徵收地上權。
  • 此為特別犧牲補償請求權具體化為請求徵收之適例。
簡單說
  • 特別犧牲補償請求權是人民因公益承受逾越社會義務之負擔時，請求國家補償之權利。

公法上不當得利

概念
  • 公法上不當得利，係指在公法範疇內，欠缺法律上原因而發生財產變動，致一方得利、他方受損害之謂。
  • 於依法行政原則，不合法之財產變動應予回復，受損害之一方對受有利益之一方，即有不當得利返還請求權。
核心要件
  • 財產變動：一方受有利益，他方受有損害。
  • 公法範疇：發生於公法關係中（非私法契約）
  • 欠缺法律上原因：給付之法律依據不存在或嗣後消滅。
類型
  • 特殊公法上不當得利
    • 授予利益之行政處分經撤銷、廢止或條件成就而溯及失效，受益人應返還所受領給付。
    • 法律依據：行政程序法第127條：
      1. 授予利益之行政處分，其內容係提供一次或連續之金錢或可分物之給付者，經撤銷、廢止或條件成就而有溯及既往失效之情形時，受益人應返還因該處分所受領之給付。其行政處分經確認無效者，亦同。
      2. 前項返還範圍準用民法有關不當得利之規定。
      3. 行政機關依前二項規定請求返還時，應以書面行政處分確認返還範圍，並限期命受益人返還之。
      4. 前項行政處分未確定前，不得移送行政執行。
  • 一般公法上不當得利
    • 非基於行政處分而生之公法上財產變動（如無效行政契約之給付、誤寫誤算之給付）
    • 不成文請求權，類推適用民法。
特殊公法上不當得利：行政程序法第127條
  • 成立前提：授予利益之行政處分（提供一次或連續之金錢或可分物給付），經撤銷、廢止或條件成就而有溯及既往失效之情形；或行政處分經確認無效者。
  • 返還範圍：準用民法有關不當得利之規定（第127條第2項）。
  • 請求方式：行政機關應以書面行政處分確認返還範圍，並限期命受益人返還（第127條第3項）。該處分未確定前，不得移送行政執行（第127條第4項）。
  • 時效：依行政程序法第131條第1項，公法上請求權因5年間不行使而消滅。
  • 時效起算點：實務見解認為，自撤銷處分生效時起算，非自各月受領時起算。
    • 「迨原處分機關撤銷原處分後，使處分失其效力，受領人因原處分所受領給付始構成不當得利，原處分機關對之始發生給付返還請求權，請求權消滅時效自撤銷處分生效時起算。」
一般公法上不當得利
  • 適用情形：非基於行政處分而生之公法上財產變動，例如：
    • 無效行政契約所為之給付。
    • 給付對象錯誤、誤寫誤算。
    • 給付違反行政處分內容。
  • 請求方式：因無行政程序法第127條之適用，行政機關應依行政訴訟法第8條第1項提起一般給付訴訟請求返還。
  • 返還範圍：類推適用民法第181條、第182條規定。
範例
社會救助溢領
  • 甲隱匿現金致獲核准救助 → 原核准處分屬違法授益處分。
  • 甲信賴不值得保護（行政程序法第119條第2款）→ 社會局得撤銷原處分。
  • 撤銷後依行政程序法第127條，以書面行政處分命甲返還溢領款項。
敘薪撤銷後溢領薪資
  • B撤銷原敘薪處分，重新核定較低薪額 → 原處分溯及失效。
  • 甲溢領之薪資構成公法上不當得利。
  • 依行政程序法第127條命返還；5年時效自撤銷處分生效時起算，非自各月受領時起算。
  • 甲主張時效已消滅 → 無理由（起算點錯誤）。
易錯陷阱
認為公法上不當得利時效自「各月受領時」起算 錯。自撤銷處分生效時起算
認為所有公法上不當得利均依行政程序法第127條請求 錯。第127條僅適用於基於授益處分經撤銷、廢止或無效之情形；一般公法上不當得利應提起一般給付訴訟
認為行政機關得逕行移送行政執行追討 錯。依第127條第4項，命返還之處分未確定前不得移送執行
認為特別犧牲補償請求權均可直接請求 錯。釋字第336號情形仍屬立法形成；釋字第747號始明確賦予請求徵收之權利
